# A股 P0 首轮验证与原型输入清单

更新时间：2026-07-12

## 用途

- 把 `A股_P0_验证任务单__20260711.md` 中分散的输入项收成一张首轮执行前准备清单。
- 让后续数据验证、低保真原型和文案验证不需要再逐张任务卡回找输入前提。
- 明确当前缺的是“哪些输入和素材”，而不是重新讨论 P0 合同本身。

## 使用边界

- 当前只覆盖 `T01 ~ T08` 的首轮最小输入准备。
- 当前不覆盖：
  - 数据供应商选型
  - 数据库存储结构
  - API 设计
  - 正式前端实现

## 数据侧最小输入

### D01 日线行情与量能

- 最小需要：
  - A 股日线 `OHLCV`
  - 复权口径说明
  - 指数基准数据
- 主要服务：
  - `T01 量价阈值触发密度验证`
  - `T04 行业轮动阈值敏感度验证`
  - `T05 历史类比样本门槛验证`

### D02 行业与标的映射

- 最小需要：
  - 个股与行业/板块映射表
  - 常用宽基与行业指数清单
- 主要服务：
  - `T04 行业轮动阈值敏感度验证`
  - `T05 历史类比样本门槛验证`

### D03 资金异动数据

- 最小需要：
  - 主力资金字段
  - 北向资金字段
  - 字段更新时间说明
- 可选补充：
  - 融资融券字段，用于验证“是否应继续排除”
- 主要服务：
  - `T02 主力资金主触发验证`

### D04 业绩事件数据

- 最小需要：
  - 业绩预告/快报样本
  - 是否可获得一致预期口径的可得性说明
- 主要服务：
  - `T03 业绩预期差降级验证`

## 原型与文案侧最小输入

### P01 桌面端低保真

- 最小需要：
  - 首页四卡草图
  - `事件流 -> 解释卡 -> 决策记录` 同屏主工作区
  - 历史决策追踪的次级位置
- 主要服务：
  - `T06 影响推演文案理解验证`
  - `A股_P0_首页原型审阅清单__20260711.md`
  - `A股_P0_桌面端低保真框架__20260712.md`

### P02 移动端低保真

- 最小需要：
  - 事件流首屏
  - 底部抽屉或固定底栏方案
  - 键盘弹起时的字段可见性检查位
- 主要服务：
  - `T07 移动端共用工作区验证`
  - `A股_P0_移动端低保真框架__20260712.md`

### P03 解释卡文案样本

- 最小需要：
  - `6` 类事件各 `1` 组短模板
  - 一组“简版”
  - 一组“完整模板版”
- 主要服务：
  - `T06 影响推演文案理解验证`

### P04 动作与理由标签样本

- 最小需要：
  - `动作` 词表示例
  - `理由标签` 词表示例
  - `调仓`、`观察` 的边界样例
- 主要服务：
  - `T08 调仓动作理解验证`

## 首轮必须产出

- 数据侧：
  - 量价阈值触发密度摘要
  - 主力/北向职责分工建议
  - 行业轮动伪触发样例
  - 历史类比样本门槛建议
- 原型侧：
  - 桌面端首页低保真
  - 移动端首页低保真
  - 文案理解反馈
  - 动作词歧义记录

## 当前阻塞项

- `一致预期` 是否稳定可得，当前仍未锁死。
- `主力资金` 与 `北向资金` 的字段口径仍需统一。
- 移动端低保真原型当前还未形成可点击样稿。

## 当前建议准备顺序

1. 先整理数据字段与样本范围
2. 再出桌面端首页低保真
3. 再出移动端首页低保真
4. 先跑 `T01`、`T02`、`T04`、`T05`
5. 再补 `T03`、`T06`、`T07`、`T08`
