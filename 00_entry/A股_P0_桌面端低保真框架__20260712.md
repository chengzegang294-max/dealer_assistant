# A股 P0 桌面端低保真框架

更新时间：2026-07-12

## 用途

- 把 `A股_P0_首页线框与点击流__20260711.md` 继续压成桌面端可直接出低保真的 frame 级说明。
- 让画稿、评审和后续可点击原型都围绕同一套区域划分与状态切换，不再靠口头补充。
- 保证桌面端首页仍然围绕 `事件流 -> 解释卡 -> 决策记录 -> 回看` 这条主路径。

## 使用边界

- 当前只定义桌面端首页低保真的结构、区域、状态和出稿注意事项。
- 当前不定义：
  - 视觉风格
  - 品牌语言
  - 精细动效
  - 正式前端组件命名

## 首屏目标

- 用户进入首页后，第一眼先看见 `今日事件流`。
- 用户点击任一事件后，右侧主工作区立即出现解释卡和决策记录区。
- `历史决策追踪` 可回看，但不与当前事件竞争主注意力。

## Frame 结构

### F01 默认首屏

```text
+--------------------------------------------------------------------------------------------------+
| 顶部：全局状态条                                                                                |
| - 今日市场状态 - 持仓风险提醒 - 待处理事件数 - 最近一次决策状态                                  |
+-----------------------------------+--------------------------------------------------------------+
| 左列：今日事件流                  | 右列：主工作区                                               |
| - 分组：持仓相关 / 关注相关 / 其它 | +----------------------------------------------------------+ |
| - 事件卡 1                        | | 空状态 / 默认提示                                         | |
| - 事件卡 2                        | | - 说明“选择一条事件查看解释与决策”                        | |
| - 事件卡 3                        | +----------------------------------------------------------+ |
| - ...                             | | 待处理决策台摘要                                           | |
|                                   | | - 最近未处理事件 1~3 条                                    | |
|                                   | +----------------------------------------------------------+ |
+-----------------------------------+--------------------------------------------------------------+
| 底部：历史决策追踪（折叠）                                                                     |
+--------------------------------------------------------------------------------------------------+
```

### F02 选中事件后

```text
+--------------------------------------------------------------------------------------------------+
| 顶部：全局状态条                                                                                |
+-----------------------------------+--------------------------------------------------------------+
| 左列：今日事件流                  | 右列：主工作区                                               |
| - 当前选中事件高亮                | +----------------------------------------------------------+ |
| - 相邻事件保持可见                | | 解释卡                                                     | |
|                                   | | - 事件标题                                                 | |
|                                   | | - 触发对象 / 时间                                          | |
|                                   | | - 触发逻辑                                                 | |
|                                   | | - 影响推演                                                 | |
|                                   | | - 展开：历史类比 / 下一次复查点                            | |
|                                   | +----------------------------------------------------------+ |
|                                   | | 决策记录区                                                 | |
|                                   | | - 动作                                                     | |
|                                   | | - 理由标签                                                 | |
|                                   | | - 预期周期                                                 | |
|                                   | | - 备注                                                     | |
|                                   | | - 提交按钮                                                 | |
|                                   | +----------------------------------------------------------+ |
+-----------------------------------+--------------------------------------------------------------+
| 底部：历史决策追踪（最近 3~5 条，可展开）                                                       |
+--------------------------------------------------------------------------------------------------+
```

### F03 提交后

- 左列事件状态从 `待处理` 切到 `已记录`。
- 右侧保留提交结果回显，不跳转新页面。
- 底部历史区新增最近一条记录。

## 区域说明

### R01 顶部全局状态条

- 只放：
  - 市场状态一句话
  - 持仓风险提醒
  - 待处理事件数量
  - 最近一次决策状态
- 不放：
  - 大图表
  - 新闻流
  - 多市场切换器

### R02 左列事件流

- 宽度建议：
  - 占桌面主内容区约 `30% ~ 36%`
- 最小要求：
  - 当前选中态明显
  - 已处理/未处理状态可区分
  - 事件卡标题一眼能扫完
- 单卡最少信息：
  - 事件标题
  - 触发对象
  - 时间
  - 与持仓关系标签

### R03 右列主工作区

- 宽度建议：
  - 占桌面主内容区约 `64% ~ 70%`
- 上半区固定给解释卡
- 下半区固定给决策记录
- 禁止把决策记录拆到弹窗或二级页面

### R04 底部历史决策追踪

- 默认折叠或半展开
- 只展示最近几条摘要
- 点击后可查看更完整记录，但不应挤占右侧主工作区

## 关键状态

### S01 空状态

- 右侧不出现空白大区域
- 必须有一句引导：
  - `请选择一条事件，查看解释并记录决策`

### S02 选中状态

- 左侧卡片高亮
- 右侧加载解释卡
- 决策记录区默认可见，不需要再次展开

### S03 已提交状态

- 事件流状态更新
- 右侧出现提交成功回显
- 历史区同步追加最近记录

## 出稿护栏

- 不把 `待处理决策台` 单独做成第五张大卡。
- 不在桌面端首屏加入大面积 K 线。
- 不让历史回看抢过当前事件解释。
- 不让解释卡和决策记录分离到两个远距离区域。

## 低保真最小交付

- `1` 张默认首屏
- `1` 张选中事件后的页面
- `1` 张提交后的状态页
- `1` 张标注区域说明稿
