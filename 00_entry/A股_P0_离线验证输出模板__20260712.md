# A股 P0 离线验证输出模板

更新时间：2026-07-12

## 用途

- 给 `T01 ~ T05` 的离线验证结果提供统一输出骨架。
- 避免后续每个验证项都各写各的，导致无法横向对比、无法快速回看结论。
- 让“触发密度、抽样观察、是否通过、下一步动作”形成固定闭环。

## 使用边界

- 当前只适用于 A 股 P0 首轮离线验证的结果输出。
- 当前不适用于：
  - 正式研究报告
  - 长篇周报
  - 生产监控看板

## 单项输出模板

```text
验证项：
- T0X / VX

验证范围：
- 时间窗口：
- 覆盖标的：
- 覆盖行业：
- 市场阶段：

输入口径：
- 使用字段：
- 关键阈值：
- 增强字段是否启用：

核心结果：
- 触发总量：
- 日均触发数：
- 高峰日触发数：
- 中位日触发数：
- 持仓相关占比：

抽样观察：
- 极多触发日：
- 极少触发日：
- 中位日：
- 行业横截面：

结论判断：
- 当前口径：保留 / 微调 / 降级 / 暂缓
- 原因：

风险与例外：
- ...

下一步动作：
- ...
```

## 必填区块

### O01 验证范围

- 必填：
  - 时间窗口
  - 标的覆盖范围
  - 市场阶段覆盖
- 作用：
  - 防止结果脱离样本背景

### O02 输入口径

- 必填：
  - 使用字段
  - 关键阈值
  - 是否启用增强字段
- 作用：
  - 让结论能回到可复查的输入条件

### O03 核心结果

- 必填：
  - 触发总量
  - 日均触发数
  - 高峰/中位结果
- 若适用，再补：
  - 持仓相关占比
  - 行业覆盖度
  - 一致预期可得率

### O04 抽样观察

- 至少填写：
  - 一个极多触发样本
  - 一个极少触发样本
  - 一个典型样本
- 作用：
  - 避免只有统计，没有肉眼复核

### O05 结论判断

- 只能使用以下四类：
  - `保留`
  - `微调`
  - `降级`
  - `暂缓`
- 禁止：
  - 写成模糊判断
  - 只写“感觉可以”

## 各任务补充项

### 对 `T01`

- 额外建议填写：
  - 微盘股集中度
  - 热门题材集中度
  - 漏报样本描述

### 对 `T02`

- 额外建议填写：
  - 主力资金触发频次
  - 北向资金触发频次
  - 融资融券若纳入时的增噪情况

### 对 `T03`

- 额外建议填写：
  - 一致预期字段可得率
  - 降级规则是否可独立运行

### 对 `T04`

- 额外建议填写：
  - 普涨日伪触发数
  - 普跌日伪触发数
  - 行业解释增量判断

### 对 `T05`

- 额外建议填写：
  - `N=3`
  - `N=5`
  - `N=8`
  三档对覆盖率的影响

## 汇总页建议

- 首轮汇总至少要回答：
  - 哪些口径可直接保留
  - 哪些口径只需微调
  - 哪些口径需要降级
  - 哪些口径因输入不可得而暂缓

## 当前结论标签说明

- `保留`
  - 当前口径基本可用，不需要改主合同
- `微调`
  - 主方向成立，但阈值或展示策略要轻调
- `降级`
  - 需要改成更简单、更稳的触发方式
- `暂缓`
  - 输入或口径当前不足，暂不纳入首轮执行
