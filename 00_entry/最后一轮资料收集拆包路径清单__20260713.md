# 最后一轮资料收集拆包路径清单

更新时间：2026-07-13

## 用途

- 这份清单只服务于“资料整理阶段最后一次资料收集”。
- 当前目标是把原材料进入仓库后的路径、职责、拆包深度和完成标准一次写清楚。

## 当前总原则

- 不整包直接塞进活跃层。
- 不先做功能动作。
- 所有新材料统一先走：
  - `10_source_library_archive/<batch>/00_raw_snapshot`
- 然后补：
  - `README.md`
  - `manifest`
  - `provenance`
- 再做四分流：
  - `已吸收`
  - `可重开`
  - `future bucket`
  - `仅旧仓保留`

## 原材料入口路径

### 一、本地临时资料

- 来源路径：
  - `d:\Stock\trading_assistant\暂时存放\`
- 当前规则：
  - 这里只允许临时放置
  - 不进入 git
  - 不作为正式留存路径
- 处理方式：
  - 若无价值：直接删除
  - 若有价值：先吸收到正式路径，再删除原临时文件

### 二、旧仓或历史镜像资料

- 来源路径：
  - `12_tooling_runtime_archive/batch_09_legacy_analysis_migration__20260707/lifted_trading_analysis/`
- 当前规则：
  - 这里只是历史快照与对账区
  - 不作为默认阅读入口
- 处理方式：
  - 先按批次判断
  - 再决定是否进入 `10_source_library_archive`

### 三、新收集的电子书/文章/视频/网页摘录

- 来源路径：
  - 外部导入目录
  - 用户手工投递目录
  - 临时会话产物
- 当前规则：
  - 未经准入判断前，不允许直接进活跃对象层或 runtime 层
- 处理方式：
  - 统一先落 `10_source_library_archive/<batch>/00_raw_snapshot`

## 正式落点规则

### 一、只做来源归档

- 推荐落点：
  - `10_source_library_archive/<batch>/00_raw_snapshot`
- 适用：
  - 原始电子书
  - 视频导出稿
  - 网页摘录
  - 文章正文
  - 外部方法论原件

### 二、整理后的批次入口

- 推荐落点：
  - `10_source_library_archive/<batch>/README.md`
  - `manifest_v1.tsv`
  - `provenance.md`
- 适用：
  - 原材料已经确认值得入库
  - 需要形成正式批次入口

### 三、repo-global 台账或裁决

- 推荐落点：
  - `00_entry/`
- 适用：
  - 全库总台账
  - 全局收集清单
  - 全局裁决
  - 临时资料纳入评估卡

## 找谁拆

### 主负责人

- 角色：
  - 助手主负责人
- 负责：
  - 定批次名
  - 定正式落点
  - 定四分流结论
  - 定是否进入检索层

### 材料拆解者

- 角色：
  - AI 拆解
  - 或人工整理
- 负责：
  - 把原材料拆成：
    - 结构摘要
    - 章节索引
    - 字段候选
    - 对象候选
    - 方法卡候选

### 用户

- 负责：
  - 提供缺失原材料
  - 对高歧义材料做最终业务判断
  - 决定是否值得继续补采

## 拆到什么情况算达标

### Level 0：仅原件留存

- 条件：
  - 只确认值得保留原件
- 最低要求：
  - `README + manifest + provenance`

### Level 1：可检索摘要

- 条件：
  - 已能回答这份材料讲了什么
- 最低要求：
  - 原件留存
  - 摘要卡
  - 阅读顺序

### Level 2：对象/主题候选

- 条件：
  - 已能识别主题、对象或方法家族
- 最低要求：
  - 主题候选
  - 对象候选
  - 字段候选
  - 下一跳建议

### Level 3：可进入正式检索层

- 条件：
  - 已能明确：
    - 放在哪个 topic
    - 属于哪个 object
    - 是否需要独立 batch
- 最低要求：
  - topic/object/batch 的正式挂载建议

## 需要哪一部分

### 必需

- 原始正文或原始导出稿
- 来源说明
- 当前用途判断
- 去重判断

### 强烈建议

- 章节目录
- 摘要
- 字段清单
- 方法或对象候选

### 没有也能先入 raw snapshot

- 完整对象化结果
- 完整 runtime 接线
- 完整验证结论

## 当前不允许的动作

- 不把临时资料直接放进 `00_entry` 充当真值正文
- 不把单篇文章直接升级为默认功能合同
- 不把还没拆清楚的材料直接写进 runtime 入口
