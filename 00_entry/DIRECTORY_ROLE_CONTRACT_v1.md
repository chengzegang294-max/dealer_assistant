# Directory Role Contract v1

更新时间：2026-07-09

## 目标

- 把仓库顶层目录的职责写死，避免“看起来都像 docs / 都像入口”的混乱。
- 任何新增内容必须先选定角色目录；禁止为了省事乱放。

## 顶层目录职责（只认这一版）

| 目录 | 角色 | 放什么 | 不放什么 |
|---|---|---|---|
| `00_entry/` | 合同层与台账层 | 迁移计划/执行口径/任务板/全局裁决/入口卡（非日常长文） | 大体量资产、运行产物 |
| `01_active_objects/` | 活跃对象最小集 | 对象包责任卡/快入口卡/对象级不变量 | 大规模来源文档、回测输出 |
| `02_runtime/` | 可复现运行时 | 可跑脚本+样本+验收卡+运行记录 | 纯参考资料、未验收草稿 |
| `03_docs/` | 项目文档包 | 指标工程/开发说明/专题文档包 | 批次级来源库快照 |
| `04_active_main_docs/` | 日常入口层 | 主线索引/执行清单/日活/方向边界（五件套） | 流程模板库、迁移台账 |
| `10_source_library_archive/` | 来源库归档 | 外部资料/AI产物/旧库材料的批次化入档 | 直接可跑主线组件 |
| `11_frozen_summaries_archive/` | 冻结总结层 | 阶段性冻结结论与可检索锚点 | 临时草稿、未收口的猜想 |
| `12_tooling_runtime_archive/` | 工具运行时归档 | 大体量运行产物/历史运行时备份 | 主线入口文档 |
| `20_tools_workspace/` | 工具工作台 | 临时中转/一次性工具/批次工作台（可迁走可删） | 仓库级真值入口、长期归档包 |
| `21_trae_system_archive/` | Trae 系统归档 | 旧 `.trae` 迁移裁决索引/恢复稿/系统提示归档 | 日常入口五件套、业务 runtime 入口 |
| `.trae/` | Trae 本地工具层 | 当前可直接调用的 skill（最小集） | 仓库可追踪真值入口（受 `.gitignore` 约束） |
| `docs/playbooks/` | 流程模板库 | 可复用 playbook 模板（迁移/删除门控/盘点等） | 日常入口五件套 |

## 重名与兼容规则

- `04_active_main_docs/batch_01_selected/PLAYBOOK_滚动模板.md` 只允许作为兼容指针，正式版永远在 `docs/playbooks/`。
- 任何新的流程模板只进 `docs/playbooks/`，不在 `04_active_main_docs` 复制一份。

## 执行约束

- 任何新资料入库先判断：`来源库(10)` / `运行时(02)` / `主文档入口(04)` / `合同台账(00)` / `冻结总结(11)`。
- 不确定时先落 `10_source_library_archive/<batch>/00_raw_snapshot`，并写 `provenance + manifest`，再逐步提升归位。
- 提升归位硬门槛（禁止长期悬挂在工具工作台）：
  - 若 `20_tools_workspace/` 内的工具脚本沉淀出可长期复用的合同/索引/入口说明，必须提升到对应层
  - 合同台账与入口卡归 `00_entry/`
  - 可复现运行入口归 `02_runtime/`
  - 历史归档与大体量产物归 `12_tooling_runtime_archive/`
