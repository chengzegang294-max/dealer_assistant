# A股 P0 功能合同

更新时间：2026-07-11

## 用途

- 把当前多轮讨论已经收口的 A 股 P0 产品合同固定下来，作为进入原型、数据对接与实现前的仓库级真值入口。
- 明确哪些条目已经冻结，哪些条目不在本文件内继续发散，避免反复把已定事项重新拉回讨论。
- 给后续的原型、数据验证、实现和验收提供统一边界，不让系统退化成资料仓、假智能或普通看板。

## 上位前提

- 当前系统定位不是资料仓、纯看板软件或纯分析工具，而是一个 `可解释的投资决策辅助驾驶舱`。
- P0 先做 `A 股单市场`，不在本合同内展开多市场扩展。
- P0 当前目标是跑通最小闭环：
  - `提醒 -> 解释 -> 记录 -> 回看`
- 当前采用：
  - `轻驾驶舱外壳 + 事件解释闭环内核 + 问答下钻增强`
- 当前固定原则：
  - `无持仓关联，不默认置顶`
  - `无明确关注关系，默认折叠`
  - `P0 不做长文 AI 解释`
  - `P0 不做复杂相似度引擎`
  - `P0 不做目标价或未来价格预测`

## 当前范围

- 当前只覆盖：
  - A 股 P0 事件与解释闭环
  - 首页四卡结构
  - 解释卡字段
  - 决策日志字段
  - 当前主触发与主交互口径
- 当前不覆盖：
  - 数据供应商选择
  - 历史/在线数据分工
  - 数据库、API、代码实现
  - 多市场扩展
  - 回测系统、自动执行、Tick 级监控

## 事件框架

- 当前固定为 `6` 类事件：
  1. 指数关键位突破/破位
  2. 个股或持仓标的量价异常
  3. 业绩预告/快报显著超预期或低于预期
  4. 资金异动
  5. 行业/板块异常轮动
  6. 市场情绪极值

## 事件触发口径

### 1. 指数关键位突破/破位

- 当前主口径：
  - `前高/前低 + 少量整数关口`
- 当前边界：
  - 均线只做辅助观察或复查点参考，不作为主触发条件。

### 2. 个股或持仓标的量价异常

- 当前冻结口径：
  - `20日均量 1.8 倍 + 当日涨跌幅绝对值 > 4.5%`
- 当前说明：
  - 这是当前阶段的默认主阈值，用于 P0 合同，不在本文件中继续做参数扩展。

### 3. 业绩预告/快报事件

- 当前固定方向：
  - 采用 `预期差` 或 `同比显著变化` 触发
- 当前说明：
  - 具体数据口径仍受一致预期数据可得性影响，详细降级规则放在验证清单中跟进。

### 4. 资金异动

- 当前冻结优先级：
  - `主力资金` 为主触发
  - `北向资金` 只做增强标签或辅助说明
  - `融资融券` 不进入首页主触发

### 5. 行业/板块异常轮动

- 当前固定方向：
  - 采用 `相对大盘偏离 + 成交活跃度放大` 的轻量口径
- 当前边界：
  - 不在 P0 上复杂重叠度模型、复合评分模型或多层排名系统。

### 6. 市场情绪极值

- 当前固定方向：
  - 优先使用直观指标，例如：
    - `涨跌停家数比`
    - `市场宽度`
- 当前边界：
  - P0 不做复杂情绪复合打分。

## 解释卡合同

- 当前默认显示 `5` 个字段：
  1. `事件标题`
  2. `触发对象`
  3. `触发时间`
  4. `触发逻辑`
  5. `影响推演`
- 当前展开后显示 `2` 个字段：
  6. `历史类比`
  7. `下一次复查点`

### 影响推演

- 当前冻结模板：
  - `方向 + 强度 + 常见路径 + 复查点`
- 当前强度词收口为：
  - `显著`
  - `有限`
- 当前文案护栏：
  - 必须使用回顾性、非承诺式表达
  - 不允许写成价格预测
  - 不允许出现目标价口吻
  - 不允许膨胀成长文研报

### 历史类比

- 当前冻结结构：
  - 第一层：`本标的最近一次同类事件`
  - 第二层：`行业轻量统计`
- 当前降级原则：
  - 样本不足时隐藏统计，不强行展示概率或胜率。

## 决策日志合同

- 当前必填字段：
  1. `关联事件ID`
  2. `动作`
  3. `理由标签`
  4. `预期周期`
- 当前可选字段：
  5. `备注`

### 动作词表

- 当前冻结为 `5` 个：
  - `忽略`
  - `观察`
  - `加仓`
  - `减仓`
  - `调仓`

### 理由标签词表

- 当前冻结为 `6+1`：
  - `趋势`
  - `基本面`
  - `资金`
  - `情绪`
  - `风控`
  - `事件催化`
  - `其他`

## 首页四卡

- 当前冻结为 `4` 张：
  1. `全局状态条`
  2. `今日事件流`
  3. `待处理决策台`
  4. `历史决策追踪`

### 首页主轴

- 当前主轴固定为：
  - `今日事件流`

### 主工作区

- 当前固定交互：
  - `点击事件 -> 展开解释卡 -> 卡底直接记录决策`
- 当前固定布局原则：
  - 桌面端：事件流左侧，解释卡与决策记录右侧共用主工作区
  - 移动端：解释卡与决策记录使用下方抽屉、固定底栏或等价收口交互

## P0 铁律排除项

- 当前明确不做：
  - 三情景预测
  - 长文 AI 解释
  - 相似 K 线或复杂相似度引擎
  - 目标价或收益预测
  - Tick 级监控
  - 多市场联动
  - 自定义阈值 UI
  - 多维度资料筛选器
  - 把历史报告、深度图表或原始公告直接嵌入事件流主路径
