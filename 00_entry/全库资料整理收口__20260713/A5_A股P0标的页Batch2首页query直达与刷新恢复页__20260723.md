# A5 A股 P0 标的页 Batch2 首页 query 直达与刷新恢复页

更新时间：2026-07-23

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 首页返回链继续压到 `query 直达与刷新恢复`
  - 确认首页只靠 `eventId` 就能在刷新后恢复同一事件上下文
- 本页不做：
  - localStorage / sessionStorage
  - 草稿恢复
  - 多层返回栈记忆
  - 新全局状态容器

## 二、主负责人裁决

- 当前最值钱的一刀不是继续改 UI，而是把已经存在的 `eventId` 恢复能力补成“真实刷新仍成立”的可复验停点。
- 本轮只允许补：
  - 首页打开标的页时带当前 `eventId`
  - 首页带 `eventId` 直达
  - 浏览器刷新后按 `eventId` 恢复当前事件工作区

## 三、本轮最小通过条件

- 满足以下四项即可停：
  1. 首页已选事件时，进入标的页 URL 会保留 `eventId`
  2. 直接打开 `/?eventId=...` 时，首页能恢复对应事件工作区
  3. 浏览器刷新首页后，仍能恢复同一事件上下文
  4. `test/lint/build` 全绿并补走查与入口回填

## 四、明确不做

- 不恢复未提交表单
- 不持久化最近多个事件
- 不做浏览器后退栈增强
- 不改首页主区布局

## 五、停止规则

- 只把 `query 直达 + 刷新恢复` 做成真实可复验闭环；通过后立刻停。
