# A5 信息直播间登录态历史摘录模板页

更新时间：2026-07-31

## 一、这页用途

- 本页只做：
  1. 固定
     `信息直播间`
     后续摘录时的最小字段模板
  2. 避免每次再为
     `房间名 / 日期 / 正文 / 图片`
     重新约定写法

## 二、当前模板适用范围

- 当前模板只适用于：
  - `登录态下`
  - `历史记录`
  - `选日期后`
  - 右侧正文区可见的
    `文本 + 图片`
    类内容

- 当前模板不适用于：
  - 游客态页面
  - 外部公开视频
  - 结构化 API 响应

## 三、最小字段模板

```text
source_family: 信息直播间
source_url: https://mx2025.hhhuu.com/#/
access_mode: login_state_required
sample_date: YYYY-MM-DD
room_anchor: <直播间名/栏目名>
history_entry: 历史记录
display_date: <页面显示日期>
display_time: <正文区时间或列表时间>
topic_anchor: <标题或主题句>
excerpt: <正文摘录 1-3 句>
image_evidence: <有/无 + 图片说明>
content_form: static_text_and_image
a5_role_layer: explanation_layer_or_side_evidence
notes: <是否与市场情绪/上榜资金/题材中心相关>
```

## 四、字段写法冻结

- `sample_date`
  - 写实际回看目标日期
  - 不写登录当天日期

- `room_anchor`
  - 优先写左侧列表里完整房间名
  - 若当前只看清部分，
    暂写：
    `candidate_room_anchor`

- `display_date`
  - 写页面实际显示的日期样式，
    不强行改写

- `display_time`
  - 优先写右侧正文时间
  - 若右侧不清楚，
    可先用左侧列表时间，
    但要在
    `notes`
    里标明

- `topic_anchor`
  - 优先取标题
  - 若没有明显标题，
    取正文第一句

- `excerpt`
  - 只摘
    `1-3`
    句关键原文
  - 不做大段改写

- `image_evidence`
  - 有图就写：
    `yes + 图片位置/类型`
  - 没图就写：
    `no`

## 五、当前最推荐的入档粒度

- 当前最推荐的入档粒度冻结为：
  - `一条历史记录 = 一笔摘录`

- 当前不推荐：
  - 一整个房间一天的内容混成一条
  - 多个房间合成一条

## 六、当前与 A5 的回链口径

- 当前每笔摘录，
  统一按：
  - `解释层 / 旁证层`
  接入

- 当前优先回链对象仍是：
  1. `市场情绪总览`
  2. `上榜资金`
  3. `题材中心`

## 七、主负责人正式裁决

- 当前正式裁决为：

1. `信息直播间`
   后续历史摘录，
   统一按本模板入档

2. 当前若字段不齐，
   允许先用：
   - `candidate_room_anchor`
   - `candidate_display_date`
   过渡

3. 但不得跳过：
   - `sample_date`
   - `excerpt`
   - `a5_role_layer`

## 八、一句话口径

- 从现在起，`信息直播间` 的历史内容不再凭感觉记录，而是统一按“日期、房间、正文摘录、图片证据、A5 回链角色”这套最小模板入档。
