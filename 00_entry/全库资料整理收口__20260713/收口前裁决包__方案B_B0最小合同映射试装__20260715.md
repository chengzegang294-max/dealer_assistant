- 选取字段：
  - `n01_current_regime`
- 字段类型：
  - `bridge pseudo-field`
- 字段来源：
  - `atrRatio`
  - `detectVolatilityRegime(...)`
  - `getRegimeName(...)`
- 语义定义：
  - 以 `ATR / baseline` 比值与阈值判断当前波动环境阶段
  - 允许最小输出：
    - `COMPRESSION`
    - `EXPANSION`
    - `HIGH VOLATILITY`
    - `EXHAUSTION`
- 证据锚点：
  - `getATRRatio(float atrValue, float atrBaseline) => atrBaseline > 0 ? atrValue / atrBaseline : 1.0`
  - `if atrRatio >= highVolThreshold -> regime := 3`
  - `else if atrRatio >= expansionThreshold -> regime := 2`
  - `else if atrRatio < compressionThreshold -> regime := 1`
  - `else if wasRecentlyHighVol and isATRDeclining(...) -> regime := 4`
  - `1 => "COMPRESSION" / 2 => "EXPANSION" / 3 => "HIGH VOLATILITY" / 4 => "EXHAUSTION"`
