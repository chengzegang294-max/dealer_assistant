# A5 连板天梯盘后 3 分钟怎么看｜极简版

更新时间：2026-08-09
状态：当前极简版

## 一、这页怎么用

这页只回答一件事：

- 收盘后 3 分钟内，连板天梯最先看什么，才能最快判断今天市场结构到底偏强还是偏弱。

一句话：

- 不求看全，先把最值钱的 3 步看完。

## 二、先看哪三步

### 第 1 步：先看市场高度和梯队

先看：

1. 最高板有没有抬高
2. 高位梯队有没有断层
3. 总连板数是扩张还是收缩

你要快速回答：

- 今天是“高度还在抬”，还是“高度开始塌”。

### 第 2 步：再看主线题材有没有集中

先看：

1. 高标主要集中在哪个题材
2. 中位票是不是也围着同一条线
3. 是一条主线更集中，还是很多题材都在乱动

你要快速回答：

- 今天是“主线更清楚”，还是“轮动更散、更乱”。

### 第 3 步：最后看板块资金快照能不能对上

先看：

1. `mainNetAmount` 靠前的是哪些板块
2. `strength` 和 `pctChg` 是不是一致
3. 资金靠前板块，能不能和天梯主线对上

你要快速回答：

- 今天是“结构和资金同向”，还是“结构热但资金没跟”。

## 三、盘后 3 分钟的一句话模板

你可以直接按这句去写：

```text
今天连板结构（偏强 / 偏弱 / 分化），市场高度（抬高 / 持平 / 塌掉），主线题材（集中 / 分散），板块资金与结构（同向 / 背离）。
```

比如：

```text
今天连板结构偏强，市场高度继续抬高，主线题材更集中，板块资金与结构基本同向。
```

## 四、最先看哪些字段

### 1. 天梯主表

先看：

- `boards`
- `level`
- `continue_num`
- `primary_theme`
- `first_limit_up_time`
- `last_limit_up_time`

### 2. 板块资金

先看：

- `sectorName`
- `mainNetAmount`
- `strength`
- `pctChg`
- `relativeInflow`

## 五、最容易看错的地方

### 1. 只看最高板，不看梯队

错法：

- 最高板还在，就以为情绪还强

正确看法：

- 最高板只是一个点，下面梯队断了，结构也可能已经在走弱

### 2. 只看热闹题材名，不看资金有没有跟

错法：

- 题材很多票在动，就以为主线成立

正确看法：

- 还要看板块资金快照是不是同向，不然容易只是热闹

### 3. 只看当天强，不看是不是比前一天更好

错法：

- 今天看起来挺热，就默认偏强

正确看法：

- 盘后最值钱的是“跟前一天相比，结构是在扩张还是在收缩”

## 六、当前一句话

- 盘后 3 分钟看连板天梯，先看高度和梯队，再看题材集中度，最后看板块资金有没有跟上；三步对下来，你就能很快判断今天到底是强、弱，还是分化。
