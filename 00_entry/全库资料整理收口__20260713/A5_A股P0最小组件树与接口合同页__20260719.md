# A5 A股 P0 最小组件树与接口合同页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把当前
    `A股 P0`
    已完成的页面合同，
    收成实现前可直接消费的
    `最小组件树`
    与
    `接口合同`
- 本页不做：
  - 前端框架选型
  - API 真实实现
  - 样式系统选型
  - 新 runtime

## 二、上位约束

- 当前首页唯一主轴仍是：
  - `今日事件流`
- 当前唯一主路径仍是：
  - `事件流 -> 解释卡 -> 决策记录 -> 回看`
- 当前问答下钻仍是：
  - 增强层
  - 不是首页第一跳

## 三、当前最小页面树

- 当前最小页面树固定为：
  1. `首页工作台页`
  2. `标的分析页`
  3. `问答下钻页`

## 四、首页工作台页组件树

- 当前首页工作台页固定拆为：
  1. `HomePageShell`
  2. `GlobalStatusBar`
  3. `StockSearchEntry`
  4. `EventStreamPanel`
  5. `MainWorkspacePanel`
  6. `DecisionQueueSummary`
  7. `HistoryTracePanel`

### 4.0 HomePageShell 下游组件

- 当前首页必须正式包含：
  - `StockSearchEntry`
- 当前其唯一作用是：
  - 接通
    `首页搜标的 -> 标的分析页`
    的跨页入口

### 4.1 EventStreamPanel 下游组件

- 当前固定包含：
  - `EventGroupSection`
  - `EventCard`
- 当前 `EventCard`
  点击后唯一落点是：
  - `MainWorkspacePanel`

### 4.2 MainWorkspacePanel 下游组件

- 当前固定包含：
  - `SelectedEventSummaryBar`
  - `ExplanationCard`
  - `DecisionRecordForm`
  - `DecisionSubmitEcho`
  - `FinanceDisclosureEntry`

## 五、标的分析页组件树

- 当前标的分析页固定拆为：
  1. `StockPageShell`
  2. `StockHeaderSummary`
  3. `RelatedEventsPanel`
  4. `CurrentExplanationPanel`
  5. `RecentDecisionPanel`
  6. `QaEntryPanel`

### 5.1 RecentDecisionPanel 下游组件

- 当前固定包含：
  - `LatestDecisionSummary`
  - `DecisionReasonPeriodBlock`
  - `SupplementRecordEntry`
  - `SupplementRecordEditor`
  - `LatestSupplementEcho`

### 5.2 QaEntryPanel 下游组件

- 当前固定包含：
  - `QaEntryButton`
  - `QaContextHint`
- 当前必须正式输出：
  - `onOpenQaPage(eventId)`

### 5.3 RelatedEventsPanel 复用规则

- 当前
  `RelatedEventsPanel`
  默认复用：
  - `EventCard`
- 当前默认复用同一语义：
  - `onSelectEvent(eventId)`
- 当前不允许为标的页另造第二套事件卡合同

## 六、问答下钻页组件树

- 当前问答下钻页固定拆为：
  1. `QaPageShell`
  2. `QaContextBar`
  3. `QaRecommendedQuestionGroups`
  4. `QaAnswerDisplay`
  5. `QaNextActionBar`
  6. `QaFinanceDisclosureBar`
  7. `BackToStockPageEntry`

## 七、跨页共享接口对象

- 当前跨页共享对象固定为：
  1. `EventSummary`
  2. `ExplanationPayload`
  3. `DecisionRecordDraft`
  4. `DecisionRecord`
  5. `SupplementRecord`
  6. `QaContext`

## 八、最小接口合同

### 8.1 EventSummary

- 当前最小字段固定为：
  - `eventId`
  - `title`
  - `subject`
  - `occurredAt`
  - `holdingRelation`
  - `processStatus`
  - `disclosureFlag`

### 8.2 ExplanationPayload

- 当前最小字段固定为：
  - `eventId`
  - `title`
  - `subject`
  - `logic`
  - `impact`
  - `historyAnalogy`
  - `nextReviewPoint`
- 当前补充规则固定为：
  - `title`
    必须与当前
    `eventId`
    对应事件标题同源
  - `occurredAt`
    不在
    `ExplanationPayload`
    内重复造字段，
    解释区统一透传
    `EventSummary.occurredAt`

### 8.3 DecisionRecordDraft

- 当前最小字段固定为：
  - `eventId`
  - `action`
  - `reasonTag`
  - `horizon`
  - `note`

### 8.4 DecisionRecord

- 当前最小字段固定为：
  - `decisionId`
  - `eventId`
  - `action`
  - `reasonTag`
  - `horizon`
  - `note`
  - `createdAt`
  - `decisionStatus`

### 8.5 SupplementRecord

- 当前最小字段固定为：
  - `supplementId`
  - `decisionId`
  - `eventId`
  - `supplementNote`
  - `supplementCreatedAt`

### 8.6 QaContext

- 当前最小字段固定为：
  - `stockCode`
  - `stockName`
  - `eventId`
  - `questionGroup`
  - `questionText`
  - `sourceFieldRefs`
  - `disclosureFlag`
  - `benchmarkLimitNote`

## 九、关键组件输入输出

### 9.1 EventCard

- 输入必须至少有：
  - `EventSummary`
- 输出只允许：
  - `onSelectEvent(eventId)`

### 9.1A StockSearchEntry

- 输入必须至少有：
  - `searchDraft`
- 输出只允许：
  - `onChangeSearchDraft(searchDraft)`
  - `onOpenStockPage(stockCode)`

### 9.1B GlobalStatusBar

- 输入必须至少有：
  - `marketSummary`
  - `pendingEventCount`
  - `holdingRiskHint`
- 输出只允许：
  - `onOpenFinanceDisclosure`

### 9.2 MainWorkspacePanel

- 输入必须至少有：
  - `selectedEventId`
  - `EventSummary`
  - `ExplanationPayload`
  - `DecisionRecordDraft`
    可空
  - `DecisionRecord`
    可空
- 输出只允许：
  - `onSubmitDecision`
  - `onOpenFinanceDisclosure`

### 9.2A DecisionQueueSummary

- 输入必须至少有：
  - `queuedEvents`
- 输出只允许：
  - `onSelectQueuedEvent(eventId)`

### 9.2B HistoryTracePanel

- 输入必须至少有：
  - `recentDecisionRecords`
- 输出只允许：
  - `onOpenDecisionHistory`

### 9.3 RecentDecisionPanel

- 输入必须至少有：
  - `DecisionRecord`
    可空
  - `SupplementRecord`
    可空
  - `eventId`
- 输出只允许：
  - `onOpenSupplementEditor`
  - `onViewDecisionHistory`

### 9.3A StockHeaderSummary

- 输入必须至少有：
  - `stockCode`
  - `stockName`
  - `subjectTags`
  - `holdingRelation`
- 输出只允许：
  - `onBackToHome`

### 9.3B RelatedEventsPanel

- 输入必须至少有：
  - `relatedEventList`
  - `selectedRelatedEventId`
- 输出只允许：
  - `onSelectEvent(eventId)`

### 9.4 QaRecommendedQuestionGroups

- 输入必须至少有：
  - `QaContext`
  - `recommendedQuestions`
- 输出只允许：
  - `onAskQuestion(questionText, questionGroup)`

### 9.4A QaEntryPanel

- 输入必须至少有：
  - `eventId`
  - `QaContext`
- 输出只允许：
  - `onOpenQaPage(eventId)`

### 9.5 QaAnswerDisplay

- 输入必须至少有：
  - `QaContext`
  - `answerBody`
  - `sourceFieldRefs`
- 输出只允许：
  - `onBackToStockPage`
  - `onOpenSupplementEditor`
