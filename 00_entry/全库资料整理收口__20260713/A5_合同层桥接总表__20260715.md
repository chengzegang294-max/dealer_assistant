# A5 合同层桥接总表

更新时间：2026-07-16

## 用途

- 把 `A_REQ_002` 与 `A_REQ_003` 已落的 req 级产物，统一桥接到 `GROUP_10_A5` 的合同层准备口径。
- 当前目标不是新增资料。
- 当前目标是把：
  - 基本面因子字段
  - 组合风险字段
  - 最小验收断言

  收成一张总表，供后续继续下沉到对象卡/合同层。

## 二、A_REQ_002 桥接摘要

### 当前固定字段族

- `value`
  - `value_pe_ttm`
  - `value_pb_lf`
  - `value_ps_ttm`
- `quality`
  - `quality_roe_avg`
  - `quality_debt_to_asset`
- `growth`
  - `growth_revenue_yoy`
  - `growth_net_profit_yoy`
- `cashflow`
  - `cashflow_operating_cf_net`
  - `cashflow_ocf_to_net_profit`

### 当前最小输入族

- 财报输入：
  - `revenue_current / revenue_prior`
  - `net_profit_current / net_profit_prior`
  - `shareholders_equity_current / shareholders_equity_prior`
  - `total_assets / total_liabilities`
  - `operating_cashflow_net`
- 估值输入：
  - `price_per_share / market_cap / eps_ttm / revenue_ttm / book_value_per_share`
- 元数据：
  - `industry_name / report_date / price_date`

### 当前验收主断言

- 必须覆盖 `value / quality / growth / cashflow` 四个因子族
- `ROE / YoY / OCF_to_NP` 必须能回溯到输入字段
- `valuation_factor_confidence` 必须随缺字段与降级而下降

### 当前降级主口径

- `eps_ttm <= 0`
  - `PE = NA`
- 缺平均权益
  - 允许用期末权益替代，但必须标记 `degraded`
- 缺上期值
  - 对应增长率置 `NA`
- 缺行业
  - 禁止做行业对比解释

## 三、A_REQ_003 桥接摘要

### 当前固定字段族

- `optimizer`
  - `alpha_score`
  - `covariance_model_id`
  - `benchmark_id`
  - `tracking_error_limit`
  - `active_risk_aversion`
  - `transaction_cost_bps`
- `constraint`
  - `turnover_limit`
  - `weight_lower_bound`
  - `weight_upper_bound`
  - `long_only_flag`
- `risk_overlay`
  - `kelly_size_scalar`
  - `vt_size_scalar`
  - `pq_position_max_size`
- `final`
  - `target_weight`
  - `final_size_scalar`
  - `adjusted_position_weight`
  - `portfolio_expected_active_return`
  - `portfolio_tracking_error`

### 当前最小输入族

- 当前组合快照
- alpha 或排序得分快照
- benchmark 快照或 `nonbenchmark_mode`
- 约束配置
- 风险缩放输入
- 调仓频率与触发规则

### 当前验收主断言

- `target_weight` 必须满足权重上下界
- `final_size_scalar = min(kelly, vt, pq, 1.0)`
- `adjusted_position_weight = target_weight * final_size_scalar`
- benchmark 模式下必须能输出 `portfolio_tracking_error`

### 当前降级主口径

- 缺 `covariance_model_id`
  - 降级为 `equal_weight_or_value_weight + risk_overlay`
- 缺 `transaction_cost_bps`
  - 使用默认交易成本参数并标记 `degraded`
- 缺 `benchmark_id`
  - 切为 `nonbenchmark_mode`
- 缺 `alpha_score`
  - 不允许伪优化，直接中止

## 四、当前统一桥接规则

- `A_REQ_002` 负责：
  - 把基本面/估值信息收成可解释因子族
- `A_REQ_003` 负责：
  - 把 alpha、风险、约束、仓位缩放收成组合层最小合同
- 两者当前的桥接顺序固定为：
  - 先 `A_REQ_002` 形成因子解释层
  - 再 `A_REQ_003` 消费 alpha / 风险 / 约束形成权重层
