# A5 技术指标缺失判断与补池边界页

更新时间：2026-07-25

## 一、这页用途

- 本页只回答：
  - 当前大家是否认为我们
    `缺指标`
  - 若缺，
    缺的是：
    - `指标名字`
      还是
    - `职责空位`
  - 当前要不要立刻补上
- 本页不做：
  - 新一轮多AI正式发包
  - 直接扩新指标池
  - 直接进入回测层

## 二、当前问题怎么问才对

- 当前更准确的问题不是：
  - `我们还缺不缺几个常见指标名字`
- 当前更准确的问题应改写成：
  - 现有
    `5`
    条代表指标，
    是否已经覆盖了第一批场景矩阵所需的核心职责
  - 如果没有覆盖，
    缺的是哪类职责位、
    哪类场景位、
    哪类失效方式位

## 三、多AI与仓内既有结论怎么看

### 3.1 高信号共识

- 现有高信号共识并不支持：
  - 现在就回到
    `补更多指标名字`
- 现有高信号共识更支持：
  - 先把
    `指标职责 x 市场特征 x 单子特征`
    场景矩阵压实
  - 再看哪类格子出现
    `职责空位`
    或
    `失效方式空位`

### 3.2 已有正式口径

- 已有正式页已经明确写过：
  - 当前缺的不是
    `完全没有资料`
  - 而是
    `第一批场景矩阵还没正式压实`
- 已有正式页也已经明确写过：
  - 当前更该先补的是：
    - `职责空位`
    - `场景空位`
    - `失效方式空位`
    - `单子特征空位`

## 四、那我们到底算不算“缺指标”

## 4.1 如果按“名字数量”问

- 当前判断是：
  - `暂不算缺`
- 原因是：
  1. 第一批框架讨论，
     现在已经有
     `5`
     条代表指标可用
  2. 这
     `5`
     条指标已经能覆盖第一版矩阵里最基础的：
     - `方向层`
     - `触发层`
     - `过滤层`
     讨论入口
  3. 现在继续加名字，
     大概率会稀释主线，
     把问题重新带回
     `指标池思维`

## 4.2 如果按“职责覆盖”问

- 当前判断是：
  - `有结构性缺位`
- 但这个缺位更像：
  - `缺职责代表`
  - 不是
    `缺更多热门名词`

- 当前最像缺位的地方有：
  1. `仓位层`
  2. `退出层`
  3. `波动 / 风险约束层`

- 原因是：
  - 当前
    `沪深涨跌停 / HYDB行业对比 / ZSDB指数对比`
    更偏：
    - `方向层`
    - `过滤层`
  - 当前
    `打板资金 / 上榜资金`
    更偏：
    - `触发层`
    - `过滤层`
  - 但对
    `仓位层`
    和
    `退出层`
    来说，
    目前更多还是讨论性占位，
    还没有明显的代表型对象

## 五、当前要不要立刻补上

- 当前正式裁决是：
  - `不立刻补指标池`
- 但同时不是说：
  - 以后永远不补

- 当前更稳的做法是：
  1. 先把第一批矩阵继续压实
  2. 看哪些职责位真的持续空着
  3. 只按
     `缺口类型`
     定点补
  4. 每次最多补
     `1~2`
     类代表对象，
     不搞扩池式补法

## 六、什么条件下才允许补

- 当前只有出现以下情况，
  才建议正式开
  `补指标`
  这条支线：

### 6.1 职责空位连续存在

- 例如：
  - 第一批矩阵反复发现
    `仓位层`
    没有可稳定承接的代表对象
  - 或
    `退出层`
    只有抽象描述，
    没有可讨论的代表型对象

### 6.2 失效方式解释不够

- 例如：
  - 现有指标能说
    `什么时候有用`
  - 但无法稳定说清
    `什么时候不该用`
    `什么时候该降权`

### 6.3 某一整类市场特征没有抓手

- 例如：
  - 高波动保护、
    波动收缩/扩张、
    风险约束类场景
    如果一直没有合适抓手，
    才值得补一个
    `波动/风险约束型`
    代表对象

## 七、如果后面真要补，优先补哪类，不优先补哪类

## 7.1 更值得优先观察的补位方向

- 若后面必须补，
  当前更值得优先观察的是：
  1. `波动/风险约束型`
     代表对象
     - 用来补
       `仓位层 / 退出层`
       的讨论抓手
  2. `退出确认型`
     代表对象
     - 用来补
       `结构破坏 / 强度衰减 / 退场`
       的讨论抓手

## 7.2 当前不优先补的方向

- 当前不优先补：
  1. 再补一批
     `同类强弱 / 热度 / 资金`
     指标
  2. 为了显得全面，
     去补一串常见指标名字
  3. 直接把外部交易系统整套并进来冒充补位

## 八、主负责人裁决

- 当前正式裁决为：
  1. 大家并没有形成
     `现在明显缺很多指标名字`
     的高信号共识
  2. 当前真正存在的，
     是
     `职责覆盖上的结构性缺位`
     ，
     尤其是：
     - `仓位层`
     - `退出层`
     - `波动/风险约束层`
  3. 但这个缺位，
     当前先不靠
     `扩指标池`
     解决
  4. 当前先继续压实：
     - 第一批场景矩阵
     - 职责说明
     - 失效方式
     - 不该怎么用
  5. 等矩阵继续往下压后，
     若某个职责位仍持续空缺，
     再定点补
     `1~2`
     个角色型代表对象

## 九、当前先做什么

- 当前先做：
  1. 在现有矩阵页旁边，
     正式写出
     `当前结构性缺位`
     的判断
  2. 下一轮优先围绕：
     - `仓位层`
     - `退出层`
     - `失效方式`
     继续细化

## 十、一句话口径

- 当前不是
  `指标名字明显不够`
  ，而是
  `职责覆盖还不够完整`
  ；
  所以现在不做扩池式补指标，
  只在后续确认
  `仓位层 / 退出层 / 波动风险约束`
  持续空缺时，
  再做定点补位。
