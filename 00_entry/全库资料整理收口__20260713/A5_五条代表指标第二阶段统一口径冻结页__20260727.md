# A5 五条代表指标第二阶段统一口径冻结页

更新时间：2026-07-27

## 一、这页用途

- 本页只做：
  - 把五条代表指标第二阶段细化后的统一口径正式冻结
  - 统一：
    - 先分哪一类对象
    - 优先用哪类动作语言
    - 什么情况下升级到观察或退出
  - 给后续交叉映射补页提供母口径

- 本页不做：
  - 金融有效性证明
  - 参数化门禁
  - 回测阈值

## 二、当前先分哪两类对象

### 2.1 触发型对象

- 当前包括：
  - `打板资金`
  - `上榜资金`

- 当前统一问题是：
  - `当前触发还值不值得继续被信`

- 当前默认优先动作是：
  1. `先降权`
     或
     `先降级职责`
  2. 污染明显上升后，
     再
     `回观察位`
  3. 只有前提被打掉时，
     才
     `退出原解释`

### 2.2 背景型对象

- 当前包括：
  - `HYDB行业对比`
  - `ZSDB指数对比`
  - `沪深涨跌停`

- 当前统一问题是：
  - `当前背景还值不值得继续给原解释背书`

- 当前默认优先动作是：
  1. `先降级职责`
     或
     `先降权`
  2. 背景连续失真后，
     再
     `回观察位`
  3. 只有背景前提被打掉时，
     才
     `退出原解释`

## 三、当前四档统一动作语言

### 3.1 先降权

- 当前统一口径：
  - `逻辑未坏，但当前支持强度下降，先降权。`

- 当前更适合：
  - `打板资金`
  - `ZSDB指数对比`

### 3.2 先降级职责

- 当前统一口径：
  - `解释还能讲，但当前不再配继续承担原职责，先退一层职责。`

- 当前更适合：
  - `上榜资金`
  - `HYDB行业对比`
  - `沪深涨跌停`

### 3.3 回观察位

- 当前统一口径：
  - `当前污染或噪音已高到不该继续给解释权重，先回观察位。`

- 当前适用于：
  - 五条对象全部可用
  - 但触发条件必须按对象分别写，
    不允许混写

### 3.4 退出原解释

- 当前统一口径：
  - `原来的前提已经不在了，这不是弱一点，而是逻辑失效。`

- 当前适用条件：
  - 原核心前提被打掉
  - 再继续保留原解释会误导判断

## 四、当前五条对象的统一冻口径

| 指标 | 当前先回答的问题 | 当前优先动作 | 什么时候升级 |
| --- | --- | --- | --- |
| `打板资金` | `触发是否还值得被信` | `先降权` | 污染穿越后 `回观察位`，反证后 `退出原解释` |
| `上榜资金` | `事件标签还值不值得继续当触发依据` | `先降级职责` | 强度继续下降后 `先降权 / 回观察位` |
| `HYDB行业对比` | `行业背景还支不支持原方向解释` | `先降级职责` | 联动持续失真后 `回观察位`，结构破坏后 `退出原解释` |
| `ZSDB指数对比` | `指数背景还值不值得继续背书` | `先降权` | 波动压强失控后 `回观察位`，前提反证后 `退出原解释` |
| `沪深涨跌停` | `市场宽度还值不值得继续背书` | `先降级职责` | 热度衰减加重后 `回观察位`，宽度前提打掉后 `退出原解释` |

## 五、当前禁止混写的地方

- 当前禁止把：
  - `先降权`
    和
    `退出原解释`
    写成同一层
- 当前禁止因为一次波动，
  就直接把背景型对象写成
  `结构失效`
- 当前禁止把触发型对象的
  `事件退潮`
  和背景型对象的
  `背景背离`
  不加区分地混在一句话里

## 六、当前主负责人冻结判断

- 当前正式冻结为：
  1. 后续再写五条对象时，
     先分
     `触发型 / 背景型`
  2. 触发型优先回答：
     `还值不值得继续当触发`
  3. 背景型优先回答：
     `还值不值得继续给原解释背书`
  4. 后续如开交叉映射补页，
     只能在这张统一口径页之下继续细分，
     不再重开母口径

## 八、一句话口径

- 当前五条代表指标第二阶段已经不仅是“分别写完”，而是正式冻结成一套统一母口径：
  先分
  `触发型 / 背景型`
  ，
  再判
  `降权 / 降级职责 / 观察 / 退出`

  后续补页都必须挂在这套口径之下继续推进。
