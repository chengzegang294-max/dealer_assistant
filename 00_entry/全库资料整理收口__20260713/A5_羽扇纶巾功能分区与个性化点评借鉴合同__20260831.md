1. 从 `batch_149 / 羽扇纶巾参考族` 中，**借鉴哪些产品结构**。

## 6. 个性化冷启动规则

当前固定采用：

`PERSONALIZATION_COLD_START`

冷启动阶段只允许个性化：

1. 展示顺序
2. 语言长短
3. 解释深度
4. 风险提示显著程度
5. 用户手工选择的关注字段
6. 用户手工声明的持仓事实

冷启动阶段禁止自动推断：

1. 用户擅长打板
2. 用户偏好低吸
3. 用户能承受高仓位
4. 用户喜欢高波动
5. 用户适合某种交易体系
6. 用户会执行某类建议

未来只有以下证据，才允许升级画像：

1. 用户明确声明
2. 多次真实选择
3. 执行记录
4. 结果复盘
5. 稳定重复行为
6. 用户确认后的经验结论

## 7. 直白点评合同

点评必须拆成六段：

1. 一句话结论
   - 只回答最值得注意的是什么
2. 关键事实
   - 最多 3 条
   - 每条都必须带时间和来源
3. 结构解释
   - 先写支持点，再写反证
4. 风险与反证
   - 至少 1 条
   - 优先写当前缺口或失效条件
5. 条件化建议占位
   - 固定为 `FUTURE_INTERFACE_ONLY_NOT_ACTIVE`
6. 证据入口
   - 必须可回链到来源、时间、口径和缺口

固定边界：

1. 当前允许设计点评接口
2. 当前不允许激活真实建议
3. 当前不允许自动生成用户画像
4. 当前不允许把黑盒概率混入点评
