# A5 第二日期接入串行执行Runbook页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 把第二日期样本一旦到位后的串行执行顺序，
    压成一页 runbook
  - 避免后面在
    `起批次 / absorb / 计划行 / 单包验收 / 两日期门槛`
    之间来回跳步骤

## 二、当前串行顺序

1. 若第二日期批次还没起，
   先运行批次脚手架生成器
2. 把东方财富 PC 的 3 张图落到：
   `00_raw_snapshot/user_screenshots/`
3. 运行 absorb 收口脚手架，
   把 `manifest_v1.tsv`
   改成 `absorbed`
4. 渲染第二日期输入包计划行
5. 把计划行写回
   `a5_input_pack_sample_plan_v1.tsv`
6. 运行单输入包验收
7. 重跑两日期门槛
8. 生成一份总控摘要 JSON

## 三、当前总控脚手架应做什么

- 当前总控脚手架至少要做：
  1. 检查批次结构是否存在
  2. 必要时初始化最小批次结构
  3. 串行调用：
     - `finalize_a5_second_date_batch_absorb_v1.py`
     - `render_a5_second_date_plan_row_v1.py`
     - `upsert_a5_input_pack_plan_row_v1.py`
     - `run_a5_input_pack_acceptance_v1.py`
     - `run_a5_multi_pack_gate_acceptance_v1.py`
  4. 产出总控摘要 JSON

## 四、当前成功标准

- 第二日期 runbook 当前最小成功标准冻结为：
  1. 单输入包验收 `passed=true`
  2. 两日期门槛摘要已重跑
  3. 总控摘要 JSON 已产出

## 五、主负责人裁决

- 当前正式裁决为：
  1. 第二日期接入不再靠人工临时串命令
  2. 当前用一条 runbook +
     一个总控脚手架收口
  3. 后面一旦新日期 3 张图到位，
     就按这条 runbook 一口气推进

## 六、一句话口径

- 第二日期一旦到位，
  当前直接按 runbook 串行跑：
  `起批次 -> absorb -> 计划行 -> 单包验收 -> 两日期门槛 -> 总控摘要`。
