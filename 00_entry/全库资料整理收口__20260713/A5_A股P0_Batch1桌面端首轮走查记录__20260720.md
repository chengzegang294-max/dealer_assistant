## 四、桌面端走查结果

| 步骤 | 结果 | 说明 |
|---|---|---|
| 打开首页 | 通过 | 首屏可见 `今日事件流` 与金融限制披露入口 |
| 不选事件时主工作区为空态 | 通过 | 主工作区显示明确空态提示，没有提前展示旧草稿与旧回显 |
| 点击任一事件卡进入选中态 | 通过 | 点击后在同一首页进入主工作区，不跳新页 |
| 摘要、解释、记录区连续可见 | 通过 | 选中态下连续看到事件摘要、解释卡、记录表单 |
| 填写动作/理由/周期并提交 | 通过 | 提交后立即出现最新提交回显 |
| `processStatus` 回写 | 通过 | 当前事件从 `未处理` 变为 `已处理` |
| 待处理摘要回流 | 通过 | 待处理数量减少，点击另一待处理事件可回到同一主工作区上下文 |
| 切事件清空旧回显 | 通过 | 切到新事件后，旧提交回显被清空，草稿重建 |
| 搜索入口触发打开动作 | 通过 | 输入标的代码后，页面内回显“已发出打开标的页动作” |
