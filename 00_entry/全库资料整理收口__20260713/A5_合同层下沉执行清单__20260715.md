# A5 合同层下沉执行清单

更新时间：2026-07-16

## 用途

- 把 `A5` 当前已经 bridge_ready 的内容，继续压成后续真正可执行的下沉顺序。
- 这份清单不是新一轮资料补采计划。
- 这份清单只回答：
  - 接下来先下沉哪一层
  - 每层要产出什么
  - 什么情况下算完成

## 当前总顺序

- 第一步：
  - `A_REQ_002` 因子字段 -> 统一对象卡字段分组
- 第二步：
  - `A_REQ_003` 组合字段 -> 风险预算/权重合同分组
- 第三步：
  - 把两条线合成 `A5` 统一对象接口草案
- 第四步：
  - 把统一接口改写成 `A5` 最小对象卡草案
- 第五步：
  - 冻结字段真实来源状态与 runtime 边界
- 第六步：
  - 用一张 `最小样本实例卡` 检查可读性与误写边界

### 目标

  - `meta`
  - `input_raw`
  - `factor`
  - `constraint`
  - `risk_overlay`
  - `final_output`

### 产出物

- `A5_统一字段分组表`

### 当前状态

- `已落盘`：
  - `A5_统一字段分组表__20260715.tsv`

### 达标标准

- `A_REQ_002` 所有字段都能归入：
  - `meta / input_raw / factor / final_output`
- `A_REQ_003` 所有字段都能归入：
  - `meta / optimizer / constraint / risk_overlay / final_output`

## 二、阶段 S2：统一验收断言冻结

### 目标

- 把两条线当前的最小验收口径，写成一张统一验收断言表。

### 产出物

- `A5_统一验收断言表`

### 当前状态

- `已落盘`：
  - `A5_统一验收断言表__20260715.tsv`

### 断言分层

- `traceability`
  - 字段可回溯到输入
- `coverage`
  - 输出字段族必须齐全
- `bounds`
  - 权重/标量必须满足边界
- `degrade_behavior`
  - 降级时不能伪造结果

### 达标标准

- `A_REQ_002` 至少冻结：
  - 四因子族覆盖
  - 关键公式回溯
  - 缺字段时 NA / degraded 行为
- `A_REQ_003` 至少冻结：
  - 权重边界
  - `final_size_scalar` 公式
  - 缺 alpha / covariance / benchmark 时的降级或中止
