# A5 A股 P0 问答下钻推荐问题组与答案展示样式层

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把
    `问答下钻`
    继续压到
    `推荐问题组`
    与
    `答案展示样式`
    层
- 本页吸收：
  - 问答下钻模板与回答边界
  - 标的页返回流与补充记录联动
- 本页不做：
  - 大模型实现
  - 提示词工程细节
  - 自由聊天首页
  - 长篇研报式版面

## 二、上位约束

- 当前问答下钻仍只服务于：
  - `解释补充`
  - `字段释义`
  - `回看复盘`
- 当前问答下钻不是：
  - 自由聊天页
  - 荐股页
  - 长文研究页
- 当前每次答案展示都必须保留：
  - 当前标的
  - 当前事件
  - 当前解释回链
  - 记录/回看入口
  - `still_need_evidence`
    与相对基准限制提醒

## 三、推荐问题组结构

- 当前推荐问题组固定为
  `3`
  组：
  1. `解释补充组`
  2. `记录复盘组`
  3. `下一步关注组`

## 四、推荐问题组 1：解释补充组

- 当前只允许放：
  - `这次事件为什么触发`
  - `影响推演具体在说什么`
  - `历史类比对应了哪段过去情况`
- 当前作用是：
  - 帮用户把当前解释读透
- 当前不允许放：
  - 泛市场问题
  - 与当前事件无关的问题

## 五、推荐问题组 2：记录复盘组

- 当前只允许放：
  - `上次为什么记录成观察/减仓`
  - `这个理由标签是什么意思`
  - `这次还需要补充记录什么`
- 当前作用是：
  - 帮用户理解最近记录与当前事件的关系
- 当前若用户点此组问题，
  答案末尾必须能接到：
  - `查看最近记录`
  - `补充这次记录`

## 六、推荐问题组 3：下一步关注组

- 当前只允许放：
  - `下一次复查点要看什么`
  - `回看这条记录时先看哪几个字段`
  - `如果还不确定，应该回到哪里继续看`
- 当前作用是：
  - 让用户把问答结果接回主路径
- 当前不允许放：
  - 未来价格预测
  - 下一只股票推荐

## 七、推荐问题排序原则

- 当前默认排序固定为：
  1. `解释补充组`
  2. `记录复盘组`
  3. `下一步关注组`
- 当前若用户刚从标的页解释区进入，
  默认优先高亮：
  - `解释补充组`
- 当前若用户是从最近记录区进入，
  默认优先高亮：
  - `记录复盘组`

## 八、答案展示样式结构

- 当前答案展示固定为
  `5`
  个区块：
  1. `问题条`
  2. `事件与字段来源条`
  3. `核心回答区`
  4. `下一步动作条`
  5. `金融限制提醒条`

## 九、区块 1：问题条

- 当前必须显示：
  - 用户问的是什么
  - 该问题属于哪一组
- 当前作用是：
  - 防止回答跑题

## 十、区块 2：事件与字段来源条

- 当前必须显示：
  - 当前标的
  - 当前事件标题
  - 回答引用了哪些解释卡/记录字段
- 当前不允许：
  - 只给结论不写来源

## 十一、区块 3：核心回答区

- 当前核心回答只允许：
  - 中短回答
  - 单问题闭合
  - 回顾性 / 条件式 / 非承诺式表达
- 当前不允许：
  - 扩成多主题长文
  - 命令式买卖建议
  - 确定性收益表达

## 十二、区块 4：下一步动作条

- 当前答案结束后必须给出：
  - `回到标的页继续看解释`
  - `查看最近记录`
  - `补充这次记录`
  三者中的一个或多个
- 当前不允许：
  - 把用户直接引到自由聊天
  - 推荐跳到无关股票

## 十三、区块 5：金融限制提醒条

- 当前答案末尾必须固定保留：
  - `still_need_evidence`
  - 相对基准限制仍存在
- 当前不允许用：
  - 已验证
  - 稳定有效
  - 可以直接执行
  作为结尾

## 十四、答案展示长度与层级

- 当前桌面端答案展示应优先做到：
  - 一屏内先看完问题条、来源条、核心回答主段
- 当前移动端答案展示应优先做到：
  - 先看问题条与核心回答
  - 再下滑看到下一步动作和金融限制提醒
- 当前不允许：
  - 把来源条折叠得太深
  - 把金融限制提醒藏到底部不可见区

## 十五、异常态

- 当前若推荐问题生成失败，
  只允许降级到：
  - 手动提问入口
  - 最近 `3`
    条固定问题模板
- 当前若答案生成失败，
  必须至少保留：
  - 原问题
  - 原事件上下文
  - 返回标的页入口
  - 再试一次入口

## 十六、通过标准

- 当前通过标准是：
  - 用户进入问答下钻后，
    能一眼看懂：
    - 现在问的是哪类问题
    - 回答基于哪条事件和哪些字段
    - 看完之后下一步该回哪里
- 若出现以下任一情况，
  视为不通过：
  - 推荐问题组与当前事件无关
  - 答案不标明来源字段
  - 答案结束后没有下一步动作条
  - 金融限制提醒被隐藏

## 十七、停止规则

- 当前写清以下内容后即停：
  - 推荐问题三组结构
  - 推荐问题排序原则
  - 答案展示五区块结构
  - 下一步动作条
  - 异常态与通过标准
- 当前不继续顺手扩：
  - 前端视觉稿
  - 提示词实现
  - 新 runtime
