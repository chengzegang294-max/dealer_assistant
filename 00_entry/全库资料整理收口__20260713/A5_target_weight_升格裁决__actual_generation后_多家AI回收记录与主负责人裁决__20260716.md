# A5 target_weight 升格裁决 actual_generation后 多家AI回收记录与主负责人裁决

更新时间：2026-07-16

## 用途

- 吸收本轮外部模型对“`actual_generation` 后是否足以进入更进一步升级判断”的首轮回包。
- 区分：
  - 有效票
  - 边界漂移票
  - 无效票
- 最终由主负责人正式拍板，不把外部模型回包直接当最终结论。

## 二、单模型吸收

### 1. `GPT`

- 有效性：
  - `有效`
- 结论：
  - `conditional`
- 一句话原因：
  - 已确认“重开资格成立”，但“actual_generation 后是否足以进入更进一步升级判断”仍是新题，不能沿用上一轮 `yes`。
- 唯一最小剩余缺口：
  - 必须按新题单独裁决 `degraded_risk_handling / covariance_model_id` 边界
- 禁止误写提醒：
  - 不能把“重开资格已成立”外推成“更进一步升级判断已通过”，更不能写成 `output_passed`。
- 主负责人备注：
  - 这是当前唯一真正完成题目切换并抓住新边界的一票。

### 2. `Kimi`

- 有效性：
  - `边界漂移`
- 结论：
  - `yes`
- 一句话原因：
  - 仍在回答“actual generation execution 完成后是否足以重开裁决资格”。
- 唯一最小剩余缺口：
  - 不适用
- 禁止误写提醒：
  - 仍提醒不能写成 `output_passed`。
- 主负责人备注：
  - 不是错误，但没跟上题目从“重开资格”切到“更进一步升级判断”的前移。

### 3. `GLM`

- 有效性：
  - `边界漂移`
- 结论：
  - `yes`
- 一句话原因：
  - 继续停在“满足重开升格裁决门槛”的旧题层面。
- 唯一最小剩余缺口：
  - 不适用
- 禁止误写提醒：
  - 仍提醒不能写成 `output_passed`、`正式优化器 ready` 或 `covariance_model_id ready`。
- 主负责人备注：
  - 对上一轮是好票，但对本轮不是有效票。

### 4. `DeepSeek`

- 有效性：
  - `无效`
- 结论：
  - `无独立结论`
- 一句话原因：
  - 主要在判断 `Qwen` 是否无效，没有回答本轮核心题。
- 唯一最小剩余缺口：
  - 不适用
- 禁止误写提醒：
  - 不适用
- 主负责人备注：
  - 可作为旁证，但不能进入本轮票面。

### 5. `Qwen`

- 有效性：
  - `无效`
- 结论：
  - `无回包`
- 一句话原因：
  - 当前贴回内容中没有本轮可吸收的独立答案。
- 唯一最小剩余缺口：
  - 不适用
- 禁止误写提醒：
  - 不适用
- 主负责人备注：
  - 这轮继续视为缺席，不纳入票面。

## 三、主负责人裁决

- 当前有效票面不是：
  - 多数模型对新题给出稳定 `yes / no / conditional`
- 当前有效票面是：
  - `1/5` 有效
  - `2/5` 边界漂移
  - `2/5` 无效
- 当前正式裁决为：
  - `票面不足，不直接拍板`
- 当前最稳正式口径是：
  - 已确认：
    - `target_weight 足以重开升格裁决`
  - 尚未确认：
    - `target_weight 是否已足以进入更进一步升级判断`

## 四、为什么不直接采纳 `GPT`

- 原因 1：
  - 当前虽然 `GPT` 最对题，但仍只有单票有效。
- 原因 2：
  - 其核心贡献是把题目边界纠正过来，而不是给出一轮多票一致的升级判断票面。
- 原因 3：
  - 当前最顺主线不是单票拍板，而是立刻把问题收得更窄，再做一轮对题回收。

## 五、当前先做什么

- 当前先做：
  - 正式吸收本轮失焦回包
  - 把“新题与旧题不同”写死
  - 直接起第二轮更窄追问稿

## 六、当前暂缓什么

- 暂缓：
  - 直接写成 `yes` 或 `no`
  - 直接把 `target_weight` 推进到下一状态
- 暂缓原因：
  - 当前多AI票面质量不足
  - 仍需更窄、更强约束的一轮回包

## 七、一句话口径

- 当前这轮 `actual_generation后` 升级判断首轮回包的正式结论是：
  - `旧题残留严重，票面不足`
  - `必须用更窄追问稿再做一轮`
