## 一、这页用途

- 把当前 Batch1 的“本地 fixtures 直连”升级为“异步 API 桩加载”，为后续接真实数据层留出落点。
- 保持 UI 与 contract 不变，只调整数据入口。

## 二、主负责人裁决

- 可以把当前阶段冻结为“可交付基线”。
- 下一刀：补异步数据源桩（API 层），让事件与记录可以从异步 mock 加载。

## 三、本轮允许范围

- 允许新增：
  - `src/features/home/api/homeApi.ts`
- 允许修改：
  - `useHomeWorkspace.ts`（把初始数据加载迁到 API）
  - 相关测试用例（适配异步加载）
  - `README`、`Cursor 同步包`
- 不允许：
  - 结构美化（adapter/section contract）
  - UI 改动
  - E2E 自动化

## 四、本轮最小通过条件

- 满足以下四项即可收口：
  1. 事件与记录不再由 hook 直接引用样本数据初始化，而是通过异步 API 获取
  2. `npm run test / npm run lint / npm run build` 全绿
  3. 现有最小护栏不回归（模型/WorkspaceHook/PageHook）
  4. README 与 Cursor 同步包已回填新的停点口径

## 四点五、本轮实际结果

  - `test / lint / build` 全绿
- 本轮停止规则已满足，当前不继续猜写真实 endpoint 与 schema
