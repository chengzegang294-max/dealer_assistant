# A5 金融测试标准化最小输入包页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 冻结进入金融测试标准化准备前，
    一组样本最少要带哪些输入
  - 把必需项、增强项、可降级项分开

## 二、当前输入包分层

### 2.1 必需输入

- 当前认定的最小必需输入为：
  1. `sample_date`
  2. `页面级来源锚点`
  3. `背景对象至少 1 组`
  4. `触发对象至少 1 组`
  5. `provenance / manifest / source_anchor`

### 2.2 当前最稳的页面级必需样本包

- 若当前样本来自
  `东方财富 PC 客户端`
  ，最稳的最小必需页先冻结为：
  1. `市场情绪总览`
  2. `市场宽度涨停跌停`
  3. `龙虎榜异动资金`

- 这三项分别承担：
  1. 日期总览锚点
  2. `沪深涨跌停`
     背景对象
  3. `上榜资金`
     触发对象

### 2.3 当前候选增强输入

- 当前候选增强输入冻结为：
  1. `涨停`
  2. `炸板`
  3. `题材中心`
  4. `看盘工作台`
  5. `连板天梯 / quicktiny`

- 这些增强项当前的角色分别是：
  1. `涨停 + 炸板`
     - `打板资金`
       候选页对
  2. `题材中心`
     - `HYDB`
       行业/题材背景候选页
  3. `看盘工作台`
     - `ZSDB`
       指数环境候选页
  4. `连板天梯 / quicktiny`
     - 高度结构/情绪周期增强层

### 2.4 当前可降级项

- 当前允许先降级而不阻塞标准化准备的输入为：
  1. `HYDB` 严格同日页面/日线输入
  2. `ZSDB` 严格同日页面/日线输入
  3. `打板资金` 与原系统公式的一比一等价页
  4. `精确 occurredAt`

- 当前这些项可以先降级，
  是因为：
  - 当前主线还在
    `金融测试标准化准备`
    不是正式金融测试执行

## 四、当前主负责人裁决

- 当前正式裁决为：
  1. 进入金融测试标准化准备时，
     先不要求所有对象都达到严格同日真值态
  2. 当前先把样本最小输入包冻结成：
     - `3项必需`
     - `4类增强`
     - `可降级项单列`
  3. 第二轮 `2026-07-29`
     已可作为这套最小输入包的首个工作样本

## 五、一句话口径

- 金融测试标准化准备当前先用
  `市场情绪总览 + 市场宽度涨停跌停 + 龙虎榜异动资金`
  立住最小输入包，
  其余页面先作为增强项和可降级项管理。
