## 四、统一抽检口令

每房固定顺序：

1. 登录态进入该房历史记录（建议倒序）
2. 先跑当前页：
   - `live_info_current_page_export_v1.js`（v1.3）
3. 再设增量变量并跑：
   - `live_info_incremental_export_v1.js`（v1.1）

### 4.1 格兰投研（续跑到顶）

若本地仍有该房 checkpoint，可直接续跑；否则先小跑再建续跑：

```js
// 若确定要清旧断点重来：
window.__infoLiveIncrementalExportV1Options = {
  reset_checkpoint: true,
  scroll_direction: "up",
  start_position: "keep",
  max_rounds: 40
};
// 跑增量脚本后，若 stop_reason=manual_limit，再续：
window.__infoLiveIncrementalExportV1Options = {
  reset_checkpoint: false,
  scroll_direction: "up",
  max_rounds: 200
};
```

### 4.2 周期女王（重跑纠 `scroll_stuck`）

## 五、抽检通过门槛

单房记「增量抽检通过」需同时满足：

1. 视觉真实滚动
2. `stop_reason = scroll_end`（或明确无更多记录）
3. `room_anchor` 可接受（正确名或已登记别名）
4. JSON 落入：
   - `02_runtime/info_live_room_sampling/batch_05__.../00_raw/priority_rooms/<房间名>/`
