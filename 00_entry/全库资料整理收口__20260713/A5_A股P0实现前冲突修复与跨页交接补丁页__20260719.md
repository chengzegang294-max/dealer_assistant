# A5 A股 P0 实现前冲突修复与跨页交接补丁页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 吸收
    `Cursor`
    的编码向审校结果
  - 把当前实现前会断链或撞名的硬问题正式修复
- 本页不做：
  - 前端框架选型
  - API 真实实现
  - 多AI重开
  - 条件式门禁重开

## 二、Trae 最终吸收判断

- 当前接受的硬问题包括：
  1. 首页到标的页搜索入口断链
  2. `SupplementRecord.createdAt`
     与
     `supplementCreatedAt`
     撞名
  3. `DecisionRecord`
     把草稿与成稿混用
  4. `QaEntryPanel`
     缺正式输出合同
  5. 金融披露被排到过晚顺序，
     与首页首批强制披露冲突
- 当前不直接照抄的部分是：
  - 任何还未进入正式页的开放式推测

## 三、当前正式修补项

### 3.1 搜索入口补齐

- 当前首页组件树必须补：
  - `StockSearchEntry`
- 当前首页必须补正式输出：
  - `onOpenStockPage(stockCode)`
- 当前其作用是：
  - 把
    `首页搜标的 -> 标的分析页`
    这条已冻结路径接通

### 3.2 补充记录编辑组件补齐

- 当前标的页最近记录区必须补：
  - `SupplementRecordEditor`
- 当前其作用是：
  - 给
    `补充记录编辑态 / 提交态 / 失败态`
    一个正式挂点

### 3.3 问答入口输出合同补齐

- 当前
  `QaEntryPanel`
  必须补：
  - `onOpenQaPage(eventId)`
- 当前其作用是：
  - 让标的页进入问答页不再只是口头路径

### 3.4 字段名统一

- 当前补充记录时间字段统一冻结为：
  - `supplementCreatedAt`
- 当前不再允许：
  - `createdAt`
    与
    `supplementCreatedAt`
    双写并存

### 3.5 草稿与成稿拆分

- 当前正式拆为：
  - `DecisionRecordDraft`
  - `DecisionRecord`
- 当前规则是：
  - 草稿不要求
    `decisionId`
  - 成稿提交后必须有
    `decisionId`

### 3.6 披露顺序前移

- 当前金融披露不是第
  `6`
  步才接入
- 当前必须前移到：
  - `Batch 1`
- 当前原因是：
  - 首页事件卡
  - 首页主工作区
  - 问答页
  都已强制要求披露入口

## 四、跨页交接优先级

- 当前
  `currentEventSummary`
  交接优先级冻结为：
  1. 在首页内，
     由
     `selectedEventId`
     对应事件回写
  2. 进入标的页后，
     由
     `selectedRelatedEventId`
     对应事件覆盖当前页上下文
  3. 返回首页时，
     恢复首页最近一次
     `selectedEventId`
     上下文
- 当前不允许：
  - 首页与标的页同时争抢写同一个当前事件摘要

## 五、事件状态回写归属

- 当前
  `processStatus`
  的写回规则冻结为：
  - 首页记录提交成功后，
    由首页事件流源对象更新
  - 标的页只消费该状态的镜像，
    不单独发明第二套状态真值
