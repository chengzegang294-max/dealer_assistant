# A_REQ_001 数据可得性与成本裁决补页

更新时间：2026-07-15

## 用途

- 把 `A_REQ_001` 当前最缺的：
  - 数据可得性
  - 成本
  - formal raw 边界
  一次写清。

## 当前结论

- 当前 A股行情底座的正式闭合范围是：
  - `daily_ohlcv_catalog`
- 分钟级当前状态不是：
  - 不可得
- 而是：
  - `sample_available_but_not_formalized`
- Level-2 / 席位逐笔当前状态是：
  - `future_only`

## 一、日线

- 当前状态：
  - `closed`
- 依据：
  - runtime 已有正式 raw 目录与 catalog
- 当前口径：
  - 可作为正式可复现输入底座

## 二、分钟级

- 当前状态：
  - `partial`
- 当前可得性：
  - 有 provider 候选
  - 有 live probe / 限频阻塞记录
  - 有外部分钟样本 provenance
- 当前成本口径：
  - `Tushare` 不适合大额预付，只建议最小必要补点
  - `通达信` 优先承担后续 `daily/minute OHLCV`
  - 外部历史分钟包可作为定点样本补位，但不能冒充默认 runtime 主源

## 三、Level-2 / 席位逐笔

- 当前状态：
  - `not_available_in_current_runtime`
- 当前成本口径：
  - 成本最高
  - 权限最重
  - 仓内无 fresh-run 实证
- 当前裁决：
  - 不纳入当前 runtime 合同
  - 保持 `future_only`

## 四、正式分层裁决

| 层级 | 当前状态 | 是否可作为默认正式输入 | 当前成本/权限判断 | 当前裁决 |
|---|---|---|---|---|
| `1d` | `closed` | yes | 已有 formal raw + catalog | 正式底座 |
| `60m/5m` | `partial` | no | 有候选源与样本，但未 formalize | 只作定点样本验证 |
| `Level-2` | `future_only` | no | 成本高、权限重、无仓内实证 | 暂不纳入 |

## 五、主负责人裁决

- 当前 A_REQ_001 不再缺：
  - “有没有任何行情数据”
- 当前 A_REQ_001 真缺的是：
  - `minute 是否能 formalize`
  - `Level-2 是否暂时禁止纳入`
- 所以当前正式口径固定为：
  - `default = daily_only`
  - `minute = sample_only_with_provenance`
  - `level2 = unavailable_in_current_runtime`
