## 四、当前内容复核后的分层

### 1. 前台高频盯盘（优先通知）

- `猫哥竞价`
  - 特征：盘前 / 竞价 / 日内动作提示密度高
  - 当前问题：旧导出脚本曾把 `room_anchor` 抽歪成 `爽歪歪`

- `擒龙小师姐`
  - 特征：常见 `天时 / 地利 / 跟踪 / 建仓建议`
  - 当前判断：结构化强，适合通知

- `小作文嗅嗅+机构研报`
  - 特征：题材催化、小作文、机构研报线索
  - 当前判断：独特性高，适合重点盯

- `七福潜伏低吸`
  - 特征：有仓位、日内动作、观察点
  - 当前判断：适合通知，但噪声略高

### 2. 二线参考（保留但不必最高频通知）

- `机构电话会议纪要+小作文+情报`
  - 特征：信息汇编密度高
  - 当前判断：适合做补充参考，不一定要放前台最顶

- `机构研报资讯精选`
  - 特征：研报 / 外盘 / 纪要摘要
  - 当前判断：参考价值有，但即时交易动作弱于前台组

- `只爱主波浪`
  - 特征：节奏、观点、波段判断较多
  - 当前判断：适合辅助参考

### 3. 观察层

- `大师兄擒妖`
  - 当前判断：有盘前思路，但现阶段证据厚度不如前两层

## 五、关于模糊词 / 谐音 / 图片

- 模糊词、谐音、规避敏感词的写法：
  - 当前可读，不构成主阻塞。
  - 后续若样本继续增多，可单独沉淀一份“直播间常见替代表达词表”。

- 纯文字房间：
  - 当前优先级最高，最适合先做稳定抽取与复核。

- 图片较多房间：
  - 当前不判为不可做。
  - 但难度确实高于纯文字，应作为第二层能力补充：
    - 先拿到图片 URL / 可见图片数
    - 再决定是否需要 OCR

## 六、当前执行口径

- 当前默认动作不是让用户重新从头挑房间。
- 当前默认动作是：
  1. 用户继续按自己对“有用 / 持续更新 / 值得通知”的理解做保留
  2. 工具导出“房间名 + 最近预览 + 最近时间 + 内容形态提示”
  3. 主负责人据此做内容复核与分层
