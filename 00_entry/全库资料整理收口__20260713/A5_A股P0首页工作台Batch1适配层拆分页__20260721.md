# A5 A股 P0 首页工作台 Batch1 适配层拆分页

更新时间：2026-07-21

## 一、这页用途

- 本页只做：
  - 冻结 `A股 P0 Batch1` 当前对 `homeViewModel` 适配层的继续拆分口径
  - 说明为什么当前最值钱的一步不是继续加功能，而是防止 adapter 重新堆成单文件中心
  - 写死这轮拆分允许的范围与停止规则
- 本页不做：
  - 重开产品方向
  - 重开字段合同
  - 新增页面功能
  - 重开多市场、本地 AI 技术栈

## 二、当前主线与当前不是

- 当前主线：
  - `A股 P0 Batch1` 首页工作台实现线
- 当前不是：
  - `batch_149` 新吸收线
  - 外部验证线
  - 新合同泛扩线

## 三、为什么这一手最值钱

- 到当前为止，首页展示层已经把：
  - 头部
  - 搜索
  - 事件流
  - 右栏
  - 主工作区摘要
  - 解释卡
  - 表单展示文案
  逐步改为先接 adapter 产出的展示字段。
- 这意味着当前风险已经从“页面太胖”转移成：
  - `homeViewModel.ts` 可能重新长成新的单文件中心
- 因此这一手最值钱的不是扩展新能力，而是把 adapter 继续按消费区域拆开，让后续真数据接入时不必再回到单文件修改。

## 四、本轮允许继续拆分的范围

- 允许继续拆分：
  - `homeViewModel.ts` 的类型与函数
  - 头部/搜索 adapter
  - 事件流/右栏 adapter
  - 主工作区 adapter
  - barrel re-export
- 允许新增：
  - adapter 子文件
  - adapter 类型文件
  - 保持原导入路径稳定的转发文件
- 不允许借机扩展：
  - 新 UI 功能
  - 新状态字段
  - 新交互路径
  - 新数据协议

## 五、当前目标边界

- `Home.tsx`
  - 继续只做编排与 adapter 调用
- `adapter`
  - 按消费区域分拆，而不是把所有 view model 长期堆在一个文件里
- `components`
  - 继续优先接收裁剪后的展示字段
- `workspaceModel` 与 `useHomeWorkspace`
  - 不因本轮拆分而回流展示口径

## 六、本轮停止规则

- 满足以下四项即可视为这一小段收口：
  1. `homeViewModel.ts` 不再直接承载整套 adapter 细节
  2. 原有组件导入路径不必大面积改写
  3. `npm run build` 通过
  4. `npm run lint` 通过
