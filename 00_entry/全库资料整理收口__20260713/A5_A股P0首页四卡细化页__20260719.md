# A5 A股 P0 首页四卡细化页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把
    `A股 P0`
    首页的
    `4`
    张卡
    从首页入口层继续压到可直接画稿、
    可直接评审的页面级合同
- 本页不做：
  - 视觉风格
  - 具体前端组件命名
  - 多市场扩展
  - 金融门禁重讨论

## 二、上位约束

- 当前首页唯一主轴仍是：
  - `今日事件流`
- 当前主路径仍是：
  - `事件流 -> 解释卡 -> 决策记录 -> 回看`
- 当前首页任何涉及：
  - 事件
  - 解释
  - 决策
  - 信号
  的区域，
  都不得脱离：
  - `A5_A股P0原型阶段金融披露与条件式门禁页__20260719.md`

## 三、四卡清单

- 当前首页四卡固定为：
  1. `全局状态条`
  2. `今日事件流`
  3. `待处理决策台`
  4. `历史决策追踪`

## 四、卡 1：全局状态条

### 4.1 角色

- 当前角色只允许是：
  - 首页抬头级摘要
- 当前不允许长回：
  - 第二主轴
  - 行情大屏
  - 大图表区

### 4.2 最小字段

- 当前只放：
  - `市场一句话`
  - `待处理事件数`
  - `持仓风险提醒`
  - `最近一次决策状态`

### 4.3 不放什么

- 当前不放：
  - 新闻流
  - 多市场切换器
  - 复杂筛选器
  - 长段 AI 摘要

## 五、卡 2：今日事件流

### 5.1 角色

- 当前是首页绝对主轴
- 当前第一页最先看的必须是：
  - `今日事件流`

### 5.2 单卡最小字段

- 当前事件卡最少展示：
  - `事件标题`
  - `触发对象`
  - `触发时间`
  - `与持仓关系标签`
  - `已处理/未处理状态`

### 5.3 分组口径

- 当前允许的轻分组只有：
  - `持仓相关`
  - `关注相关`
  - `其它`
- 当前不允许扩成：
  - 多维过滤器中心
  - 复杂排序工作台

### 5.4 点击后行为

- 当前点击事件后，
  必须在同一页面主工作区加载：
  - `解释卡`
  - `决策记录区`
- 当前不允许：
  - 跳新页面
  - 打开大弹窗
  - 把记录入口藏到二级页

## 六、卡 3：待处理决策台

### 6.1 角色

- 当前只承担：
  - 摘要提醒
- 当前不是：
  - 新页面
  - 第二工作台

### 6.2 内容边界

- 当前只展示：
  - 最近未处理事件
  - 待复查事件
  - 即将到期的复查点
- 当前不展示：
  - 大段历史记录
  - 大图表
  - 复杂统计

### 6.3 与主工作区的关系

- 当前必须理解成：
  - `待处理决策台`
    只是主工作区的摘要入口
- 当前不得把它做成：
  - 第五张大卡
  - 独立功能页

## 七、卡 4：历史决策追踪

### 7.1 角色

- 当前只承担：
  - 回看层
- 当前不得抢占：
  - 事件流
  - 解释卡
  - 决策记录
  的主注意力

### 7.2 最小展示

- 当前默认只显示：
  - 最近 `3~5` 条摘要
- 当前允许：
  - 展开查看更多
- 当前不允许：
  - 首屏大面积默认展开

### 7.3 位置原则

- 桌面端：
  - 底部折叠区
  - 或右侧次级区
- 移动端：
  - 底部 Tab
  - 或等价次级入口

## 八、四卡之间的注意力优先级

- 当前优先级固定为：
  1. `今日事件流`
  2. `解释卡 + 决策记录`
  3. `待处理决策台`
  4. `历史决策追踪`
- 若视觉或布局上出现：
  - 历史追踪比事件流更显眼
  - 待处理决策台比解释卡更抢主工作区
  视为偏离主线

## 九、桌面端走查重点

- 当前桌面端必须检查：
  - 左列事件流是否足够一眼扫完
  - 右列解释卡与决策记录是否共区自然
  - 待处理决策台是否只是摘要
  - 历史追踪是否保持次级

## 十、移动端走查重点

- 当前移动端必须检查：
  - 事件流首屏是否仍为主入口
  - 半高抽屉是否足够传达事件含义
  - 全展开后记录入口是否仍明显
  - 历史回看是否次要但可达

## 十一、四卡通过标准

- 当前四卡通过标准不是：
  - 模块越多越好
  - 信息越满越好
- 当前四卡通过标准是：
  - 用户能顺着四卡结构，
    在不迷路的情况下完成：
    - 看见事件
    - 理解解释
    - 做记录
    - 之后回看

## 十二、一句话口径

- 当前最准确的一句话是：
  - `A股 P0`
    首页四卡已经被压成一个以
    `今日事件流`
    为第一主轴、
    其余三卡只做摘要、回看和辅助收口、
    不允许抢主工作区的页面级合同。
