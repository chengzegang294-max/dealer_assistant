## 3. 正式冻结的定义层

本轮正式冻结 `3` 项定义层：

1. `F026 normalized_price_precision`
   - 原始保存精度、计算精度、展示精度、交易所最小价位必须分层。
   - 禁止把价格处理粗暴统一成“两位小数”。
   - 当前只冻结定义层，不声称当前 OHLC 数据源已落地。
2. `F031 TRANGE`
   - 公式冻结为：`max(high-low, abs(high-prev_close), abs(low-prev_close))`
   - 只冻结公式定义，不冻结上游 `high / low / prev_close` 的 landed variant。
   - 上游价格链未落地前禁止实施。
3. `F032 ATR14_Wilder`
   - `seed = 首 14 个有效 TR 的简单平均`
   - `ATR_t = (prev_ATR*13 + TR_t)/14`
   - 必须显式命名 `Wilder`
   - 不得与 `SMA ATR`、`EMA ATR` 混用
   - 上游价格链未落地前禁止实施

## 4. 交易所层条件定义

本轮正式吸收 `4` 项交易所层条件定义：

1. `F008 open`
2. `F009 high`
3. `F010 low`
4. `F011 close`

固定口径：

1. 只冻结交易事实层或交易所层定义。
2. 不等于 `SRC-003` 字段已经确认。
3. 不证明当前 supplier 的单位、复权状态、缺失值处理或回退规则。
4. 沪深规则若有差异，保留交易所范围，不强行合并成供应商统一语义。

## 5. 必须显式命名的变体族

本轮正式吸收 `4` 项变体族冻结：

1. `F012 prev_close`
   - 必须显式拆成 `raw`、除权昨收、前复权昨收等变体。
   - 禁止保留一个不带变体名的笼统 `prev_close`。
2. `F016 turnover_rate`
   - 必须显式拆成总股本、流通股本、自由流通股本分母变体。
   - 禁止默认选择某一个分母作为全局口径。
3. `F030 SMA5`
   - 必须写成 `SMA5(close_variant)`。
   - 不默认使用前复权或不复权。
4. `F034 gap`
   - 第一层：开盘价相对昨收的事实
   - 第二层：全天是否回补
   - 第三层：事后形态分类
   - 只有第一层允许进入事实候选

## 6. 未解决字段、黑箱及内部启发式

### 6.1 字段语义继续缺失：3 项

1. `F013 volume`
   - `股 / 手` 口径未定
   - 单边 / 双边统计语义未定
2. `F014 amount`
   - `元 / 千元` 口径未定
   - 统计范围与供应商语义未定
3. `F015 pct_change`
   - denominator 未定
   - `percent / ratio` 尺度未定

固定口径：

- 禁止用行业惯例补猜。

### 6.2 黑箱展示字段：1 项

1. `F019 sector_main_net_amount`
   - 只允许记录供应商展示值
   - 不允许解释主力阈值、主动买卖或累计窗口
   - 不允许生成公式

### 6.3 内部启发式：2 项

1. `F033 range_position_20d`
2. `F035 sector_alignment`

固定口径：

1. 它们不是标准指标。
2. 不进入事实预填默认字段。
3. 不得作为自动建议依据。
4. 后续只有单独建立实现合同和历史验证后才能重开。
