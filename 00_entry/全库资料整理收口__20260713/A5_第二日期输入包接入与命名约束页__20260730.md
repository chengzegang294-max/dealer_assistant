# A5 第二日期输入包接入与命名约束页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 冻结第二日期样本接入现有验收链路时的命名约束
  - 避免第二次补证时文件名、输入包名、输出名各写各的

## 二、当前统一命名规则

### 2.1 输入包 ID

- 第二日期输入包统一写法冻结为：

```text
A5_R2_EASTMONEY_SCREENSHOT_INPUT_PACK_<sample_date>_V1
```

- 示例：

```text
A5_R2_EASTMONEY_SCREENSHOT_INPUT_PACK_2026-07-29_V1
```

### 2.2 截图文件名

- 第二日期最小必需截图统一写法冻结为：

```text
<sample_date>__市场情绪总览.png
<sample_date>__市场宽度涨停跌停.png
<sample_date>__龙虎榜异动资金.png
```

- 当前不再接受：
  - 只有 `截图1.png`
  - 只有 `情绪.png`
  - 同一批里日期前缀一会儿有一会儿没有

### 2.3 验收输出文件名

- 第二日期输入包验收输出统一写法冻结为：

```text
a5_input_pack_acceptance_<batch_or_family>_<yyyymmdd>.json
```

- 两日期门槛验收输出继续写法固定为：

```text
a5_multi_pack_gate_acceptance_<yyyymmdd>.json
```

## 三、当前统一路径规则

### 3.1 来源批次路径

- 第二日期样本应先落到：

```text
10_source_library_archive/<new_batch_family>/00_raw_snapshot/user_screenshots/
```

### 3.2 运行时计划路径

- 第二日期输入包计划行统一回填到：

```text
02_runtime/a5_financial_testing_standardization/a5_input_pack_sample_plan_v1.tsv
```

### 3.3 运行时输出路径

- 第二日期输入包验收输出统一落到：

```text
02_runtime/a5_financial_testing_standardization/acceptance_outputs/
```

## 四、主负责人裁决

- 当前正式裁决为：
  1. 第二日期接入时，
     先统一命名与路径，
     再谈对象映射
  2. 不让第二日期接入重新回到
     `临时截图 + 临时命名`
     状态
  3. 一旦第二日期到位，
     就按这页命名规则直接进现有验收链

## 五、一句话口径

- 第二日期当前先统一
  `输入包 ID / 截图文件名 / 验收输出名 / 回填路径`，
  这样后面补进来时就不用再改口径。
