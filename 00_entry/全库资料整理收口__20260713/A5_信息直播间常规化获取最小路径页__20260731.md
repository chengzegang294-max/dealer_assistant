# A5 信息直播间常规化获取最小路径页

更新时间：2026-07-31

## 一、这页用途

- 本页只做：
  1. 把
     `信息直播间`
     能否常规化获取
     压成可执行最小路径
  2. 明确这条线当前的真实门槛，
     不再模糊说成“能看历史”

## 二、当前主线

- 当前主线是：
  - `信息直播间常规化获取`

- 当前不是：
  - 再讨论站点是否存在
  - 再试图把它写成匿名直连源

## 三、当前最关键的新结论

- 当前最关键的新结论只有一句：

`信息直播间可以做常规化获取，但前提不是匿名访问，而是稳定登录态与账号留痕。`

## 四、常规化获取的最小路径

- 当前最小路径冻结为：

1. 保持可用登录态
2. 进入左侧直播间列表
3. 选择目标直播间/栏目
4. 点
   `历史记录`
5. 选择目标日期
6. 在右侧正文区读取：
   - 文本内容
   - 图片内容
   - 时间信息
7. 形成最小摘录单元：
   - `sample_date`
   - `room_or_topic_anchor`
   - `text_excerpt`
   - `image_evidence`

## 五、当前不应误判成什么

- 当前不应误判成：

1. `公开网页直接抓取`
   - `不是`

2. `游客态可稳定回看历史`
   - `不是`

3. `视频回放站`
   - `不是`

4. `天然结构化 API 源`
   - `不是`

## 六、当前真实门槛

- 当前真实门槛冻结为：

1. 必须处于可用登录态
2. 账号需要有
   `留痕`
   才能看到历史记录
3. 当前内容主要是：
   - `静态文本`
   - `静态图片`
4. 当前回看路径依赖：
   - `房间选择`
   - `历史记录`
   - `日期切换`

## 七、当前最适合的常规化模式

- 当前主负责人正式裁决为：

1. 当前最适合的不是：
   - `匿名自动抓取`

2. 当前最适合的是：
   - `人工登录后常规摘录`
   - `人工登录 + 半自动整理`

3. 当前暂不建议直接写成：
   - `全自动稳定采集`

- 原因：
  - 历史能力受
    `登录态 + 留痕`
    约束，
    这意味着账号环境本身就是采集条件的一部分

## 八、当前与 A5 的连接方式

- 当前这条线进入 A5，
  统一按：
  - `解释层 / 旁证层`
  接入

- 当前最适合回链的对象优先仍是：
  1. `市场情绪总览`
  2. `上榜资金`
  3. `题材中心`

- 当前不把这条线升成：
  - `正式真值主源`

## 九、当前最小采集单元

- 当前最小采集单元冻结为：

1. 日期：
   - `sample_date`
2. 直播间名或栏目名：
   - `room_anchor`
3. 文本摘录：
   - `excerpt`
4. 图片证据：
   - `image`
5. 右侧正文时间戳：
   - `occurredAt_or_display_time`

## 十、当前最小下一步

- 当前最小下一步冻结为：
  1. 后续再补一笔真实历史摘录样例
  2. 把
     `room_anchor`
     与
     `topic_anchor`
     写法冻结
  3. 再决定是否需要做
     `人工登录后的摘录模板`

## 十一、主负责人正式裁决

- 当前正式裁决为：

1. `信息直播间`
   已经具备
   `常规化获取`
   的最小成立条件

2. 但这个
   `常规化`
   当前必须明写为：
   - `登录态下的常规获取`

3. 当前不把它升级成：
   - `匿名公开源`
   - `全自动稳定源`

## 十二、一句话口径

- 当前这条线已经能正式收口成一句话：`信息直播间` 可以做常规化获取，但方式不是匿名抓取，而是“保持登录态 -> 选直播间 -> 点历史记录 -> 选日期 -> 摘录文本与图片”的登录态常规获取链。
