# A5 A股 P0 标的页 Batch2 问答结果样式层页

更新时间：2026-07-23

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 问答下钻从“可进入的占位页”继续压到“结果区样式层”
  - 让当前问答页更接近可交付界面，而不是继续扩真实问答逻辑
- 本页不做：
  - 真实大模型回答
  - 自由输入问答
  - 价格预测 / 买卖建议
  - 新数据协议

## 二、主负责人裁决

- 当前最值钱的一刀不是再扩问题数量，而是把 `推荐问题区 + 结果区` 收成更稳定的展示合同。
- 本轮只允许补：
  - 推荐问题三组结构
  - 问题条
  - 事件与字段来源条
  - 核心回答区
  - 下一步动作条
  - 金融限制提醒条

## 三、本轮最小通过条件

- 满足以下五项即可停：
  1. 推荐问题按 `解释补充组 / 记录复盘组 / 下一步关注组` 展示
  2. 当前选中问题能明确显示所属问题组
  3. 问答结果区能显示来源字段，而不是只给一段正文
  4. 问答结果区能明确给出下一步动作提示
  5. `test/lint/build` 全绿并补桌面端走查与 README / 冻结页回填

## 四、明确不做

- 不增加自由输入框
- 不新增更多页面跳转
- 不让 QA 页直接提交记录
- 不在本轮继续美化到视觉稿级别

## 五、停止规则

- 三组问题、五段式结果、下一步动作条跑通后立刻停。
- 下一阶段再判断是否进入更细的样式 polish，或首页返回链是否保留最近事件上下文。
