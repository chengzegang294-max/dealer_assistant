# A5 A股 P0 标的页 Batch2 补充记录入口壳页

更新时间：2026-07-22

## 一、这页用途

- 本页只做：
  - 把 `最近记录区` 从“只读展示”推进到“补充这次记录”的最小入口壳
  - 让用户在当前事件上下文里补充备注并原地回显
- 本页不做：
  - 第二套记录系统
  - 独立补充记录页面
  - 问答页本体

## 二、主负责人裁决

- 当前最值钱的一刀是把 `最近记录区` 变成真实可点的最小交互壳。
- 本轮只允许：
  - `补充这次记录` 入口
  - 当前上下文提示
  - `补充备注` 最小编辑框
  - 成功/失败最小回显

## 三、本轮最小通过条件

- 满足以下五项即可停：
  1. 仅在存在最近记录且当前事件已锁定时出现 `补充这次记录`
  2. 点击后原地展开最小编辑壳，不跳新页面
  3. 空备注提交时显示失败提示且不清空草稿
  4. 成功提交后显示最近一次补充回显
  5. `test/lint/build` 全绿并回填 README / 同步包

## 四、明确不做

- 不改原动作 / 理由标签 / 周期
- 不新增第二条独立记录
- 不把补充记录扩成复杂表单
- 不接真实端

## 五、停止规则

- 入口壳、原地提交与回显完成后立刻停。
- 下一阶段再判断是否开问答下钻占位页或更深的记录编辑态。
