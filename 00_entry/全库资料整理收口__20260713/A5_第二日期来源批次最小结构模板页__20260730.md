# A5 第二日期来源批次最小结构模板页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 冻结第二日期样本进入来源库时，
    一个新批次最小需要长什么样
  - 避免后面为了接第二日期，
    临时重写批次结构

## 二、当前最小批次结构

- 第二日期来源批次最小结构冻结为：

```text
<new_batch_root>/
  README.md
  provenance.md
  manifest_v1.tsv
  00_raw_snapshot/
    user_screenshots/
      <sample_date>__市场情绪总览.png
      <sample_date>__市场宽度涨停跌停.png
      <sample_date>__龙虎榜异动资金.png
```

## 三、三个入口文件分别干嘛

### 3.1 README.md

- 只负责说明：
  1. 这个批次是干什么的
  2. 当前吸收了哪些截图
  3. 当前支撑主线到哪一步

### 3.2 provenance.md

- 只负责说明：
  1. 临时路径来自哪里
  2. 正式去向是什么
  3. 临时副本什么时候可以删

### 3.3 manifest_v1.tsv

- 只负责说明：
  1. 每个文件的相对路径
  2. 材料类型
  3. sample_date
  4. 当前状态
  5. source_note

## 四、当前为什么先只收 3 张图

- 因为第二日期当前最小目标，
  不是一上来就补全所有对象；
  而是先通过：
  - 新日期存在
  - 单输入包验收
  - 两日期门槛重跑

- 所以先只收：
  1. `市场情绪总览`
  2. `市场宽度涨停跌停`
  3. `龙虎榜异动资金`

## 五、主负责人裁决

- 当前正式裁决为：
  1. 第二日期一旦到位，
     优先先立一个最小来源批次
  2. 批次最小结构当前只收：
     - README
     - provenance
     - manifest
     - 3 张必需截图
  3. 其他增强页后补，
     不阻塞当前接入

## 六、一句话口径

- 第二日期当前先立最小来源批次，
  不求全，
  只求能最快接入现有验收链。
