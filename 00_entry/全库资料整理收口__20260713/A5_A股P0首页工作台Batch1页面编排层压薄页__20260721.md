# A5 A股 P0 首页工作台 Batch1 页面编排层压薄页

更新时间：2026-07-21

## 一、这页用途

- 本页只做：
  - 冻结 `A股 P0 Batch1` 当前对首页页面编排层继续压薄的口径
  - 说明为什么当前最值钱的一步不是再拆展示组件，而是把页面级组装继续收口到明确入口
  - 写死本轮允许下沉与不允许扩展的边界
- 本页不做：
  - 重开产品方向
  - 重开字段合同
  - 新增 UI 功能
  - 扩展到标的页或问答页

## 二、当前主线与当前不是

- 当前主线：
  - `A股 P0 Batch1` 首页工作台实现线
- 当前不是：
  - `batch_149` 新吸收线
  - 新功能扩线
  - 多市场或技术栈讨论

## 三、为什么这一手最值钱

- 到当前为止：
  - `workspaceModel`
  - `useHomeWorkspace`
  - adapter 分层
  - 首页级 view model 汇总入口
  都已经形成。
- 但 `Home.tsx` 里仍然残留：
  - workspace 数据解包
  - finance disclosure 页面动作
  - 页面级 props 转发
- 这意味着页面层虽然变薄了，但还没有完全收成“纯页面壳”。
- 因此当前最值钱的一步是把页面级组装再收成一个 hook，让：
  - 页面只负责布局
  - hook 负责页面级数据与动作装配

## 四、本轮允许继续下沉的范围

- 允许继续下沉：
  - `Home.tsx` 中的页面级组装
  - finance disclosure 页面动作
  - 首页级 props 打包
- 允许新增：
  - 页面级 hook
  - 只服务首页壳的轻量页面装配结构
- 不允许借机扩展：
  - 新状态字段
  - 新业务逻辑
  - 新功能入口
  - 新页面跳转协议

## 五、当前目标边界

- `Home.tsx`
  - 只保留页面布局与三栏编排
- 页面级 hook
  - 负责消费 `useHomeWorkspace`
  - 负责生成首页所需 view model
  - 负责页面级 UI 动作
- `useHomeWorkspace`
  - 继续只管首页状态机与不变量
- adapter
  - 继续只做展示字段适配

## 六、本轮停止规则

- 满足以下四项即可视为这一小段收口：
  1. `Home.tsx` 不再直接持有页面级装配细节
  2. 页面级动作已收入独立 hook
  3. `npm run build` 通过
  4. `npm run lint` 通过
