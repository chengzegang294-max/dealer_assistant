# A5 A股 P0 标的页 Batch2 首页无效 eventId 降级页

更新时间：2026-07-23

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 首页恢复链最后一个硬缺口压到 `无效/空 eventId` 的显式降级口径
  - 让首页在 `query 恢复失败` 时不再静默 `return`
- 本页不做：
  - 新全局状态容器
  - localStorage / sessionStorage
  - 草稿恢复
  - 浏览器返回栈增强

## 二、主负责人裁决

- 当前最值钱的一刀不是继续 polish，而是把“恢复失败时怎么办”从隐式行为改成显式口径。
- 本轮只允许补：
  - `/?eventId=` 时回到首页默认空态并给出提示
  - `/?eventId=<unknown>` 时回到首页默认空态并给出提示
  - `/?eventId=<valid>` 时继续恢复对应事件工作区
  - 用户重新选择事件后，首页继续按正常工作区流转

## 三、本轮最小通过条件

- 满足以下四项即可停：
  1. 空 `eventId` 时首页保留默认空态
  2. 不存在的 `eventId` 时首页保留默认空态
  3. 上述两种场景都会给出轻提示，而不是静默失败
  4. `test/lint/build` 全绿并补真实走查与入口回填

## 四、明确不做

- 不自动修正 URL
- 不把非法 `eventId` 重写成首条事件
- 不恢复未提交表单
- 不新增持久化最近事件列表

## 五、停止规则

- 只把 `无效/空 eventId` 的降级行为做成真实可复验闭环；通过后立刻冻结 `Batch2` 前台线。
