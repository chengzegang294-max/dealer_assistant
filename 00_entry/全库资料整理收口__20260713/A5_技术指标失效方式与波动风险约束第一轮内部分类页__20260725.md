# A5 技术指标失效方式与波动风险约束第一轮内部分类页

更新时间：2026-07-25

## 一、这页用途

- 本页只做：
  - 把当前门槛卡住的最小缺口正式补出来
  - 把
    `失效方式`
    和
    `波动风险约束`
    从抽象话压成第一轮可复用分类
- 本页不做：
  - 参数化止损
  - 金融有效性证明
  - 交易门禁升级

## 二、这页为什么现在必须补

- 当前多AI回包已经明确：
  - 当前不能直接进入下一步
- 当前最强共识不是：
  - 再补指标名字
  - 立刻抓外部体系
- 当前最强共识是：
  - `失效方式 / 退出判据 / 波动风险约束语言`
    仍不够稳定

## 三、当前统一分类框架

- 第一轮先把失效方式固定成
  `5`
  类：
  1. `结构破坏型`
  2. `强度衰减型`
  3. `波动失控型`
  4. `事件退潮型`
  5. `背景背离型`

- 第一轮先把处理动作固定成
  `4`
  类：
  1. `直接退出`
  2. `先降权`
  3. `先降级职责`
  4. `回观察位`

## 四、五类失效方式怎么理解

## 4.1 结构破坏型

- 含义：
  - 原本成立这次判断的核心前提，
    已经被打掉
- 典型表现：
  1. 关键结构快速回收
  2. 原本顺风背景明显反转
  3. 触发后的延续条件不再存在
- 默认处理：
  - `直接退出`

- 一句标准话术：
  - `原来的前提已经不在了，这不是弱一点，而是逻辑失效。`

## 4.2 强度衰减型

- 含义：
  - 逻辑还没完全坏，
    但已经不配原来的力度
- 典型表现：
  1. 量能 / 活跃度开始掉
  2. 推进速度明显变慢
  3. 联动与确认开始减弱
- 默认处理：
  - `先降权`

- 一句标准话术：
  - `逻辑未坏，但当前不该继续按原力度处理。`

## 4.3 波动失控型

- 含义：
  - 不是判断方向已经错，
    而是当前波动压强过大，
    信号质量明显恶化
- 典型表现：
  1. 高波动乱跳
  2. 事件噪音快速放大
  3. 短时间来回穿越关键判断边界
- 默认处理：
  - `先降权`
  - 若信号污染严重，
    则
    `回观察位`

- 一句标准话术：
  - `不是先判断对错，而是先承认当前噪音已经高到不该按原方式参与。`

## 4.4 事件退潮型

- 含义：
  - 事件驱动所带来的强度与叙事支撑，
    已经明显退潮
- 典型表现：
  1. 事件热度消退
  2. 异动标签失去延续
  3. 原本只能在事件窗口成立的信号开始失灵
- 默认处理：
  - `先降级职责`
  - 从
    `触发层`
    退回
    `过滤层`
    或
    `背景说明`

- 一句标准话术：
  - `事件还留着影子，但已经不配继续当动作触发器。`

## 4.5 背景背离型

- 含义：
  - 标的信号还在，
    但支撑它的行业 / 指数 / 宽度背景开始背离
- 典型表现：
  1. 行业共振消失
  2. 指数顺风切逆风
  3. 宽度热度收缩，
     背景不再支持加权
- 默认处理：
  - `先降级职责`
  - 或
    `回观察位`

- 一句标准话术：
  - `局部信号还亮着，但背景已经不再给它同样的解释权重。`

## 五、四类处理动作的边界

| 动作 | 何时优先触发 | 当前不应误用成什么 |
| --- | --- | --- |
| `直接退出` | 已出现 `结构破坏型` | 不要把普通波动直接升级成退出 |
| `先降权` | 更像 `强度衰减型` 或 `波动失控型` | 不要把降权误写成逻辑已坏 |
| `先降级职责` | 更像 `事件退潮型` 或 `背景背离型` | 不要把职责降级误写成彻底失效 |
| `回观察位` | 信号污染严重、方向与触发打架 | 不要把观察位误写成轻仓试错默认位 |

## 六、风险约束语言模板

- 当前第一轮统一只保留这些可复用短句：
  1. `逻辑失效，直接退出。`
  2. `逻辑未坏，但当前先降权。`
  3. `当前先退一层职责，不再继续当触发依据。`
  4. `当前噪音过大，先回观察位。`
  5. `背景不再支持原解释权重。`

## 七、五条代表指标的第一轮映射锚点

| 代表指标 | 更像先关注哪类失效 | 当前更像先接哪类处理 |
| --- | --- | --- |
| `沪深涨跌停` | `背景背离型`、`强度衰减型` | `先降级职责 / 回观察位` |
| `打板资金` | `波动失控型`、`事件退潮型` | `先降权 / 先降级职责` |
| `上榜资金` | `事件退潮型`、`强度衰减型` | `先降级职责 / 先降权` |
| `HYDB行业对比` | `背景背离型`、`结构破坏型` | `先降级职责 / 直接退出` |
| `ZSDB指数对比` | `背景背离型`、`波动失控型` | `先降权 / 回观察位` |
