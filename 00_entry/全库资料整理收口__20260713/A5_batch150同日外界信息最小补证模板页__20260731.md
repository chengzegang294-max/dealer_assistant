# A5 batch150同日外界信息最小补证模板页

更新时间：2026-07-31

## 一、这页用途

- 本页只做：
  1. 给 `batch150`
     的同日外界信息补证提供一个最小模板
  2. 让后续一旦拿到
     `2026-07-29`
     同日 raw，
     可以直接按模板吸收

## 二、这页属于哪条线

- 文件类型：`REPO_GLOBAL`
- 推荐落点：`00_entry\全库资料整理收口__20260713\`
- 原因：
  - 这是当前第三手补证需求对应的最小执行模板
- 是否允许放根目录：`no`
- 是否需要后续迁移：`no`

## 三、当前适用范围

- 当前模板只适用于：
  - `batch150`
  - `sample_date = 2026-07-29`
  - `信息直播间`
    这类外界信息旁证

- 当前不直接用于：
  - `金十`
  - `Tushare`
  - `quicktiny`

## 四、最小字段模板

```text
sample_date   = 2026-07-29
source_anchor = 平台 / 栏目 / 说话人或主题
topic_anchor  = 这段信息主要在解释什么
linked_object = 市场情绪总览 | 上榜资金 | 题材中心
raw_type      = screenshot | excerpt | replay_link
raw_evidence  = 文件名 / 摘录片段 / 回放链接+时间点
role_layer    = 解释层旁证
hard_linkable = yes | no
note          = 仅作解释层旁证，不作为真值字段
```

## 五、三种可直接套用的模板

### 5.1 截图型

```text
sample_date   = 2026-07-29
source_anchor = 信息直播间 / 某栏目 / 某主题
topic_anchor  = 盘面总览或板块轮动
linked_object = 市场情绪总览
raw_type      = screenshot
raw_evidence  = 2026-07-29__xxx.png
role_layer    = 解释层旁证
hard_linkable = yes
note          = 该来源仅作为市场情绪总览的解释层旁证，不作为真值字段
```

### 5.2 摘录型

```text
sample_date   = 2026-07-29
source_anchor = 信息直播间 / 某栏目 / 某主题
topic_anchor  = 龙虎榜异动解释
linked_object = 上榜资金
raw_type      = excerpt
raw_evidence  = 摘录正文 + 来源说明
role_layer    = 解释层旁证
hard_linkable = yes
note          = 该来源仅作为上榜资金的解释层旁证，不作为真值字段
```

### 5.3 回放节点型

```text
sample_date   = 2026-07-29
source_anchor = 信息直播间 / 某场回放 / 某主题
topic_anchor  = 主线题材或情绪变化
linked_object = 题材中心
raw_type      = replay_link
raw_evidence  = 回放链接 + 关键时间点
role_layer    = 解释层旁证
hard_linkable = yes
note          = 该来源仅作为题材中心候选背景的解释层旁证，不作为真值字段
```

## 六、当前必须满足的通过条件

- 只有同时满足以下条件，
  当前才允许写成
  `hard_linkable = yes`
  ：

1. 日期明确是
   `2026-07-29`
2. 来源栏目能写清
3. 主题语义能写清
4. 能明确链接到
   `市场情绪总览 / 上榜资金 / 题材中心`
   三者之一

## 七、当前必须拦截的情况

- 当前只要出现以下任一情况，
  就不能写成同日硬回链：

1. 日期不是
   `2026-07-29`
2. 只有零散图片，
   没有来源锚点
3. 主题完全说不清
4. 只能模糊地说
   `可能跟市场有关`

## 八、一句话口径

- 这张模板页的作用，就是让 `batch150` 同日外界信息补证一旦到手，就能立刻按统一格式吸收，不再临场重编字段。
