# A5 runtime 对接边界页

更新时间：2026-07-15

## 用途

- 把 `A5` 当前哪些内容只停在合同层，哪些已具备 formalize 条件，哪些绝不能误写成 runtime 已支持，一次钉死。
- 这页不是实现计划。
- 这页只做边界裁决。

## 当前结论

- `A5` 当前已经到：
  - `对象卡草案层`
- `A5` 当前还没到：
  - `runtime ready`
- 当前最容易误写的不是输入字段，而是：
  - 把 `proxy / future_only / sample_only_with_provenance`
    误写成 runtime 已可直接消费

## 一、可以视为“formalizable_now”的部分

### 财务与估值解释层

- 可直接 formalize 的主要是：
  - 三大报表输入
  - 价格/估值输入
  - `PE / PB / PS`
  - `ROE / 资产负债率`
  - `营收增长率 / 净利润增长率`
  - `经营现金流净额`

### 组合政策输入

- 可直接 formalize 的主要是：
  - `benchmark_id`
  - `tracking_error_limit`
  - `turnover_limit`
  - `weight_lower_bound`
  - `weight_upper_bound`
  - `long_only_flag`
  - `rebalance_frequency`
  - `rebalance_trigger`
  - `current_weight`

## 二、只能保留 proxy 的部分

- 当前应明确保留为 `proxy` 的：
  - `alpha_score`
  - `active_risk_aversion`
  - `transaction_cost_bps`
  - `kelly_size_scalar`
  - `vt_size_scalar`
  - `pq_position_max_size`

### 原因

- 这些字段当前不是没有定义。
- 而是：
  - 来源尚未闭合成单一正式源
  - 当前仍依赖策略口径、默认参数或既有合同

## 三、只能保留 rules_engine_derivable 的部分

- 当前应明确保留为 `rules_engine_derivable` 的：
  - `cashflow_ocf_to_net_profit`
  - `valuation_factor_confidence`
  - `final_size_scalar`
  - `adjusted_position_weight`
  - `degrade_flags`
  - `abort_reason`

### 原因

- 这些字段不是原始输入，也不是独立真实源字段。
- 它们依赖现有合同、规则或融合逻辑派生。

## 四、当前必须保留 future_only 的部分

- 当前必须写成 `future_only` 或 `not_formalizable_yet` 的：
  - `covariance_model_id`
  - `target_weight`
  - `portfolio_expected_active_return`
  - `portfolio_tracking_error`
  - `minute_data_runtime_status`
  - `level2_runtime_status`

### 原因

- 当前不是完全没讨论这些字段。
- 而是：
  - 还没有正式协方差模型
  - 还没有优化器输出链
  - 分钟级 formal raw 尚未统一入 catalog
  - Level-2 仍是 `future_only`

## 五、禁止误写

- 禁止写成：
  - `A5 已 runtime ready`
  - `A5 已有正式 target_weight 输出`
  - `A5 已闭合 minute / level2`
  - `A5 已有正式 alpha / covariance 主源`

- 当前只允许写成：
  - `A5 已到合同层对象卡草案`
  - `A5 有一部分字段 formalizable_now`
  - `A5 仍有一部分字段只能 proxy / rules_engine_derivable / future_only`

## 六、主负责人裁决

- `A5` 当前已经足够继续做：
  - 正式化裁决
  - 样本实例卡
  - 未来对象卡模板
- `A5` 当前还不允许直接做：
  - runtime 实现承诺
  - 优化器承诺
  - 分钟与 Level-2 主路线承诺

## 七、一句话口径

- 现在 `A5` 的正确写法是：
  - `contract_layer_ready_with_mixed_source_status`
- 不是：
  - `runtime_ready`
