# A_REQ_002 对象卡验收例

更新时间：2026-07-15

## 用途

- 这份验收例只服务 `A_REQ_002`：
  - 把“财报与估值可解释”从概念层推进到“最小对象卡验收口径”
- 它不是 runtime 实现文件。
- 它是当前阶段的：
  - 最小样本合同
  - 最小断言集合
  - 最小降级规则

## 对象卡标识

- `object_card`:
  - `A_REQ_002_P0_A`
- `feature`:
  - `valuation_factor_framework`

## 最小输入样本

- `1` 个 A股标的
- `1` 份最新已披露年报或足够构造 TTM 的财报快照
- `1` 份价格快照
- `1` 个行业分类标签

## 最小输入字段

- 三大报表：
  - `revenue_current`
  - `revenue_prior`
  - `net_profit_current`
  - `net_profit_prior`
  - `shareholders_equity_current`
  - `shareholders_equity_prior`
  - `total_assets`
  - `total_liabilities`
  - `operating_cashflow_net`
- 估值输入：
  - `price_per_share`
  - `market_cap`
  - `eps_ttm`
  - `revenue_ttm`
  - `book_value_per_share` 或 `net_asset`
- 元数据：
  - `industry_name`
  - `report_date`
  - `price_date`

## 验收输出字段

- 必须至少输出：
  - `value_pe_ttm`
  - `value_pb_lf`
  - `value_ps_ttm`
  - `quality_roe_avg`
  - `quality_debt_to_asset`
  - `growth_revenue_yoy`
  - `growth_net_profit_yoy`
  - `cashflow_operating_cf_net`
  - `cashflow_ocf_to_net_profit`
  - `valuation_factor_confidence`

## 关键断言

- 断言 1：
  - 输出必须覆盖 `value / quality / growth / cashflow` 四个因子族
- 断言 2：
  - `quality_roe_avg` 必须能从 `净利润 / 平均股东权益` 回溯
- 断言 3：
  - `growth_revenue_yoy` 与 `growth_net_profit_yoy` 必须能回溯到当前期与上期数据
- 断言 4：
  - `cashflow_ocf_to_net_profit` 若分母不可用，必须显式为 `NA`，不能伪造为 `0`
- 断言 5：
  - `valuation_factor_confidence` 必须随着核心字段缺失或降级而下降

## 最小降级规则

- 若 `eps_ttm <= 0`
  - `value_pe_ttm = NA`
  - 不阻塞其它字段计算
- 若缺 `average_shareholders_equity`
  - 允许使用期末权益替代
  - 但必须标记 `degraded`
- 若 `prior_revenue == 0` 或 `prior_net_profit == 0`
  - 对应增长率字段置为 `NA`
  - 不允许伪造无限增长
- 若 `industry_name` 缺失
  - 保留绝对字段计算
  - 禁止做行业对比解释

## 最小验收样例（示意）

```json
{
  "object_card": "A_REQ_002_P0_A",
  "sample_type": "single_a_share_report_snapshot",
  "checks": [
    {
      "field": "quality_roe_avg",
      "expected_rule": "net_profit / average_shareholders_equity",
      "passed": true
    },
    {
      "field": "growth_revenue_yoy",
      "expected_rule": "(revenue_current - revenue_prior) / revenue_prior",
      "passed": true
    },
    {
      "field": "cashflow_ocf_to_net_profit",
      "expected_rule": "operating_cashflow_net / net_profit_current",
      "passed": true
    }
  ],
  "degrade_flags": [
    "use_end_equity_if_avg_missing"
  ]
}
```
