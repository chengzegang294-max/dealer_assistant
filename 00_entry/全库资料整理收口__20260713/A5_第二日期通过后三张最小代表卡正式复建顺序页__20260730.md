# A5 第二日期通过后三张最小代表卡正式复建顺序页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 冻结第二日期样本一旦通过后，
    三张最小代表卡应该按什么顺序正式复建
  - 避免后面在
    `先做哪张卡`
    上重新打转

## 二、当前正式复建顺序

- 当前顺序冻结为：

1. `HYDB行业对比 / 沪深涨跌停 -> 上榜资金`
2. `ZSDB指数对比 / 沪深涨跌停 -> 打板资金`
3. `HYDB行业对比 / ZSDB指数对比 -> 上榜资金`

## 三、为什么先按这个顺序

- 当前先按这个顺序，
  原因是：
  1. 第一张卡最贴近
     `题材背景 -> 市场宽度 -> 上榜资金`
     的已知页面证据链
  2. 第二张卡再引入
     `打板资金`
     这个更靠动作层的对象
  3. 第三张卡才把
     `HYDB / ZSDB`
     双背景并列使用

## 四、当前每张卡的最小要求

- 三张卡当前统一最小要求冻结为：
  1. 明写 `sample_date`
  2. 明写 `source_anchor`
  3. 明写 `still_need_evidence`
  4. 禁止写成金融真值结论

## 五、当前先不做什么

- 当前正式复建三张最小代表卡时，
  先不做：
  1. 六卡矩阵扩展
  2. 金融有效性结论
  3. 收益相关结论

## 六、主负责人裁决

- 当前正式裁决为：
  1. 第二日期一旦通过，
     先按固定顺序正式复建三张最小代表卡
  2. 当前不把“多做几张”当推进，
     而是把
     `三张卡都落到正式页`
     当推进

## 七、一句话口径

  当前先按固定顺序正式落
