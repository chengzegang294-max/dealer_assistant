# A5 最小样本实例卡

更新时间：2026-07-16

## 用途

- 用一张最小真样例，验证 `A5_最小对象卡草案` 是否已经具备可读、可回溯、可区分边界的对象卡阅读形态。
- 这张卡不是 runtime 输出截图。
- 这张卡也不是历史验证结论。
- 这张卡只服务：
  - `合同层阅读`
  - `字段回溯`
  - `proxy / rules_engine_derivable / future_only` 的边界显性化

- 样本标识：
  - `A5_P0_AR_SAMPLE_MIN_20260716`
- 样本类型：
  - `contract_reading_sample`
- 阅读口径：
  - `解释层可读`
  - `组合层部分可读`

  - 组合层仅有部分字段可 formalize

## 二、字段回溯计算

| 字段 | 计算规则 | 样本结果 | 状态 |
|---|---|---|---|
| `value_pe_ttm` | `price_per_share / eps_ttm` | `18.0 / 1.5 = 12.0` | `direct` |
| `value_pb_lf` | `price_per_share / book_value_per_share_or_net_asset` | `18.0 / 9.0 = 2.0` | `direct` |
| `value_ps_ttm` | `market_cap / revenue_ttm` | `18000.0 / 6000.0 = 3.0` | `direct` |
| `quality_roe_avg` | `net_profit_current / ((equity_current + equity_prior) / 2)` | `180.0 / 800.0 = 0.225` | `direct` |
| `quality_debt_to_asset` | `total_liabilities / total_assets` | `900.0 / 2000.0 = 0.45` | `direct` |
| `growth_revenue_yoy` | `(revenue_current - revenue_prior) / revenue_prior` | `(1200.0 - 1000.0) / 1000.0 = 0.20` | `direct` |
| `growth_net_profit_yoy` | `(net_profit_current - net_profit_prior) / net_profit_prior` | `(180.0 - 150.0) / 150.0 = 0.20` | `direct` |
| `cashflow_ocf_to_net_profit` | `operating_cashflow_net / net_profit_current` | `210.0 / 180.0 = 1.1667` | `rules_engine_derivable` |
| `final_size_scalar` | `min(kelly, vt, pq, 1.0)` | `min(0.80, 0.60, 0.50, 1.0) = 0.50` | `rules_engine_derivable` |
