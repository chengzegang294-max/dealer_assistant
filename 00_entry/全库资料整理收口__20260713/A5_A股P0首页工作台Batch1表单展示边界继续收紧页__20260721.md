# A5 A股 P0 首页工作台 Batch1 表单展示边界继续收紧页

更新时间：2026-07-21

## 一、这页用途

- 本页只做：
  - 冻结 `A股 P0 Batch1` 首页工作台在当前阶段对 `DecisionRecordForm` 的继续收紧口径
  - 说明为什么当前最值钱的一步是把表单展示文案与选项说明继续抽离
  - 写死这一轮允许下沉与不允许扩展的边界
- 本页不做：
  - 重开产品方向
  - 重开事件字段合同
  - 重开 `FV gate`、第四窗、新 evidence type、多市场、本地 AI 技术栈

## 二、当前主线与当前不是

- 当前主线：
  - `A股 P0 Batch1` 首页工作台实现线
- 当前不是：
  - `batch_149` 新吸收线
  - 任何 runtime / 回测 / 外部验证线
  - 多市场与技术栈讨论

## 三、为什么这一手最值钱

- 到当前为止：
  - `EventStreamPanel`
  - `HomeSidebar`
  - `HomeHero`
  - `StockSearchBar`
  - `SelectedEventSummaryCard`
  - `ExplanationCard`
  已开始优先接收 adapter 产出的展示字段。
- 主工作区里仍然最容易把“展示口径重新揉回组件”的剩余位置，就是：
  - `DecisionRecordForm`
- 如果表单组件继续自己持有：
  - 标题文案
  - 描述文案
  - select 标签与 placeholder
  - 文本域 placeholder
  - 按钮文案
  那么后续接真数据或改展示时，页面层与组件层仍会继续混口径。

## 四、本轮允许继续下沉的范围

- 允许继续下沉：
  - `DecisionRecordForm` 的展示用文案
  - `DecisionRecordForm` 的选项显示配置
  - `draft.eventId` 的展示文案包装
- 允许保留在组件内的内容：
  - 草稿当前值
  - `onChangeDecisionDraft`
  - `onSubmitDecision`
  - `onRetrySubmitDecision`
  - `formError`
- 不允许借机扩展：
  - 新表单字段
  - 新提交逻辑
  - 新状态机
  - 新数据协议

## 五、当前收紧后的目标边界

- 页面编排层：
  - 生成 `DecisionRecordFormViewModel`
- 表单组件：
  - 只消费草稿值、回调和 view model
- 状态逻辑层：
  - 继续停留在 `useHomeWorkspace` 与 `workspaceModel`
- 不变量仍然只锁在：
  - 切事件时强制重置 `homeRecordDraft`
  - 切事件时清空 `latestSubmitEcho`

## 六、本轮停止规则

- 满足以下四项即可视为这一小段收口：
  1. `DecisionRecordForm` 的大部分固定展示文案已先经 adapter
  2. `README` 已回填
  3. `npm run build` 通过
  4. `npm run lint` 通过

## 七、下一手

- 再回填 `README` 与 `Cursor 同步包`
