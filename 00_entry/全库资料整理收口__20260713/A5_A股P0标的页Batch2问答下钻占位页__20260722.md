# A5 A股 P0 标的页 Batch2 问答下钻占位页

更新时间：2026-07-22

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 的问答下钻从“入口占位”推进到“可进入的占位页”
  - 接通 `标的页 -> 问答页 -> 回到标的页` 最小返回链
- 本页不做：
  - 真实大模型问答
  - 自由输入长聊
  - 问答答案样式层深挖

## 二、主负责人裁决

- 当前最值钱的一刀不是继续加深记录系统，而是把 `问答下钻` 变成真实可进入的占位页。
- 本轮只允许：
  - 上下文条
  - 推荐问题区
  - 五段式占位回答
  - 回到标的页入口

## 三、本轮最小通过条件

- 满足以下五项即可停：
  1. 标的页 `问答下钻` 可进入独立路由页
  2. 问答页显示当前标的、当前事件、`still_need_evidence`
  3. 问答页展示推荐问题，点击后切换占位回答
  4. 可返回原标的页，保留 `stockCode + selectedEventId`
  5. `test/lint/build` 全绿并回填 README / 同步包 / 冻结页

## 四、明确不做

- 不接真实 AI
- 不输出目标价/买卖建议
- 不脱离当前事件扩写新事实
- 不开自由输入问答框

## 五、停止规则

- 占位页、返回链、推荐问题切换跑通后立刻停。
- 下一阶段再判断是否进入问答答案样式层或真实问答接线。
