# A5 A股 P0 技术指标产品层组合可行性第一轮 首页市场宽度最小实现页

更新时间：2026-07-24

## 一、这页用途

- 本页只做：
  - 冻结首页侧
    `市场宽度`
    的最小实现边界
- 本页不做：
  - 首页新增独立卡片
  - 首页多组并列入口
  - 首页按组重排

## 二、当前主线

- 当前主线是：
  - `A股 P0 技术指标产品层组合可行性第一轮`
- 当前不是：
  - 金融真值层
  - 组合回测
  - 首页重做

## 三、当前最值钱的一步

- 当前最值钱的一步是：
  - 把首页现有
    `市场摘要`
    正式收成
    `市场宽度`
    轻背景说明
- 只服务：
  - 首页唯一主轴：
    `今日事件流`

## 四、当前正式裁决

- 首页当前只允许：
  - `市场宽度`
    进入现有状态卡
- 首页当前不允许：
  - `资金活跃`
    独立主组
  - `行业 / 指数参照`
    独立主组
  - 多组并列

## 五、实现合同

- 当前只改：
  - 首页 hero 区当前第一张状态卡
- 当前输出统一为：
  - 标题：
    `市场宽度`
  - 值：
    `marketSummary`
  - hint：
    `市场宽度语义组（沪深涨跌停），只做首页轻背景说明`

## 六、停止规则

- 当前做到以下条件后立刻停：
  1. 首页状态卡标题改为
     `市场宽度`
  2. hint
     明确写出：
     - 语义组
     - 成员
     - 轻背景说明
  3. 页面层至少有一条断言
     能证明：
     - 首页 hero 区确实渲染出
       `市场宽度`
       与对应 hint
  4. 首页页面层进一步证明：
     - hero 的
       `市场宽度`
       与主工作区 explanation card 的
       `当前优先回链`
       可同时成立，不互相抢位
  5. 首页
     `市场宽度`
     的标题与 hint
     不再由首页 adapter 单独维护拼接，
     而是回收到共享语义组层
  6. 测试与 build 通过
