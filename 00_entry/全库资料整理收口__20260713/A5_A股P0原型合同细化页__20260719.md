# A5 A股 P0 原型合同细化页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把现有
    `A股 P0`
    功能合同、
    原型线框、
    审阅清单
    和
    条件式门禁
    收成一份当前可直接消费的
    原型合同细化页
- 本页不做：
  - 前端实现
  - 新 runtime
  - 新证据类型
  - 多市场扩展

## 二、当前上位约束

- 当前项目终局是：
  - `可解释投资决策辅助驾驶舱`
- 用户感知层更接近：
  - `私人投资管家`
- 当前
  `A股 P0`
  最小闭环是：
  - `提醒 -> 解释 -> 记录 -> 回看`
- 当前原型阶段已冻结为：
  - `条件式门禁`
- 当前必须同时满足：
  - 允许进入
    `A股 P0`
    最小原型闭环
  - 不得把当前金融限制包装成：
    - 已可信投资系统

## 三、当前原型的唯一目标

- 当前原型的唯一目标不是：
  - 做全功能交易终端
  - 证明系统已稳定跑赢基准
  - 一次性接通所有市场和数据源
- 当前原型的唯一目标是：
  - 把
    `提醒 -> 解释 -> 记录 -> 回看`
    跑成一条可审阅、可走查、可继续实现的单轴闭环

## 四、当前原型的唯一主路径

- 当前唯一主路径固定为：
  - `事件流 -> 解释卡 -> 决策记录 -> 回看`
- 当前不允许把主路径改写成：
  - K 线先行
  - 新闻流先行
  - 自由问答先行
  - 多页面管理后台先行

## 五、当前原型对象

### 5.1 事件对象

- 当前事件对象只围绕
  `A股 P0`
  已冻结的
  `6`
  类事件：
  - 指数关键位突破/破位
  - 个股或持仓标的量价异常
  - 业绩预告/快报显著超预期或低于预期
  - 资金异动
  - 行业/板块异常轮动
  - 市场情绪极值
- 当前事件对象最小展示字段应包括：
  - `事件标题`
  - `触发对象`
  - `触发时间`
  - `与持仓关系标签`
  - `已处理/未处理状态`

### 5.2 解释卡对象

- 当前解释卡默认
  `5`
  字段固定为：
  - `事件标题`
  - `触发对象`
  - `触发时间`
  - `触发逻辑`
  - `影响推演`
- 当前展开后
  `2`
  字段固定为：
  - `历史类比`
  - `下一次复查点`
- 当前解释卡文案必须遵守：
  - 回顾性表达
  - 非承诺式表达
  - 不写目标价
  - 不写必然涨跌
  - 不写长文研报

### 5.3 决策记录对象

- 当前决策记录必填字段固定为：
  - `关联事件ID`
  - `动作`
  - `理由标签`
  - `预期周期`
- 当前可选字段为：
  - `备注`
- 当前动作词表固定为：
  - `忽略`
  - `观察`
  - `加仓`
  - `减仓`
  - `调仓`
- 当前理由标签固定为：
  - `趋势`
  - `基本面`
  - `资金`
  - `情绪`
  - `风控`
  - `事件催化`
  - `其他`

### 5.4 回看对象

- 当前回看对象不做新系统台账，
  只做：
  - 最近决策摘要
  - 历史记录追踪入口
- 当前回看对象不允许抢主工作区，
  只作为：
  - 底部折叠区
  - 次级区
  - 或移动端次级 Tab

## 六、当前页面级合同

### 6.1 首页角色

- 当前首页不是：
  - 行情大屏
  - 资料仓入口
  - 自由问答总门户
- 当前首页角色是：
  - 事件驱动的最小工作台

### 6.2 主轴

- 当前首页绝对主轴固定为：
  - `今日事件流`
- 当前解释卡与决策记录
  必须共用同一主工作区
- 当前历史回看只能是：
  - 回看层
  - 不是第二主轴

### 6.3 搜索入口

- 当前允许：
  - 首页提供标的搜索入口
- 但当前搜索结果进入后，
  仍应回到：
  - 事件
  - 解释
  - 记录
  这条主路径
- 当前不允许把搜索做成：
  - 纯股票百科页
  - 纯数据终端页

### 6.4 问答入口

- 当前允许：
  - 问答下钻增强
- 但当前问答只应服务于：
  - 解释补充
  - 字段释义
  - 回看复盘
- 当前不允许把问答变成：
  - 首页主界面
  - 无约束长文解释器
