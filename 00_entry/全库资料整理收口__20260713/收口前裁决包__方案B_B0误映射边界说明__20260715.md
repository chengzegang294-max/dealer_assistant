# 收口前裁决包 方案B B0误映射边界说明

更新时间：2026-07-15

## 用途

- 这份说明页只负责固定 `B0` 的桥接说明 3：
  - `N01 / N02 / CHZL_BSD` 哪些内容已经足够进入 `方案B`
  - 哪些内容仍然只能作为边界说明存在
  - 哪些写法一旦提前冒充已齐，就会在后续合同映射里造成返工

## 当前统一原则

- 当前允许进入 `方案B` 的，是：
  - 已被收成 `bridge field / formal bridge / validation-grade input` 的最小输入
- 当前不允许提前冒充的，是：
  - 完整源码真值
  - 完整教材原始图版真值
  - 完整结构真值或完整自动结构引擎完成

## 一、N01 误映射边界

### 当前已经够用的部分

- 可进入 `方案B` 的最小桥接位：
  - `n01_current_regime`
- 当前已经有：
  - `atr_ratio`
  - `regime` 阈值
  - `COMPRESSION / EXPANSION / HIGH VOLATILITY / EXHAUSTION`
  - 更长连续源码窗口
  - `AGPro` invite-only / `Source code disabled` 访问边界说明

### 当前不能提前冒充的部分

- 不能写成：
  - `AG Pro` 完整 Pine 正文已拿到
- 不能写成：
  - 参数截图级真值已齐
- 不能写成：
  - `AG Pro` 精确公式上下游联动已完整固定

### 误映射风险

- 若把当前 `N01` 直接当成完整生产合同字段源：
  - 后续会把 `GainzAlgo` 连续源码窗口与 `AG Pro` invite-only 页面限制混成“同等硬度”
- 若把 `AG Pro` 的参数默认值与 family 级页面说明直接冒充成完整核心计算公式：
  - 后续合同层会错误高估 `AG Pro` 的可直接实现性

### 当前允许的降级口径

- 当前允许写成：
  - `源码逻辑层近硬证据`
  - `可提供波动环境解释层桥接字段`
- 当前必须保留：
  - `needs_more_formula_context`
  - `invite_only_access_boundary`

## 二、N02 误映射边界

### 当前已经够用的部分

- 可进入 `方案B` 的最小桥接位：
  - `n02_ib_accept_2period`
- 当前已经有：
  - `ib_high / ib_low / ib_range`
  - `IB = A + B`
  - `two 30 minute periods`
  - `2+ time periods outside IB`
  - 教材图例包
  - `CBOT handbook` 与教材扫描页级入口

### 当前不能提前冒充的部分

- 不能写成：
  - 原始 `Market Profile` 教材扫描图版已完整齐备
- 不能写成：
  - 原始源码实现层证据已齐
- 不能写成：
  - `N02` 已具备完整生产级图表定义与实现说明

### 误映射风险

- 若把 glossary / 教学图例 / 扫描页入口直接等同于“原始教材全图版”：
  - 后续会在图示级合同里误判证据强度
- 若把结构化最小公式页直接等同于源码层：
  - 后续会把解释层桥接误写成实现层真值

### 当前允许的降级口径

- 当前允许写成：
  - `definition/chart-caption/scan-entry evidence ready`
  - `可提供 IB acceptance 桥接字段`
- 当前必须保留：
  - `chart_source_not_fully_hardened`
  - `source_code_hard_evidence_missing`

## 三、CHZL_BSD 误映射边界

### 当前已经够用的部分

- 可进入 `方案B` 的最小输入定位：
  - `semi_auto validation-grade input`
- 当前已经有：
  - `daily + weekly + auto_series + seed`
  - `semi_auto output`
  - `acceptance flags`
  - 更强校验记录页

### 当前不能提前冒充的部分

- 不能写成：
  - 完整结构真值已齐
- 不能写成：
  - 完整自动结构引擎已完成
- 不能写成：
  - 已无需人工 seed 依赖

### 误映射风险

- 若把当前 `semi_auto seed bound + stub validated` 直接写成“结构真值已闭合”：
  - 后续会错误高估样本结构链的自动化成熟度
- 若忽略 `degraded = true`：
  - 后续会把降级链路误当成标准链路

### 当前允许的降级口径

- 当前允许写成：
  - `semi_auto seed bound + stub validated + acceptance flags fixed`
  - `validation-grade input`
- 当前必须保留：
  - `degraded = true`
  - `manual_seed_dependency_not_yet_cleared`

## 当前统一禁止误写清单

- 不允许写：
  - `N01 / N02 / CHZL_BSD` 已满分收口
- 不允许写：
  - `N01` 已完整源码可实现
- 不允许写：
  - `N02` 已完整教材/源码双硬证据闭合
- 不允许写：
  - `CHZL_BSD` 已完整结构真值自动化就绪

## 当前结论

- `B0` 的桥接说明 3 已可正式落盘。
- 当前最准确的统一口径是：
  - `N01 / N02 / CHZL_BSD` 均已达到可进入方案B的最小输入强度`
  - `但各自仍保留一层不能被提前冒充已齐的误映射边界`
- 这意味着：
  - 当前已具备从 `B0过渡切入` 推进到 `方案B正式生效` 的条件
  - 且不需要再额外重开大范围资料线
