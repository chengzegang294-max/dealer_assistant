# A5 A股 P0 标的页 Batch2 首页返回链保留事件上下文页

更新时间：2026-07-23

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 从 `Home -> Stock -> QA -> Stock -> Home` 的返回链继续压到“回首页仍保留最近事件上下文”
- 本页不做：
  - 首页新路由层重构
  - 新全局状态容器
  - 新数据协议
  - 回首页后自动恢复表单提交历史

## 二、主负责人裁决

- 当前最值钱的一刀不是再补新页面，而是把“回首页掉回空态”的链路断点补平。
- 本轮只允许通过：
  - `query eventId`
  - `Home hook 初始化选中`
  - `Stock/QA 返回首页时带回当前 eventId`
  来保留最近事件上下文。

## 三、本轮最小通过条件

- 满足以下五项即可停：
  1. 从标的页返回首页时，URL 可带回最近一次 `eventId`
  2. 首页按 `eventId` 初始化选中事件
  3. 首页主工作区不再回到空态，而是直接显示对应事件摘要与解释区
  4. `test/lint/build` 全绿
  5. 补桌面端走查、README、同步包、冻结页回填

## 四、明确不做

- 不把首页做成长期记忆页
- 不引入 localStorage/sessionStorage
- 不恢复未提交草稿
- 不推自由返回栈管理

## 五、停止规则

- 只把最近事件上下文通过返回链带回首页；跑通并验证通过后立刻停。
- 下一阶段再判断是否继续做更细的返回体验 polish。
