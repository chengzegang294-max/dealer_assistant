# A5 经验型视频补充触发与排除页

更新时间：2026-07-23

## 一、这页用途

- 本页只做：
  - 把“经验型视频 / 先进交易员实操 / 博主系统讲解”何时值得补，压成正式触发规则
  - 把何时不该补、何时只能留在 `future_only` 写死
- 本页不做：
  - 直接吸收具体某条视频
  - 把视频经验自动升成系统真值
  - 代替对象卡、字段卡、运行验证

## 二、主负责人裁决

- 经验型视频不是默认当前刀。
- 只有当它能补当前验证缺口、解释缺口、异常处理缺口时，才允许被 `Trae` 主动提出。
- 若只能提供：
  - 情绪鼓动
  - 喊单复盘
  - 模糊盘感
  - 不可拆字段的“经验之谈”
  则默认不补，最多登记为 `future_only`。

## 三、允许补入的四类触发

### 1. `验证缺口触发`

- 当前已有对象卡 / 字段桥 / 运行结果无法解释某个稳定出现的现象。
- 且该现象已经进入：
  - 技术分析验证
  - 交易动作解释
  - 失败原因归类

### 2. `动作规则触发`

- 当前体系缺的是：
  - 入场前过滤
  - 持仓中观察点
  - 退出/减仓/停手动作
  - 异常行情例外处理
- 且视频内容能被拆成：
  - 条件
  - 动作
  - 反例
  - 失败前兆

### 3. `对象映射触发`

- 视频中的核心内容可以明确落到至少一类 repo 对象：
  - 主题/情绪
  - 风控/停手
  - 盘口/行为
  - 仓位/执行
- 且能继续映射到：
  - 对象卡
  - 字段候选
  - 页面解释位
  - 验证断言

### 4. `反例补盲触发`

- 当前仓内资料偏“规则正向描述”，但缺：
  - 不该做什么
  - 哪些场景容易误判
  - 哪些形态会失真
- 若视频能稳定提供反例与失败案例，可作为补盲来源。

## 四、默认不补的五类内容

- `纯喊单 / 纯盘感 / 纯情绪表达`
- `没有时间戳、没有原始转写、无法复核原话`
- `不能映射到对象/字段/动作/异常处理`
- `与现有仓内结论高度重复，只是换一种说法`
- `会把当前主线从可验证对象重新拖回泛学习`

## 五、谁来提出

- 默认提出人是：
  - `Trae`
- 提出时必须同时写清：
  - 当前缺口是什么
  - 为什么现有仓内材料不够
  - 希望从视频里抽出什么
  - 抽完后准备挂到哪里
- 用户当然可以直接指定某条视频；
  但是否纳入正式吸收，仍按本页触发规则裁决。

## 六、提出时的最小发包格式

- 视频来源：
  - 标题 / URL / 作者 / 日期
- 当前触发类型：
  - `验证缺口 / 动作规则 / 对象映射 / 反例补盲`
- 当前明确缺什么：
  - `rule / field / action / exception / explanation`
- 预期吸收产物：
  - `raw transcript`
  - `timestamp chunks`
  - `rule-extract note`
  - `repo mapping note`
- 当前若抽不出来，落什么状态：
  - `future_only / weak_evidence / delete_after_review`

## 七、停止规则

- 若一条视频在首轮抽取后仍不能形成至少 `1` 条可复核的：
  - 规则
  - 字段候选
  - 异常处理
  - 失败前兆
  之一，则立刻停止继续深挖。
- 停止后只允许：
  - 登记为 `future_only`
  - 或直接不纳入当前主线

## 八、与当前仓库的直接口径

- 当前前台 `Batch2` 已冻结，经验型视频不再回头抢这条线。
- 当前只有进入：
  - 技术分析验证
  - 交易动作解释
  - 风控/异常归因
  才允许重新评估是否补视频。
- 视频原始材料若要吸收，必须进：
  - `10_source_library_archive/<batch>/00_raw_snapshot/`
- 不允许把 `暂时存放/` 里的视频摘录直接当正式来源。

## 九、一句话口径

- 经验型视频只有在能补“当前验证或解释缺口”且可拆成可复核规则时才值得补；否则默认不补，不让主线重新退化成泛学习。
