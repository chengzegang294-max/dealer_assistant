# A5 正式对象卡模板

更新时间：2026-07-16

## 用途

- 把 `A5` 当前已经形成的草案、来源状态、边界页和样本实例卡，进一步压成一张可复用的正式对象卡填写骨架。
- 这份模板不是实现文档。
- 这份模板也不是运行时 schema。
- 这份模板只服务：
  - 未来正式对象卡填写
  - 后续对象家族复用
  - 实现前冻结检查

## 使用原则

- 先填 `formalizable_now` 的部分。
- 再显式标注：
  - `proxy`
  - `rules_engine_derivable`
  - `future_only`
- 不允许为了“看起来完整”伪造：
  - `target_weight`
  - `portfolio_tracking_error`
  - `minute / level2` 主路线

### 填写要求

- `formalizable_now` 只填当前已能稳定定义且不依赖未来实现的字段。
- `proxy` 必须说明代理来源或默认参数口径。
- `rules_engine_derivable` 必须给出明确计算或融合规则。
- `future_only` 必须写清未闭合原因，禁止只写 `NA` 不解释。

## 六、最小断言模板

- 断言 1：
  - `quality_roe_avg` 可回溯到：
    - `net_profit / average_or_proxy_equity`
- 断言 2：
  - `growth_revenue_yoy` 可回溯到：
    - `(revenue_current - revenue_prior) / revenue_prior`
- 断言 3：
  - `cashflow_ocf_to_net_profit` 可回溯到：
    - `operating_cashflow_net / net_profit_current`
- 断言 4：
  - `final_size_scalar` 可回溯到：
    - `min(kelly_size_scalar, vt_size_scalar, pq_position_max_size, 1.0)`
- 断言 5：
  - 若 `target_weight` 未闭合：
    - 必须显式保留 `future_only`
- 断言 6：
  - 若 `adjusted_position_weight` 缺上游：
    - 不得伪造最终结果

## 七、最小降级模板

- 场景 1：
  - `eps_ttm <= 0`
  - 动作：
    - `value_pe_ttm = NA`
- 场景 2：
  - 缺平均权益
  - 动作：
    - 用期末权益代理并记 `degraded`
- 场景 3：
  - 缺 `covariance_model_id`
  - 动作：
    - 保持 `future_only` 或降为非优化器阅读口径
- 场景 4：
  - 缺 `alpha_score`
  - 动作：
    - 直接 `ABORT`

## 八、中止条件模板

- 缺 `alpha_score`
- `final_size_scalar <= 0.05`
- 关键解释字段无法回溯
- 输出被伪造成“看起来齐全”

## 十、禁止误写模板

- 禁止写成：
  - `runtime ready`
  - `target_weight 已正式可得`
  - `portfolio_tracking_error 已稳定输出`
  - `minute / level2 已纳入正式主路线`
- 当前只允许写成：
  - `合同层对象卡已整理`
  - `对象卡存在 mixed_source_status`
  - `实现前仍需冻结门槛确认`

## 十一、填写完成判定

- 通过条件 1：
  - 头部字段齐全
- 通过条件 2：
  - 来源状态四分类齐全
- 通过条件 3：
  - 最小输入/输出字段齐全
- 通过条件 4：
  - 断言、降级、中止条件齐全
- 通过条件 5：
  - 已挂接样本实例卡
- 不通过条件：
  - 把 `future_only` 偷写成已闭合
  - 把 `proxy` 写成正式主源

## 十二、主负责人裁决

- `A5` 当前最顺的不是继续补材料，而是先把“以后怎么正式写对象卡”固定下来。
- 这份模板的作用就是：
  - 让后续每一次对象卡正式化都沿同一骨架推进
  - 不再因为写法漂移把边界写穿
