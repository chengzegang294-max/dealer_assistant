## 三、三张卡字段合同

### 1. 盘前方向卡 `preopen`

先回答：

1. 今天偏强还是偏弱
2. 该盯哪些板块
3. 该盯哪些标的

| 字段 | 类型 | 来源偏好 | 谁填 |
|------|------|----------|------|
| `trade_date` | 事实 | 人工/口令 | 人工或预填 |
| `bias_preopen` | 判断 | P1 竞价 + 昨日结构 | 人工 |
| `watch_sectors` | 判断 | sector 快照 + 天梯 | 人工 |
| `watch_symbols` | 判断 | P1 + 方向房摘要 | 人工 |
| `ladder_yesterday_fact` | 事实 | 连板天梯昨日 | 可后预填 |
| `sector_snapshot_ref` | 事实 | 当日 sector 快照路径（优先 `sector_daily_snapshots`；缺则回退当日 `batch_*_daily_close__/00_raw`；仍无则写 `（无 sector 输入）`） | 可后预填 |
| `p1_auction_ref` | 事实 | 当日 P1 竞价段 | 可后预填 |
| `live_room_note` | 事实/摘要 | 方向房少量人话 | 人工 |
| `one_liner` | 判断 | 综合 | 人工 |

### 2. 盘中确认卡 `intraday`

先回答：

1. 早上判断有没有被资金继续确认
2. 观察池里谁还值得盯
3. 直播间有没有补到关键转折解释

| 字段 | 类型 | 来源偏好 | 谁填 |
|------|------|----------|------|
| `trade_date` | 事实 | 同上 | 人工或预填 |
| `confirm_10_00` | 判断 | P1 盘中跟随 | 人工 |
| `confirm_13_30` | 判断 | P1 盘中跟随 | 人工 |
| `confirm_14_30` | 判断 | 可选 | 人工 |
| `still_watch` | 判断 | 观察池收敛 | 人工 |
| `live_turn_note` | 事实/摘要 | 片段优先房 | 人工 |
| `one_liner` | 判断 | 综合 | 人工 |

说明：`intraday` 的可选 `P1` 路径提示仅保留在日文件末尾统一引用区；不纳入 `intraday` 字段合同。

### 3. 盘后复盘卡 `afterclose`

先回答：

1. 今天判断对不对
2. 真正有用的信息来自哪里
3. 哪些内容值得沉到长期库

| 字段 | 类型 | 来源偏好 | 谁填 |
|------|------|----------|------|
| `trade_date` | 事实 | 同上 | 人工或预填 |
| `judge_ok` | 判断 | 回看 | 人工 |
| `most_useful` | 判断 | 回看 | 人工 |
| `most_useless` | 判断 | 回看 | 人工 |
| `ladder_result_fact` | 事实 | 连板天梯当日/结构 | 可后预填 |
| `sector_eod_ref` | 事实 | 当日 sector 快照路径（优先 `sector_daily_snapshots`；缺则回退当日 `batch_*_daily_close__/00_raw`；仍无则写 `（无 sector 输入）`） | 可后预填 |
| `p1_day_ref` | 事实 | P1 当日日记录路径 | 可后预填 |
| `keep_to_longterm` | 判断 | 直播间短名单口径 | 人工 |
| `p1_incremental_value` | 判断 | P1 收盘回看 | 人工 |
| `one_liner` | 判断 | 综合 | 人工 |

## 五、最短日用口径

1. 有交易日时，可先只填空壳里能填的事实引用
2. 判断格跟 P1 同一纪律：一项最多一句话，没看到留空
3. C/D 降权房不进工作台主视野；直播间只引长期保留 / 片段优先短名单
