# A5 技术指标仓位层第一轮讨论页

更新时间：2026-07-25

## 一、这页用途

- 本页只做：
  - 把
    `仓位层`
    从抽象占位压成第一轮正式讨论页
  - 回答：
    - 什么情况下该加权
    - 什么情况下该降权
    - 什么情况下只观察不动作
- 本页不做：
  - 具体参数化
  - 回测
  - 交易门禁升级

## 二、当前主负责人口径

- `仓位层`
  当前回答的不是：
  - `上不上`
- 它当前回答的是：
  - `对了以后上多少`
  - `错了之前先缩多少`
  - `什么时候虽然有想法但先不动作`

## 三、第一轮最小仓位层写法

- 当前第一轮只保留三档：
  1. `加权`
  2. `降权`
  3. `只观察不动作`

## 四、什么情况下可加权

- 当前更适合加权的情况：
  1. `方向层`
     清楚
     - 例如趋势不纠缠、
       背景顺风
  2. `触发层`
     干净
     - 例如回踩确认清楚、
       突破质量较高
  3. `过滤层`
     没亮红灯
     - 例如不是假突破环境、
       不是极端失控波动
  4. 当前单子特征允许承压
     - 例如：
       `短单 / 长单`
       对应的容忍度匹配

## 五、什么情况下该降权

- 当前更适合降权的情况：
  1. `高波动`
     但还没恶化到完全不做
  2. 方向层还在，
     但触发层不够干净
  3. 事件驱动场景里，
     噪音开始放大
  4. 单子本身
     `小回撤容忍`
     或
     `低波动承受`
     较弱

- 当前一句顺口写法可固定为：
  - `方向未坏、触发发虚、波动偏大时，先降权，不急着上满。`

## 六、什么情况下只观察不动作

- 当前更适合只观察不动作的情况：
  1. `方向层`
     与
     `触发层`
     相互打架
  2. 市场进入：
     - `均线纠缠`
     - `高波动乱跳`
     - `事件噪音放大`
  3. 过滤层已经明显提示：
     - 信号质量不够
     - 假突破概率升高

- 当前一句顺口写法可固定为：
  - `有故事但没把握时，不是轻仓试错优先，而是先回观察位。`

## 七、仓位层和五条代表指标怎么先接

| 代表指标 | 当前更像给仓位层提供什么 |
| --- | --- |
| `沪深涨跌停` | 市场宽度是否支持加权或应回观察位 |
| `打板资金` | 触发强度够不够支撑更高权重 |
| `上榜资金` | 事件型活跃是否只值得轻参与 |
| `HYDB行业对比` | 行业背景是否支持维持权重 |
| `ZSDB指数对比` | 指数顺逆风是否要求降权或暂停 |

## 八、当前仓位层 still_need_evidence

- 当前继续保留
  `still_need_evidence`
  的问题有：
  1. 哪些情形应直接
     `降权`
     ，
     哪些应直接
     `回观察位`
  2. `事件驱动单`
     与
     `常规节奏单`
     的降权边界是否应明显不同
  3. `短单 / 长单`
     对仓位缩放的影响，
     当前还没冻结成统一写法

## 九、主负责人裁决

- 当前正式裁决为：
  1. 仓位层第一轮先不写成参数表
  2. 先写成：
     - `加权`
     - `降权`
     - `只观察不动作`
     三档
  3. 当前最值钱的不是算具体数值，
     而是先把
     `什么情况下升、什么情况下缩、什么情况下不做`
     写清楚

## 十、一句话口径

- 仓位层第一轮先不追求精确配比，
  先把
  `加权 / 降权 / 回观察位`
  三档逻辑写清楚，
  让它能稳定挂在
  `方向层 + 触发层 + 过滤层`
  之后。
