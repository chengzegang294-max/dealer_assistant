# A5 A股 P0 技术指标产品层第二轮角色命名与短句合同页

更新时间：2026-07-24

## 一、这页用途

- 本页只做：
  - 冻结
    `首页 / 标的页 / 问答页`
    的技术指标角色命名与短句合同
- 本页不做：
  - 新指标扩充
  - 金融真值讨论
  - 页面大改版

## 二、当前主线

- 当前主线是：
  - `A股 P0 技术指标产品层第二轮补全`
- 当前不是：
  - 技术指标金融有效性
  - 技术指标组合回测
  - 首页环境条扩张

## 三、当前最值钱的一步

- 当前最值钱的一步是：
  - 先把三页里最常出现的技术指标短标签说成同一种话，
    防止用户在
    `首页 -> 标的页 -> 问答页`
    之间切换时，
    看到的是三套命名

## 四、主负责人裁决

- 当前正式裁决：
  - 角色名只保留：
    - `技术指标语义源`
    - `背景解释`
  - 标签的
    `detail`
    只保留：
    - 指标来源名本身
- 当前不选：
  - 把事件标题塞进标签
  - 把解释短句塞进标签
  - 让同一页的标签既有角色又有长句

## 五、页面合同

### 5.1 首页

- 首页解释卡里的
  `sourceTags`
  固定为：
  - `label = 技术指标语义源 / 背景解释`
  - `detail = 当前 sourceCard`
- 首页不在标签里附带：
  - 事件标题
  - 解释长句

### 5.2 标的页

- 标的页解释区里的
  `indicatorContextTags`
  固定为：
  - `label = 技术指标语义源 / 背景解释`
  - `detail = 当前 sourceCard`
- 标的页解释标题与正文
  继续承接长句，
  标签本身不再重复长句

### 5.3 问答页

- 问答页技术指标释义组
  固定为：
  - `问题名 = <sourceCard> 这里在提示什么`
- 问答页继续允许：
  - 在答案正文里承接
    `触发逻辑 / 影响推演`
- 问答页不把长解释塞回组标题

## 六、为什么这样定

- 这样定的直接好处是：
  - 首页和标的页的标签合同完全一致
  - 长句只留在解释正文，
    不挤到标签里
  - 问答页继续保持
    `来源名 -> 提问 -> 回答`
    的最短路径

## 七、当前检查清单

- 若首页和标的页出现：
  - 一个页面写
    `背景解释`
  - 另一个页面写
    `背景解释：ZSDB指数对比`
  视为口径漂移
- 若标签里开始混入：
  - 事件标题
  - 历史类比
  - 影响推演
  视为偏离
- 若问答页把问题名改成长句标题，
  视为偏离

## 八、下一手执行物

- 当前这一页之后，
  下一手唯一应落的是：
  - `stockPageViewModel.ts`
    与对应测试
- 只做：
  - 把标的页标签命名对齐到首页
  - 不顺手改页面结构

## 九、一句话口径

- 第二轮当前先把技术指标标签合同固定为：
  - `label 只写角色`
  - `detail 只写来源名`
  长句继续留在解释正文与问答回答里，
  不让标签承担第二套表达。
