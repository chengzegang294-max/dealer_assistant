# A5 A股 P0 标的页 Batch2 最小壳页

更新时间：2026-07-22

## 一、这页用途

- 本页只做：
  - 把 `Batch2` 标的页从“合同已存在”推进到“最小页面壳已落地”
  - 接上首页搜索/解释卡中的真实跳转入口
- 本页不做：
  - 问答下钻真实页面
  - 补充记录编辑态全实现
  - 真实 endpoint / schema

## 二、主负责人裁决

- 当前最值钱的一刀不是继续磨 `Batch1`，而是把 `标的页` 真正落成最小壳，接上首页主点击流。
- 本轮只允许做：
  - 路由接入
  - 标的页五段最小壳
  - 同页切事件更新解释与记录区

## 三、本轮允许范围

- 允许新增：
  - `src/pages/Stock.tsx`
  - `src/features/stock/**`
- 允许修改：
  - `src/App.tsx`
  - `src/features/home/hooks/useHomePage.ts`
  - `README`
  - `Cursor 同步包`
- 不允许：
  - 问答页实现
  - 标的页复杂编辑态
  - 回改 `Batch1` 的 UI 合同

## 四、本轮最小通过条件

- 满足以下五项即可收口：
  1. 首页有效标的动作能跳到标的页
  2. 标的页具备五段最小壳：
     - 页头摘要区
     - 相关事件区
     - 当前解释区
     - 最近决策记录区
     - 问答下钻入口区
  3. 点击相关事件可在同页更新解释区与记录区
  4. `npm run test / npm run lint / npm run build` 全绿
  5. README 与 Cursor 同步包已回填

## 五、当前明确不做

- 不做问答页真跳转
- 不做补充记录编辑提交流
- 不补真实股票详情数据协议

## 六、停止规则

- 最小壳与跳转接通、验证全绿后立刻停。
- 下一阶段转 `Batch2` 后续块或 `Batch3` 问答下钻，不在本轮继续加深标的页内部复杂度。
