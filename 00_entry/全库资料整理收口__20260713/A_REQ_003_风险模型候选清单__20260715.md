# A_REQ_003 风险模型候选清单

更新时间：2026-07-15

## 用途

- 这份清单只回答 `A_REQ_003`：
  - 当前组合构建与风险预算，应该优先采用哪类风险模型口径
- 当前不做回测实现。
- 当前只做：
  - 候选模型比较
  - 当前推荐顺序
  - 当前降级路径

## 当前结论先行

- 当前最合适的正式口径不是：
  - 直接上完整多资产最优模型
- 当前最合适的正式口径是：
  - `基准约束 + 跟踪误差限制 + 风险预算叠层缩放`
- 更直白地说：
  - 上层用组合管理里的 `alpha / covariance / transaction_cost / active_risk_aversion / benchmark_constraints`
  - 下层用仓位风控里的 `Kelly / VolTarget / VanTharp / PQ`
  - 最终收成一个 `final_size_scalar`

## 候选模型

### 模型 1：等权或市值权重 + 风险缩放

- 核心思路：
  - 先用 `equal_weight` 或 `value_weight`
  - 再叠加 `Kelly / VolTarget / VanTharp / PQ` 缩放
- 当前证据：
  - `QEPM chapter09` 明确把 `equal weighting / value weighting` 作为 ad hoc methods
  - `risk_architecture_field_contract_v1.tsv` 已有 `final_size_scalar = min(kelly, vt, pq, 1.0)`
- 优点：
  - 最易落地
  - 字段最少
  - 对噪声输入更稳
- 缺点：
  - 理论最弱
  - 不能充分利用 alpha / covariance
- 当前裁决：
  - `可作为降级模型`

### 模型 2：基准相对 + 跟踪误差限制 + 约束优化

- 核心思路：
  - 给定 `benchmark`
  - 在 `tracking_error_limit` 下最大化 `active_return`
  - 使用 `alpha / covariance / transaction_cost / constraints`
- 当前证据：
  - `QEPM chapter09`
  - `Active Portfolio Management chapter_14`
- 优点：
  - 最符合组合管理正式口径
  - 能把 `约束 / 风险 / 成本` 一起纳入
- 缺点：
  - 对协方差和成本估计敏感
  - 输入质量不足时会变脆弱
- 当前裁决：
  - `当前推荐主模型`

### 模型 3：纯均值-方差 / 协方差最优化

- 核心思路：
  - 在给定收益预期和协方差下，直接做最优权重
- 当前证据：
  - `QEPM chapter09` 与主动组合管理章节
- 优点：
  - 理论清晰
  - 对“风险预算”表达完整
- 缺点：
  - 输入噪声最敏感
  - 需要更强协方差估计与清洁 alpha
- 当前裁决：
  - `作为 future 模型，不作为当前第一顺位`

## 当前推荐顺序

- 第一顺位：
  - `模型 2：基准相对 + 跟踪误差限制 + 约束优化`
- 第二顺位：
  - `模型 1：等权或市值权重 + 风险缩放`
- 第三顺位：
  - `模型 3：纯均值-方差 / 协方差最优化`

## 当前最小降级路径

- 如果缺 `covariance_estimate`
  - 从模型 2 降级到模型 1
- 如果缺 `transaction_cost_estimate`
  - 使用默认交易成本参数，并标记 `degraded`
- 如果缺 `benchmark`
  - 改成 `long_only + max_weight_cap` 的受限组合
- 如果缺 `alpha`
  - 不允许伪优化
  - 直接中止本轮，不进入权重求解

## 当前正式口径

- 现在 `A_REQ_003` 不需要先决定全套投资组合理论。
- 现在只需要先把：
  - `模型 2` 作为主口径
  - `模型 1` 作为降级口径
  固定下来即可。
