# A5 A股 P0 技术指标产品层组合可行性第一轮 跨页语义组一致性护栏最小实现页

更新时间：2026-07-24

## 一、这页用途

- 本页只做：
  - 冻结
    `首页 / 标的页 / 问答页`
    三页对
    `语义组`
    的一致性护栏
  - 让后续继续补实现时，
    三侧口径不漂移
- 本页不做：
  - 前台按组改版
  - 技术指标金融有效性判断
  - 组合回测

## 二、当前主线

- 当前主线是：
  - `A股 P0 技术指标产品层组合可行性第一轮`
- 当前不是：
  - `FV gate`
  - 金融真值层
  - 组合回测

## 三、当前最值钱的一步

- 当前最值钱的一步是：
  - 把三页里“语义组相关的固定短句”
    收成共享 helper
    并用跨页 contract 测试锁死

## 四、当前正式裁决

- 当前三页都继续保持：
  - `sourceCard`
    为第一锚点
  - `语义组`
    只做第二层说明
- 当前允许统一冻结的三种角色短句为：
  - `行业 / 指数参照`
    - `当前解释骨架：行业 / 指数参照`
  - `资金活跃`
    - `当前事件说明补强：资金活跃`
  - `市场宽度`
    - `当前轻背景说明：市场宽度`
- 当前首页的
  `市场宽度`
  hint
  也允许回收至共享语义组层，
  不再由首页 adapter 单独拼接

## 五、输出合同

- 首页：
  - hero 第一张状态卡标题为：
    `市场宽度`
  - hint 固定为：
    `市场宽度语义组（沪深涨跌停），只做首页轻背景说明`
- 标的页：
  - 解释区角色说明顺序固定：
    1. `当前解释骨架：行业 / 指数参照`
    2. `当前事件说明补强：资金活跃`
- 问答页：
  - 来源条 role summary
    必须来自共享语义组 helper
- 共享 context summary：
  - 输出格式固定为：
    `前缀：角色 / sourceCard · 语义组：groupLabel`
  - 当前不允许改成：
    - 省略 `sourceCard`
    - 调换 `角色 / sourceCard` 顺序
    - 改掉 `· 语义组：`
      这一段分隔口径

## 六、停止规则

- 当前做到以下条件后立刻停：
  1. 三页角色短句与首页 market width hint 已统一吃共享语义组 helper
  2. 新增跨页 contract 测试，能同时证明：
     - `市场宽度` 的标题与 hint
     - `行业 / 指数参照` 与 `资金活跃` 的角色短句
     - `buildIndicatorContextSummary` 输出仍以 `sourceCard` 为第一锚点
     - 且完整文案格式仍为：
       `前缀：角色 / sourceCard · 语义组：groupLabel`
  3. 测试与 build 通过
