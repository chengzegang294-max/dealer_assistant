# A5 五条代表指标失效样式交叉映射补页

更新时间：2026-07-27

## 一、这页用途

- 本页只做：
  - 补齐五条代表指标第二阶段细化后的交叉映射关系
  - 回答：
    - 触发型失效和背景型失效如何互相影响
    - 哪些样式容易同时出现
    - 当前主负责人应先判哪一类，再判哪一类

- 本页不做：
  - 金融有效性证明
  - 回测阈值
  - 自动交易门禁

## 四、当前最常见的交叉关系

### 4.1 背景背离型 -> 事件退潮型

- 当前更常见的读法是：
  - 背景先不支持，
    触发随后退潮

- 当前更典型的组合是：
  - `HYDB / ZSDB / 沪深涨跌停`
    的
    `背景背离型`
  - 叠加
    `上榜资金`
    的
    `事件退潮型`

- 当前主负责人优先口径：
  1. 先写：
     `背景不再支持原解释权重`
  2. 再写：
     `事件标签不再配继续当触发依据`

### 4.2 波动失控型 -> 回观察位

- 当前更常见的读法是：
  - 不先争论方向对错，
    先承认环境污染

- 当前更典型的组合是：
  - `打板资金`
    的
    `波动失控型`
  - 叠加
    `ZSDB指数对比`
    的
    `波动失控型`

- 当前主负责人优先口径：
  1. 先写：
     `逻辑未坏，但当前先降权`
  2. 若穿越反复，
     升级成
     `回观察位`

### 4.3 强度衰减型 -> 先降级职责

- 当前更常见的读法是：
  - 解释力还在，
    但已经不配原权重

- 当前更典型的组合是：
  - `上榜资金`
    的
    `强度衰减型`
  - 叠加
    `沪深涨跌停`
    的
    `强度衰减型`

- 当前主负责人优先口径：
  1. 先退一层职责
  2. 再看是否需要进入观察位

### 4.4 结构破坏型 -> 退出原解释

- 当前更常见的读法是：
  - 背景前提被打掉时，
    触发型对象即使局部还亮，
    也不该继续单独撑解释

- 当前更典型的组合是：
  - `HYDB行业对比`
    的
    `结构破坏型`
  - 压掉
    `打板资金 / 上榜资金`
    的局部解释残留

- 当前主负责人优先口径：
  1. 先承认：
     `原背景前提已经不在`
  2. 再把触发型对象降回：
     `观察 / 局部说明`

## 五、当前优先判定顺序

- 当前正式优先顺序冻结为：
  1. 先看背景型对象有没有出现：
     - `背景背离型`
     - `结构破坏型`
     - `波动失控型`
  2. 再看触发型对象是：
     - 还能维持解释
     - 还是已经退潮 / 衰减
  3. 最后才决定：
     - `先降权`
     - `先降级职责`
     - `回观察位`
     - `退出原解释`

- 当前不推荐的顺序是：
  - 只看触发型对象局部还亮，
    完全不先看背景型对象

## 六、当前交叉映射的统一一句话模板

### 6.1 背景先坏，触发后退

- 当前模板：
  - `当前先是背景不再支持原解释权重，随后触发型对象也退潮，因此先退一层职责或回观察位，不再继续按原逻辑推进。`

### 6.2 触发先乱，背景也脏

- 当前模板：
  - `当前不是单点失效，而是触发节奏已乱、背景噪音也在上升，因此先降权，必要时整体回观察位。`

### 6.3 背景已破，局部亮点不再单独成立

- 当前模板：
  - `当前背景前提已经被打掉，局部亮点不能再单独撑住原解释，因此退出原解释或只保留局部观察价值。`
