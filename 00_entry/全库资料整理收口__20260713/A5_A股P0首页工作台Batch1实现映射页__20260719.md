# A5 A股 P0 首页工作台 Batch1 实现映射页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把
    `Batch 1`
    已冻结的首页工作台最小闭环，
    继续压到
    `props / event / dataflow / 状态切换`
    映射层
- 本页只服务于：
  - 首页工作台第一批实现
- 本页不做：
  - 标的页实现映射
  - 问答页实现映射
  - API 协议
  - 前端框架选型

## 二、当前唯一目标

- 当前唯一目标是：
  - 让实现侧只看本页，
    就知道首页
    `Batch 1`
    该怎么把对象接起来
- 当前不是：
  - 再解释为什么这样设计
  - 继续补产品页合同

## 三、Batch 1 页面壳映射

- 当前首页工作台最小实现树固定为：
  1. `HomePageShell`
  2. `GlobalStatusBar`
  3. `StockSearchEntry`
  4. `EventStreamPanel`
  5. `MainWorkspacePanel`
  6. `DecisionQueueSummary`
  7. `HistoryTracePanel`

## 四、首页持有状态映射

- 当前首页必须持有：
  - `selectedEventId`
  - `homeWorkspaceState`
  - `homeRecordDraft`
  - `latestSubmitEcho`
  - `searchDraft`
- 当前首页只消费但不自造第二真值：
  - `eventList`
  - `currentEventSummary`
  - `financeDisclosureContext`

## 五、组件 props 映射

### 5.1 GlobalStatusBar

- 输入 props 固定为：
  - `marketSummary`
  - `pendingEventCount`
  - `holdingRiskHint`
  - `financeDisclosureContext`
- 输出事件固定为：
  - `onOpenFinanceDisclosure()`

### 5.2 StockSearchEntry

- 输入 props 固定为：
  - `searchDraft`
- 输出事件固定为：
  - `onChangeSearchDraft(searchDraft)`
  - `onOpenStockPage(stockCode)`
- 当前规则固定为：
  - `searchDraft`
    是首页本地草稿态
  - `stockCode`
    是提交打开动作时的有效输出值

### 5.3 EventStreamPanel

- 输入 props 固定为：
  - `eventList`
  - `selectedEventId`
  - `financeDisclosureContext`
- 输出事件固定为：
  - `onSelectEvent(eventId)`

### 5.4 MainWorkspacePanel

- 输入 props 固定为：
  - `homeWorkspaceState`
  - `selectedEventSummary`
  - `selectedExplanationPayload`
  - `homeRecordDraft`
  - `latestSubmitEcho`
  - `financeDisclosureContext`
- 输出事件固定为：
  - `onChangeDecisionDraft(partialDraft)`
  - `onSubmitDecision()`
  - `onRetrySubmitDecision()`
  - `onOpenFinanceDisclosure()`

### 5.5 DecisionQueueSummary

- 输入 props 固定为：
  - `queuedEvents`
  - `selectedEventId`
- 输出事件固定为：
  - `onSelectQueuedEvent(eventId)`

### 5.6 HistoryTracePanel

- 输入 props 固定为：
  - `recentDecisionRecords`
  - `latestSubmitEcho`
- 输出事件固定为：
  - `onOpenDecisionHistory()`

## 六、主工作区内部映射

### 6.1 空状态

- 进入条件：
  - `selectedEventId = null`
- 必须消费：
  - `financeDisclosureContext`
- 不消费：
  - `homeRecordDraft`
  - `latestSubmitEcho`

### 6.2 选中态

- 进入条件：
  - `selectedEventId != null`
  - `homeWorkspaceState = selected`
- 必须消费：
  - `selectedEventSummary`
  - `selectedExplanationPayload`
  - `financeDisclosureContext`
- 当前默认生成：
  - `homeRecordDraft.eventId = selectedEventId`

### 6.3 编辑态

- 进入条件：
  - `homeRecordDraft.action / reasonTag / horizon`
    任一开始填写
- 必须消费：
  - `homeRecordDraft`
  - `selectedEventSummary`
  - `selectedExplanationPayload`

### 6.4 提交成功回显态

- 进入条件：
  - `onSubmitDecision()`
    成功
- 必须消费：
  - `latestSubmitEcho`
  - `selectedEventSummary`
  - `financeDisclosureContext`
- 必须触发：
  - `EventSummary.processStatus`
    更新

## 七、首页关键 dataflow

### 7.1 事件选择流

1. `EventCard.onSelectEvent(eventId)`
2. 首页写入：
   - `selectedEventId`
   - `homeWorkspaceState = selected`
3. 首页派生：
   - `selectedEventSummary`
   - `selectedExplanationPayload`
4. 首页初始化：
   - `homeRecordDraft.eventId = selectedEventId`

### 7.2 草稿编辑流

1. `DecisionRecordForm`
   触发
   `onChangeDecisionDraft(partialDraft)`
2. 首页合并更新：
   - `homeRecordDraft`
3. 首页切换：
   - `homeWorkspaceState = editing`

### 7.3 提交流

1. `DecisionRecordForm`
   触发
   `onSubmitDecision()`
2. 首页用：
   - `homeRecordDraft`
   组装最小提交对象
3. 成功后首页写入：
   - `latestSubmitEcho`
   - `homeWorkspaceState = submitted`
4. 同时更新：
   - 当前事件
     `processStatus`
   - `recentDecisionRecords`
   - `queuedEvents`

### 7.4 待处理摘要回流

1. `DecisionQueueSummary.onSelectQueuedEvent(eventId)`
2. 首页写入：
   - `selectedEventId`
   - `homeWorkspaceState = selected`
3. 主工作区重新加载当前事件上下文

### 7.5 搜索打开流

1. `StockSearchEntry`
   写入：
   - `searchDraft`
2. 用户确认后触发：
   - `onOpenStockPage(stockCode)`
3. 当前
   `Batch 1`
   到此即停，
   不展开标的页内部实现

## 八、Batch 1 最小校验点

- 当前提交前只校验：
  - `selectedEventId`
    存在
  - `action`
    非空
  - `reasonTag`
    非空
  - `horizon`
    非空
- 当前搜索前只校验：
  - `searchDraft`
    非空
  - 可映射到一个
    `stockCode`

## 九、Batch 1 局部失败处理

- 当前允许最小失败态只有：
  - `解释加载失败`
  - `记录提交失败`
- 当前提交失败后必须保留：
  - `selectedEventId`
  - `selectedEventSummary`
  - `selectedExplanationPayload`
  - `homeRecordDraft`
  - `financeDisclosureContext`
- 当前不允许：
  - 失败后清空草稿
  - 失败后回到空状态
