# A5 技术指标结构性缺位第一轮 仓位层退出层失效方式与外部参考边界页

更新时间：2026-07-25

## 一、这页用途

- 本页只回答：
  - 当前识别出的三类结构性缺位，
    是否可以先靠仓内资料推进
  - 什么时候才需要借外部成熟交易体系
  - 真要借时，
    该借哪几个、
    借到哪一层
- 本页不做：
  - 直接重开参考交易系统补采
  - 直接扩指标池
  - 直接进入回测层

## 二、当前真正缺的是什么

- 当前已经正式识别出的结构性缺位是：
  1. `仓位层`
  2. `退出层`
  3. `失效方式`
     及其背后的
     `波动 / 风险约束层`

- 当前这几个缺位的性质是：
  - `讨论抓手偏弱`
  - 不是
    `完全没有任何资料`

## 三、仓内现在有没有足够锚点先往下做

## 3.1 当前判断

- 当前判断是：
  - `有`
  - 而且
    `够做第一轮`

## 3.2 主要依据

- 仓内已经有以下锚点可直接复用：
  1. `A5_指标职责分层与场景映射页__20260716.md`
     - 已明确：
       - `仓位层=按置信度与风险缩放`
       - `退出层=结构破坏或强度衰减`
       - `高波动风险保护=降权 / 缩仓 / 不交易`
  2. `A5_指标效用组合与回测启动边界页__20260716.md`
     - 已明确：
       - 真正值钱的是
         `职责分层`
         而不是
         `指标池思维`
       - 冲突时要有
         `优先级和降权规则`
  3. `A5_最小信号组合卡__候选骨架__20260716.md`
     - 已经给出了：
       - `仓位层`
         的最小写法
       - `退出层`
         的最小写法
       - `高波动乱跳阶段要降权`
         这类风险约束句子
  4. `A5_技术指标第一批场景矩阵_v0页__20260725.md`
     - 已正式冻结第一批：
       - 职责层
       - 市场特征
       - 单子特征
  5. `A5_技术指标缺失判断与补池边界页__20260725.md`
     - 已正式裁决：
       当前先不扩指标池，
       而是先看职责位是否持续空缺

## 四、所以当前最顺主线先做什么

- 当前最顺主线不是：
  - 回头补更多指标名字
  - 重开外部成熟体系大范围补采
- 当前最顺主线应是：
  1. 先把
     `仓位层`
     写成：
     - 何时加权
     - 何时降权
     - 何时只观察不动作
  2. 再把
     `退出层`
     写成：
     - 哪些属于结构破坏
     - 哪些属于强度衰减
     - 哪些属于事件后快速失效
  3. 再把
     `失效方式`
     写成：
     - 什么时候不该用
     - 什么时候该降权
     - 什么时候该从触发改回过滤

## 五、那现在需不需要借外部成熟交易体系

## 5.1 当前正式判断

- 当前正式判断是：
  - `暂时不需要马上借`
  - 但
    `可以预留为下一跳辅助输入`

## 5.2 为什么现在还不需要马上借

- 原因是：
  1. 当前三类缺位，
     还没有压到
     `仓内完全无话可写`
     的程度
  2. 仓内旧页已经提供了第一轮最小语义：
     - `降权`
     - `缩仓`
     - `不交易`
     - `结构破坏`
     - `强度衰减`
  3. 如果现在立刻切去借外部体系，
     很容易把当前主线从
     `技术指标职责与场景`
     滑回
     `成熟体系搬运`

## 六、什么情况下才需要借

- 当前只有出现以下情况，
  才建议正式借外部成熟体系做
  `辅助案例输入`：

### 6.1 仓位层仍旧发虚

- 例如：
  - 我们反复只能写出
    `权重大一点 / 小一点`
  - 但说不清：
    - 为什么降权
    - 降权的触发条件
    - 降权与不交易的边界

### 6.2 退出层仍旧只剩抽象话

- 例如：
  - 只能写
    `结构破坏`
    `强度衰减`
  - 但无法稳定拆成：
    - 哪类破坏算真失效
    - 哪类只是短噪音
    - 哪类应先减仓不应直接清退

### 6.3 失效方式仍旧无法稳定归类

- 例如：
  - 我们能写出
    `什么时候有用`
  - 但持续写不出
    `什么时候不该用`
    `什么时候要从触发层降回过滤层`

## 七、真要借时，先借哪几个体系

## 7.1 第一优先：`NFTRADEZ`

- 当前最适合借它的地方是：
  - `risk_guard`
  - `premarket`
  - `glossary`
    这类方法参考层
- 更像拿来补：
  - 风险约束语言
  - 失效样式命名
  - 主落点与次回链的表达方式
- 不拿来做：
  - 对象合同
  - 执行接线

## 7.2 第二优先：`Smile_SMC交易系统2_0`

- 当前最适合借它的地方是：
  - explain / review
    结构
  - 逐帧过程文字化
- 更像拿来补：
  - 退出后的复盘表达
  - 失效过程的叙事拆法
  - 结构破坏与误判样式的讲法
- 不拿来做：
  - 主策略照搬
  - 交易规则接线

## 7.3 第三优先：`TK外汇`

- 当前最适合借它的地方是：
  - 更细的判据口径
  - 例外与降级映射
- 更像拿来补：
  - `什么时候只是例外`
  - `什么时候需要降级`
  - `什么时候仍不该升级成动作`
- 不拿来做：
  - 把外汇判据整体平移成
    A股默认逻辑

## 八、借的时候只借哪一层

- 当前统一边界继续写死为：
  - 只借
    `方法参考包 / 映射页 / explain-review 结构 / 风险约束语言`
- 不借：
  - 完整策略本体
  - 交易门禁
  - 默认执行逻辑
  - 回测入口

## 九、主负责人裁决

- 当前正式裁决为：
  1. `仓位层 / 退出层 / 失效方式`
     的第一轮细化，
     当前可以先完全在仓内推进
  2. 当前还没到必须借外部成熟体系
     才能继续的程度
  3. 但如果下一轮细化后，
     仍明显发虚，
     就正式触发：
     - `NFTRADEZ`
       的风险约束语言参考
     - `Smile_SMC`
       的 explain/review 结构参考
     - `TK外汇`
       的例外与降级判据参考
  4. 这些体系即便被借入，
     也只保持：
     - `辅助案例输入`
     - 不并入主线本体

## 十、当前先做什么

- 当前先做：
  1. 直接落
     `仓位层第一轮讨论页`
  2. 再落
     `退出层与失效方式第一轮讨论页`
  3. 做完这两页后，
     再判断是否触发外部参考下一跳

## 十一、一句话口径

- 当前三类结构性缺位还可以先靠仓内资料推进，
  暂时不必立刻借外部成熟交易体系；
  只有当
  `仓位层 / 退出层 / 失效方式`
  在下一轮细化后仍明显发虚，
  才把
  `NFTRADEZ / Smile_SMC / TK`
  作为
  `辅助案例输入`
  借进来，
  且只借方法层，
  不并入主线本体。
