# A5 第二日期输入包接入执行页

更新时间：2026-07-30

## 一、这页用途

- 本页只做：
  - 把第二日期样本怎么接入现有验收链路，
    压成一页执行顺序

## 二、当前执行顺序

1. 先拿到同一个新交易日的 3 张必需图
   - `市场情绪总览`
   - `市场宽度涨停跌停`
   - `龙虎榜异动资金`
2. 把截图按统一文件名规则落到新批次的
   `00_raw_snapshot/user_screenshots/`
3. 用运行时脚手架生成该日期的输入包计划行
4. 把计划行回填到
   `a5_input_pack_sample_plan_v1.tsv`
5. 运行
   `run_a5_input_pack_acceptance_v1.py`
   验收第二日期输入包
6. 再运行
   `run_a5_multi_pack_gate_acceptance_v1.py`
   重跑两日期门槛

## 三、当前最小成功标准

- 第二日期接入当前最小成功标准冻结为：
  1. 新日期 3 张图文件已入库
  2. 输入包计划行已回填
  3. 单输入包验收 `passed=true`
  4. 两日期门槛由
     `need_second_distinct_sample_date_input_pack`
     进入下一状态

## 四、当前不做什么

- 当前不要求第二日期一上来就补：
  1. `HYDB / ZSDB` 严格同日页
  2. `打板资金` 严格等价页
  3. 精确 `occurredAt`

- 这些仍放在后手，
  不阻塞第二日期最小接入

## 五、主负责人裁决

- 当前正式裁决为：
  1. 第二日期接入，
     先走
     `3 张图 -> 计划行 -> 单包验收 -> 两日期门槛重跑`
  2. 现有脚手架已经够用，
     不需要重新发明一套流程

## 六、一句话口径

- 第二日期一旦到位，
  就直接按
  `东方财富 PC 3 张图 -> 输入包计划 -> 单包验收 -> 两日期门槛`
