# A5 A股 P0 页面间状态归属与最小实现顺序页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 冻结当前
    `A股 P0`
    的页面间状态归属
  - 冻结实现前的最小开发顺序
- 本页不做：
  - 真实项目排期
  - Sprint 管理
  - 框架实现

## 二、当前状态归属原则

- 当前状态只分为：
  1. `首页持有状态`
  2. `标的页持有状态`
  3. `问答页持有状态`
  4. `跨页共享状态`

## 三、首页持有状态

- 当前固定归首页持有的状态包括：
  - `selectedEventId`
  - `homeWorkspaceState`
  - `homeRecordDraft`
  - `latestSubmitEcho`
- 当前这些状态只服务于：
  - 首页事件流
  - 首页主工作区
  - 首页历史追踪的即时回显

## 四、标的页持有状态

- 当前固定归标的页持有的状态包括：
  - `selectedRelatedEventId`
  - `stockExplanationState`
  - `latestDecisionState`
  - `supplementEditorState`
  - `latestSupplementEchoState`

## 五、问答页持有状态

- 当前固定归问答页持有的状态包括：
  - `qaQuestionGroupState`
  - `qaSelectedQuestion`
  - `qaAnswerState`
  - `qaGenerationErrorState`

## 六、跨页共享状态

- 当前固定跨页共享的只允许是：
  - `currentStockContext`
  - `currentEventSummary`
  - `financeDisclosureContext`
- 当前不允许把：
  - 页面局部编辑态
  - 局部 loading/error 态
  乱提成全局共享状态
- 当前交接优先级固定为：
  - 首页内由
    `selectedEventId`
    回写
    `currentEventSummary`
  - 进入标的页后由
    `selectedRelatedEventId`
    覆盖当前页上下文
  - 返回首页后恢复首页最近一次事件上下文

## 七、状态归属红线

- 当前不允许首页直接持有：
  - 问答页答案展示内部态
- 当前不允许问答页直接改写：
  - 首页记录草稿
- 当前不允许标的页直接接管：
  - 首页主工作区三态
- 当前不允许首页与标的页同时争抢写：
  - `currentEventSummary`

## 八、最小实现顺序

- 当前最小实现顺序固定为：
  1. `首页页面壳 + 事件流 + 主工作区空态/选中态 + 金融披露入口`
  2. `首页记录提交与提交回显 + processStatus 回写`
  3. `首页搜索入口 + 跨页上下文交接（进标的页）`
  4. `标的页页面壳 + 相关事件 + 当前解释`
  5. `标的页最近记录区 + 补充记录编辑`
  6. `问答下钻页 + 推荐问题组 + 答案展示`
  7. `历史回看跨页联动收口`

## 九、为什么按这个顺序

- 首页先做，
  因为它承接：
  - 唯一主轴
  - 第一跳交互
- 金融披露必须跟首页首批一起做，
  因为事件卡与主工作区已要求披露字段
- 标的页第二段做，
  因为它承接：
  - 首页搜索进入后的记录闭环
- 问答页最后做，
  因为它仍是：
  - 增强层
  - 不是第一跳主轴

## 十、当前最短实现批次

- 当前最短实现批次可冻结为：
  - `Batch 1`
    首页工作台最小闭环
    + 金融披露
    + 搜索入口
  - `Batch 2`
    标的页记录补充闭环
  - `Batch 3`
    问答下钻增强闭环

## 十一、关键回写归属

- 当前
  `processStatus`
  的正式写回归属固定为：
  - 首页记录提交成功后，
    由首页事件流真值对象更新
  - 标的页只消费该状态的镜像，
    不单独产生第二真值
- 当前
  `DecisionQueueSummary`
  点击后必须写入：
  - `selectedEventId`
  - `homeWorkspaceState`

## 十二、Cursor 最适合审校的点

- 当前最适合让
  `Cursor`
  审校的是：
  - 状态有没有乱归属
  - 首页和标的页是否共享了不该共享的局部态
  - 最小实现顺序是否仍有倒置

## 十三、通过标准

- 当前通过标准是：
  - 实现侧只看本页，
    就能知道：
    - 每类状态该挂在哪一页
    - 什么能共享，
      什么不能共享
    - 真开始做时先做哪一批，
      后做哪一批

## 十四、停止规则

  - 四类状态归属
  - 状态归属红线
  - 七步最小实现顺序
