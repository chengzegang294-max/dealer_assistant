# A5 A股 P0 技术指标产品层组合可行性第一轮 问答页语义组角色最小实现页

更新时间：2026-07-24

## 一、这页用途

- 本页只做：
  - 冻结问答页侧
    `语义组角色`
    的最小实现边界
- 本页不做：
  - 问答页按组改题
  - 问答页按组改回答
  - 新增问答入口

## 二、当前主线

- 当前主线是：
  - `A股 P0 技术指标产品层组合可行性第一轮`
- 当前不是：
  - 金融真值层
  - 组合回测
  - 问答页重做

## 三、当前最值钱的一步

- 当前最值钱的一步是：
  - 让问答结果页的
    `事件与字段来源条`
    不只告诉用户：
    - 回链到哪个 `sourceCard`
  - 还明确告诉用户：
    - 这条回链对应的语义组角色

## 四、当前正式裁决

- 问答页当前只允许：
  - 在
    `contextPrioritySummary`
    后面追加一行语义组角色说明
- 问答页当前不允许：
  - 把语义组写成交易信号
  - 用语义组替代 `sourceCard`
  - 把问答重写成按组回答

## 五、实现合同

- 当前输出格式固定为：
  - `当前解释骨架：行业 / 指数参照`
  - `当前事件说明补强：资金活跃`
  - `当前轻背景说明：市场宽度`
- 并同步补齐上下文可见性：
  - 问答页相关事件上下文在直连标的事件外，
    额外带入该事件前置的 `3` 条市场上下文事件，
    使 `资金活跃`（打板/上榜资金）能进入指标释义问题组并触发角色说明
- 当前仍保持：
  - `sourceCard`
    为第一锚点
  - 语义组角色只做第二层说明

## 六、停止规则

- 当前做到以下条件后立刻停：
  1. 问答页来源条已出现语义组角色说明
  2. `sourceCard` 仍为第一锚点
  3. hook / 页面层至少各有一条断言
     能证明：
     - `资金活跃`
       已可进入指标释义问题组并触发角色说明
  4. 测试与 build 通过
