# A5 真实案例采样第二轮案例扩展起手顺序页

更新时间：2026-07-27

## 一、这页用途

- 本页只做：
  - 冻结第二轮案例扩展一旦拿到新日期样本，
    应该先怎么起手

## 二、第二轮当前起手顺序

- 当前第二轮起手顺序冻结为：

1. 先确认新的 `sample_date`
   是否真实存在于仓内来源链中
2. 先做一张
   `第二轮日期锚点确认页`
3. 再在该日期上，
   先复建三张最小代表卡：
   - `HYDB行业对比 / 沪深涨跌停 -> 上榜资金`
   - `ZSDB指数对比 / 沪深涨跌停 -> 打板资金`
   - `HYDB行业对比 / ZSDB指数对比 -> 上榜资金`
4. 三张卡成立后，
   再决定是否扩成第二轮完整六卡矩阵

## 三、为什么不是一上来就重做六张

- 当前不是一上来就重做六张，
  原因是：
  1. 第二轮现在缺的是：
     - 新日期锚点
  2. 在新日期还没完全稳住前，
     先做三张最小代表卡更稳
  3. 这样可以最快判断：
     - 新日期是否真的有复建价值
     - 第一轮口径是否可平移

## 四、当前暂缓什么

- 当前暂缓：
  1. 第二轮完整六卡矩阵
  2. 第二轮更细 `occurredAt`
  3. 第二轮任何金融有效性判断

## 五、主负责人裁决

- 当前正式裁决为：
  1. 第二轮若启动，
     先按
     `新日期 -> 三张最小代表卡 -> 再看是否补齐六卡`
     这条顺序走
  2. 当前不再把“页数变多”当推进，
     而是把“新日期样本成立”当推进

## 六、一句话口径

- 第二轮案例扩展当前起手顺序已经冻结：
  先拿新日期，
  再做三张最小代表卡，
  稳住后才考虑扩成完整六卡矩阵。
