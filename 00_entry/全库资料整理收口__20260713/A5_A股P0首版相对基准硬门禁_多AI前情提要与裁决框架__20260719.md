# A5 A股 P0 首版相对基准硬门禁 多AI前情提要与裁决框架

更新时间：2026-07-19

## 一、当前任务

- 当前要讨论的不是：
  - 项目终局是什么
  - 第一版要不要做全市场
  - 要不要继续第四窗
- 当前要讨论的唯一问题是：
  - 对 `A股 P0`
    第一版可用雏形而言，
    是否应把：
    - `相对基准不系统性跑输`
    写成进入产品原型阶段的
    `硬门禁`

## 二、前情提要

- 当前项目终局已经明确为：
  - `可解释投资决策辅助驾驶舱`
  - 用户感知层更接近：
    - `私人投资管家`
- 当前最小终局闭环已经固定为：
  - `提醒 -> 解释 -> 记录 -> 回看`
- 当前市场优先级已经固定为：
  - `A股(P0) > 外汇(P1) > 币圈(P2) > 期货(P3) > 指数/期权(P4)`
- 当前执行侧已把：
  - `FV_gate_evidence_packet_v0`
    冻结为正式停点
- 当前证据包总标签为：
  - `cross_window_return_sign_majority_positive__active_sign_majority_negative__still_need_evidence`
- 当前已知核心张力为：
  - 绝对收益与 holdout
    在三窗上是：
    - `2 正 1 负`
  - 但相对基准的
    `net active_total_return`
    是：
    - `1 正 2 负`

## 三、为什么现在要讨论这个

- `Cursor`
  这轮有价值的一点是：
  - 它把真正的判断题收成了：
    - 第一版是否应把
      `不系统性跑输基准`
      写成硬门禁
- 这个问题一旦不拍板，
  后面就会反复漂移成：
  - 一会儿想先做首页
  - 一会儿想继续补证据
  - 一会儿又回到“能不能做出来”的泛讨论
- 当前最需要的是：
  - 让多家 AI
    从产品、量化、风险、规划四个角度，
    对这个单点问题给出方案对比

## 四、当前允许讨论到哪里

- 当前允许讨论：
  - 是否把
    `相对基准不系统性跑输`
    设为
    `A股 P0 第一版`
    的硬门禁
  - 若不设为硬门禁，
    是否应降级为：
    - 明示限制条件下可进入原型
  - 若条件式允许进入原型，
    应如何写停止规则与披露口径
- 当前也允许讨论：
  - 这个门禁更适合绑定：
    - `CSI300`
    - 还是
      `选定基准`
  - 但若缺证据，
    必须显式写：
    - `NEED_EVIDENCE`

## 五、当前明确不讨论什么

- 当前不讨论：
  - 第四窗
  - 同窗微调
  - 更宽成本带
  - 持有规则扩网格
  - 新 runner
  - 新 evidence type
  - UI 细节
  - 本地 AI 技术选型
  - 外汇 / 币圈 / 期货并行落地
  - 完整题材库与财报管线的实现细节

## 六、已知约束

- 当前不得把任何结论写成：
  - `financial-valid`
  - `output_passed`
  - `cross_window_consistency_passed`
- 当前项目并不是：
  - 没终局
  - 没路线
  - 资料不够开工
- 当前更准确的状态是：
  - 终局已清楚
  - `A股 P0`
    最小闭环已清楚
  - 但金融证据门禁还没彻底关掉
- 当前若允许先做第一版，
  也只能理解成：
  - 允许进入
    `A股 P0`
    最小原型闭环
  - 不等于：
    - 有金融有效性背书
    - 有超额收益背书
    - 可直接扩到多市场

## 七、建议外部模型必须覆盖的三种方案

- 方案 A：
  - 设为
    `硬门禁`
- 方案 B：
  - 不设为硬门禁，
    但保留明示限制披露，
    允许先做第一版原型
- 方案 C：
  - 条件式门禁
    即：
    - 不要求先达到“不系统性跑输”
    - 但要求先补一页正式裁决或补一条极窄验证

## 八、主负责人希望比较的维度

- 产品可信度
- 量化证据严谨性
- 执行可落地性
- 是否会把项目拖死在门禁前
- 是否会把当前 `still_need_evidence`
  错包装成
  “第一版已经可信”

## 九、期望输出

- 每个模型都必须：
  - 先明确：
    - `yes / no / conditional`
  - 再对
    - 方案 A / B / C
      做对照
  - 最后给出：
    - 当前最推荐方案
    - 对 `Trae`
      的唯一下一手
    - 停止规则

## 十、一句话口径

- 当前要讨论的不是“项目能不能做”，而是“在 `A股 P0` 第一版进入产品原型前，是否必须先把相对基准不系统性跑输写成硬门禁，还是允许在明示限制下先进入最小闭环原型”。
