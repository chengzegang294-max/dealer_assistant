# A5 统一对象接口草案

更新时间：2026-07-15

## 用途

- 在不进入 runtime 新开发的前提下，先把 `GROUP_10_A5` 当前可用的合同层输出收成一个统一接口。
- 这份文件不是代码接口。
- 这是：
  - 阅读接口
  - 合同接口
  - 后续对象卡/实现层的前置草案

## 当前设计目标

- 让 `A_REQ_002` 与 `A_REQ_003` 不再各说各话。
- 让后续继续下沉时，有一套统一的字段层次和解释边界。

## 当前统一解释规则

- `A_REQ_002` 负责从：
  - `raw_financial_inputs`
  推到：
  - `valuation_factor_outputs`
- `A_REQ_003` 负责从：
  - `portfolio_policy_inputs + risk_overlay_inputs`
  推到：
  - `portfolio_final_outputs`
- `meta.degrade_flags / abort_reason` 负责统一承接：
  - 降级
  - 中止
  - 边界说明

## 当前最小可消费视图

- 若只读解释层：
  - 读 `valuation_factor_outputs`
- 若只读组合层：
  - 读 `portfolio_final_outputs`
- 若要判定结果是否可信：
  - 读 `degrade_flags + abort_reason + valuation_factor_confidence`

## 当前不承诺

- 不承诺：
  - 所有字段都已实现
  - 所有字段都已完成历史验证
  - 当前已经具备优化器或生产可运行接口
