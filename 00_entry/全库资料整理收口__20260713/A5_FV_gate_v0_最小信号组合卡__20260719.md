- 把 `FV gate v0` 首轮成绩单为负之后，第二轮只允许调整的最小信号组合维度正式冻结。
- 本页不重开大范围策略讨论。
- 本页不宣布：

  - 已完成正式多AI裁决

## 当前结论

- 当前首轮 `FV gate v0` 已证明：
  - 入口可跑
  - 成绩单可生成
- 当前首轮 `FV gate v0` 也同时证明：
  - 当前 `alpha_model_or_factor_rank_proxy` 驱动下的最小静态权重，
    未给出正向金融结果
- 因此当前下一手不是：
  - 回退否定工程链
  - 直接铺 `4-6` 类策略大全
- 当前下一手是：
  - 冻结第二轮只允许调整的一组最小信号假设

## 六点二、2026-07-19 第三轮过滤失败与 risk-lite 修正

- 本轮先试了：
  - `strict_trend_stability_filter_v2`
  - `strict_trend_stability_filter_v2_soft`
- 两次都触发了同一失败边界：
  - `non_positive_alpha_sum`
- 当前失败含义是：
  - 这组三只样本在“趋势稳定过滤”前提下被整体筛空
  - 失败对象是：
    - 当前过滤假设
  - 不是：
    - `TW -> PTE -> APW -> FV gate` 工程链
- 随后本轮改为：
  - 保留 A 候选原始分数
  - 不加过滤器
  - 只下调 `final_size_scalar` 到 `0.6`
- risk-lite 第三轮结果已新增：
  - `net total_return = -0.01247598`
  - `holdout net total_return = -0.00454041`
  - `net active_total_return = -0.13144024`
  - `net max_drawdown = -0.02229168`
- 当前新增含义：
  - 相比第二轮 A 候选，risk-lite 明显继续改善
  - 当前更值钱的杠杆是：
    - 风险暴露收缩
  - 而不是：
    - 先继续加趋势稳定过滤
