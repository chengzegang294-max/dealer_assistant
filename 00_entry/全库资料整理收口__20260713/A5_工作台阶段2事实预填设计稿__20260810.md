## 二、阶段边界（再钉一次）

| 可预填 | 不可预填 |
|--------|----------|
| `trade_date` | `bias_preopen` / 盘前一句话 |
| 连板结构事实摘要 | `watch_sectors` / `watch_symbols` |
| sector 路径 + 前5净额摘要 | 盘中确认是/否 |

一句话：

- 脚本只负责“把已有事实贴进卡”；人负责“今天怎么看”。

## 三、字段 ← 来源映射

### 盘前 `preopen`

| 字段 | 预填规则 |
|------|----------|
| `trade_date` | 口令 `--trade-date` |
| `ladder_yesterday_fact` | 优先读昨日 ladder json；没有则写「（无 ladder 输入）」 |
| `sector_snapshot_ref` | 优先 `sector_daily_snapshots/sector_capital_flow_snapshot__{date}.json`；若当日未归档，则回退 `batch_*_daily_close__{date}/00_raw/sector_capital_flow_snapshot__{date}.json`；仍无则写 `（无 sector 输入）` |
| `p1_auction_ref` | `p1_day__{date}.md` 路径；文件不存在则标注未生成 |
| 判断格 | 全部留空 |

### 盘中 `intraday`

| 字段 | 预填规则 |
|------|----------|
| `trade_date` | 同上 |
| 全部确认/仍值得盯/一句话 | **不预填** |
| `P1` 路径提示（设计备注） | 仅保留在日文件末尾统一引用区；**不纳入 intraday 字段合同** |

### 盘后 `afterclose`

| 字段 | 预填规则 |
|------|----------|
| `ladder_result_fact` | 当日 ladder json 结构摘要；无则空提示 |
| `sector_eod_ref` | 优先 `sector_daily_snapshots/sector_capital_flow_snapshot__{date}.json`；若当日未归档，则回退 `batch_*_daily_close__{date}/00_raw/sector_capital_flow_snapshot__{date}.json`；仍无则写 `（无 sector 输入）` |
| `p1_day_ref` | `p1_day__{date}.md` |
| 判断格 | **不预填** |

## 五、与日常口令的关系

日常主线仍是：

```text
今天做 P1 记录 + sector 当日快照。交易日：YYYYMMDD。
```

工作台预填是**附加件**：P1/sector 有了之后，再生成/刷新 `workbench_day__{date}.md`。
