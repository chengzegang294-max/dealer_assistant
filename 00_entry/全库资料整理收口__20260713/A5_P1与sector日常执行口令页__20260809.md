## 一、当前主线

只做两件事，连续做：

1. `P1` 连续记录
2. `sector` 当日快照累积

不做：新接口、权限购买讨论、金融判断、整包扩源。

## 二、每天怎么开工

收盘后你发：

```text
今天做 P1 记录 + sector 当日快照。交易日：YYYYMMDD。
```

若已有 raw，再补：

```text
raw 在：<ladder或可忽略>；<sector_capital_flow_snapshot 当日 json 路径>
```

## 三、Cursor 当天要交什么

1. `02_runtime/shortline_funding_gap/batch_01_p1_manual_validation__20260809/daily/p1_day__{YYYYMMDD}.md`
2. 在月日志里追加一行：
   - `.../derived/p1_manual_validation_log__YYYYMM.tsv`
3. sector 当日归档到：
   - `02_runtime/quicktiny_capture/sector_daily_snapshots/sector_capital_flow_snapshot__{YYYYMMDD}.json`
   - 同名前缀 `.tsv` / `.meta.json`
4. 当天执行回报（可写在 daily 页末尾，或单独 `A5_Cursor执行回报_P1日更__{YYYYMMDD}.md`）
