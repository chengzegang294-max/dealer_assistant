## 2. 数据来源权威顺序

先把两个概念拆开：

### 2.1 产品目标锚点

`东方财富 PC` 是当前产品目标中的**核心数据锚点**。

这句话只表示：

- 产品长期要围绕东方财富 PC 建立稳定事实链；
- 当前可见页与第二日期最小补证已经证明它是**现实可见锚点**。

这句话**不表示**：

- 当前仓内已经证明了 Eastmoney 的 landed field source；
- 当前所有技术分析字段都已经由 Eastmoney 落盘验真。

### 2.2 当前已验真的字段权威顺序

就当前仓内已经落盘、可回链、可复查的字段事实而言，权威顺序冻结为：

1. `ladder_day_min / ladder_day raw`
   - 当前最强的日级结构事实源
   - 可支撑：最高板、总连板池、板高分布、部分个股结构字段、题材、换手、成交额等
2. `sector_daily_snapshots`
   - 当前最强的板块资金事实源
   - 规范归档优先；当规范归档不完整时，允许使用当日 `raw fallback`，但必须降级
3. `P1 daily`
   - 当前最强的日级人工事实页
   - 可支撑：竞价/盘中/收盘回看的事实引用、连板与 sector 摘要、路径回链
4. `workbench three-day samples`
   - 当前最强的事实预填样例层
   - 证明了哪些字段已预填、哪些字段留空、哪些字段只能人工
5. `live-room sentinel index`
   - 只证明房间范围、Raw 状态和 frozen-out 范围
   - 不能直接当技术事实正文

   - 仅进入 `TA-02`
2. `外部视频材料`

一句话：

## 6. 来源回退与冲突处理

### 6.1 回退规则

1. `sector`
   - 主来源：`sector_daily_snapshots`
   - 备用来源：当日 `batch_*_daily_close__/00_raw/sector_capital_flow_snapshot__{date}.json`
   - 回退后状态必须降级为：`SOURCE_CONFIRMED_WITH_LIMITATION` 或 `FALLBACK_ONLY`
2. `ladder`
   - 主来源：`ladder_day_min`
   - 备用来源：`ladder_day raw`
3. `P1 / workbench`
   - 只允许引用现有日文件
   - 文件不存在就写缺失，不补猜

### 6.2 明确禁止

1. 不允许跨交易日拼接冒充当日事实
2. 不允许用旧 snapshot 冒充当日 snapshot
3. 不允许把 live-room Raw/Draft 直接冒充事实
4. 不允许把 batch149 / 外部视频抬成当前正式来源

### 6.3 冲突处理

只要出现以下任一情况，必须显式记冲突，不能静默覆盖：

- 日期不同
- 名称不同
- 板块归属不同
- 最高板/连板结构不同
- 价格或金额口径不同

## 7. 数据质量闸门

### 身份闸门

- `trade_date` 合法
- `source_path` 存在
- 路径日期与目标日期一致

### 结构闸门

- `ladder_total_stocks >= 0`
- `ladder_highest_board >= 0`
- `ladder_structure_text` 不能为空串或伪造串

### 成交闸门

- `amount >= 0`
- `sector_main_net_amount` 保留原金额单位
- 单位不明时必须降级

### 时间闸门

- 交易日与自然日不可混用
- 历史 snapshot 不可冒充当日 snapshot
- fallback 仅限同交易日 raw

### A股语义闸门

- ST / 退市整理 / 停牌 / 除权除息语义未处理时，不得直接比较历史价格
- 指数、个股、板块数据不得混用
- 通用涨跌停价规则未坐实前，不得宣称已适配

### 判断闸门

- 判断字段不自动预填
- 看不到就留空
- 手工补写必须保留人工属性，不能回写成“自动事实”
