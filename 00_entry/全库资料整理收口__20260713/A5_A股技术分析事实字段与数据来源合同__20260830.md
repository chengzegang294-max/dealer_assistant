### L1｜原始事实

当前已能成立的重点：

- `turnover_rate` 的默认分母与默认变体

### L2｜标准化事实

当前允许冻结为合同规则：

- 统一 `trade_date=YYYYMMDD`
- `normalized_price_precision` 必须拆成原始保存精度、计算精度、展示精度、交易所最小价位四层
- 统一来源优先级
- 统一缺值状态
- 统一路径存在性检查

注意：

- 这些是**合同规则**，不是说所有原始字段已经齐全。
- `amount / pct_change / turnover_rate` 当前不得靠行业惯例直接统一成单一单位、尺度或分母。

### L3｜派生指标

本轮按 `TA-04` 正式裁决吸收后的口径冻结为：

- `SMA5(close_variant)`：允许保留为**变体族定义**
- `TRANGE`：允许保留为**冻结定义层**
- `ATR14_Wilder`：允许保留为**冻结定义层**
- `20日区间位置`：只允许保留为**内部启发式**
- `缺口类型`：只允许保留为**分层事实/变体族**
- `题材-板块对齐度候选`：只允许保留为**内部启发式**

本轮统一规则：

- 只冻结定义、变体族和依赖边界；
- 不新算指标；
- 上游价格链未落地前，`TR / ATR / SMA5 / gap` 一律不得写成已实施；
- 参数来源不明时写 `PARAMETER_UNRESOLVED`；
- FX 里的数学定义只能当数学参考，不能当 A股已适配证明。

## 5. 派生指标定义边界

派生指标本轮的统一边界：

1. `F031 TRANGE` 的公式定义冻结为：
   - `max(high-low, abs(high-prev_close), abs(low-prev_close))`
   - 但在上游 `high / low / prev_close` 变体未落地前，禁止实施。
2. `F032 ATR14_Wilder` 的公式定义冻结为：
   - `seed = 首 14 个有效 TR 的简单平均`
   - `ATR_t = (prev_ATR*13 + TR_t)/14`
   - 必须显式保留 `Wilder` 命名，且在上游价格链未落地前禁止实施。
3. `F030 SMA5` 必须写成 `SMA5(close_variant)`，不得默认前复权或不复权。
4. `F034 gap` 必须拆成：
   - 开盘相对昨收的事实层
   - 全天是否回补
   - 事后形态分类
   其中只有第一层允许进入事实候选。
5. `F033 range_position_20d` 与 `F035 sector_alignment` 只保留内部启发式，不得当作正式已实施指标。
6. 任何需要跨交易日的派生指标，必须先证明：
   - 交易日键稳定；
   - 来源日期一致；
   - 停牌与除权语义已处理。

一句话：

- 当前可以冻结定义层和变体边界，但不能把它们写成已经可稳定计算的正式产出。

## 6. 来源回退与冲突处理

### 6.1 回退规则

1. `sector`
   - 主来源：`sector_daily_snapshots`
   - 备用来源：当日 `batch_*_daily_close__/00_raw/sector_capital_flow_snapshot__{date}.json`
   - 回退后状态必须降级为：`SOURCE_CONFIRMED_WITH_LIMITATION` 或 `FALLBACK_ONLY`
2. `ladder`
   - 主来源：`ladder_day_min`
   - 备用来源：`ladder_day raw`
3. `P1 / workbench`
   - 只允许引用现有日文件
   - 文件不存在就写缺失，不补猜

### 6.2 明确禁止

1. 不允许跨交易日拼接冒充当日事实
2. 不允许用旧 snapshot 冒充当日 snapshot
3. 不允许把 live-room Raw/Draft 直接冒充事实
4. 不允许把 batch149 / 外部视频抬成当前正式来源

### 6.3 冲突处理

只要出现以下任一情况，必须显式记冲突，不能静默覆盖：

- 日期不同
- 名称不同
- 板块归属不同
- 最高板/连板结构不同
- 价格或金额口径不同

## 7. 数据质量闸门

### 身份闸门

- `trade_date` 合法
- `source_path` 存在
- 路径日期与目标日期一致

### 结构闸门

- `ladder_total_stocks >= 0`
- `ladder_highest_board >= 0`
- `ladder_structure_text` 不能为空串或伪造串

### 成交闸门

- `amount >= 0`
- `sector_main_net_amount` 保留原金额单位
- 单位不明时必须降级

### 时间闸门

- 交易日与自然日不可混用
- 历史 snapshot 不可冒充当日 snapshot
- fallback 仅限同交易日 raw

### A股语义闸门

- ST / 退市整理 / 停牌 / 除权除息语义未处理时，不得直接比较历史价格
- 指数、个股、板块数据不得混用
- 通用涨跌停价规则未坐实前，不得宣称已适配

### 判断闸门

- 判断字段不自动预填
- 看不到就留空
- 手工补写必须保留人工属性，不能回写成“自动事实”
