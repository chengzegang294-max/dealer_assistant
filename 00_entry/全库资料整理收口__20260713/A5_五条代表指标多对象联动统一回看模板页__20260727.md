# A5 五条代表指标多对象联动统一回看模板页

更新时间：2026-07-27

## 一、这页用途

- 本页只做：
  - 把五条代表指标进入多对象联动时的统一回看写法正式固定
  - 统一：
    - 先看什么
    - 后看什么
    - 用什么句式收口
  - 给后续联动分析页提供可直接复用的模板

- 本页不做：
  - 金融有效性证明
  - 回测阈值
  - 自动交易门禁

## 二、当前统一回看顺序

- 当前正式顺序冻结为：
  1. 先看
     `背景型对象`
  2. 再看
     `触发型对象`
  3. 最后决定：
     - `先降权`
     - `先降级职责`
     - `回观察位`
     - `退出原解释`

- 当前不推荐的写法是：
  - 一上来只盯着
    `打板资金 / 上榜资金`
    局部还亮不亮，
    完全不先看背景

## 三、当前统一回看模板

### 3.1 第一步：先看背景怎么坏

- 当前要先回答：
  1. `HYDB行业对比`
     有没有出现
     `背景背离 / 结构破坏`
  2. `ZSDB指数对比`
     有没有出现
     `顺逆风切换 / 波动失控`
  3. `沪深涨跌停`
     有没有出现
     `宽度转弱 / 强度衰减`

- 当前标准句式：
  - `当前先看到背景侧开始失真：行业 / 指数 / 市场宽度中，哪一层已经不再支持原解释。`

### 3.2 第二步：再看触发怎么退

- 当前要再回答：
  1. `打板资金`
     当前是
     `波动失控`
     还是
     `事件退潮`
  2. `上榜资金`
     当前是
     `事件退潮`
     还是
     `强度衰减`

- 当前标准句式：
  - `在背景已经转弱之后，触发侧当前是延续不稳、事件退潮，还是标签强度已经不够继续承担原职责。`

### 3.3 第三步：最后决定动作升级

- 当前统一判断顺序：
  1. 若只是支持减弱，
     先
     `降权`
  2. 若解释还能讲但不再配原职责，
     先
     `降级职责`
  3. 若污染明显上升，
     `回观察位`
  4. 若原前提被打掉，
     `退出原解释`

- 当前标准句式：
  - `当前最合适的处理不是直接改写成结论，而是按降权 / 降级职责 / 回观察位 / 退出原解释的顺序逐层升级。`

## 四、当前三类最常见联动写法

### 4.1 背景先坏，触发后退

- 当前适用情形：
  - 背景型对象先出现
    `背景背离`
    或
    `结构破坏`
  - 触发型对象随后出现
    `事件退潮`
    或
    `强度衰减`

- 当前模板：
  - `当前先是背景不再支持原解释，随后触发侧也开始退潮；因此先退一层职责或回观察位，不再继续按原逻辑推进。`

### 4.2 触发先乱，背景也脏

- 当前适用情形：
  - `打板资金`
    与
    `ZSDB指数对比`
    同时出现
    `波动失控`

- 当前模板：
  - `当前不是单点问题，而是触发节奏已乱、背景噪音也在上升；因此先降权，必要时整体回观察位。`

### 4.3 背景已破，局部亮点只留观察价值

- 当前适用情形：
  - `HYDB`
    已出现
    `结构破坏`
  - 但局部触发对象仍有残余亮点

- 当前模板：
  - `当前背景前提已经被打掉，局部亮点不再单独撑住原解释；因此退出原解释，只保留局部观察价值。`

## 五、当前推荐输出骨架

- 后续若写多对象联动回看，
  当前统一骨架写成：

1. `背景先发生了什么`
2. `触发随后发生了什么`
3. `当前最合适的动作升级是什么`
4. `哪些仍保留 still_need_evidence`

- 当前不建议跳过第 1 步，
  直接从第 2 步开始写

## 六、当前一句最小模板

- 当前可以直接复用的一句话模板是：
  - `当前先看背景侧是否还支持原解释，再看触发侧是否还值得继续被信；若只是支持减弱则降权，若不再配原职责则降级职责，若污染明显则回观察位，只有前提被打掉时才退出原解释。`

## 七、主负责人裁决

- 当前正式裁决为：
  1. 多对象联动统一回看模板正式开启
  2. 当前后续再写五条对象联动时，
     一律先按这张模板走
  3. 当前下一手不再回头扩对象池，
     而是更适合补：
     `多对象联动样例页`

## 八、当前 still_need_evidence

- 当前继续保留：
  1. 哪几组联动最值得先举真实样例，
     仍待下一手判断
  2. 当前模板页，
     仍然不是金融有效性结论
  3. 若后续进入样例层，
     仍需保持
     `still_need_evidence`
     标注

## 九、一句话口径

- 当前五条代表指标已经从“各自细化”推进到“联动回看模板”：
  先看背景怎么坏，
  再看触发怎么退，
  最后才决定
  `降权 / 降级职责 / 观察 / 退出`
  的升级顺序。
