## 一、这页只回答一个问题

- 直播间首轮精简，为什么先动 `C / D` 桶，以及具体怎么动。

## 二、当前一句话原则

- `A` 先保
- `B` 再看
- `C` 先降
- `D` 基本只留评分

也就是说：

- 现在不是先去争 `A` 桶里谁最强
- 而是先把最不值钱、最容易降的部分先收掉

## 三、为什么先处理 C / D

原因很简单：

1. 风险最低
   - 先动 `C / D`，最不容易误伤真正高价值房

2. 收视野最快
   - 当前房间已经很多
   - 先把低价值和低必要性的房间降下来，后面看盘面会清爽很多

3. 不和主线打架
   - `A / B` 还涉及更细的人审与连板天梯重叠判断
   - `C / D` 先动，不会卡住主线

## 四、C 桶怎么处理

`C_downgrade` 的真实含义不是“现在就删掉”。

它的意思是：

- 后续不再全文常更
- 默认降成：
  - 摘要保留
  - 偶发抽检
  - 或只保关键片段

### C 桶当前建议动作

#### 1. 模板房 / 已抓够房

例如：

- `孙悟空金牌`

处理建议：

- 不再把它当全文常更房
- 只留：
  - 房间评分
  - 必要锚点
  - 少量代表性片段

#### 2. 轻量历史、旧 tier 本就偏低的房

例如：

- `上海老梁`
- `七龙珠`
- `兄安`

处理建议：

- 先降成 `summary_only`
- 不继续追求全文扩档
- 后续若某阶段突然出现明显独特价值，再单独升回观察

#### 3. 轻量历史、偶发抽检型房

例如：

- `浮光`
- `大师兄擒妖`

处理建议：

- 保房间卡
- 保极短摘要
- 后续只做低频抽检

## 五、D 桶怎么处理

`D_score_only_or_archive` 的意思更直白：

- 基本不值得继续背全文历史包袱
- 只留最小评分记录即可

### D 桶当前建议动作

例如：

- `招财大师姐`

处理建议：

- 保：
  - 房间名
  - 最小评分字段
  - 一句原因
- 不保：
  - 全文常更
  - 大段原文沉淀

## 六、当前建议的保留动作翻译成人话

### `keep_fragments`

- 保留有价值片段
- 不等于保全文

### `summary_only`

- 只留摘要
- 不继续长期背原文

### `score_only`

- 只留评分和结论
- 原文不作为重点资产

### `archive_candidate`

- 进入待归档 / 待边缘化队列
- 不再占主视野

## 八、现在不要做什么

这一轮先不要：

1. 直接删房
2. 直接删 runtime 原始证据
3. 对 `A / B` 桶下最终死结论
4. 把“保房”误解成“保全文”

2. 把每个房的 `retention_action` 填上
3. 再回头处理 `B` 桶
4. 最后才精修 `A` 桶
