# A5 A股 P0 首页工作台 Batch1 组件入参收口页

更新时间：2026-07-21

## 一、这页用途

- 本页只做：
  - 冻结 `A股 P0 Batch1` 当前对首页组件入参继续收口的口径
  - 说明为什么当前最值钱的一步是把页面层散传 props 收成 section-level contract
  - 写死本轮允许收紧与不允许扩展的边界
- 本页不做：
  - 重开产品方向
  - 重开字段合同
  - 新功能扩展
  - 新页面跳转协议

## 二、当前主线与当前不是

- 当前主线：
  - `A股 P0 Batch1` 首页工作台实现线
- 当前不是：
  - `batch_149` 新吸收线
  - 新功能线
  - 技术栈与多市场讨论

## 三、为什么这一手最值钱

- 到当前为止：
  - 页面级 hook
  - workspace 状态机
  - adapter 分层
  - 首页级 view model 汇总入口
  都已经形成。
- 但页面层仍然在：
  - 一项项把 `searchDraft / searchActionEcho / onOpenStockPage`
  - `selectedEventSummaryViewModel / explanationCardViewModel / decisionRecordFormViewModel`
  - `viewModel + onSelectEvent`
  这类字段继续散传给下层组件。
- 这会让页面壳虽然更薄，但 props 面仍偏宽，不利于后续维持清晰的 section contract。

## 四、本轮允许继续收口的范围

- 允许继续收口：
  - `EventStreamPanel` 页面入参
  - `StockSearchBar` 页面入参
  - `MainWorkspacePanel` 页面入参
  - `HomeSidebar` 页面入参
- 允许新增：
  - section-level props object
  - 页面级 props 打包结构
- 不允许借机扩展：
  - 新状态字段
  - 新业务逻辑
  - 新 UI 能力
  - 新数据协议

## 五、当前目标边界

- `Home.tsx`
  - 只做布局与 section 组件拼装
- `useHomePage`
  - 负责把页面所需字段收成 section-level props
- section 组件
  - 可以继续内部持有细粒度 props
  - 但页面层不再一项项散传

## 六、本轮停止规则

- 满足以下四项即可视为这一小段收口：
  1. 页面层对至少 3 个 section 改为整包传 props
  2. `Home.tsx` 明显减少散传字段
  3. `npm run build` 通过
  4. `npm run lint` 通过

## 七、下一手
