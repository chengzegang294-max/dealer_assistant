## 三、优化目标（先四房）

1. **抓住核心正文**：去掉引流壳，优先最长实质段落
2. **抗混标签**：短漂移名（`k神`/`先知`/`浮光`）降权；优先模板房名单
3. **粘连卡可拆**：超长卡按日期时间边界拆成多条
4. **可强制纠偏**：支持 `forced_room_anchor`，置顶名单未冻结前先人工保底
5. **留存可验收**：导出 `export_version` 升版，heuristics 记下是否启用剥离/拆分

## 五、核心规则（冻结）

### 5.1 正文

1. 叶子文本先滤 UI 壳，再滤广告壳：
   - `更多资讯加微信好友…`
   - `防止失联QQ群…`
   - 纯表情标签（捂脸等）
2. 多叶子时：优先最长实质段；短广告段不进正文
3. 叶子几乎全是广告时：回退 `card.innerText` 并剥离广告碎片；仍只剩短广告则丢弃该卡
4. 单卡文本过长（≥600）且含 ≥2 个日期时间戳：按时间边界拆成多条留存

### 5.2 房间锚点

优先级：

1. `forced_room_anchor`（人工指定）
2. 说话人别名（`至尊宝→孙悟空金牌`，`陈子瞻→龙头交易猿`）
3. 侧栏/标题已命中优先房（格兰/女王/天机/龙头/孙悟空）→ **不让混标签覆盖**
4. 正文 `#房间名#`（降权漂移名；优先名单加权）
5. 其余回退

房间名归一：

- `天机短线试更新` → `天机`
- `周期女王（新一期…）` / `周期女王…` → `周期女王`

### 5.3 侧栏选取

- 不再「越短越好」硬规则
- `active/selected` + 优先房加分；`k神/先知/浮光/知行合一` 减分

## 七、复跑口令（四房验收）

每房：

```js
// 可选：侧栏仍飘时强制
window.__infoLiveCurrentPageExportV1Options = {
  forced_room_anchor: "周期女王" // 或 格兰投研 / 天机 / 龙头交易猿
};
// 1) 粘贴 live_info_current_page_export_v1.js（确认 console 为 v1.5）
window.__infoLiveIncrementalExportV1Options = {
  reset_checkpoint: true,
  scroll_direction: "up",
  start_position: "keep",
  max_rounds: 80,
  forced_room_anchor: "周期女王" // 与上保持一致
};
// 2) 粘贴 live_info_incremental_export_v1.js（确认 console 为 v1.3）
```

### 验收清单

1. `export_version` = `..._v1.5` / 增量 `..._v1.3`
2. `room_anchor` = 目标正式名（或你 forced 的名）
3. `excerpt` / `visible_messages[].text` **不是**单独一句微信引流
4. 龙头：可见 `陈子瞻` 前缀正文，房间仍为 `龙头交易猿`
5. 天机：若页面上肉眼有市场正文，导出里应出现非广告核心；若 DOM 真无正文只剩广告，记「图片/外链型」另案，不硬编
6. JSON 仍回落到 `batch_05/.../priority_rooms/<房间>/`
