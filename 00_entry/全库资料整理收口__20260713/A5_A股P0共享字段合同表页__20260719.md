# A5 A股 P0 共享字段合同表页

更新时间：2026-07-19

## 一、用途

- 本页只做：
  - 把当前
    `A股 P0`
    跨组件、跨页面会共用的字段收成一张统一合同表
- 本页不做：
  - 数据库建模
  - 接口实现
  - 新页面设计

## 二、字段分组

- 当前共享字段固定分为：
  1. `事件字段组`
  2. `解释字段组`
  3. `记录草稿字段组`
  4. `记录成稿字段组`
  5. `补充记录字段组`
  6. `问答上下文字段组`
  7. `金融披露字段组`

## 三、事件字段组

- `eventId`
  - 角色：事件主键
  - 必填：`yes`
  - 消费组件：`EventCard / SelectedEventSummaryBar / CurrentExplanationPanel / RecentDecisionPanel / QaContextBar`
- `title`
  - 角色：事件标题
  - 必填：`yes`
  - 消费组件：`EventCard / ExplanationCard / QaAnswerDisplay`
  - 同源规则：解释侧若复用 `title`，必须与当前 `eventId` 对应事件标题一致
- `subject`
  - 角色：触发对象
  - 必填：`yes`
  - 消费组件：`EventCard / SelectedEventSummaryBar / StockHeaderSummary`
- `occurredAt`
  - 角色：触发时间
  - 必填：`yes`
  - 消费组件：`EventCard / SelectedEventSummaryBar / CurrentExplanationPanel`
- `holdingRelation`
  - 角色：与持仓关系
  - 必填：`yes`
  - 消费组件：`EventCard / SelectedEventSummaryBar`
- `processStatus`
  - 角色：已处理/未处理状态
  - 必填：`yes`
  - 消费组件：`EventCard / DecisionSubmitEcho / HistoryTracePanel`

## 四、解释字段组

- `logic`
  - 角色：触发逻辑
  - 必填：`yes`
  - 消费组件：`ExplanationCard / CurrentExplanationPanel / QaAnswerDisplay`
- `impact`
  - 角色：影响推演
  - 必填：`yes`
  - 消费组件：`ExplanationCard / QaAnswerDisplay`
- `historyAnalogy`
  - 角色：历史类比
  - 必填：`no`
  - 消费组件：`ExplanationCard / QaAnswerDisplay`
- `nextReviewPoint`
  - 角色：下一次复查点
  - 必填：`no`
  - 消费组件：`ExplanationCard / QaRecommendedQuestionGroups`

## 五、记录草稿字段组

- `eventId`
  - 角色：草稿绑定的事件
  - 必填：`yes`
  - 消费组件：`DecisionRecordForm`
- `action`
  - 角色：草稿动作
  - 必填：`yes`
  - 消费组件：`DecisionRecordForm`
- `reasonTag`
  - 角色：草稿理由标签
  - 必填：`yes`
  - 消费组件：`DecisionRecordForm`
- `horizon`
  - 角色：草稿预期周期
  - 必填：`yes`
  - 消费组件：`DecisionRecordForm`
- `note`
  - 角色：草稿备注
  - 必填：`no`
  - 消费组件：`DecisionRecordForm`

## 六、记录成稿字段组

## 十、命名一致性规则

- 当前统一使用：
  - `eventId`
  - 不再混写
    `id / event_id / current_event_id`
- 当前统一使用：
  - `reasonTag`
  - 不再混写
    `reason / label / tag`
- 当前统一使用：
  - `horizon`
  - 不再混写
    `period / expectation_window`
- 当前统一使用：
  - `supplementCreatedAt`
  - 不再混写
    `createdAt / supplement_created_at`
- 当前正式区分：
  - `DecisionRecordDraft`
  - `DecisionRecord`
  - 不再混用一套必填口径

## 十一、禁止项

- 当前不允许：
  - 同一字段在不同页改名但含义不变
  - 把页面展示别名误当成接口字段名
  - 漏掉金融披露字段却照常出卡或出答案
  - 把 `decisionId` 当成草稿态必填
  - 让问答上下文脱离金融披露字段

## 十二、通过标准

- 当前通过标准是：
  - 实现侧能依据本页知道：
    - 哪些字段必须跨页共享
    - 哪些字段是可选补充
    - 哪些组件必须消费这些字段
    - 同名字段不能再漂移

## 十三、停止规则

- 当前写清以下内容后即停：
  - 七组共享字段
  - 每组字段角色
  - 必填与消费组件
  - 命名一致性规则
