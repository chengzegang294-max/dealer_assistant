# A股 P0 离线验证执行卡

更新时间：2026-07-12

## 用途

- 把 `T01 ~ T05` 的首轮离线验证从“准备齐了”推进到“可以按步骤开跑”。
- 固定本轮验证顺序、每一步的输入依赖、执行动作、产出和停点。
- 避免真正开始跑时，又回到“先做哪个、做到什么算一轮结束”的临场决策。

## 使用边界

- 当前只适用于 A 股 P0 首轮离线验证。
- 当前不适用于：
  - 正式回测
  - 多市场统一扫描
  - 线上实时监控

## 本轮目标

- 先完成 `T01`、`T02`、`T04`、`T05` 的首轮离线验证。
- `T03` 只先做可得性判断与降级路径，不强行依赖一致预期字段开跑。
- 本轮目标不是得出完美参数，而是先判断：
  - 哪些口径可保留
  - 哪些需要微调
  - 哪些必须降级
  - 哪些应暂缓

## 执行前检查

1. 确认已具备：
   - `A股_P0_首轮数据字段清单__20260712.md`
   - `A股_P0_首轮样本范围与抽样口径__20260712.md`
   - `A股_P0_离线验证输出模板__20260712.md`
2. 确认主合同与验证任务单口径一致
3. 确认本轮不扩展到新事件类型
4. 确认结果只输出到首轮验证资产，不污染主合同
5. 若引用 `趋势仓位 / 轮动仓位`，只把它当桥接参考：
   - `00_entry/A股_P0_趋势仓位与轮动仓位桥接卡__20260712.md`

## 推荐执行顺序

### Step 1: 跑 T01 量价阈值触发密度

- 输入依赖：
  - 日线行情字段
  - 量能字段
  - 行业映射字段
- 执行动作：
  - 用固定口径扫描近 `12` 个月样本
  - 统计日均、高峰、中位触发密度
  - 抽样复核极多、极少、典型交易日
- 产出：
  - `T01` 单项结果页
  - 触发密度摘要
- 当前停点：
  - 能判断当前阈值是偏吵、偏静还是基本可用
- 桥接备注：
  - 当前只给趋势仓位提供市场强弱背景，不直接输出仓位上限

### Step 2: 跑 T02 主力资金主触发

- 输入依赖：
  - 主力资金字段
  - 北向资金字段
  - 市场阶段分段
- 当前前置检查：
  - 先跑 `02_runtime/ashare_p0_first_round_validation/check_t02_tushare_env_v1.py`
  - 若 `TUSHARE_TOKEN` 缺失或 `tushare` 未安装，则先补环境，不继续把模板级结果误当真实判断
- 执行动作：
  - 按 `普涨 / 普跌 / 震荡` 三类阶段分段统计
  - 比较主力资金与北向资金的主触发/增强标签表现
  - 观察融资融券纳入时是否显著增噪
- 产出：
  - `T02` 单项结果页
  - 主触发与增强标签职责建议
- 当前停点：
  - 能回答“主力主触发、北向增强、融资融券排除”是否站得住

### Step 3: 跑 T04 行业轮动阈值敏感度

- 输入依赖：
  - 行业映射字段
  - 行业指数字段
  - 大盘基准字段
  - 成交活跃度字段
- 执行动作：
  - 对普涨、普跌、震荡样本分别统计
  - 抽样看行业伪触发
  - 判断是否能提供持仓解释增量
- 产出：
  - `T04` 单项结果页
  - 伪触发样例
- 当前停点：
  - 能判断该事件是否值得保留当前灵敏度
- 桥接备注：
  - 当前是轮动仓位桥接口径的直接前置验证项

### Step 4: 跑 T05 历史类比样本门槛

- 输入依赖：
  - 行业映射字段
  - 事件类型字段
  - 样本窗口统计
- 执行动作：
  - 分 `6` 类事件统计行业样本量分布
  - 比较 `N=3 / 5 / 8`
  - 看 `N=5` 是否过松或过紧
- 产出：
  - `T05` 单项结果页
  - 样本门槛建议
- 当前停点：
  - 能判断当前 `N=5` 是否保留
- 桥接备注：
  - 当前结果将决定趋势/轮动类比展示是否值得保留

### Step 5: 跑 T03 业绩事件可得性与降级

- 输入依赖：
  - 业绩事件字段
  - 一致预期可得性说明
- 执行动作：
  - 先盘点一致预期字段是否稳定可得
  - 若不可得，直接验证同比显著变化降级路径
- 产出：
  - `T03` 单项结果页
  - 降级建议
- 当前停点：
  - 能回答业绩事件是否应以降级形态进入首轮
- 桥接备注：
  - 当前结果会决定业绩事件是否还能进入轮动解释链

## 每步必须产出

- 一张单项验证结果页
- 一段抽样观察
- 一个结论标签：
  - `保留 / 微调 / 降级 / 暂缓`
- 一个下一步动作

## 本轮结束条件

- `T01`、`T02`、`T04`、`T05` 至少完成首轮结果页
- `T03` 至少完成可得性判断与降级建议
- 已能产出一张首轮汇总结论页

## 本轮禁止

- 不因为局部样本好看就修改主合同
- 不在本轮扩展到新字段大包
- 不在没有结果页时直接口头拍板
- 不把历史回收数据或临时截屏当正式结论
