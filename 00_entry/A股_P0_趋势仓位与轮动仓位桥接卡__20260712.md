# A股 P0 趋势仓位与轮动仓位桥接卡

更新时间：2026-07-12

## 用途

- 把资料库里的“趋势仓位 / 轮动仓位”想法接到 `A股 P0` 当前验证链。
- 当前只做桥接，不把这张卡直接当成默认执行合同。

## 当前主负责人裁决

- `趋势仓位`
  - 只保留 `regime -> 仓位上限` 的桥接口径
- `轮动仓位`
  - 只保留 `行业集中 / 分散 + 行业暴露上限` 的桥接口径
- 当前明确不直接升级为：
  - 默认仓位引擎
  - 默认行业配置引擎

## 趋势仓位桥接口径

- `ATTACK_SUSTAINED = 1.0`
- `ATTACK_CONFIRMED = 0.7`
- `POWER_TRANSITION = 0.3`
- `GESTATION = 0.3`
- `REMAINING_WARMTH / ATTACK_UNSUSTAINED / CUTTING_COMPLETE = 0.0`

## 轮动仓位桥接口径

- 当 `行业集中`：
  - 单行业上限 `20%`
- 当 `行业分散`：
  - 至少 `3` 个行业

## 角色边界

- 趋势仓位更像：
  - 总仓位上限解释层
  - 风险预算层
- 轮动仓位更像：
  - 行业暴露解释层
  - 配置约束层
- 二者当前都不是：
  - 默认硬门控
  - 自动执行脚本

## 当前可量化字段

- 趋势仓位：
  - `regime_state`
  - `position_cap_total`
  - `single_position_cap`
  - `position_budget_note`
- 轮动仓位：
  - `rotation_state`
  - `industry_concentration_mode`
  - `industry_cap`
  - `min_industry_count`
  - `rotation_note`
