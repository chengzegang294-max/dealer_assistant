# Tooling Runtime Archive

## 用途

- 这里放从旧 `12_工具运行时_TOOLING_RUNTIME` 中筛选后迁入的历史运行时材料。
- 这里不是旧运行时层的整包镜像。

## 迁入原则

- 活跃对象当前真正运行的最小集，优先进入 `02_runtime`
- 历史复现材料、说明卡、旧样本、旧探针，按批次筛入本层
- 只迁仍有证据或追溯价值的材料

## 当前批次

- `batch_01_selected`
  - `cross_line_frozen` 最小冻结链
- `batch_02_mt_indicator_family`
  - `MT` 指标家族最小工程集
- `batch_03_mt4_portable_probe_templates`
  - `MT4` 便携探针最小文本配置模板
- `BATCH_02_ACCEPTANCE_CHECK.md`
  - `MT` 指标家族批次的文件集合与哈希校验
- `BATCH_03_TEMPLATE_ACCEPTANCE_CHECK.md`
  - `MT4` 便携模板批次的字段裁剪校验

## 不直接迁入

- 整包旧运行时目录
- 与当前对象无关的历史试验目录
- 无职责说明的散乱临时文件
