## 4. 为什么这些文件不能乱搬

### 4.1 活跃入口脚本

- 这些文件在主文档、命令示例、研究记录中被反复直接引用。
- 当前使用方式就是：
  - `python .\backtest_p0.py ...`
  - `python .\ashare_preprocess.py ...`
  - `.\mt5_daily_ops.ps1 -Mode ...`
- 直接搬走会造成：
  - 文档命令失效
  - 旧记录断链
  - 外部复现口径漂移

### 4.2 配置锚点

- `pyrightconfig.json` 与 `basedpyrightconfig.json` 默认就依赖根目录位置。
- 这类文件不以“整齐”为目标，优先保证 IDE 与工具链稳定。

### 4.3 说明文档与辅助索引

- 这类文件可以开始从根目录迁到 `docs/`。
- 但为避免旧引用断掉，根目录应保留轻量入口或兼容说明。

## 5. 当前建议的根目录保留原则

- 根目录只留四类东西：
  - 四份活跃主文档 + 临时粘贴区
  - 活跃入口脚本
  - 配置锚点
  - 少量兼容入口
- 其他说明性文档、索引、一次性辅助脚本，逐步迁到：
  - `docs/`
  - `tools/`
  - 或冻结层
