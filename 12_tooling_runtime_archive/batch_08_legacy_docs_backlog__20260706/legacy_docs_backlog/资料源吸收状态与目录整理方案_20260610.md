## 1. 结论先行

- “单字段阶段已完成”只代表当前可量化单字段在既有口径下已收口。
- 它不代表来源库已经逐目录、逐文件全部吃透。
- 当前仓库已经按方案 B 做了半硬整理，来源库、冻结总结层、工具运行时、活跃主文档已正式分开。
- 用户当前选择的路线是：先做全量扫库，再进入稳定候选组合优化。

## 2. 本次整理后的统一口径

### 2.1 四类资产

- `SOURCE_LIBRARY`
  - 位置：`10_来源库_SOURCE_LIBRARY`
  - 含义：来源资料、规则壳、原子规则、未完全量化内容
- `FROZEN_SUMMARIES`
  - 位置：`11_冻结总结层_FROZEN_SUMMARIES`
  - 含义：冻结备份、历史总结层、不可直接视为 backlog
- `TOOLING_AND_RUNTIME`
  - 位置：`12_工具运行时_TOOLING_RUNTIME`
  - 含义：MT 指标源码、探针、运行时实例、历史归档、兼容副本
- `ACTIVE_MAIN_DOCS`
  - 位置：仓库根目录
  - 含义：当前工作唯一持续更新的主文档入口

### 2.2 量化 vs 未量化

- 已量化且已讨论：进入字段角色体系。
- 未量化但后续可能量化：保留在 `SOURCE_LIBRARY`，等待明确重开。
- 当前数据口径不适配：转入 future bucket。
- 工具/探针/历史实例：归入 `TOOLING_AND_RUNTIME`，不计入“待讨论指标 backlog”。
