## 📚 四大核心概念详解

**时间段**: 06:05 - 12:51

![章节截图 06:05](https://asset.localhost/C%3A%5CUsers%5C91883%5CAppData%5CLocal%5Cco.bibigpt.desktop%5Cscreenshots%5Cvideo_11484140865024647085%5Cscreenshot_365.6s.jpg)

共振我们大家都已经知道了，共振所谓的共振就是两组指标，就是短的、长的两组指标的共振，在高位或者在低位重合就叫做共振。如就是说共振了以后，基本上大概率的会发生，也就百分之八九十以上的概率会发生价格运动的逆转，就是他级别的价格运动逆转。

如果是三组指标在高位或者低位共振，那么他们逆转以后的空间将会比两组指标的空间要来的大很多，时间也长很多。

给大家讲清楚什么叫背离。背离就是说什么，就是说价格运动的顶部比高，但是它指标的顶部比低，所以就造成了所谓的背离。大家看大黄线，就是粗的白黄线，就是属于背离现象。因为是周线，周线属于季线指标了，非常难得的，就是说它的运行非常的慢，所以我就给大家讲讲背离就难讲一些。

大家来看，这都是季线、半日线的，你看所谓的背离，大家可以看到红蓝线，你看半日线和那个啥都在往下，但价格往上，就是背离。背离了以后，它就会出现方向性的（转变）。你看这两组背离它还继续上涨，背了又背，在缠论里面说了什么，背了又背，它玩意儿就是背了又背，直到背了又背。为什么它不下跌？告诉大家，**就是因为只有大级别的指标组在稳健的上扬**，因为大级别的指标在拖着他们，使它无法下跌。当大级别指标和它发生共振的时候，他们就开始下跌了。

背离的概念讲完了，给大家讲什么叫离散。离散实际上就是说大级别指标和小级别指标在天上、在地下，或者在地下、在天上，而二者之间有一定的距离叫做离散，它呈一种概率分布的离散状态。

离散状态出现了以后，就有什么东西？它就有特别的功能，就是说大级别指标有一种就相当于地球的吸引力一样，它有要求小级别指标靠拢的这么一种要求。你比如说在位置，大家看，是周线、月线，周线和月线这俩离散大了，所以大级别指标就有吸引小级别指标往上靠拢的这种引力。所以大家把离散功能记住了以后非常关键。**离散概念基本上是我一手研究出来，并且使用得非常得心应手的概念**。

好了，下面还有概念叫做“完美”。什么叫完美？我们这里就讲了什么完美，完美就是说假如说大家看红蓝色的指标在这里，它的价格顶部在这里，现在指标红蓝线的指标在这里，它们的顶部也是在这里。它们二者之间没有背离现象，它是你高我也高，你低我也低，在这种情况下，它就属于一种完美状态。

这完美状态暗示着什么？暗示着后市还要继续新高。你比如说你看黄白线、季线指标，你看在地方高点的时候，它在这儿，在顶部的时候它越来越高了。我们根据指标走的这种情况，我们就会得出，**因为完美了以后必有新高，做出新高以后指标要做出背离它才会下跌**。

所以这里面的道理就在这里了。好了，我给大家讲了背离和什么东西，反正这些概念对我来说简直是太容易了。所以有些东西我讲起来觉得很容易，可能没有完完全全表达出来，大家还没有听懂，所以我讲的不是很到位，到时候大家提提意见，我会再补充一些相应的材料，好吧？大家看一看日线，日线就比那个周线它又来了……
