## 💎 核心总结与关键提醒

**时间段**: 23:54 - 31:25

![章节截图 23:54](https://asset.localhost/C%3A%5CUsers%5C91883%5CAppData%5CLocal%5Cco.bibigpt.desktop%5Cscreenshots%5Cvideo_15941272368380291298%5Cscreenshot_1434.1s.jpg)

大家来看，它已经反弹的空间已经远远大于这么长时间的上涨空间了。你说它还会下跌吗？它下跌也就是个调整，调整内部止浪再继续上。我在前面举过大量例子，就是说不要去想着去做空，做空是没有什么太大意义的。

给大家说明白了，一定大家要记住，道琼斯现在开始走的，还有就是澳元的现在的走势图形，给大家看现在的 ABC 小转大的图形。大家看，它已经完完全全走过了 0.618 了，它未来再下跌，它也不会再去做五浪了，不要去做那个梦了，没有意义了。大家看见它已经走了多少了，它已经反弹到 0.786 了，就反弹到了敏感位了。以后它可调整再继续往上，它再跌、再做东西、它再跌，我告诉大家，澳元它以后再跌它也是做 B 浪的走势了，它不会再做 C 浪了。

大家要记住，**小转大条件下的未来上涨是非常明确的**。大家心里面有个谱就好办了。给大家讲的例子，到了位置不要想着再去去做空了，我们要看大方向，它震荡就要往上了，这是非常关键的。

今天我给大家讲的所谓“小转大条件下的大赢二维时空波浪”，这属于一种特例，它出现的概率大概是 5% 到 10%。为什么它和那个普通行情不同？因为小转大之后，你看它内部没有什么止浪，它本身属于多头。多头基本上在这内部被套牢了，根本就没办法割肉出局。所以一旦时空转暖，也就是基本面转暖了以后，条件一成熟，它会发起强劲的反弹。反弹了以后，它不会因为基本面而再次出逃，它是基本面发生了变化才出现的图形。

大家不要完完全全被技术面、被传统理论的大概率事件给蒙蔽了双眼。**这种小概率事件照样会把很多人给忽悠得不得了，造成毁灭性的打击**。所以大家一定要记住，现在那个道琼斯，它的基本面本身没有发生变化。大家可以看到，道琼斯它是我们亲身经历了一段时间的，虽然流动性陷入困境，但它的基本面没有出现问题。所以在二月份、三月份的时候，主力做多的那些大基金、对冲基金统统被套住了。基本面不坏，在这种情况下，它就是要继续做多。

所以我认为大家在考虑问题的大方向上，犯了所谓的“惯性思维”错误，也是经验太少、复盘复得少造成的。很多没有做中长线经历的人，一般来说都会犯这种错误，他们思路已经被限制在短 C 浪的格局里面了。所以他们在长 C 浪大反弹的这种情况下，会因为技术考量欠缺或者经验不到位，导致出现判断失误。

今天给大家讲的所谓小转大条件下的大赢二维时空波浪分析技术就到这里。希望大家了解，虽然它在实战中间出现不多，因为是小概率事件，但大家也要注意避免犯错。**小概率事件如果应对失误，会导致你大概率的犯错，那是非常不值得的**。

大家记住，内部止浪的 0.618 是它多空牛熊的分水岭，这一点非常关键。掌握了这一点，以后的思路就不会发生根本性的方向错误了。好了，今天的课程就讲到这里，谢谢大家，再见。
