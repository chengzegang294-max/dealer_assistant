## 3) 期望总值（Expectunity）✅ 最终版

**DEFINITION_SENTENCE:** "在评估系统时，还有一个和期望值一样重要的可变因素，这一因素就是机会...游戏1：0.2R的期望值×60次机会=12R/小时 游戏2：0.78R的期望值×12次机会=9.36R/小时...因此，在任意施加了以上机会约束后，游戏1实际上要比游戏2还好。" + "你现在理解利润是期望总值或者说是期望收益乘以机会的结果了吗？"

**SOURCE_ANCHOR:** 
- 2(1).png / 第7章7.3"机会与期望值"节 / p.146
- 3-副本.png / 第13章13.2"期望总值：影响机会因素"节 / p.290

**STATE_AXIS_MAP:** 验真伪+摩擦轴

**FAILURE_MODES:**
- 只优化期望忽视交易频率
- 假设交易频率恒定

**FALSIFIABLE_TEST:** 期望×频率=期望总值；两系统年化期望总值差异显著(t-test)则频率因素占主导

**DO_NOT_DO:** 禁止在不考虑交易频率时比较系统优劣

## 8) 交易成本对期望的侵蚀 ✅ 最终版

**DEFINITION_SENTENCE:** "交易机会的成本...交易肯定需要成本。做市商必须要有赚头，经纪人也有其费用，而你的利润就是将这些成本都扣除之后所剩的部分。每笔交易的成本确实会构成期望收益等式中的一部分，而且它太重要了。"

**SOURCE_ANCHOR:** 3-副本.png / 第13章13.3"交易机会的成本"节 / p.292

**STATE_AXIS_MAP:** 摩擦轴

**FAILURE_MODES:**
- 忽视总成本累积效应（每笔小但频率高）
- 未将滑点/佣金/执行成本纳入期望

**FALSIFIABLE_TEST:** 净期望=毛期望-每笔成本×频率；净期望<0则系统不可交易

**DO_NOT_DO:** 禁止未扣除成本时声称正期望

## 10) 分布验证（原bootstrap降级为小额实盘验证）✅ 最终版

**DEFINITION_SENTENCE:** "在初次确定期望收益时，你可能受到很多偏见的影响，因此，现在需要通过进行小额的实时交易来确定R乘数分布的准确性。如果交易1~10股股票或一手商品合约会怎样？你会得到什么样的R乘数分布？它是否和你通过理论推导出来的或通过历史测试得出来的结果类似？"

**SOURCE_ANCHOR:** 1(1).png / 第4章4.10"确定R乘数分布的准确性"节 / p.66

**STATE_AXIS_MAP:** 验真伪

**FAILURE_MODES:**
- 用理论推导的R分布代替实际验证
- 历史回测的分布与未来真实分布差异大

**FALSIFIABLE_TEST:** 小额实盘30+笔R分布 vs 回测R分布；KS检验p<0.05则分布显著不同

**DO_NOT_DO:** 禁止用回测R分布直接替代实盘的R分布

## 13) 机会成本（资金占用）✅ 最终版

**DEFINITION_SENTENCE:** "一个期望值为0.5R（扣除交易成本之后），每周提供3次交易机会的系统要比每月提供一次交易机会期望值也为0.5R（同样也是在扣除交易成本之后）的交易系统优越得多。"

**SOURCE_ANCHOR:** 2(1).png / 第7章7.3节 / p.147

**补充锚点:** 3-副本.png / 第13章13.3节 / p.290表13-1：四位交易商的期望值对比（机会从0.05到500不等）

**STATE_AXIS_MAP:** 摩擦轴+风险轴

**FAILURE_MODES:**
- 低频系统占用资金过久
- 忽视不同系统的资金效率差异

**FALSIFIABLE_TEST:** 年化期望总值=期望×频率×平均R；年化差异显著(t-test)则频率因素占主导

**DO_NOT_DO:** 禁止在不比较年化期望总值时判断系统优劣
