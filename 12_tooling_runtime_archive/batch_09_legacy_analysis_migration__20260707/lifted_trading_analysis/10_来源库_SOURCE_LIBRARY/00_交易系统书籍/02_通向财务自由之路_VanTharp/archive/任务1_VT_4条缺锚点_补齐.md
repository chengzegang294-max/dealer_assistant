## 3) 期望总值（Expectunity）✅ 补齐

**DEFINITION_SENTENCE:** "在评估系统时，还有一个和期望值一样重要的可变因素，这一因素就是机会...游戏1：0.2R的期望值×60次机会=12R/小时 游戏2：0.78R的期望值×12次机会=9.36R/小时...因此，在任意施加了以上机会约束后，游戏1实际上要比游戏2还好。而在对市场交易进行评价时，也必须对系统可以向你展示的机会次数给予类似的考虑。"

**SOURCE_ANCHOR:** 2(1).png / 第7章7.3"机会与期望值"节 / p.146

**补充锚点:** 3-副本.png / 第13章13.2"期望总值：影响机会因素"节 / p.290-291："你现在理解利润是期望总值或者说是期望收益乘以机会的结果了吗？结果是你所考察的时段内产生的总的平均R利润。"

**STATE_AXIS_MAP:** 验真伪+摩擦轴

**FAILURE_MODES:**
- 只优化期望忽视交易频率（高期望低频系统长期收益可能不如低期望高频系统）
- 假设交易频率恒定（实际受市场状态影响）

**FALSIFIABLE_TEST:** 系统A（高期望低频）vs系统B（低期望高频）比较年化收益分布：期望0.78R×12次/月=9.36R vs期望0.2R×60次/月=12R，若前者<后者则频率因素>期望因素

**DO_NOT_DO:** 禁止在不考虑交易频率的情况下比较两个系统的"优劣"

## 8) 交易成本对期望的侵蚀 ✅ 补齐

**DEFINITION_SENTENCE:** "交易机会的成本...交易肯定需要成本。做市商必须要有赚头，经纪人也有其费用，而你的利润就是将这些成本都扣除之后所剩的部分。每笔交易的成本确实会构成期望收益等式中的一部分，而且它太重要了...一笔交易的成本确实会构成期望收益等式中的一部分。"

**SOURCE_ANCHOR:** 3-副本.png / 第13章13.3"交易机会的成本"节 / p.292

**STATE_AXIS_MAP:** 摩擦轴

**FAILURE_MODES:**
- 忽视总成本的累积效应（每笔小但频率高）
- 未将滑点/佣金/执行成本纳入期望计算

**FALSIFIABLE_TEST:** 净期望=毛期望-每笔成本×交易频率；净期望<0则系统不可交易

**DO_NOT_DO:** 禁止在未扣除所有成本时声称系统"有正期望"

## 10) 样本量与分布准确性（原"bootstrap"降级）✅ 补齐

**DEFINITION_SENTENCE:** "在初次确定期望收益时，你可能受到很多偏见的影响，因此，现在需要通过进行小额的实时交易来确定R乘数分布的准确性。如果交易1~10股股票或一手商品合约会怎样？你会得到什么样的R乘数分布？它是否和你通过理论推导出来的或通过历史测试得出来的结果类似？"

**SOURCE_ANCHOR:** 1(1).png / 第4章4.10"确定R乘数分布的准确性"节 / p.66-67

**NOTE:** 撒普此处用的是"小额实时交易验证法"而非统计bootstrap，精神相同——用独立样本验证分布。我将其记录为"小样本验证"而非严格bootstrap。

**STATE_AXIS_MAP:** 验真伪

**FAILURE_MODES:**
- 用理论推导的R分布代替实际验证
- 历史回测的分布与未来真实分布差异大

**FALSIFIABLE_TEST:** 小额实盘30+笔的R乘数分布 vs 回测R分布；若二样本KS检验p<0.05则分布显著不同，回测不可信

**DO_NOT_DO:** 禁止用回测R分布直接替代实盘的R分布

## 13) 机会成本（资金占用）✅ 补齐

**DEFINITION_SENTENCE:** "一个期望值为0.5R（扣除交易成本之后），每周提供3次交易机会的系统要比每月提供一次交易机会期望值也为0.5R（同样也是在扣除交易成本之后）的交易系统优越得多...市场往往会根据在其中运作的人的特点而改变。"

**SOURCE_ANCHOR:** 2(1).png / 第7章7.3节 / p.147

**补充锚点:** 3-副本.png / 第13章13.3节 / p.290表13-1：交易商1（机会0.05/期望总值2.58R）vs交易商4（机会500/期望总值0.03R）

**STATE_AXIS_MAP:** 摩擦轴+风险轴

**FAILURE_MODES:**
- 低频系统占用资金过久（机会成本）
- 忽视不同系统的资金效率差异

**FALSIFIABLE_TEST:** 年化期望总值=期望×频率×平均R；若两个系统年化差异显著（t-test）则频率因素占主导

**DO_NOT_DO:** 禁止在不比较年化期望总值时判断系统优劣
