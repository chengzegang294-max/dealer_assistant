### #3 期望总值（Expectunity）— 补齐 ✅

**DEFINITION_SENTENCE:** "在评估系统时，还有一个和期望值一样重要的可变因素，这一因素就是机会，即第四个可变因素。你玩游戏的频率如何？假如，游戏1或者游戏2你都可以玩，不过，游戏2只允许你每5分钟取出一个球，而游戏1允许你每分钟取出一个球，在这种情形下，你愿意玩哪一个？游戏1：0.2R的期望值×60次机会=12R/小时；游戏2：0.78R的期望值×12次机会=9.36R/小时。因此，在任意施加了以上机会约束后，游戏1实际上要比游戏2还好。"

**SOURCE_ANCHOR:** index-171_1.png ~ index-174_1.png（待截）/ 第7章7.3"机会与期望值"节 / p.146-147；当前证据：2(1).png

**STATE_AXIS_MAP:** 验真伪+摩擦轴

**FAILURE_MODES:**
- 只优化期望忽视交易频率
- 假设交易频率恒定

**FALSIFIABLE_TEST:** 期望×频率=期望总值；两系统年化期望总值差异显著(t-test)则频率因素占主导

**DO_NOT_DO:** 禁止在不考虑交易频率时比较系统优劣

### #8 交易成本对期望的侵蚀 — 补齐 ✅

**DEFINITION_SENTENCE:** "交易肯定需要成本。做市商必须要有赚头，经纪人也有其费用，而你的利润就是将这些成本都扣除之后所剩的部分。每笔交易的成本确实会构成期望收益等式中的一部分，而且它太重要了...交易机会的成本...你所做的交易越少，每笔交易所涉及的成本就越不会成为一个因素。很多长期趋势跟踪交易商很少花费时间考虑他们的交易成本问题，因为与其能获得的潜在利润相比，这是微不足道的。"

**SOURCE_ANCHOR:** 
- 主锚点：index-167_1.png ~ index-169_1.png（待截）/ 第7章"交易成本"小节 / p.~144-146
- 补充锚点：index-291_1.png ~ index-293_1.png（待截）/ 第13章13.3"交易机会的成本"节 / p.291-293；当前证据：3-副本.png

**STATE_AXIS_MAP:** 摩擦轴

**FAILURE_MODES:**
- 忽视总成本累积效应（每笔小但频率高）
- 未将滑点/佣金/执行成本纳入期望

**FALSIFIABLE_TEST:** 净期望=毛期望-每笔成本×频率；净期望<0则系统不可交易

**DO_NOT_DO:** 禁止未扣除成本时声称正期望

### #10 分布验证 — 补齐 ✅（改名：小额实盘验证分布，书内无bootstrap）

**DEFINITION_SENTENCE:** "在初次确定期望收益时，你可能受到很多偏见的影响，因此，现在需要通过进行小额的实时交易来确定R乘数分布的准确性。如果交易1~10股股票或一手商品合约会怎样？你会得到什么样的R乘数分布？它是否和你通过理论推导出来的或通过历史测试得出来的结果类似？"

**SOURCE_ANCHOR:** index-066_1.png ~ index-068_1.png（待截）/ 第4章4.10"确定R乘数分布的准确性"节 / p.66-67；当前证据：1(1).png

**NOTE:** 撒普书中**没有提到统计bootstrap或重采样**。他用的是"小额实盘验证法"——用最小仓位做真实交易来验证R乘数分布。两者精神相同（用独立样本验证分布），但方法不同。

**STATE_AXIS_MAP:** 验真伪

**FAILURE_MODES:**
- 用理论推导的R分布代替实际验证
- 历史回测的分布与未来真实分布差异大

**FALSIFIABLE_TEST:** 小额实盘30+笔R分布 vs 回测R分布；KS检验p<0.05则分布显著不同

**DO_NOT_DO:** 禁止用回测R分布直接替代实盘的R分布

### #13 机会成本（资金占用）— 补齐 ✅

**DEFINITION_SENTENCE:** "一个期望值为0.5R（扣除交易成本之后），每周提供3次交易机会的系统要比每月提供一次交易机会期望值也为0.5R（同样也是在扣除交易成本之后）的交易系统优越得多。市场往往会根据在其中运作的人的特点而改变。记住你的期望值是经过大量的机会每一风险美元可以得到的收益。因此，你玩游戏的次数越多，就越有可能实现游戏的期望值。"

**SOURCE_ANCHOR:**
- 主锚点：index-171_1.png ~ index-174_1.png（待截）/ 第7章7.3节 / p.146-147
- 补充锚点（表13-1）：index-291_1.png ~ index-293_1.png（待截）/ 第13章13.2"期望总值"节 / p.290-291；当前证据：2(1).png + 3-副本.png

**STATE_AXIS_MAP:** 摩擦轴+风险轴

**FAILURE_MODES:**
- 低频系统占用资金过久
- 忽视不同系统的资金效率差异

**FALSIFIABLE_TEST:** 年化期望总值=期望×频率×平均R；年化差异显著(t-test)则频率因素占主导

**DO_NOT_DO:** 禁止在不比较年化期望总值时判断系统优劣
