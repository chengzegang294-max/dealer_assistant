## 1) R乘数（R-Multiple）

**DEFINITION_SENTENCE:** "我喜欢把交易中的风险叫做R，这样比较容易记，因为R是风险（risk）的缩写。R可以代表你每一个单位的风险...如果你买了100股股票，每股风险为10美元，那么你的全部风险就将1000美元。"

**SOURCE_ANCHOR:** index-170_1.png / 第7章"在放大镜下观察期望值"节 / p.143

**STATE_AXIS_MAP:** 摩擦轴+风险轴

**FAILURE_MODES:**
- 未严格定义初始R（止损随意变动），R乘数失真
- 允许单笔亏损超过1R，破坏可比性

**FALSIFIABLE_TEST:** 用30+笔R乘数序列做重采样估计期望的置信区间；若区间跨过0，则证据不足（不下结论）。

**DO_NOT_DO:** 禁止在没有固定止损时计算R乘数

## 2) 期望收益（Expectancy）

**DEFINITION_SENTENCE:** "期望值也就是每一笔交易每一风险美元对你的账户的平均影响。"

**SOURCE_ANCHOR:** index-170_1.png / 第7章"在放大镜下观察期望值"节 / p.143（同页段首）

**STATE_AXIS_MAP:** 验真伪

**FAILURE_MODES:**
- 样本量<30时期望不稳健
- 未扣除交易成本高估期望

**FALSIFIABLE_TEST:** bootstrap重采样10000次，95%CI包含0则不显著

**DO_NOT_DO:** 禁止用盈利金额而非R乘数计算期望

## 3) 机会因素/期望总值（Expectunity）

**DEFINITION_SENTENCE:** (原文对应) "期望值×机会=期望总值...一个期望值为0.5R的系统如果每周给你一次机会，一年下来...期望值是0.5R但每年只有4次机会..."

**SOURCE_ANCHOR:** 
- index-167_1.png / 第7章 7.2~7.3（机会与期望值起始段）/ p.143-146
- index-171_1.png / 第7章 7.4~7.5（机会约束与示例推演段落）/ p.147-150

**STATE_AXIS_MAP:** 验真伪+摩擦轴

**FAILURE_MODES:**
- 只优化期望忽视频率
- 假设频率恒定

**FALSIFIABLE_TEST:** 对两个系统分别计算“期望总值=期望×机会频率”的区间估计（重采样或滚动窗口）；若两者区间高度重叠，则“频率差异带来显著优势”的说法不成立。

**DO_NOT_DO:** 禁止在比较两系统时不考虑交易频率

## 4) 玻璃球/雪球隐喻（随机性 vs 长期收敛）

**DEFINITION_SENTENCE:** "图7-1 玻璃球游戏：系统所产生的连续的R乘数...图7-1给出了一个类似于表7-1所描述的交易次数为60的取球游戏样本的交易分布。记住这只是一个样本，每个样本很可能是不同的。"

**SOURCE_ANCHOR:** index-180_1.png / 第7章"玻璃球游戏"节 / p.153（图7-1及说明文字）

**STATE_AXIS_MAP:** 摩擦轴+偏置轴

**FAILURE_MODES:**
- 经历短期连败后认为系统失效
- 经历连胜后期望过度膨胀

**FALSIFIABLE_TEST:** 已知胜率p和盈亏比b，计算N次交易中连续k次亏损概率P(streak≥k)；实际连败显著超理论值则系统可能regime变化

**DO_NOT_DO:** 禁止因连续5-10笔亏损就放弃正期望系统

## 5) 初始止损(1R定义)与停价原则

**DEFINITION_SENTENCE:** "因此，一个1R的损失对迪克来说就是1.70美元...在进入每一笔交易之前，你应该事先确定为了保住资本而将退出市场的点，这一点就是你的交易所承担的风险或者说是你的预期损失。"

**SOURCE_ANCHOR:** 
- index-302_1.png / 第12章"每个人都有钱赚" / p.275（1R案例）
- index-170_1.png / 第7章 p.143（止损定义：退出市场以保住资本的点）

**STATE_AXIS_MAP:** 风险轴

**FAILURE_MODES:**
- 止损过紧被正常波动触发（whipsaw）
- 亏损后移动止损farther away（心理逃避）

**FALSIFIABLE_TEST:** 对比不同止损宽度方案，观察R乘数分布（中位数、左尾深度、最大回撤）是否显著改善；若仅靠“加宽止损”把亏损推迟而左尾更深，则判为无效改动。

**DO_NOT_DO:** 禁止在亏损后把止损移远——这等于假装没亏损

## 6) 头寸规模核心原则（%risk / %vol）

**DEFINITION_SENTENCE:** "有关资产管理或资产配置重要的是...你的交易系统中用以回答'多少'这个问题的部分...我在本书自始至终称之为'头寸规模确定'...进行头寸规模确定最好的方法是利用百分比风险法则，比如在给定的头寸承担总资本1%的风险。"

**SOURCE_ANCHOR:** index-330_1.png / 第14章"确定头寸规模：实现目标的关键" / p.303

**STATE_AXIS_MAP:** 风险轴

**FAILURE_MODES:**
- 风险%>3%导致连续亏损后大幅缩水
- 账户缩水后未调整仓位

**FALSIFIABLE_TEST:** MC模拟：0.5%/1%/2%/3%各10000次，Ruin<1%前提下选最优

**DO_NOT_DO:** 禁止亏损后加大仓位"翻本"

## 7) 最大亏损/回撤与停机语言

**DEFINITION_SENTENCE:** (撒普版) "你需要确定这些接连失败可能会持续多久，以便在其发生时能够应对...很多交易商利用一个安全的系统进行交易但还是失败了，这是因为他们对市场呈现给他们的交易分布没有做好应有的准备。"

**SOURCE_ANCHOR:** index-180_1.png / 第7章 p.153（连败准备+分布预期）

**STATE_AXIS_MAP:** 风险轴（STRESS边界）

**FAILURE_MODES:**
- 低估最大回撤（只考虑历史最大）
- 未做精神准备导致中途放弃

**FALSIFIABLE_TEST:** MC模拟99%分位最大回撤；若>账户承受极限则系统不匹配

**DO_NOT_DO:** 禁止用历史max DD当最坏情况估计

## 9) 样本量与分布形态（median=0/长尾）

**DEFINITION_SENTENCE:** (从图7-1推知) "系统成功交易的百分比和接连失败的交易的长度成反比。即使一个在60%的时间里是正确的系统也很容易在100次的系列交易中产生长达10次的接连失败。"

**SOURCE_ANCHOR:** index-180_1.png / 第7章 p.153（图7-1说明文字）

**STATE_AXIS_MAP:** 验真伪

**FAILURE_MODES:**
- 样本量<30时结论不稳健
- 忽视分布偏度和峰度

**FALSIFIABLE_TEST:** 30+笔R乘数序列，若去掉top 5%后期望<0，则说明系统高度依赖少数大盈利（右尾）；这类系统在摩擦/压力状态下更易失真，需要更强的风险约束。

**DO_NOT_DO:** 禁止用<30笔交易验证系统

## 10) 分布验证（小额实盘验证）

**DEFINITION_SENTENCE:** (原文对应) "在初次确定期望收益时，你可能受到很多偏见的影响，因此，现在需要通过进行小额的实时交易来确定R乘数分布的准确性..."

**SOURCE_ANCHOR:** index-066_1.png / 第4章 4.10"确定R乘数分布的准确性" / p.67-69

**STATE_AXIS_MAP:** 验真伪（工具）

**FAILURE_MODES:**
- 只用推导/回测分布，不做小额实盘验证
- 用大仓位验证导致行为偏差与风险扰动

**FALSIFIABLE_TEST:** 小额实盘30+笔R分布 vs 回测R分布，若分布差异显著（如KS检验p<0.05），则回测分布不可直接当作实盘分布使用

**DO_NOT_DO:** 禁止跳过小额实盘验证就用“回测分布”下结论

## 11) 连败长度/风险暴露

**DEFINITION_SENTENCE:** "给定了系统成功交易的百分比，就可以估计1000次试验中交易连续失败的最多次数，但是你永远不会知道实际次数。例如，即使是抛硬币也可能产生一连串正面朝上的结果。"

**SOURCE_ANCHOR:** index-180_1.png / 第7章 p.153（连败长度估计段落）

**STATE_AXIS_MAP:** 摩擦轴+风险轴

**FAILURE_MODES:**
- 低估连败长度（50%胜率系统也可能连输8次）
- 连败中加大仓位试图翻本

**FALSIFIABLE_TEST:** 用二项分布计算P(连败≥k)；若实际连败长度>p=0.01临界值，则怀疑regime变化或系统失效

**DO_NOT_DO:** 禁止连败后加大风险比例

## 12) 多元退出策略如何改变分布右尾

**DEFINITION_SENTENCE:** "一旦波段设立，他对从任一波段中获得8R的利润将会非常满意（从以前和目前的交易中）。这通常最多只在1~2笔交易中才能做到的。"

**SOURCE_ANCHOR:** index-302_1.png / 第12章"每个人都有钱赚" / p.275

**STATE_AXIS_MAP:** 风险轴+摩擦轴

**FAILURE_MODES:**
- 过早止盈（小profit即平仓）错失大趋势
- 过晚止盈导致盈利大幅回吐

**FALSIFIABLE_TEST:** 比较追踪止损vs固定目标的R乘数分布：追踪止损的skewness>固定目标且>0时，追踪止损更适合捕捉右尾

**DO_NOT_DO:** 禁止盈利时提前退出只因"害怕回撤"

**DEFINITION_SENTENCE:** (原文对应) "一个期望值为0.5R（扣除交易成本之后），每周提供3次交易机会的系统要比每月提供一次交易机会期望值也为0.5R（同样也是在扣除交易成本之后）的交易系统优越得多。"

## 14) 禁止跑偏规则（从书中抽2-3条有锚点的）

**规则A：** 禁止把胜率当目标 — "即使一个在60%的时间里是正确的系统也很容易在100次的系列交易中产生长达10次的接连失败。"（index-180_1.png p.153）

**规则B：** 禁止在没有固定止损时计算R乘数 — "在进入每一笔交易之前，你应该事先确定为了保住资本而将退出市场的点，这一点就是你的交易所承担的风险。"（index-170_1.png p.143）

**规则C：** 禁止亏损后加大仓位"翻本" — 百分比风险法则要求"在给定的头寸承担总资本1%的风险"，账户缩水后1%的金额自动减小。（index-330_1.png p.303）
