## STATE_TEMPLATE_V1 草案（墨菲贡献）

### 结构轴（TREND/RANGE/NEUTRAL）— 图表定义层

| 概念 | 定义句（来源） | 可观测证据 | 可证伪检验 |
|------|-------------|-----------|-----------|
| 趋势三方向 | 上升/下降/横向：峰谷依次升/降/平（ch04-s1） | 连续N个峰谷同向排列 | Cohen's kappa>0.6 |
| 趋势三类型 | 主要>6月/次要3周-3月/短暂<2周（ch04-s1） | 多时间尺度峰谷方向 | 跨尺度一致性>50% |
| 支撑-阻挡 | 至少两次触及验证，三维度重要性（ch04-s2） | 双触点+时间/量/远近 | 反弹率>50% |
| 角色互换 | 突破10%后支撑变阻挡（ch04-s3） | 突破后回踩验证 | 回踩反弹率>50% |
| 趋势线 | 双点连线+第三点验证（ch04-s4） | 触点数量+验证成功率 | 回测期望>0 |
| 有效突破 | 3%+2天原则（ch04-s5） | 穿越幅度+连续天数 | 最优参数跨市场对比 |
| 扇形原理 | 连续三趋势线被突破=反转（ch04-s6） | 三趋势线+角度递减 | 突破后方向一致性>50% |
| 跳空 | 四种类型：突破/度量/衰竭/普通（ch04-s7） | 缺口位置+类型分类 | 各类型方向一致性>50% |
| 头肩形 | 三峰结构+颈线突破（mur-s01） | 结构完整性+颈线突破 | 到达目标概率>50% |
| V形反转 | 剧烈反向+关键反转日+天量（mur-s02） | 反转日特征+量放大 | 占比<10%为低概率事件 |
| 三角形 | 对称/上升/下降/扩大（mur-s03） | 收敛边界+突破位置 | 晚突破成功率<早突破 |
| RSI/随机/MACD | 超买>70/<30超卖（mur-s04） | 0-100范围+背离 | RANGE有效/TREND钝化 |

**结构轴判定规则：**
- TREND：峰谷依次升/降 + 趋势线验证 + 量确认 + 无头肩顶结构
- RANGE：峰谷横向伸展 + 三角形/矩形内部运行 + RSI 40-60震荡
- NEUTRAL：所有指标矛盾 + ACF不显著 + MACD≈0
- TREND反转信号：头肩形完成/连续三趋势线突破/V形关键反转日

### 偏置轴（BULL/BEAR/NEUTRAL）

| 状态 | 可观测证据 |
|------|-----------|
| BULL+ | 上升趋势线有效+量增+MACD>0+RSI 50-70 |
| BULL- | 头肩顶形成中+RSI超买钝化+量萎缩（顶背离） |
| NEUTRAL | RSI 40-60 + MACD≈0 + 三角形内运行 |
| BEAR- | 下降趋势有效+量增+MACD<0+RSI<50 |
| BEAR+ | 头肩底形成中+RSI超卖+底背离 |

### 摩擦轴（NORMAL/STRESS）

| 代理变量 | NORMAL | STRESS | 来源 |
|----------|--------|--------|------|
| 交易量 | 趋势方向量>60% | 背离或天量>2× | ch04/ch05 |
| RSI范围 | 30-70 | >80或<20（钝化） | ch10 |
| 形态失败率 | <30% | >50%（假突破频发） | ch05/ch06 |
| 跳空频率 | 正常 | 缺口密集（衰竭信号） | ch04 |

**NORMAL→STRESS：**
- 头肩形/三角形失败率突增>50%
- RSI钝化（持续>80或<20）
- 量价背离+天量+价格反向
- 跳空缺口密集出现

### 验真伪 — 6项检验

| # | 检验项 | 失败判据 |
|---|--------|---------|
| 1 | 趋势定义一致性 | Cohen's kappa<0.6 |
| 2 | 支撑-阻挡反弹率 | 反弹率≤50% |
| 3 | 趋势线策略期望 | 期望≤0 |
| 4 | 头肩形到达目标 | 概率≤50% |
| 5 | RSI分桶有效性 | TREND中不显著 |
| 6 | 三角形突破时机 | 晚突破成功率显著低 |

### 禁止跑偏规则（12条）

1. 禁止在无时间规模标注时声称"趋势"（ch04）
2. 禁止价格同时破坏前高前低时仍声称"趋势明确"（ch04）
3. 禁止未经二次验证的单一低点当支撑（ch04）
4. 禁止突破后不回测即追高（ch04）
5. 禁止用固定百分比穿越标准跨市场套用（ch04）
6. 禁止为了凑三条而强行画趋势线（ch04）
7. 禁止在连续交易市场硬套跳空概念（ch04）
8. 禁止在右肩未形成时预测头肩顶（ch05）
9. 禁止声称能预测V形反转（ch05）
10. 禁止在三角形顶点后才等待突破（ch06）
11. 禁止在强趋势中用RSI超买做反向（ch10）
12. 禁止用盈利当唯一验收标准（ch16）
