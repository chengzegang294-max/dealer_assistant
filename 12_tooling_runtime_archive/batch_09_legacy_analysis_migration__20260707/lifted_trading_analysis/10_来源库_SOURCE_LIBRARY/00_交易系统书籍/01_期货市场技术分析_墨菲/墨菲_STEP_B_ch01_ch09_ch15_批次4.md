## 切片20: 市场行为包容消化一切

**TERM:** 市场行为包容消化一切

**STATE_AXIS_MAP:** 偏置轴（所有信息已反映在价格中）

**DEFINITION_SENTENCE:** "能够影响某种商品期货价格的任何因素——基础的、政治的、心理的或任何其它方面的——实际上都反映在其价格之中。由此推论，研究价格变化就是必须做的事情。"

**OBSERVABLE_EVIDENCE:** 重大消息发布后价格迅速调整至新均衡；价格变化反映供求关系，需求>供给则价格上涨。

**FAILURE_MODES:**
- 消息消化存在时间延迟，短期价格可能未完全反映
- "已知已知"与"已知未知"的定价差异被忽视

**FALSIFIABLE_TEST:** 消息发布后价格异常波动（>2σ）在T个交易日内消退则假设成立；若持续偏离则假设失效。

**DO_NOT_DO:** 禁止在消息发布后追涨杀跌并声称"消息已被消化"而不定义时间窗口。

**SOURCE_ANCHOR:** ch01"技术分析的理论基础" / 180847.png / p.1

## 切片21: 价格以趋势方式演变

**TERM:** 价格以趋势方式演变

**STATE_AXIS_MAP:** 结构轴（TREND/RANGE）

**DEFINITION_SENTENCE:** "趋势概念是技术分析的核心。当前趋势将一直持续到掉头反向为止。这就是趋势顺应理论的源头。" + "坚定不移地顺应一个既成趋势，直至有反向的征兆为止。"

**OBSERVABLE_EVIDENCE:** 价格序列呈现持续方向性运动（ higher highs + higher lows = uptrend ）；趋势反转有明确的破位信号。

**FAILURE_MODES:**
- 将趋势中的正常回调误判为趋势反转
- 在无趋势市场（RANGE）中强行寻找趋势导致连续亏损

**FALSIFIABLE_TEST:** 价格序列自相关性检验（Ljung-Box Q统计量），p<0.05拒绝随机行走则趋势存在；方差比检验（Variance Ratio Test）拒绝随机行走。

**DO_NOT_DO:** 禁止在无趋势确认时假设趋势存在并入场。

**SOURCE_ANCHOR:** ch01"理论基础" / 180847.png / p.2

## 切片22: 历史会重演

**TERM:** 历史会重演

**STATE_AXIS_MAP:** 偏置轴+验真伪

**DEFINITION_SENTENCE:** "它们在过去很管用，就不妨认为它们在未来同样有效。因为它们是以人类心理为根据的，而人类心理从来就是'江山易改本性难移'。'历史会重演'说得具体点就是，打开未来之门的钥匙隐藏在历史之中。"

**OBSERVABLE_EVIDENCE:** 特定价格形态（如头肩顶、双底）在历史上反复出现并产生可预测结果；市场参与者行为模式重复。

**FAILURE_MODES:**
- 样本内优化导致"发现"的模式在样本外失效
- 市场结构变化（如监管、参与者结构）导致历史模式不再有效

**FALSIFIABLE_TEST:** 历史模式在未来独立数据上的预测准确率显著>随机水平（二项检验，p<0.05）；bootstrap置信区间不包含50%。

**DO_NOT_DO:** 禁止仅用历史回测结果声称模式有效而不做样本外验证和前瞻性测试。

**SOURCE_ANCHOR:** ch01"历史会重演" / 180847.png / p.2

## 切片23: 随机行走理论

**TERM:** 随机行走理论

**STATE_AXIS_MAP:** 结构轴+验真伪

**DEFINITION_SENTENCE:** "随机行走理论认为价格变化在顺序上互相独立，历史价格不是未来价格方向的可取线索。价格变化是随机而不可预测的。" + "如果市场果真随机，那么没有什么预测技术靠得住。"

**OBSERVABLE_EVIDENCE:** 价格变化的自相关函数≈0；游程检验符合随机性；方差比≈1。

**FAILURE_MODES:**
- 市场并非完全随机（趋势存在）时错误接受随机行走假设
- 短期随机但长期存在可预测结构

**FALSIFIABLE_TEST:** 游程检验（runs test）拒绝随机性；方差比检验（Lo-MacKinlay）拒绝随机行走；Ljung-Box自相关检验p<0.05。若检验拒绝随机行走则技术分析有统计依据。

**DO_NOT_DO:** 禁止在随机行走假设未被拒绝时声称拥有预测能力。

**SOURCE_ANCHOR:** ch01"随机行走理论" / 180856.png / 180907.png / p.3-4

## 切片24: 移动平均线趋势确认

**TERM:** 移动平均线趋势确认

**STATE_AXIS_MAP:** 结构轴+偏置轴

**DEFINITION_SENTENCE:** "移动平均线是一种平滑工具。其目的在于识别和显示旧趋势已经终结或反转、新趋势正在萌生的关键契机。移动平均线实质上是一种追踪趋势的工具。"

**OBSERVABLE_EVIDENCE:** 价格位于MA上方=上升趋势；价格位于MA下方=下降趋势；MA斜率方向=趋势方向。

**FAILURE_MODES:**
- 滞后性：MA基于历史价格，永远无法领先于市场
- 在无趋势市场（RANGE）中产生大量拉锯假信号

**FALSIFIABLE_TEST:** MA方向与后续N日价格趋势一致性检验；MA信号胜率显著>50%（二项检验，p<0.05）；否则MA无效。

**DO_NOT_DO:** 禁止在无趋势确认时仅凭MA位置入场。

**SOURCE_ANCHOR:** ch09"移动平均线"引言 / 180921.png / p.1

## 切片25: 双移动平均线交叉系统

**TERM:** 双移动平均线交叉

**STATE_AXIS_MAP:** 结构轴

**DEFINITION_SENTENCE:** "第一种称为'双线相交法'。当短期平均线向上穿越长期平均线时，构成买入信号。当短期平均线向下穿越长期平均线后，形成卖出信号。" + "采用双移动平均线法在时间上滞后于市场更多一些，但由此也减少了拉锯现象。"

**OBSERVABLE_EVIDENCE:** 5天/20天组合、10天/40天组合的交叉信号；两条平均线及其价格三者的相互作用共同产生趋势信号。

**FAILURE_MODES:**
- 拉锯现象（whipsaws）：无趋势市场连续假信号
- 信号滞后：交叉发生时价格已运行一段距离

**FALSIFIABLE_TEST:** 交叉信号后N日（如5/10/20日）收益率显著异于0（t检验，p<0.05）；胜率显著>50%。若低于阈值则系统无效。

**DO_NOT_DO:** 禁止在无趋势过滤器的纯MA交叉系统中交易。

**SOURCE_ANCHOR:** ch9.3"怎样利用两条移动平均线产生信号" / 180933.png

## 切片26: 移动平均线过滤器（穿越规则）

**TERM:** MA过滤器（穿越幅度+时间验证）

**STATE_AXIS_MAP:** 摩擦轴+结构轴

**DEFINITION_SENTENCE:** "收市价格穿越移动平均线的幅度必须达到预定的要求，这一点属于'穿越规则的范畴'。顶定穿越幅度，可以是最小价格单位的一定倍数，或者是某个百分比。" + "有些分析者要求，移动平均线信号必须由其余图表的突破信号所验证。"

**OBSERVABLE_EVIDENCE:** COMEX黄金最小单位10美分→过滤器设为5倍即50美分(0.50)；百分比过滤器：收市价格穿越幅度达到1%；时间延迟过滤器：信号出现后观察1-3天。

**FAILURE_MODES:**
- 过滤器过小→假信号过多，摩擦成本高
- 过滤器过大→入场过晚，错过主要行情
- 过度优化过滤器参数导致曲线拟合

**FALSIFIABLE_TEST:** 不同过滤器阈值下系统夏普比率最优化；最优值显著≠0（存在有效过滤）。参数平原测试确认最优值区域而非单点。

**DO_NOT_DO:** 禁止不使用过滤器的裸MA穿越交易；禁止将过滤器优化至单点最优。

**SOURCE_ANCHOR:** ch9.3"移动平均线过滤器" / 180933.png

## 切片27: 4-9-18天移动平均线系统

**TERM:** 4-9-18天MA系统

**STATE_AXIS_MAP:** 结构轴

**DEFINITION_SENTENCE:** "最短期的4天平均线最贴近价格趋势，9天平均线次之，18天平均线最远。在上升趋势中，合理的排列应当为，4天平均线高于9天平均线，而后者又高于18天平均线。" + "4天平均线同时向上越过了9天和18天平均线后，则构成买入的预警信号。"

**OBSERVABLE_EVIDENCE:** 三线多头排列=上升趋势确认；三线空头排列=下降趋势；4天穿越9天和18天=预警；排列顺序混乱=无趋势。

**FAILURE_MODES:**
- 趋势反转时三线频繁交叉产生连续假信号
- 横盘市场中三线缠绕，信号失效

**FALSIFIABLE_TEST:** 三线排列方向与后续N日价格方向一致性检验（卡方检验，p<0.05）；三线排列时胜率显著>50%。

**DO_NOT_DO:** 禁止在三线排列混乱或缠绕时强行判断趋势方向。

**SOURCE_ANCHOR:** ch9.4"怎样利用4-9-18天移动平均线系统" / 180942.png

## 切片28: 移动平均线与周期关系

**TERM:** MA与主导周期匹配

**STATE_AXIS_MAP:** 驱动力轴+结构轴

**DEFINITION_SENTENCE:** "移动平均线的时间跨度应当与市场的主流周期相匹配。每个周期都倾向于按照一二个倍数因子，与其上一级长周期，或者下一级短周期和谐地相互呼应。" + "月周期的长度是20天。40天移动平均值是20天的两倍。10天移动平均值是20天的一半。"

**OBSERVABLE_EVIDENCE:** 5天/10天/20天/40天MA分别对应月周期的分数和倍数；市场存在可测量的主导周期（如4周、8周、13周）。

**FAILURE_MODES:**
- 使用固定MA参数忽略市场周期变化
- 周期偏移（regime shift）导致MA失效
- 过度拟合周期参数

**FALSIFIABLE_TEST:** 市场主导周期（FFT谱分析或周期图）与MA周期匹配度检验；匹配时MA信号准确率显著高于不匹配时（双样本t检验）。

**DO_NOT_DO:** 禁止在所有市场使用同一固定MA周期参数而不考虑市场周期。

**SOURCE_ANCHOR:** ch9"移动平均线与周期现象关系密切" / 180949.png

## 切片29: 四周规则（周规则）

**TERM:** 四周规则

**STATE_AXIS_MAP:** 结构轴

**DEFINITION_SENTENCE:** "只要价格涨过前四个日历周内的最高价，则平回空头头寸，开立多头头寸。只要价格跌过前四个周内的最低价，则平回多头头寸，建立空头头寸。"

**OBSERVABLE_EVIDENCE:** 1970年邓恩和哈吉特《交易商手册》研究；唐迁系统在所有测试对象中最为成功；连续在市系统始终持有头寸。

**FAILURE_MODES:**
- 无趋势市场频繁拉锯，连续亏损
- 四周参数对某些市场过长/过短
- 市场结构变化导致历史最优参数失效

**FALSIFIABLE_TEST:** 四周突破信号后续收益率显著>0（t检验，p<0.05）；参数平原测试（2-8周）确认四周附近为最优区域而非单点。

**DO_NOT_DO:** 禁止在横盘无趋势市场中使用四周规则；禁止不经验证地将四周参数用于所有市场。

**SOURCE_ANCHOR:** ch9"周规则" / 180957.png

## 切片30: 自动交易系统的长处与局限

**TERM:** 自动交易系统（ ATS ）

**STATE_AXIS_MAP:** 验真伪+偏置轴

**DEFINITION_SENTENCE:** "自动交易系统的长处：1.排除了人类主观情绪的影响。2.具有更严格的自律。3.能达到更高程度的协调一致性。4.顺着趋势方向交易。5.确保不错过每个顺着重要趋势的方向入市的机会。" + "短处：绝大多数自动交易系统是顺应趋势的，当市场无趋势可循时，趋势顺应系统一般是不盈利的。"

**OBSERVABLE_EVIDENCE:** 自动化系统能"让利润充分增长，把损失控制在小额"；在70%的时间内（无趋势或趋势不强时）效果不如人意。

**FAILURE_MODES:**
- 过度优化（curve fitting）导致样本外失效
- 无法适应市场结构变化
- 参数过多导致脆弱性

**FALSIFIABLE_TEST:** 自动系统vs主观交易：同一规则下自动执行夏普比率显著更高（双样本t检验）；样本外表现与样本内比值>0.7（防过拟合）。

**DO_NOT_DO:** 禁止声称自动系统消除所有交易风险；禁止不过样本外验证直接上线自动系统。

**SOURCE_ANCHOR:** ch15"自动交易系统的长处" / 181021.png

## 切片31: 方向性运动指数(ADXR)

**TERM:** 方向性运动指数(ADXR/DMI)

**STATE_AXIS_MAP:** 结构轴+摩擦轴

**DEFINITION_SENTENCE:** "ADXR的读数刻度是从0到100分布。趋势型交易商只要径直地选择趋势程度最高的市场就行了。而当ADXR线低于20时，则意味着市场处于无趋势状态。" + "当+DMI(实线)向上穿越-DMI(虚线)时，构成买入信号，而当它向下穿过-DMI线时，构成卖出信号。"

**OBSERVABLE_EVIDENCE:** ADXR>25=趋势强，适合趋势系统；ADXR<20=无趋势，不适合；+DMI/-DMI交叉=买卖信号。

**FAILURE_MODES:**
- ADXR滞后性：趋势已反转但ADXR尚未响应
- ADXR极端值后的反转信号
- +DMI/-DMI交叉在无趋势市场产生假信号

**FALSIFIABLE_TEST:** ADXR阈值与趋势识别准确率ROC曲线最优化；ADXR>25时趋势系统胜率显著>ADXR<20时（双样本t检验）。

**DO_NOT_DO:** 禁止在ADXR<20（无趋势）时使用趋势跟踪系统。

**SOURCE_ANCHOR:** ch15"方向性运动指数" / 181021.png

## 切片32: 商品选择指数(CSI)

**TERM:** 商品选择指数(CSI)

**STATE_AXIS_MAP:** 摩擦轴+结构轴

**DEFINITION_SENTENCE:** "王尔德在CSI的设计中，不但把方向性运动系统和ADXR线的算法移植过来，而且还增加了对波动性因子(所谓平均实际区间，ATR)、保证金要求、以及交易费用等。" + "一般认为，无论从趋势性强弱的角度来看，还是从波动性大小的方面来看，CSI水平高的市场都是很好的交易媒介。"

**OBSERVABLE_EVIDENCE:** CSI综合考虑：方向性运动(ADXR)、波动性(ATR)、保证金要求、交易成本；CSI高的市场=方向性强+波动性适中+成本合理。

**FAILURE_MODES:**
- CSI高但方向性不确定（波动大但无方向）
- CSI参数固定不适应市场变化
- 忽视流动性风险

**FALSIFIABLE_TEST:** CSI排名靠前的市场实际交易夏普比率显著高于排名靠后的（双样本t检验，p<0.05）。

**DO_NOT_DO:** 禁止仅根据CSI单一指标选择交易标的而不考虑流动性。

**SOURCE_ANCHOR:** ch15"商品选择指数(CSI)" / 181021.png

## 切片33: 人工智能形态识别

**TERM:** AI形态识别（指标组合优化）

**STATE_AXIS_MAP:** 验真伪+偏置轴

**DEFINITION_SENTENCE:** "形态识别的目的是，把所有的技术指标组合在一起，以产生'协同'的效果，而不是孤立地处理各项因素。" + 步骤：选最佳个别指标→挑出最佳一对→三种指标组合→不断加入新指标直至不再改善总成绩。

**OBSERVABLE_EVIDENCE:** 使用两组不同数据（学习数据+测试数据）避免"曲线自适应"；测试数据验证学习数据的结果。

**FAILURE_MODES:**
- 过度拟合：样本内优化组合在样本外失效
- 指标组合过于复杂导致脆弱性
- 计算成本过高，实盘不可行

**FALSIFIABLE_TEST:** 形态识别系统样本外测试夏普比率显著>样本内随机组合（t检验）；样本外/样本内夏普比率>0.7（过拟合检验）。

**DO_NOT_DO:** 禁止将样本内优化指标组合直接用于实盘而不经独立测试验证。

**SOURCE_ANCHOR:** ch15"人工智能形态识别" / 181039.png

## 切片34: 系统信号作为警报（而非指令）

**TERM:** 系统信号=警报而非指令

**STATE_AXIS_MAP:** 偏置轴+结构轴

**DEFINITION_SENTENCE:** "我们也可以把自动系统简单地用作验证性的技术指标，纳入我们的市场分析中。" + "计算机趋势信号用作自己警惕当前的趋势变化的审查工具。只要扫一眼这张表格，马上就能挑出7种交易对象。"

**OBSERVABLE_EVIDENCE:** 系统警报+人工判断 vs 纯自动交易；系统信号帮助识别趋势变化但不代替独立分析。

**FAILURE_MODES:**
- 信号过多导致分析瘫痪
- 过度依赖系统信号忽视市场结构变化
- 系统黑箱化导致理解缺失

**FALSIFIABLE_TEST:** "系统警报+人工确认"模式夏普比率显著>纯自动交易（配对t检验，p<0.05）则人工叠加有价值。

**DO_NOT_DO:** 禁止完全由系统牵着鼻子走而不做独立判断；禁止将系统信号作为唯一交易依据。

**SOURCE_ANCHOR:** ch15"以系统信号作警报" / 181039.png
