## SLICE: k24-s1 | 资产多元化与相关性变化 — 分散的边界条件

**TERM:** 资产多元化（Diversification）与相关性情境变化

**STATE_AXIS_MAP:** 风险轴（组合层面的NORMAL/STRESS）+ 验真伪

**DEFINITION_SENTENCE:** "多元化是降低风险的有效方法，但有边界：当资产数量从1种增加到10-15种时，风险显著下降；超过20种后风险降低的边际效应趋近于零。相关性是关键：当市场处于压力状态时，原本低相关的资产可能趋同（相关性飙升），此时分散化失效。主动型交易者的特殊情境：当使用趋势系统进行趋势分析时，两种策略持有头寸只占50%时间，无头寸时无法通过分散化获益。"

**OBSERVABLE_EVIDENCE:**
- 多元化效应曲线：风险随资产数量增加而递减（凹函数），20种后趋于平坦
- 相关性矩阵：正常时期vs压力时期的对比（压力期相关性趋1）
- 图24-1：资产多元化对风险的影响模式（边际递减）
- 图24-3：标准普尔指数期货与10年期国债、欧元和黄金期货的循环滚动相关性
- 主动型交易的特殊情境：策略持有时间占比影响分散化效果

**FAILURE_MODES:**
- 伪分散（多个高度相关资产看似分散实则集中风险）
- 忽视压力期相关性趋同（分散化在最需要时失效）
- 过度多元化（>20种导致管理成本侵蚀收益）
- 用正常时期的相关性矩阵做压力期配置

**FALSIFIABLE_TEST:** 计算正常时期和压力时期（VIX>30）的相关性矩阵差异；若压力期平均相关性比正常期增加>0.3（t-test），则分散化在STRESS时显著失效，需设定"压力期最大仓位上限"

**DO_NOT_DO:** 禁止用正常时期的相关性矩阵来配置压力期的组合——分散化在最需要时可能失效

## SLICE: k24-s2 | 投资组合四种模型 — 配置方法论

**TERM:** 投资组合模型（等值权重/等值风险/α驱动/决策树）

**STATE_AXIS_MAP:** 风险轴（组合配置操作层）+ 验真伪

**DEFINITION_SENTENCE:** "四种基本投资组合模型：(1)资本（美元）等值权重模式：每项资产获相同美元权重；(2)等值风险权重：头寸反比于波动率，使每头寸风险贡献相等；(3)阿尔法（α）驱动的权重模式：较高α值资产获较大分配；(4)决策树型模式：根据资产属性进行分类匹配。"

**OBSERVABLE_EVIDENCE:**
- 等值权重：简单，但高波动品种风险过大
- 等值风险：σ_A=4%, σ_B=1% → A配20%资金, B配80%资金
- α驱动：按预期超额收益排序分配
- 决策树：根据相关性/波动率/流动性等属性分桶配置
- E(R) = w₁E(R₁) + w₂E(R₂) + ... + wₙE(Rₙ), Σwᵢ = 1.0
- σ²_p = Σwᵢ²σᵢ² + ΣΣwᵢwⱼcovᵢⱼ

**FAILURE_MODES:**
- 等值权重忽视波动率差异（高波动品种隐性风险大）
- α驱动依赖α估计的准确性（α预测错误→配置错误）
- 决策树分类标准主观（不同分类方式结果不同）
- 忽视品种间协方差（只关注方差忽视相关性）

**FALSIFIABLE_TEST:** 对同一组资产分别用4种模型配置，回测比较OOS的Sharpe ratio；若某模型在至少3个不同市场regime中 consistently 优于其他模型，则该模型在此资产集上更优

**DO_NOT_DO:** 禁止在忽视品种间相关性的情况下做组合配置——协方差对组合风险的影响>方差

## SLICE: k24-s3 | 基因演算方法GASP — 组合优化引擎

**TERM:** 基因演算资产配置系统（GASP: Genetic Algorithm System for Portfolios）

**STATE_AXIS_MAP:** 验真伪（组合优化方法论）+ 风险轴

**DEFINITION_SENTENCE:** "GASP是考夫曼提出的基因演算方法用于资产配置：初始化→目标函数计算→测试完成→传播→配置→变异→迭代至收敛。目标函数OF = AROR/σ_D（年化收益/标准差或半方差）。约束条件：权重之和=1，允许负权重（做空），但需在-1到+1之间。"

**OBSERVABLE_EVIDENCE:**
- 6步骤：(1)初始化 (2)目标函数计算 (3)测试完成 (4)传播 (5)配置 (6)变异
- 目标函数：最大化AROR/σ（收益风险比）
- 约束条件：Σwᵢ=1, -1≤wᵢ≤1
- 变异机制：防止过早收敛到局部最优
- 与现代投资组合理论MPT的关系：GASP可处理非线性、非正态分布

**FAILURE_MODES:**
- 过早收敛（局部最优而非全局最优）
- 目标函数选择不当（如过度追求收益忽视风险）
- 约束条件设置不合理（权重范围过宽或过窄）
- GASP结果不稳定（多次运行得到差异大的配置）

**FALSIFIABLE_TEST:** 用GASP优化10次独立运行，计算10次结果的配置权重标准差；若权重标准差>10%（即每次结果差异大），则GASP不稳定，结果不可靠。若<5%，则结果可复现

**DO_NOT_DO:** 禁止运行一次GASP就直接采用其结果——需多次运行验证稳定性

**SOURCE_ANCHOR:** ch24 24.6+24.6.7 / 4(7).png（p.946-949）+ 5(6).png（p.948-951）"考夫曼的投资组合模型所相关的基因演算方法（GASP）"+"基因演算方法（GASP）相关的解决方案"

## SLICE: k24-s4 | 投资组合约束条件与风险目标 — 组合层STRESS边界

**TERM:** 投资组合约束条件（Constraints）与目标风险

**STATE_AXIS_MAP:** 风险轴（组合层面的NORMAL/STRESS边界定义）

**DEFINITION_SENTENCE:** "投资组合约束条件：不超过一天的平均交易量应是总资本的1%，一些经理人说是3%——少量交易总是更好的。目标风险：在给定时间范围内由标准差或投资百分比值而导出的一种特殊损失相关的概率。例如10年内资产下跌10%的可能性是0.1%（1%的1/10）。压力测试：应用极端价格变动测试组合表现。"

**OBSERVABLE_EVIDENCE:**
- 流动性约束：单笔交易不超过日均成交量的1-3%
- 目标风险：特定置信水平下的最大可接受损失
- 压力测试：历史最大动荡日×1.5倍冲击组合
- 约束多样化：流动性约束+风险约束+相关性约束+做空约束
- 资产链接池初始化：随机投资组合模式+基因库概念

**FAILURE_MODES:**
- 约束过松（流动性冲击导致无法退出）
- 约束过严（交易机会过少）
- 忽视压力期约束失效（正常期的1%流动性约束在压力期可能不足）
- 目标风险设定过低（过于保守导致收益不足）

**FALSIFIABLE_TEST:** 设定"单笔不超过日均量1%"约束，回测历史所有退出操作；若存在>5%的退出操作因流动性不足而被迫以>2×正常价差成交，则1%约束在STRESS时不足，需降至0.5%

**DO_NOT_DO:** 禁止在正常时期设定流动性约束后不做压力期验证——压力期的流动性可能只有正常期的10-30%
