# TK-R8 B 区域判定壳 后续对象定义入口 v1

## 作用

- 把 `TK-R8 = B 区域 qualify 壳` 从综合整理稿里的“可重开结论”推进成更明确的后续对象入口。
- 当前目标不是把它直接写成进场规则，而是先固定：
  - 它解决什么问题
  - 它与 `ABC / B 位挂单` 的关系
  - 最小输入
  - 最小输出
  - 当前边界

## 当前定位

- 层级：
  - `TK` 后续对象层
- 当前角色：
  - `qualify_shell_entry`
- 不是：
  - 当前独立策略
  - 当前硬门控
  - 当前已量化完成对象

## 来源锚点

- 主要来源：
  - `20231219TK外汇交易系统学习资料整理(6)_导出.md`
  - `20231219TK外汇交易系统学习资料整理(6)_吸收结论_v1.md`
- 当前已固定可引用语义：
  - 不是所有回撤区都算 `B`
  - 需要维持 `ABC` 波段结构成立
  - 越接近 `B 区域` 入场，通常 `RRR` 更好

## 为什么要单独开 TK-R8

- 旧 `ABC / B 位挂单` 更像教学级口径。
- 新综合整理稿补的是：
  - 哪些回撤能算 `B`
  - 哪些只是看起来像 `B`
- 因而 `TK-R8` 的价值不在于提供新信号，而在于：
  - 给既有 `ABC / B 位挂单` 补一个 qualify 壳
  - 减少“回撤区泛化”
  - 改善进入 `B 位` 时的结构一致性

## 最小语义

- 当前保守写法：
  - `TK-R8` 用于判断某次回撤是否仍可被视为有效 `B 区域`。
- 当前不写成：
  - `出现回撤 = 一定是 B`
  - `只要接近 B 就必须挂单`
  - `B qualify` 单独构成完整交易系统

## 最小输入

- 波段结构：
  - `A-B-C` 基本结构是否存在
- 回撤位置：
  - 当前价格是否接近理论 `B` 区域
- 主方向：
  - 当前仍是否属于原趋势/原波段的延续环境
- 可选辅助：
  - `Fib` 回撤位置
  - `IB / DB / CB` 是否共振

## 最小输出

- `b_zone_candidate`
  - 当前是否可视为候选 `B 区域`
- `abc_structure_valid`
  - 当前 `ABC` 结构是否仍成立
- `b_zone_quality_note`
  - 当前属于：
    - `not_b_zone`
    - `weak_b_zone`
    - `qualified_b_zone`

## 当前建议的派生输出

- `b_zone_distance_bucket`
  - 距理论 `B` 位的距离分桶
- `b_zone_rrr_bias`
  - 当前入场风报比倾向
- `abc_break_flag`
  - 当前是否已经破坏原 `ABC` 结构

## 与现有 TK 主线的关系

- 当前更稳的关系是：
  - `TK-R8` 不替代 `ABC / B 位挂单`
  - `TK-R8` 也不替代 `IB/DB/CB`
  - 它更像 `ABC / B 位挂单` 的 qualify 壳
- 当前更适合放在：
  - 结构 qualify 层
  - 诊断标签层
  - 后续对象层
- 当前不适合直接放在：
  - 硬门控
  - 独立 signal family

## 最小验收定义

- 有一份对象语义文档：
  - 说明它是 qualify 壳，而不是独立策略
- 有一份最小输入/输出合同：
  - 至少把 `ABC validity / B candidate / quality note` 说清
- 有一份 proof-of-mapping 的证据表（可审计）：
  - `12_工具运行时_TOOLING_RUNTIME\TK_R8\tkr8_manual_audit_sheet_v1.tsv`
- 有一份可复现的汇总产物（可审计）：
  - `12_工具运行时_TOOLING_RUNTIME\TK_R8\tkr8_manual_audit_summary_v1.md`
- 有一份当前角色裁决：
  - `DIAG_ONLY_OBJECT_CANDIDATE`
  - 或 `qualify_shell_entry`

## 当前 gaps

- `B 区域` 的精确价格范围仍未冻结。
- `ABC` 结构失效的判据仍未冻结。
- 当前还没有统一样本去判断：
  - `qualified_b_zone`
  - 相比普通回撤区
  - 是否真的带来更好的 `RRR` 或更高到达率。
- 当前不应把教学语义直接写成统计优势结论。

## 当前裁决

- `TK-R8` 是新综合整理稿里第二优先的新增对象。
- 当前应把它固定为：
  - `ABC / B 位挂单` 的 qualify 壳入口
  - `TK` 后续对象层中的结构 qualify 对象
- 同时继续保持边界：
  - 不直接升级成硬门控
  - 不直接升级成独立策略
  - 不宣称已完成量化验证
