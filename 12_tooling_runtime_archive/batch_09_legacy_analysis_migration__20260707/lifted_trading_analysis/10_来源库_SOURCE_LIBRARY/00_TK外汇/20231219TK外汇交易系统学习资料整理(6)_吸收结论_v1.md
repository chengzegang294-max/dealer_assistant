## 这份整理稿带来的新增主题

### 1. 交易策略层新增

- 四种最佳入场法被放到同一套教学口径下：
  - `ABC / B 位挂单`
  - `IB 区域挂单`
  - `小周期寻找回撤终点`
  - `Fibonacci minor/major 区域挂单`
- 新增的稳定可引用点：
  - `IB` 是信号最后关口
  - 若回撤到 `IB` 后被强力阻挡，则继续走向 `TP3` 的概率增强
  - 一根强势蜡烛同时突破 `IB + CB` 时，可讨论“不等回撤直接入场”，但 `RRR` 变差

### 2. 风险辅助层新增

- `AO` 被明确放在：
  - 动量/背离参考
  - 风险调整
  - 转向概率补充
- 当前更稳的吸收方式不是把 `AO` 当成独立硬信号，而是：
  - `signal present + divergence present`
  - 作为反向信号的风险/置信度修正标签

### 3. 高级篇新增

- 新增了 `B 区域` 鉴定规则：
  - 不是所有回撤区都算 `B`
  - 需要维持 `ABC` 波段结构成立
  - 更强调“信号接近 B 区域时入场，RRR 更好”
- 这给旧 `ABC / B 位挂单` 增加了更细的 qualify 壳，而不是单纯案例重复。

### 4. 独立顺势策略新增

- 文稿后段新增了一套独立的顺势交易策略：
  - `50EMA`
  - `150EMA(HIGH/LOW)`
  - `WPR10`
  - `WPR100`
- 当前判断：
  - 这是新的策略家族，不应硬塞回现有 `IB/DB/CB + Fib` 主线
  - 更适合后续单独作为 future strategy shell

### 5. 平台与资管鉴别新增

- 文稿系统化整理了：
  - 监管分级
  - 黑平台特征
  - 黑资管迹象
  - `MYFXBOOK` 核查
- 当前判断：
  - 这部分对实务筛选平台有价值
  - 但不属于当前仓库的可量化字段层

### 6. 复盘与计划层新增

- 文稿把 `TP3 延伸区做单法` 进一步收成了 SOP：
  - 入场：`FIBO 1.0`
  - 止损：`FIBO 0`
  - 止盈：`FIBO 2.618`
  - 风报比：`1:1.618`
  - 最低盈率：`38.2%`
  - 风险控制：`每单 5%`
- 同时明确提到：
  - `MT4` 手动复盘
  - `Forex Tester` 更接近实盘的计划验证
