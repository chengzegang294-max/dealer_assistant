# 技术指标_随机指标_KDJ与MACD共振量化规则

## 核心定义
KDJ与MACD共振是当两个指标同时发出同向信号时，信号可靠性大幅提升的交易确认方法，用于过滤假信号、提高胜率。

## 可量化执行标准

**共振类型定义**：

| 共振类型 | KD信号 | MACD信号 | 综合信号强度 | 交易动作 |
|---------|--------|---------|------------|---------|
| 强多头共振 | KD金叉+K<30 | MACD金叉或柱线翻红 | S级 | 立即入场，标准仓×1.5 |
| 中多头共振 | KD金叉+K<50 | MACD柱线缩短（将金未金） | A级 | 确认后入场，标准仓 |
| 弱多头共振 | KD金叉+K>50 | MACD金叉 | B级 | 轻仓试探，标准仓×0.7 |
| 强空头共振 | KD死叉+K>70 | MACD死叉或柱线翻绿 | S级 | 立即出场或做空×1.5 |
| 中空头共振 | KD死叉+K>50 | MACD柱线缩短（将死未死） | A级 | 减仓或确认后做空 |
| 弱空头共振 | KD死叉+K<50 | MACD死叉 | B级 | 轻仓做空或观望 |

**共振入场规则**：
1. KD信号先出现，MACD信号后出现（最佳顺序）
2. 两个信号出现时间差≤5根K线
3. 价格出现同向反转K线确认
4. 成交量配合（多头共振需放量，空头共振可缩量）
5. 止损设在入场K线极值外+0.2xATR
6. 目标位按斐波那契扩展或前高/前低设定

**背离共振（最强信号）**：
- KD顶背离 + MACD顶背离 = S级卖出信号
- KD底背离 + MACD底背离 = S级买入信号
- 双背离共振成功率>80%
- 仓位可达标准仓×2（最高级别信号）

**背离共振入场规则**：
1. 两个指标同时出现背离结构
2. 价格出现明确反转K线（评分≥8分）
3. 背离确认后第1根同向K线收盘入场
4. 止损设在背离极值外+0.3xATR
5. 目标位至少1:3 R:R

**共振失败处理**：
- KD信号后MACD未跟随 = 假共振，按KD单独信号处理
- 双指标共振后价格反向运行 = 共振失效，止损离场
- 连续2次共振失效 = 该周期指标共振暂时失效

## 适用场景与禁忌
- **适用场景**：所有周期的趋势确认和反转识别，尤其适用于过滤KD假信号
- **禁忌场景**：单一指标信号即入场（未形成共振）；MACD严重滞后时等待MACD确认可能错过最佳入场点
- **核心约束**：共振是信号增强机制，不是信号生成机制，基础信号必须首先存在
