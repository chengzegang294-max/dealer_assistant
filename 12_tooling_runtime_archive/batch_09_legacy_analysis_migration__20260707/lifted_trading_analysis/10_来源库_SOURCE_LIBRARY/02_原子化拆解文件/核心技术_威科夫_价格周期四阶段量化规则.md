# 核心技术_威科夫_价格周期四阶段量化规则

## 核心定义
威科夫价格周期将市场划分为积累(A)、上涨(M)、派发(D)、下跌(M)四个阶段，通过价格波动结构、成交量特征、K线形态三维度量化判定当前所处阶段。

## 可量化执行标准

**阶段A 积累阶段判定条件（满足4项以上）**：
1. 前期下跌趋势明显，跌幅>10%
2. 价格开始横盘整理，波动幅度收窄（ATR递减20%+）
3. 成交量在下跌末端放量（>均量150%），随后缩量整理
4. 出现弹簧(Spring)现象：价格短暂跌破横盘区间下轨后迅速回到区间内
5. 自动反弹(AR)出现：从区间下轨的自动反弹幅度>区间高度的30%
6. 二次测试(ST)：价格再次测试区间下轨，成交量萎缩

**阶段B 上涨阶段判定条件（满足4项以上）**：
1. 价格突破区间上轨+收盘于上轨外侧
2. 突破时成交量放大（>均量120%）
3. 回踩测试突破点（回测）时不跌破区间上轨
4. 回测成交量萎缩（<突破时成交量的70%）
5. 高点持续抬高，低点持续抬高
6. 均线系统多头排列（5EMA>20EMA>60EMA）

**阶段C 派发阶段判定条件（满足4项以上）**：
1. 前期上涨趋势明显，涨幅>10%
2. 价格开始横盘整理，波动幅度收窄
3. 上涨末端成交量异常放大或萎缩
4. 出现上抛(UT)现象：价格短暂突破横盘区间上轨后迅速回到区间内
5. 自然回落(LPSY)：从区间高点的回落幅度>区间高度的30%
6. 最后支撑点(LPS)：价格测试区间下沿，成交量放大

**阶段D 下跌阶段判定条件（满足4项以上）**：
1. 价格跌破区间下轨+收盘于下轨外侧
2. 跌破时成交量放大
3. 反弹测试跌破点时不突破区间下轨
4. 反弹成交量萎缩
5. 高点持续降低，低点持续降低
6. 均线系统空头排列（5EMA<20EMA<60EMA）

**阶段判定优先级**：
- 成交量特征 > 价格结构 > 时间因素
- 弹簧/上抛是阶段转换的最强信号
- 阶段B和D必须有突破+回测确认

## 适用场景与禁忌
- **适用场景**：股票/指数的中期波段（周线/日线）阶段判定，用于确定大方向
- **禁忌场景**：5分钟等超短周期威科夫阶段判定不可靠；单一信号判定阶段禁止交易
- **核心约束**：威科夫周期以日线/周线为主要判定周期，小周期仅作入场时机选择
