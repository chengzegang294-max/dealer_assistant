# 技术指标_补充技术_成交量形态量化识别规则

## 核心定义
成交量形态分析是通过成交量的异常变化（放量、缩量、堆量等）判断资金动向和趋势健康度的补充技术方法。

## 可量化执行标准

**成交量关键形态量化**：

| 形态 | 量化条件 | 市场含义 | 交易动作 |
|------|---------|---------|---------|
| 底部放量 | 价格低位+成交量>5日均量200%+阳线 | 资金抄底 | 关注反转信号 |
| 顶部放量 | 价格高位+成交量>5日均量200%+阴线 | 资金出逃 | 警惕顶部 |
| 上涨缩量 | 价格上涨+成交量<5日均量70% | 上涨乏力 | 不追涨，准备减仓 |
| 下跌缩量 | 价格下跌+成交量<5日均量70% | 抛压枯竭 | 不杀跌，准备抄底 |
| 量价齐升 | 价格上涨+成交量>5日均量150% | 健康上涨 | 顺势持有或加仓 |
| 量价齐跌 | 价格下跌+成交量>5日均量150% | 恐慌下跌 | 等待止跌信号 |
| 堆量整理 | 横盘+成交量阶梯式放大 | 主力吸筹 | 关注突破方向 |
| 缩量整理 | 横盘+成交量阶梯式缩小 | 洗盘整理 | 等待变盘 |

**成交量与KD共振规则**：
- KD金叉+放量 = 上涨信号确认
- KD金叉+缩量 = 假金叉嫌疑
- KD死叉+放量 = 下跌信号确认
- KD死叉+缩量 = 假死叉嫌疑
- KD底背离+底部放量 = 强反转信号
- KD顶背离+顶部放量 = 强反转信号

**均量线量化规则**：
- 5日均量>60日均量 = 量能趋势向上
- 5日均量<60日均量 = 量能趋势向下
- 成交量上穿均量线+价格上涨 = 买入信号
- 成交量下穿均量线+价格下跌 = 卖出信号

## 适用场景与禁忌
- **适用场景**：趋势健康度判断、反转确认、主力行为识别
- **禁忌场景**：单一成交量信号不做交易依据；小盘股成交量分析可能失真
- **核心约束**：成交量是价格变动的确认指标，不是预测指标
