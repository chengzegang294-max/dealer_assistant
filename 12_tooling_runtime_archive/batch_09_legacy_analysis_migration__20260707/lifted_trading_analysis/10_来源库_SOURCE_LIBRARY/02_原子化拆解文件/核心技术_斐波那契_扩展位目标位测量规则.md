# 核心技术_斐波那契_扩展位目标位测量规则

## 核心定义
斐波那契扩展位(Fibonacci Extension)是基于黄金分割比率的趋势运行目标位预测系统，用于测量趋势延续时的潜在目标价格。

## 可量化执行标准

**主要扩展位定义**：

| 扩展位 | 比率 | 适用场景 | 目标位计算方式 |
|--------|------|---------|---------------|
| 保守扩展 | 1.0 | 弱势趋势/第一波推动 | 回调波段等幅投射 |
| 标准扩展 | 1.272 | 中趋势/常规推动 | 前波段×1.272 |
| 激进扩展 | 1.618 | 强趋势/主升浪 | 前波段×1.618 |
| 极限扩展 | 2.0 | 极强趋势/赶顶赶底 | 前波段×2.0 |
| 极端扩展 | 2.618 | 极端行情/泡沫阶段 | 前波段×2.618 |
| 超极限 | 4.236 | 历史性行情 | 前波段×4.236 |

**ABCD形态扩展目标位**：
- D点目标 = C点 ± (B-A)×1.272（保守）
- D点目标 = C点 ± (B-A)×1.618（标准）
- D点目标 = C点 ± (B-A)×2.0（激进）
- D点确认：价格触及扩展位+反转信号+成交量异常

**三推动形态扩展目标位**：
- 第2推动目标 = 第1推动×1.0-1.618
- 第3推动目标 = 第1推动×1.618-2.618
- 第3推动为最终目标，完成后大概率反转

**目标位叠加确认**：
- 1.618扩展位与前期极点共振 = 高概率目标
- 1.272扩展位与斐波那契回调位（如0.618）重叠 = 强阻力/支撑
- 多个扩展位间距<0.5xATR = 目标密集区，重点关注

## 适用场景与禁忌
- **适用场景**：趋势持仓的目标位设定、形态交易（ABCD/三推动）的D点预测
- **禁忌场景**：反转行情中禁止使用扩展位目标；无明确ABCD结构时禁止预测D点
- **核心约束**：扩展位目标需分批平仓（1.272平50%/1.618平75%/2.0平100%）
