# 特色优化_仓位动态优化量化规则

## 核心定义
仓位动态优化是根据趋势强度、信号质量、市场环境三维度实时调整持仓仓位的系统化规则，实现强趋势重仓、弱趋势轻仓、震荡观望。

## 可量化执行标准

**基础仓位模型**：

| 趋势强度 | 趋势评分 | 基础仓位 | 最大持仓 |
|---------|---------|---------|---------|
| 极强趋势 | 10-12分 | 80% | 5只 |
| 强趋势 | 7-9分 | 60% | 4只 |
| 中趋势 | 4-6分 | 40% | 3只 |
| 弱趋势 | 1-3分 | 20% | 2只 |
| 无趋势 | 0分 | 0% | 空仓 |

**信号质量仓位乘数**：

| 信号质量 | 乘数 | 适用场景 |
|---------|------|---------|
| S级 | ×1.5 | 多周期共振+强形态+放量 |
| A级 | ×1.2 | 双周期共振+标准形态 |
| B级 | ×1.0 | 单周期信号+标准形态 |
| C级 | ×0.7 | 弱信号或单一指标 |
| D级 | ×0.3或不交易 | 疑似信号 |

**市场环境仓位调整**：

| 市场环境 | 仓位调整 | 说明 |
|---------|---------|------|
| 大盘强趋势 | 基础仓位×1.2 | 允许满仓 |
| 大盘震荡 | 基础仓位×1.0 | 按基础执行 |
| 大盘弱势 | 基础仓位×0.6 | 降低仓位 |
| 系统性风险 | 基础仓位×0.0 | 空仓 |

**实际仓位计算公式**：
```
实际仓位 = 基础仓位 × 信号质量乘数 × 市场环境系数
单笔仓位 = min(实际仓位, 25%账户资金)
```

**加仓规则**：
- 浮盈>15%后可加仓（加仓量≤原仓位的50%）
- 加仓必须有新的入场信号（不可无信号加仓）
- 最多加仓1次（避免越加越重）
- 加仓后止损统一上移至最新加仓点的成本线

**减仓规则**：
- 浮亏达5%减仓30%
- 趋势强度从强转中减仓30%
- 大盘走弱减仓30%
- 减仓可多次执行直至清仓

## 适用场景与禁忌
- **适用场景**：所有交易品种的全周期仓位管理
- **禁忌场景**：无信号加仓、满仓单只标的、亏损加仓
- **核心约束**：仓位管理是风险控制的核心，任何情况下不得突破仓位上限
