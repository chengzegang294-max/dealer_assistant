# 技术指标_时空波浪_推动浪与调整浪量化特征

## 核心定义
推动浪(Impulse Wave)是与主趋势同向的5浪结构，调整浪(Corrective Wave)是与主趋势反向的3浪结构，两者在幅度、时间、成交量上有明确可量化的区别特征。

## 可量化执行标准

**推动浪5子浪量化特征**：

| 特征维度 | 1浪 | 3浪 | 5浪 |
|---------|------|------|------|
| 幅度 | 基准X | 1.0-2.618X（最长） | 0.618-1.0X |
| 时间 | 基准T | 1.0-1.618T | 0.5-1.0T |
| 成交量 | 温和放大 | 最大放量 | 缩量或平量 |
| 子浪结构 | 清晰5浪 | 最清晰5浪 | 可能失败（缩短） |
| 动量(KD) | 50-70 | 70-80（最强） | 50-70（可能背离） |

**调整浪3子浪量化特征**：

| 特征维度 | A浪 | B浪 | C浪 |
|---------|------|------|------|
| 幅度 | 5浪的0.236-0.5 | A浪的0.382-0.786 | ≥A浪或1.0-1.618×A浪 |
| 时间 | 较短 | 较短 | 较长 |
| 成交量 | 开始萎缩 | 缩量反弹 | 可能放量（恐慌） |
| 子浪结构 | 5浪或3浪 | 3浪（最复杂） | 5浪 |
| 动量(KD) | 从高位回落 | 50附近反弹 | 低位或超卖 |

**推动浪vs调整浪判别**：

| 判别指标 | 推动浪特征 | 调整浪特征 |
|---------|-----------|-----------|
| 趋势方向 | 与主趋势同向 | 与主趋势反向 |
| 子浪结构 | 5个子浪 | 3个子浪（或三角形） |
| 成交量 | 整体放量 | 整体缩量 |
| 动能指标 | 持续强势 | 动能减弱 |
| 5/10日均线 | 均线发散向上 | 均线收敛或走平 |
| MACD | 柱线持续同向 | 柱线缩短或交叉 |

**调整浪深度预判**：
- 强势调整：0.236×推动浪（浅调整，趋势极强）
- 正常调整：0.382×推动浪（健康调整）
- 深度调整：0.5×推动浪（调整较深，警惕）
- 极端调整：0.618×推动浪（趋势可能终结）
- >0.618×推动浪：趋势大概率反转，非调整

## 适用场景与禁忌
- **适用场景**：趋势结构识别、调整结束预判、加仓点选择
- **禁忌场景**：推动浪和调整浪判别不清时禁止交易；单一特征判别需综合验证
- **核心约束**：推动浪和调整浪的判别是波浪分析的基础，误判会导致方向性错误
