# 交易系统_复盘优化_量化复盘规则

## 核心定义
交易复盘是对每笔交易、每日交易、每周交易的系统化回顾分析，通过数据化复盘找出系统缺陷、优化参数、提升胜率。

## 可量化执行标准

**单笔复盘模板**：

| 复盘项目 | 记录内容 | 评估标准 |
|---------|---------|---------|
| 入场质量 | 信号等级/入场价/止损价/目标价 | A-D级评定 |
| 入场理由 | 技术信号/基本面/消息面 | 是否符合规则 |
| 实际R:R | (目标-入场)/(入场-止损) | ≥1:2为合格 |
| 执行质量 | 是否按计划入场/止损/止盈 | 优秀/良好/差 |
| 结果 | 盈利/亏损/盈亏比 | 统计记录 |
| 改进点 | 可优化之处 | 具体建议 |

**日复盘流程**：
1. 记录当日所有交易（入场/出场/盈亏）
2. 计算当日胜率、盈亏比、最大回撤
3. 对比大盘和板块表现，评估相对收益
4. 标记违反规则的交易（违规次数统计）
5. 记录市场情绪和技术观察

**周复盘流程**：
1. 统计周胜率、盈亏比、最大回撤、夏普比率
2. 分析盈利交易共性（找出优势场景）
3. 分析亏损交易共性（找出系统漏洞）
4. 评估市场状态判断准确度
5. 制定下周交易计划和改进措施

**月度系统优化**：
- 月度胜率<50% → 检查入场信号是否过于宽松
- 月度盈亏比<1.5 → 检查止盈止损设置是否合理
- 月度回撤>8% → 检查仓位管理是否合规
- 连续2月亏损 → 暂停实盘，回测验证系统

**关键绩效指标(KPI)**：
- 胜率目标：≥55%
- 盈亏比目标：≥2.0
- 最大回撤：≤8%/月
- 夏普比率：>1.5
- 交易频率：日均1-3笔

## 适用场景与禁忌
- **适用场景**：所有交易者的系统化复盘和持续优化
- **禁忌场景**：不复盘直接继续交易；复盘不记录不分析
- **核心约束**：复盘是交易进步的唯一途径，没有复盘的系统无法进化
