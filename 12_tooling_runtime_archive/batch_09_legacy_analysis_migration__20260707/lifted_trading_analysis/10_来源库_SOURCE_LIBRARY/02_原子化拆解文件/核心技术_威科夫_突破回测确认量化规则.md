# 核心技术_威科夫_突破回测确认量化规则

## 核心定义
突破回测(Breakout Test/Back Test)是价格突破区间边界后，回到原边界附近测试支撑/阻力有效性的行为，是威科夫阶段B（上涨）和阶段D（下跌）的关键确认信号。

## 可量化执行标准

**突破确认条件（全部满足）**：
1. 价格突破区间边界（上轨或下轨）
2. 突破时成交量放大（>均量120%）
3. 突破棒收盘于区间边界外侧
4. 次棒确认：次棒收盘仍于区间外侧

**回测成功判定（多头突破后回测，空头反之）**：
1. 价格回踩区间上轨（原阻力位现变支撑位）
2. 回踩幅度≤区间高度的30%
3. 回踩时成交量萎缩（<突破时成交量的70%）
4. 回踩后出现多头信号K线（评分≥5分）
5. 价格不再跌破区间上轨

**回测失败判定（假突破）**：
1. 价格回到区间内并收盘于区间边界内侧
2. 回踩时成交量放大（>突破时成交量）
3. 连续2根棒线收盘于区间内
4. 出现反向信号K线

**突破回测入场规则**：

| 入场类型 | 入场点 | 止损 | 目标 | 仓位 |
|---------|--------|------|------|------|
| 突破入场 | 突破棒收盘于区间外 | 区间边界内侧+0.2xATR | 区间高度×1.618 | 标准仓×0.8 |
| 回测入场 | 回测信号K线收盘 | 回测低点-0.2xATR | 区间高度×1.618 | 标准仓 |
| 二次突破 | 回测后再次突破前高 | 回测低点-0.2xATR | 区间高度×2.0 | 标准仓×1.2 |

**A股特殊适配**：
- T+1制度下，回测入场优于突破入场（避免当日假突破被套）
- 突破后次日高开低走不回测 = 可能为诱多，需谨慎
- 突破后3日内完成回测确认 = 有效突破概率高

## 适用场景与禁忌
- **适用场景**：日线/周线级别的区间突破交易，是威科夫体系最可靠的入场信号
- **禁忌场景**：突破时无成交量放大禁止追单；回测超过区间高度50%视为回测失败
- **核心约束**：突破回测是阶段B和D的必经之路，无回测的突破大概率是假突破
