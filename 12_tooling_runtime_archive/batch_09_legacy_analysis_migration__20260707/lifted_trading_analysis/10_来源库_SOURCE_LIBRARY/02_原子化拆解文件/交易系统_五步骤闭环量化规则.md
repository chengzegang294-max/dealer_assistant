# 交易系统_五步骤闭环量化规则

## 核心定义
交易系统完整闭环是指「选股→择时→买入→持仓管理→卖出」五个步骤的标准化执行流程，每个步骤有明确量化标准，形成完整交易链路。

## 可量化执行标准

**步骤一：选股量化标准**

| 筛选维度 | 量化条件 | 权重 |
|---------|---------|------|
| 趋势筛选 | 20EMA向上+价格在20EMA上方 | 20% |
| 成交量筛选 | 5日均量>20日均量×1.2 | 15% |
| 波动率筛选 | ATR(14)在2-6%区间 | 10% |
| 市值筛选 | 流通市值30-500亿 | 10% |
| 技术形态 | 处于阶段B上涨或突破回测中 | 20% |
| 板块效应 | 所属板块5日涨幅>大盘 | 15% |
| 基本面 | 无ST/无退市风险/非重大问题 | 10% |

- 综合评分≥75分的标的进入观察池
- 观察池最多10只标的，超出剔除最低分

**步骤二：择时量化标准**

| 择时信号 | 量化条件 | 信号强度 |
|---------|---------|---------|
| 强信号 | 回调至20EMA+反转K线(>7分)+KD<30 | A级 |
| 中信号 | 回调至10EMA+反转K线(>6分)+KD<40 | B级 |
| 弱信号 | 突破前高+回踩确认+KD<50 | C级 |

- A级信号：立即建仓
- B级信号：观察1日确认后建仓
- C级信号：等待更强信号

**步骤三：买入量化标准**
- 入场K线收盘后买入（避免盘中波动干扰）
- 仓位按信号等级分配：A级100%/B级70%/C级50%
- 买入时同时设定止损位和目标位
- R:R<1:1.5的交易禁止买入

**步骤四：持仓管理量化标准**

| 持仓阶段 | 管理动作 | 量化条件 |
|---------|---------|---------|
| 盈利期 | 移动止盈 | 浮盈>15%止损上移成本+5% |
| 亏损期 | 严格止损 | 触及止损位无条件平仓 |
| 震荡期 | 观察等待 | 价格在成本±3%内运行>5日 |
| 加速期 | 持有不动 | 连续3日大涨且量价齐升 |

**步骤五：卖出量化标准**
- 止损卖出：触及预设止损位立即执行
- 止盈卖出：达到预设目标位分批执行（30%/30%/20%/20%）
- 技术卖出：跌破20日线或均线死叉执行
- 时间卖出：持股>15天无收益强制评估

## 适用场景与禁忌
- **适用场景**：所有交易品种的标准化交易流程
- **禁忌场景**：跳过任一步骤直接进入交易；步骤执行不严格打折
- **核心约束**：五步闭环必须完整执行，缺失任一步骤即为不完整交易
