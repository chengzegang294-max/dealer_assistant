# 核心技术_威科夫_复合人操作量化分析

## 核心定义
复合人(Composite Operator)是威科夫理论中对机构主力/大资金操作行为的抽象概念，通过识别复合人的积累-拉升-派发-打压的完整操作周期，跟随主力资金方向进行交易。

## 可量化执行标准

**复合人积累行为识别（满足3项以上）**：
1. 价格下跌末期成交量异常放大（恐慌盘涌出）
2. 价格进入横盘区间，波动收窄（主力吸筹）
3. 区间内多次出现弹簧现象（清洗浮筹）
4. 自动反弹(AR)后二次测试(ST)成交量萎缩
5. 区间内高点和低点逐步抬高（吸筹痕迹）
6. 大单成交占比提升（>日均水平20%）

**复合人拉升行为识别（满足3项以上）**：
1. 价格突破区间上轨+成交量持续放大
2. 突破后回测不跌破区间上轨
3. 均线系统多头排列
4. 上涨过程中回调时间短（<5根K线）、幅度小（<30%涨幅）
5. 量价齐升，无背离现象

**复合人派发行为识别（满足3项以上）**：
1. 价格上涨末期成交量异常放大或萎缩
2. 价格进入横盘区间，波动收窄
3. 区间内多次出现上抛现象（诱多）
4. 自然回落(LPSY)后最后支撑点(LPS)成交量放大
5. 区间内高点和低点逐步降低

**复合人打压行为识别（满足3项以上）**：
1. 价格跌破区间下轨+成交量放大
2. 跌破后反弹不突破区间下轨
3. 均线系统空头排列
4. 下跌过程中反弹时间短（<5根K线）、幅度小

**跟随复合人交易策略**：
- 阶段A（积累）：不操作，观察和等待弹簧信号
- 阶段B（上涨）：回测入场，顺势持仓
- 阶段C（派发）：不操作，观察UT信号准备做空
- 阶段D（下跌）：反弹入场做空，顺势持仓

## 适用场景与禁忌
- **适用场景**：大盘股/指数等主力资金主导的品种，日线/周线级别分析
- **禁忌场景**：小盘股/庄股主力行为过于隐蔽，复合人分析可能失效；散户主导品种量价关系失真
- **核心约束**：复合人分析是方向性判断工具，具体入场仍需等待价格信号确认
