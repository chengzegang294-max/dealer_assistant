# 技术指标_随机指标_KD背离量化判定规则

## 核心定义
KD背离是价格走势与KD指标走势出现不一致的现象，是趋势反转的重要预警信号，分为顶背离（看跌）和底背离（看涨）两种。

## 可量化执行标准

**顶背离量化判定（看跌信号）**：

| 判定条件 | 量化标准 | 权重 |
|---------|---------|------|
| 价格创新高 | 当前高点>前高点（幅度>0.5xATR） | 必需 |
| KD未创新高 | 当前KD高点<前KD高点 | 必需 |
| KD位置 | KD>70（高位背离更可靠） | 增强 |
| 背离次数 | 连续2次+背离（二次背离） | 极强信号 |
| 背离幅度 | 价格涨幅>前涨幅但KD差值>5 | 增强 |
| K线确认 | 背离后出现空头反转K线 | 确认信号 |

**底背离量化判定（看涨信号）**：

| 判定条件 | 量化标准 | 权重 |
|---------|---------|------|
| 价格创新低 | 当前低点<前低点（幅度>0.5xATR） | 必需 |
| KD未创新低 | 当前KD低点>前KD低点 | 必需 |
| KD位置 | KD<30（低位背离更可靠） | 增强 |
| 背离次数 | 连续2次+背离（二次背离） | 极强信号 |
| 背离幅度 | 价格跌幅>前跌幅但KD差值>5 | 增强 |
| K线确认 | 背离后出现多头反转K线 | 确认信号 |

**背离强度评级**：

| 评级 | 条件 | 成功率 | 仓位建议 |
|------|------|--------|---------|
| S级 | 二次背离+KD极值区+大实体反转K线 | 75%+ | 标准仓×1.5 |
| A级 | 一次背离+KD极值区+明确反转K线 | 65-75% | 标准仓 |
| B级 | 一次背离+KD非极值区+一般反转K线 | 55-65% | 标准仓×0.7 |
| C级 | 疑似背离+无明确反转K线 | <55% | 观望 |

**背离失败处理**：
- 价格继续创新高/新低且KD也创新高/新低 = 背离失效
- 背离后反向运行5根K线无确认 = 背离失效
- 连续2次背离失效 = 趋势极强，暂停反向交易

## 适用场景与禁忌
- **适用场景**：趋势末端反转预判、震荡区间边缘反转识别
- **禁忌场景**：背离出现后无反转K线确认禁止入场；强趋势中首次背离常失效
- **核心约束**：背离是预警信号不是交易信号，必须等待价格行为确认
