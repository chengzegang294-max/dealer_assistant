# 特色优化_趋势衰竭点量化识别规则

## 核心定义
趋势衰竭点是趋势运行至末端，动量枯竭即将反转的临界点，通过背离、缩量、形态等量化信号识别，用于及时止盈或反向开仓。

## 可量化执行标准

**趋势衰竭点量化条件（满足3项以上）**：
1. KD顶背离：价格新高但KD未新高（差值>5）
2. MACD顶背离：价格新高但MACD柱线/快线未新高
3. 成交量萎缩：价格上涨但成交量<5日均量80%
4. 形态信号：出现射击之星/黄昏之星/空头吞没
5. 波浪结构：5浪完成或5浪失败（5浪<3浪高点）
6. 时间周期：到达斐波那契时间窗口（13/21/34日）
7. 均线偏离：价格偏离20EMA>2xATR（极端偏离）
8. 波动率下降：ATR连续5日递减（动力减弱）
9. 情绪指标：涨停数量从峰值下降>50%

**趋势衰竭点强度分级**：

| 等级 | 条件 | 操作动作 | 仓位 |
|------|------|---------|------|
| S级 | 5项+满足+双背离 | 立即清仓+反向轻仓 | 反向标准仓×0.7 |
| A级 | 4项满足+单背离 | 减仓50%+移动止盈 | 减仓后持有 |
| B级 | 3项满足无背离 | 减仓30%+ tighten止损 | 减仓后持有 |
| C级 | <3项满足 | 移动止盈持有 | 维持仓位 |

**衰竭确认规则**：
- 价格跌破5EMA且3日不收回 = 衰竭确认
- 价格跌破前波段低点 = 趋势结束确认
- 衰竭信号后价格继续新高 = 信号失效，重新评估

## 适用场景与禁忌
- **适用场景**：趋势持仓的止盈决策、趋势末端反向交易
- **禁忌场景**：强趋势中首次衰竭信号常失效，需多次确认；无背离的衰竭信号谨慎对待
- **核心约束**：趋势衰竭点识别难度高于启动点，宁可早出场不晚出
