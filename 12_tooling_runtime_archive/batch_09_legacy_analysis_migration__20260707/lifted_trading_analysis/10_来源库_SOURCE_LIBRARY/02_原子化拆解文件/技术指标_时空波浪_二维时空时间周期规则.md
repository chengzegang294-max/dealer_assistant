# 技术指标_时空波浪_二维时空分析时间周期规则

## 核心定义
二维时空分析是将时间维度与价格空间维度结合的分析方法，通过斐波那契时间周期与波浪结构的共振，预测市场变盘时间节点。

## 可量化执行标准

**时间周期与波浪对应关系**：

| 波浪 | 时间比例 | 斐波那契时间窗口 | 变盘概率 |
|------|---------|-----------------|---------|
| 1浪 | 基准时间T | 启动时间点 | - |
| 2浪 | 0.382T - 0.618T | 1浪时间×0.5 | 中高 |
| 3浪 | 1.0T - 1.618T | 1浪时间×1.0/1.618 | 高 |
| 4浪 | 0.5×3浪时间 | 3浪时间×0.5 | 中 |
| 5浪 | 0.5T - 1.0T | 1浪时间×0.618/1.0 | 中高 |
| A浪 | 0.382×5浪时间 | 5浪时间×0.382 | 中 |
| B浪 | 0.5×A浪时间 | A浪时间×0.5 | 低 |
| C浪 | 1.0×A浪时间 | A浪时间×1.0/1.618 | 高 |

**二维共振判定（时间+空间）**：
1. 价格到达斐波那契回调/扩展位
2. 同时到达斐波那契时间窗口
3. 两者同时满足 = 高概率变盘
4. 空间到位但时间未到 = 可能延续，需等待
5. 时间到位但空间未到 = 可能加速，需观察

**周期嵌套分析**：
- 大浪时间周期内嵌套小浪时间周期
- 大浪5浪结束时间 + 小浪5浪结束时间 = 强共振
- 大浪2浪回调时间 + 小浪调整时间 = 调整结束信号

**A股特殊时间窗口**：
- 日线：5-8-13-21天为关键变盘窗口
- 周线：5-8-13周为中期变盘窗口
- 月线：3-5-8月为长期变盘窗口
- 结合农历节气/月底/季度末增强变盘概率

## 适用场景与禁忌
- **适用场景**：大周期持仓的时间管理、变盘节点预警
- **禁忌场景**：单独时间窗口无价格信号不交易；小周期时间分析噪音过多
- **核心约束**：时间分析是辅助工具，必须与价格行为共振才可作为交易信号
