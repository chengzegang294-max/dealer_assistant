# 核心技术_斐波那契_扇形线趋势分析规则

## 核心定义
斐波那契扇形线(Fibonacci Fan)是从波段极点出发，按38.2%、50%、61.8%角度辐射的三条趋势线，用于动态支撑阻力判定。

## 可量化执行标准

**扇形线绘制方法**：
1. 确定重要波段极点（显著高点或低点）
2. 从极点向右侧绘制水平基线至对侧波段极点
3. 从起点按38.2%/50%/61.8%角度绘制三条辐射线
4. 价格与扇形线交叉点=潜在支撑/阻力位

**扇形线支撑阻力量化规则**：

| 扇形线 | 角度比率 | 支撑/阻力强度 | 价格触及后反应 |
|--------|---------|--------------|---------------|
| 38.2%线 | 最平缓 | 弱支撑/阻力 | 可能短暂停顿后继续原方向 |
| 50%线 | 中等 | 中支撑/阻力 | 可能回调或整理 |
| 61.8%线 | 最陡峭 | 强支撑/阻力 | 高概率反转或大幅回调 |

**扇形线交易信号**：
- 价格从上方回调至61.8%扇形线+反转K线 = 多头入场
- 价格从下方反弹至61.8%扇形线+反转K线 = 空头入场
- 价格突破61.8%扇形线+收盘于线外 = 趋势加速信号
- 价格沿50%扇形线运行 = 趋势正常，持仓不动

**扇形线与形态结合**：
- ABCD形态的D点落在61.8%扇形线上 = 高概率反转点
- 三推动的第三推动末端触及61.8%扇形线 = 趋势终结信号
- 扇形线与水平斐波那契回调位共振 = 超强支撑/阻力

## 适用场景与禁忌
- **适用场景**：趋势运行中的动态支撑阻力判定、持仓期间的趋势健康监测
- **禁忌场景**：无明确波段极点的震荡行情中扇形线失效；单根扇形线无其他信号禁止交易
- **核心约束**：扇形线需定期重新绘制（每出现新极点时），旧扇形线失效
