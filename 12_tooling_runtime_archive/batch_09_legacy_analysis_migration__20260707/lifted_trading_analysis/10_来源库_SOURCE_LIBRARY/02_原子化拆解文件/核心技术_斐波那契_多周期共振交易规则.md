# 核心技术_斐波那契_多周期共振交易规则

## 核心定义
斐波那契多周期共振是指日线、4小时、1小时等多个时间周期的斐波那契回调位/扩展位在同一价格区域重叠，形成超强支撑/阻力区域。

## 可量化执行标准

**共振类型与量化判定**：

| 共振类型 | 构成条件 | 反转概率 | 仓位建议 |
|---------|---------|---------|---------|
| 双周期回调共振 | 日线回调位与4小时回调位价差<0.5xATR | 65-75% | 标准仓位 |
| 三周期回调共振 | 日+4H+1H回调位价差<0.5xATR | 75-85% | 标准仓位×1.2 |
| 回调-扩展共振 | 日线回调位与4小时扩展位重叠 | 70-80% | 标准仓位×1.2 |
| 多工具共振 | 斐波那契位+EMA+趋势线+前极点汇聚 | 80-90% | 标准仓位×1.5 |

**共振区域入场规则**：
1. 价格进入共振区域±0.3xATR范围内开始观察
2. 等待明确反转K线信号（吞没/锤子/十字星）
3. 成交量萎缩至5日均量80%以下 = 动能衰竭确认
4. KD指标处于超买(>80)或超卖(<20)区域 = 增强信号
5. 止损设在共振区域外侧+0.3xATR

**共振失败处理**：
- 价格突破共振区域+收盘于外侧+成交量放大 = 共振失效
- 共振失效后顺势追单，止损设在共振区域内侧
- 连续2次共振失效 = 该周期斐波那契工具暂时失效，切换周期

## 适用场景与禁忌
- **适用场景**：大级别支撑/阻力位识别、高概率入场点选择、关键目标位设定
- **禁忌场景**：共振区域无明确反转信号禁止入场；共振区域过宽（>1xATR）意义降低
- **核心约束**：多周期共振是最高优先级交易信号，仓位可放大但止损不可放宽
