# 核心技术_ALBrooks_入场形态20个量化判定

## 核心定义
AL Brooks定义的20种入场K线形态，每种形态对应独立的可量化入场条件，分为趋势跟随、反转、区间交易三大类。

## 适用场景与禁忌
- **适用场景**：5分钟/15分钟/1小时周期均可适用，形态需与总在场内方向一致
- **禁忌场景**：形态信号与总在场内方向相反时禁止入场（反转形态除外）；信号棒评分不达标时禁止入场
- **核心约束**：单次入场最多使用2个形态叠加确认，禁止3个以上形态同时解读导致的过度分析
