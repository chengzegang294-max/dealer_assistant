# 技术指标_随机指标_KD基础用法量化规则

## 核心定义
KD指标（随机指标）是通过比较收盘价与一定周期内价格区间的相对位置，判断超买超卖和动量变化的震荡指标，K线为快线，D线为慢线。

## 可量化执行标准

**KD计算公式**：
- RSV = (收盘价 - N日内最低价) / (N日内最高价 - N日内最低价) × 100
- K = 2/3 × 前日K + 1/3 × 当日RSV
- D = 2/3 × 前日D + 1/3 × 当日K
- 默认参数：N=9，K=3，D=3

**KD超买超卖量化标准**：

| 区域 | KD值范围 | 市场含义 | 交易动作 |
|------|---------|---------|---------|
| 严重超卖 | K<10且D<10 | 极度弱势，可能反弹 | 准备抄底，等待反转信号 |
| 超卖区 | K<20且D<20 | 弱势，反弹概率增加 | 关注反转信号 |
| 弱势区 | 20<KD<50 | 相对弱势 | 观望或做空 |
| 中性区 | KD≈50 | 多空平衡 | 观望 |
| 强势区 | 50<KD<80 | 相对强势 | 观望或做多 |
| 超买区 | K>80且D>80 | 强势，回调概率增加 | 关注反转信号 |
| 严重超买 | K>90且D>90 | 极度强势，可能回调 | 准备逃顶，等待反转信号 |

**KD金叉死叉量化规则**：

| 信号类型 | 触发条件 | 有效性要求 | 交易动作 |
|---------|---------|-----------|---------|
| 金叉买入 | K线上穿D线 | K<50区域金叉更可靠 | 金叉+价格反转K线入场 |
| 死叉卖出 | K线下穿D线 | K>50区域死叉更可靠 | 死叉+价格反转K线出场 |
| 高位二次死叉 | KD>80后死叉再金叉再死叉 | 顶背离确认 | 立即减仓或清仓 |
| 低位二次金叉 | KD<20后金叉再死叉再金叉 | 底背离确认 | 立即建仓或加仓 |

**KD参数优化**：
- 短线交易：N=5，K=3，D=3（更敏感）
- 中线交易：N=9，K=3，D=3（标准参数）
- 长线交易：N=14，K=3，D=3（更平滑）
- 波动率大的品种：N=14（减少噪音）
- 波动率小的品种：N=5（增加敏感度）

## 适用场景与禁忌
- **适用场景**：震荡行情中的超买超卖判断、趋势行情中的动量确认
- **禁忌场景**：强趋势中KD持续超买/超卖时禁止逆势操作；KD单独使用不做交易依据
- **核心约束**：KD是震荡指标，强趋势中会钝化，必须结合价格行为使用
