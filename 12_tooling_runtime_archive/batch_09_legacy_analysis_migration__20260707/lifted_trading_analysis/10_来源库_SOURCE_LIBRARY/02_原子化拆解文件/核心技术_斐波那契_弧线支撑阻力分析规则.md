# 核心技术_斐波那契_弧线支撑阻力分析规则

## 核心定义
斐波那契弧线(Fibonacci Arcs)是以波段极点为圆心，按38.2%/50%/61.8%比例画出的半圆形弧线，用于时间和价格共振点的识别。

## 可量化执行标准

**弧线绘制与解读**：
1. 确定重要波段极点作为圆心
2. 以38.2%/50%/61.8%比例画出三条半圆形弧线
3. 价格与弧线交叉点 = 潜在变盘点
4. 时间轴与弧线交叉点 = 潜在时间窗口

**弧线交叉交易规则**：

| 交叉类型 | 量化判定 | 交易信号 |
|---------|---------|---------|
| 价格触及61.8%弧线 | 价格触碰弧线+反转K线 | 反向入场，止损极值外 |
| 价格突破61.8%弧线 | 收盘于弧线外侧+确认K线 | 趋势延续，加仓或追单 |
| 50%弧线支撑 | 价格沿50%弧线运行不跌破 | 趋势健康，持仓不动 |
| 38.2%弧线跌破 | 收盘于38.2%弧线内侧 | 趋势转弱，减仓或平仓 |

**弧线与时间周期共振**：
- 价格触及弧线 + 斐波那契时间周期节点 = 强变盘信号
- 多条弧线在同一价格区域密集 = 强支撑/阻力区
- 弧线与水平回调位（0.618/0.786）共振 = 超高概率反转区

## 适用场景与禁忌
- **适用场景**：中长期持仓的时间-价格共振点识别、趋势终结预警
- **禁忌场景**：短线交易（<5根K线）中弧线无效；单弧线信号需价格行为确认
- **核心约束**：弧线分析以日线/4小时周期为主，小周期弧线噪音过多
