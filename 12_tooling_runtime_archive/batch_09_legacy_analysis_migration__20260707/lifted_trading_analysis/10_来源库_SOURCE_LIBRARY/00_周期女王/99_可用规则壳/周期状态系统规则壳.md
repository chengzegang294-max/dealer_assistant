## 2. LEXICON

### 2.1 势

- **TERM**: 势
- **DEFINITION_SENTENCE**: "涨幅有持续它就是势"（20240122）；"势就是涨幅，可持续的涨幅就是势，持续涨就是势"
- **STATE_AXIS_MAP**: 结构轴、驱动力轴
- **OBSERVABLE_EVIDENCE**: 10日区间涨幅榜排名持续上升；个股连续多日收盘价创新高；涨停时间早且能持续
- **FAILURE_MODES**: 把单日大涨当势（没有持续性）；把消息刺激当势（不可持续）；把连板数量当势忽略持续度
- **DO_NOT_DO**: 不要追单日暴涨无持续个股；不要把消息/题材当势；不要在没有10日区间涨幅榜验证时认定势已形成
- **SOURCE_ANCHOR**: 20240122用势交易_ev.mp4_导出.md — "什么是势？它就是涨幅，可持续的涨幅就是势"

### 2.2 一生（一生个股）

- **TERM**: 一生（一生个股）
- **DEFINITION_SENTENCE**: "所有可以在十个交易日上涨幅度超过100%的个股，都可以称之为一生个股"（20240310）
- **STATE_AXIS_MAP**: 结构轴
- **OBSERVABLE_EVIDENCE**: 10日区间涨幅榜上10个交易日内涨幅超过100%；成为10日区间涨幅榜常驻嘉宾；价格持续新高
- **FAILURE_MODES**: 把连板空间最高的个股当一生（可能只是余翁）；把涨停早但无持续的个股当一生；过早认定某股为一生（涨幅未到30%-40%进入视野时）
- **DO_NOT_DO**: 不要相互争谁是龙头/一生；不要执念某股一定能翻倍；不要鱼头鱼尾都想要，只吃鱼身
- **SOURCE_ANCHOR**: 20240310翻倍个股的表现形式_ev.mp4_导出.md — "所有可以在十个交易日上涨幅度超过100%的个股"

### 2.3 攻击有持续

- **TERM**: 攻击有持续
- **DEFINITION_SENTENCE**: "攻击有持续代表了上涨周期"；"状态只分为两种情况，攻击有持续和攻击无持续"（20240128）
- **STATE_AXIS_MAP**: 结构轴、驱动力轴
- **OBSERVABLE_EVIDENCE**: 前一天空间板可以继续涨；前一天涨停时间早的领涨可以继续涨；前交易日领涨和空间板都持续不换人；头部没有退潮力量
- **FAILURE_MODES**: 只看连板数量不看持续度；只看个股涨势不看阵型协同；忽略10日区间涨幅榜头部变化
- **DO_NOT_DO**: 不要频繁换股；不要在攻击有持续时过早下车；不要分散仓位去追包容度个股
- **SOURCE_ANCHOR**: 20240128用状态交易_ev.mp4_导出.md — "攻击有持续代表了上涨周期"

### 2.4 攻击无持续

- **TERM**: 攻击无持续
- **DEFINITION_SENTENCE**: "攻击无持续等于退潮"；"攻击无持续代表了下降周期"（20240128）
- **STATE_AXIS_MAP**: 结构轴、驱动力轴
- **OBSERVABLE_EVIDENCE**: 前一天空间板不能继续涨；前一天涨停时间早的领涨不能继续涨；频繁换领涨/换空间板；失败的空间板不能修复且持续下杀
- **FAILURE_MODES**: 把余翁阶段的反弹当攻击有持续；把换空间板过程中的短暂持续当攻击恢复；在第一天杀跌后就急于抄底
- **DO_NOT_DO**: 不要在攻击无持续时频繁交易；不要追空间板；不要意淫二波；不要参与余翁个股
- **SOURCE_ANCHOR**: 20240204用状态交易_ev.mp4_导出.md — "攻击无持续就等于退潮"

### 2.5 余温（余翁）

- **TERM**: 余温（余翁）
- **DEFINITION_SENTENCE**: "周期结束的尾声，鱼的尾巴，结束时的一种惯性"；"就是周期结束的尾声，上涨力量的惯性"（20240225）
- **STATE_AXIS_MAP**: 摩擦轴
- **OBSERVABLE_EVIDENCE**: 上一龙领涨高位反复无法新高；老面孔在高位震荡不跌；个股高位横盘或小幅反弹但无法持续新高；上涨个股数量减少但仍有活口
- **FAILURE_MODES**: 把余温阶段的个股当新领涨；把余温反弹当攻击恢复；在余温阶段追高空间板
- **DO_NOT_DO**: 不要在完成切割之前参与任何上涨个股（全部当余翁看）；不要在余温阶段追涨停；不要觉得"跌多了该反弹了"就去抄底余翁
- **SOURCE_ANCHOR**: 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "周期结束的尾声，鱼的尾巴，结束时的一种惯性"

### 2.6 切割

- **TERM**: 切割
- **DEFINITION_SENTENCE**: "上一轮周期彻底宣告结束的终点线"；"切割完成的条件只有这两种，不会有第三种"（20240225）
- **STATE_AXIS_MAP**: 结构轴
- **OBSERVABLE_EVIDENCE**: 上一龙领涨直接A杀持续跌；每天一个空间板换人且无持续（杀3-4个空间板）；完成切割后老龙退出10日区间涨幅榜头部
- **FAILURE_MODES**: 认为横着不跌就是切割完成；看到一个空间板死了就认定切割完成（需要持续观察）；忽略横盘阶段的诱惑提前动手
- **DO_NOT_DO**: 不要在切割完成前参与新攻击；不要觉得"已经跌了这么多该完了"；不要在每天杀空间板的过程中去试错
- **SOURCE_ANCHOR**: 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "上一轮周期彻底宣告结束的终点线"以及"切割完成的条件只有这两种"

### 2.7 孕化

- **TERM**: 孕化
- **DEFINITION_SENTENCE**: "新周期攻击没有确认之前，它都是孕化攻击阶段"；"十月怀胎，能不能平安生下来"（20240225）
- **STATE_AXIS_MAP**: 结构轴
- **OBSERVABLE_EVIDENCE**: 完成切割后出现新的尝试性领涨；新面孔个股开始尝试持续；但攻击阵型尚未完全确认；包容度扩散不明显
- **FAILURE_MODES**: 把孕化阶段的试错失败当整体退潮；在孕化期重仓试错；无法区分孕化失败和余翁未切割完
- **DO_NOT_DO**: 不要在孕化阶段重仓；不要把孕化期所有上涨个股都当一生；不要在孕化期频繁切换
- **SOURCE_ANCHOR**: 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "新周期攻击没有确认之前，它都是孕化攻击阶段"

### 2.8 确认攻击

- **TERM**: 确认攻击
- **DEFINITION_SENTENCE**: "前交易日的领涨能够带出扩散，形成攻击阵型，带动盘面情绪回暖，下一步就是确认攻击"（20240303）
- **STATE_AXIS_MAP**: 结构轴、驱动力轴
- **OBSERVABLE_EVIDENCE**: 前交易日领涨持续攻击；形成3-4只核心个股构成的攻击阵型；盘面有包容度（失败个股有修复）；头部没有退潮力量；带动情绪回暖
- **FAILURE_MODES**: 把单打独斗的个股持续当确认攻击；忽略攻击阵型是否完整；只看领涨持续不看包容度扩散
- **DO_NOT_DO**: 不要只盯一只个股不看阵型；不要在确认攻击阶段随意降仓；不要追已掉队的余翁个股
- **SOURCE_ANCHOR**: 20240303确认攻击的识别与把握_ev.mp4_导出.md — "前交易日的领涨能够带出扩散，形成攻击阵型，带动盘面情绪回暖"

### 2.9 交权磨合期

- **TERM**: 交权磨合期
- **DEFINITION_SENTENCE**: "在上一个领涨示弱交权的过程中，下一个领涨没有走出来"；"市场老龙头示弱、新龙头尚未清晰确立的过渡阶段"（20240128）
- **STATE_AXIS_MAP**: 结构轴、摩擦轴
- **OBSERVABLE_EVIDENCE**: 原领涨开始示弱（无法新高）；多个候选个股竞争新领涨位置；10日区间涨幅榜头部出现换人迹象；盘面多空交织
- **FAILURE_MODES**: 把交权期的短暂表现当确认交权；在交权未清晰时盲目站队；忽视交权期可能持续多天的特征
- **DO_NOT_DO**: 不要在交权未清晰时重仓；不要同时参与多个候选领涨；不要幻想无缝切换
- **SOURCE_ANCHOR**: 20240128用状态交易_ev.mp4_导出.md — "在上一个领涨示弱交权的过程中，下一个领涨没有走出来"

### 2.10 包容度

- **TERM**: 包容度
- **DEFINITION_SENTENCE**: "盘面一起上涨的个股"；"对发动攻击失败的个股有了包容度"（20240303）
- **STATE_AXIS_MAP**: 驱动力轴
- **OBSERVABLE_EVIDENCE**: 失败的空间板/涨停个股隔天有修复（地天板或反包）；非领涨个股也能涨；10日区间涨幅榜前十个一片通红；市场容错度高
- **FAILURE_MODES**: 把个股偶然的修复当包容度；忽视包容度需要持续多个交易日验证；把跟风上涨当真正包容度
- **DO_NOT_DO**: 不要因为包容度就放松选股标准；不要参与非领涨非攻击阵型的个股；不要觉得"市场好随便买"
- **SOURCE_ANCHOR**: 20240303确认攻击的识别与把握_ev.mp4_导出.md — "旁边对于发动攻击失败的个股有了包容度"

### 2.11 头部个股

- **TERM**: 头部个股
- **DEFINITION_SENTENCE**: "10日区间涨幅榜内只有持续度好的头部个股可以代表周期"（20240128）
- **STATE_AXIS_MAP**: 结构轴
- **OBSERVABLE_EVIDENCE**: 排名在10日区间涨幅榜前十个；持续多日处于榜单前列；有持续度（连板/断板反包/趋势新高）
- **FAILURE_MODES**: 只看实时涨幅第一当头部；忽视头部需要持续度验证；把刚进入前十但无持续的个股当头部
- **DO_NOT_DO**: 不要把头部范围扩大到十个之外；不要在头部尚未清晰时急于交易；不要忽视头部的动态变化
- **SOURCE_ANCHOR**: 20240128用状态交易_ev.mp4_导出.md — "10日区间涨幅榜内只有持续度好的头部个股可以代表周期"

### 2.12 十日区间涨幅榜前十

- **TERM**: 十日区间涨幅榜前十
- **DEFINITION_SENTENCE**: "头部范围给前十个主板10厘米定情绪周期的状态跟运行范围"（20240128）
- **STATE_AXIS_MAP**: 结构轴、偏置轴
- **OBSERVABLE_EVIDENCE**: 通达信/同花顺10日区间涨幅榜排序；只看主板10cm个股；观察前十名个股的持续度和协同性
- **FAILURE_MODES**: 看5日或20日涨幅榜而非10日；把20cm/30cm个股混入10cm判断；忽视前十的动态变化
- **DO_NOT_DO**: 不要看其他周期涨幅榜代替10日区间；不要把20cm/30cm/5cm个股纳入10cm情绪判断；不要只盯着第一名不看整个前十
- **SOURCE_ANCHOR**: 20240128用状态交易_ev.mp4_导出.md — "头部范围给前十个主板10厘米定情绪周期的状态跟运行范围"

### 2.13 最早涨停

- **TERM**: 最早涨停
- **DEFINITION_SENTENCE**: "前交易日涨停时间最早的那一个是领涨"（20240225）
- **STATE_AXIS_MAP**: 偏置轴
- **OBSERVABLE_EVIDENCE**: 当日涨停时间在10日区间涨幅榜前十中最早；次日开盘继续强势或涨停；领涨地位不因其他个股涨停而动摇
- **FAILURE_MODES**: 只看涨停时间不看是否在十日区间前十；忽视一字板买不到的情况；把盘中最早涨停但炸板的当领涨
- **DO_NOT_DO**: 不要只数涨停时间不看10日区间排名；不要在领涨一字买不到时盲目追其他跟风股；不要把炸板股当最早涨停
- **SOURCE_ANCHOR**: 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "10厘米10日涨幅榜前十个，前交易日涨停时间最早的那一个是领涨"

### 2.14 蹭状态但不可失自强

- **TERM**: 蹭状态但不可失自强
- **DEFINITION_SENTENCE**: "蹭状态的个股不可失了自强"；"蹭着状态，蹭着情绪来一个小胜"（20240128）
- **STATE_AXIS_MAP**: 驱动力轴
- **OBSERVABLE_EVIDENCE**: 个股在攻击有持续状态下跟涨；自身也保持日K新高；不随领涨波动而大幅回调；有独立走势特征
- **FAILURE_MODES**: 把完全跟风无独立的个股当蹭状态；忽视自强需要持续新高验证；在状态变化时蹭状态个股最先受损
- **DO_NOT_DO**: 不要在攻击无持续时蹭状态；不要蹭完全跟风没有自强的个股；不要把蹭状态当主要盈利模式
- **SOURCE_ANCHOR**: 20240128用状态交易_ev.mp4_导出.md — "蹭状态的个股不可失了自强"

### 2.15 自强

- **TERM**: 自强
- **DEFINITION_SENTENCE**: "个股可以日日新高"；"天行健，君子以自强不息"（20240303）
- **STATE_AXIS_MAP**: 驱动力轴
- **OBSERVABLE_EVIDENCE**: 日K持续创新高（收盘价）；不受大盘/其他个股大跌影响；分时选择方向向上；收盘能站稳
- **FAILURE_MODES**: 把盘中冲高当自强（收盘回落）；忽视横盘不新高也是示弱；把炸板回封当自强
- **DO_NOT_DO**: 不要把冲高回落当自强；不要把横盘震荡当自强；不要在个股失去自强时仍持有
- **SOURCE_ANCHOR**: 20240303确认攻击的识别与把握_ev.mp4_导出.md — "个股可以日日新高...自强的泛标准就是日日新高"

## 3. STATE MACHINE

### 3.1 状态转移表

```
[上涨周期]                                                    [下降周期]
                                                                    
  ┌──────────────┐      切割完成      ┌──────────────┐     确认攻击      ┌──────────────┐
  │  攻击有持续   │◄─────────────────│     孕化      │◄────────────────│  余温/切割   │
  │  (上涨周期)   │                   │  (新周期启动)  │                  │ (老周期尾声) │
  └──────┬───────┘                   └──────┬───────┘                  └──────┬───────┘
         │                                   ▲                                    │
         │         领涨示弱+交权              │           切割完成                │
         │         +新领涨持续               │                                   │
         │         (分期转移)                │           未切割完:                │
         │                                   │           杀空间板3-4个           │
         ▼                                   │           或领涨A杀              │
  ┌──────────────┐                           │                                    │
  │  交权磨合期   │───────────────────────────┘                                    │
  │  (过渡阶段)   │         未形成持续+余翁未清                                      │
  └──────┬───────┘                                                              │
         │         持续无承接:                                                    │
         │         频繁换人+杀空间                                               │
         │         (全面退潮)                                                    │
         ▼                                                                        ▼
  ┌──────────────┐                                                          ┌──────────────┐
  │  攻击无持续   │◄─────────────────────────────────────────────────────────│  余温补跌    │
  │  (下降周期)   │                                                          │  (尾声惯性)  │
  └──────────────┘                                                          └──────────────┘
```

### 3.2 各状态转移条件详表

| 转移 | 观测条件 | 反例 | SOURCE_ANCHOR |
|------|----------|------|---------------|
| **攻击有持续 → 交权磨合期** | 领涨个股示弱（无法新高/收盘价不创新高）；分时选择方向向下或上攻乏力；原攻击阵型出现松动 | 领涨只是断板但次日继续新高（假示弱）；单日波动但次日修复（正常颠簸） | 20240128用状态交易_ev.mp4_导出.md — "在上一个领涨示弱交权的过程中" |
| **交权磨合期 → 攻击有持续** | 新领涨明确持续（前交易日领涨+空间板双持续）；攻击阵型重新聚合；无退潮力量 | 新领涨只是一日游；无新领涨持续（频繁换人） | 20240317万法归一的应对思维_ev.mp4_导出.md — "风雨持续的时间长短取决于有没有攻击持续的力量出来" |
| **交权磨合期 → 攻击无持续** | 频繁换领涨/换空间板；新领涨无持续；出现退潮力量（头部个股持续跌） | 短暂换人间歇后持续恢复 | 20240128用状态交易_ev.mp4_导出.md — "频繁换人空难颠簸" |
| **攻击有持续 → 余温** | 领涨个股多次无法新高；攻击阵型瓦解；个股高位反复但无法突破 | 单日调整后继续新高（正常分期） | 20240204用状态交易_ev.mp4_导出.md — "周期结束的尾声，鱼的尾巴" |
| **余温 → 切割完成** | 条件1: 上一龙领涨直接A杀持续跌；条件2: 每天杀一个空间板（3-4个）；两种满足其一即切割完成 | 只是小幅回调未A杀；只杀一个空间板就停止 | 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "切割完成的条件只有这两种" |
| **切割完成 → 孕化** | 完成切割后出现新面孔个股；新面孔开始尝试持续；孕化阶段可能有试错失败 | 切割完成后无新面孔（真空期）；新面孔全是余翁未清完 | 20240225余温与孕化阶段的识别与应对_ev.mp4_导出.md — "完成切割之后去看孕化新攻击" |
| **孕化 → 确认攻击** | 前交易日领涨持续；形成攻击阵型（3-4只个股协同）；带动盘面情绪回暖；有包容度扩散 | 只是个股单独持续无阵型；带不出全局扩散（案例：中式传媒只有自己在持续，带不出全局扩散，被全局拖累，代表尚未确认攻击状态） | 中式传媒锚点：20240204用状态交易_ev.mp4_导出.md — "中世传媒只有自己在持续，带不出全局扩散，被全局拖累。代表了还没有确认攻击状态"；另见 20240331万法归一完结篇_ev.mp4_导出.md — "第二种走势走成中式传媒，那只有自己在持续，带不出全局扩散，被全局拖累。代表了还没有确认攻击状态就单打独斗" |
| **孕化 → 余温** | 孕化失败走成余温型：①特发信息型（余温未完全切割，再杀空间后才入至暗）；②中式传媒型（带不出全局扩散，被全局拖累，确认攻击状态前就夭折） | 反例：孕化期个股短暂回调/停顿后重新持续并带出阵型扩散（类似安奈儿在克莱机电死后经历风雨又重新持续），则属于孕化继续而非退回余温 | 特发信息锚点：20240204用状态交易_ev.mp4_导出.md — "特发信息的那个天地板砸下来之后，我们才说他这个地方进入了致暗"；另见 20240331万法归一完结篇_ev.mp4_导出.md — "第一种组成特发信息，无法确认攻击状态，然后再杀空间，然后进入至暗时刻，代表了他在换空间还在杀，代表了还没有完全度过余温区间"；中式传媒锚点：20240204用状态交易_ev.mp4_导出.md — "只有自己在持续，带不出全局扩散，被全局拖累。代表了还没有确认攻击状态"；另见 20240331万法归一完结篇_ev.mp4_导出.md — "第二种走势走成中式传媒，那只有自己在持续，带不出全局扩散，被全局拖累。代表了还没有确认攻击状态就单打独斗" |
| **确认攻击 → 交权磨合期** | 状态持续领涨换人（分期转移制）；部分个股掉队但阵型不散 | 一掉就全面瓦解（退潮非分期） | 20240324用状态交易-实战篇_ev.mp4_导出.md — "状态分期转移制的风雨" |
| **确认攻击 → 攻击无持续** | 频繁换领涨/空间板；触发切割条件；头部出现退潮力量 | 短暂换人间阵重新聚合 | 20240331万法归一完结篇_ev.mp4_导出.md — "状态无持续领涨换人交权切割进入下一轮" |
