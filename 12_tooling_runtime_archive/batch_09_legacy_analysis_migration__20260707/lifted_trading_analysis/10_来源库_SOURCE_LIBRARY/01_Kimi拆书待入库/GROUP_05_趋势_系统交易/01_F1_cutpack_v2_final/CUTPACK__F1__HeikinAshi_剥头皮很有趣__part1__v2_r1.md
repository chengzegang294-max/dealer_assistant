# CORE_CONCEPTS

1. **Heikin Ashi Chart Advantage**: Visually smoothed compared to candlesticks; trend clarity; candle size and wicks indicate trend strength; shows supply-demand imbalance and turning points.
2. **Basic Scalping Setup**: Enter on color change (green→red or red→green); exit immediately when opposite color appears. Simple color-following system.
3. **Emergency Stop**: Fixed stop of 5-10 pips. Traders should exit quickly if momentum turns against them, even before stop is hit, to save 1-2 pips.
4. **Chart Timeframe**: Primary is 1-minute chart. Can switch to 30-second or 10-second charts during high volatility (e.g., after economic data). Faster/more active markets should use smaller time units.
5. **Trend Strength Indicators**: Large candles = strong trend. Small candles = weakening trend. Long wicks/shadows = trend exhaustion. No new higher highs/lower lows = consolidation/turnaround.
6. **Trading Time**: Max 2-3 hours per day (e.g., 9:00-11:00 for EUR/USD). Short focused sessions better than all-day trading. 90 minutes is the psychological focus limit.
7. **Avoidance Rules**: No trading during economic data releases (pure gambling); avoid unclear trends / unclear Heikin Ashi charts; avoid small ranges; avoid central bank rate decisions.
8. **Risk Management**: Two control tools only — stop loss and position size. Reduce size when losing; increase when winning. Account growth is the only thing that matters. Capital gain/loss table shows asymmetric recovery difficulty (50% loss requires 100% gain to break even).
9. **Scalping as Flow**: Scalping is fun, not a 9-to-5 job. Requires focus and discipline. Should be treated as a skill like playing an instrument or top sports.

# FORMULAS_AND_ALGOS

- **Heikin Ashi OHLC Calculation**:
  - HA_Close = (Open + High + Close + Low) / 4
  - HA_Open = (Previous HA_Open + Previous HA_Close) / 2
  - HA_High = max(High, HA_Open, HA_Close)
  - HA_Low = min(Low, HA_Open, HA_Close)
- **Color Change Entry/Exit**:
  - Color_t = sign(HA_Close_t - HA_Open_t)  # +1 = green, -1 = red
  - Entry_long = (Color_t == +1) AND (Color_{t-1} == -1)
  - Entry_short = (Color_t == -1) AND (Color_{t-1} == +1)
  - Exit_long = Color_t == -1
  - Exit_short = Color_t == +1
- **Candle Size Strength**:
  - HA_Body_t = abs(HA_Close_t - HA_Open_t)
  - Strength_ratio = HA_Body_t / SMA(HA_Body, 20)
  - Strong_trend = Strength_ratio > 1.5
  - Weak_trend = Strength_ratio < 0.5
- **Wick Exhaustion**:
  - Upper_Wick = HA_High - max(HA_Open, HA_Close)
  - Lower_Wick = min(HA_Open, HA_Close) - HA_Low
  - Exhaustion = (Upper_Wick > 2 × HA_Body) OR (Lower_Wick > 2 × HA_Body)
- **Fixed Stop**:
  - Stop_loss = Entry_price ± 10 pips (for EUR/USD)
- **Time Filter**:
  - Trade_allowed = (Time_of_day >= 09:00) AND (Time_of_day <= 11:00) AND (not Economic_data_release_within_±30min)
- **Capital Recovery Asymmetry**:
  - Recovery_multiplier = Drawdown_pct / (1 - Drawdown_pct)
  - Example: Drawdown = 0.50 → Recovery = 1.00 (need 100% gain)
  - Example: Drawdown = 0.80 → Recovery = 4.00 (need 400% gain)
