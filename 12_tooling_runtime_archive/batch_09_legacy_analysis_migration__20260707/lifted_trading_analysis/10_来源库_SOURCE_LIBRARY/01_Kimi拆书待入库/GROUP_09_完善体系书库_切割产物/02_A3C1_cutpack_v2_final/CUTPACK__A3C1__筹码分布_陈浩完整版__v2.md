| 1-1 | 1.1 | CYQ 算法原理 | 筹码分布通过仿真算法估算市场投资者持仓成本，核心假设：筹码抛出概率与浮动盈利及持股时间有关。软件通过抽样检测获得抛出概率函数，认定每日交易中哪些老筹码被冲销、由新筹码代替。 | A股中筹码分布（CYQ）是同花顺/通达信等软件的标配功能，理解其算法原理有助于正确使用。 |
| 1-2 | 1.2 | 筹码密集与发散 | 筹码密集：某价位附近横盘很长时间，上下方筹码向横盘区集中，20%价格空间内聚集几乎所有筹码。筹码发散：筹码分布在广阔价格空间内。密集是多空之战前奏，发散是战役进行时。 | 最基础的筹码形态定义，所有后续分析的基石。 |
| 1-3 | 1.3 | 低位密集 | 股价自某价位深幅下跌后，在相对低价位区形成新的集中。低位密集的最佳买入条件：确认高度控盘+确认大盘中级行情已开始。低位标准：筹码转移最少要有6个跌停板空间。 | 6个跌停板（约47%跌幅）的量化标准，可用于筛选深度下跌后的候选股。 |
| 1-4 | 1.4 | 高位密集 | 低位筹码大量向高位转移，CYQ显示为红色警戒色。高位密集的市场含义：低位获利盘大规模在高位获利了结，大多数情况下意味着前期主力离场。 | 高位密集是出货风险的核心信号，保留红色警戒色的视觉锚定。 |
| 1-5 | 1.5 | 低位锁定 | 股价强劲上扬但筹码未向上转移，绝大部分筹码沉淀在低位不动。低位锁定与低位密集的区别：低位锁定时股价正在上涨。低位锁定是主力高度持仓的典型特征。 | 低位锁定是识别高控盘的重要视觉形态，区别于普通低位密集。 |
| 1-6 | 1.6 | 双峰形态 | 双峰：高位峰+低位峰+中间峡谷。双峰填谷：主力吸筹的高效方式。大双峰：低位峰为主力成本，高位峰为散户套牢，主力在大双峰峡谷中护盘。 | 双峰形态是"受伤庄股"和"豺狼出击"策略的基础结构。 |
| 1-7 | 1.7 | 筹码颜色规则 | 紫色：低位密集或低位锁定（下方30%空间聚集62%以上筹码）。黄色：获利筹码。蓝色：套牢筹码。红色：高位密集（上方30%空间聚集62%以上筹码）。 | 颜色规则是快速视觉判断的量化标准，可直接映射到软件显示。 |
| 1-8 | 1.8 | 博弈K线 | 博弈K线（CYQK）的开盘/收盘/最高/最低指的是获利盘。CYQKLEN（博弈K线长）= 开盘与收盘之差。CYQKLEN>18 为长阳线，当日有18%以上套牢盘被解套。 | 博弈K线是衡量筹码穿透力的核心指标，可量化。 |
| 1-9 | 1.9 | ASR 活动筹码 | ASR：以当日收盘价为基准，上下10%区间内筹码总量。ASR高→股价位于筹码密集区；ASR低→位于真空地带。 | ASR 阈值可直接用于判断筹码密集/稀疏状态。 |
| 1-10 | 1.10 | CKDP 相对价位 | CKDP = (当前价-最低成本价)/(最高成本价-最低成本价)×100%。CKDP=0 表示当前价等于最低持仓价；CKDP=100 表示当前价是最高持仓价。 | 提供了股价相对筹码成本位置的量化指标。 |
| 1-11 | 1.11 | CKDW 成本重心 | CKDW = (平均成本价-最低成本价)/(最高成本价-最低成本价)×100%。CKDW高→高位密集；CKDW低→低位密集。 | 为电脑自动选股设计的指标，可量化。 |
| 1-12 | 1.12 | CBW 成本带宽 | CBW = (最高成本价-最低成本价)/最低成本价×100%。CBW从小到大→筹码发散；CBW从大到小→筹码密集。 | 衡量筹码分布宽度的指标，可量化。 |

| 3-3 | 3.3 | 无庄超跌股操作纪律 | 投入资金量不超过总资金10%；同时买5只不同股票分仓；一旦大盘反弹结束迹象出现，不论盈利与否立即清仓。 | 无庄超跌股是超短线操作，纪律比选股更重要。 |
| 3-4 | 3.4 | 受伤庄股定义 | 受伤庄股：庄股经历吸筹和拉抬，没来得及派发股价就回落。运动轨迹：吸-拉-落，缺少"派"。外部因素：大盘下跌连累；主力自身弱点。 | 受伤庄股是博弈性最强的品种，主力与散户利益一致。 |

| 3-6 | 3.6 | 受伤庄股操作 | 轻伤（股价略高于主力成本）比重伤（跌穿成本）更可爱；最佳时机：大盘熊牛交界处（"熊尾巴"或"牛头"）；分仓至少三只。 | 受伤庄股操作有时机和仓位管理要求。 |
| 3-7 | 3.7 | 龙头股识别 | 中级底部强势股：大盘破位下行时，满盘获利（套牢盘<10%）的个股。1999年12月27日满盘获利个股仅0.8%，这0.8%的股票在2000年上半年平均涨幅129%。 | 满盘获利是龙头股的重要特征，有统计支撑。 |
| 3-8 | 3.8 | 龙头股捕捉技术 | 用CYES指标排序，选出短线强势股；再用庄家分析方法（筹码形态/仓位测量）沙里淘金。步骤：技术指标初选→庄家分析复选。 | 龙头股捕捉的两步筛选法，可程序化。 |
| 3-9 | 3.9 | 低位高控盘庄股定义 | 主力建仓完毕且未大幅获利，具备中线上涨必然性。但主力何时拉抬完全由主力决定，需等待大盘配合和题材配合。 | 低位高控盘是中线金矿，但需耐心。 |
| 3-10 | 3.10 | MYP 最大年收益 | MYP = (当前股价-循环年最低价)/循环年最低价×100%。MYP<57 时买入博弈K线无量长阳盈利；MYP>57 不挣钱。实战常用 MYP∈[10,50]。 | MYP 是判断股价相对高低的核心指标，有回测验证。 |
| 3-11 | 3.11 | RPY2 年相对价位 | RPY2 = (当日收盘价-双年度最低价)/(双年度最高价-双年度最低价)×100%。RPY2<30 为低位，30-70 为中间位，>70 为高位。 | RPY2 提供更长周期的股价相对位置判断。 |
| 3-12 | 3.12 | 天狐1号定式 | 买入条件：博弈K线长[18,100]+换手率<3%+RPY2∈[0,30]；卖出：获利10%了结/套牢10%止损。1997-2001年回测：成功率65.82%，资金收益率56.83%。止损改为20%后：成功率84.29%，资金收益率63.43%。 | 天狐1号是书中提供完整回测数据的选股定式，可复现。 |
| 3-13 | 3.13 | 天狐1号+大盘条件 | 附加大盘0A01_CYES>1.0：成功率98.23%，平均收益率12.61%，资金收益率270.86%，但年可操作天数仅12.99天。 | 大盘条件是提升定式胜率的关键变量。 |
