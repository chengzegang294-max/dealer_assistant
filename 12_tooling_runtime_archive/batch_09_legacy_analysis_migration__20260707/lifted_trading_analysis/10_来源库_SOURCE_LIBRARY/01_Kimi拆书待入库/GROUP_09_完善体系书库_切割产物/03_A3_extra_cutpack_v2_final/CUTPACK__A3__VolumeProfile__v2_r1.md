**id**: VP-R1-02
**section**: 价格行为 / 机构活动三大迹象
**topic**: 价格横盘区域是机构积累头寸的地方
**quote**: > "散户（也就是我们）与机构之间最大的区别之一就是我们所管理的交易资金量。机构拥有极高的资金量，正因为，他们会遇到我们永远不会遇到的问题。问题仅仅在于资金太多。如果他们想神不知鬼不觉地进行大额交易，就需要大量时间来建立头寸。只有在价格横盘时，他们才能缓慢而谨慎地积累头寸。在这种情况下，他们可以完美地隐藏自己的活动。因此，下次看到横向价格行动通道时，不要它很无聊，什么也没发生。你很可能错了。横向价格行动通道是大型机构准备采取行动的地方。"
**why_it_matters**: 这是 Volume Profile 第一种交易设置（累积设置）的理论基础。横盘区域=机构积累头寸=Volume Profile 出现宽厚的成交量分布。识别横盘区域是寻找高成交量支撑/阻力区的前提。
**A-share_mapping**: A 股中，平台整理/箱体震荡后的突破，对应本书的"横盘区域→积极启动"模式；突破前的平台换手率可用于判断机构是否已充分吸筹。

**id**: VP-R1-03
**section**: 价格行为 / 机构活动三大迹象
**topic**: 积极的启动活动与趋势方向
**quote**: > "积极的启动活动基本上是一种重大的价格变动或趋势。它是由将价格推高的激进买家或将价格推低的激进卖家引起的。这种激进的买入或卖出往往发生在价格横盘活动之后。如果价格横盘后出现强劲的上升趋势，那么我们就知道大机构积累的头寸是多头头寸。另一方面，如果出现横向价格行动通道，随后是积极的抛售（或下降趋势），那么我们就知道累积的头寸是空头头寸。"
**why_it_matter**: 积极启动活动是判断横盘区域积累头寸方向的关键信号。Volume Profile 的 D 型形状就是在这种横盘+启动的组合中形成的。启动方向决定了后续交易的偏向。
**A-share_mapping**: A 股平台突破方向（向上突破=多头积累，向下跌破=空头积累）是判断后续趋势的核心依据；结合筹码分布的低位密集/高位密集可交叉验证。

**id**: VP-R1-04
**section**: 价格行为 / 机构活动三大迹象
**topic**: 强烈拒绝（更高或更低的价格）
**quote**: > "对较高或较低价格水平的强烈拒绝是一种突然的价格反转。当价格猛烈地向一个方向波动，然后以同样的力度和速度迅速转向另一个方向时，就会出现这种形态。所有强力阻力的一个共同特征是攻击性和突然反转。拒绝区域向我们展示了市场一方开始激进的地方。市场中的一方（如买方）咄咄逼人，以一种方式拉动价格。然后，它与另一方（如强势卖方）发生冲突，后者突然变得更加强大，更加咄咄逼人。于是，价格迅速转向，强势一方接管了市场。"
**why_it_matters**: 强烈拒绝是 Volume Profile 第三种设置（剔除设置）的基础。强烈拒绝区域=激进的买方/卖方反对当前价格=形成强支撑/阻力。同时也是识别强势高点/低点的核心依据。
**A-share_mapping**: A 股中，长上影线/长下影线+放量=强烈拒绝信号；结合 Volume Profile 的"成交量集群"可确认拒绝区域的有效性。

**id**: VP-R1-05
**section**: 强或弱的高点/低点
**topic**: 强势高点/低点的识别
**quote**: > "强势高点和低点的形成与攻击性密切相关。最简单、最广为人知的显示反应性攻击的蜡烛是针形蜡烛。还有更多的蜡烛形态与销钉柱相似，但你并不需要知道它们的名称或定义。它们都是长尾巴和方向的快速变化。长尾巴意味着出现了强烈而激进的反应活动。这正是区分强势高/低和弱势高/低的方法。如果出现震荡低点，可以看到较低价格出现强烈而快速的拒绝，随后出现积极的上扬走势，就是强势低点。"
**why_it_matters**: 作者强调不依赖特定蜡烛形态，而是关注"攻击性"和"快速方向变化"。这为 A 股提供了更普适的高点/低点强度判断框架——不局限于锤子线/流星线等特定形态。
**A-share_mapping**: A 股中，判断波段高低点的强度不依赖具体 K 线形态，而是看是否出现"快速拒绝+放量+方向反转"。强势高点=强阻力，弱势高点=易被突破。

**id**: VP-R1-06
**section**: 拍卖失败
**topic**: 拍卖失败的定义与交易应用
**quote**: > "拍卖失败是不完整的拍卖。它是一种不完善，迟早会被处理掉。在交易中，总是需要有'最后一个人'出现在波段高点/低点的顶部（或底部）。在价格转向另一个方向（另一个方向的新拍卖开始）之前，最后一个人进行交易。但是，如果拍卖失败，则会有更多的人在波段高/低点的顶部（或底部）进行交易。从这里开始，一个新的拍卖过程就会从另一个方向开始，即使之前的拍卖还没有结束（没有成功）。因此，在摇摆点的顶端有几个人可能已经准备好争夺奖品了，但他们没有机会。在这种情况下，拍卖失败了，因为它没有一个赢家。拍卖失败是一种缺陷。市场最终会解决这个问题，让那些站在摇摆点顶端的人有机会一决高下。拍卖失败就像一块磁铁。如果价格接近这样的拍卖，那么它很可能会对其进行测试，并创造新的高/低点，以弥补缺陷。"
**why_it_matter**: 拍卖失败是本书独创性极高的概念，提供了判断价格是否会测试前高/前低的理论依据。双顶/双底结构可以用拍卖失败理论解释。这对于设置盈利目标和避免错误交易极有价值。
**A-share_mapping**: A 股中，双顶/双底/M头/W底等经典形态可以用拍卖失败理论重新解读；M头=第一次拍卖失败（未创更高高点），价格会回来测试并解决缺陷。

**id**: VP-R1-07
**section**: Volume Profile / 容量简介：控制点
**topic**: POC（控制点）定义与重要性
**quote**: > "每个音量曲线直方图中最重要的位置是控制点(POC)。POC 是机构交易量最大的地方，也可能是他们积累大额交易头寸的地方。他们积累头寸的范围更广，但 POC 是他们积累交易量最多的地方。这对所有市场参与者来说都是一个非常有力的参考点，因为它显示了机构的利益所在。价格通常会对POC水平做出相当强烈的反应。"
**why_it_matter**: POC 是 Volume Profile 最核心的单一指标。与西方 Volume Profile 的 POC 定义完全一致，但本书更强调 POC 作为"机构利益所在"的解读视角。这提供了交易方向判断的锚点。
**A-share_mapping**: A 股中，日内 POC 可作为当日关键参考点；价格回测 POC 且缩量企稳=支撑有效，放量跌破=结构转弱。日级 POC 可用于判断近期密集成交成本区。

**id**: VP-R1-08
**section**: Volume Profile / 四种形状
**topic**: D 型剖面（平衡/积累）
**quote**: > "最常见、最著名的是D型。其形状类似于字母'D'。它是在市场'平衡'时形成的。这意味着买方和卖方找到了暂时的平衡，都不比对方更激进。价格处于旋转或横向价格通道中。D 型剖面通常是机构累积交易量（=大量建仓）的迹象。有3个重要的地方：D级最高点、D-轮廓的低点、POC（=体积最重的地方）。通常靠近 D 型剖面的中部。在此轮廓的高点/低点附近有成交量集群的地方是强支撑/阻力区。"
**why_it_matters**: D 型是 Volume Profile 最常见的形状，对应横盘/平衡市场。D 型的高点和低点附近的成交量集群是强支撑/阻力区。这是设置 #1（累积设置）最常出现的形状。
**A-share_mapping**: A 股中，D 型对应箱体震荡/平台整理阶段；箱体上下沿的成交量集群是突破后的关键回测位；突破后 D 型的 POC 变为支撑/阻力。

**id**: VP-R1-09
**section**: Volume Profile / 四种形状
**topic**: P 型轮廓（上升趋势/买方主导）
**quote**: > "其形状类似字母'P'。当出现积极的买方和疲软的卖方时，就会形成这种形态。如果您查看价格图表，很可能会看到牛烛（积极的买方），然后在当天的高点出现旋转（疲软的卖方）。通常可以看到 P 型图：1.当市场处于上升趋势；2.在下跌趋势可能结束时。P-profile中最重要的领域是：POC：如果第二天价格上涨，然后再次回到该区域回撤，则为良好的支撑区域。剖面薄区的成交量集群：在这一区域，买方的攻击性最为明显——他们在市场上投放，以推高价格。如果价格回到该处，这些激进的买家很有可能再次变得激进，他们将捍卫自己的仓位，并再次推高价格。"
**why_it_matter**: P 型是上升趋势中的 Volume Profile 形状，对应买方主导市场。P 型的 POC 和薄区成交量集群是上升趋势中的关键支撑区。这对应威科夫理论的"供不应求"阶段。
**A-share_mapping**: A 股上升趋势中，P 型 Volume Profile 的 POC 和薄区成交量集群是回调买入的参考位；若价格回测这些区域且缩量企稳，可视为加仓机会。

**topic**: b 型档案（下降趋势/卖方主导）
**quote**: > "其形状类似于一个小字母'b'。（与 P 型截然相反。）当卖方咄咄逼人而买方势单力薄时，就会形成这种形态。如果查看价格走势图，你很可能会看到熊烛（积极卖方），然后在当日低点出现轮动（弱势买方）。通常可以 b 型档案：1.当市场处于下跌趋势；2.上升趋势可能结束时。b-profile 中最重要的领域是：POC：如果第二天市场下跌，然后再次回到该区域回调，则为良好的阻力区域。图形薄区的成交量集群：在这一区域，卖方的攻击性最为明显——他们在市场上投入大量资金，以压低价格。如果价格回到该处，这些激进的卖家很可能会再次变得激进，他们会捍卫自己的仓位，并再次将价格推低。"

**topic**: 逆转交易的规则与心理
**quote**: > "有时，价格根本不会对基于成交量的支撑/阻力区做出反应，而是直接越过它，进入止损区。这种情况时有发生。交易失败也是交易的一部分。但是，您仍然可以做一件事。只要价格没有对我向您展示的任何基于交易量的设置做出反应，并且触及止损位，您就只需等待价格回到原来的支撑/阻力位。当价格触及支撑/阻力位时，您就进入反转仓位——这意味着，如果您原先做多，新的反转交易将是做空。重要提示：反转交易的重要一点是，价格必须完全不尊重您的原始支撑/阻力水平，而且必须超过它。举例来说，如果价格对你的水平线做出反应，但只比它早了 1-2个点，那么我不建议进行反转交易。在这种情况下，支撑/阻力位起作用了，只是早了一点。"

| **激进买方/卖方（Aggressive Buyers/Sellers）** | 使用市场订单、立即成交、推动价格快速变动的市场参与者 | 对应威科夫理论中的"强势买方/卖方"；对应 VSA 的"专业人士/机构" |
| **价格横盘区域（Rotation Area）** | 价格横向波动的区域，机构在此缓慢积累头寸而不引起市场注意 | 对应威科夫吸筹/派发阶段；对应筹码分布的"筹码密集区"；是 Volume Profile D 型形状的形成环境 |
| **积极启动活动（Aggressive Initiating Activity）** | 横盘后的重大价格变动/趋势，表明机构已积累完头寸并开始推动价格 | 对应威科夫的 JOC（突破）；对应 VSA 的"高量确认趋势启动" |
| **强烈拒绝（Strong Rejection）** | 价格猛烈向一个方向波动后迅速反向，表明市场一方被另一方强势反击 | 对应日本蜡烛图的锤子线/流星线/吞没形态；但本书不依赖具体形态，只看"攻击性" |
| **强势高点/低点（Strong High/Low）** | 方向快速且易见变化的高点/低点，标志着激进参与者出现 | 对应威科夫支撑/阻力；用于判断 S/R 区域强度 |
| **弱势高点/低点（Weak High/Low）** | 方向变化缓慢且不明显的高点/低点，无激进参与者 | 价格最可能突破的区域，应避免在此附近设交易位 |
| **拍卖失败（Failed Auction）** | 波段高点/低点的拍卖未成功完成（无"最后一人"），市场缺陷迟早会被解决 | 本书独创概念，对应双顶/双底/M头/W底等经典形态；可用于预测价格是否会测试前高/前低 |
| **POC（Point of Control / 控制点）** | Volume Profile 中成交量最大的单一价格水平，代表机构积累头寸最多的地方 | 与筹码分布"筹码峰"对应；与 Volume Profile 通用定义的 POC 一致 |
| **D 型剖面（D-Profile）** | 单峰对称形状，POC 靠近中部，对应市场平衡/横盘/积累 | 对应威科夫震荡区间；对应 VSA 供需平衡 |
| **P 型轮廓（P-Profile）** | 高成交量集中在高位，买方积极卖方疲软，对应上升趋势 | 对应威科夫供不应求；对应 VSA 高量确认上涨 |
| **b 型档案（b-Profile）** | 高成交量集中在低位，卖方积极买方疲软，对应下降趋势 | 对应威科夫供过于求；对应 VSA 高量确认下跌 |
| **Thin 型轮廓（Thin Profile）** | 趋势强烈时形成的薄型分布，一方极端激进，成交量集群为趋势加仓点 | 对应威科夫趋势阶段；对应 VSA 趋势中的高量确认 |
| **灵活 Volume Profile（Flexible Volume Profile）** | 可选择任意区域和周期分析成交量分布的工具 | 本书特色改进，突破标准固定周期限制；可用于精细化分析特定价格区域 |
| **设置 #1：音量累积设置（Volume Accumulation Setup）** | 横盘区域后，用灵活 VP 定位最大成交量价位，价格回测时入场 | 核心交易设置；对应威科夫吸筹/派发后的突破回测 |
| **设置 #2：趋势设置（Trend Setup）** | 趋势中的薄型 VP + 成交量集群，价格回测集群时顺势入场 | 核心交易设置；对应威科夫趋势延续中的加仓点 |
| **设置 #3：剔除设置（Rejection Setup）** | 强烈拒绝区域 + 灵活 VP 定位拒绝区域内最大成交量价位 | 核心交易设置；对应日本蜡烛图的反转形态 + Volume Profile 验证 |
| **成交量集群（Volume Cluster）** | Volume Profile 中的局部成交量峰值区域，在 Thin 型中尤为重要 | 对应 HVN（High Volume Node）；是趋势中的关键支撑/阻力 |
| **逆转交易（Reversal Trade）** | 价格突破原支撑/阻力并触及止损后，在原位的另一侧建立反向仓位 | 本书独创风险管理工具；对应"支撑变阻力/阻力变支撑" |
| **基于成交量的止损（Volume-Based Stop Loss）** | 止损设置在重要成交量区域之后（低成交量区域） | 本书特色风控方法；利用成交量区域作为天然保护 |
| **替代止损法（Alternative Stop Loss）** | 不触及即止损，而是蜡烛收盘确认后才止损；设 150% 灾难性止损 | 应对假突破/止损猎杀的高级技巧；适用于波段交易 |

# 7. NOT_QUANT_YET

| 知识点 | 暂不量化原因 | 未来量化条件 |
|--------|-------------|-------------|
| "攻击性"的主观判断（强烈拒绝/强势高低点） | 依赖交易经验和对价格"流动性和侵略性"的直觉理解，难以单指标量化 | 需建立多维度"攻击性评分"（影线长度/成交量/反转速度/后续走势） |

| 逆转交易中的"偏见快速切换"心理 | 属于交易心理学，无法直接量化 | 需结合交易日志和行为数据分析 |
| 灵活 Volume Profile 的"感兴趣区域"自动选择 | 当前需人工选择分析区域 | 需建立基于价格行为特征（横盘区域、拒绝区域）的自动区域检测算法 |
| 多市场（外汇/期货/股票/加密货币）的差异化参数 | 不同市场的交易机制、波动率、成本结构不同 | 需分市场建立参数校准框架 |
| 作者定制的 NinjaTrader 指标逻辑 | 本书引用作者定制指标，但无开源/技术细节 | 需获取指标源码或自行开发等效 Python 实现 |
