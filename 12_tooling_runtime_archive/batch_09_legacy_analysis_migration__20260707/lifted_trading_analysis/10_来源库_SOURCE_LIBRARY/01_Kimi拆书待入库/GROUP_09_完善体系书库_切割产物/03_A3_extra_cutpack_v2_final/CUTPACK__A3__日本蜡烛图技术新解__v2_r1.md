### 4.1 差异指数（第5章）

**id**: CANDLE2-05-01
**section**: 第5章 差异指数
**topic**: 差异指数定义与超买超卖判断
**quote**: > "差异指数也称差异比率，用百分数表示，以收盘价减去移动平均值后的差除以所选定的移动平均值得出。如果某个收盘价的13周差异指数为-25%，就表明收盘价比移动平均值低25%。如果某个200天差异指数为+12%，则表示当前的收盘价比200天移动平均值高12%。"
**why_it_matters**: 差异指数是日本人广泛使用的摆动指标，将价格与均线的关系量化为百分比，比西方双均线系统更直观。可直接用于A股判断个股/指数是否处于极端状态（超买/超卖）。
**A-share_mapping**: 对沪深300、中证500等指数计算13周或75日差异指数，当到达±10%~±15%时警惕反转；对高波动创业板个股需校准极端值。

---

**id**: CANDLE2-05-02
**section**: 第5章 差异指数
**topic**: 差异指数的多重用途
**quote**: > "差异指数是有用的工具，可以用来判断市场是否处于超买或超卖状态...如果差异指数上升，说明行情正在上行；如果该指数下行，反映行情也在下行...差异指数还可以监测行情的背离程度。"
**why_it_matters**: 差异指数同时具备三种功能：超买超卖指标、趋势方向确认器、背离检测工具。一指标多用，适合A股多维度验证。
**A-share_mapping**: 在A股中，差异指数与MACD/RSI/KDJ结合使用，当差异指数超卖+KDJ金叉+成交量放大时，构成多指标共振的买入信号。

**id**: CANDLE2-05-03
**section**: 第5章 偏离指数
**topic**: 偏离指数与差异指数的关系
**quote**: > "偏离指数与差异指数反映的是同样的行情，只是表达方式不尽相同。例如，如果某日的13日偏离值是102%，那么当日的价格比13日移动平均值高2%。而如果某日的13日差异指数为+2%，那么当日的价格也是高于13日移动平均值2%。102%的偏离指数就相当于+2%的差异指数。"
**why_it_matters**: 两种指标本质相同，仅纵坐标刻度不同。许多交易软件使用偏离指数（Price/MA比率），理解等价关系有助于跨平台指标应用。
**A-share_mapping**: A股通达信/同花顺等软件中的"BIAS（乖离率）"即为本差异指数概念，可直接调用。

### 4.2 三线反向突破图（第6章）

**id**: CANDLE2-06-01
**section**: 第6章 三线反向突破图
**topic**: 三线反向突破图核心画法
**quote**: > "如果某个收盘价超过前高，就画一条白线；如果收盘到达一个新低，就画一条黑线；如果收盘既没有创新高也没创新低，就不用画线。如果一波上涨（或下跌）比较强劲，足以形成三根连续的白线（或黑线），那么要画一根相反颜色的新线，就必须打破这三根白线的最低点（或者超越这三根黑线的最高点）。"
**why_it_matters**: 三线反向突破图的核心规则是"突破前三线才反转"，天然过滤小幅回调噪音，只捕捉主趋势反转。规则机械化，易于编程实现。
**A-share_mapping**: 对A股指数（如沪深300）绘制周线三线反向突破图，当连续三根白线后首次出现黑线时，警惕趋势反转；适合识别A股牛熊转换的大节点。

---

**id**: CANDLE2-06-02
**section**: 第6章 三线反向突破图
**topic**: 与蜡烛图结合的交易策略
**quote**: > "三线反向突破图的作用就是判断市场的牛熊趋势...如果出现了连续三根白线，按三线反向突破图的理论，市场的大趋势是向上的。在这个前提下，如果蜡烛图上出现多头信号，我们就可以视之为一个买入信号，而在这个向上趋势中的空头蜡烛图信号，我们就可以视之为空头仓位的平仓时机。"
**why_it_matters**: 提供了跨图形工具的协同框架：新价图定方向，蜡烛图定时机的"双图联动"策略。这是A股实战中极为实用的组合思路。
**A-share_mapping**: A股操作中：三线反向突破图（周线）确认上升趋势 → 日线蜡烛图寻找启明星/锤子线等买入信号 → 差异指数确认非超买状态 → 再执行买入。

### 4.3 砖形图（第7章）

**id**: CANDLE2-07-01
**section**: 第7章 砖形图
**topic**: 砖形图核心规则
**quote**: > "如果行情沿着此前的方向继续前进，而且变动幅度到达一个预定的固定数值，我们就画一根新的砖形线（加一块新砖头）。也就是说，如果此前是一块白砖，而今天的涨幅达到了预先规定的一个固定数值，我们就可以画一块新砖头。砖形图中各块砖头的大小是一样的。"
**why_it_matters**: 砖形图通过固定价格单位（如5点、2%）过滤时间维度和微小波动，只反映"有意义的"价格变动。适合捕捉A股主升浪，避免被日内震荡洗出。
**A-share_mapping**: A股个股设置1%~3%砖块大小（根据波动率调整），白砖出现买入/持仓，黑砖出现卖出/观望；适合波段操作，尤其适合趋势明确的板块龙头。

---

**id**: CANDLE2-07-02
**section**: 第7章 砖形图
**topic**: 砖形图的交易技巧
**quote**: > "砖形图上唯一的反转信号就是多头白砖或空头黑砖。买入信号（图中以字母B表示）因白砖的出现而形成，卖出信号（以字母S表示）随着黑砖的出现而产生。砖形图技术的主要魅力在于它能让交易者抓住行情的主段。"
**why_it_matters**: 砖形图的交易规则极其简单（白买黑卖），但关键是参数设定（砖块大小）。参数过小→频繁交易；参数过大→反应迟钝。需根据标的波动特性优化。
**A-share_mapping**: A股ETF（如沪深300ETF）使用较小砖块（0.5%~1%）捕捉波段；个股使用较大砖块（2%~5%）避免噪音；需通过历史回测确定最优砖块大小。

### 4.4 钥匙图（第8章）

**id**: CANDLE2-08-01
**section**: 第8章 钥匙图
**topic**: 钥匙图核心画法与阴阳线
**quote**: > "如果价格沿着此前的方向行进，则钥匙线继续延伸。如果价格反向运行，而且达到了预先设定的幅度，则钥匙线右移一格反向延伸。必须注意的是，钥匙线有粗细之分，如果价格刺破了前低或前高，钥匙线的粗细就会发生变化。粗线称为'阳线'，细线称为'阴线'。"
**why_it_matters**: 钥匙图的独特价值在于"阴阳线粗细变化"直观反映多空力量转换，且仅需收盘价+转向值即可绘制。是日本新价图中流行度最高的工具。
**A-share_mapping**: A股共同基金/理财产品的净值分析（仅有收盘价）可使用钥匙图；转向值设为3%适用于多数A股主动权益基金。

**quote**: > "双窗口底部形成的形态特征是：在下行趋势中，市场发生反弹，形成一个肩部（S1），这个肩部的高点低于前一个腰部的低点W1。后面一个腰部W2也高于肩部S1。这个形态之所以称为双窗口形态，是因为两个腰部位置W1与W2都高于中间的肩部S1。这个形态就好像在肩部S1与左右两个腰部之间出现了一个价格缺口。"

# 5. CORE_CONCEPTS

| 概念 | 定义 | 与 repo 其他书籍的关联 |
|------|------|------------------------|
| **差异指数** | `(收盘价-MA)/MA×100%`，衡量价格与均线偏离程度的百分比摆动指标 | 与和谐交易的PRZ（潜在反转区）互补：差异指数判定极端状态，PRZ定义几何反转区域 |
| **偏离指数** | `收盘价/MA×100%`，与差异指数等价（102%偏离=+2%差异） | 与筹码分布的成本偏离度概念类似 |
| **三线反向突破图** | 基于收盘价，创新高/低画白/黑线，突破前三线极值才反转 | 与筹码分布的趋势确认结合：三线确认趋势 + 筹码峰确认支撑/阻力 |
| **砖形图** | 固定价格变动单位，达到单位画等高白/黑砖，不足不画 | 适合A股ETF和趋势型板块，过滤时间噪音 |
| **钥匙图** | 基于收盘价+转向值，反向达转向值右移画线；刺破前高/前低时粗细变化（阳/阴） | 与蜡烛图互补：钥匙图宏观趋势 + 蜡烛图微观时机；肩腰概念可映射到A股板块强弱 |
| **肩（S）/腰（W）** | 钥匙图中的前高/前低；肩腰逐级抬高=强势，逐级降低=弱势 | 对应A股板块轮动的领涨/领跌板块识别 |
| **双窗形态** | 双窗底：左腰>中间肩，右腰>中间肩；双窗顶：左肩<中间腰，右肩<中间腰 | 对应A股岛形反转/缺口理论，但基于钥匙图结构 |
| **三佛顶/底** | 对应头肩顶/底；右佛突破确认 | 经典形态在钥匙图中的变体，适用于A股大形态判断 |
| **多级突破** | 突破两个或以上前高/前低才确认信号 | 提高准确率，适合A股假突破较多的环境 |
| **百分比钥匙图** | 转向值设为百分比（如3%），自动适应不同价格水平 | 解决A股高价股（茅台）与低价股转向值差异问题 |

# 7. FORMULAS_AND_ALGOS

## 7.1 差异指数公式
公式：差异指数 = (收盘价 - 移动平均值) / 移动平均值 × 100%

公式：偏离指数 = 收盘价 / 移动平均值 × 100%

等价关系：
差异指数 = 偏离指数 - 100%
公式：偏离指数 = 差异指数 + 100%

超买超卖判断（示例阈值，需根据标的校准）：
13周差异指数 > +10% → 超买区域
13周差异指数 < -10% → 超卖区域

## 7.2 三线反向突破图算法伪描述
描述：输入：收盘价序列 P[1..n]
描述：输出：白/黑线序列（每线含高点、低点）

描述：初始化：基价 = P[1]
描述：当前趋势 = None
连续同色线数 = 0

描述：for i = 1 to n:
步骤：if 当前趋势 == None:
步骤：画线(基价, P[i], 白 if P[i] >= 基价 else 黑)
步骤：当前趋势 = 白 if P[i] >= 基价 else 黑
连续同色线数 = 1
步骤：elif 当前趋势 == 白:
步骤：if P[i] > 前高:
步骤：画新白线(前高, P[i])
公式：连续同色线数 += 1
步骤：elif P[i] < 前三白线最低点 and 连续同色线数 >= 3:
步骤：画黑转向线(前三白线最低点, P[i])
步骤：当前趋势 = 黑
连续同色线数 = 1
步骤：elif 当前趋势 == 黑:
步骤：if P[i] < 前低:
步骤：画新黑线(前低, P[i])
公式：连续同色线数 += 1
步骤：elif P[i] > 前三黑线最高点 and 连续同色线数 >= 3:
步骤：画白转向线(前三黑线最高点, P[i])
步骤：当前趋势 = 白
连续同色线数 = 1

## 7.3 砖形图算法伪描述
描述：输入：收盘价序列 P[1..n]，砖块大小 B
描述：输出：白/黑砖序列

描述：当前方向 = None
公式：当前砖顶/底 = P[1]

描述：for i = 1 to n:
步骤：if 当前方向 == None:
步骤：差值 = P[i] - P[1]
公式：砖数 = floor(|差值| / B)
步骤：if 砖数 > 0:
步骤：画砖(方向=白 if 差值>0 else 黑, 数量=砖数)
步骤：当前方向 = 白 if 差值>0 else 黑
步骤：elif 当前方向 == 白:
公式：if P[i] >= 当前砖顶 + B:
公式：砖数 = floor((P[i] - 当前砖顶) / B)
步骤：画白砖(数量=砖数)
步骤：elif P[i] <= 当前砖底 - B:
公式：砖数 = floor((当前砖底 - P[i]) / B)
步骤：画黑砖(数量=砖数)
步骤：当前方向 = 黑
步骤：elif 当前方向 == 黑:
步骤：if P[i] <= 当前砖底 - B:
公式：砖数 = floor((当前砖底 - P[i]) / B)
步骤：画黑砖(数量=砖数)
公式：elif P[i] >= 当前砖顶 + B:
公式：砖数 = floor((P[i] - 当前砖顶) / B)
步骤：画白砖(数量=砖数)
步骤：当前方向 = 白

## 7.4 钥匙图算法伪描述
描述：输入：收盘价序列 P[1..n]，转向值 R
描述：输出：钥匙线序列（含方向、粗细、高点、低点）

描述：当前方向 = None
描述：当前线终点 = P[1]

描述：for i = 1 to n:
步骤：if 当前方向 == None:
步骤：画线(P[1], P[i])
步骤：当前方向 = 上 if P[i] >= P[1] else 下
步骤：elif 当前方向 == 上:
步骤：if P[i] > 当前线终点:
延长当前线到 P[i]
步骤：if P[i] > 前高: 标记为粗线（阳）
步骤：elif P[i] <= 当前线终点 - R:
右移一格画反向线(当前线终点, P[i])
步骤：当前方向 = 下
步骤：if P[i] < 前低: 标记为细线（阴）
步骤：elif 当前方向 == 下:
步骤：if P[i] < 当前线终点:
延长当前线到 P[i]
步骤：if P[i] < 前低: 标记为细线（阴）
公式：elif P[i] >= 当前线终点 + R:
右移一格画反向线(当前线终点, P[i])
步骤：当前方向 = 上
步骤：if P[i] > 前高: 标记为粗线（阳）
