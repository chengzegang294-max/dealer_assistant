# 4. RETAINED_EXCERPTS

### 4.1 三大原则

**id**: WYCKOFF-01-01
**section**: 前言/第一章
**topic**: 供求关系原则
**quote**: > "供求关系是价格涨跌的基本元素，我们在观察市场时，要不断地衡量供求关系的变化...趋势的动力来自于供求关系的不平衡。供不应求，价格上涨；供过于求，价格下跌。"
**why_it_matter**: 威科夫理论的第一性原理。所有趋势变化的根本驱动力是供求失衡。本书反复强调从价量细节中解读供求关系，这是贯穿全书的分析主线。
**A-share_mapping**: A股涨停板封单量/成交量比例直接反映供求；封单大=供不应求，开板放量=供应涌入。

---

**id**: WYCKOFF-01-02
**section**: 前言/第一章
**topic**: 因果关系原则
**quote**: > "任何主要趋势的反转之前，都需要一个过程（比如牛市之前的吸筹过程），没有这个过程，接下来形成的趋势不会持续太久，比如公众喜欢抄底，他们在熊市中的第一个反弹就买入，结果是被套或者被震仓出局。他们失败的原因就是没有等到吸筹过程结束，这个过程就是因，后面产生的趋势就是果。"
**why_it_matters**: 解释了A股中为何"V型反转"罕见而"W型/圆弧底"常见。无准备过程的反弹是假反弹，有吸筹过程的突破才是真突破。这是避免被套的关键原则。
**A-share_mapping**: A股消息刺激的一字板/快速涨停（无吸筹过程）往往缺乏持续性，因果定律解释其易A字杀的原因。

---

**id**: WYCKOFF-01-03
**section**: 前言/第一章
**topic**: 努力和结果原则
**quote**: > "主要作用是告诉我们走势出现停止行为。努力是指成交量（市场流入订单总量），结果是指价格的进展幅度。比如在支撑价位附近，我们怎么知道这个支撑是有效的还是价格会突破？当我们看到价格接触支撑价位的时候，成交量突然扩大，此时如果价格范围很窄（小蜡烛），这就是努力没有产生相应的结果。"
**why_it_matter**: "努力和结果"是VSA的核心操作法则。大量成交量（努力）但价格进展很小（结果）=停止行为=潜在反转。这是判断支撑/阻力有效性的量化方法。
**A-share_mapping**: A股前低支撑处放量小实体K线=供应被吸收=支撑有效，可买入；若放量大实体跌破=支撑失效，需止损。

### 4.2 CM行为与吸筹

**id**: WYCKOFF-01-04
**section**: 第一章
**topic**: CM吸筹行为特征
**quote**: > "CM在幕后制造针对公众的价格走势，操纵新闻消息。如果他们不懂他们的游戏规则，我们就是市场上的牺牲品；反之，如果我们深知他们的行为习惯，我们会利用这些知识在市场上由励志到成功。我们不用知道他们是谁，住在哪里，我们能够解读出他们的行为就足够了。"
**why_it_matter**: 本书核心理念：不猜主力是谁，只通过价量解读主力行为。这为A股投资者提供了不依赖消息/内幕的纯技术分析路径。
**A-share_mapping**: A股投资者常试图通过龙虎榜/大宗交易猜测主力身份，但威科夫方法提供了通过K线+成交量直接推断主力意图的框架，无需外部信息。

**id**: WYCKOFF-02-01
**section**: 第二章
**topic**: 恐慌抛售（SC）与吸筹开始
**quote**: > "假如某一天出现天量配上超长阴线，这不是市场会继续大跌的信号，而是市场遇到巨大买盘的信号。在威科夫理论中，这种现象叫作恐慌抛售。被套的公众眼看着自己的资金每天大幅递减，无法承受心理的压力，在利空消息的恐吓下，索性抛掉全部股票，使自己的痛苦得以解脱。当然他们的抛盘被CM吸收。"
**why_it_matter**: 恐慌抛售是威科夫理论中最重要的底部信号之一。它重新定义了"放量长阴"——不是卖出信号，而是CM吸筹信号。这为A股抄底提供了理论依据。
**A-share_mapping**: A股系统性下跌（如2020年疫情底、2022年4月底）中的放量长阴，符合SC特征，后续若有缩量二次测试确认，是中期底部信号。

### 4.3 派发与逃顶

**id**: WYCKOFF-03-01
**section**: 第三章
**topic**: 抢购高潮（BC）与CM出货
**quote**: > "蜡烛1是供应扩大的体现，它的特点是新高长阳，伴随天量。我们知道牛市中是需求大于供应，能够止住价格上涨的只有供应扩大。所以在牛市中，如果我们没有看到供应扩大，不能轻易猜顶。蜡烛1放量说明供求都在扩大，但是需求来自公众的抢购高潮，他们害怕错过最后一班车。此时的供应来自CM，他们看到自己的利润目标达到，开始利用公众的疯狂暗自出货。"
**why_it_matter**: 抢购高潮是威科夫理论中最重要的顶部信号。它解释了A股中"天量天价"现象的本质——CM利用公众贪婪出货。这是逃顶的核心依据。
**A-share_mapping**: A股连续涨停后"天量开板"或"高位放量长上影线"，符合BC特征，是坚决卖出信号，不可再追。

### 4.4 Spring交易法

**id**: WYCKOFF-04-01
**section**: 第四章
**topic**: 弹簧效应（Spring）定义
**quote**: > "在震荡区中，一个故意使价格下降或上涨的行为，其目的是激起公众平掉当前仓位而投机者趁机接盘。分为普通震仓和终极震仓。普通震仓发生在上升趋势中，多数是受不利消息影响，造成市场临时波动。普通震仓之后，价格会快速恢复上涨。终极震仓发生在吸筹过程中，目的是让还在死扛的公众抛掉手里股票，来帮助CM吸筹。"
**why_it_matter**: Spring/震仓是威科夫理论中最具实战价值的交易信号。它是CM的"陷阱"，但聪明钱可以反向利用——在Spring处买入。A股中极为常见。
**A-share_mapping**: A股"挖坑洗盘"——突然跌破平台/均线后迅速拉起，是Spring的经典形态；最佳买入点之一，止损设于坑底。

---

**id**: WYCKOFF-04-02
**section**: 第四章
**topic**: Spring后的确认
**quote**: > "震仓之后，市场的浮动供应被CM全部吸收，然后需求开始主导市场。有时震仓之后，价格会再次回测底部，看是否还有漏网之鱼（浮动供应）。在确认市场上的浮动供应已经耗尽，我们应该毫不犹豫地开始建多仓。"
**why_it_matter**: Spring不是孤立信号，需确认：1）Spring后需求跟随（长阳）；2）无大量浮动供应回测。这提供了Spring交易的风险控制框架。
**A-share_mapping**: A股Spring后若次日缩量小阳回测前低不破，说明浮动供应耗尽，可加仓；若放量跌破Spring低点，说明震仓失败，止损离场。

### 4.5 关键价位与信号

**id**: WYCKOFF-01-05
**section**: 第一章
**topic**: 上冲回落（Upthrust）与JOC
**quote**: > "蜡烛3突破了阻力线回落，我们叫上冲回落。上冲回落要想发挥反转的作用，必须有阴线跟随和成交量递增。如果成交量没有增加，说明抛盘没有出现。在上升趋势中，这样的上冲回落是个试探行为，不能做空。如果上冲回落后的回调很萧条（小蜡烛，小成交量），说明供应枯竭，价格有机会突破阻力，形成JOC。"
**why_it_matter**: 上冲回落是突破失败的预警信号，但需确认（阴线+增量）；若回调萧条则供应枯竭，后续JOC（突破）概率大增。这为A股突破操作提供了前置判断框架。
**A-share_mapping**: A股突破前高后若当日回落至前高内，次日需观察：若放量阴线=假突破，应卖出；若缩量小阳=供应枯竭，等待JOC突破后买入。

---

**id**: WYCKOFF-01-06
**section**: 第一章
**topic**: 死角（Dead Angle）
**quote**: > "死角在交易中非常重要，因为他预示着行情即将有大动作发生。此时如果价格回落稍微加强（力量不用很大因为当时处于供求都不活跃状态中），价格会突破需求线（下轨），导致大幅下跌。"
**why_it_matter**: 死角是上升趋势通道上轨与水平阻力线的交叉点，是威科夫理论中独特的预警形态。预示着变盘即将发生，需提前减仓/观望。
**A-share_mapping**: A股高位震荡时，若上升趋势线与前期高点阻力形成死角，一旦缩量跌破下轨，需警惕大幅下跌（如2021年2月核心资产抱团瓦解）。

# 5. CORE_CONCEPTS

| 概念 | 定义 | 与 repo 其他书籍的关联 |
|------|------|------------------------|
| **CM（Composite Man）** | 市场操纵者/聪明钱，掌握庞大资金可短期控制价格走势 | 对应A股"主力/机构/游资"；与VSA的"局内人/做市商"概念相同；本书提供了更详细的CM行为阶段分析 |
| **供求关系原则** | 趋势动力来自供求不平衡；供不应求=涨，供过于求=跌 | 与VSA的供求定律相同；与筹码分布的"筹码集中=供不应求""筹码分散=供过于求"互补 |
| **因果关系原则** | 趋势反转前需要准备过程（吸筹/派发），无准备则趋势不持久 | 解释了A股假突破/假反弹的原因；与和谐交易的PRZ准备过程互补 |
| **努力和结果原则** | 成交量=努力，价格进展=结果；努力无结果=停止行为=潜在反转 | 与VSA的投入产出定律相同；提供了支撑/阻力有效性的量化判断方法 |
| **恐慌抛售（SC）** | 下降趋势中的天量超长阴线，公众恐慌抛售，CM吸收 | 对应VSA的恐慌抛售；与筹码分布的"恐慌盘割肉=筹码转移"对应 |
| **抢购高潮（BC）** | 上升趋势中的新高长阳+天量，公众疯狂抢购，CM出货 | 对应VSA的抢购高潮；与筹码分布的"放量滞涨=筹码松动"对应 |
| **吸筹阶段** | SC→反弹→二次测试→震仓→SOS→JOC→牛市 | 与VSA的吸筹阶段相同；本书提供了更详细的A股案例 |
| **派发阶段** | BC→自动下跌→二次测试→缩量反弹→跌破→熊市 | 与VSA的派发阶段相同 |
| **震仓（Shake out）** | 故意使价格突然大幅下沉，清除浮动供应 | 终极震仓=吸筹中；普通震仓=上升趋势中；本书核心交易机会之一 |
| **Spring（弹簧效应）** | 价格短暂跌破支撑后迅速收回，CM震仓陷阱 | 本书最独特的实战信号；A股"挖坑洗盘"的威科夫解释；最佳买入点之一 |
| **SOS（强势出现）** | 需求吸收全部供应并占上风的信号 | 标志吸筹结束/趋势开始；常与震仓后长阳同时出现 |
| **SOW（弱势出现）** | 供应主导市场的信号 | 标志派发开始/趋势结束 |
| **JOC（Jump Over Creek）** | 放量长阳跳过阻力线（Creek），确认吸筹结束 | 突破买入信号；需缩量回调不跌破突破阳线底部确认 |
| **Upthrust（上冲回落）** | 突破阻力后迅速回落 | 可能是假突破（需阴线+增量确认）或试探行为（回调萧条则后续JOC概率大） |
| **垂直需求柱** | 放量长阳突破阻力，底部形成天然支撑 | 与VSA的垂直需求柱相同；对应A股"放量突破平台" |
| **垂直供应柱** | 放量长阴跌破支撑，顶部形成天然阻力 | 与VSA的垂直供应柱相同；对应A股"放量跌破平台" |
| **冰线（Ice Line）** | 关键支撑线，跌破后变为阻力 | 对应A股的"前低/颈线"；跌破后需止损/做空 |
| **死角（Dead Angle）** | 上升趋势通道上轨与水平阻力线交叉 | 预警变盘信号；A股高位震荡时需注意 |
| **危机管理** | 聪明钱使用止损/仓位管理/情绪控制，公众无危机管理 | 本书提供了系统化的风险管理框架，可直接量化执行 |

# 7. FORMULAS_AND_ALGOS

## 7.1 恐慌抛售（SC）检测
描述：条件：
1. 当日跌幅 > 3%（A股个股）或 > 1.5%（指数）
2. 成交量 > 前5日均量 × 2.5
3. 实体大小 > 前20日平均实体 × 2
4. Close接近Low（下影线 < 实体大小 × 0.3）
5. 前期为下降趋势（20日均线向下，或20日涨幅 < -10%）

描述：信号价值：SC可能标志熊市结束，需等待二次测试确认（缩量回测前低）
描述：注意：不是所有下降趋势都有SC，没有SC的熊市结束需要其他信号确认

## 7.2 抢购高潮（BC）检测
描述：条件：
1. 当日涨幅 > 5%（个股）或 > 2%（指数）
2. 成交量 > 前5日均量 × 2.5
3. 上影线长度 > 实体大小 × 0.5（显著上影线）
4. 前期为上升趋势（20日均线向上，或20日涨幅 > 15%）
5. 创20日新高

描述：信号价值：BC可能标志牛市结束，需等待二次测试确认（缩量反弹前高）

## 7.3 Spring（弹簧效应）检测
条件（终极震仓型Spring）：
1. 价格处于吸筹区间底部或前低支撑位
2. 快速跌破支撑位（当日跌幅 > 2%，或跌破幅度 > 支撑价×2%）
3. 跌破后迅速收回（当日或次日Close回到支撑位上方）
4. 跌破时放量（Volume > 前5日均量 × 1.5），收回时放量（Volume > 前5日均量 × 1.5）
5. 收回后1-3日内出现长阳（涨幅 > 3%，实体大）

描述：止损位：Spring低点下方 1%~2%
加仓条件：缩量回测Spring低点不跌破 + 再次长阳

## 7.4 JOC（Jump Over Creek）检测
描述：条件：
1. 放量长阳突破阻力线/平台（涨幅 > 3%，Volume > 前5日均量 × 1.5）
2. 突破前价格在平台内震荡至少10个交易日（有吸筹过程）
3. 突破后1-3日内缩量回调（Volume < 突破日Volume × 0.6）
4. 回调不跌破突破阳线实体底部（或底部的一半）
5. 回调后出现再次放量上涨

描述：买入点：缩量回调至突破阳线底部附近
描述：止损位：突破阳线底部下方 1%~2%

## 7.5 震仓检测
描述：条件：
1. 价格处于吸筹区间或震荡平台内
2. 无重大利空消息（排除真跌）
3. 突然快速下跌（1-2日内跌幅 > 3%~5%）
4. 跌破平台底部/前低
5. 但随后迅速收回（3-5日内回到平台内）
6. 收回时成交量放大（需求入场）

描述：区分：终极震仓（吸筹中）vs 普通震仓（上升趋势中）
终极震仓：发生在长期下跌后的底部平台，目的是清除浮动供应
普通震仓：发生在上升趋势中，多受消息影响，震仓后快速恢复上涨

## 7.6 努力结果不匹配（停止行为）检测
描述：条件：
1. 成交量 > 前5日均量 × 2
2. 实体大小 < 前5日平均实体 × 0.8
3. 出现在关键位置（支撑/阻力/趋势线）

描述：信号解读：
在支撑位：高量小实体 = 需求吸收了供应，支撑有效，可能见底
在阻力位：高量小实体 = 供应吸收了需求，阻力有效，可能见顶
在趋势中：高量小实体 = 趋势可能停止

## 7.7 危机管理执行框架
进场前：
1. 确定交易理论根据（供求关系判断）
2. 设定止损位（技术位下方1%~2%，或Spring低点下方）
3. 确定仓位（单笔风险不超过总资金2%）
4. 确定加仓条件（缩量回测不跌破+再次确认信号）

进场后：
1. 每日评估供求关系是否支持持仓
2. 若出现SOW/异常信号，收紧止损或减仓
3. 达到目标位后，根据背景决定是否止盈或移动止损
4. 若触发止损，无条件执行，不抱希望

情绪管理：
1. 不预测，只跟随价量信号
2. 不追涨杀跌，按信号操作
3. 不补仓摊低成本（除非有明确的新信号确认）
4. 每笔交易独立评估，不受前一笔盈亏影响
