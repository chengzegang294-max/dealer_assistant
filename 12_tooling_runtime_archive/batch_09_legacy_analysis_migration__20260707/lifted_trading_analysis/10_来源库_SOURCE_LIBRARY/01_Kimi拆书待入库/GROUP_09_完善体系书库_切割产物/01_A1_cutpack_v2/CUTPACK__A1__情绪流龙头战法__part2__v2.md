### EX-028

- **topic**: 顺向而为与方向定数
- **quote**: "本门情绪流认为：一般意义上的趋势，正确的理解应该是方向。那么‘顺势而为’这几个字，应该稍稍改一下，变成‘顺向而为’，那么事情就变得简单得多。当我们知道B处指数是市场底的时候，按‘大多数股票根据大盘指数起落’这一原则，选一只有‘中长期题材预期’的股票，难吗？因为我们知道了他的方向，就是一个字涨。如果我们选了有主力建仓痕迹的票，那不更是‘好风凭借力，送我上青云’？这就叫顺向而为。市场底以后，大概率是上涨的，但所谓的市场底是稀缺的，怎么办呢？比较稳妥的办法是，等待大盘一轮大跌以后，我们发现主力建仓行为，择机介入即可。总之，对散户朋友而言，把‘顺势而为’理解‘顺向而为’，更具实操性。方向是定数，实际走势是变数，守住定数，忽略变数。这就是所谓的‘以定制变’。"

## # CORE_CONCEPTS（后半部分：弱转强 ~ 题材级别/硬度）

### 11. 弱转强
- **concept**: 弱转强
- **plain_explanation**: 前一交易日表现较弱（烂板、炸板、长上影、尾盘封单弱）的个股，次日却超预期地高开、快速涨停或强势承接，形成“由弱转强”的反差。这代表市场资金对其认可度的逆转，常是买入信号。
- **original_basis**: 有些股票前一天比较弱，或者涨停时间比较晚，但第二天却强势快速涨停，这些票我们定义为超预期的股票（line 3309-3311）；某只票前面两天还炸板，但是接下来的承接却非常好，则体现出某些资金的意图（line 3236）。
- **market_context**: A 股中常见“烂板次日高开秒板”或“炸板次日反包涨停”，如大港股份等案例中的分歧转一致。
- **quant_relevance**: 可量化为：前日炸板/烂板标记 + 次日开盘涨幅 > 3% + 封板时间 < 开盘30分钟 + 次日竞价量/昨日成交额比 > 阈值。

### 12. 强更强
- **concept**: 强更强
- **plain_explanation**: 龙头在确认地位后，由实体换手板转为缩量一字板或秒板，加速上行，板块跟风股也集体高开。这是“一致预期”的极致表现，属于加速阶段，持筹者的盛宴，但场外介入风险累积。
- **original_basis**: 加速阶段，龙头股自然往往是一字板，或集合竞价开得很高（line 2341-2343）；生于分歧，死于一致（line 4478-4479）。
- **market_context**: A 股中龙头3板后若次日一字或T字缩量加速，代表强更强，但若板块后排掉队则风险临近。
- **quant_relevance**: 可量化为：昨日换手板 + 今日竞价一字/高开>7% + 竞价量/昨日成交额 < 5% + 板块跟风股开盘涨幅均值 > 3%。

### 13. 炸板/回封
- **concept**: 炸板与回封
- **plain_explanation**: 炸板指涨停后被抛盘打开；回封指打开后再次封住。炸板暴露分歧，回封体现承接。回封速度越快、封单越稳，质量越高；反复炸板不回封则是风险信号。
- **original_basis**: 扫板即时成交无法撤单，一旦封板后板上出现抛单或撤单，无法做出补救（line 2095-2107）；换手板显示筹码交换，非换手板极度缩量（line 2122-2127）。
- **market_context**: A 股中炸板率反映市场分歧度，回封质量反映龙头韧性，是判断龙头健康度的重要盘口指标。
- **quant_relevance**: 炸板可用Level-2数据计算开板次数、开板时长；回封质量可用回封时间、回封时板块状态、封单金额/流通市值比来代理。

### 14. 承接/抛压
- **concept**: 承接与抛压
- **plain_explanation**: 承接是买盘在下跌过程中吸收筹码的能力，表现为分时均线附近有买单托住、下跌缩量；抛压是卖盘集中涌出，表现为瀑布杀、放量跌破均线。龙头分时承接无力是出场信号。
- **original_basis**: 分时出现瀑布线下跌，充分说明个股承接无力（line 3237）；个股承接出现很大问题，就要及时处理（line 3236）。
- **market_context**: A 股中龙头在高位若出现分时直线跳水且无承接，往往预示阶段性顶部；炸板后次日低开高走则承接良好。
- **quant_relevance**: 可用分时均线偏离度、下跌段成交量占比、买一档位厚度变化、Level-2逐笔大单流向代理承接与抛压。

### 15. 辨识度
- **concept**: 辨识度
- **plain_explanation**: 一只股票被全市场短线资金识别为“龙头”的清晰程度。辨识度源于逻辑硬度、连板高度、板块地位、历史股性和市场人气。辨识度越高，越能吸引跟风资金，也越能在分歧中存活。
- **original_basis**: 当龙头股鹤立鸡群，从而有了更多的关注度！关键是这种关注度是跟风股望尘莫及的（line 2024-2028）；人气出于逻辑，但高于逻辑（line 2080-2086）。
- **market_context**: A 股中辨识度最高的票通常是全市场最高板、题材最纯正、名字最顺口（如东方通信）、历史妖股记忆深的标的。
- **quant_relevance**: 可用综合排名代理：连板高度排名 + 涨停封单金额排名 + 社交媒体/股吧热度 + 搜索指数 + 昨日涨停溢价排名。

### 16. 市场合力
- **concept**: 市场合力
- **plain_explanation**: 不同性质的资金（点火、半路、扫板、排板）在利好或题材感召下共同买入，推动股价涨停。与单一主力控盘不同，合力涨停具有更高的市场认可度和持续性。
- **original_basis**: 各类不同的资金合称为市场合力（line 236-242）；一个好的点火单通常引导市场合力买入（line 2095-2107）。
- **market_context**: A 股中突发利好下的板块集体涨停、无单一主力痕迹的秒板，都是市场合力的体现，龙虎榜通常呈现多路游资共同参与。
- **quant_relevance**: 可用龙虎榜买方家数（≥3家知名游资）、封单分散度（非一家独大）、换手充分性（非缩量一字）来代理市场合力强度。

### 17. 人气
- **concept**: 人气
- **plain_explanation**: 市场对某只股票的集体关注度和参与意愿，是逻辑、高度、板块、资金共同作用的结果。人气股一旦崩溃，对市场情绪打击巨大；人气股超预期走强，则能激活全场。
- **original_basis**: 当龙头股有逻辑、有高度、有板块跟随，自然就有人气。人气出于逻辑，但高于逻辑。有了人气，就能带来源源不断的关注和资金（line 2080-2086）。
- **market_context**: A 股中人气股通常出现在通达信“在线人气”榜、同花顺热股榜、东方财富人气榜，封单金额和换手率显著高于同板块个股。
- **quant_relevance**: 可用涨停封单金额 + 换手率 + 股吧/雪球讨论量 + 昨日涨停今日溢价 + 开盘竞价量综合打分代理人气。

### 18. 分歧/一致
- **concept**: 分歧与一致
- **plain_explanation**: 分歧是多空双方对股价后市看法不一，表现为高换手、炸板、放量、长上下影；一致是多空达成共识，表现为缩量一字、秒板、排队抢筹。核心口诀：买在分歧，卖在一致。
- **original_basis**: 生于分歧，死于一致；买在分歧，卖在一致（line 4478-4479）。
- **market_context**: A 股中分歧常出现在龙头加速前的换手板或炸板后回封；一致常出现在高潮期批量一字板。连续一致后往往接分歧或退潮。
- **quant_relevance**: 可量化为：高换手率（>15%）+ 炸板次数 + 长上下影线 = 分歧；缩量（<5%）+ 一字板/秒板 + 高开无回调 = 一致。

### 19. 筹码结构（阴区/迎龙玉带/龙行猫步）
- **concept**: 筹码结构
- **plain_explanation**: 股价上方是否存在密集套牢区（阴区），以及当前筹码是否均匀分散。远离阴区且筹码分散的形态称为“迎龙玉带”；底部量价异常（阳多阴少、阳密阴疏）的形态称为“龙行猫步”。健康的筹码结构是短线爆发的基础。
- **original_basis**: 密集成交带、放量大阴柱、跳空缺口所在的区域称之为阴区（line 2531-2535）；迎龙玉带是距离阴区时空较远、筹码均匀分散的形态（line 2531-2535）；龙行猫步是底部量价异常（阳高阴低、阳多阴少、阳密阴疏）的建仓痕迹（line 2593-2612）。
- **market_context**: A 股中突破前高或缺口后若无套牢盘压制，涨停更容易持续；底部阳线放量、阴线缩量的个股更易被主力运作。
- **quant_relevance**: 阴区可用筹码分布PEAK、前高/缺口距离代理；迎龙玉带可用筹码集中度（低PEAK）+ 股价至前高距离代理；龙行猫步可用阳线量/阴线量、阳线数/阴线数、阳线换手/阴线换手代理。

### 20. 题材级别/硬度
- **concept**: 题材级别与硬度
- **plain_explanation**: 题材级别指政策或事件的影响力层级（国家综合政策>行业政策>公司公告）；题材硬度指个股与题材逻辑的关联紧密程度。级别大、硬度高、盘面强的题材才值得参与。
- **original_basis**: 大级别的题材孕育着大机会；国家综合性政策就是如此（line 1308-1338）；题材和个股的关联程度称之为“题材的硬度”（line 1537）。
- **market_context**: A 股中“中共中央国务院”发文级别最高，如雄安新区、科创板；公司主营业务与题材直接相关的个股硬度高，蹭概念的个股硬度低。
- **quant_relevance**: 级别可用政策发布机构层级（国务院/部委/地方）+ 关键词权重代理；硬度可用公司公告/财报中题材关键词匹配度+营收关联度代理。两者均需NLP技术，目前属于shell_only或needs_extra_data。

## # FORMULAS_AND_ALGOS

### 1. 情绪阶段评分草案（EmotionCycleScore）
- **source_basis**: 共振冰点、物极必反、涨跌家数、涨停跌停比、连板数（EX-021、EX-042、EX-045）
- **proxy_formula_or_logic**: 
  ```
  Score = 0.25 * (上涨家数 / 总交易家数) 
        + 0.15 * min(涨停家数 / 80, 1.0) 
        - 0.25 * min(跌停家数 / 20, 1.0) 
        + 0.20 * (最高连板高度 / 10) 
        + 0.15 * (昨日涨停指数涨幅 / 5%) 
  阶段判定：
    Score < -0.3  -> 冰点/退潮
    -0.3 ~ 0.1   -> 分歧/混沌
    0.1 ~ 0.4    -> 发酵/修复
    0.4 ~ 0.7    -> 加速/一致
    > 0.7        -> 高潮/过热（风险区）
  ```
- **required_fields**: 每日涨跌家数、涨停家数、跌停家数、最高连板高度、昨日涨停指数涨幅（或涨停股次日平均溢价）
- **caveats**: 参数需根据市场总家数（A股约5000+）校准；熊市和牛市阈值不同，建议用历史分位数动态调整；需区分大盘情绪与短线情绪。

### 2. 龙头评分草案（DragonScore）
- **source_basis**: 龙头六大特征（逻辑、逆势、领涨、高度、板块、人气）及市场地位排序（EX-009、EX-010、EX-011、EX-038）
- **proxy_formula_or_logic**:
  ```
  DragonScore = 0.25 * 连板高度（归一化到10板）
              + 0.20 * min(同题材涨停家数 / 15, 1.0)
              + 0.15 * (1 - 封板时间排序分位，越早越高)
              + 0.15 * max(昨日涨停今日溢价, 0) / 10%
              + 0.15 * 封单金额 / 流通市值（归一化）
              + 0.10 * (1 - |换手率 - 10%| / 20%)  // 适中换手最优
  主线龙头加分：+0.10（若属于当日最强板块）
  市场总龙头加分：+0.15（若全市场连板最高）
  ```
- **required_fields**: 连板高度、同题材涨停家数、封板时间、昨日溢价、封单金额、流通市值、换手率、板块强度排名
- **caveats**: 不同市场阶段权重应动态调整（加速期降低换手权重，分歧期提高换手权重）；缩量一字板评分可能虚高，需用“非换手板扣分”修正；排除ST及问题股。

### 3. 板块联动强度评分（BlockStrengthScore）
- **source_basis**: 涨停家数3只勉强合格、5只以上算强；连板梯队；中军支撑（EX-034、EX-035、EX-003）
- **proxy_formula_or_logic**:
  ```
  BlockScore = 0.35 * min(板块涨停家数 / 10, 1.0)
             + 0.30 * 连板梯队完整度
               （1板存在+0.1，2板存在+0.1，3板+0.1，4板+0.1，5板+0.1，满分0.5）
             + 0.20 * max(板块指数涨幅, 0) / 5%
             + 0.15 * max(中军涨幅, 0) / 5%
  其中：中军 = 板块内流通市值前3且当日涨幅前3的个股中涨幅最高者
  ```
- **required_fields**: 板块涨停列表、连板分布、板块指数涨幅、板块成分股市值与涨幅
- **caveats**: 中军需预先定义；ST股应剔除；板块指数需与概念一致（如通达信/同花顺概念指数）；一字板占比过高时强度评分需打折。

### 4. 弱转强事件检测逻辑（WeakToStrongDetector）
- **source_basis**: 前日烂板/炸板，次日强势修复（EX-011、EX-039、EX-040）
- **proxy_formula_or_logic**:
  ```
  IF (前日最大回撤 > 3% OR 前日炸板 = 1 OR 前日长上影 = 1)
     AND 次日开盘涨幅 > 3%
     AND 次日封板时间 <= 开盘后30分钟
     AND 次日开盘成交量 / 前日成交额 > 5%
  THEN WeakToStrong = 1
  
  附加过滤：
    - 排除当日有明确利空公告的个股
    - 排除大盘当日跌幅 > 2%的极端环境
    - 加分：同题材龙头当日也强势（板块效应确认）
  ```
- **required_fields**: 前日K线高点/收盘回撤、炸板标记、长上影标记、次日开盘涨幅、次日封板时间、次日开盘成交量、前日成交额、公告事件
- **caveats**: 需排除公告利空和大盘极端下跌；弱转强失败率不低，建议仅作为“观察池”信号，需结合板块强度二次确认；连续弱转强（2次以上）效力递减。

### 5. 回封质量评分（ReSealQualityScore）
- **source_basis**: 炸板后回封速度与板块强度、换手充分性（EX-012、EX-013、EX-040）
- **proxy_formula_or_logic**:
  ```
  ReSealScore = 0.45 * (1 / max(回封时间分钟数, 1))  // 回封越快分越高
              + 0.30 * min(回封时板块涨停家数 / 板块前日涨停家数, 1.0)
              + 0.15 * 回封时封单金额 / 流通市值（归一化）
              + 0.10 * (1 - 开板次数 / 5)  // 开板越少越好
  
  若无法回封（收盘未封板）：ReSealScore = 0
  ```
- **required_fields**: 首次开板时间、回封时间、回封时板块涨停家数、前日板块涨停家数、回封时封单金额、流通市值、开板次数
- **caveats**: 需要Level-2精确时间；分钟线可用“首次回封所在分钟数”近似；回封质量高不代表次日一定溢价，需结合情绪周期（加速期回封>退潮期回封）；尾盘回封（14:30后）评分需打折。

### 6. 退潮风险评分（EbbRiskScore）
- **source_basis**: 龙头倒、涨停溢价低、跌停增多、首冰再冰（EX-018、EX-016、EX-019）
- **proxy_formula_or_logic**:
  ```
  EbbRiskScore = 0.30 * (1 - max(昨日涨停今日平均开盘, 0) / 5%)
               + 0.25 * max(龙头池平均跌幅, 0) / 5%
               + 0.20 * min(跌停家数 / 10, 1.0)
               + 0.15 * max(炸板率 - 0.3, 0) / 0.7
               + 0.10 * (1 - min(涨停家数 / 50, 1.0))
  
  其中龙头池 = 前一日连板高度 >= 3板的全部个股（或市场前10高标）
  
  风险等级：
    < 0.3 -> 安全/正常
    0.3 ~ 0.6 -> 警惕/分歧加大
    > 0.6 -> 退潮/空仓信号
  ```
- **required_fields**: 昨日涨停股今日开盘涨幅、龙头池涨跌幅、跌停家数、炸板率、涨停家数
- **caveats**: 龙头池定义主观（可用全市场连板高度前10或前一日非一字连板股）；阈值需动态调整（牛市容忍度更高）；注意区分“良性分歧”与“系统性退潮”。
