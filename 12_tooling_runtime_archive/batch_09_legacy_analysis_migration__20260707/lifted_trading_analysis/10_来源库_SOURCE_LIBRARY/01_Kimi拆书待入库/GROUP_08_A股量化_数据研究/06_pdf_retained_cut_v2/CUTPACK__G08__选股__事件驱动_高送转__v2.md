## FULL_TEXT

### 摘要

"高送转"是指大比例送红股或大比例以资本公积金转增股本，一般10送或转5以上才定义为高送转。我国股票市场存在很显著的"高送转"效应，即在上市公司发布"高送转"预告前后，股票常常会有显著的超额收益。

核心结论：
- 预测模型分为两个部分：样本股的筛选和因子打分环节。样本股的筛选：以全部A股为对象，剔除总股本在75%分位数以上、股价在50%分位数以下的股票。因子打分：设定每股收益、每股净资产、每股资本公积、每股未分配利润、每股现金流、总股本和股价这7个因子为打分因子（总股本取负数），针对每个因子进行打分，最后将股票在各个因子上的得分加总，得分越高的股票预测其发生高送转的可能性越大。
- 在2007年至2011年的实证期内，得分最高的10只、30只、50只股票的平均预测命中率分别为82%、71%、68%。
- 2011年的年报尚未全部公布，从已公布送转方案的公司统计，得分最高的10只、30只和50只股票的命中率分别已达80%、86%和90%，随着分红方案的不断公布，命中率可能还会有进一步的提升。

### 1. 高送转股票的特点

从2006年以来高送转股票的统计来看：
- 每年发生高送转的股票数量基本维持逐年增加的趋势（除2008年数量有所减少）
- 从股本规模来看，高送转股票的总股本平均在4亿股左右，85%高送转的股票的总股本都在6亿股以下。股本越小的上市公司，股本扩张的意愿就更强
- 近年来，高成长性的中小盘股票逐渐成为高送转队伍的主力军。在2006年以来高送转股票中，中小板和创业板的股票占比越来越高，这一占比在2006年至2010年分别为21%、35%、45%、56%和76%，每年都能有10%以上的稳定增加
- 高送转的股票成长性普遍较好，2006年至2010年，高送转股票的扣非后净利润平均增速分别为68%、112%、94%、168%和146%
- 高送转股票往往具有较高的每股收益、每股净资产、每股资本公积、每股未分配利润和每股现金流

### 2. 高送转预测模型

**样本股的筛选**：根据前面的分析，绝大多数高送转股票都具有股本小、股价高、成长性高业绩增速快等特点。以全部A股为对象，剔除总股本在75%分位数以上、股价在50%分位数以下的股票，剩余的股票作为样本空间，以避免预测过程中过多的噪音。

**因子打分环节**：设定每股收益、每股净资产、每股资本公积、每股未分配利润、每股现金流、总股本和股价这7个因子为打分因子（由于股本越小扩张的意愿就更强，便于处理，总股本指标取负数），针对每个因子将样本空间中的股票进行打分，最后将股票在各个因子上的得分加总，得分越高的股票预测其发生高送转的可能性越大。

**预测模型的具体流程**：
1. 获取全部A股数据
2. 剔除总股本>75%分位数、股价<50%分位数的股票
3. 对7个因子分别进行行业内或全市场排序打分
4. 将各因子得分加总（总股本得分取负）
5. 按总分从高到低排序
6. 选取Top10/30/50作为预测组合
7. 年报披露后验证命中率

### 3. 模型预测的实证分析

**注意事项**：
1. 由于一年中绝大多数的高送转发生在年报，所以实证中不包括中报高送转股票的预测，仅仅对年报高送转进行预测
2. 由于信息不对称等原因，高送转股票在预告前股价常常会有提前反应。为了提前布局，增强操控性，财务数据来源均是以当年的三季报为准，股本和股价以当年最后一个交易日为准
3. 依据筛选规则，每年选出得分靠前的50只股票作为参考组合，当参考组合中的股票在当年年报实施10送转5股或以上时，认为预测正确

**命中率统计**：

| 年份 | Top10命中率 | Top30命中率 | Top50命中率 |
|------|-------------|-------------|-------------|
| 2007 | 100% | 80% | 72% |
| 2008 | 60% | 40% | 40% |
| 2009 | 80% | 70% | 66% |
| 2010 | 90% | 96.67% | 94% |
| 2011 | 80% | 86.2% | 90% |
| 平均 | 82% | 71.33% | 67.60% |

（资料来源：海通证券研究所）

特点：
1. 在不同年份，随着预测股票数目的增加，预测命中率均呈现减小的趋势，这也从侧面说明了打分排序是有效的，即得分高的股票发生高送转的可能性更大
2. 2007年至2011年的实证期内，得分最高的10只股票的平均预测命中率为82%，命中率最低2008年为60%，最高的2007年的命中率均高达100%
3. 得分最高的30只股票的平均预测命中率为71.33%，命中率最低2008年为40%，最高的2010年的命中率均高达96.67%
4. 得分最高的50只股票的平均预测命中率为67.60%，命中率最低2008年为40%，最高的2010年的命中率均高达94%

2011年的年报尚未全部公布，从已公布送转方案的公司统计，得分最高的10只、30只和50只股票的命中率分别已达80%、86.2%和90%，随着分红方案的不断公布，命中率可能还会有进一步的提升。

## FORMULAS_AND_ALGOS

### 高送转定义
```
送转比例 >= 0.5（即每10股送转>=5股）
包括：送红股、资本公积金转增股本、或两者结合
```

### 样本筛选规则
```
剔除：总股本 > 75%分位数
剔除：股价 < 50%分位数
剩余：样本空间
```

### 7因子打分体系
```
因子列表：
1. 每股收益（正向）
2. 每股净资产（正向）
3. 每股资本公积（正向）
4. 每股未分配利润（正向）
5. 每股现金流（正向）
6. 总股本（负向）——得分取负数
7. 股价（正向）

总分 = Σ(各因子得分)
```

### 预测命中率计算
```
命中率 = 预测组合中实际高送转的股票数 / 预测组合股票总数
```

### 策略执行步骤
1. 每年三季报披露后，获取全市场数据
2. 按总股本和股价筛选样本空间
3. 计算7个因子值并排序打分
4. 计算总分（注意总股本取负）
5. 按总分排序，选取Top10/30/50
6. 持续跟踪至年报披露，验证命中率
7. 对得分较高但还未公布送转方案的股票提前布局

### 适用条件
- 每年三季报披露后启动预测（11月-12月）
- 预测对象为年报高送转（忽略中报）
- 适用于中小盘、高成长、高股价股票池
- 股本小于6亿股、股价较高的股票概率更大
- 提前布局以获取预告前的超额收益

### 失效条件
- 2008年命中率显著下降（市场环境极端）
- 高送转监管政策变化（如限制高送转比例）
- 大盘股、低股价股票（已被筛选剔除）
- 业绩下滑但历史资本公积高的公司（可能不满足成长性）
- 信息不对称程度降低后，预告前股价提前反应减弱
