> 全文保留：海通证券《相关性选股策略——在化学工业行业的实证》
> 研究时段：2003年12月–2011年9月；样本外起点：2005年12月；采样频率：月度

## 一、研究目的与方法

相关性选股通过对因子和股票超额收益历史相关性的度量，筛选出具有显著相关性的选股因子，以此为基础在行业中进行选股。此前该策略已在全市场、商业贸易、房地产、有色金属、纺织服装和公用事业行业获得较好超额收益。本文选定化工行业进行实证，沿用之前报告中的选股模型，最终得到明显的超额收益。

### 1.1 指标池

备选因子共25个，分为6类：

| 类别 | 指标 |
|------|------|
| 盈利能力 | ROA、ROE、EPS、毛利率、净利润率、Delta(ROA)、Delta(ROE)、Delta(毛利率)、Delta(EPS)、Delta(净利润率)、主营业务收入增长率 |
| 偿债能力 | 资产负债率 |
| 资产运营 | 总资产周转率、每股净资产 |
| 估值 | PE、PB |
| 市值 | 流通市值、总市值 |
| 技术面 | 一个月收益率、三个月收益率、六个月收益率、DIFF、MACD、一个月平均换手率、三个月平均换手率 |

### 1.2 数据处理与样本划分

- 样本内：2003年12月–2005年11月（24个月）
- 样本外：2005年12月–2011年9月（70个月）
- 财务指标在没有更新的月份，采用最新可获得的数据作为备选指标。
- 固定样本内数据长度为24个月，滚动更新（每次加入最新月，舍去起点月）。
- 在样本内每个月上，分别对收益率和待选指标排序，得到考察相关性的数据集。
- 用Pearson相关性检验获得具有显著相关性的优选指标（显著性水平取0.01）。
- 在样本外按这些指标对股票排序打分，计算每只股票的平均得分，从高到低取排名前5%和10%的股票形成投资组合。

### 1.3 交易费用

市值加权，交易费用采用双边各0.5%。考察各投资组合在样本外的累积收益，并与海通证券行业分类中的化学工业指数进行比较。

## 二、实证结果

### 2.1 策略长期收益表现（市值加权）

| 策略 | 样本股数 | 累计收益(%) | 年化收益率(%) | 年化波动率(%) | 夏普值 | 信息比 | 最大回撤(%) |
|------|----------|-------------|---------------|---------------|--------|--------|-------------|
| 化学工业指数 | — | 173.89 | 18.85 | 40.68 | 0.46 | — | -30.67 |
| 策略 | 10只 | 676.22 | 42.09 | 44.12 | 0.95 | 1.44 | -30.32 |
| 策略 | 20只 | 526.45 | 36.97 | 44.24 | 0.84 | 1.44 | -30.75 |

**结论**：
1. 从月度收益看，策略对指数胜率约70%，最终净值分别为行业指数的2.83倍（10只）和2.29倍（20只）。
2. 10只股票的组合略优于20只，显示相关性选股策略能识别对未来超额收益有预测作用的指标。
3. 策略在09年前几乎无超额收益，之后大幅战胜指数，原因是选股因子结构性变化：从08年12月开始，市值因子（总市值、流通市值）每期显著负相关，小市值公司超额收益更高，与09–10年小盘股行情吻合。
4. 市场齐涨共跌时（07–08年）策略跟踪指数走势，市场风格变化时（09–10年）及时反应获取超额收益，兼顾稳定性与灵敏性。

### 2.2 等权重加权对比

和市值加权相比，等权重加权的超额收益下降明显：
- 10只组合累积净值降为行业指数的1.49倍，波动较为剧烈。
- 20只组合基本无法战胜指数。

策略的单调性表现明显，说明相关性选股策略在化学工业行业有效。

### 2.3 2011年表现

截至2011年9月，策略累计收益7.93%，超额收益22.04%。但2011年9月市值加权组合大幅跑输行业（超额收益-9.82%），原因是中石化（600028）和中石油（601857）流通市值占化工行业70%以上，对行业指数影响举足轻重；策略推荐小市值公司，导致市值加权组合跑输。若剔除中石化和中石油后计算指数，上月收益率为-11.69%，策略收益为-14.18%，仅跑输2.49%。截至10月13日，市值加权组合已获得4.35%超额收益。

# FORMULAS_AND_ALGOS

## 1. Pearson相关性选股核心流程（伪代码）
```
输入：行业股票池 S，因子池 F（25个），窗口长度 L=24个月
输出：每月优选因子集合 G_t，组合持仓 P_t

for 每个样本外月份 t:
    样本内数据 = [t-L, t-1] 的月度数据
    for 每个月 m in 样本内:
        对行业内所有股票按下期收益率排序 → rank_R_m
        对每个因子 f in F:
            对行业内所有股票按因子值排序 → rank_f_m
    for 每个因子 f in F:
        计算 rank_R 与 rank_f 的Pearson相关系数 r_f
        进行双侧显著性检验，得 p_f
        if p_f ≤ 0.01:
            将 f 加入优选集合 G_t
    for 每只股票 s in S:
        score_s = mean( rank_f_t(s) ) for f in G_t  // 按优选因子排序后取平均排名
    按 score_s 从高到低排序
    P_t(10只) = 前5%股票
    P_t(20只) = 前10%股票
    持仓权重 = 流通市值加权（或等权重）
```

## 2. 关键公式

**Pearson相关系数**
$$r_{XY} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$$

其中 $X_i$ 为因子排序值，$Y_i$ 为下期收益率排序值。

**年化收益率**
$$R_{annual} = \left( \frac{NAV_T}{NAV_0} \right)^{\frac{12}{T}} - 1$$

**夏普比率**
$$Sharpe = \frac{R_p - R_f}{\sigma_p}$$

**信息比率**
$$IR = \frac{\alpha_p}{TE_p}$$

## 3. 因子定义

| 因子 | 计算公式 |
|------|----------|
| Delta(ROA) | $(ROA_t - ROA_{t-1}) / \|ROA_{t-1}\|$ |
| Delta(ROE) | 同上 |
| Delta(EPS) | 同上 |
| Delta(毛利率) | 同上 |
| Delta(净利率) | 同上 |
| 主营业务收入增长率 | $(Revenue_t - Revenue_{t-4}) / Revenue_{t-4}$ |
| 资产负债率 | 总负债 / 总资产 |
| MACD | DIF - DEA（其中DIF=12日EMA−26日EMA，DEA=DIF的9日EMA） |
| 一个月平均换手率 | 近20个交易日换手率均值 |
| 总市值 | 总股本 × 收盘价 |
| 流通市值 | 流通股本 × 收盘价 |
