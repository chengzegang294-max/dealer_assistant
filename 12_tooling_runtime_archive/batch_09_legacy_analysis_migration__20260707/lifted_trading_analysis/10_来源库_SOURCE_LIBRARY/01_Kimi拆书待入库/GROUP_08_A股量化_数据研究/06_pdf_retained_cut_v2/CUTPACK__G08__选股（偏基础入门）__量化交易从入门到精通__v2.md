## CONTENT_CLUSTERS

### CLUSTER-01 能量守恒与价格-时间分析框架
- 核心：将物理能量守恒映射到市场多空能量守恒，提出价格(P)+时间(T)守恒公式。
- 量化锚点：等距箱体突破、震荡充分定义（30根K线）、周期对等循环。
- 关键产出：主观交易六要素口诀（量能、趋势、形态、均线、周期、指标）可转化为多维度打分模型。

### CLUSTER-02 趋势定义与结构识别
- 核心：高点/低点排列定义趋势；末升低/末跌高作为趋势终结信号；震荡区间的支撑阻力反转。
- 量化锚点：市场结构极值点连线、趋势线、水平位反转概率。
- 关键产出：TOP32趋势理论量化策略（突破结构高低点+SAR离场）已提供MC源码。

### CLUSTER-03 速度分型与速率循环
- 核心：急速↔缓速行情的对应规律（急涨→缓跌，急跌→缓涨，缓涨→急跌，缓跌→急涨）。
- 量化锚点：速率分型图、顶底背离的物理本质（速度从鼎盛到衰退）。
- 关键产出：不同速度型行情应使用不同策略（顺势 vs 逆势），可作为策略切换的体制转换(Regime Switching)输入。

### CLUSTER-04 移动平均线体系
- 核心：MA/EMA/专业线/双子线/生命线/织女线；蓝绿系统、红绿系统、红蓝系统（成本线通道）。
- 量化锚点：周期2-49短期、50-99中期、100+长期；多头排列/空头排列定义。
- 关键产出：TOP41均线离散策略（三均线离散度+自适应均线通道）源码。

### CLUSTER-05 通道与波动率突破策略
- 核心：金肯特纳（Keltner）、布林线（Bollinger）、唐奇安通道（Donchian）、Aberration通道。
- 量化锚点：三价均线±ATR、中轨±2σ、35日MA±35日标准差、收盘价突破上轨/下轨。
- 关键产出：TOP22简单布林策略、TOP29五线谱策略、TOP18肯特纳量化策略、强盗布林策略源码。

### CLUSTER-06 经典指标量化应用（RSI/MACD/SAR/ADX/Aroon）
- 核心：各指标的计算公式、参数适配、改良用法、与通道/均线结合的多重滤网。
- 量化锚点：RSI(20/80超买超卖)、MACD(DIF=EMA12-EMA26)、ADX(20分界)、Aroon(100/70/45/30/0分级)。
- 关键产出：TOP3价格回归策略（RSI+均线偏离）、TOP27（SAR+唐奇安）、TOP34（ADX+均线+SAR）、TOP30三重滤网（飞跃线+ATR+SAR）源码。

### CLUSTER-07 多因子与经典策略复现
- 核心：六君子多因子打分（趋势+飞跃线+回归+K线异常+海龟突破+布林突破）；R-Breaker日内反转；恒温器(Thermostat)体制转换；Dual Thrust日内突破；一目均衡表。
- 量化锚点：因子权重累加、非对称通道、CMI震荡/趋势切换、六个价位计算。
- 关键产出：TOP38六君子策略、R-Breaker、Thermostat、Dual Thrust、一目均衡表源码。

### CLUSTER-08 仓位管理与风控体系
- 核心：最大回撤10%红线；保证金+风险权益拆分；凯利公式变体仓位计算；网格策略的四种实现与动态调整。
- 量化锚点：仓位=[胜率-(1-胜率)/盈亏比]/2；固定百分比止损止盈；时间止盈；自适应均线出场递减。
- 关键产出：金肯特纳、强盗布林、TOP55双唐奇安等策略的风控模块可直接复用。

### CLUSTER-09 量价异动与波动率择时
- 核心：量在价先、天量天价、地量地价；成交量波幅与价格波幅对比；波动率对数收益率择时。
- 量化锚点：单根K量突放大X倍+涨跌幅>Y倍ATR；对数收益率波动率上穿90周期高点做多。
- 关键产出：TOP40量价异动策略；附录一吕尚沪深300波动率择时策略（Python+MC双版本）。

### CLUSTER-10 策略设计方法论与误区证伪
- 核心：震荡策略vs趋势策略的环境判定；左侧vs右侧交易；正态分布与价格偏离；程序化交易作为证伪工具。
- 量化锚点：正态分布μ±σ确定合理价格区间；假突破过滤；条件单与追踪型停止单。
- 关键产出：设计步骤模板（交易类型→环境判定→进场信号→出场判定→仓位管理）。

    量能为纲、趋势为先、形态为优、均线为绳、周期为重、指标为辅。
    量能为纲——主观交易中我们以“能量守恒理论”为核心，以等距箱体理论、黄金分割延展理论、实用波浪理论为主体。

    形态为优——形态分析是一种直接从历史价格图表上去分辨价格变动趋势的分析方法。市场行情的形态是有其必然性的。
    均线为绳——移动平均线（MA）是以道·琼斯的“平均成本概念”为理论基础，采用统计学中“移动平均”的原理，将一段时期内价格平均值连成曲线，用来显示行情价格的历史波动情况，进而反映价格指数未来发展趋势的技术分析方法。

    指标为辅——笔者认为常用指标是分析行情的辅助工具，而不再是分析过程中的固定主体，以规避在指标分析中经常会出现的本身缺陷。

- **why_kept**: 速度的“对应规律”与“异常变化”提供了行情结构转换的预警信号。当规律被打破时，往往意味着趋势转折。

## FORMULAS_AND_ALGOS

### F01 能量守恒简化公式
- **公式**: P₁ + T₁ = P₂ + T₂ + C
- **变量定义**: P=price（价格）；T=time（时间）；N=选择参数（0.382, 0.5, 0.618, 1, 1.382, 1.5, 1.618等）；C=剩余参数
- **适用条件**: 主观交易中的等距箱体突破目标位估算；震荡充分（30根K线）后的突破。
- **失效条件**: 无法用于精确量化，N和C的选取主观性强；不适用于连续流动市场的高频场景。
- **算法步骤**: 1) 识别震荡箱体（上下轨）；2) 确认突破方向；3) 按箱体等宽设置目标位；4) 时间周期按对等循环估算。

### F02 金肯特纳通道
- **公式**: 三价均线 = (high + low + close) / 3；上轨 = 三价均线 + ATR(atr_period)；下轨 = 三价均线 - ATR(atr_period)
- **变量定义**: atr_period通常为3；MA周期通常为56
- **适用条件**: 中长期趋势跟踪；多品种（期货/股票）适用。
- **失效条件**: 震荡行情中假突破频繁；单一通道无趋势过滤时胜率低。
- **算法步骤**: 1) 计算典型价格；2) 计算典型价格的MA；3) 计算ATR；4) 构建上下轨；5) 收盘突破上轨做多，突破下轨做空；6) MA反穿出场。

### F03 考夫曼自适应均线（Kaufman AMA）
- **公式**: direction = |close - close.shift(n)|; volatility = Σ|close - close.shift(1)| over n periods; ER = direction / volatility; sc = (ER × (2/(fast+1) - 2/(slow+1)) + 2/(slow+1))²; AMA = AMA[1] + sc × (close - AMA[1])
- **变量定义**: fast=2, slow=30（常用）；n=效率系数计算周期（常用10）
- **适用条件**: 需要平衡灵敏度与噪音的均线场景；趋势/震荡过渡频繁的市场。
- **失效条件**: 效率系数接近0时AMA几乎不移动，可能错过快速启动；价格跳空时滞后。
- **算法步骤**: 1) 计算方向变动；2) 计算总波动；3) 求效率系数ER；4) 映射到平滑系数；5) 递推计算AMA。

### F04 布林带（Bollinger Bands）
- **公式**: MB = MA(close, N); MD = sqrt(Σ(close - MA)² / N); UP = MB + k × MD; DN = MB - k × MD; WIDTH = (UP - DN) / MB
- **变量定义**: N=周期（常用20/48/75）；k=标准差倍数（常用2/1.8/3）；WIDTH=极限宽指标
- **适用条件**: 波动率压缩后的突破（WIDTH收窄）；均值回归（价格触及上轨/下轨）。
- **失效条件**: 强趋势中价格可能长期沿上轨运行，此时回归策略失效；WIDTH阈值需品种适配。
- **算法步骤**: 1) 计算中轨MA；2) 计算标准差MD；3) 构建上下轨；4) 计算WIDTH判断收口；5) 突破上轨做多/下轨做空，或触及上下轨反向操作。

### F05 强盗布林出场递减算法
- **公式**: exit_ma_period = max(initial_ma - bars_since_entry, min_ma)
- **变量定义**: initial_ma=44; min_ma=18; bars_since_entry=持仓周期数
- **适用条件**: 趋势策略的出场优化；持仓越久越保护利润。
- **失效条件**: 在V型反转中，递减MA可能来不及保护利润；需配合硬止损。
- **算法步骤**: 1) 开仓时记录currentbar；2) 每周期计算持仓周期数；3) 计算exit_ma_period = max(initial - held, minimum)；4) 以exit_ma_period计算MA，价格跌破则出场。

### F06 RSI
- **公式**: RSI = SMA(max(close - close_prev, 0), N, 1) / SMA(|close - close_prev|, N, 1) × 100
- **变量定义**: N=周期（A股日线常用15）
- **适用条件**: 摆动区间判断超买超卖；结合趋势过滤做反转。
- **失效条件**: 强趋势中RSI可能长期>80或<20（钝化）；单独使用假信号多。
- **算法步骤**: 1) 计算价格变动；2) 分离上涨和下跌幅度；3) 计算平滑移动平均；4) 求RSI值；5) >80超买/20超卖；6) 结合均线或成本线偏离确认信号。

### F07 MACD
- **公式**: DIF = EMA(close, 12) - EMA(close, 26); DEA = EMA(DIF, 9); MACD柱 = (DIF - DEA) × 2
- **变量定义**: 快线12/慢线26/DEA9为国内默认参数
- **适用条件**: 趋势方向判断；DIF上穿零轴做多；柱斜率判断趋势加速/减速。
- **失效条件**: 震荡行情中DIF围绕零轴反复穿越，产生大量假信号；需配合过滤条件。
- **算法步骤**: 1) 计算EMA12和EMA26；2) 求DIF；3) 计算DEA；4) 求MACD柱；5) 观察DIF/DEA交叉和柱斜率。

### F08 ADX/DMI
- **公式**: TR = max(high - low, |high - close_prev|, |low - close_prev|); +DM = high - high_prev if > low_prev - low else 0; -DM = low_prev - low if > high - high_prev else 0; +DI = SMA(+DM, N) / SMA(TR, N) × 100; -DI = SMA(-DM, N) / SMA(TR, N) × 100; DX = |+DI - -DI| / (+DI + -DI) × 100; ADX = SMA(DX, N)
- **变量定义**: N=14（常用）
- **适用条件**: 趋势强度判断；ADX<20且递增为趋势初生；ADX高位转跌为趋势衰竭。
- **失效条件**: 计算复杂，滞后性明显；ADX不指示方向，仅指示强度。
- **算法步骤**: 1) 计算TR、+DM、-DM；2) 平滑得到+DI14、-DI14；3) 计算DX；4) 平滑得到ADX；5) 判断ADX水平及方向。

### F09 R-Breaker 六个价位
- **公式**: Ssetup = High + a × (Close - Low); Bsetup = Low - a × (High - Close); Senter = b/2 × (High + Low) - c × Low; Benter = b/2 × (High + Low) - c × High; Sbreak = Ssetup - d × (Ssetup - Bsetup); Bbreak = Bsetup + d × (Ssetup - Bsetup)
- **变量定义**: a=0.1, b=0.2, c=0.15, d=5（常用）；High/Low/Close为前一日数据
- **适用条件**: 日内股指/高流动性品种的突破+反转策略。
- **失效条件**: A股T+1限制日内反转；参数过多易过度拟合；波动过小不交易需额外过滤。
- **算法步骤**: 1) 计算前日6个价位；2) 盘中追踪价格；3) 突破Bbreak/Sbreak开仓；4) 触及观察价后反转至反转价则反手；5) 收盘前平仓。

### F10 CMI（恒温器市场波动指数）
- **公式**: CMI = |close - close.shift(n-1)| × 100 / (highest(high, n) - lowest(low, n))
- **变量定义**: n=28（常用）
- **适用条件**: 趋势/震荡体制切换；CMI<20震荡，CMI≥20趋势。
- **失效条件**: 单一阈值（20）可能不适用于所有品种；需根据历史数据校准。
- **算法步骤**: 1) 计算n周期价格变化绝对值；2) 计算n周期价格区间；3) 求CMI；4) 与阈值20比较确定体制；5) 分别执行震荡或趋势策略。

### F11 波动率对数择时（附录一）
- **公式**: return = log(close) / log(close.shift(90)) - 1; ma90 = return.rolling(90).mean(); up_line = return.rolling(90).max().shift(1); 信号：return > up_line时做多；return < ma90时平仓
- **变量定义**: 周期=90；标的=沪深300ETF/现货/IF期货60分钟线
- **适用条件**: 大盘指数择时；ETF定投/股指期货交易。
- **失效条件**: 仅做多；做空逻辑未验证；90周期参数需滚动测试。
- **算法步骤**: 1) 计算90周期对数收益率；2) 计算90周期均线和前期最高点；3) 上穿上轨开多；4) 下穿均线平多；5) 循环执行。

### F12 仓位管理公式（凯利变体）
- **公式**: position = [win_rate - (1 - win_rate) / profit_loss_ratio] / 2
- **变量定义**: win_rate=策略历史胜率；profit_loss_ratio=平均盈亏比（平均盈利/平均亏损）
- **适用条件**: 策略上线前的仓位规划；已知历史胜率与盈亏比时。
- **失效条件**: 历史统计不代表未来；需确保样本量足够；结果>1时需截断至1。
- **算法步骤**: 1) 回测获得胜率与盈亏比；2) 代入公式计算理论仓位；3) 除以2作为保守折减；4) 设置最大回撤10%硬约束；5) 根据实盘表现动态调整。

### F13 一目均衡表（Ichimoku）
- **公式**: 转换线 = (9日最高 + 9日最低) / 2; 基准线 = (26日最高 + 26日最低) / 2; 先行带A = (转换线 + 基准线) / 2, 前移26日; 先行带B = (52日最高 + 52日最低) / 2, 前移26日; 云带 = 先行带A与B之间的区域; 迟行带 = 收盘价后移26日
- **变量定义**: 9/26/52为传统参数（日本6天工作周），现代建议7/22/44（5天工作周）
- **适用条件**: 中长期趋势判断；多维度支撑阻力分析。
- **失效条件**: 参数调整需历史验证；云带较宽时信号迟钝；不适合短周期高频。
- **算法步骤**: 1) 计算转换线、基准线；2) 计算并前移先行带A/B；3) 构建云带；4) 价格位于云上方为多头；5) 结合转换线/基准线交叉和迟行带确认。
