# FORMULAS_AND_ALGOS
**公式1：检验统计量**
T = (n-2)R² / (1-R²)

**公式2：组合构建**
每月末对过去J个月收益率排序，分q组
买入最低组（Losers），持有K个月
初始资金分K份，形成K条独立资金链

**公式3：低估值+反转策略**
1. 剔除PB<0样本
2. 保留PB最小的前25%
3. 选择其中收益率最低的5%作为组合

**适用条件**：
- A股市场存在显著反转效应（J=3,K=1最优）
- 低估值+反转复合策略效果最佳
- 可战胜中证800指数

**失效条件**：
- 动量效应策略（J=K=1）表现最差
- 卖空Winners组合无法持续累积收益
- 市场极端行情（2007年普涨）
