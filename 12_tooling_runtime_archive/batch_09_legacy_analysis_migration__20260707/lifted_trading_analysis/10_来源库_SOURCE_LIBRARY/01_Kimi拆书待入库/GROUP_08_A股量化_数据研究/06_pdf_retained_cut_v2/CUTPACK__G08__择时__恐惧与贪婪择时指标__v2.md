# 度量市场“恐惧与贪婪”的量化择时指标

## 报告摘要

- 行为金融学将心理学尤其是行为科学的理论融入到金融学之中，它从微观个体行为以及产生这种行为的心理等动因来解释、研究和预测金融市场的发展。本文希望从量化度量的角度，对市场中经常提及的“恐惧”和“贪婪”进行度量，并寻找其可能带来的投资机会。
- 我们将市场视为不同行业的组合结构，通过分析行业指数同市场指数之间表现的差异性，定义市场一致性指标。当市场处在单边走势下且一致性指标不断抬升，则我们对该类市场定义为“贪婪”或“恐惧”的市场。
- 通过量化操作规则的制定，我们发现市场在进入贪婪或恐惧状态时，往往能够延续原有市场趋势并保持不变，在模型确认的市场拐点处，投资者对行业分歧逐渐加大到一定程度，并开始怀疑原有趋势的合理性，最终导致市场结束趋势并开始反向运行。
- 通过市场指数和一致性指标的对应关系，我们可以寻找到过去5年以来重要的市场“贪婪”时段，如：2007年7月-10月、2009年1月-8月。以及重要的“恐惧”时段，如：2008年8月-11月、2011年9月-12月等。
- 通过市场指数和一致性指标的对应关系，我们可以寻找到过去5年以来重要的市场中长期拐点位置，如：2007年10月9日、2008年11月6日、2009年8月4日、2012年1月11日等。
- 根据交易规则，使用反转点固定持有期策略下，持有1周-10周的绝对次均收益都在1%以上，持有6周收益最高，次均收益为5.11%。若跟踪市场一致性指标高位持续时间长度后，重新定义随后持有相应长度反向交易策略，亦可获得4.33%的次均收益和9周的平均持有期。

## 1. 原理

传统金融学的理论架构是建立在人类理性基础上的一系列严格的假设，诸如自利经济人、理性预期、有效市场等，是基于市场有效假说和投资者理性假说的传统金融理论的基石，影响着金融理论和实践的发展。但实际金融市场却总是偏离理性的价值轨道而运行，各主要国家的证券市场非理性地繁荣或走熊，货币政策总是使得经济难以匀速增长，投资者也不能够简单运用所学的金融知识在市场上获利。

行为金融学将心理学尤其是行为科学的理论融入到金融学之中，它从微观个体行为以及产生这种行为的心理等动因来解释、研究和预测金融市场的发展。这一研究视角通过分析金融市场主体在市场行为中的偏差和反常现象进行理论构建。其有两个基本的研究主题：一是市场并非是有效的，也就是所谓的无效市场（inefficient market）；二是投资者并非是理性的，也就是所谓的“投资者心态”（investor sentiment），主要探讨现实世界中的投资者会发生各种各样的认知和行为偏差问题。围绕这两个主题，我们试图研究如何修正传统金融学理论，使其更加符合实际也更具解释力。本文希望从量化度量的角度，对市场中经常提及的“恐惧”和“贪婪”进行度量，并寻找其可能带来的投资机会。

我们试图用一种量化的方式来解释市场恐惧和贪婪的行为，使用市场的涨跌和市场内部构成品种表现的一致性指标（1-内部差异性）的涨跌进行状态定义。如上图中左半部分被刻画为一个“贪婪”的市场，我们可以看到一个单边上涨的市场和市场内部成分表现的不断趋同，这是典型的狂热买盘的市场，在该市场环境下投资者在看到一个强大赚钱效应机会诱惑下，对市场内部成分的投资价值不做过多划分和区别，而是统一买入各类品种，是典型的“饥不择食”的行为方式，入市行为逐渐脱离了价值投资的理念，而更多转为投机。

反观上图中右半部分，单边下跌的市场，同样伴随着市场内部各成分表现的一致性提升。投资者在类似市场中的直观感受是个股普跌，在经历了一段时间的市场持续下跌后，投资者的情绪开始逐渐从乐观转为中性，并进一步转为悲观，对市场持续下跌的担忧导致了投资者忽略短期相对较好的单独投资品种而选择直接抛售，当抛售行为变得义无反顾时，市场下跌的一致性也达到了更高的位置，这是典型的熊市“恐惧”特征。

## 2. 模型介绍

我们选择使用市场下属的第一层分类、即行业指数来作为市场整体的构成因素，通过行业指标表现的差异性来勾勒市场的一致性指标。而在具体计算中，使用收益率回归拟合的方式，反映具体的定量一致性，最终统计变量为R²。

R²衡量的是回归方程整体的拟合度，是表达因变量与所有自变量之间的总体关系。R²等于回归平方和在总平方和总所占的比率，即回归方程所能解释的因变量变异性的百分比。R²可用下面的韦恩图来解释：圆圈Y表示因变量Y的变异，X表示解释变量X的变异，重叠部分则表示Y的变异能被X的变异解释的部分。

- R²=0：无解释力
- R²=1：完全解释
- 0<R²<1：部分解释

我们用拟合优度来表征市场与行业间的差异程度（若市场完全趋同）则拟合应表现出完全线性性，此时R²取最大值1，反之R²取值较小。

**模型流程：**

1. 输入：沪深300日收盘、万得3级行业指数日收益
2. 以沪深300指数收益为X，各行业指数收益为Y，进行回归分析：Y_i,t = α_i,t + β_i,t × X_t + ε_i,t
3. 保留拟合优度R²值，构成时间序列
4. 以构建的R²序列代表一类市场一致性指标
5. 通过形态分析，按此指标发出预警、反转信号

## 4. 总结

行为金融学将心理学尤其是行为科学的理论融入到金融学之中，它从微观个体行为以及产生这种行为的心理等动因来解释、研究和预测金融市场的发展。本文希望从量化度量的角度，对市场中经常提及的“恐惧”和“贪婪”进行度量，并寻找其可能带来的投资机会。

我们将市场视为不同行业的组合结构，通过分析行业指数同市场指数之间表现的差异性，定义市场一致性指标。当市场处在单边走势下且一致性指标不断抬升，则我们对该类市场定义为“贪婪”或“恐惧”的市场。

通过量化操作规则的制定，我们发现市场在进入贪婪或恐惧状态时，往往能够延续原有市场趋势并保持不变，在模型确认的市场拐点处，投资者对行业分歧逐渐加大到一定程度，并开始怀疑原有趋势的合理性，最终导致市场结束趋势并开始反向运行。

通过市场指数和一致性指标的对应关系，我们可以寻找到过去5年以来重要的市场“贪婪”时段，如：2007年7月-10月、2009年1月-8月。以及重要的“恐惧”时段，如：2008年8月-11月、2011年9月-12月等。

通过市场指数和一致性指标的对应关系，我们可以寻找到过去5年以来重要的市场中长期拐点位置，如：2007年10月9日、2008年11月6日、2009年8月4日、2012年1月11日等。

根据交易规则，使用反转点固定持有期策略下，持有1周-10周的绝对次均收益都在1%以上，持有6周收益最高，次均收益为5.11%。若跟踪市场一致性指标高位持续时间长度后，重新定义随后持有相应长度反向交易策略，亦可获得4.33%的次均收益和9周的平均持有期。

## FORMULAS_AND_ALGOS

### 核心回归公式

对每一行业指数i，在每一时点t进行回归：

```
Y_i,t = α_i,t + β_i,t × X_t + ε_i,t
```

其中：
- `Y_i,t` = 行业i在t日的收益率
- `X_t` = 沪深300指数在t日的收益率
- `α_i,t` = 截距项（行业特异超额收益）
- `β_i,t` = 行业对市场风险的敏感度
- `ε_i,t` = 回归残差（行业非系统性收益）

### 市场一致性指标

```
Consistency_Indicator_t = R²_t
```

其中R²_t为t时点所有行业回归的**平均拟合优度**（或综合拟合优度），取值范围[0,1]。

- R²_t → 1：市场高度一致（贪婪/恐惧状态）
- R²_t → 0：市场分歧大，行业分化明显

### 行业差异性指标

```
Divergence_Indicator_t = 1 - R²_t
```

### 信号生成规则（形态分析）

1. **贪婪/恐惧状态确认**：市场处于单边趋势（沪深300连续上涨/下跌）且R²持续处于高位区间
2. **动量（预警）信号**：R²从高位开始回落，表明原有趋势正在减弱
3. **反转信号**：R²大幅回落至低位区间，市场随时可能出现拐点

### 固定持有期策略

- 以**反转信号日**为建仓起点
- 持有固定N周（N=1,2,...,10）
- 平仓并计算绝对收益

### 浮动持有期策略

- 以**反转信号日**为建仓起点
- 持仓时长 = 前期一致性指标高位持续时长
- 方向：反向交易（高位贪婪后做空/空仓，高位恐惧后做多）

### 适用条件

- 市场处于有明显趋势的单边行情（牛市或熊市）
- 行业间存在可度量的系统性联动关系
- 适用于沪深300为代表的蓝筹市场

### 失效条件

- 震荡市（无明显单边趋势）：一致性指标缺乏方向性基础
- 结构性行情（行业严重分化）：R²天然偏低，无法进入高位区间
- 政策突变或外部冲击导致市场机制改变
- 小盘股主导市场时（建议结合强弱指数=中证500/沪深300进行辅助判断）

## NOT_QUANT_YET

1. **R²阈值参数缺失**：报告未披露R²高位的具体阈值（如0.8、0.9等）、回落比例的具体数值（如从高点回落10%、20%），以及低位区间的具体定义。这些核心参数需要自行通过历史数据标定，存在过拟合风险。——需要完整的R²历史分布数据与稳健的参数优化方法。

2. **形态分析的主观性**：信号生成依赖“形态分析”，缺乏严格的算法化定义。动量信号和反转信号的判定标准包含人的主观判断成分，难以完全程序化。——需要将形态分析转化为可量化的规则（如R²移动平均交叉、MACD式指标等）。

3. **行业指数替代方案**：报告使用万得三级行业指数，但万得数据需授权。若使用申万或中信行业指数替代，R²的绝对值水平和分布特征可能不同，需要重新校准。——需要对比不同行业分类体系下的指标一致性。

4. **浮动策略的映射函数缺失**：报告提到“跟踪市场一致性指标高位持续时间长度后，重新定义随后持有相应长度反向交易”，但未给出具体的时长映射函数（如1:1线性映射还是其他非线性映射）。——需要更详细的规则说明或自行构建映射函数。

5. **样本量不足**：全样本仅14个信号，统计显著性有限。尤其是错误信号仅有3个，难以准确估计错误率置信区间。——需要更长的历史样本或蒙特卡洛模拟评估。

6. **滚动回归窗口长度未披露**：报告未说明回归使用的滚动窗口长度（如30日、60日、120日等），这直接影响R²的平滑度和信号灵敏度。——需要测试不同窗口长度的效果。

7. **未考虑交易成本**：回测结果未扣除交易手续费、冲击成本等。考虑到信号频率较低（约每年2-3次），交易成本影响相对有限但仍需量化。——需要引入成本模型进行净收益回测。

8. **未区分顶部反转与底部反转**：虽然报告用绿色/红色区分顶部和底部反转，但量化规则上是否使用相同参数未说明。底部反转（恐惧后做多）和顶部反转（贪婪后做空/空仓）的市场微观结构不同。——需要分别建模和验证。
