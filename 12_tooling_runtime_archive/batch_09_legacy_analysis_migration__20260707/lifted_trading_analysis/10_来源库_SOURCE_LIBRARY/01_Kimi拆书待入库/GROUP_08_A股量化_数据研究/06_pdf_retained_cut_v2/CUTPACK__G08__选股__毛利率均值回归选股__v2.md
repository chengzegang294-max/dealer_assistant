## FULL_TEXT

### 摘要与研究结论

本文从时间梯度上对行业内部和行业间毛利率本身以及毛利率与涨跌幅之间的关系进行了系统研究。核心结论如下：

1. **行业内毛利率无均值回归**：在行业内部，没有发现均值回归或是反转现象。各行业的毛利率基本都不存在均值回归现象。不同档次股票的毛利率领先落后的趋势，基本上始终保持不变。第一档的公司，其毛利率水平始终处于领先地位；第五档公司，其毛利率也始终落后于行业水平。毛利率是一个非常稳定，并带有持续趋势的指标。

2. **毛利率与涨跌幅的正相关性**：在多数行业中，涨跌幅都不存在均值回归现象。但极少数行业会在季报公布后的某些月份出现反转现象。在第一档公司中，造纸行业会在季报公布后的第一个月度出现收益反转，石油与天然气和有色金属行业会在第二个月度出现收益反转。建议对这两个行业中的这档公司保持谨慎。第五档公司中，医药与健康护理会在第二个月度出现收益反转，可以关注相应的股票。

3. **季度收益高度正相关**：对于行业内毛利率与季度涨跌幅的关系，统计检验发现：化工、建材、机械、纺织与服装、食品、医药与健康护理、信息设备、煤炭，在这8个行业中，认为毛利率是高度有效的选股指标，毛利率与收益成正相关。

4. **行业间毛利率反转**：行业间的毛利率表现出明显的反转现象，基本以两个季度为周期，毛利率表现不同的行业总会出现反转。但行业间毛利率与行业收益的关系则并不明确，这是由于行业的涨跌与更多的因素相关，仅通过毛利率单一的指标很难把握。

### 1. 研究方法与数据

我们按照海通二级行业分类标准，共27个行业，剔除掉金融行业（因毛利率指标不适用该行业），作为检验样本。计算了A股市场所有上市公司从2003年以来单季度的公司毛利率，之后剔除了st公司的数据，以及毛利率异常数据（如毛利率大于100%或小于-100%）。将股票按照海通二级行业标准分类，每年更新一次行业分类，计算出行业的平均毛利率，用公司毛利率减去行业的毛利率即得到公司的超额毛利率ir（以下仍用毛利率表示）。对于行业属性变化的公司，不考虑其当年的毛利率情况，即不计入样本集。

数据集表示为：

```
(T, stock, industry, r_T, r_T+1, r_T+2, r_T+3)
```

其中T代表当季时间，r_T代表当季毛利率，r_T+1代表下季毛利率，以此类推。

对每个行业内的股票均按照毛利率数值划为五档，得到新的数据集：

```
(T, stock, industry, rank, r_T+1, r_T+2, r_T+3, r_T+4)
```

其中1表示毛利率最高的一个级别，而5表示毛利率最低的级别。然后观察T+0时期按照此规则分类的5类行业内上市公司在接下来3个季度的毛利率表现情况。

### 2. 毛利率均值回归现象的显著性检验

进行直观的观察之后，我们得到了希望得到的结论，即行业的毛利率指标并不存在均值回归现象。我们需要检验这一结论是否能够通过统计上的显著性检验。

使用的检验方法是**平均值的成对二样本均值检验**，样本就是每个行业的第一档和第五档股票组合及行业平均毛利率。对比行业内各公司未来三期毛利率与同期行业平均毛利率的高低，如果第一档公司未来毛利率显著低于行业平均水平，或者第五档显著高于行业平均水平，就能严格判定该行业存在显著的均值回归现象。

从26个二级行业的均值检验结果来看，均值回归现象都没有通过显著性检验，且P值都极为接近或者等于1。这意味着，毛利率这一指标并不存在均值回归现象，这也正是我们所预期的结果。我们完全可以接受我们的假设条件：第一档公司的毛利率指标在未来三期依然会高于行业的平均水平，而第五档公司的毛利率在未来三期依然无法超越行业平均水平。这一结果在统计上显著成立。


其中T代表当季时间，r_T代表当季毛利率，sr_T+1代表第二期股票相对于所属行业的超额收益，以此类推。

在时间纬度上，检验月度收益率的均值回归情况，即检验毛利率对随后三个月股价的影响，实证中不考虑报表公布时间的早晚，均假定收入数据在每个季度最后一个交易日获得。

### 4. 毛利率作为行业内选股指标的实证效果

在8个有效行业中，从2003年一季报公布之后，确定第一期的投资组合。分别检验了季报即时取得（自然季度的最后一天取得）以及延迟一个月的投资效果。投资组合选择第一档以及第二档的所有公司（行业内40%的股票）作为样本股，按照流通市值加权，季度调整组合样本。

组合命名说明：
- Top_T：行业内毛利率最高的40%，季报即时取得
- Top_T+1：毛利率最高的40%，季报延迟一个月取得
- Bottom_T/Bottom_T+1：毛利率最低的40%组合
- Top10%_T/Top10%_T+1：毛利率最高的10%组合

**实证结果**：
- Top40%的组合在较长时间内都能跑赢行业指数，而Bottom40%的组合基本持续弱于行业指数
- Top10%的组合长期来看净值能够大幅超越行业水平，但是波动率相应的也比较大，收益不稳定

### 5. 行业间毛利率的关系以及与涨跌幅的关系

由于下游以及服务行业（如旅游、传媒、通讯服务、医药等）毛利率普遍较高，而传统制造业毛利率相对较低，直接划档可能因行业特性差异导致结果偏差。因此进行标准化处理：修正毛利率 = (当季毛利率 - 上一年平均毛利率) / 上一年平均毛利率，按修正毛利率划分为3档。

**统计检验结果**：

| 检验 | T+1 | T+2 | T+3 | T+4 | T+5 |
|------|-----|-----|-----|-----|-----|
| 第一档（H0:θ≥θ0）P值 | 0.998 | 0.013 | 0.016 | 0.950 | 0.697 |
| 第二档（H0:θ≤θ0）P值 | 0.990 | 0.008 | 0.002 | 0.730 | 0.418 |

T+1时刻，毛利率高的行业依然保持优势；T+2及T+3时刻，第一档行业显著弱于市场平均，第五档显著强于市场平均。行业间毛利率存在明显反转现象，基本以两个季度为周期。但行业涨跌幅与毛利率关系不明确，因行业涨跌受多因素影响。

### 6. 主要结论

本文从时间梯度上对行业内部和行业间毛利率本身以及毛利率与涨跌幅之间的关系进行了系统研究，并未发现均值回归现象，肯定了毛利率具有非常好的持续性。公司毛利率的延续性很强，好公司能够长期战胜差公司，毛利率是比较可靠的财务指标。

在**化工、建材、机械、纺织与服装、食品、医药与健康护理、信息设备、煤炭**这8个行业中，毛利率是高度有效的选股指标。

行业间的毛利率存在明显的反转现象，基本以两个季度为周期。但行业的涨跌幅，仅仅通过毛利率指标则很难把握。

## FORMULAS_AND_ALGOS

### 超额毛利率计算
```
IR = 公司毛利率 - 行业平均毛利率
```

### 修正毛利率（行业间比较）
```
修正毛利率 = (当季毛利率 - 上一年平均毛利率) / 上一年平均毛利率
```

### 五档分级法
1. 按行业内毛利率排序
2. 分为5档，每档20%
3. 第1档=最高20%，第5档=最低20%

### 成对二样本均值检验
- H0（第一档）：θ ≥ θ0（未来毛利率≥行业平均）
- H0（第五档）：θ ≤ θ0（未来毛利率≤行业平均）
- 若拒绝H0，则存在均值回归

### 选股策略构建步骤
1. 获取最新季报毛利率数据
2. 按海通二级行业分类
3. 剔除ST及异常数据（|毛利率|>100%）
4. 行业内分五档
5. 在8个有效行业中选取Top40%或Top10%
6. 流通市值加权构建组合
7. 季度调仓

### 适用条件
- 适用于：化工、建材、机械、纺织、食品、医药、信息设备、煤炭
- 不适用于：金融、非金属（关系不明确）
- 延迟一个月获取数据仍有效
- 季度调仓频率

### 失效条件
- 石油与天然气、有色金属第一档在T+2可能反转（需谨慎）
- 行业间毛利率反转不用于预测行业涨跌
- 非金属行业毛利率与收益关系不明确
- 造纸行业第一档在T+1可能反转
