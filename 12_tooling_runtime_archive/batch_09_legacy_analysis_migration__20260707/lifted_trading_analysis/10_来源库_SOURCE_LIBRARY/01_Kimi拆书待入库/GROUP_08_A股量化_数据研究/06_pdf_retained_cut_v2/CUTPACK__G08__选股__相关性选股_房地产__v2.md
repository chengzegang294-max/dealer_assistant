# CONTENT_CLUSTERS
1. **相关性选股方法论**：Pearson相关性检验筛选显著因子，排序打分构建组合；沿用商贸行业报告方法，但加入房地产特性指标。
2. **房地产行业因子池**：31个备选指标，覆盖盈利能力、偿债能力、资产运营、估值、市值、技术面，并加入预收账款/营业收入、付息负债率、每股现金流、Delta(现金流)等房地产特性指标。
3. **双时间窗口策略**：短样本（固定24个月滚动更新）vs 长样本（固定起点2003.11，逐月扩展样本长度）；反映敏感性与稳定性的博弈。
4. **指标数量敏感性分析**：发现前2年大量指标入选（20个左右）导致策略失效；对比2个最显著指标 vs 全指标，证明过多指标削弱选股能力；但在市场环境清晰后，全指标优于限指标。
5. **长期收益表现**：短样本10只终值4.2倍，20只2.3倍；长样本10只1.3倍，20只1.2倍；短样本波动大但收益高，长样本稳定但收益低。
6. **行业风格变化识别**：策略在不同时期表现强弱不一，暗示行业内风格变化；前期（07.10前）大量因子入选，后期（08年后）指标减少，策略走强。
7. **等权重与市值加权对比**：等权重下短样本10只终值更高，但长样本和20只组合等权重表现一般。
8. **最新选股结果**：10月末短样本指标（12个）和长样本指标（11个）及权重，样本股清单（短样本10只、长样本10只）。
9. **方法论普适性反思**：被动型相关性策略难以提前预知风格转变，需结合因子识别度跟踪，实现量化与主观经验融合。

## 一、研究目的与方法

本文使用相关性选股策略在房地产行业进行深入研究。该策略在前面的研究中已被证明相当有效，因而沿用这套方法和步骤。但相比于商业贸易行业，房地产业有其独特性，调整了选股指标：剔除了两个和费用相关的变量以及成交量的变化率，加入反映公司资本结构的指标（预收账款/营业收入、付息负债率、每股现金流、Delta现金流），以期更好地抓住地产行业特点。

### 1.1 指标池

备选因子共31个：

| 类别 | 指标 |
|------|------|
| 盈利能力 | ROA、ROE、EPS、毛利率、净利润率、Delta(ROA)、Delta(ROE)、Delta(毛利率)、Delta(EPS)、Delta(净利润率)、主营业务收入增长率 |
| 偿债能力 | 资产负债率、流动比率 |
| 资产运营 | 总资产周转率、每股净资产、存货周转率 |
| 估值 | PE、PB |
| 市值 | 流通市值、总市值 |
| 技术面 | 一个月收益率、三个月收益率、六个月收益率、DIFF、MACD、一个月平均换手率、三个月平均换手率、Delta(成交量) |
| 行业特性 | 预收账款/营业收入、付息负债率、每股现金流、Delta(现金流) |

### 1.2 数据处理与样本划分

- 样本外：2005年11月–2010年10月（60个月）
- 财务指标未更新月份采用最新可获得数据。
- 交易费用：单边0.5%（双边各0.5%）。
- 两种时间窗口：
  - **短样本**：固定24个月滚动窗口，每月向后滚动一个月。
  - **长样本**：固定起点2003年11月，逐月扩展样本长度（24→25→26…）。
- 在样本内每个月上，对收益率和待选指标排序，Pearson相关性检验获得显著优选指标（默认显著性水平0.1）。
- 样本外按优选指标排序打分，取平均得分前10%（10只）和20%（20只）形成投资组合。

### 1.3 换手率

短样本策略下10只和20只组合平均换手率分别为51.19%、41.19%；长样本下为42.03%、31.36%。

## 二、实证结果

### 2.1 策略长期收益表现（市值加权）

| 策略 | 样本股数 | 累计收益(%) | 年化收益率(%) | 年化波动率(%) | 夏普值 |
|------|----------|-------------|---------------|---------------|--------|
| 房地产指数 | — | 383.30 | 37.04 | 48.72 | 0.76 |
| 短样本 | 10只 | 1682.48 | 77.91 | 54.36 | 1.43 |
| 短样本 | 20只 | 1027.85 | 62.35 | 52.27 | 1.19 |
| 长样本 | 10只 | 538.59 | 44.89 | 55.25 | 0.81 |
| 长样本 | 20只 | 458.52 | 41.06 | 52.65 | 0.78 |

**结论**：
1. 从累计收益看，绝大多数时间策略跑赢指数，最终净值分别为房地产指数的4.2、2.3、1.3、1.2倍（短10/短20/长10/长20）。
2. 短样本策略累计净值更好，但波动率较大；长样本策略波动幅度小，但净值相对较低。这符合时间窗口长度对敏感性与稳定性平衡的讨论。
3. 短样本10只样本股组合表现优秀，呈稳步上升之势。

### 2.2 对相关性选股方法的进一步探讨

#### 2.2.1 前2年表现较弱的原因

前2年（至07年10月）短样本策略相对强弱在1上下波动，表现不尽如人意；后3年相当强势。长样本策略战胜基准幅度较小，相对强弱较平坦。原因分析：
- 较长的时间窗口引入冗余噪声，相关性结果反映的是前面一段历史里因子与收益率的关系，而实际操作中指标仅作为下一个月选股依据，期限错配可能造成收益损失。
- 指标过多会削弱选股效果，因为指标之间的相关性还无法度量。

#### 2.2.2 指标数量敏感性测试

考察发现前2年每期入选指标约20个（权重绝对值0.05），后3年入选指标减少至约10个（权重绝对值0.1）。为验证指标数量影响，进行极端测试：每次只用相关性最显著的2个指标选股，与全指标对比。

- **前24个月**：2个指标的组合均胜过多指标组合，对相对强弱终值改善明显。
- **后36个月**：2个指标的策略表现远不如所有指标的结果；分别选取1、3、4、5个指标也无法战胜所有指标表现。

**总结**：长样本策略由于采样方式稳定，每期入选指标较稳定，限制指标数量仍能提升业绩（主要是07年牛市贡献）。短样本策略在60个月样本期上最终累积净值优异，但不同市场环境下表现有差异。过多指标入选会降低选股能力，实际运用中应注意。

### 2.3 等权重加权对比

等权重加权下，短样本10只终值优于等权重指数，长样本和20只组合表现一般。具体数据原文未完整列出，但趋势与市值加权一致：短样本10只最佳，长样本20只最弱。

# FORMULAS_AND_ALGOS

## 1. 双窗口相关性选股核心流程（伪代码）
```
输入：行业股票池 S，因子池 F（31个），窗口模式 MODE
输出：每月优选因子 G_t，组合持仓 P_t

for 每个样本外月份 t:
    if MODE == 短样本:
        样本内 = [t-24, t-1]
    else if MODE == 长样本:
        样本内 = [起点, t-1]  // 起点固定，长度逐月+1
    
    for 每个月 m in 样本内:
        rank_R_m = 按下期收益率排序
        for f in F:
            rank_f_m = 按因子值排序
    
    for f in F:
        r_f = Pearson(rank_R, rank_f)
        p_f = 双侧检验p值
        if p_f ≤ 0.1:
            G_t.append(f)
    
    // 可选：限制指标数量
    if 限制指标数量:
        G_t = 取|r_f|最大的k个因子
    
    for s in S:
        score_s = mean( rank_f_t(s) ) for f in G_t
    
    P_t = 前5%或10%股票
    权重 = 流通市值加权（或等权重）
```

## 2. 关键公式

**年化收益率**
$$R_{annual} = \left( \frac{NAV_T}{NAV_0} \right)^{\frac{12}{T}} - 1$$

**夏普比率**
$$Sharpe = \frac{R_p - R_f}{\sigma_p}$$

**指标权重归一化**
$$w_f = \frac{1}{|G_t|} \cdot sign(r_f)$$

即每个入选因子等权重，方向由Pearson相关系数符号决定。

## 3. 房地产特性因子定义

| 因子 | 计算公式 | 数据来源 |
|------|----------|----------|
| 预收账款/营业收入 | 预收账款 / 营业收入 | 资产负债表、利润表 |
| 付息负债率 | (短期借款+长期借款+应付债券) / 总负债 | 资产负债表 |
| 每股现金流 | 经营活动现金流量净额 / 总股本 | 现金流量表 |
| Delta(现金流) | $(CF_t - CF_{t-1}) / |CF_{t-1}|$ | 同上 |
| 流动比率 | 流动资产 / 流动负债 | 资产负债表 |
| 存货周转率 | 营业成本 / 平均存货 | 利润表、资产负债表 |
