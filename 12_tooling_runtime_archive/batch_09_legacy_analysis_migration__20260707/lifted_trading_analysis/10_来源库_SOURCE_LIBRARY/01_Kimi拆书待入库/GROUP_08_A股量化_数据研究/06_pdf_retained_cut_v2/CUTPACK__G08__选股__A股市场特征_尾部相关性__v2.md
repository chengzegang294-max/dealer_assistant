## FULL_TEXT

### 摘要

个股的系统性风险，即个股与市场之间的关联性，历来都是投资研究中的热点问题。在假定线性的条件下，CAPM描述了个股期望收益与市场期望收益之间的相关性，beta系数则被用作度量个股受市场影响的程度。但随着研究与应用的不断深入，beta系数的缺点也逐渐暴露：收益率在其均值附近的聚集性使得beta系数无法有效刻画市场极端状态下，个股所受影响的大小。

尾部相关系数的提出则为度量极端市场中个股的行为提供了一个良好的观察角度。本文以沪深300最新一期的所有样本股为研究对象，通过向前滚动5日、20日的收益率，计算不同周期下的尾部相关系数，并扩展了研究覆盖范围。

核心结论：
- 以日收益率时，涨跌停制度带来的影响不可忽视。因为有时候个股的系统性风险可能远远超出了跌停板这一形式所能体现的
- 从较长的投资周期来看，当较大的系统性风险或机会来临，短期内个股的表现可能有所差异，一旦周期拉长，个股很难逃脱市场的影响
- 大部分沪深300样本股和市场之间的尾部相关系数，短期（1日或5日）内个股受市场影响的程度可能有所不同，但周期拉长至20日，同一个股的尾部相关系数便会出现显著性的大幅上涨的状态中，这一变化愈加明显

### 1. 尾部相关性和尾部相关系数

#### 1.1 尾部相关性

假定有两项资产X和Y，各自的累计分布函数为F_X(x)和F_Y(y)，则上尾相关系数的定义是：

```
λ+ = lim(u→1-) Pr{X > F_X^-1(u) | Y > F_Y^-1(u)}
```

类似地，下尾相关系数可定义为：

```
λ- = lim(u→0+) Pr{X < F_X^-1(u) | Y < F_Y^-1(u)}
```

在国内A股市场中，如果X为某一个股，Y为市场指数，两者之间较大的λ-表明市场的大幅下跌很容易引起个股X出现相似的极端状态。这对实际投资的伤害是相当巨大的，因此有必要对这类风险予以度量和管理。

#### 1.2 CAPM的尾部相关系数

假定X和Y分别表示个股和市场的收益率，传统的CAPM可写成如下形式：

```
X = α + β·Y + ε
```

如果进一步假定市场收益率Y和误差项ε服从尾部指数为α的常规变化分布，即补充分布函数分别为F_Y(y) = C_y·y^-α和F_ε(ε) = C_ε·ε^-α。那么在CAPM中，个股X和市场Y的上尾相关系数为：

```
λ+ = (C_y^α) / (C_y^α + C_ε^α / β^α)
```

其中，β系数可通过普通或加权最小二乘估计得到，尾部指数α和正则参数C由极值理论中著名的Hill估计给出。

### 2. 沪深300样本股的尾部相关系数

#### 2.1 5日收益率的尾部相关系数

以5个交易日为周期，向前滚动1个交易日的方式计算得到每个样本股的收益率序列，对应相同方式计算的沪深300指数5日收益率，获得计算尾部相关系数的基础数据。选择1500个交易日作为计算的时间跨度，通过每日向前滚动的方式估计得到个股上、下尾相关系数的时间序列。

由于计算时需保证有1500个交易日，因此300个样本股中只有215个符合条件。

**均值分布**：从平均意义上来说，下尾相关系数的取值更大一些，接近70%的个股都集中在0.5-0.8之间，而8成以上的上尾相关系数在0.1-0.5之间。相比于大幅上涨，个股和市场更倾向于同时出现较大幅度的下跌，这一发现也和日常所观察到的现象吻合。

**极差分布**：大部分个股的尾部相关系数随时间推移的变化并不剧烈，80%的极差都小于0.1。相对而言，下尾相关系数更容易发生改变，有10%的个股的极差超过0.12。上尾和下尾相关系数的极差接近或大于0.2的个股分别有2例和3例，需要及时关注。

#### 2.2 20日收益率的尾部相关系数

将计算收益率的周期扩大到20个交易日，同样以1500个交易日作为计算的固定时间长度，得到212个样本股尾部相关系数的时间序列均值。

对比5日结果，出现较大尾部相关系数的比例有显著地上升，尤其是上尾相关系数，取值超过0.5的占比接近35%。这表明，收益率计算周期越长，个股与市场同时出现大幅上涨或下跌的概率也会上升。这一现象也符合市场的一般规律：当较大的系统性风险或机会来临，短期内个股的表现可能有所差异，一旦周期拉长，个股很难逃脱市场的影响。

随着计算周期的变长，不论是上尾还是下尾，相关系数发生改变的个股数量和幅度都有很大程度的提升。

**上尾与下尾差异**：
- 5日周期：下尾相关系数均值一致地小于上尾相关系数（即下尾>上尾）
- 20日周期：53个股票的上尾相关系数均值大于下尾，即上尾>下尾的情况大大增加

这说明从短期来看，个股和市场共同出现大幅下跌的可能性高于上涨；但计算周期扩大后，上尾相关性高于下尾的情况大大增加。

### 3. 总结与讨论

收益率在不同取值处分布的疏密性使得单一指标，如beta，无法全面把握个股与市场之间的关系。它更多地是体现数据聚集部分，即市场处于一般状态时，个股如何随市场波动而变化。尾部相关系数的提出则为度量极端市场中个股的行为提供了一个良好的观察角度。在实际交易中，投资者可以结合这两个指标，选择更加符合自身风险偏好的股票。

后续研究还将涉及个股收益率的高阶性质、A股市场的流动性观察以及市场波段分解等内容，同时还将推出定期跟踪报告。

## FORMULAS_AND_ALGOS

### 上尾相关系数
```
λ+ = lim(u→1-) Pr{X > F_X^-1(u) | Y > F_Y^-1(u)}
```

### 下尾相关系数
```
λ- = lim(u→0+) Pr{X < F_X^-1(u) | Y < F_Y^-1(u)}
```

### CAPM尾部相关系数（正则变化分布假设）
```
λ+ = (C_y^α) / (C_y^α + C_ε^α / β^α)
```

其中：
- β：OLS或WLS估计的CAPM beta
- α：尾部指数（Hill估计）
- C_y, C_ε：正则参数（Hill估计）

### Hill估计（尾部指数）
```
1/α = (1/k) * Σ(i=1 to k) ln(X_(n-i+1)/X_(n-k))
```
其中X_(1)≤...≤X_(n)为次序统计量，k为极值个数。

### 计算步骤
1. 计算5日/20日滚动收益率序列（个股+市场）
2. 选择1500个交易日作为固定窗口
3. 每日向前滚动1日，更新收益率序列
4. 对收益率序列进行排序，提取极值
5. 用Hill估计计算尾部指数α和正则参数C
6. 估计CAPM beta
7. 代入公式计算尾部相关系数
8. 记录时间序列，计算均值和极差

### 适用条件
- 需要至少1500个交易日的历史数据
- 使用5日或20日收益率规避涨跌停影响
- 适用于沪深300成分股等大盘股
- 结合beta系数使用，互补分析

### 失效条件
- 个股数量不足（300样本中仅215个满足5日条件）
- 计算周期过短（日数据受涨跌停限制）
- 市场环境剧烈变化时，尾部指数估计不稳定
- 小盘股流动性不足，系统性风险度量偏差
- 2012年后部分个股尾部相关系数出现结构性跃升（如平庄能源、招商地产）
