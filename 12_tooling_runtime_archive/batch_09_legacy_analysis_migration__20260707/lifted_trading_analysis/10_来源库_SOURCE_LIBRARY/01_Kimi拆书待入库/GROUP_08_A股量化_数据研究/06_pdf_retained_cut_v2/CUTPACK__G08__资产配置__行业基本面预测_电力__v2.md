## CONTENT_CLUSTERS

1. **研究框架与目标**：通过分析电力行业面临的宏观经济因素、行业在国民经济中的地位、行业供需关系以及行业周期等特征，构建行业基本面走势预测模型，对电力行业主要经济指标做出预测。
2. **电力行业市场地位**：电力行业是国民经济发展中最重要的基础能源产业，关系国计民生。第二产业GDP占比自1990年至今一直超过40%，近年来第二产业耗电量超过三大产业总耗电量的70%。
3. **行业与股票基本面相关性**：电力行业与电力上市公司基本面走势（收入、成本、利润）高度相关，为行业股票市场中长线投资提供依据。上市公司总市值占全部A股市值比重由2004年的8.49%逐年下降至2011年的1.95%。
4. **宏观经济指标先行因子**：CPI、PPI、M1增速-M2增速、金融机构各项贷款、城镇固定资产投资完成额。
5. **需求端先行因子**：工业用电需求（占全社会用电70%以上，黑色金属冶炼、有色金属冶炼、非金属矿物制品、化学原料是四大耗电工业）、居民用电需求（家用电器及音响设备器材零售价格指数）。
6. **供给端先行因子**：直供电厂库存、煤炭产量、煤炭价格。
7. **发电量先行指标**：原煤价格指数（负向领先3个月）、直供电厂库存（负向领先1个月）、煤炭开采投资（负向领先11个月）、钢材产量（正向领先6个月）、商品房销售面积（正向领先6个月）、金融机构贷款余额（正向领先5个月）、PMI（正向领先4个月）、工业增加值（正向领先1个月）、M1/M2增速（正向领先10个月）、汽车销量增速（正向领先9个月）。
8. **发电成本先行指标**：M1/M2增速（正向领先4个月）、原煤价格指数（正向领先1个月）、汽车销量（正向领先12个月）、金融机构贷款余额（正向领先12个月）、十种有色金属产量（正向领先10个月）、黑色金属冶炼投资（正向领先7个月）、有色金属冶炼投资（正向领先10个月）、非金属矿物制品投资（正向领先10个月）、CPI（正向领先2个月）、PPI电力工业（负向领先7个月）。
9. **发电价差与毛利率先行指标**：因国内电力价格主要由国家政策调控，煤价及工业生产等对电力生产成本的影响大大超过对电力单价的影响，因此电力行业的毛利以及毛利率的主要决定因素为发电成本。价差先行指标对成本的影响方向基本相反。
10. **预测效果与提高领先期**：模型预测效果良好，特别在总体趋势预测上较为准确，且预测模型结果总体上略提前于实际指标先出现拐点。提高领先期后预测出现一些滞后性，但预测趋势较为稳定。

## FULL_TEXT

### 1. 研究对象—行业利润表数据预测

利润表主要提供有关企业经营成果方面的信息，是反映企业或行业在一定会计期间经营成果的报表；便于报表使用者判断行业未来的发展趋势，做出经济决策。行业经济效益指标中的营业收入、营业成本以及利润总额等是影响行业基本面走势的核心指标；基本面中的市盈率、利润增长率、毛利率等都可以通过上述指标推导得出，这些基本面信息也是体现行业景气情况的主要指标，最终成为推动行业内股票涨跌的原动力。

通过对宏观经济运行态势、行业在国民经济中的地位、供需关系以及行业周期特点的分析，制作行业主要经济效益指标走势预测模型，进而对整个行业的基本面态势做出预测。

### 2. 本文研究对象-电力行业

#### 2.1 电力行业的市场地位

电力行业是国民经济发展中最重要的基础能源产业，也是关系国计民生的基础产业。电力行业是我国第二产业的重要组成部分，第二产业的GDP占比自1990年至今一直超过40%，居三大产业产值之首。而近年来，第二产业的耗电量也超过三大产业总耗电量的70%。

电力行业基本面的研究及预测对国民经济的走势和发展有着重要的指导意义，也为行业配置提供了重要的投资参考依据。本文通过数量化模型对电力行业总体的营业收入、营业成本、发电量、毛利率等进行预测，从不同角度刻画行业基本面。

#### 2.2 电力行业与电力股票基本面有较强相关性

本文主要研究电力行业的基本面信息（营业收入、营业成本、发电量、毛利率等）。比较了电力行业与电力上市公司的基本面走势，发现两者有较强的相关性。由于行业股票走势在中长期来说必然趋向其内在价值，也就是基本面所反映出来的信息，所以该研究可以为电力行业股票市场的中长线投资提供依据。

### 3. 本文主要研究方法

#### 3.1 自变量简介

影响行业基本面的外因是宏观经济指标波动、经济周期、上下游产业链的供应需求变动，内因是行业的产品需求变动、生产能力变动、技术水平变化及产业政策的变化等。

**宏观经济指标**：CPI、PPI、M1增速-M2增速、金融机构各项贷款、城镇固定资产投资完成额。

**需求**：
- 工业用电需求：工业用电占全社会用电的70%以上，其中第二产业用电量在整个工业用电量中占比最大（超过70%）；而黑色金属冶炼及压延加工业、有色金属冶炼及压延加工业、非金属矿物制品业及化学原料及化学制品制造业是生产上耗电最多的四大工业。选取相应的固定资产投资完成额以及产量指标作为工业用电需求因子。
- 居民用电需求：居民生活用电占全社会用电的比重较小（低于30%），主要选取家用电器及音响设备器材零售价格指数作为影响居民用电需求的因子。

**供给**：电力行业的供给也受上游煤炭产业的牵制。选取影响电力供给的指标为：直供电厂库存、煤炭产量、煤炭价格。

**其他先行指标**：汽车和房地产属于可选消费品，在宏观经济中一般先行于其他行业。汽车和房地产的发展也可以拉动其他耗电产业（包括化工、有色金属、非金属等），进而拉动电力行业的发展。但后续跟踪研究结果显示其对电力行业直接影响作用有限。

### 5. 提高领先期数后的结果分析

将发电量、成本、价差、毛利率的预测分别从提前一期向前推移至提前两期、三期以及六期等。外推多期后，预测结果出现一些滞后性，且变化的幅度较原模型预测结果明显减小，但预测趋势较为稳定。总体来说，提高领先期数的外推预测效果良好，可以在一定程度上为投资分析提供一些辅助依据。

### 6. 结论

本文通过分析电力行业面临的宏观经济因素、行业在国民经济中的地位、行业供需关系以及行业周期等特征，构建行业基本面走势预测模型，对电力行业的主要经济指标做出预测，为电力行业的分析提供量化结论。

从宏观经济、行业需求、行业供给等角度选取若干影响行业基本面走势的主要先行因子，运用相关性分析筛选主要影响因子并确定各个因子的领先期。对主要电力行业财务指标的影响因子做主成分分析，提取相应财务指标的主要模拟走势；并运用回归分析，对第一主成分和财务指标做样本内回归分析，调整主成分量纲，最后外推至样本外与真实值进行比较分析。

模型预测效果良好，特别在总体趋势预测上较为准确。主要分析预测的财务指标包括：发电量、单位成本、毛利、毛利率以及利润总额。各个预测结果的变化趋势都与目标值的变化趋势较为相符，且预测模型结果总体上略提前于实际指标先出现拐点。

提高模型领先期数后，预测效果良好。外推多期后，预测结果出现一些滞后性，但预测趋势较为稳定。总体来说，提高领先期数的外推预测可以在一定程度上为投资分析提供一些辅助依据。

## FORMULAS_AND_ALGOS

### 三步骤预测模型（同工程机械/煤炭）

```
步骤1: 相关性分析筛选先行指标
  For each candidate indicator X and target Y:
    Find lag l that maximizes Corr(X(t-l), Y(t))
    Keep indicators with |Corr| > threshold and stable sign

步骤2: 主成分分析（PCA）
  Z = W' * X
  where X = standardized先行指标矩阵
  W = 特征向量矩阵（取前k=2-3个主成分）

步骤3: 多元线性回归
  Y = beta0 + beta1*Z1 + beta2*Z2 + ... + epsilon
  用样本内数据估计beta，样本外预测Y_hat
```

### 适用条件
- 行业周期波动具有历史规律性和可重复性
- 先行指标与行业变量存在稳定的领先关系
- 电力价格受政策调控但成本端市场化
- 宏观经济未发生结构性突变

### 失效条件
- 电价政策剧烈调整（如煤电联动机制变更）
- 极端天气（如干旱导致水电出力骤降）
- 煤炭供应极端波动（如矿难、进口禁令）
- 电力体制改革（如竞价上网、输配电价改革）
- 新能源替代加速（光伏/风电占比急剧提升）

## NOT_QUANT_YET

1. **电价政策的量化纳入**：电力价格受国家政策调控，电价调整公告缺乏量化指标，无法自动纳入预测模型。
2. **新能源替代效应**：未纳入光伏、风电、核电等新能源发电量及占比变化，对火电需求长期趋势影响显著。
3. **极端天气因子**：未纳入气温、降水、干旱、寒潮等极端天气因子，对发电量和用电需求影响大。
4. **电力市场化改革**：报告发表于2010年前，未考虑2015年后电力体制改革对行业盈利模式的改变。
5. **区域电力市场差异**：未区分火电/水电/核电区域差异，不同区域电价和成本差异大。
6. **容量电价机制**：未考虑容量电价、辅助服务市场等新机制对电力企业利润的影响。
7. **高频负荷数据**：未引入电网日负荷曲线、最大负荷、负荷率等高频数据。
8. **行业通用框架迁移**：报告为电力行业定制，未建立可迁移到其他公用事业（燃气、水务）的通用框架。
9. **碳交易影响**：未考虑碳排放权交易对火电企业成本的影响。
10. **储能影响**：未考虑储能发展对电力供需平衡和电价波动的影响。
