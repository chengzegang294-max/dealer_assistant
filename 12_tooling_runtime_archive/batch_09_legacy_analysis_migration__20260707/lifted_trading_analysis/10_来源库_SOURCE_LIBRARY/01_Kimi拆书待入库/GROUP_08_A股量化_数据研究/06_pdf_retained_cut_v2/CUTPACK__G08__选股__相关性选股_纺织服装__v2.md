# CONTENT_CLUSTERS
1. **相关性选股方法论**：Pearson相关性检验筛选显著性水平0.05的优选指标，排序打分构建组合；沿用有色金属行业指标池和选股模型。
2. **纺织服装行业因子池**：25个备选指标，与有色金属完全一致，覆盖盈利能力、偿债能力、资产运营、估值、市值、技术面。
3. **显著性水平微调**：使用与有色金属相同的指标池，显著性水平取0.05（介于地产0.1和有色0.005之间），保证模型有效性。
4. **短样本策略**：固定24个月滚动窗口；8只和15只股票组合（行业股票总数79只）。
5. **长期收益表现**：8只市值加权终值2.96倍，15只1.97倍；等权重8只1.83倍，15只1.39倍；8只组合表现更好，策略单调性明显。
6. **风险调整后收益**：从夏普值看，8只组合最高；15只组合年化波动率较低，但信息比反而更高（超额收益标准差更小）。
7. **最新选股结果**：12月末短样本指标（12个）及权重，样本股清单（8只）。
8. **因子权重历史表**：附表1列出短样本策略Dec-05至Dec-10所有样本期上各指标权重。
9. **长样本暂停**：由于长样本组合的收益及风险指标未达预期，与短样本相比无明显优势，暂停公布长样本组合。

> 研究时段：2003年12月–2010年12月；样本外起点：2005年12月；采样频率：月度

## 一、研究目的与方法

相关性选股通过对因子和股票超额收益历史相关性的度量，筛选出具有显著相关性的选股因子，以此为基础在行业中进行选股。此前通过全市场、商贸、地产、有色行业的实证，该选股策略都获得了较好的超额收益。本文选定纺织服装行业进行实证，构造出纺织服装行业的相关选股模型，方法上沿用有色中的选股模型，只对显著性水平进行了微调，最终得到明显的超额收益。

另外，考虑到长样本组合的收益及风险指标并未达到预先设想，与短样本组合相比也未体现出明显的优势和特点，因此暂停公布长样本组合。

### 1.1 指标池

备选因子共25个，与有色金属行业完全一致：

| 类别 | 指标 |
|------|------|
| 盈利能力 | ROA、ROE、EPS、毛利率、净利润率、Delta(ROA)、Delta(ROE)、Delta(毛利率)、Delta(EPS)、Delta(净利润率)、主营业务收入增长率 |
| 偿债能力 | 资产负债率 |
| 资产运营 | 总资产周转率、每股净资产 |
| 估值 | PE、PB |
| 市值 | 流通市值、总市值 |
| 技术面 | 一个月收益率、三个月收益率、六个月收益率、DIFF、MACD、一个月平均换手率、三个月平均换手率 |

### 1.2 数据处理与样本划分

- 样本外：2005年12月–2010年12月（61个月）
- 财务指标未更新月份采用最新可获得数据。
- 交易费用：双边各0.5%。
- 固定样本内数据长度24个月，滚动更新。
- 显著性水平：0.05。
- 分别选取8只（前10%）和15只（前20%）构建投资组合。

### 1.3 换手率

两种股票组合的平均换手率分别为56.88%（8只）和43.78%（15只）。

## 二、实证结果

### 2.1 策略长期收益表现（市值加权）

| 策略 | 样本股数 | 累计收益(%) | 年化收益率(%) | 年化波动率(%) | 夏普值 | 信息比 |
|------|----------|-------------|---------------|---------------|--------|--------|
| 纺织服装指数 | — | 331.0 | 33.30 | 48.70 | 0.68 | — |
| 短样本 | 8只 | 1175.15 | 65.00 | 54.38 | 1.20 | 1.39 |
| 短样本 | 15只 | 850.16 | 52.35 | 50.10 | 1.05 | 1.49 |

**结论**：
1. 从累计收益看，绝大多数时间策略跑赢指数，最终净值分别为纺织服装指数的2.96（8只）和1.97（15只）倍。
2. 8只股票的组合优于15只，符合理论预期（前10%优于前20%），证明策略可靠。
3. 从年化收益率看，策略均战胜指数，8只组合超越幅度很大，体现策略优越性。
4. 从夏普值看，8只组合最高；从波动率看，15只组合年化波动率较低（50.10% vs 54.38%），但信息比反而更高（1.49 vs 1.39），原因在于15只组合超额收益的标准差更小。

### 2.2 等权重加权对比

和市值加权相比，等权重加权的超额收益略有下降：
- 8只组合累积净值降为行业指数的1.83倍。
- 15只组合降为1.39倍。
- 年化收益率、夏普值和信息比均有不同程度降低，但和等权重指数相比，策略表现仍有较大优势。

# FORMULAS_AND_ALGOS

## 1. 相关性选股核心流程（伪代码）
```
输入：行业股票池 S，因子池 F（25个），窗口长度 L=24个月，显著性水平 α=0.05
输出：每月优选因子 G_t，组合持仓 P_t

for 每个样本外月份 t:
    样本内数据 = [t-L, t-1]
    for 每个月 m in 样本内:
        rank_R_m = 按下期收益率排序
        for f in F:
            rank_f_m = 按因子值排序
    for f in F:
        r_f = Pearson(rank_R, rank_f)
        p_f = 双侧检验p值
        if p_f ≤ α:
            G_t.append(f)
    for s in S:
        score_s = mean( rank_f_t(s) ) for f in G_t
    P_t(8只) = 前10%股票
    P_t(15只) = 前20%股票
    权重 = 流通市值加权（或等权重）
```

## 2. 关键公式

**Pearson相关系数**
$$r_{XY} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$$

**年化收益率**
$$R_{annual} = \left( \frac{NAV_T}{NAV_0} \right)^{\frac{12}{T}} - 1$$

**夏普比率**
$$Sharpe = \frac{R_p - R_f}{\sigma_p}$$

**信息比率**
$$IR = \frac{\alpha_p}{TE_p}$$

## 3. 因子定义

| 因子 | 计算公式 | 数据来源 |
|------|----------|----------|
| Delta(ROA) | $(ROA_t - ROA_{t-1}) / |ROA_{t-1}|$ | 财报 |
| Delta(ROE) | 同上 | 财报 |
| Delta(EPS) | 同上 | 财报 |
| PB | 总市值 / 净资产 | 行情+财报 |
| 总市值 | 总股本 × 收盘价 | 行情 |
| 流通市值 | 流通股本 × 收盘价 | 行情 |
