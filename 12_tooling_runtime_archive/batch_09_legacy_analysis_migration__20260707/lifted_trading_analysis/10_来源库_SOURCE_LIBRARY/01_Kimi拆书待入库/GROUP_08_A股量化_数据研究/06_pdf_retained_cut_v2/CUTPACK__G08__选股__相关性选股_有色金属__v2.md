# CONTENT_CLUSTERS
1. **相关性选股方法论**：Pearson相关性检验度量因子与超额收益的历史相关性，筛选显著性水平0.005的优选指标，排序打分构建组合。
2. **有色金属行业因子池**：25个备选指标（去掉商贸行业的费用指标），覆盖盈利能力、偿债能力、资产运营、估值、市值、技术面。
3. **严格显著性水平**：将显著性水平从0.1降至0.005，避免大量指标通过检验导致全指标选股，已在地产报告中得到验证。
4. **双时间窗口策略**：短样本（24月滚动）和长样本（固定起点扩展）；8只和15只股票组合（行业股票总数不多）。
5. **长期收益表现**：短样本8只终值2.7倍，15只2.2倍；长样本8只1.4倍，15只1.6倍；短样本-8只表现最佳，组合单调性良好。

7. **最新选股结果**：11月末短样本指标（7个）和长样本指标（16个）及权重，样本股清单（短样本8只、长样本8只）。
8. **因子权重历史表**：附表1列出短样本策略Dec-05至Nov-10所有样本期上各指标权重。
9. **策略普适性验证**：8只组合全面强于15只，与理论预期（前10%股票优于前20%）吻合，证明策略可靠。

> 研究时段：2003年12月–2010年11月；样本外起点：2005年12月；采样频率：月度

## 一、研究目的与方法

通过对因子和股票超额收益历史相关性的度量，筛选出具有显著相关性的选股因子，以此为基础在行业中进行选股。此前通过全市场、商贸和地产行业的实证，该选股策略都获得了较好的超额收益。本文选定有色金属行业进行实证，沿用商贸和地产中的选股模型，但选股指标略有改动，最终得到明显的超额收益。

### 1.1 指标池

备选因子共25个（去掉商贸行业的两个费用指标）：

| 类别 | 指标 |
|------|------|
| 盈利能力 | ROA、ROE、EPS、毛利率、净利润率、Delta(ROA)、Delta(ROE)、Delta(毛利率)、Delta(EPS)、Delta(净利润率)、主营业务收入增长率 |
| 偿债能力 | 资产负债率 |
| 资产运营 | 总资产周转率、每股净资产 |
| 估值 | PE、PB |
| 市值 | 流通市值、总市值 |
| 技术面 | 一个月收益率、三个月收益率、六个月收益率、DIFF、MACD、一个月平均换手率、三个月平均换手率 |

### 1.2 数据处理与样本划分

- 样本外：2005年12月–2010年11月（60个月）
- 财务指标未更新月份采用最新可获得数据。
- 交易费用：双边各0.5%。
- 两种时间窗口：
  - **短样本**：固定24个月滚动窗口。
  - **长样本**：固定起点2003年12月，逐月扩展。
- 显著性水平：0.005（更严格）。
- 由于行业内股票总数不多，分别选取8只（前10%）和15只（前20%）构建投资组合。

### 1.3 换手率

短样本策略下8只和15只组合平均换手率分别为40.25%、27.12%；长样本下为28.81%、22.82%。

## 二、实证结果

### 2.1 策略长期收益表现（市值加权）

| 策略 | 样本股数 | 累计收益(%) | 年化收益率(%) | 年化波动率(%) | 夏普值 | 信息比 |
|------|----------|-------------|---------------|---------------|--------|--------|
| 有色金属指数 | — | 556.19 | 45.68 | 59.62 | 0.77 | — |
| 短样本 | 8只 | 1663.14 | 77.52 | 61.77 | 1.25 | 1.70 |
| 短样本 | 15只 | 834.20 | 56.35 | 59.59 | 0.95 | 0.96 |
| 长样本 | 8只 | 1349.83 | 70.71 | 60.99 | 1.16 | 1.03 |
| 长样本 | 15只 | 960.93 | 60.38 | 60.27 | 1.00 | 0.95 |

**结论**：
1. 从累计收益看，绝大多数时间策略跑赢指数，最终净值分别为有色金属指数的2.7、2.2、1.4、1.6倍（短8/短15/长8/长15）。
2. 8只股票的组合全面强于15只，符合理论预期（前10%股票优于前20%），证明策略可靠。
3. 短样本-8只样本股的组合表现最好，呈逐步上升之势。
4. 从年化收益率和夏普值看，策略均战胜指数，短样本8只最佳。

### 2.2 等权重加权对比

和市值加权相比，等权重加权表现略有下降，但8只组合仍能较好地战胜指数，证明相关性选股在有色行业有效。

# FORMULAS_AND_ALGOS

## 1. 严格显著性水平相关性选股流程（伪代码）
```
输入：行业股票池 S，因子池 F（25个），窗口长度 L=24个月，显著性水平 α=0.005
输出：每月优选因子 G_t，组合持仓 P_t

for 每个样本外月份 t:
    样本内数据 = [t-L, t-1]
    for 每个月 m in 样本内:
        rank_R_m = 按下期收益率排序
        for f in F:
            rank_f_m = 按因子值排序
    for f in F:
        r_f = Pearson(rank_R, rank_f)
        p_f = 双侧检验p值
        if p_f ≤ α:
            G_t.append(f)
    for s in S:
        score_s = mean( rank_f_t(s) ) for f in G_t
    P_t(8只) = 前10%股票
    P_t(15只) = 前20%股票
    权重 = 流通市值加权（或等权重）
```

## 2. 关键公式

**Pearson相关系数**
$$r_{XY} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$$

**年化收益率**
$$R_{annual} = \left( \frac{NAV_T}{NAV_0} \right)^{\frac{12}{T}} - 1$$

**夏普比率**
$$Sharpe = \frac{R_p - R_f}{\sigma_p}$$

**信息比率**
$$IR = \frac{\alpha_p}{TE_p}$$
