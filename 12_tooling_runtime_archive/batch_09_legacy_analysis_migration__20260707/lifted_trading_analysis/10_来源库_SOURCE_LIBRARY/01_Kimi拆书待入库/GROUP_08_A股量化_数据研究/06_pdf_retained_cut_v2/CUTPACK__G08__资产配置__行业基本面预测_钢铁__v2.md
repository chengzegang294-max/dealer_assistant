## FULL_TEXT

### 1. 研究对象—行业利润表数据预测

利润表主要提供有关企业经营成果方面的信息，是反映企业或行业在一定会计期间经营成果的报表；便于报表使用者判断行业未来的发展趋势，做出经济决策。行业经济效益指标中的营业收入、营业成本以及利润总额等是影响行业基本面走势的核心指标；基本面中的市盈率、利润增长率、毛利率等都可以通过上述指标推导得出，这些基本面信息也是体现行业景气情况的主要指标，最终成为推动行业内股票涨跌的原动力。

通过对宏观经济运行态势、行业在国民经济中的地位、供需关系以及行业周期特点的分析，制作行业主要经济效益指标走势预测模型，进而对整个行业的基本面态势做出预测。

### 2. 本文研究对象-钢铁行业

#### 2.1 钢铁行业的市场地位

钢铁是国民经济的中流砥柱，是国家的命脉，是国家生存和发展的物质保障。随着国际产业的转移和我国国民经济的快速发展，我国钢铁工业取得了巨大成就。我国钢铁工业不仅为我国国民经济的快速发展做出了重大贡献，也为世界经济的繁荣和世界钢铁工业的发展起到积极的促进作用。

钢铁行业基本面的研究及预测对国民经济的走势和发展有着重要的指导意义，也为行业配置提供了重要的投资参考依据。本文通过数量化模型对钢铁行业总体的营业收入、营业成本、产量、毛利率等进行预测，从不同角度刻画行业基本面。

上市公司中钢铁相关股票总市值占全部A股市值比重由2005年的高位7.1%逐年下降至2011年的2.2%，下图反映出钢铁行业在二级市场受到资金的关注程度从2005年以来逐年下降，2011年延续了低迷的市场表现。虽然钢铁行业的市场总市值占比逐年减小，但其流通市值自2008年以来持续迅速的扩大，一直以来都是机构投资者关注的焦点之一。

#### 2.2 钢铁行业与钢铁股票基本面有较强相关性

本文主要研究钢铁行业的基本面信息（营业收入、营业成本、产量、毛利等）。比较了钢铁行业与钢铁上市公司的基本面走势，发现两者有较强的相关性。由于行业股票走势在中长期来说必然趋向其内在价值，也就是基本面所反映出来的信息，所以该研究可以为钢铁行业股票市场的中长线投资提供依据。

### 3. 本文主要研究方法

#### 3.1 自变量简介

影响行业基本面的外因是宏观经济指标波动、经济周期、上下游产业链的供应需求变动，内因是行业的产品需求变动、生产能力变动、技术水平变化及产业政策的变化等。

**宏观经济指标**：CPI、PPI、M1增速-M2增速、金融机构各项贷款、城镇固定资产投资完成额。

**需求**：钢铁行业的主要下游产业包括建筑用钢、机械、船舶、汽车等。经过筛选，选取了房屋施工面积、商品房销售面积、民用钢制船舶产量、工业锅炉产量作为主要的用钢需求因子。

**供给**：钢铁行业的供给也受上游铁矿石产业的牵制，同时炼钢需要大量的煤炭作为燃料。选取影响钢铁行业上游供给的指标为：粗钢库存、铁矿石产量、铁矿石价格、焦炭产量、焦炭出口价格等。

#### 3.3 主成分分析确定变量权重，回归分析调整量纲

同其他行业方法：主成分分析提取2-3个主成分（已包含90%以上的信息），多元线性回归调整量纲到与因变量一致，求得回归模型估计方程。

### 4. 研究预测效果分析

#### 4.1 钢铁产量预测效果分析

数据：选取了2005年12月至2008年3月的数据作为样本内数据，2008年4月至2011年9月作为样本外数据。2011年10月的产量增速预测数据即为外推一个月的预测数据值。

效果分析：总体来说钢铁增速预测模型在方向预测上效果良好，但是涨跌幅度在2008年6月至今明显低于实际产量增速的涨跌幅度。该模型的预测效果略领先于实际产量增速的变化，2008年11月的样本外产量增速出现了低点，预测数据也在11月出现低点。2009年11月的样本外产量增速出现峰值，预测数据也在11月出现峰值，基本同步于实际增速出现拐点。模型在今年12月时出现了上行拐点，提前于真实的产量增速拐点1期。总体来说模型在大趋势上的预测比较准确，略领先实际产量增速。

#### 4.2 单位成本预测效果分析

数据：选取了2005年2月至2007年10月的数据作为样本内数据，2007年11月至2011年8月作为样本外数据。

效果分析：总体来说单位成本增速预测模型预测效果良好，在预测幅度上也与原成本增速的变化幅度基本一致，当然有些较小的波动，模型未能完全拟合。该模型的预测效果基本同步于单位成本增速的变化。前3次的波谷和波峰分别出现在2005年12月、2008年8月以及2009年8月，模型都能较好的指示出来。

#### 4.3 单位价格预测效果分析

数据：同成本预测。

效果分析：钢铁单价的走势与成本的走势基本一致，单价预测模型也可以较好的模拟钢铁单价的走势，效果与成本预测类似。该模型较准确的指出了2005年12月、2008年8月以及2009年8月的拐点。

#### 4.4 毛利增速预测效果分析

数据：同成本预测。

效果分析：总体来说毛利增速预测模型能模拟出大体的走势，但是存在一定程度的偏差，并且模拟的毛利增速走势变化幅度明显小于真实毛利增速变化幅度。

**偏差数据分析**：
- 第一个明显偏差出现在2007年2月至6月，实际毛利增速有较大幅度的下跌，而模型只有微小幅度的下跌。经过具体分析后发现，几乎所有的自变量因子都指示出该阶段毛利增速的下跌，但是指示下跌幅度比较弱，远小于真实毛利增速的变化幅度。
- 第二个明显偏差出现在08年5月至8月，实际的毛利增速有较大幅度的上升，模型该阶段的结果有小幅的下降。该阶段毛利增速预测值的下跌主要是由于对应期数M1增速/M2增速和CPI较大幅度的下跌导致的。
- 第三个明显预测偏差出现在2010年8月至10月，实际毛利增速与8月反弹上行，模型预测增速震荡下跌。该阶段预测增速的下跌主要是由于对应期数CPI和PPI有较大幅度的下跌所致。

#### 4.5 毛利率预测效果分析

数据：同成本预测。

效果分析：总体来说毛利率预测模型能模拟出大体的走势，但是存在一定程度的偏差和滞后，并且模拟的毛利率走势变化幅度明显小于真实毛利增速变化幅度。

#### 4.6 利润及利润同比增速预测效果分析

数据：产量增速预测值、毛利增速预测值。

主营业务利润 = 营业收入 - 营业成本 - 营业税。假定营业税变化较小，暂不做考虑。

利润同比增速 = (1 + 产量同比增速) × (1 + 毛利同比增速) - 1

### 5. 提高领先期数后的结果分析

将钢铁产量、成本、单价、毛利的预测分别从提前一期向前推移至提前两期、三期以及六期等。这些预测结果，由于预测的期数增加，为整体基本面的走势提供参考信息。

效果分析：外推多期后，总体来说预测结果的变化幅度较之前有所减小，但走势基本不变。产量增速预测曲线、毛利增速预测曲线在领先期数改变后，各个预测曲线的拐点和走势都基本没发生变化；而领先期数提高了，能够预测的期数增多，得到的未来因变量走势趋势的信息增多。单位成本增速预测曲线、单位价格预测曲线在提高领先期后，预测结果出现了滞后性，但是滞后的期数小于外推预测期数，该结果在一定程度上也能提供更多的因变量未来走势信息。总体来说，提高领先期数的外推预测效果良好，可以在一定程度上为分析提供一些辅助依据。

### 6. 结论

本文以主成分分析模型为基础，利用景气分析方法对我国钢铁行业的周期波动进行了研究，构建了钢铁行业的基本面信息，刻画了近年来我国钢铁行业的波动特点。首先分析了宏观经济发展对钢铁行业的影响；行业在国民经济中的地位，供需关系以及行业周期特点，选取若干影响行业基本面走势的主要先行因子，制作行业基本面走势预测模型，对整个行业的主要经济指标做出预测，为钢铁行业的发展提供基础分析依据。

运用相关性分析筛选主要影响因子并确定各个因子的领先期，对主要钢铁行业财务指标的影响因子做主成分分析，提取相应财务指标的主要模拟走势；并运用回归分析调整主成分量纲，最后外推至样本外与真实值进行比较分析。

模型预测效果良好，特别在总体趋势预测上较为准确。主要分析预测的财务指标包括：产量、单位成本、单价、毛利增速以及利润增速。各个预测结果的变化趋势都与目标值的变化趋势较为相符，且预测模型结果总体上略提前于实际指标先出现拐点。

提高模型领先期数后，预测效果良好。外推多期后，预测结果出现一些滞后性，且变化的幅度较原模型预测结果减小，但预测趋势较为稳定。总体来说，提高领先期数的外推预测可以在一定程度上为投资分析提供中期参考价值。

最新预测结果显示：钢铁行业中期基本面四季度不宜过度悲观，钢材产量增速四季度低位徘徊，受到年初固定资产投资增速回升周期影响，可能在年末有小幅上行，但明年三月后可能继续回到下行之中。

## FORMULAS_AND_ALGOS

### 三步骤预测模型（同工程机械/煤炭/电力）

```
步骤1: 相关性分析筛选先行指标
  For each candidate indicator X and target Y:
    Find lag l that maximizes Corr(X(t-l), Y(t))
    Keep indicators with |Corr| > threshold and stable sign

步骤2: 主成分分析（PCA）
  Z = W' * X
  where X = standardized先行指标矩阵
  W = 特征向量矩阵（取前k=2-3个主成分）

步骤3: 多元线性回归
  Y = beta0 + beta1*Z1 + beta2*Z2 + ... + epsilon
  用样本内数据估计beta，样本外预测Y_hat
```

### 利润同比增速公式

```
利润同比增速 = (1 + 产量同比增速) × (1 + 毛利同比增速) - 1
```

### 预测偏差分解

```
预测偏差 = Y_actual - Y_predicted
         = sum( weight_i * (X_actual_i - X_expected_i) * lag_effect_i )
通过标准化后的指标变动×权重，可分解各指标对偏差的贡献
```

### 适用条件
- 行业周期波动具有历史规律性和可重复性
- 先行指标与行业变量存在稳定的领先关系
- 宏观经济未发生结构性突变
- 行业内未出现颠覆性政策或供应端冲击
- 钢铁市场化定价机制相对稳定

### 失效条件
- 政策剧烈调控（如供给侧改革、环保限产）
- 国际大宗商品价格极端波动（如铁矿石、焦炭价格暴涨）
- 钢铁行业产能严重过剩或极端短缺
- 下游需求结构性变化（如房地产断崖式下跌）
- 行业统计口径变更

1. **政策事件的量化纳入**：供给侧改革、环保限产、关税调整等政策事件缺乏量化指标，无法自动纳入预测模型。
2. **国际大宗商品价格实时接入**：铁矿石、焦炭、废钢等国际大宗商品价格未自动接入和更新，国际地缘政治影响大。
3. **高频数据融合**：仅使用月度数据，未引入日频的螺纹钢期货价格、热卷期货价格、铁矿石期货价格等高频数据。
4. **库存与港口数据**：未纳入螺纹钢社会库存、钢厂库存、铁矿石港口库存等供需平衡指标。
5. **钢材品种差异**：未区分螺纹钢、热卷、冷轧、中厚板等不同品种的差异，不同品种下游需求和价格走势不同。
6. **行业通用框架迁移**：报告为钢铁行业定制，未建立可自动迁移到其他周期性行业（如水泥、玻璃）的通用框架。
7. **机器学习对比**：未尝试XGBoost、LSTM等机器学习方法对非线性关系的捕捉。
8. **期货与现货价差**：未纳入螺纹钢期货价格、基差、期限结构等金融市场信息。
9. **电弧炉产能影响**：未考虑电弧炉产能占比提升对废钢需求和钢铁产量的影响。
10. **碳中和政策冲击**：报告发表于2011年，未考虑2020年后碳达峰碳中和政策对钢铁行业的长期结构性影响。
