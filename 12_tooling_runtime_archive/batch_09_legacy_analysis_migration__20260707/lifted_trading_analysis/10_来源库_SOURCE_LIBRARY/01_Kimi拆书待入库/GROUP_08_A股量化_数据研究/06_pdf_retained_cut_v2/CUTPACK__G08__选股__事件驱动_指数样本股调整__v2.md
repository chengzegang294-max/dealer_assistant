## FULL_TEXT

### 摘要

本篇报告对指数样本股调整这一事件型机会进行剖析，发掘在该类事件中是否存在交易机会可以进行操作。核心结论：

1. 市场上所有指数基金进行样本股调整时，大多数股票的流动性非常充分，基金调仓所需交易量能够快速被市场消化，交易基本能够在1日内完成。
2. 少数股票历史成交量相对较小，估算需要多个交易日基金才能够完成调仓。如果估算调仓用时不会过长，该类股票后期的成交量不会发生过大变化；如果估算交易耗时过久，股票后期有较大概率出现放量情况，基金会牺牲冲击成本以确保交易完成。
3. 指数样本股定期调整时，调入股票组合相对调出股票组合持续走强，可通过融资融券构建多空组合来获取绝对收益。仅仅通过买入调入股票组合，难以获取稳定的绝对或超额收益。运用交易量分析，挑选历史成交量较小的股票构建调入调出的多空组合，绝对收益得到显著提高；亦可采用该类调入样本的现货组合和股指期货对冲来赢得绝对收益。对冲策略的日胜率高达62%，7次交易机会中仅2次收益为负，且亏损在2%以内。
4. 指数样本股临时调整时，调入调出组合难以获得稳定的绝对或超额收益，对环境适用性以及个股的基本面等因素较为敏感。
5. 2011年12月12日、13日中证指数公司以及上交所、深交所公布了指数的调整公告，分析后建议关注泛海建设、广州控股、梅花集团、大唐发电由于调入动作构成的投资机会，在调出组合中，上港集团、九州通、建设银行由于历史成交量相对基金调仓所需交易量而言过小，估算可能需要5个交易日以上才能全部完成调整，提示警惕12月底前的股价变动。

### 1. 指数基金定期调整样本股成交量分析

#### 1.1 预测交易天数

指数的定期调整时间为每年的7月及1月的第一个交易日。根据交易所以及中证指数公司的规定，指数样本股在进行定期调整时，一般都会提前2周进行样本股披露，真正的样本股在次月的第一个交易日生效。

计算步骤：
1. 当获取到指数公司发布的最新样本股数据时（一般提前两周公布），计算市场上指数基金的最新净值，采用最新可以获得的份额数据，粗略估算指数基金的规模
2. 按照指数构成规则中的权重计算方法，计算各只指数中样本股的权重
3. 汇总每只指数上跟踪的基金总规模，计算该只指数调整时，调入调出股票产生的交易额，采用最近的收盘价数据，估算每只股票近期将要发生的交易量
4. 汇总所有指数，统计每只股票由于市场上指数基金调仓产生的总交易量，当某只股票在不同指数中的调入调出方向不同，交易量相互抵消，最后得出的为无法抵消的单向交易量
5. 对比股票的总交易量与先前一个月的日均成交量，计算调仓过程可能的耗时

从2006年年中以来，绝大部分股票都能够在一个交易日内调整完毕。平均交易天数仅在2008年中期超过了1个交易日，这是由于在2008年罕见的熊市中交易惨淡，市场流动性不足所致。但预测交易天数大于3天的有40余条数据，这些股票日均成交量较小，指数基金的大额交易很可能会带来短期的交易型机会。

#### 1.2 真实交易量变化

通过两种时间窗口观察（后期1周和2周的日均成交量），比较真实需要的交易时间与测算时间的差值。无论哪一种时间窗口，股票真实需要的交易时间与测算时间的误差绝大多数情况不会超过1日。

当测算天数不属于异常高的范围（如10日以上），该类股票其后期的交易量不会出现异常变化，走势平滑，测算天数与真实天数差异很小。但如果历史上股票的成交量过小，测算得到交易时长可能需要10日以上，甚至高达几十日，这种情况，股票后期明显放量，真实所需交易时长基本都在几个交易日内。

### 2. 指数定期调整样本股后收益效应

对第二类标的（估算交易用时大于三天）的划分标准为：估算出的基金调仓交易量/前期日均股票成交量 > 3天。

考察收益的时间窗口：调整公告公布之后，在第二日以均价买入股票，持有到调整生效日前（6月/12月的最后一个交易日）以均价卖出。构建调入股票组合以及调出股票组合，均采用等权重加权方式计算组合收益。

#### 2.1 绝对收益

两种组合（全样本 vs 历史成交量较小）：
1. 调出组合无论市场走势如何，净值均持续向下，即调出股票其绝对收益基本都维持在零值之下
2. 调入组合的净值在调出组合之上，但对于投资者而言，并没有投资价值，其2006年以来的11次投资收益累计，净值基本围绕在1附近波动
3. 调入组合相对于调出组合而言，具备明显优势。从相对强弱曲线观察，调入组合基本都战胜了同期的调出组合，相对强弱曲线累计向上
4. 前期交易量较小的股票群，其收益曲线相对全样本而言并没有明显改善。仅仅通过投资调入股票样本，难以获取绝对收益

#### 2.2 多空组合收益

假定样本股都可以进行融资融券交易，多空组合的净值走势：
- 全样本投资组合：总交易次数11次，持有期2-3周不等。考虑融资融券费率9.1%及交易费用0.3%后，次均收益为1.88%
- 历史成交量较小的股票组合：2006年至今有投资标的的次数共7次，费后次均收益水平高达4.87%

这验证了前期假设："基金调仓交易量形成了股票交易主买/主卖力量时，交易型机会及收益明显改善"。

#### 2.3 超额收益与对冲策略

全样本组合相对沪深300战胜幅度非常小，其净值走势基本与大盘走势一致。历史交易量较小的组合与沪深300的相对强弱和全样本相比有了明显提升，2006年至今累计超越幅度约为40%。

对冲策略：
- 现货组合为前期成交量较小的调入标的股票
- 采用股指期货对冲
- 费后净值曲线考虑了保证金比例，将80%的资金投资现货组合，20%作为期货保证金
- 日胜率：62.5%
- 7次交易机会中，5次正收益，2次负收益（-0.75%和-1.7%）

### 3. 临时调整样本股后收益效应

临时调整公告一般会提前2-3周披露。采用临时调整生效之前2周介入操作，买入价采用日均价，持有至调整生效时以均价卖出。

观察调入组合的走势，净值波动幅度较大，其绝对收益或是超额收益均来自于2007年以及2008年后期的累积，自2009年以来，临时调整样本股并没有绝对或超额收益空间。这说明临时调整样本股的收益稳定性并没有良好保障，或者其环境适用性有较高要求，亦或是临时调整的股票收益更多的受到股票基本面等因素的影响。在此不推荐关注该类事件。

### 4. 2011年12月交易机会提示

2011年12月12日及13日，中证指数公司和上交所、深交所分别公布了2012年1月第一个交易日生效的调整样本股信息。规模较大的指数：沪深300、上证50、深100、上证180、中证500、中证100、深成指、中小板指数、上证180治理、沪深300金融地产、巨潮100、上证红利指数。

**调入样本关注**：泛海建设、广州控股、梅花集团、大唐发电

## FORMULAS_AND_ALGOS

### 预测交易天数
```
预测交易天数 = 指数基金调仓单向交易量 / 股票前期日均成交量
```

### 指数基金调仓交易量估算
```
1. 计算指数基金总规模 = 净值 × 份额
2. 计算样本股权重
3. 调入/调出交易额 = 总规模 × 权重变化
4. 多指数汇总净额（同向相加，反向相抵）
5. 单向交易量 = 无法抵消的净调入或净调出量
```

### 多空组合构建
```
1. 筛选预测交易天数>3天的调入和调出股票
2. 调入组合：等权重买入
3. 调出组合：等权重融券卖出（需融券标的）
4. 持有至调整生效日
5. 计算费后收益（融资费率9.1% + 交易费用0.3%）
```

### 股指期货对冲策略
```
1. 买入历史成交量较小的调入标的股票现货组合（80%资金）
2. 卖出沪深300股指期货（20%保证金）
3. 持有至调整生效日
4. 计算对冲后收益
```

### 适用条件
- 定期调整事件（每年1月/7月）
- 优先关注历史成交量较小的调入/调出股票（预测交易天数>3）
- 需要融资融券工具（多空组合）或股指期货（对冲策略）
- 持有期约2-3周（公告后至生效日）
- 适用于流动性分析+事件驱动结合

### 失效条件
- 临时调整样本股（不稳定，不推荐）
- 全样本调入组合难以获取绝对收益（仅相对调出组合有优势）
- 大盘股流动性充足，预测交易天数<1，无交易机会
- 2008年极端熊市中，市场流动性整体不足
- 需要融资融券标的（部分调出股票不在融券范围）
- 股指期货对冲存在基差风险
