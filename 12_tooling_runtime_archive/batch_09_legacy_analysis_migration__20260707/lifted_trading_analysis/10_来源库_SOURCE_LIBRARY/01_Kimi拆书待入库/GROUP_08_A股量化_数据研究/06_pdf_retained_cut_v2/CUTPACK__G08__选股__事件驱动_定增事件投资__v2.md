# CONTENT_CLUSTERS

## 1. 临近解禁日，股票投资机会分析
- **核心逻辑**：定向增发股票即将解禁前，上市公司高管或股东具有驱动股价上涨的动力（尤其是折价股票面临股东压力）。
- **折溢价率定义**：解禁日前股价相对增发价格的折价率或溢价率。
- **样本量**：2006年以来所有定向增发的沪深A股共1251只，具有统计意义的股票763只（解禁日在报告发布日之前）。
- **折价股票分组**（解禁前60日）：低于增发价0-20%、20%-40%、40%-60%、60%以上四档。
- **溢价股票分组**（解禁前60日）：高于增发价0-20%、20%-40%、40%-60%、60%以上四档。

### 1.1 解禁压力对折价股票具有驱动力
- **解禁前60日-折价股票**：
  - 折价率0-20%的股票走势较差，一直弱于市场。
  - 折价率20%-40%的股票初期表现较好，但持有40天后超额收益率一路走低。
  - 折价率40%-60%的股票持有初期表现平平，但临近解禁日时开始爆发，持有120天后超额收益率达8.52%。
  - 折价率60%以上的股票在解禁日前后一段时间都有很不错表现。
  - **基本结论**：解禁日前股价相对增发价的折价率越高，其在之后的表现越好，尤其是折价率大于40%的股票，在解禁日前后的表现比较不错。
  - **胜率**：表现最好的是折价率大于60%的股票集合，很长一段时间胜率大于50%，最高达60.87%。
  - **超额收益分布**：折价率40%-60%和大于60%的股票集合收益率分布右端明显较厚。
- **解禁前60日-溢价股票**：
  - 溢价股票在解禁日前后的表现明显较差。除溢价率40%-60%的股票集合外，其他股票走势基本相同：初期小跌，进入平稳状态，然后在解禁日前的20天开始大幅下跌，到解禁日时进入小幅上涨趋势。
  - 所有溢价股票集合的胜率均小于50%，临近解禁时点胜率基本达到低点。
  - **核心结论**：解禁日前60天溢价的股票集合，绝大多数在解禁前明显下跌，相对指数超额收益、胜率均为负值，且低点基本在解禁日附近形成。这很可能是由于具有溢价空间的增发股票，其持有人在股票可流通之后选择了卖出股票获利了结。因此，对于该种类型的股票，不建议投资者在解禁前再进行参与。
- **解禁前120日-折价股票**：
  - 仅有一组股票组合其超额收益有启动趋势，其他组合的超额收益在较长时间内上下震荡没有明显趋势。折价率较大的股票组合基本强于折价率小的组合。
  - **核心结论**：折价股票相对而言股价启动不会太过提前，投资者可选择临近解禁时参与（如提前60个交易日）。
- **解禁前120日-溢价股票**：
  - 初期股价没有明显异动，随后随着解禁日期临近，超额收益率下跌幅度明显，在解禁日附近超额收益达到阶段低点。
  - 大多数溢价股票在解禁日前的20个交易日之内会有一次大幅下跌的过程。

### 1.2 市场的上涨能够形成股价上升的助力
- **市场环境定义**：根据考察收益时间窗口中沪深300指数收益率大于0（牛市）或小于0（熊市）来划分。
- **核心结论**：除了折价率极小的公司（0-0.2折价率），市场环境对于股价的影响不明显之外，其他公司基本具有统一规律：市场的上涨带动超额收益效应更为明显，而在市场下跌时，折价公司难以逆市而上获取超额收益。
- **投资者要求**：进行折价股票投资时，还需要对市场环境进行一定预判，这种投资机会并非能够免疫市场走势，总是获取超额收益。

### 1.3 折价股票投资策略
- **策略构建**：
  - 参与时间：解禁前60个交易日。
  - 观察窗口：解禁前[-65,-60]个交易日。
  - 买入信号：观察窗口内，5个交易日的平均股价相对增发价的折价率低于40%（即折价率>=40%），发出买入信号。观察5天时间通过均价来确认买入信号，避免股价短期波动产生毛刺信号。
  - 持有期：75个交易日（观察到股票一般在解禁后较短时间内仍会有一波上涨行情）。
  - 调仓：等权重分配，调仓时计入手续费0.3%。
- **策略表现**：
  - 平均超额收益：10%
  - 年化超额收益：4.73%
  - 胜率：58%
  - 信息比：0.346
  - 上涨市平均超额收益：18%
  - 下跌市平均超额收益：1%
  - 上涨市胜率：69%
  - 下跌市胜率：44%
  - 最大回撤：-25.81%
  - 收益回撤比：0.183
- **策略分析**：
  - 整体运作下来策略年化超额收益仅有4.73%，且信息比非常低，难以对投资者形成吸引力。但上涨市中折价股票表现突出（胜率69%，平均超额收益18%），如果投资者对未来市场环境有一定预判能力，临近解禁期的折价股票是非常好的选股标的。
  - 市场疲软时拖累折价股票，胜率仅44%，建议回避。
  - 2009年上涨市中策略未获超额收益，原因在于持仓少于10只且不断到期退出，没有跟住市场强势上涨。
  - 2011年下跌市中取得良好收益（年化19%），因捕捉到华新水泥和苏宁环球两只高收益个股。
  - 总体而言，此类事件投资标的有限，平均持仓股票数量仅在10余只，构建单一策略净值势必会经历大幅波动。

## 2. 增发预案后投资机会分析
- **核心逻辑**：从事件驱动角度出发，分析上市公司公布增发计划后，无论是从投资者期许方面还是从上市公司利用募集资金可能采取的动作方面，二级市场股价是否会有一定反映。

### 2.1 增发预案发布后，个股存在超额收益机会
- **总体表现**：预案发布后120个交易日左右，股票超额收益初期会经历一定幅度震荡，后期有较为稳定的上升趋势，胜率表现类似。
- **发布后一个月**：在发布后的20个交易日以内，股价相对指数基本不存在超额收益，围绕在指数附近震荡。这与股权激励事件研究结果类似，多数是由于重大事件披露后，前期不对称信息交易者的出货期。
- **持有期角度**：绝大多数年份中，持有一年的超额收益都高于持有半年的超额收益。增发事件是个相对影响时间窗口较长的事件。
- **超额收益与市场环境关系显著**：2011年-2013年的持有一年期超额收益波动区间可从0分布至30%左右。
- **总体结论**：发布增发预案的上市公司在中长期时间窗口具有超额收益空间。

### 2.2 买入时点的延后会损失超额收益
- **重要时点**：董事会决议、股东大会批准、发审委通过、证监会核准通过、股票发行。
- **首次获得信息**：增发预案发布日。
- **延后买入测试**：如果将买入时点延后至发审委通过或证监会核准，超额收益存在较为明显的递减趋势，且具有单调性：预案后首个买点 > 发审委通过后 > 证监会核准后。
- **核心结论**：增发事件的参与时点不宜过于延后，对消息的及时反映会获得较多超额收益回报。

### 2.3 市场环境对增发公司股价影响显著
- **预案发布前市场走势**：
  - 预案发布前1个月、3个月市场走势对增发后股价有一定影响，但区分作用不十分显著。
  - 相对而言，选择在上涨市发布增发预案的公司，后期的股价涨幅更为平稳。下跌市中超额收益会经历大幅度震荡。
  - 投资者可以适当根据预案前期的市场环境进行投资标的的筛选。
- **预案发布后市场走势**：
  - 预案后股价影响与临近解禁期截然不同：市场小幅震荡和小幅下跌的环境下，股票的平均超额收益明显高于其他市场环境。
  - 当市场大涨大跌时，增发事件难以形成股价的强有力刺激。价格上看不到支撑或是动力。
  - 较为平稳的市场环境更有利于增发股票的投资。
  - 市场小幅下跌时（日均涨幅<-0.1%），股票超额收益明显强于上涨环境。但市场大幅下跌时，股价也难挡系统性风险下挫。

### 2.4 增发事件策略的构建
- **买入时点**：预案发布后20个交易日买入（规避"出货期效应"）。
- **持有期**：分别考察1个月和2个月。由于增发股票标的不多，建议投资者持有2个月。
- **市场环境筛选**：预案前处于上涨市的增发股票（前一个月市场日均涨幅在0.1%以上），后期超额收益相对较为稳定。

## 3. 结论
- 增发类股票即将解禁前，折价股票存在超额收益机会，相对而言股价启动不会太过提前，投资者可选择临近解禁时参与（如提前60个交易日）。其股价在解禁日前后的表现与其相对于增发价格的折价率的大小有一定关系：折价率大的股票表现相较折价率小的股票表现更优。
- 解禁日前溢价的股票集合，绝大多数在解禁前明显下跌，相对指数超额收益、胜率均为负值，且超额收益以及胜率的低点基本全在解禁日附近形成。这很可能是由于具有溢价空间的增发股票，其持有人在股票可流通之后选择了卖出股票获利了结。因此，对于该种类型的股票，不建议投资者在解禁前再进行参与。
- 折价增发股票的投资机会一方面与其折价率密切相关，另一方面也受到市场走势较大影响。市场的上涨带动超额收益效应更为明显，而在市场下跌时，折价公司难以逆市而上获取超额收益。对于这类机会的把握，对投资者的要求较高，最好建立在对未来市场趋势有一定预判的前提下再参与。且此类事件投资标的有限，平均持仓股票数量仅在10余只，构建单一策略净值势必会经历大幅波动。
- 增发预案发布后，个股在中长期时间窗口存在超额收益机会。增发事件的参与时点不宜过于延后，对消息的及时反映会获得较多超额收益回报。
- 市场环境对预案发布后的股价具有影响：增发预案发布前，市场涨跌对增发后股价有一定区分作用，相对而言，选择在上涨市发布增发预案的公司，后期的股价涨幅更为平稳。预案发布后的市场走势对股价的影响和临近解禁期股价的影响截然不同：市场小幅震荡和小幅下跌的环境下，股票的平均超额收益明显高于其他市场环境。当市场大涨大跌时，增发事件难以形成股价的强有力刺激，价格上看不到支撑或是动力。由此，较为平稳的市场环境更有利于增发股票的投资。
- 根据定向增发的预案发布构建策略指数，相对沪深300年化收益可达24%，信息比1.5，2009年以来年度胜率为100%，且每年超额收益均保持在10%以上。

# FULL_TEXT

## 定增事件投资——甄别市场，把握买点

**摘要**

- 增发类股票即将解禁前，折价股票存在超额收益机会，相对而言股价启动不会太过提前，投资者可选择临近解禁时参与，如提前60个交易日。其股价在解禁日前后的表现与其相对于增发价格的折价率的大小有一定关系：折价率大的股票表现相较折价率小的股票表现更优。
- 解禁日前溢价的股票集合，绝大多数在解禁前明显下跌，相对指数超额收益、胜率均为负值，且超额收益以及胜率的低点基本全在解禁日附近形成。这很可能是由于具有溢价空间的增发股票，其持有人在股票可流通之后选择了卖出股票获利了结。因此，对于该种类型的股票，不建议投资者在解禁前再进行参与。
- 折价增发股票的投资机会一方面与其折价率密切相关，另一方面也受到市场走势较大影响。市场的上涨带动超额收益效应更为明显，而在市场下跌时，折价公司难以逆市而上获取超额收益。对于这类机会的把握，对投资者的要求较高，最好建立在对未来市场趋势有一定预判的前提下再参与。且此类事件投资标的有限，平均持仓股票数量仅在10余只，构建单一策略净值势必会经历大幅波动。
- 增发预案发布后，个股在中长期时间窗口存在超额收益机会。增发事件的参与时点不宜过于延后，对消息的及时反映会获得较多超额收益回报。
- 市场环境对预案发布后的股价具有影响：增发预案发布前，市场涨跌对增发后股价有一定区分作用，相对而言，选择在上涨市发布增发预案的公司，后期的股价涨幅更为平稳。预案发布后的市场走势对股价的影响和临近解禁期股价的影响截然不同：市场小幅震荡和小幅下跌的环境下，股票的平均超额收益明显高于其他市场环境。当市场大涨大跌时，增发事件难以形成股价的强有力刺激，价格上看不到支撑或是动力。由此，较为平稳的市场环境更有利于增发股票的投资。
- 根据定向增发的预案发布构建策略指数，相对沪深300年化收益可达24%，信息比1.5，2009年以来年度胜率为100%，且每年超额收益均保持在10%以上。

### 1. 临近解禁日，股票投资机会分析

本节主要研究定向增发的股票，在临近解禁前，是否由于股票即将上市流通而使得上市公司高管或是股东具有驱动股价上涨的动力？如果存在这一动力，那么没有拿到定向增发股票的投资者可以通过在二级市场进行交易获取一定的收益机会。认为对于即将解禁的股票，其所承受的最大压力来自于股价相对增发价折价，故而折溢价率是分析股票的一个要素。除此之外，对应时间段上市场情绪如何，或者说市场走势如何，对股价也会造成较大影响。后文主要针对这两个要素进行分析。

#### 1.1 解禁压力对折价股票具有驱动力

统计了自2006年以来的所有定向增发的沪深A股，共1251只股票，其中很多股票的解禁日在本报告发布日之后，无法确切知道股票在当时的表现。所以具有统计意义的股票有763只。分别研究在解禁日前的第60个交易日时股价相对增发价格的折溢价率以及在解禁日前的第120个交易日时股价相对增发价格的折溢价率对于股价日后表现的影响。

在所有的763只股票中，解禁日前的第60个交易日时股价相对增发价格折价的有300只股票，溢价的有463只股票。解禁日前的第120个交易日时的股价相对增发价格折价的有255只股票，溢价的有508只股票。将折价股票分为4档：低于增发价格0-20%、20%-40%、40%-60%、低于增发价格60%以上的股票集合；将溢价股票分为4档：高于增发价格0-20%、20%-40%、40%-60%、高于增发价格60%以上的股票集合，然后分情况统计从解禁日前60个交易日或者120个交易日开始持有每个股票集合的平均超额收益率、超额收益率的胜率以及超额收益率的分布情况。

**解禁日前60个交易日时股价相对增发价格折价**：
- 从所有折价股票的后期持有一定时间相对于沪深300指数平均累计超额收益走势可以看出：
  - 折价率在0-20%的股票集合走势较差，一直弱于市场。
  - 折价率在20%-40%的股票则在解禁日前60个交易日的初期表现较好，然而在持有40天后，其超额收益率一路走低，直追折价0-20%集合。
  - 折价率在40%-60%的股票集合在持有初期表现平平，但是在临近解禁日时开始爆发，持有120天后超额收益率能够达到8.52%。
  - 折价率在60%以上的股票集合，在解禁日前后的一段时间内都有很不错的表现。
- 基本可以得出，如果解禁日前股价相对增发价的折价率越高，其在之后的表现会越好，尤其是折价率大于40%的股票，在解禁日前后的表现比较不错。

从胜率方面，表现最好的是折价率大于60%的股票集合，其在很长一段时间内都保持大于50%的胜率，最高到达60.87%。其他股票集合的胜率表现一般。但根据整个折线图的走势，也可以看出股票走势是受到其解禁前折价率的影响的。折价率越高的股票，其后期反弹的可能性也越高。

从超额收益分布来看，相比于折价率0-20%与20%-40%的股票集合，折价率40%-60%的和大于60%的股票集合所呈现的收益率分布右端明显较厚。而从整体的分布情况来看，除去折价大于60%的股票集合，其它集合的超额收益率为负的股票分布居多，这也与前面分析胜率所得到的结论相吻合。

从上面的统计分析可以初步得出结论，解禁前60天折价的股票集合，其股价在解禁日前后的表现确实与其相对于增发价格的折价率的大小有一定关系：折价率大的股票表现相较折价率小的股票表现好些。

**解禁日前60个交易日股价相对增发价格溢价**：
- 前面重点分析折价股票在临近解禁时点时的股价表现，原因在于折价股票很可能会面临股东方面或是增发股票持有者的压力，其股价具有潜在上涨可能，尤其是折价较大的股票。那么具有溢价率的股票，其前期的上涨动力能否延续？本节具体分析溢价股票其后期的股价走势。
- 与折价股票对比发现，溢价股票在解禁日前后的表现明显较差。从图中发现，除溢价率40%-60%的股票集合外，其他股票的走势基本相同：初期小跌，进入平稳状态，然后在解禁日前的20天开始大幅下跌，到解禁日时进入一个小幅上涨的趋势。而溢价率40%-60%的股票集合也具有这样的总体趋势，但是其在大幅下跌的趋势区间下跌并不明显。
- 研究溢价股票集合的超额收益率的胜率。从图中可以看出，所有溢价股票集合的胜率均小于50%。且观察到在临近解禁时点，股票胜率基本都达到低点。
- 到解禁日时的收益率分布比较集中的区间是(-20%, 0%)。大部分的股票超额收益率小于0，也与之前所研究的结论相吻合。解禁日后60天的收益率分布中，比较集中的分布区间是(-30%, 10%)。相比于解禁日时的情况，超额收益率大于0的股票小量增多，这一阶段，胜率与收益率小幅提升。
- 从之上的分析中可以看到，解禁日前60天溢价的股票集合，绝大多数在解禁前明显下跌，相对指数超额收益、胜率均为负值，且超额收益以及胜率的低点基本全在解禁日附近形成。这很可能是由于具有溢价空间的增发股票，其持有人在股票可流通之后选择了卖出股票获利了结。因此，对于该种类型的股票，不建议投资者在解禁前再进行参与。

**解禁日前120个交易日股价相对增发价格折价**：
- 仅有一组股票组合其超额收益有启动趋势，其他组合的超额收益在较长时间内上下震荡没有明显趋势，当然折价率较大的股票组合基本强于折价率小的组合。这说明折价股票相对而言股价启动不会太过提前，投资者可选择临近解禁时参与。
- 分别统计了对于解禁前120个交易折价的股票，持有至解禁前60个交易日、解禁日的超额收益分布。发现结论与前面类似，折价率大的股票，其收益分布右尾明显厚于折价率较小的股票。

**解禁日前120个交易日时股价相对增发价格溢价**：
- 继续考察解禁前120天溢价股票走势，在初期股价没有明显异动，超额收益率上下波动，随后随着解禁日期的临近，超额收益率下跌幅度明显，在解禁日附近（即附中持有天数120天左右）超额收益达到阶段低点。这与前面的结论也一致。溢价股票的胜率都比较低，基本都小于50%，并且随着持有天数的增加，胜率会越来越低。
- 从之上对溢价股票的分析中，可以得出一个很明显的结论：大多数溢价股票在解禁日前的20个交易日之内会有一次大幅下跌的过程。而在其他时间段，股票走势较平稳。

#### 1.2 市场的上涨能够形成股价上升的助力

本节主要考察在对应时间区间内，市场走势对于股价是否也会产生影响。根据考察收益的时间窗口中，沪深300指数的收益率大于0还是小于0来定义市场环境，如考察解禁前60日到解禁日的股票收益，如果该段时间沪深300指数收益为正，则记为牛市，否则记为熊市。

对不同折价股票所处的市场环境进行划分，统计解禁前60个交易日买入股票，持有不同时间长度的平均超额收益。除了折价率极小的公司（0-0.2折价率），市场环境对于股价的影响不明显之外，其他公司基本具有统一规律：市场的上涨带动超额收益效应更为明显，而在市场下跌时，折价公司难以逆市而上获取超额收益。

由此，投资者在进行折价股票投资时，还需要对市场环境进行一定预判，这种投资机会并非能够免疫市场走势，总是获取超额收益。

#### 1.3 折价股票投资策略

根据上述结论：临近解禁日期的较大幅度折价股票短期内具有一定概率获取超额收益，且平均超额收益较为可观，制定投资策略来观测该种方案的投资效果。由于观察到折价公司的股价并不会过早启动，故而将参与时间设定在解禁前60个交易日。观察窗口设置在解禁前[-65,-60]个交易日。策略构建法则如下：当观察窗口内，5个交易日的平均股价相对增发价的折价率低于40%（即折价率>=40%），则发出买入信号。观察5天的时间通过均价来确认买入信号，主要是为了避免股价短期波动产生毛刺信号。持有期投资者可根据资金运作需求自行设定，观察到股票一般在解禁后较短时间内仍会有一波上涨行情，故而将持有期设置为75个交易日。所有股票被选入之后，按照等权重分配，调仓时计入手续费0.3%。

- 上涨市中，折价股票表现突出：股票胜率高达69%，个股平均超额收益为18%（持有期75个交易日）。这个数据告诉我们，如果投资者对未来的市场环境有一定的预判能力，那么临近解禁期的折价股票是非常好的选股标的。
- 市场疲软走势，势必拖累折价股票。当市场走势较差时，已经折价的股票，投资者本身就具有负面情绪，外加外界市场负面情绪的影响，很可能形成雪上加霜的局面，上市公司推高股价的动力难抵情绪面影响，最终拖累股价。这种时候，该类标的的胜率仅有44%，虽然平均超额收益为1%，并没有出现负值，但建议投资者回避。
- 从策略整体表现看，在2009年的上涨市中策略并没有获取超额收益，原因在于2009年3月到6月期间发生了较大回撤。当时策略并没有选出新的股票，且持仓少于10只，股票不断到期退出。该段时间的股票前期超额收益都较为显著，但在退出时点附近发生了一定回调，没有跟住市场的强势上涨行情，导致回撤发生。
- 在2011年的下跌市中，策略取得了良好收益，年化超额收益高达19%，与其一般的下跌市表现不一致，原因在于2011年净值上涨最快的时间中，策略整体持仓股票较少，多数在2-5只，而且期间分别在3月以及7月，策略捕捉到两只高收益个股：华新水泥在2011年初期经历了股价翻番的行情、苏宁环球2011年7月份附近逆市上涨约30%。
- 总体而言，折价增发股票的投资机会一方面与其折价率密切相关，另一方面也受到市场走势较大影响，对于这类机会的把握，对投资者的要求较高。且此类事件投资标的有限，平均持仓股票数量仅在10余只，构建单一策略净值势必会经历大幅波动。

### 2. 增发预案后投资机会分析

前文中，主要从情绪面出发，捕捉在临近解禁时，上市公司可能具有做高股价的动力，分析投资者是否能够在二级市场根据这种情绪变动获取超额收益。本节则从事件驱动的角度出发，分析在上市公司公布了增发计划后，无论是从投资者期许方面还是从上市公司利用募集资金可能采取的动作方面，二级市场股价是否会有一定反映。

#### 2.1 增发预案发布后，个股存在超额收益机会

首先考察预案发布后，股票标的的股价表现。统计增发股票在预案发布后120个交易日左右的股价相对沪深300超额收益以及胜率走势，总体来看股票超额收益初期会经历一定幅度的震荡，后期有较为稳定的上升趋势，胜率表现类似。

另外发现，预案发布后公司股价中长期虽然一直处于上升通道，但是在发布后的一个月以内（即20个交易日以内），股价相对指数基本不存在超额收益，围绕在指数附近震荡。这与先前对股权激励事件的研究结果类似，这种现象存在的原因，多数是由于重大事件披露后，往往会有一段时间是前期的不对阵信息交易者的出货期。投资者在二级市场进行参与时，建议可以规避这段时期后再进行买入。

下面的统计结果将多种市场环境下的股票放在一起进行考察，难以明确看出股票的时间序列收益如何。简单的将市场按照年份划分，考察收益表现。

从持有期角度看，绝大多数年份中，持有一年的超额收益都高于持有半年的超额收益。增发事件是个相对影响时间窗口较长的事件。超额收益与市场环境关系显著。2011年-2013年的持有一年期超额收益的波动区间可从0分布至30%左右。这一结论与前文对解禁前机会的研究结论一致。总体而言，发布增发预案的上市公司在中长期时间窗口具有超额收益空间。

#### 2.2 买入时点的延后会损失超额收益

对于增发类事件，一般而言有几个比较重要的时点：董事会决议、股东大会批准、发审委通过、证监会核准通过、股票发行。这其中二级市场投资者首次获得增发信息是在增发预案发布日，也就是在第一节中考察的首个买点。在这个时间节点之后，投资者会非常关注两个进程：发审委是否通过、证监会核准是否通过。当这两个进程完成后，公司的增发股票即可以进行发行，是个比较重要的利好信息。故而考察如果将买入时点延后至预案可以实行的确定性更高的这两个时点，是否能够在投资收益和胜率上有所改善。

从考察不同时点买入股票后相对沪深300指数的累计超额收益情况可以看到，随着时点的不断延后，超额收益存在较为明显的递减趋势，且具有单调性：预案后的首个买点，累计超额收益总是高于后期买入的超额收益；发审委通过后买入的超额收益也高于证监会核准后的超额收益。由此，增发事件的参与时点不宜过于延后，对消息的及时反映会获得较多超额收益回报。

#### 2.3 市场环境对增发公司股价影响显著

增发事件势必对于市场走势较为敏感，作为一种融资行为，投资者一般会根据市场的涨跌产生积极或是负面情绪，这种情绪自然会传导到对于企业融资行为的预期上。考察市场对增发股票的影响时，多数投资者会简单的根据牛熊市对市场进行划分。但需要注意的是，一方面需要考察增发时或者增发前市场走势如何，另一方面是增发后市场的走势对股价有何带动作用。

**增发预案发布前，市场涨跌对增发后股价有一定影响**：
- 考察增发预案发布前1个月、3个月市场的走势，根据这段时间的市场涨跌划分股票标的（选择沪深300作为市场指数）。
- 最终股票的累计超额收益幅度在120个交易日时相差不大，但是相对而言，上涨市中收益的累计趋势较为平稳，而下跌市中超额收益会经历大幅度震荡，从投资角度而言，平稳的上升趋势更容易把握，故而投资者可以适当根据预案前期的市场环境进行投资标的的筛选。

**预案发布后的市场走势对股价的影响和临近解禁期股价的影响截然不同**：
- 市场小幅震荡和小幅下跌的环境下，股票的平均超额收益明显高于其他市场环境。
- 当市场大涨大跌时，增发事件难以形成股价的强有力刺激，价格上看不到支撑或是动力。
- 由此，较为平稳的市场环境更有利于增发股票的投资。
- 市场出现小幅下跌时（日均涨幅<-0.1%），股票超额收益明显强于上涨环境中的股票表现。但是当市场大幅下跌时，股价也难挡系统性风险的下挫，超额收益会大幅下降至零值以下。市场大幅上涨，增发公司股价难以追上市场涨幅，说明增发事件的驱动作用较为平和，并不是短期的有力刺激，在市场大幅波动时无法形成股价的支撑或是动力。

#### 2.4 增发事件策略的构建

根据前文的研究结果，可以将增发事件形成策略指数具体考察投资效果。
- **买入时点**：前文提到增发类事件驱动策略的买点不宜过于延后，可能会造成超额收益的损失，但是预案发布后短期内可能具有"出货期效应"，将股票的买入时点设为增发预案后的20个交易日买入。
- **持有期**：增发事件是个可以中长期持有的事件驱动策略，但是过长的持有期往往会造成中间难以控制的个股风险出现，而且考虑到股票的超额收益在一年以内大概率处于上升通道，分别考察持有1、2个月的超额收益。由于增发股票标的不多，建议投资者可以持有2个月，一方面扩大组合容量，一方面降低组合波动。
- **市场环境影响**：预案前后的市场走势对于股票收益都会产生一定影响，但是后期的市场环境难以通过模型进行判断，这里仅对前期的市场环境进行一定区分。预案前处于上涨市的增发股票，其后期的超额收益相对较为稳定，可以选择前期一个月市场日均涨幅在0.1%以上的股票进行投资。

### 3. 结论

增发类股票即将解禁前，折价股票存在超额收益机会，相对而言股价启动不会太过提前，投资者可选择临近解禁时参与，如提前60个交易日。其股价在解禁日前后的表现与其相对于增发价格的折价率的大小有一定关系：折价率大的股票表现相较折价率小的股票表现更优。

解禁日前溢价的股票集合，绝大多数在解禁前明显下跌，相对指数超额收益、胜率均为负值，且超额收益以及胜率的低点基本全在解禁日附近形成。这很可能是由于具有溢价空间的增发股票，其持有人在股票可流通之后选择了卖出股票获利了结。因此，对于该种类型的股票，不建议投资者在解禁前再进行参与。

折价增发股票的投资机会一方面与其折价率密切相关，另一方面也受到市场走势较大影响。市场的上涨带动超额收益效应更为明显，而在市场下跌时，折价公司难以逆市而上获取超额收益。对于这类机会的把握，对投资者的要求较高，最好建立在对未来市场趋势有一定预判的前提下再参与。且此类事件投资标的有限，平均持仓股票数量仅在10余只，构建单一策略净值势必会经历大幅波动。

增发预案发布后，个股在中长期时间窗口存在超额收益机会。增发事件的参与时点不宜过于延后，对消息的及时反映会获得较多超额收益回报。

市场环境对预案发布后的股价具有影响：增发预案发布前，市场涨跌对增发后股价有一定区分作用，相对而言，选择在上涨市发布增发预案的公司，后期的股价涨幅更为平稳。预案发布后的市场走势对股价的影响和临近解禁期股价的影响截然不同：市场小幅震荡和小幅下跌的环境下，股票的平均超额收益明显高于其他市场环境。当市场大涨大跌时，增发事件难以形成股价的强有力刺激，价格上看不到支撑或是动力。由此，较为平稳的市场环境更有利于增发股票的投资。

根据定向增发的预案发布构建策略指数，相对沪深300年化收益可达24%，信息比1.5，2009年以来年度胜率为100%，且每年超额收益均保持在10%以上。

# FORMULAS_AND_ALGOS

## 信号生成公式

### 1. 解禁前折价策略
```
折价率 = (增发价 - 股价) / 增发价

观察窗口：解禁前[-65, -60]个交易日
买入信号：MA5(股价) 对应的折价率 >= 40%

即：在观察窗口内，5日均价对应的折价率大于等于40%时触发买入

持有期：75个交易日
卖出：持有期满后以均价卖出

排除：溢价股票（不建议在解禁前参与）
```

### 2. 增发预案后策略
```
买入时点：预案公告日 + 20个交易日
（规避发布后的"出货期"）

持有期：2个月（约40个交易日）
（标的不多，建议中长期持有以扩大组合容量）

市场环境筛选：
  预案前20日沪深300日均涨幅 >= 0.1%
  （上涨市预案的后期涨幅更平稳）

卖出：持有期满后以均价卖出
```

### 3. 折溢价分组
```
折价分组：
  组1: 折价率 0-20%
  组2: 折价率 20%-40%
  组3: 折价率 40%-60%
  组4: 折价率 >= 60%

溢价分组：
  组1: 溢价率 0-20%
  组2: 溢价率 20%-40%
  组3: 溢价率 40%-60%
  组4: 溢价率 >= 60%

优选：折价组3和组4
回避：所有溢价组（胜率<50%，解禁前下跌）
```

### 4. 市场环境划分（解禁前）
```
如果 考察期沪深300收益 > 0:
  市场环境 = "上涨市"
  预期：超额收益更显著（上涨市平均18%）
  
如果 考察期沪深300收益 < 0:
  市场环境 = "下跌市"
  预期：难以逆市而上（下跌市平均1%，胜率44%）
  
建议：仅在上漲市或对市场有预判时参与折价策略
```

### 5. 市场环境划分（预案后）
```
预案前环境：
  上涨市：前期1月/3月日均涨幅 > 0
  下跌市：前期1月/3月日均涨幅 < 0

预案后环境：
  小幅震荡：日均涨幅 ∈ [-0.1%, 0.1%]
  小幅下跌：日均涨幅 < -0.1%
  大涨/大跌：日均涨幅 > 0.1% 或 < -0.3%

最优：预案后小幅震荡或小幅下跌环境
回避：预案后大涨或大跌环境（事件难以形成强刺激）
```

### 6. 等权重调仓
```
入选股票等权重分配
调仓手续费：0.3%（双边）
```

## 适用条件与失效条件

**适用条件**：
- 解禁前策略：折价率>=40%的定增股票，提前60个交易日介入，持有75日
- 预案后策略：预案发布后20个交易日买入（避开出货期），持有2个月
- 预案后策略：优先选择预案前处于上涨市（前1月日均涨幅>0.1%）的标的
- 市场环境：上涨市或平稳市（小幅震荡/小幅下跌）时参与，超额收益最显著
- 折价率越高越好（60%以上表现最优），但40%以上即可纳入
- 等权重配置，控制个股风险

**失效条件**：
- 溢价股票：解禁前20日大幅下跌，胜率<50%，不建议参与
- 下跌市：折价公司难以逆市而上，胜率仅44%，建议回避
- 预案后大涨/大跌环境：增发事件难以形成强刺激，价格无支撑或动力
- 买入时点过于延后：发审委通过/证监会核准后买入，超额收益单调递减
- 标的有限：平均持仓仅10余只，单一策略净值波动大
- 解禁前120日过早介入：折价股票股价启动不会太过提前，过早介入收益震荡
- 难以找到大牛股：策略在收益分布最右端极值上未能选中大牛股

# NOT_QUANT_YET

1. **定增折扣率的实时估算**：当前使用历史增发价，对于尚未完成发行的定增，需基于预案中的发行底价和当前市价实时估算折扣率。
2. **解禁股东身份识别**：折价股票的股东是控股股东、机构投资者还是财务投资者，对解禁后抛售压力的影响差异未量化。
3. **定增募集资金的用途分类**：募集资金用于并购、扩产、还债、补充流动资金等不同用途对后期收益的影响。
4. **定增破发后的二次机会**：解禁后若股价持续低于增发价，是否存在"二次反弹"机会。
5. **与业绩预告/股权激励的叠加**：定增股票同时发布业绩利好或股权激励时的信号叠加效应。
6. **行业层面的定增效应**：不同行业（如TMT、医药、周期股）的定增事件收益差异。
7. **定增规模与市值比**：当前仅用折价率，未考虑定增规模相对市值的比例对股价冲击的影响。
8. **大宗交易折价的影响**：解禁前通过大宗交易折价转让的份额对二级市场价格的提前反映。
9. **监管政策变化**：2020年后再融资新规对定增折价率、锁定期、发行对象数量的影响，策略需更新适配。
