我们于2010 年6 月份推出了相关性选股策略，通过构建因子库、因子筛选、因
子打分等步骤来构建股票组合，经过近四年的样本外跟踪，无论是在全市场还是行业
层面，策略组合都取得了超越业绩基准的优异表现，具备显著的alpha 收益。
多因子选股的核心在于如何筛选有效因子，相关性选股通过检验单个因子和下期
收益之间的相关性是否显著来决定因子是否有效。在实际投资中，投资者通常关注因
子处于极端部分的股票（如高成长、低估值的股票），而对因子值处于中间部分的股票
不会给予太多关注，也就是说如果因子极值组的股票正好对应到收益率的极值组，这

# 6. FORMULAS_AND_ALGOS

## 6.1 超跌定义
- **一级突破（超跌）**: 相对同期沪深300跌幅超过10%
- **剔除规则**: 一周内连发信号剔除；跌停导致的一级突破剔除

## 6.2 下跌速度与股价弹性
- 具体计算公式原文未显式给出，但可通过量价数据构建:
  - 下跌速度 = 近期跌幅 / 时间窗口
  - 股价弹性 = 价格对成交量的敏感度（通常可用振幅/换手率近似）

## 6.3 二重突破策略执行
- **买入**: 信号触发日次日开盘价
- **卖出**: 持有到期后收盘价
- **持有期**: 5个交易日（1周）
- **资金管理**: 分拆为5个子账户，每份资金周一买入周五清算，以此类推

## 6.4 相关性选股流程
1. 因子库构建（25/29个因子）
2. 对样本空间内股票按因子值排序，得到排名
3. 对下期收益率排序，得到收益排名
4. 过去24期因子排名与收益排名做Pearson相关性检验
5. 显著因子（P值<阈值）进入有效因子集，符号由相关系数正负决定
6. 等权加权有效因子，对股票打分，取Top10%/20%构建组合

## 6.5 极值因子筛选条件
- **分化性**: abs(mean(R_5) - mean(R_1)) > R_threshold
- **极值性**: max(R_1..5) = R_5 或 min(R_1..5) = R_1
- **稳定性**: sum(w_i^+)/24 > W_threshold 或 sum(w_i^-)/24 < -W_threshold
  - 其中 w_i^+ = 1 if R_5 > R_1 else 0

## 6.6 Fama-French三因子模型（参考）
- R_it - R_ft = α_i + β_i(R_mt - R_ft) + s_i SMB + h_i HML + ε_it

## 6.7 现金流量市值比
- Cfmv = 经营活动产生的现金流净额（当季） / 总市值

## 6.8 相对估值
- 相对PB = 个股PB / 行业PB
- 相对PE = 个股PE / 行业PE

## 6.9 微观分位点评价
1. 计算每期精选股票、样本空间股票下期收益
2. 计算精选股票下期收益在样本空间中的分位点 p_i
3. Logistic变换: p_i* = ln(p_i / (1 - p_i))
4. 与[0,1]均匀分布的Logistic变换基准比较
5. 多头应右偏，空头应左偏

## 6.10 指数成分股调整冲击测算
- 冲击 = 调仓金额 / 近期日均成交金额
- 正向冲击（调入）越大，后期上涨空间越大
- 负向冲击（调出）越大，后期下跌风险越大
