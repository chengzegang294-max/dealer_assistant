8. **最新样本股**：2010年2月末24只样本股清单。
9. **策略叠加原理**：行业内选股超额收益受行业配置权重放大效应影响，强势阶段应优选策略B（高alpha），弱势阶段优选策略A（稳健alpha）。

## 一、引言

### 1.1 自上而下投资流程

市场上的主流投资流程分为"自上而下"和"自下而上"两类。

- **自上而下**：从整体的仓位控制及资产配置入手（大类资产配置策略），通过对各行业政策变化及盈利成长前景进行行业配置比例预设（行业配置策略），最后通过行业内个股定性和定量分析得到行业内个股超配低配观点（选股策略）。体现了团队合作的风格，从三个层次上寻求不同类型的超额收益，且可相互叠加。
- **自下而上**：排除个股行业属性等同对待，通过精选满足估值条件和长期投资条件的个股组合，组合的行业配置和市场大类资产配置相应完成。美国富达基金（Fidelity）及彼得·林奇的成长价值选股策略是典型的自下而上策略。

两种体系各有优缺点：自上而下可宏观整体性把握，但灵活不足；自下而上可充分发挥主观能动性，但全局性观察和分析不够，投资风险较难控制。

海通金融工程部此前推出了A股市场指数及主要大市值行业的月度走势趋势预测观点、不同市场板块（大小盘、消费非消费）的月度强弱趋势预测体系，以及基于基金季度报告的行业配置比例提炼得到的行业配置策略。本文开始的行业内选股模型报告，将定量的自上而下投资流程进一步完善，构建一个自上而下的量化选股模型，与前期推出的自下而上选股策略系列有所区别。

### 1.2 有色金属行业选股意义

不同的行业具有不同特征，影响行业内个股表现的因素也会有所不同。大市值行业更加注重历史业绩和估值，小市值行业更注重预期变化和未来成长性。有色金属行业选择依据：
1. 高波动行业，走势与市场节奏相同，具备相对均等的强势和弱势阶段。
2. 流通市值较小，主要由中小市值公司构成，行业内选股表现与钢铁行业（大市值）有所差异，有必要独立研究。

## 二、有色金属行业的行业内个股单因素回归检验分析

### 2.1 行业主要走势区间划分

行业内选股选取行业内alpha，但自上而下策略更感兴趣的是市场强势阶段、行业强势时期中表现强势的个股，同时希望选股逻辑在行业弱势阶段也有一定alpha贡献。

将研究区间划分为样本内和样本外，并依据行业指数强弱划分为强势和弱势阶段。更重视强势下的显著因子，因为：
- 当看多行业时高配行业权重，此时行业内超额收益alpha被放大。
- 当看空行业时低配行业权重，行业内超额收益贡献被削弱。

选取天相二级行业有色指数(998315)和上证综指对比，寻找有色金属行业最近4年的相对强势时期。同时使用49只样本股等权重指数与全样本等权重指数对比。相对强弱指数：
- 相对强弱（有色/上证）= ln(有色（天相）/上证综指)
- 相对强弱（有色等权重/全样本等权重）= ln(有色等权重指数/全样本等权重指数)

#### 2.2.1 历史财务数据

在10%显著性检验下，历史财务指标的单变量显著性（样本内全区间35期）未表现出显著稳定性。强势区间和弱势区间显著指标也不多。这同钢铁板块有所不同，反映小市值行业中影响个股更多的因素来自预期和新信息而非历史信息。

#### 2.2.2 历史估值水平和市值大小指标

截面数据单变量回归显示，历史估值指标在35期样本内未表现显著稳定性，市值指标显著次数较多但方向并不稳定。

- 强势阶段：大市值行业表现更好，历史市盈率有一定解释度但次数有限。
- 弱势阶段：小市值个股相对抗跌，市现率出现显著负相关（同逻辑相悖）。

总体来看没有特别稳健的估值指标出现。

#### 2.2.3 情绪指标（一致预期）

情绪指标基于朝阳永续一致预期数据库。样本内全区间：
- cPE_P（当年一致预期PE倒数）：正向显著次数较多。
- cPB_P（当年一致预期PB倒数）：正向显著次数较多。
- cPE_P_P1（第二年一致预期PE倒数）：显著次数较多，方向稳定。
- cPB_P_P1（第二年一致预期PB倒数）：显著次数较多，方向稳定。
- G_P、G_P_diff、G_P_P1、G_P_diff_P1：部分月份显著，但稳定性不如估值类情绪指标。

#### 2.2.4 技术指标

 mom_3（过去3个月涨幅）在样本内全区间显著次数较多，且方向稳定（负相关，即反转效应）。其他动量指标（mom_1、mom_2、mom_6、mom_12）显著性不如mom_3。

## 三、有色金属行业打分模型构建及评价

### 3.1 打分模型指标选择

基于单因素回归结果，最终选择三个指标构建综合打分模型：
1. **下一年预估市盈率倒数（cPE_P_P1）**：一致预期估值类情绪指标，在强势和弱势阶段均有稳定表现。
2. **下一年预估市净率倒数（cPB_P_P1）**：一致预期估值类情绪指标，同上。
3. **3个月个股涨幅（mom_3）**：技术指标，反转效应稳定。

由于选股目的在于构建稳定超额收益组合，保留50%数量个股（24只），符合大资金配置需求。

打分规则：
$$Score = rank(cPE\_P\_P1) + rank(cPB\_P\_P1) + rank(mom\_3)$$

按Score从高到低排序，取前50%（24只）构建组合。

# FORMULAS_AND_ALGOS

## 1. 自上而下打分模型核心流程（伪代码）
```
输入：行业股票池 S（49只），因子池 F（一致预期PE、PB、3个月动量）
      行业强弱区间划分 R
输出：每月选股组合 P_t

// 行业强弱区间划分
for 每个交易日:
    RS_log = ln(行业指数 / 大盘指数)
    当RS_log趋势向上时标记为强势，向下标记为弱势

// 单因素回归检验（样本内）
for 每个月 m in 样本内:
    for 每个因子 f in F:
        截面回归：return_i = α + β × f_i + ε
        if |t统计量| > 1.645 (p<0.10):
            f 标记为显著

// 打分模型构建
选定显著因子：cPE_P_P1, cPB_P_P1, mom_3

for 每个月 t in 样本外:
    for 每只股票 s in S:
        score_s = rank(cPE_P_P1_s) + rank(cPB_P_P1_s) + rank(mom_3_s)
    P_t = top-50% 等权重或市值加权
```

## 2. 关键公式

**相对强弱对数**
$$RS_{log} = \ln\left(\frac{行业指数}{大盘指数}\right)$$

**行业内选股alpha贡献**
$$\alpha_{portfolio} = \alpha_{industry} \times weight_{industry}$$

**综合打分**
$$Score_s = rank(cPE\_P\_P1_s) + rank(cPB\_P\_P1_s) + rank(mom\_3_s)$$

**年化夏普比率**
$$Sharpe_{annual} = \frac{R_p - R_f}{\sigma_p} \times \sqrt{12}$$

**信息比率**
$$IR = \frac{\alpha_p}{TE_p}$$

## 3. 因子定义

| 因子 | 计算公式 | 数据来源 |
|------|----------|----------|
| cPE_P_P1 | 1 / 一致预期第二年市盈率 | 朝阳永续一致预期 |
| cPB_P_P1 | 1 / 一致预期第二年市净率 | 朝阳永续一致预期 |
| mom_3 | (Close_t / Close_{t-60}) - 1 | 行情 |
| T_value | 总股本 × 收盘价 | 行情 |
| A_value | 流通股本 × 收盘价 | 行情 |
| G | (净利润_t − 净利润_{t-4}) / |净利润_{t-4}| | 财报 |
| G_S | (营收_t − 营收_{t-4}) / 营收_{t-4} | 财报 |

# NOT_QUANT_YET
1. **一致预期数据依赖**：打分模型核心依赖朝阳永续/万得一致预期数据库，数据成本高、覆盖延迟，未研究无一致预期数据时的替代方案（如历史外推、机器学习预测）。
2. **重组预期量化难题**：有色行业中小市值公司重组预期影响大，但未将重组预期纳入量化模型（如并购概率、公告事件、大股东变更）。
3. **行业强弱区间划分主观性**：基于目视观察和定性判断，未建立量化规则（如RS_log的MA交叉、波动率突破、HMM隐状态）。
4. **单因素回归未控制多重检验**：35期截面回归进行10%显著性检验，未进行Bonferroni或FDR校正，可能存在假阳性。
5. **因子等权打分的优化**：三个因子等权相加，未通过历史IC加权、风险调整或优化算法确定最优权重。
6. **50%持仓比例最优性**：50%是经验设定，未通过信息准则或效用函数优化最优持仓比例。
7. **小市值风格风险**：策略在弱势阶段偏好小市值，但未对风格系统性回撤进行压力测试。
8. **跨行业迁移**：打分模型基于有色行业特征，未迁移到钢铁、煤炭、化工等其他周期行业验证。
9. **宏观变量缺失**：未纳入铜价、金价、美元指数、中国PMI等宏观变量，可能提升预测能力。
10. **实时数据接入**：一致预期数据更新频率低，未建立实时爬虫或API接入。
11. **事件冲击过滤**：未纳入重大政策（如稀土出口配额、环保限产）或公司事件（如定增、并购）的过滤机制。
12. **多期持仓优化**：当前月度选股，未研究最优再平衡频率（双月、季度）。

# NEXT_ACTION
1. **复现有色金属自上而下打分模型**：在2015–2024年有色数据上复现cPE_P_P1 + cPB_P_P1 + mom_3打分模型，验证跨周期有效性。
2. **构建一致预期替代方案**：当无一致预期数据时，使用历史财报外推、LSTM/Transformer预测下年PE/PB，对比替代方案与真实一致预期的效果差异。
3. **重组预期量化**：收集并购重组公告、大股东变更、定增预案等事件，构建重组概率评分（如基于公告类型、大股东背景、市值大小），纳入打分模型。
4. **行业强弱区间量化划分**：使用RS_log的MACD交叉、波动率突破、HMM隐马尔可夫模型自动划分强势/弱势区间，对比人工划分效果。
5. **多重检验校正**：对单因素回归进行Bonferroni或FDR校正，识别真正稳健的因子，排除假阳性。
6. **因子权重优化**：将等权打分改为基于历史IC的加权打分，或使用风险平价/均值方差优化确定最优权重。
7. **持仓比例优化**：在10%–90%区间测试不同持仓比例，绘制比例 vs 夏普/回撤曲线，确定最优比例。
8. **加入宏观变量**：从LME/SHFE提取铜、铝、锌、黄金期货价格，加入美元指数、中国PMI、M2增速等宏观变量，构建宏观择时开关。
9. **跨行业迁移测试**：将打分模型迁移到钢铁、煤炭、化工、电力等行业，对比因子显著性和组合收益。
10. **月度自动化选股脚本**：封装流程为月度定时任务，每月末自动下载一致预期+行情数据、计算因子、运行打分模型、输出50%持仓清单。
11. **事件冲击过滤**：建立稀土政策、环保限产、关税调整等事件数据库，在事件窗口调整模型或暂停选股。
12. **多期持仓优化**：测试月度、双月、季度再平衡频率，通过综合评分选择最优再平衡周期。
