# CONTENT_CLUSTERS
1. **线性统计困境** — Pearson相关系数多数<0.04，检验显著但拟合差
2. **有效性强弱指数** — 10组收益排序与理想序列的相关系数，ROA增速>0.7
3. **U型形态发现** — 最大收益出现在因子取值两端，非严格单调
4. **尾部相关性度量** — Pr(X>t*|F>s*)，条件概率形式刻画极端区域
5. **稳定性检验** — 前52月与后53月尾部相关系数高度一致
6. **因子筛选应用** — 尾部相关系数可预测最大收益组概率
7. **多因子推广问题** — 最优权重、组合尾部相关、两端收益原因待解

3. 因子与收益率的尾部相关性 
在本系列的第二篇专题报告——《因子模型的尾部相关性研究》中，我们定义了个
股与市场收益率之间的尾部相关性，用以刻画在市场收益率较为极端的区域内，个股所

子间的尾部行为。以F 表示因子，X 表示收益率，那么两者之间的尾部相关性可写为：
Pr(X>t*|F>s*)。其中，s*和t*为两个较大的阈值。这一表达形式不仅完全符合上一部分

# FORMULAS_AND_ALGOS
**公式1：斜率检验统计量**
T = (n-2)R²/(1-R²)

**公式2：有效性强弱指数**
1. 按因子大小分10组
2. 记录每月最大收益组序号N_i
3. 统计频数(R1,...,R10)
4. 计算(R1,...,R10)与(1,...,10)的相关系数

**公式3：尾部相关系数**
Pr(X > t* | F > s*)
其中X为收益率，F为因子，s*和t*为大阈值

**公式4：最大收益组占比**
最大/最小组出现最高平均收益的百分比

**适用条件**：
- 大样本截面数据（沪深300成分股）
- 月频因子和次月收益率
- 分组检验优于线性相关

**失效条件**：
- 小样本时统计功效不足
- 仅依赖Pearson相关系数（多数<0.04）
- 追求严格单调性（过于严苛）
