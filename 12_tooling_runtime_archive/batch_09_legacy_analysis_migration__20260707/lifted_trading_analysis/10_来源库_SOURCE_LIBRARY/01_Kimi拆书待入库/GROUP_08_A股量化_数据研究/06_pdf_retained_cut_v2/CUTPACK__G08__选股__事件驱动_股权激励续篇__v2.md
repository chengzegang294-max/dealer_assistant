## FULL_TEXT

### 摘要

本篇报告对股权激励所涉及到的整个投资周期进行研究，寻找不同阶段的参与时点，并对行权条件、业绩基准设置等细则进行了系统分析。核心结论：

1. 股票超额收益集中在两个阶段反应：第一个阶段为实施日至第一个行权日（为期1年或稍长），投资逻辑在于激励对象通过诸种措施提高公司业绩，使得股权激励最终能够完成行权/解锁条件；第二个阶段在第一个行权日后的一年时间，投资逻辑在于高管推高公司股价，使得到手的奖励股票在能够卖出时高价出货。超越这两个投资周期之后，股权激励的刺激作用边际递减。

2. 对于长期投资者而言，以一年为持有期，第一个超额收益时段买入点为首次实施公告后（规避最初的股价蛰伏期）；第二个买入点为行权日附近。

3. 有些投资者受情绪波动或投资风格影响，难以做到长期持有，建议以2个月作为换手频率。有两个买点可以参与：第一个为首次实施公告后（规避最初的股价蛰伏期）；第二个为行权股票能够上市流通前2个月左右。

4. 以实施日后买入为例，长短期持有策略的年化收益分别为45.48%，45.28%，收益相当。作为构建对冲策略的多头组合，短期持有高换手策略更优，相对沪深300战胜幅度稳定，对冲后年化收益约为43.6%。

5. 行权条件的相关设置对第一个投资周期股票筛选起到至关重要作用。基准年份刻意挑选业绩较差年份的上市公司，实施日后至第一个行权时点之间表现明显较差；行权条件设置较为严格的股票，在第一个投资周期中表现大概率强于容易行权的股票。条件严格与否的标准，采用财务数据相对比较法更为有效，即对比未来财务指标要求是否要超越当年水平。上市公司行权或股票解锁后，这两个因素对股价的影响作用迅速衰减。

6. 股票在第一次行权之前如果跌破行权价，存在着价格回补形成的绝对收益机会，但单纯通过股票多头投资依然难以完全摆脱系统风险，在市场下跌环境下无法取得绝对收益。需要借助期货做空工具。

### 1. 股权激励的投资周期分析

#### 1.1 价值型投资者的投资周期分析

期权类激励有几个相关周期需要关注：限制期（一般为一或两年），第一个行权期、第二个行权期等。行权期一般为三到六年不等，即投资周期可能长达八年之久。但绝大多数收益都集中在**前两个投资周期**中：
- 第一段：股权激励的限制期（实施日至第一个行权日）
- 第二段：第一个行权期（行权日后约1年）

**第一个买入点**：首次实施公告后（规避股价蛰伏期）。这个阶段股价上涨动力源自高管做高公司业绩，达到行权条件。

**第二个买入点**：第一个行权时刻附近（约270-280日）。激励对象通过一年努力达到行权条件，真正买入股票，随后需要做的就是推高公司股价，等待股票解禁卖出套现。投资者在这个时点参与进去便能够分享到这段收益。

随后时间中超额收益表现较差，原因是：当前A股市场上已经达到两年或以上行权期的股票数量较少；后续行权期的重要性相较第一个有所下降，如同边际效应递减过程，激励作用不断衰退。

#### 1.2 短线操作投资周期分析

以40个交易日（即2个月）作为持有期，对所有买入时点遍历。两个可以参与的买入点：
1. 首次实施公告后（规避股价蛰伏期）
2. 行权股票能够上市流通前2个月左右（第一个行权期对应的解锁位置前约40日）。这段行情捕捉的就是激励对象在解锁日即将到达时所做的最终"冲刺"，一旦股票解锁，激励对象获得的奖励便可兑现。

#### 1.3 两个买点的比较

针对同一只股票，检验在两个不同时点进入后，能够获取的超额收益。总共52个完整样本数据，发现第二个投资周期能够战胜第一个投资周期的胜率仅为51.9%。两个阶段超额收益相减，平均也在零值附近。这说明对于个股而言，两个投资时点都是非常好的参与时机。

### 2. 股权激励行权条件及业绩基准分析

#### 2.1 期权类激励行权条件限制的影响分析

行权条件的限制主要集中在以下财务数据上：
- a. 上市公司行权前一个财务年的加权ROE
- b. 扣除非经常性损益后的ROE
- c. 净利润增长率
- d. 扣除非经常性损益后的净利润增长率
- e. 主营业务增长率
- f. 研发费用增长率
- g. 每股收益、每股收益增长率

前五个财务指标出现概率极高，而研发费用和每股收益的相关数据出现频率相对较低。

**增长率类指标打分**：
- ≤20%：1分
- 20%-30%：2分
- >30%：3分

**ROE绝对打分**：
- [5%,10%]：1分
- [10%,15%]：2分
- >15%：3分

**ROE相对打分**：
- >业绩基准年份ROE：1分（严苛）
- <业绩基准年份ROE的一半：-1分（过于宽松）
- 其他：0分（正常）

**结论**：
- 绝对打分法对于识别行权条件过于宽松的股票更为有效（得分≤1分），该类股票的第一个投资周期应该予以规避。但其对于行权条件严格（得分高）的股票，识别效果不显著
- 相对打分法对于股票的区分效果更好，后期建议关注行权条件得分>=2分的股票标的。严苛类股票最终能够达到的累计超额收益均值可高达150%，相比宽松类最高点60%是显著超越

#### 2.2 业绩基准年份中的奥秘

如果公司刻意选取了盈利与成长性都表现较差的年份作为基准年份，其行权条件/解禁条件即便设置较高，却只是行权条件严苛的假象。

**基准年份业绩过差的定义**：净利润负增长 & ROE相对前一年有所倒退
**业绩表现较好的定义**：净利润正增长 & ROE相对前一年有所提高

**结论**：基准年份业绩过差的股票组合基本不存在稳定超额收益，一年中的胜率基本都在50%以下，仅在靠近行权日的时候有一波拉升行情；业绩正常的公司，第一个投资周期中超额收益稳定上升，胜率维持在50%之上。历史上已经实施的200多只股票中，仅有15%不到的公司被界定到基准年份有所调整。

#### 2.3 行权条件/业绩基准与投资周期的关联

行权条件和业绩基准这两个要素在第一个投资周期中（即第一个行权日/解禁日前一年）对于股票的筛选效果更突出，而第二个投资周期之后，股价走势都呈现大概率向上趋势，尽管超额收益幅度有所差异。

原因：两段投资周期股价上涨的逻辑有所区别。第一个周期中，参与的是高管令股权激励生效或是能否最终实施的投资逻辑。首要任务是使得股权激励生效，其次才是价格有效。如果首要目标无法达成，激励则无意义可言。第二个周期，参与的是高管得到激励股票之后，希望做高股价，从而以高回报退出的逻辑。这个阶段激励对象都被现金收益这个逻辑共同驱动，行权条件上的限制已经不是关注重点。

### 3. 公司股价跌破行权价后的绝对收益机会

考察标的限定在有行权价/股东转让价格的激励类型。所有实施数据中，投资活跃期（期权第一个行权日期/股票第一个解禁日的前一年至第一个行权日/解禁日）有跌破行权价这一条件被触发的公司共有138家。

以跌破行权价的第一日作为买入点，动态考察买入后每个时间点上的收益：
- 能够取得绝对收益的概率高达92.75%
- 绝对收益大于10%的概率，63%的股票能够实现

**策略构建**：
- 买入点：当投资活跃期内观测到当日均价跌破行权价超过5%，买入
- 持有期：持有到第一个行权期所在时点
- 加权方式：股票之间采用等权重加权

策略至2006年年底以来累计净值达到5，主要收益都在2010年以前贡献。2010年之后策略保持震荡走势，没有贡献绝对收益。这说明价格回补现象依然无法完全摆脱系统性风险。策略能够战胜市场，可构建对冲组合参与。但作为纯多头绝对收益策略（即不采用期货对冲），是否要参与这一机会仍然需要仔细斟酌。

### 4. 结论与策略指数展示

1. 事件投资周期较长，股价上涨逻辑来自公司股东刺激高管推进长远发展，这个成长过程一般需要较长时间才能逐渐呈现
2. 股票超额收益集中在两个阶段反应：实施日至第一个行权日（约1年），以及第一个行权日后的一年
3. 对于长期投资者，建议持有期一年，第一个超额收益时段买入点为首次实施公告后；第二个买入点为行权日附近
4. 建议以2个月作为换手频率。长期策略年化收益45.48%，短期策略年化收益49.28%，收益相当
5. 行权条件设置较为严格的股票，在第一个投资周期中表现大概率强于容易行权的股票。条件严格与否的标准，采用财务数据相对比较法更为有效
6. 股票在第一次行权之前如果跌破行权价，存在着价格回补形成的绝对收益机会，但单纯通过股票多头投资依然难以完全摆脱系统风险，需要借助期货做空工具

## FORMULAS_AND_ALGOS

### 两个投资周期
```
第一周期：实施公告日 → 第一个行权日/解禁日（约1年）
第二周期：第一个行权日 → 第二个行权日/解锁日（约1年）
```

### 行权条件绝对打分
```
增长率：<=20%→1分，20-30%→2分，>30%→3分
ROE绝对：[5%,10%]→1分，[10%,15%]→2分，>15%→3分
总分加总，横向比较
```

### 行权条件相对打分
```
ROE/扣非ROE > 基准年份ROE：+1分（严苛）
ROE/扣非ROE < 基准年份ROE/2：-1分（宽松）
其他：0分（正常）

增长率：对比基准年份是否要求超越当年水平
```

### 基准年份判定
```
过差：基准年净利润负增长 & ROE同比倒退
正常：基准年净利润正增长 & ROE同比提高
```

### 跌破行权价策略
```
买入点：当日均价 < 行权价 × 0.95（跌破超过5%）
持有期：至第一个行权期/解禁日
加权：等权重
适用：138家历史样本，92.75%概率收益>0，63%概率收益>10%
```

### 策略指数构建
```
短期策略：实施公告后买入，持有40个交易日
长期策略：实施公告后买入，持有250个交易日；或行权日附近买入，持有250个交易日
对冲策略：短期策略多头 + 沪深300空头
```

### 适用条件
- 首次实施公告后买入（规避蛰伏期）
- 关注行权条件严格（相对打分>=2）且基准年份正常的公司
- 第一周期投资重点看行权条件和业绩基准
- 第二周期投资无需过度关注行权条件
- 跌破行权价>5%时存在回补机会（需对冲系统风险）
- 适用于上涨市（对冲后年化约43.6%）

### 失效条件
- 2010年后纯多头跌破行权价策略震荡（无绝对收益）
- 基准年份刻意选差的股票第一周期表现差
- 行权条件过于宽松（绝对打分<=1）的股票第一周期应规避
- 2011年策略相对沪深300震荡（风格因素，70%激励股票为小盘股）
- 2010年后小盘股风格使得策略难以战胜沪深300（但相对中小板综指仍跑赢）
- 需融资融券/期货工具实现绝对收益
