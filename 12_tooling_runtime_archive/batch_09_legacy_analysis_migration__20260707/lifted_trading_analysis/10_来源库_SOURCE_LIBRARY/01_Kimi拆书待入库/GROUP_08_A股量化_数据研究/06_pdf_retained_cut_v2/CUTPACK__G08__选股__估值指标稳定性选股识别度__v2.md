## FULL_TEXT

### 摘要

本文研究了行业内部股票估值指标的稳定性，以及估值指标在不同行业内的选股识别度。核心结论：

1. **PE和PB具有很好的稳定性**：在各行业中，和毛利率指标类似，股票估值水平在行业中的相对位置会保持一段时间，即高估值或是低估值股票依然会维持这种估值风格，很少发生较大的变动。

2. **估值指标不是普遍适用的行业选股指标**：观察近一年不同估值股票的平均收益表现，估值指标的选股识别度在不同行业中不尽相同，有些有效有些无效，而PE、PB的选股能力也有差异，估值与收益的相关性方向亦存在区别。

3. **长期低估有超额收益**：若不考虑市场环境的影响，观察较长时间的历史表现，行业内低估股票相对高估股票确实存在着一定的超额收益。尽管从短期来看，在一些行业中，估值指标并不具备较好的选股能力。这对价值股的长期投资价值予以肯定。

4. **行业特异性**：
   - 在机械、汽车与零配件、旅游、商贸、煤炭、食品这些行业中，无论从PE或者PB的角度来看，低估股票都具有相对较好的投资价值
   - 估值指标在建筑行业的历史上，并没有表现出优秀的择股能力，但最近值得关注快速崛起的高PB股票
   - 金融行业中，估值指标对于选股基本无效；地产行业中，估值指标虽然在历史上表现优异，但自09年开始，不同估值组合的净值曲线和行业走势基本持平
   - 在个别行业中，超额收益对于一种估值指标的敏感性会明显强于另一种：汽车与零配件和旅游行业中，PB非常显著具有更卓越的选股识别度；家电行业中，仅PE有效；传媒行业中，仅PB有效

### 1. A股上市公司估值指标的稳定性

采用海通二级行业分类，从2009年8月以来的月度估值数据，剔除st公司以及异常数据（PE、PB为负值或极大值）。按照行业内股票当月末的估值对股票进行排序分档，观察不同档的股票，其估值水平在随后3个月的变化情况。

**结论**：各行业的PE以及PB都和毛利率指标类似，具有很好的稳定性。估值最高即第一档公司，其估值水平在行业中始终维持在较高的位置；而第五档公司，其估值水平也始终会低于行业的平均水平，基本不存在反转的可能。由此来看，股票在行业内的估值水平作为它的一种风格，不会在短时期内发生大的变化。

### 2. 估值指标近期的行业内选股识别度

观察最近一年，高估值以及低估值股票在不同行业内的平均收益对比。

**主要规律**：
1. 在化工、造纸、机械、农业这几个行业中，两种估值指标的表现都差强人意，其所区分出的不同档股票，在最近一年中，从平均收益来看，并没有体现出较大的差异。
2. 单从PE指标来看，在商贸、食品、纺织、家电、汽车与零配件这几个大消费类行业，PE指标相对于股票收益具有比较好的单调性，即高PE股票收益明显弱于低PE股票收益。而PB指标与股票收益存在明显正向关系的行业主要有煤炭、信息设备、旅游、汽车与零配件等。
3. 在强周期行业譬如交运、建筑工程、有色和建材中，在最近一年，高估值的股票相对于低估股票，往往具有比较好的超额收益。
4. 在两大权重板块金融和地产行业中，估值指标的选股识别度并不明显。在金融板块中低PB组合表现良好的抗跌性，这可能与市场环境有一定的关系。房地产调控和流动性收缩的双重打压已经让金融股和地产股萎靡了近一年，在政策的系统性风险下，估值水平跟投资收益的关联度被削弱。

### 3. 估值指标历史上的选股识别度表现

在海通二级行业分类中，从2003年5月开始，根据每个月末的最新估值指标构建行业内高PE、低PE、高PB、低PB组合，分别为PE最高20%的股票组合，PE最低20%的股票组合，PB最高20%组合，PB最低20%组合。PE以及PB指标的更新，都采用实际所能够取得的最新的财报数据进行计算。将组合内的样本股按照流通市值加权，月度调整组合样本。

**高低估值组合的收益差分布**：
- 从整体历史上观察估值指标的选股作用。将所构造的低PE组合收益减去高PE组合收益，低PB组合收益减高PB组合收益，把不同时间点上的这些收益差作为数据集进行统计。
- 从较长的历史表现观察，（低估值-高估值）的收益分布，存在着右偏现象，即低估股票存在着正向超额收益。在机械、商贸、汽车、旅游等行业中，都明显看到了股票收益差分布的右偏现象。
- 在交运和有色中，虽然高估股票近期表现较好，但历史分布图和前面几个行业并无差异，即低估股票仍然能够大概率战胜高估股票。

**高低估值组合的累计收益表现**：
1. 化工和造纸：无论估值指标在历史上的选股作用如何，从近期来看，PE和PB都不是很好的选股指标。高低估值组合都没有获取比较明显的超额收益，走势较为平缓。
2. 机械、汽车与零配件、旅游、商贸、煤炭、食品：低PE和低PB的股票组合在近期都明显的战胜了行业指数，估值指标在这些行业中具有良好的选股识别度。有色行业的高估值股票在最近几个月内具有较好的超额收益，而低估值股票比较疲软，但最近一个月低估值股票快速拉升，迎头赶上。
3. 汽车与零配件和旅游服务：尽管高低PE组合的强弱曲线拉开了一定差距，但PB指标明显超越了PE的选股能力。
4. 传媒和家电：传媒行业中，PE指标始终没有比较好的识别度，而低PB组合获得了超额收益。在家用电器与器具行业中，PB指标则不是好的选股因子，低PE组合的累计净值始终具有较强的走势。
5. 建筑工程：历史上不同估值的组合走势都没有拉开明显差距，但最近几个月，高PB的组合出现了强势上涨的态势，建议近期关注这种风格的股票。
6. 金融和地产：金融行业在整个历史上估值指标都没有展现出一定的选股识别度。地产行业中，估值指标在历史上的表现相当出色，但从09年5月以来，估值的选股识别度明显减弱，高低组合的净值走势和行业指数基本持平。

### 4. 主要结论

估值水平作为股票的一种风格，具有较好的稳定性，不会在短时间内发生大的变化。从长期来看，低估股票具有战胜高估股票的能力，存在着一定的超额收益。但当时间窗口较短时，随着市场风格的不断变化，估值指标并不是始终有效的选股指标。

就目前的市场环境，发现：
1. 在机械、汽车与零配件、旅游、商贸、煤炭、食品这些行业中，无论从PE或者PB的角度来看，低估股票都具有相对较好的投资价值
2. 在汽车和旅游行业中，PB具有更卓越的选股识别度
3. 有些行业则只对某种估值指标具有敏感性：家用电器中，只有PE对择股有效；而在传媒中，PB始终优于PE指标
4. 估值指标在建筑行业的历史上，并没有表现出优秀的择股能力，但最近值得关注快速崛起的高PB股票
5. 金融行业中，估值指标对于选股基本无效；地产行业中，估值指标虽然在历史上表现优异，但自09年开始，失去了这种选股能力

## FORMULAS_AND_ALGOS

### 估值指标计算
```
PE = 总市值 / 净利润（TTM）
PB = 总市值 / 净资产（最新财报）
```

### 行业内分档
```
1. 行业内按PE或PB排序
2. 分为5档，每档20%
3. 第1档=最高20%（高估值），第5档=最低20%（低估值）
```

### 选股组合构建
```
1. 月末获取最新估值数据（基于最新财报）
2. 行业内分档
3. 选取高PE/PB组合（Top20%）或低PE/PB组合（Bottom20%）
4. 组合内按流通市值加权
5. 月度调仓
6. 与行业指数比较净值走势
```

### 适用条件
- 行业内比较（不可跨行业直接比较PE/PB绝对值）
- 月度调仓频率
- 需最新财报数据（PE用TTM，PB用最新季报）
- 适用于消费、制造类行业
- 长期持有（低估组合需时间体现超额收益）

### 失效条件
- 金融、地产行业（政策系统性风险削弱估值关联）
- 强周期行业近期可能高估值表现更好（风格切换）
- 市场短期风格不利于价值股时（如09年10月后）
- 财报数据延迟或异常值未处理
- 单一估值指标在部分行业失效（需PE/PB结合）
