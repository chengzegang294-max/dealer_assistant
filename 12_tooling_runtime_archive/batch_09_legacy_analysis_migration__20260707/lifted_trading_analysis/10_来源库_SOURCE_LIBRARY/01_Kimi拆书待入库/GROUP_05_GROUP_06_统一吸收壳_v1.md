# GROUP_05 + GROUP_06 统一吸收壳 v1

## 目的

- 把 `GROUP_05` 的状态模板语言，与 `GROUP_06` 的对象定义语言，合并成一个后续可复用的吸收壳。
- 当前用途不是直接编码，而是给后续拆书/来源吸收提供统一章节结构。

## 壳结构

### 1. 对象层（Objects）

- 适用来源：
  - `GROUP_06`
  - 后续任何 `Market Profile / 结构对象 / 价格分布对象` 书稿
- 统一写法：
  - 概念
  - 最小可实现定义
  - 输入数据要求
  - 输出对象
  - 当前仓库映射
- 首批对象：
  - `Initial Balance`
  - `Value Area`
  - `POC`
  - `Balance vs Imbalance`
  - `Day Type`

### 2. 状态层（States）

- 适用来源：
  - `GROUP_05`
  - 后续任何“趋势/周期/风险/执行”类方法论书稿
- 统一写法：
  - 定义句
  - 可观测证据
  - 可证伪检验
  - 当前角色（解释层/模板层/候选层）
- 首批状态：
  - `Trend Existence`
  - `Breakout Validity`
  - `Market Cycle Phase`
  - `Volatility Regime`
  - `Transaction Cost Load`
  - `Liquidity Adequacy`

### 3. 护栏层（Guardrails）

- 统一写法：
  - 当前不要直接字段化的原因
  - 当前不要直接硬门控的原因
  - 需要什么额外数据/源码/样本
- 首批护栏：
  - 不把书稿主观叙述直接当字段
  - 不把 Kimi 稿直接当原书原文
  - 先做模板/对象定义，再决定是否重开实现

### 4. 仓库映射层（Repo Mapping）

- 统一写法：
  - 更接近 `N01`
  - 更接近 `N02`
  - 更接近 `N03`
  - 更接近 `研究护栏/解释层`
- 当前首批映射：
  - `GROUP_05`：
    - 更接近 `解释层 / 状态模板 / 研究护栏`
  - `GROUP_06`：
    - 更接近 `N02` 后续对象层
    - 次级关联 `N03` 定义层
