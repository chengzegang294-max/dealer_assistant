### 1.2 每步输入/输出详述

#### Step 1: Alpha 模型

| 项目 | 内容 |
|------|------|
| **功能** | 预测股票相对收益，生成交叉截面收益排序或预期收益向量 |
| **输入** | 因子数据（Value/Momentum/Quality/Growth）、价格数据、基本面数据、宏观数据 |
| **输出** | Alpha 向量 α = (α₁, α₂, ..., α_N)'，或标准化 z-score |
| **关键指标** | IC (Information Coefficient) = corr(α, r realized)，衡量预测能力 |
| **来源** | QHS Ch.4-5 (p.81-153); N Ch.3 (p.42-88); T (因子定义与回测) |

**核心公式 —  Fundamental Law of Active Management (Grinold & Kahn, 2000)**:

```
IR = IC × √N

其中：
  IR = Information Ratio (年化超额收益 / 跟踪误差)
  IC = 平均信息系数（预测与实现收益的横截面相关系数）
  N = 独立预测次数（横截面股票数 × 年换手次数）
```

- **QHS 扩展** (Ch.4, p.94-100): 多期框架下，IC 的标准差 σ_IC 对 ex-post tracking error 有重要影响
- **Tortoriello 补充**: 单因子 IC 需做衰减调整（信息衰减半衰期通常为 1-3 个月）

---

#### Step 2: 风险模型

| 项目 | 内容 |
|------|------|
| **功能** | 估计股票收益协方差结构，分解系统性风险与特异风险 |
| **输入** | 历史收益序列、因子暴露矩阵、行业分类、市值数据 |
| **输出** | 协方差矩阵 Σ = B·Σ_f·B' + Σ_ε (多因子模型分解) |
| **关键指标** | Factor exposure, specific risk, VaR, tracking error |
| **来源** | QHS Ch.3 (p.53-76); N Ch.4 (p.91-106) |

**三种风险模型架构**:

1. **宏观因子模型** (Ross & Roll APT): 用宏观经济变量（利率、通胀、油价、信用利差）解释收益
2. **基本面因子模型** (BARRA 型): 用可观察的股票特征（行业、市值、B/P、动量）作为因子
3. **统计因子模型** (PCA): 从历史收益中提取主成分，无需预设因子含义

**来源**: QHS Ch.3 (p.54-64); N Ch.4 (p.96-106)

---

#### Step 3: 约束条件

| 项目 | 内容 |
|------|------|
| **功能** | 反映投资政策、监管要求、客户限制、风控底线 |
| **输入** | 投资委托书、监管规定、内部风控政策 |
| **输出** | 约束矩阵/向量，供优化器使用 |
| **来源** | QHS Ch.11 (p.357-394); N Ch.4 (p.93-96) |

**常见约束分类**:

| 约束类型 | 数学表达 | 典型值 | 来源 |
|---------|---------|-------|------|
| 预算约束 | Σwᵢ = 1 | 100% 投资 | QHS Ch.2 (p.28) |
| 做空限制 | wᵢ ≥ 0 | 不允许做空 | QHS Ch.11 (p.374) |
| 个股权重上限 | wᵢ ≤ w_max | 3-10% | N Ch.4 (p.93) |
| 行业中性 | Σ_{i∈sector} wᵢ = benchmark | 0 active exposure | QHS Ch.11 (p.359) |
| 因子暴露限制 | |B·w - B·b| ≤ δ | ±0.5 std | QHS Ch.11 (p.363) |
| Beta 中性 | β_p = 0 | market-neutral | N Ch.4 (p.98) |
| 换手率限制 | Σ｜wᵢ^{new} - wᵢ^{old}｜ ≤ T_max | 20-100%/月 | QHS Ch.8 (p.233) |
| 组合杠杆 | Σ｜wᵢ｜ ≤ L_max | 2-4x | N Ch.4 (p.95) |

---

#### Step 4: 交易成本模型

| 项目 | 内容 |
|------|------|
| **功能** | 估计从当前组合调整到目标组合所需的交易成本 |
| **输入** | 订单规模、股票流动性（日均成交量、买卖价差）、历史冲击成本 |
| **输出** | 交易成本函数 TC(Δw)，通常包含固定成本 + 线性成本 + 二次成本 |
| **来源** | QHS Ch.12 (p.395-434); N Ch.5 (p.109-124) |

**交易成本三层分解** (N Ch.5, p.110-117):

```
TC = Commissions + Slippage + Market Impact

Commission:  佣金和费用（每股固定，通常 $0.001-0.01/股）
Slippage:    决策价到执行价的偏差（时间延迟 × 波动率）
Market Impact: 订单本身引起的价格不利变动 ≈ η × σ × (Q/V)^γ

其中：
  η = 冲击系数（股票特定）
  σ = 日波动率
  Q = 订单量
  V = 日均成交量
  γ ≈ 0.5-1.0（通常为 0.6）
```

**四种交易成本模型复杂度** (N Ch.5, p.117-124):

| 模型 | 公式 | 适用场景 |
|------|------|---------|
| 常数模型 | TC = c | 小额固定规模交易 |
| 线性模型 | TC = c × Q | 中等规模，流动性好 |
| 分段线性 | TC = c₁×Q (Q<Q₁); c₂×Q (Q≥Q₁) | 流动性有阈值效应 |
| 二次型 | TC = c₁×Q + c₂×Q² | 大额交易，需精确冲击估计 |

---

#### Step 5: 投资组合构建（优化器）

| 项目 | 内容 |
|------|------|
| **功能** | 综合 α、风险、约束、成本，求解最优权重 |
| **输入** | α向量, Σ矩阵, 约束集, TC函数, 风险厌恶系数 λ |
| **输出** | 目标权重 w* |
| **来源** | QHS Ch.2 (p.23-52), Ch.7 (p.195-229), Ch.12 (p.395-434) |

**核心优化问题** (QHS Ch.2, p.28-38):

```
maximize:  α'w - λ·w'Σw - TC(w - w_current)
subject to:
  1'w = 1           (budget constraint)
  w ≥ 0             (no shorting, optional)
  Aw ≤ b            (linear inequality constraints)
  |w_i| ≤ w_max     (position limits)
  Σ|w_i^{new} - w_i^{old}| ≤ T_max  (turnover constraint)
```

**解析解** (无约束情况, QHS Ch.2, p.33):

```
w* = (1/2λ) · Σ^{-1} · α

特例：当 Σ 为对角矩阵（股票间无相关）时：
w*_i = α_i / (2λ · σ_i²)
→ 权重 ∝ 预期超额收益，∝ 1/方差
```

---

#### Step 6: 再平衡与执行

| 项目 | 内容 |
|------|------|
| **功能** | 以最小成本将当前组合调整至目标组合 |
| **输入** | w*, w_current, 市场流动性, 执行紧迫性 |
| **输出** | 执行订单序列（时间、规模、价格限制） |
| **来源** | QHS Ch.12 (p.414-434); N Ch.7 (p.154-168) |

**再平衡频率决策** (QHS Ch.8, p.233-279):

```
最优再平衡频率 ↑ 当：
  • Alpha 衰减速度快（信息半衰期短）
  • 交易成本较低（流动性好）
  • 预测 IC 较高（信号质量高）

最优再平衡频率 ↓ 当：
  • 交易成本占预期 alpha 比重大
  • 组合漂移速度慢（低波动环境）
  • 约束严格（换手率上限低）
```

---

#### Step 7: 组合监控

| 项目 | 内容 |
|------|------|
| **功能** | 持续监控组合风险暴露、绩效归因、异常检测 |
| **输入** | 组合权重、实际收益、因子收益、基准收益 |
| **输出** | 风险报告、归因分析、预警信号 |
| **来源** | QHS Ch.1 (p.8-10); N Ch.10 (p.219-248) |

## 2) 风险模型与优化：关键概念与公式

### 2.1 协方差矩阵估计

#### FORMULA-01: 样本协方差矩阵（最大似然估计）

```
Σ̂ = (1/T) Σ_{t=1}^{T} (r_t - μ̂)(r_t - μ̂)'

其中：
  r_t = N×1 股票收益向量（时期 t）
  μ̂ = (1/T) Σ r_t  = 样本均值向量
  T = 样本期长度
  N = 股票数量
```

- **使用条件**: T >> N（样本量远大于维度），否则矩阵不满秩或病态
- **常见陷阱**:
  - 当 N > T 时，Σ̂ 奇异（不可逆），无法用于优化
  - 样本协方差对异常值敏感
  - 估计误差大：对 N 只股票需估计 N(N+1)/2 个参数
- **改进**: Ledoit-Wolf 压缩估计（向恒等相关矩阵收缩）
- **来源**: QHS Ch.2 (p.24-28); N Ch.4 (p.96-98)

---

#### FORMULA-02: 多因子风险模型（BARRA 型）

```
Σ = B · Σ_f · B' + Σ_ε

其中：
  B      = N×K 因子暴露矩阵（每只股票在 K 个因子上的暴露）
  Σ_f    = K×K 因子收益协方差矩阵
  Σ_ε    = N×N 对角特异收益方差矩阵（假设特异收益互不相关）
  K      = 因子数量（通常 20-80）
  N      = 股票数量（通常 500-3000）
```

- **优点**: 参数数量从 O(N²) 降至 O(N·K + K²)，大幅降低估计误差
- **因子暴露 B 的获取**: 
  - 行业因子：0/1 哑变量
  - 风格因子：标准化后的股票特征值（如 z-score of B/P）
- **来源**: QHS Ch.3 (p.54-64)

---

#### FORMULA-03: 因子收益估计（横截面回归）

```
r_t = B_t · f_t + ε_t

f̂_t = (B_t' · W · B_t)^{-1} · B_t' · W · r_t

其中：
  r_t    = N×1 股票收益向量
  B_t    = N×K 因子暴露矩阵（时期 t）
  f_t    = K×1 因子收益向量（待估计）
  W      = N×N 权重矩阵（通常为市值加权对角阵）
  ε_t    = N×1 特异收益向量
```

- **每时期独立回归**: 对每个 t，用该期横截面数据估计 f_t
- **WLS vs OLS**: WLS（市值加权）对大股票更重视，减少小股票噪声影响
- **来源**: QHS Ch.3 (p.56-60)

---

### 2.2 跟踪误差（Tracking Error）

#### FORMULA-04: Ex-Ante Tracking Error（预测跟踪误差）

```
TE = √(w_a' · Σ · w_a) = √[(w_p - w_b)' · Σ · (w_p - w_b)]

其中：
  w_p = 组合权重向量
  w_b = 基准权重向量
  w_a = w_p - w_b = 主动权重（active weights）
  Σ   = 股票收益协方差矩阵
```

- **与 IR 的关系**: IR = α / TE（信息比率 = 预期主动收益 / 跟踪误差）
- **典型目标**: 增强型指数：TE = 2-4%；市场中性：TE = 4-8%（对现金基准）
- **来源**: QHS Ch.2 (p.38-45); QHS Ch.4 (p.81-89)

---

#### FORMULA-05: Ex-Post Tracking Error（实现跟踪误差）

```
TE_realized = std(r_p - r_b) × √252

其中 r_p - r_b = 组合日收益 - 基准日收益
```

- **注意**: Ex-ante TE 与 Ex-post TE 常不一致，因 Σ 估计有偏
- **QHS 观点** (Ch.4): IC 的波动 σ_IC 会导致 ex-post TE 系统性大于 ex-ante TE
- **来源**: QHS Ch.4 (p.94-100)

---

### 2.3 风险贡献与风险预算

#### FORMULA-06: Marginal Contribution to Risk (MCTR)

```
MCTR_i = ∂σ_p/∂w_i = (Σ · w)_i / σ_p

其中 σ_p = √(w' · Σ · w) = 组合总风险
```

#### FORMULA-07: Absolute Contribution to Risk (ACTR)

```
ACTR_i = w_i × MCTR_i = w_i × (Σ · w)_i / σ_p

验证: Σ_i ACTR_i = σ_p（各成分贡献之和 = 总风险）
```

#### FORMULA-08: Percent Contribution to Risk (PCTR)

```
PCTR_i = ACTR_i / σ_p = w_i × (Σ · w)_i / (w' · Σ · w)

→ 风险平价目标: PCTR_i = 1/N（每个成分等风险贡献）
```

- **用途**: 识别组合中"风险集中度"过高的头寸
- **风险预算应用**: 设定每个因子/行业/个股的最大 PCTR，作为优化约束
- **来源**: QHS Ch.3 (p.72-76)

---

### 2.4 均值-方差优化核心公式

#### FORMULA-09: 有效前沿（Efficient Frontier）

```
对给定目标收益 μ*: 
minimize:  w'Σw
s.t.:     w'μ = μ*
          1'w = 1
          Aw ≤ b

解析解（拉格朗日乘子法）:
w* = Σ^{-1} · [μ, 1, A'] · ([μ,1,A']' · Σ^{-1} · [μ,1,A'])^{-1} · [μ*, 1, b']'
```

- **来源**: QHS Ch.2 (p.28-38); Markowitz (1952)

---

#### FORMULA-10: 最大夏普比率组合（Tangency Portfolio）

```
w* = Σ^{-1} · (μ - r_f · 1) / [1' · Σ^{-1} · (μ - r_f · 1)]

Sharpe Ratio = (μ_p - r_f) / σ_p = √[(μ - r_f·1)' · Σ^{-1} · (μ - r_f·1)]
```

- **注意**: 对 μ 和 Σ 的估计误差极其敏感，小样本来样本夏普比严重高估
- **来源**: QHS Ch.2 (p.38)

---

#### FORMULA-11: 布莱克-利特曼模型（Black-Litterman）

```
后验预期收益:  μ* = [(τΣ)^{-1} + P'Ω^{-1}P]^{-1} · [(τΣ)^{-1}Π + P'Ω^{-1}Q]

其中：
  Π     = 均衡超额收益（逆向优化: Π = λΣw_mkt）
  τ     = 缩放常数（通常 0.01-0.05）
  P     = K×N 观点矩阵（哪些资产有观点）
  Q     = K×1 观点收益向量
  Ω     = K×K 观点置信度对角矩阵
```

- **解决的核心问题**: 均值-方差优化对输入估计误差过度敏感
- **先验**: 市场均衡权重作为先验，减少估计偏差
- **后验**: 将投资者观点以贝叶斯方式融入
- **来源**: QHS Ch.7; Black & Litterman (1990, 1992)

---

### 2.5 换手率最优控制

#### FORMULA-12: 换手率约束下的最优组合（QHS 框架）

```
maximize:  α'w - λ·w'Σw - c·Σ|w_i - w_i^{current}|
subject to: 所有常规约束

其中 c = 单位换手率成本（双向）
```

- **等效形式**: 引入辅助变量 w⁺, w⁻ ≥ 0，将绝对值线性化
- **换手惩罚对 Alpha 的衰减** (QHS Ch.8, p.257-267):
  
```
Effective Alpha = α · (1 - e^{-t/τ}) / (t/τ)

其中：
  t = 再平衡间隔
  τ = Alpha 信息半衰期
  
→ 再平衡越频繁（t 小），有效 Alpha 越高，但交易成本越大
→ 存在最优再平衡频率使净收益最大化
```

- **来源**: QHS Ch.8 (p.233-279)

---

### 2.6 约束对 IR 的影响

#### FORMULA-13: Transfer Coefficient (Clarke, de Silva & Thorley, 2002)

```
IR_constrained = TC × IR_unconstrained = TC × IC × √N

TC = corr(w_unconstrained, w_constrained) ∈ [0, 1]

常见约束的 TC 经验值：
  - 无约束多空:       TC ≈ 1.0
  - 行业中性:         TC ≈ 0.8
  - 行业+市值中性:    TC ≈ 0.6
  - Long-only:       TC ≈ 0.4-0.6
  - Long-only+多约束: TC ≈ 0.2-0.4
```

- **TC 的经济含义**: 约束导致"信息损失"的比例
- **来源**: QHS Ch.11 (p.379-389); Clarke et al. (2002)

---

### 2.7 多因子 Alpha 模型组合

#### FORMULA-14: 复合 IC 与最优因子权重

```
对 K 个因子，每个因子 k 有 IC_k 和 σ_IC_k：

Optimal Factor Weight:  z_k ∝ IC_k / σ_IC_k²

Composite IC = √(Σ_k Σ_j z_k z_j ρ_{kj} IC_k IC_j)

当因子不相关时: Composite IC = √(Σ_k z_k² · IC_k²)
```

- **核心洞见**: 应给"高IC、低波动"的因子更高权重
- **因子正交化**: 先用回归去除因子间共线性，再独立估计IC
- **来源**: QHS Ch.7 (p.195-229); Sorensen et al. (2004)
