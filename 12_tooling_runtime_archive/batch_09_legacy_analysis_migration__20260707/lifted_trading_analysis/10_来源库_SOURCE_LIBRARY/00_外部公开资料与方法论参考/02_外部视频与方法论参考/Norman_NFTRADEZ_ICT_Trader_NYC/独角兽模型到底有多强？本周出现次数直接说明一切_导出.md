- 2. **[交易时必须死磕“完美折价区”吗？](https://bibigpt.co/search?q=%E4%BA%A4%E6%98%93%E6%97%B6%E5%BF%85%E9%A1%BB%E6%AD%BB%E7%A3%95%E2%80%9C%E5%AE%8C%E7%BE%8E%E6%8A%98%E4%BB%B7%E5%8C%BA%E2%80%9D%E5%90%97%EF%BC%9F)**
  - 不一定。如果在高级别结构中，左侧已经有足够的PD Array（如订单块或破坏块）提供支撑，价格往往会产生强烈反应而不一定会回撤到极致的折价区。有经验的交易员会根据即时的市场结构响应进行判断，而不是过度执着于等待所谓完美的入场点位。


### 术语解释
- **FVG (Fair Value Gap)**：指市场价格在短时间内单边剧烈波动，导致多空未能实现平衡而留下的“价格失衡”缺口，常作为机构入场与寻找流动性的参考点。
- **PD Array (Premium Discount Array)**：指价格在溢价区或折价区内，机构用来寻找支撑或阻力的关键参考阵列，涵盖了FVG、订单块（OB）、Breaker等概念。
- **流动性清扫 (Liquidity Sweep)**：指机构利用大资金通过短暂突破关键的前高或前低，触发散户止损盘以获取流动性，从而为后续反向运行积累筹码的操盘手法。
- **结构破坏 (Market Structure Shift)**：指价格改变了原有的高低点形态，标志着市场趋势可能发生反转，这是确认机构意图、构建独角兽模型的关键信号。
