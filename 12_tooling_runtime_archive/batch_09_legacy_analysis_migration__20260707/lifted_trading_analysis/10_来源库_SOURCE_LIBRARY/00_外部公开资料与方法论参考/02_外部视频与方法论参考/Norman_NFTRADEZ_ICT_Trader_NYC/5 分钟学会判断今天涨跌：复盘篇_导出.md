## 摘要
这段视频从机构算法交易的角度，深入浅出地讲解了价格波动的底层逻辑：即一切行情皆是为了“价格均衡”与“获取流动性”。作者通过结合市场偏见（Bias）与流动性目标（DOL）这两个维度，教会大家如何精准判断市场当前处于“方向统一”的顺势推进阶段，还是处于“方向分歧”的修正博弈阶段。通过这一分析框架，交易者可以构建清晰的“如果……那么……”（If-Then）交易剧本，从而在复杂的价格行为中提高决策的确定性与胜率。


### 亮点
- ⚖️ 价格移动的根本动因只有两个：一是完成价格均衡（Rebalancing），二是扫荡流动性（Liquidity）。
- 📈 当市场偏见（Bias）与流动性目标（DOL）方向完全一致时，市场会持续朝一个方向推进，这是交易者最应优先捕捉的顺势机会。
- 🔍 “方向分歧”通常意味着市场正在进行不同时间框架间的博弈，此时价格往往需要先回补失衡（FVG），再去寻找流动性目标。
- 🧩 市场具有分形特征，判断趋势的关键在于观察价格是否“尊重”当前上涨或下跌结构中最高级别的失衡区域（FVG）。
- 📝 构建交易剧本的核心是“If-Then”逻辑：若价格进入关键FVG并得到尊重则继续顺势，若价格直接穿透该区域则意味着当前结构可能已经失效。

### 思考
1. **[如何判断价格在进入关键失衡区域（FVG）时是“尊重”还是“不尊重”？](https://bibigpt.co/search?q=%E5%A6%82%E4%BD%95%E5%88%A4%E6%96%AD%E4%BB%B7%E6%A0%BC%E5%9C%A8%E8%BF%9B%E5%85%A5%E5%85%B3%E9%94%AE%E5%A4%B1%E8%A1%A1%E5%8C%BA%E5%9F%9F%EF%BC%88FVG%EF%BC%89%E6%97%B6%E6%98%AF%E2%80%9C%E5%B0%8A%E9%87%8D%E2%80%9D%E8%BF%98%E6%98%AF%E2%80%9C%E4%B8%8D%E5%B0%8A%E9%87%8D%E2%80%9D%EF%BC%9F)**
   - 答案：你需要观察更低的时间框架（如1分钟图）。如果价格进入该区域后，表现出支撑/阻力结构反转（Market Structure Shift）或出现了买方/卖方重新掌控市场的信号，即视为“尊重”；若价格毫无阻滞地直接穿透该区域，则视为“不尊重”。
- 2. **[如果日线级别看涨，但在小级别出现了反向的流动性目标，我该怎么办？](https://bibigpt.co/search?q=%E5%A6%82%E6%9E%9C%E6%97%A5%E7%BA%BF%E7%BA%A7%E5%88%AB%E7%9C%8B%E6%B6%A8%EF%BC%8C%E4%BD%86%E5%9C%A8%E5%B0%8F%E7%BA%A7%E5%88%AB%E5%87%BA%E7%8E%B0%E4%BA%86%E5%8F%8D%E5%90%91%E7%9A%84%E6%B5%81%E5%8A%A8%E6%80%A7%E7%9B%AE%E6%A0%87%EF%BC%8C%E6%88%91%E8%AF%A5%E6%80%8E%E4%B9%88%E5%8A%9E%EF%BC%9F)**
   - 答案：这就是典型的“方向分歧”情况。你可以将其视为一个修正阶段，暂时观望，等待价格回归到更高时间框架的FVG中，观察该区域是否有止跌信号。不要逆着日线大趋势强行追空，应等待回调结束、重回大趋势方向时再入场。


### 术语解释
- **FVG (Fair Value Gap)**: 公允价值缺口，指价格未被修复的失衡区域。它是机构资金经常回归测试，并在此寻求支撑或阻力的关键区域。
- **DOL (Draw on Liquidity)**: 流动性目标，即价格预期要前往扫荡止损订单的具体点位，如同市场的“磁铁”，是推动行情发展的核心动力。
- **Bias (市场偏见)**: 交易者对市场大方向的预判，即整体行情是看涨还是看跌。这是制定所有后续交易策略的前提。
- **Liquidity (流动性)**: 指市场中积累的大量止损订单池，通常表现为盘面上的双底、双顶或趋势线高低点，是机构资金入场的“燃料”。
