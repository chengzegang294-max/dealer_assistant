### 亮点

- 📈 高质量拒绝块的形成通常由三根K线构成：第一根进入流动性区域，第二根完成清扫并留下长影线，第三根则确认反向价格传递。

- 2. **[拒绝块和一般的支撑阻力位有什么本质区别？](https://bibigpt.co/search?q=%E6%8B%92%E7%BB%9D%E5%9D%97%E5%92%8C%E4%B8%80%E8%88%AC%E7%9A%84%E6%94%AF%E6%92%91%E9%98%BB%E5%8A%9B%E4%BD%8D%E6%9C%89%E4%BB%80%E4%B9%88%E6%9C%AC%E8%B4%A8%E5%8C%BA%E5%88%AB%EF%BC%9F)**
  - 传统的支撑阻力位通常基于交易者的主观视觉，而拒绝块反映的是机构订单流的真实足迹。它强调的是“清扫流动性”后的价格拒绝行为，具有更强的机构逻辑支撑，因此其入场精度和可靠性通常远高于普通支撑阻力。


### 术语解释
- **拒绝块 (Rejection Block)**: 机构在特定流动性区域通过强力介入，拒绝极端价格，导致价格迅速收回原有区间的价格行为遗迹。
- **流动性清扫 (Liquidity Sweep)**: 市场价格突破前高或前低，触发大量止损单和突破交易单，机构利用这些流动性完成自身大额订单执行的过程。
- **价格位移 (Displacement)**: 在流动性获取后，市场产生快速、强劲的单向运动，证明机构已掌控市场节奏。
- **平衡/不平衡价格 (FVG/Fair Value Gap)**: 市场因订单流不平衡而形成的缺口，常作为判断趋势方向和二次确认入场的重要参考。
