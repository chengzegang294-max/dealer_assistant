# N02 P0 字段落盘草案 v1

## 目标

- 把 N02 第一批最稳的时段/开盘区间字段收成“可准备落盘”的最小合约。
- 当前只覆盖 `P0`，不把 `IB`、`bias`、`acceptance` 等仍有证据缺口的字段强行塞进来。
- 这份草案服务于研究侧/诊断侧字段，不等于完整 ORB 策略实现。

## 适用边界

- 适用于：
  - `session / opening range` 上下文字段
  - 后续 scan / replay / evidence pack 的统一字段名
- 暂不适用于：
  - 收益归因面板
  - 交易结果统计
  - IB acceptance 规则
  - failed ORB 事件

## 当前裁决

- 先落 `P0 / N02`
- 当前优先保留“时段锚点 + OR 锚点 + 首次突破方向”
- `or_break_high / or_break_low / target_trigger_source` 先放到下一批 `P1`

## 口径约束

- `session_id`
  - 推荐枚举：`london` / `new_york` / `asia` / `custom`
  - 不直接把源码配置变量名当标准值
- `session_timezone`
  - 必须显式落盘
  - 不允许默认隐含在环境里
- `opening_range_window_minutes`
  - 当前建议落实际分钟值，不落作者自定义缩写
- `opening_range_high / low / mid / width`
  - `opening_range_defined=0` 时允许为 `na`
  - `opening_range_defined=1` 后应全部可得
- `opening_range_width_pct_open`
  - 仅当 `session_open_price > 0` 时计算
  - 否则记 `na`
- `first_break_direction`
  - 当前只保留 `up/down/none`
  - 不在 P0 阶段混入 `wick/close` 触发源差异
- `width_error_day`
  - 当前先保持布尔结果，不把阈值硬编码进字段名

## 派生顺序

1. 确定 `session_id / session_timezone / opening_range_window_minutes`
2. 记录 `session_open_price`
3. 在 OR 窗口结束后固定：
   - `opening_range_high`
   - `opening_range_low`
   - `opening_range_mid`
   - `opening_range_width`
   - `opening_range_defined=1`
4. 再派生：
   - `opening_range_width_pct_open`
   - `first_break_direction`
   - `width_error_day`

## 空值规则

- 永不为空：
  - `session_id`
  - `session_timezone`
  - `opening_range_window_minutes`
  - `opening_range_defined`
  - `first_break_direction`
  - `width_error_day`
- 条件允许为空：
  - `session_open_price`
  - `opening_range_high`
  - `opening_range_low`
  - `opening_range_mid`
  - `opening_range_width`
  - `opening_range_width_pct_open`
- 条件空值只允许出现在：
  - session 尚未开始
  - OR 尚未完成
  - 数据源缺口

  - 当前主要来自定义文章，不是源码级证据
- `bias / MA bias`
  - 更依赖实现细节与作者风格
