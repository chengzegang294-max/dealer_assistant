# N02 时段/开盘区间结构资料整理说明

## 本目录定位

- 目标：补 `session / opening range / initial balance / time-window context`。
- 角色：给当前主线补时段上下文，而不是新增复杂策略壳。
- 优先收 OHLC + session time 就能跑的资料。

## 已落盘文件

- `opening_range_breakout__joveteo.pine`
  - 可直接审计 opening range 的高低点计算、session、timezone、breakout 标记。
- `README__joveteo_orb.md`
  - 概述功能、参数、推荐时段、统计口径。
- `USER_GUIDE__joveteo_orb.md`
  - 更像操作手册，含 session/timezone 推荐与使用限制。
- `Initial_Balance_Breakout__page_excerpt.md`
  - 定义说明页。
  - 重点补 `IB high/low/range` 与 `2 period acceptance`。
- `N02_字段草案_v1.md`
  - 已把现有来源收成第一版字段草案。
  - 明确拆开 OR 核心字段、IB 条件字段、统计面板越界项。

## 当前判断

- N02 最实用的最小吸收形态不是“整套 ORB 策略复刻”，而是先抽这些结构化字段：
  - opening_range_high / low
  - opening_range_width
  - first_break_direction
  - session_bias
  - london_open / ny_open / custom session window
- 当前下载的 joveteo ORB 资料已经足够支持第一版字段化。
- `Initial_Balance_Breakout__page_excerpt.md` 让 N02 不只停在 ORB，还补进了 IB acceptance 的定义层。
- `N02_字段草案_v1.md` 标明：当前已够做 v1，但仍未收集完全，尤其缺更多 session 样本与 IB 源码级证据。

## 审计提示

- 时区必须单独标记，避免夏令时把结果搞偏。
- 先收 session/time-window 结构，不急着吸收其统计面板和胜率结论。
- 若后续加入 Initial Balance（第一小时）资料，要明确和 5m/15m/30m ORB 分开存放。
