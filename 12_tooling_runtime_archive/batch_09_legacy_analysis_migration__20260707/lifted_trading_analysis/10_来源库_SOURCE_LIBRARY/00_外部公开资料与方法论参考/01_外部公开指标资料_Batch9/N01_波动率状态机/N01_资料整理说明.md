# N01 波动率状态机资料整理说明

## 本目录定位

- 目标：补 `vol regime / squeeze-shock / realized vol` 的公开资料。
- 角色：给当前 FX / index / commodity 1H 主线补“波动环境切换”层。
- 当前不直接把任何单一来源升成 gate；先做定义吸收、同构检测、诊断映射。

## 已落盘文件

- `TTM_Squeeze__Alorse.pine`
  - 最小版 TTM Squeeze 骨架。
  - 核心是 `BB - KC` 的压缩判定和线性回归动量柱。
- `TTM-Squeeze-Pro__vijankush.pine`
  - 多压缩级别版本。
  - 适合观察“低压缩/中压缩/高压缩”的状态离散化。
- `TTM_Squeeze_Pro__TradingView_page_excerpt.md`
  - TradingView 正文摘录。
  - 明确给出 `1.0 / 1.5 / 2.0 ATR` 三档 Keltner 分层和 `green dot = squeeze fired` 口径。
- `AG_Pro_ATR_Compression_Map__page_excerpt.md`
  - TradingView 正文摘录。
  - 重点不在方向，而在 `compression quality` 的评分与状态分类。
- `ATR_Regime_Study__CHE__page_excerpt.md`
  - TradingView 正文摘录。
  - 明确给出 ATR percentile 的五档 regime：Extreme / Elevated / Normal / Calm / Squeeze。
- `README__volscope.md`
  - 偏研究说明。
  - 给出 realized volatility、rolling percentile、forward volatility persistence 的解释。
- `N01_字段草案_v1.md`
  - 已把现有来源收成第一版字段草案。
  - 明确区分 A层可落诊断字段、B层条件字段、C层暂缓内容。

## 当前判断

- 最有价值的不是再收一堆“普通 ATR 波动指标”，而是收：
  - squeeze -> release
  - percentile regime
  - realized volatility persistence
  - vol shock / vol-of-vol
- `TTM_Squeeze__Alorse.pine` 和 `TTM-Squeeze-Pro__vijankush.pine` 可以直接用来抽：
  - squeeze_on/off
  - momentum sign
  - compression strength
- `TTM_Squeeze_Pro__TradingView_page_excerpt.md` 让三档压缩级别和 fired 状态的命名更清楚，适合给 `squeeze_tier` 和 `squeeze_fired` 做枚举解释。
- `AG_Pro_ATR_Compression_Map__page_excerpt.md` 适合补 `compression_quality_score` 这类连续变量，以及 `atr_contraction / range_tightness / noise / containment` 四段拆解。
- `ATR_Regime_Study__CHE__page_excerpt.md` 适合补 `atr_percentile`、`atr_percentile_regime` 与 `extreme/squeeze` 两端状态。
- `README__volscope.md` 更像定义和研究补充，不是直接交易脚本。
- `N01_字段草案_v1.md` 标明：当前已够做 v1，但仍未收集完全，尤其缺部分源码级证据与 shock persistence 资料。

## 审计提示

- 优先检查是否只使用已收盘 bar。
- 若出现“当前 bar 内高低点即时切换状态”的写法，要标记为 intrabar-sensitive。
- 后续如要映射到仓库字段，先走 `DIAG_ONLY`，不要直接替代现有 `sv_regime_code`。
