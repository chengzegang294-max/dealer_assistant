# N01 字段草案 v1

## 定位

- 目标：把已收集的 `vol regime / squeeze / compression quality / ATR percentile` 资料收成可映射字段。
- 适用层级：先用于 `DIAG_ONLY` 或研究侧分桶，不直接替换现有硬 gate。
- 当前结论：N01 已经具备第一版字段草案条件，但**仍未收集完全**。

## 字段分层

- A层：定义较清楚、可先落诊断字段
- B层：有证据但仍需补源码或阈值核验
- C层：只做背景说明，不进当前字段

## A层：可先落盘字段

| field_name | type | 含义 | 当前口径 | 主要来源 |
|---|---|---|---|---|
| `atr_value` | float | 当前 ATR 值 | ATR 默认常见 14，但实现时不写死来源默认值 | GainzAlgo / CHE |
| `atr_baseline_value` | float | ATR 长窗基线 | 常见为 ATR 的长窗均值 | GainzAlgo |
| `atr_ratio` | float | 当前 ATR / 基线 ATR | N01 regime 的主轴变量之一 | GainzAlgo |
| `atr_percentile` | float | ATR 在回看窗口中的历史分位 | 0-100 标准化 | CHE |
| `atr_percentile_regime` | string | ATR percentile 所属分档 | `extreme/elevated/normal/calm/squeeze` | CHE |
| `atr_regime_is_extreme` | int | 是否极端波动 | percentile > 90 可先作默认草案 | CHE |
| `atr_regime_is_squeeze` | int | 是否极低波动压缩 | percentile < 10 可先作默认草案 | CHE |
| `squeeze_is_on` | int | 是否处于 BB inside KC 压缩态 | 压缩开/关二元状态 | TTM 系列 |
| `squeeze_tier` | string | 压缩等级 | Beardy_Fred 版本已补到 `1.0/1.5/2.0 ATR KC` 三档与 `high/medium/low/off` | TTM Pro |
| `squeeze_fired` | int | 是否从压缩转入释放 | Beardy_Fred 版本已补到 `NoSqz and not NoSqz[1]` | TTM Pro |
| `squeeze_momentum_sign` | int | 释放后的动量方向 | 1 / -1 / 0 | TTM 系列 |
| `compression_quality_score` | float | 压缩质量评分 | 连续变量；二次整理稿已补到 `30/30/20/20` 权重与 `62/80` 阈值骨架 | AG Pro |
| `atr_contraction_score` | float | ATR 收缩评分 | 压缩质量子项；对应 AG Pro 四维评分之一 | AG Pro |
| `range_tightness_score` | float | 区间收敛评分 | 压缩质量子项；对应 AG Pro 四维评分之一 | AG Pro |
| `noise_cleanliness_score` | float | 噪音洁净度评分 | 压缩质量子项；对应 AG Pro 四维评分之一 | AG Pro |
| `containment_score` | float | 包含/约束结构评分 | 压缩质量子项；对应 AG Pro 四维评分之一 | AG Pro |

## B层：条件字段

| field_name | type | 当前建议 | 暂不直接固化原因 |
|---|---|---|---|
| `compression_state` | string | 可优先对齐 `Loose/Building/Tight/Mature` | 已有 Kimi 二次整理稿枚举名，但仍缺原始源码页复核 |
| `vol_regime_code` | string | 可做 `compression/expansion/high_vol/exhaustion` | GainzAlgo 原始页仍缺源码级证据，且 script id 存在补充证据差异 |
| `vol_breakout_signal` | int | 可作为研究标签保留 | breakout threshold 的具体阈值与确认时机仍不够稳 |
| `trend_confirmation_after_vol_breakout` | int | 研究侧可保留 | 需要明确 Step1/Step2 之间的对象级逻辑 |
| `squeeze_momentum_accel` | float | 可保留为动量柱斜率/二阶变化 | 不同脚本定义差异较大 |
| `atr_percentile_window` | int | 可记录窗口长度 | CHE 默认值已知，但其他来源未统一 |

## C层：暂不进入当前字段

- `position_size_calculator`
- `dynamic_stop_loss`
- `take_profit_scaling`
- `integrated risk management`
- `完整 dashboard UI 输出字段`

这些内容在来源里经常和波动状态机绑在一起，但它们属于执行/风控说明，不属于当前 N01 最小字段层。

## 建议的最小离散映射

- `atr_percentile_regime`
  - `extreme`: percentile > 90
  - `elevated`: 70-90
  - `normal`: 30-70
  - `calm`: 10-30
  - `squeeze`: < 10
- `squeeze_tier`
  - `high`
  - `medium`
  - `low`
  - `off`

## 审计备注

- 所有 N01 字段默认优先以 `bar close` 为准。
- 若某脚本在当前 bar 内会切换状态，需额外标记 `intrabar_sensitive=1`。
- `atr_percentile_regime` 与 `squeeze_tier` 都是状态标签，不应直接替代最终交易决策。
- `TTM Squeeze Pro` 当前补到的是 `Beardy_Fred` 版本口径，其中 squeeze 条件使用 `or`；后续若接其他 TTM 变体，不能默认视为完全同义。
