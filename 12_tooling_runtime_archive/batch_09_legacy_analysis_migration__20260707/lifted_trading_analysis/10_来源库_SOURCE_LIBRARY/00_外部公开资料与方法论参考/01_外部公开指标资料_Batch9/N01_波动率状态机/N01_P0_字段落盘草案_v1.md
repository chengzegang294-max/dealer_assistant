# N01 P0 字段落盘草案 v1

## 目标

- 把 N01 第一批最稳的波动状态字段收成“可准备落盘”的最小合约。
- 当前只覆盖 `P0`，不把仍缺源码页或阈值未稳的 `P1/P2` 字段强塞进来。
- 这份草案服务于研究侧/诊断侧字段，不等于完整交易门控实现。

## 适用边界

- 适用于：
  - `volatility regime / squeeze / compression quality` 研究字段
  - 后续分桶、replay、evidence pack 的统一字段名
- 暂不适用于：
  - 仓位管理
  - 止盈止损计算
  - 二阶段 breakout 硬门控
  - 更复杂的 realized vol persistence / shock decay

## 当前裁决

- 先落 `P0 / N01`
- 当前优先保留“ATR 状态锚点 + squeeze 状态锚点 + compression 质量锚点”
- `atr_baseline_value`、`squeeze_momentum_sign`、四项子评分先放到下一批 `P1`

|---|---|---|---|---|---|---|

| `atr_ratio` | float | yes | `na` | 当前 ATR 相对基线 ATR 的比值 | GainzAlgo | ready_for_landing |
| `atr_percentile` | float | yes | `na` | ATR 在回看窗口中的历史分位，`0-100` | CHE | ready_for_landing |

| `compression_quality_score` | float | yes | `na` | 压缩质量综合评分 | AG Pro | ready_for_landing |

## 口径约束

- `atr_value`
  - 只表示当前波动水平，不默认携带窗口参数
- `atr_ratio`
  - 表示 `current_atr / baseline_atr`
  - 若缺基线 ATR，则记 `na`
- `atr_percentile`
  - 当前建议区间 `0-100`
  - 不要混成 `0-1` 比例
- `atr_percentile_regime`
  - 当前先用：
    - `extreme`
    - `elevated`
    - `normal`
    - `calm`
    - `squeeze`
    - `unknown`
- `squeeze_is_on`
  - 只表示压缩开/关
  - 不混入 tier 信息
- `squeeze_tier`
  - 当前只保留：
    - `high`
    - `medium`
    - `low`
    - `off`
- `squeeze_fired`
  - 当前只保留是否进入释放
  - 不混入方向信息
- `compression_quality_score`
  - 当前保留连续值
  - 先不离散成 state

## 建议的最小分档口径

- `atr_percentile_regime`
  - `extreme`: `atr_percentile > 90`
  - `elevated`: `70 < atr_percentile <= 90`
  - `normal`: `30 <= atr_percentile <= 70`
  - `calm`: `10 <= atr_percentile < 30`
  - `squeeze`: `atr_percentile < 10`
- `squeeze_tier`
  - `high`
  - `medium`
  - `low`
  - `off`

## 派生顺序

1. 先算 `atr_value`
2. 若有基线 ATR，则算 `atr_ratio`
3. 若有回看窗口，则算 `atr_percentile`
4. 基于 percentile 派生 `atr_percentile_regime`
5. 并行记录：
   - `squeeze_is_on`
   - `squeeze_tier`
   - `squeeze_fired`
6. 最后补：
   - `compression_quality_score`

## 空值规则

- 永不为空：
  - `atr_percentile_regime`
  - `squeeze_is_on`
  - `squeeze_tier`
  - `squeeze_fired`
- 条件允许为空：
  - `atr_value`
  - `atr_ratio`
  - `atr_percentile`
  - `compression_quality_score`
- 条件空值只允许出现在：
  - 数据历史不足
  - 缺基线窗口
  - 来源脚本未提供质量评分

- `vol_breakout_signal`

- `squeeze_momentum_accel`
- `atr_percentile_window`

## 暂不进入的原因

- `atr_baseline_value`
  - 有价值，但更适合作为 P1 增强说明层
- `atr_regime_is_extreme / atr_regime_is_squeeze`
  - 可以从 `atr_percentile_regime` 派生，不必抢先单独落
- `squeeze_momentum_sign`
  - 方向定义受不同脚本直方图算法影响
- 四项子评分：
  - `atr_contraction_score`
  - `range_tightness_score`
  - `noise_cleanliness_score`
  - `containment_score`
  - 当前还缺 AG Pro 源码页和权重口径
- `compression_state / vol_regime_code / vol_breakout_signal / trend_confirmation_after_vol_breakout`
  - 仍有源码级证据缺口，不能提前冒充成熟字段
