# N03 P0 字段落盘草案 v1

## 目标

- 把 N03 第一批最稳的市场结构字段收成“可准备落盘”的最小合约。
- 当前只覆盖 `P0`，只收定义层，不把审计层和复杂 confluence 强塞进来。
- 这份草案服务于研究侧/诊断侧字段，不等于完整 SMC 或门控实现。

## 适用边界

- 适用于：
  - `confirmed swing / BOS / CHOCH / structure direction` 研究字段
  - 后续 replay、evidence pack、结构标签分桶
- 暂不适用于：
  - 非重绘审计结论本身
  - FVG / order block / Fib / HTF overlay
  - EMA / volume / displacement 过滤层
  - failed breakout 事件

## 当前裁决

- 先落 `P0 / N03`
- 当前优先保留“摆点确认 + 突破确认方式 + 结构方向 + BOS/CHOCH 事件”
- `pivot_confirm_delay_bars`、`confirmed_pivot_non_repaint`、`extra_confluence_used` 先放到后续 `P2`

## 口径约束

- `swing_mode`
  - 当前只保留：
    - `pivot`
    - `fractal`
    - `custom`
    - `unknown`
- `swing_left_bars / swing_right_bars`
  - 只记录摆点确认参数
  - 不把它们误写成“无延迟”
- `swing_high_confirmed / swing_low_confirmed`
  - 只认确认后的摆点
  - 不记录 live 未确认摆点
- `break_confirmation_mode`
  - 当前只保留：
    - `close`
    - `wick`
- `break_level_price`
  - 指本次被突破的结构位
  - 允许在未触发事件时为 `na`
- `bos_event`
  - 只表示结构延续突破
  - 不混入过滤层条件
- `choch_event`
  - 只表示结构切换事件
  - 不混入 FVG / order block / volume 解释
- `structure_direction`
  - 当前只保留：
    - `bullish`
    - `bearish`
    - `neutral`
- `structure_event_bar_close_confirmed`
  - 仅表示该事件是否要求 bar close 确认
  - 不等于“脚本完全无重绘”

## 建议的最小事件逻辑

1. 先确认摆点：
   - `swing_mode`
   - `swing_left_bars`
   - `swing_right_bars`
   - `swing_high_confirmed`
   - `swing_low_confirmed`
2. 再确认突破口径：
   - `break_confirmation_mode`
   - `break_level_price`
   - `structure_event_bar_close_confirmed`
3. 最后记录结构事件：
   - `bos_event`
   - `choch_event`
   - `structure_direction`

## 空值规则

- 永不为空：
  - `swing_mode`
  - `swing_high_confirmed`
  - `swing_low_confirmed`
  - `break_confirmation_mode`
  - `bos_event`
  - `choch_event`
  - `structure_direction`
  - `structure_event_bar_close_confirmed`
- 条件允许为空：
  - `swing_left_bars`
  - `swing_right_bars`
  - `break_level_price`
- 条件空值只允许出现在：
  - 来源脚本未显式暴露摆点参数
  - 尚未形成可跟踪结构位

## 暂不进入的原因

- 审计层字段：
  - `pivot_confirm_delay_bars`
  - `confirmed_pivot_non_repaint`
  - `structure_label_inherits_pivot_delay`
  - `current_bar_visuals_mutable`
  - `close_vs_wick_risk_note`
  - `future_leak_risk_flag`
  - 当前都很重要，但属于“解释和风险披露”，不属于 P0 最小定义层
- 过滤层字段：
  - `extra_confluence_used`
  - `volume_scoring`
  - `EMA_momentum_confirmation`
  - `HTF_overlay`
  - 容易把定义层和策略层混在一起
- 越界内容：
  - `FVG`
  - `order_block`
  - `Fib`
  - `premium_discount`
  - `regime_adaptation`
  - 超出当前 N03 最小边界
- `failed_breakout_event`
  - 目前对象级定义还没系统收齐
