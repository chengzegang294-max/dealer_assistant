# 核心技术_ALBrooks_EMA均线量化用法规则

## 核心定义
指数移动平均线(EMA)是AL Brooks体系的核心趋势判定工具，20EMA为主要决策均线，200EMA为宏观方向参考。

## 可量化执行标准

**EMA趋势方向判定**：
- EMA上升斜率>5度：上升趋势
- EMA下降斜率>5度：下降趋势
- EMA斜率绝对值<5度：走平（交易区间信号）
- 价格位于EMA上方且EMA上升：多头趋势确认
- 价格位于EMA下方且EMA下降：空头趋势确认

**均线支撑阻力量化规则**：

| 场景 | 判定条件 | 交易动作 |
|------|---------|---------|
| EMA支撑有效 | 价格回撤触及20EMA+下尾线+立即反弹 | EMA处多头入场 |
| EMA阻力有效 | 价格反弹触及20EMA+上尾线+立即回落 | EMA处空头入场 |
| EMA突破确认 | 连续2根棒线收盘于EMA另一侧 | 方向反转，按新方向交易 |
| EMA假突破 | 单根棒线过穿EMA+次棒回到原侧 | 假突破方向入场（反向） |
| 价格远离EMA | 价格偏离EMA>2xATR | 等待回归EMA，不追价 |

**多周期EMA共振**：
- 日线EMA + 4小时EMA + 1小时EMA同向 = 强趋势，可重仓
- 4小时EMA + 1小时EMA同向 + 5分钟EMA同向 = 标准趋势，标准仓
- 多周期EMA方向不一致 = 震荡/过渡，轻仓或观望

**200EMA宏观方向约束**：
- 价格位于200EMA上方：只允许多头交易（多头顺势+空头反转）
- 价格位于200EMA下方：只允许空头交易（空头顺势+多头反转）
- 价格穿越200EMA：宏观方向可能转变，需等待确认（连续5根棒线收盘于同侧）

## 适用场景与禁忌
- **适用场景**：所有趋势判定场景，作为总在场内方向的核心参考
- **禁忌场景**：EMA走平期（斜率<5度）禁止顺势交易；单周期EMA信号需大周期确认
- **核心约束**：EMA是 lagging indicator，极强趋势中价格可能大幅偏离EMA，此时不能等待EMA入场

# 核心技术_ALBrooks_总在场内状态判定规则

## 核心定义
总在场内(Always In)是AL Brooks价格行为体系的趋势方向核心判定指标，定义为：如果被迫此刻开新仓且对方向有自信，该方向即为总在场内方向。

## 可量化执行标准

| 判定层级 | 判定条件 | 量化标准 | 周期适配 |
|---------|---------|---------|---------|
| 强多头趋势 | 20EMA向上 + 高点持续抬高 + 低点持续抬高 + 连续多头趋势棒 | 价格位于20EMA上方，回调不深于均线下方2棒 | 5分钟/15分钟/1小时 |
| 弱多头趋势/通道 | 20EMA向上 + 高点抬高但斜率平缓 + 回调频繁触及EMA | 价格在EMA上下穿插，但低点总体抬高 | 5分钟/15分钟 |
| 强空头趋势 | 20EMA向下 + 低点持续降低 + 高点持续降低 + 连续空头趋势棒 | 价格位于20EMA下方，反弹不高于均线上方2棒 | 5分钟/15分钟/1小时 |
| 弱空头趋势/通道 | 20EMA向下 + 低点降低但斜率平缓 + 反弹频繁触及EMA | 价格在EMA上下穿插，但高点总体降低 | 5分钟/15分钟 |
| 交易区间 | EMA走平 + 价格在区间内上下波动 + 无明显高低点排列 | 双方向突破均失败，带刺铁丝形态出现 | 5分钟/15分钟 |

**总在场内转换判定**：趋势结构破坏（高低点排列失效）+ 反向突破确认（反向突破前波段极点+后续棒线确认）

## 适用场景与禁忌
- **适用场景**：趋势行情（强趋势/趋势通道）、震荡行情（交易区间/旗形）、反转行情（顶底反转/趋势线突破反转）全覆盖
- **禁忌场景**：极端无波动行情（十字星密集连续20棒以上），此时总在场内方向不明确
- **周期约束**：大周期（日线/4小时）定总在场内大方向，严禁无大周期方向指引的小周期逆势操作

# 核心技术_ALBrooks_趋势强度量化评分

## 核心定义
AL Brooks原创趋势强度评分体系，通过5个维度对趋势力量进行0-12分量化评分，用于决定交易策略与仓位大小。

## 可量化执行标准

| 评分维度 | 强趋势特征(+2分) | 中趋势特征(+1分) | 弱趋势/区间特征(0分) |
|---------|-------------------|-------------------|---------------------|
| EMA方向 | 陡峭向上/向下，无走平 | 明显向上/向下，偶走平 | 走平或反复穿插 |
| 高低点排列 | 严格抬高/降低，无例外 | 总体抬高/降低，偶例外 | 无规律或反向排列 |
| 趋势棒占比 | >70%棒线为同色趋势棒 | 50-70%为趋势棒 | <50%趋势棒，十字星多 |
| 回调深度 | 不触及EMA或仅浅触 | 触及EMA但不过穿 | 过穿EMA且持续多棒 |
| 回调棒数 | 1-3棒即恢复 | 3-8棒恢复 | >8棒或形成区间 |
| 突破行为 | 连续突破前高/前低 | 偶突破，偶失败 | 双向假突破频繁 |

**趋势强度判定阈值**：
- 极强趋势：10-12分（罕见，仅持仓，不逆势）
- 强趋势：7-9分（顺势交易，回调入场）
- 中趋势：4-6分（通道内交易，高抛低吸或顺势）
- 弱趋势/区间：0-3分（观望或区间策略）

## 适用场景与禁忌
- **适用场景**：所有趋势类型行情的趋势力量评估，用于入场决策和仓位配比
- **禁忌场景**：单一维度评分即做交易决策，必须综合6个维度总分
- **核心约束**：极强趋势时禁止任何逆势操作，弱趋势/区间时禁止顺势追单

# 核心技术_ALBrooks_趋势棒与十字星量化定义

## 核心定义
趋势棒(Trend Bar)与十字星(Doji)是价格行为分析的基础K线分类，所有信号棒评分和入场判定均建立在此基础分类之上。

## 可量化执行标准

**多头趋势棒判定条件（全部满足）**：
- 实体方向：收盘价 > 开盘价
- 实体大小：实体高度 ≥ 整根棒线范围的30%
- 收盘位置：收盘价位于整根棒线范围的上40%区间
- 下尾线：下尾线长度 ≤ 整根棒线范围的30%

**空头趋势棒判定条件（全部满足）**：
- 实体方向：收盘价 < 开盘价
- 实体大小：实体高度 ≥ 整根棒线范围的30%
- 收盘位置：收盘价位于整根棒线范围的下40%区间
- 上尾线：上尾线长度 ≤ 整根棒线范围的30%

**十字星判定条件（满足任一）**：
- 实体大小：实体高度 < 整根棒线范围的10%
- 实体位置：实体位于整根棒线中点±10%范围内且上尾线与下尾线均>实体高度的2倍

**强趋势棒增强判定**：
- 强多头趋势棒：多头趋势棒 + 无上尾线 + 实体≥整根棒线范围的50%
- 强空头趋势棒：空头趋势棒 + 无下尾线 + 实体≥整根棒线范围的50%
- 强趋势棒出现后的信号棒评分+1分（额外奖励）

**十字星子类型**：
- 标准十字星：小实体+上下尾线均长
- 陀螺十字星：小实体+上尾线极长+下尾线极短
- 蜻蜓十字星：小实体+下尾线极长+上尾线极短
- 墓碑十字星：小实体+上尾线极长+下尾线极短（空头信号）
- 四价十字星：开=高=低=收（极度犹豫信号）

## 适用场景与禁忌
- **适用场景**：所有价格行为分析的基础K线分类，用于信号棒评分、入场形态判定、趋势力量评估
- **禁忌场景**：单个趋势棒/十字星不直接构成交易信号，必须结合位置、背景、EMA方向综合判定
- **周期约束**：5分钟棒线的十字星在大周期（1小时+）可能表现为趋势棒，周期嵌套时以交易决策周期为准

## 扩展：EMA均线多周期共振用法

### 多周期EMA共振规则

| 周期组合 | 共振条件 | 趋势判定 | 交易动作 |
|---------|---------|---------|---------|
| 日线+4小时 | 同向排列 | 中趋势方向 | 标准仓顺势 |
| 日线+4小时+1小时 | 同向排列 | 强趋势方向 | 重仓顺势 |
| 周线+日线 | 同向排列 | 大趋势方向 | 大方向过滤 |
| 周期冲突 | 方向不一致 | 震荡/过渡 | 观望或轻仓 |

### EMA参数设置标准
- 短期EMA：5周期（超短参考）
- 中期EMA：10/20周期（主要交易参考）
- 长期EMA：60/120周期（大趋势参考）
- 超长期EMA：200/250周期（牛熊分界）

### EMA特殊形态
- EMA金叉：短期EMA上穿长期EMA，趋势转多信号
- EMA死叉：短期EMA下穿长期EMA，趋势转空信号
- EMA多头排列：5>10>20>60，强趋势特征
- EMA空头排列：5<10<20<60，弱趋势特征
- EMA粘合：多周期EMA汇聚，变盘前兆

### 十字星交易规则

- 十字星+成交量萎缩 = 动能衰竭
- 连续3根十字星 = 大级别变盘前兆

## 扩展：趋势回调深度量化分级

### 回调深度与趋势力量关系

| 回调级别 | 深度范围 | 时间范围 | 趋势力量 | 交易策略 |
|---------|---------|---------|---------|---------|
| 极浅回调 | <0.236×前波段 | 1-3根K线 | 极强趋势 | EMA处追单 |
| 浅回调 | 0.236-0.382×前波段 | 3-5根K线 | 强趋势 | 信号棒入场 |
| 正常回调 | 0.382-0.5×前波段 | 5-10根K线 | 中趋势 | 确认后入场 |
| 深回调 | 0.5-0.618×前波段 | 10-20根K线 | 弱趋势 | 轻仓试探 |
| 极深回调 | >0.618×前波段 | >20根K线 | 趋势转区间 | 观望 |

### 回调结束确认信号
1. 出现与趋势同向的强趋势棒
2. KD指标超卖区金叉（多头回调）或超买区死叉（空头回调）
3. 成交量在回调末端萎缩后重新放大
4. 价格触及关键支撑位/阻力位后反转
5. 回调时间到达斐波那契时间窗口
