# 技术指标_时空波浪_二维时空共振交易规则

## 核心定义
二维时空共振是当价格空间维度（斐波那契回调/扩展位）与时间维度（斐波那契时间窗口）同时到达关键位时，形成高概率交易信号的分析方法。

## 可量化执行标准

**共振类型量化判定**：

| 共振类型 | 空间条件 | 时间条件 | 信号强度 | 交易动作 |
|---------|---------|---------|---------|---------|
| 强共振 | 价格精确触及0.618/0.786回调位 | 同时到达13/21/34时间窗口 | A级 | 立即入场 |
| 中强共振 | 价格触及0.5/0.618回调位 | 到达8/13时间窗口 | B级 | 确认后入场 |
| 弱共振 | 价格触及0.382回调位 | 到达5/8时间窗口 | C级 | 观望等待 |
| 多周期共振 | 日+4H+1H回调位重叠 | 多周期时间窗口汇聚 | S级 | 重仓入场 |

**共振入场规则**：
1. 空间到位：价格进入斐波那契关键位±0.2xATR范围内
2. 时间到位：进入斐波那契时间窗口±1根K线范围内
3. 共振确认：价格+时间同时到位+反转K线出现（评分≥7分）
4. 止损：共振位外侧+0.3xATR
5. 目标：反向斐波那契位或等幅投射
6. 仓位：A级标准仓×1.5/B级标准仓/C级观望

**共振失败处理**：
- 价格突破共振位+收盘于外侧 = 共振失效
- 共振失效后顺势追单（突破方向）
- 连续2次共振失效 = 该周期时空分析暂时失效

**A股适配要点**：
- T+1制度下，共振当日收盘前确认后次日入场
- 共振日成交量放大>均量120% = 确认信号
- 结合大盘时空位置判断个股共振可靠性

## 适用场景与禁忌
- **适用场景**：大周期（日线/周线）的高概率入场点选择
- **禁忌场景**：单一维度（只空间或只时间）共振不完整时禁止入场
- **核心约束**：二维时空共振是最高级别的交易信号之一，但出现频率低，需耐心等待

# 技术指标_时空波浪_二维时空分析时间周期规则

## 核心定义
二维时空分析是将时间维度与价格空间维度结合的分析方法，通过斐波那契时间周期与波浪结构的共振，预测市场变盘时间节点。

## 可量化执行标准

**时间周期与波浪对应关系**：

| 波浪 | 时间比例 | 斐波那契时间窗口 | 变盘概率 |
|------|---------|-----------------|---------|
| 1浪 | 基准时间T | 启动时间点 | - |
| 2浪 | 0.382T - 0.618T | 1浪时间×0.5 | 中高 |
| 3浪 | 1.0T - 1.618T | 1浪时间×1.0/1.618 | 高 |
| 4浪 | 0.5×3浪时间 | 3浪时间×0.5 | 中 |
| 5浪 | 0.5T - 1.0T | 1浪时间×0.618/1.0 | 中高 |
| A浪 | 0.382×5浪时间 | 5浪时间×0.382 | 中 |
| B浪 | 0.5×A浪时间 | A浪时间×0.5 | 低 |
| C浪 | 1.0×A浪时间 | A浪时间×1.0/1.618 | 高 |

**二维共振判定（时间+空间）**：
1. 价格到达斐波那契回调/扩展位
2. 同时到达斐波那契时间窗口
3. 两者同时满足 = 高概率变盘
4. 空间到位但时间未到 = 可能延续，需等待
5. 时间到位但空间未到 = 可能加速，需观察

**周期嵌套分析**：
- 大浪时间周期内嵌套小浪时间周期
- 大浪5浪结束时间 + 小浪5浪结束时间 = 强共振
- 大浪2浪回调时间 + 小浪调整时间 = 调整结束信号

**A股特殊时间窗口**：
- 日线：5-8-13-21天为关键变盘窗口
- 周线：5-8-13周为中期变盘窗口
- 月线：3-5-8月为长期变盘窗口
- 结合农历节气/月底/季度末增强变盘概率

## 适用场景与禁忌
- **适用场景**：大周期持仓的时间管理、变盘节点预警
- **禁忌场景**：单独时间窗口无价格信号不交易；小周期时间分析噪音过多
- **核心约束**：时间分析是辅助工具，必须与价格行为共振才可作为交易信号

# 技术指标_时空波浪_推动浪与调整浪量化特征

## 核心定义
推动浪(Impulse Wave)是与主趋势同向的5浪结构，调整浪(Corrective Wave)是与主趋势反向的3浪结构，两者在幅度、时间、成交量上有明确可量化的区别特征。

## 可量化执行标准

**推动浪5子浪量化特征**：

| 特征维度 | 1浪 | 3浪 | 5浪 |
|---------|------|------|------|
| 幅度 | 基准X | 1.0-2.618X（最长） | 0.618-1.0X |
| 时间 | 基准T | 1.0-1.618T | 0.5-1.0T |
| 成交量 | 温和放大 | 最大放量 | 缩量或平量 |
| 子浪结构 | 清晰5浪 | 最清晰5浪 | 可能失败（缩短） |
| 动量(KD) | 50-70 | 70-80（最强） | 50-70（可能背离） |

**调整浪3子浪量化特征**：

| 特征维度 | A浪 | B浪 | C浪 |
|---------|------|------|------|
| 幅度 | 5浪的0.236-0.5 | A浪的0.382-0.786 | ≥A浪或1.0-1.618×A浪 |
| 时间 | 较短 | 较短 | 较长 |
| 成交量 | 开始萎缩 | 缩量反弹 | 可能放量（恐慌） |
| 子浪结构 | 5浪或3浪 | 3浪（最复杂） | 5浪 |
| 动量(KD) | 从高位回落 | 50附近反弹 | 低位或超卖 |

**推动浪vs调整浪判别**：

| 判别指标 | 推动浪特征 | 调整浪特征 |
|---------|-----------|-----------|
| 趋势方向 | 与主趋势同向 | 与主趋势反向 |
| 子浪结构 | 5个子浪 | 3个子浪（或三角形） |
| 成交量 | 整体放量 | 整体缩量 |
| 动能指标 | 持续强势 | 动能减弱 |
| 5/10日均线 | 均线发散向上 | 均线收敛或走平 |
| MACD | 柱线持续同向 | 柱线缩短或交叉 |

**调整浪深度预判**：
- 强势调整：0.236×推动浪（浅调整，趋势极强）
- 正常调整：0.382×推动浪（健康调整）
- 深度调整：0.5×推动浪（调整较深，警惕）
- 极端调整：0.618×推动浪（趋势可能终结）
- >0.618×推动浪：趋势大概率反转，非调整

## 适用场景与禁忌
- **适用场景**：趋势结构识别、调整结束预判、加仓点选择
- **禁忌场景**：推动浪和调整浪判别不清时禁止交易；单一特征判别需综合验证
- **核心约束**：推动浪和调整浪的判别是波浪分析的基础，误判会导致方向性错误

# 技术指标_时空波浪_波浪延伸与失败量化判定

## 核心定义
波浪延伸(Wave Extension)是推动浪中某一子浪幅度显著超过正常比例的现象；波浪失败(Wave Failure)是第5浪未能超过第3浪终点的现象，两者是重要的趋势信号。

## 可量化执行标准

**延伸浪量化判定**：

| 延伸浪位置 | 幅度标准 | 时间标准 | 市场含义 |
|-----------|---------|---------|---------|
| 1浪延伸 | 1浪>3浪幅度 | 1浪时间>3浪时间 | 极强趋势启动，后续涨幅大 |
| 3浪延伸 | 3浪>1浪×1.618 | 3浪时间最长 | 标准强趋势，最常见 |
| 5浪延伸 | 5浪>3浪幅度 | 5浪时间>3浪时间 | 趋势末端加速，警惕反转 |

**延伸浪后的走势预测**：
- 1浪延伸：2浪回调浅（0.382），3浪更长
- 3浪延伸：4浪回调深（0.5），5浪可能缩短
- 5浪延伸：后续调整幅度大（可能回推至2浪区域）

**5浪失败量化判定**：

| 判定条件 | 量化标准 | 交易含义 |
|---------|---------|---------|
| 5浪高点<3浪高点 | 5浪终点低于3浪终点 | 趋势衰竭信号 |
| 5浪成交量<3浪成交量 | 量能未能配合 | 需求/供给枯竭 |
| 5浪KD背离 | KD在5浪高点低于3浪高点 | 动量衰竭确认 |
| 5浪时间缩短 | 5浪时间<3浪时间×0.5 | 趋势加速末段 |

**失败5浪后的走势**：
- 失败5浪后调整幅度大：常回推至3浪的0.618或更低
- 调整时间：可能与5浪推动时间等长或更长
- 后续走势：可能开启新一轮反向趋势

**交易策略**：
- 延伸浪（3浪延伸中）：顺势加仓，止损3浪起点
- 延伸浪（5浪延伸）：不追单，准备反转交易
- 失败5浪：5浪确认失败后反向入场，止损5浪极点外

## 适用场景与禁忌
- **适用场景**：趋势末端识别、反转预判、加仓/减仓决策
- **禁忌场景**：5浪未完整形成前预判失败；延伸浪中逆势交易
- **核心约束**：延伸和失败是重要信号但出现频率低，出现时需高度重视

# 技术指标_时空波浪_波浪计数量化规则

## 核心定义
时空波浪理论是基于艾略特波浪原理，结合时间周期和空间幅度二维分析的波浪计数系统，通过识别5浪推动+3浪调整的8浪循环结构预测市场走势。

## 可量化执行标准

**基本8浪结构量化定义**：

| 浪型 | 方向 | 幅度范围 | 时间特征 | 子浪结构 |
|------|------|---------|---------|---------|
| 1浪 | 与趋势同向 | 较小，常为5浪中最短 | 较短 | 5个子浪或3个子浪 |
| 2浪 | 反向回调 | 1浪的0.382-0.786回撤，不破1浪起点 | 较长 | 3个子浪（ABC） |
| 3浪 | 与趋势同向 | 5浪中最长，常>1浪的1.618倍 | 较长 | 5个子浪 |
| 4浪 | 反向回调 | 3浪的0.236-0.5回撤，不破1浪终点 | 较长 | 3个子浪或三角形 |
| 5浪 | 与趋势同向 | 常≈1浪幅度或1浪的0.618-1.0 | 较短 | 5个子浪（常失败） |
| A浪 | 与趋势反向 | 5浪整体幅度较小部分 | 较短 | 5个或3个子浪 |
| B浪 | 与趋势同向 | A浪的0.382-0.786回撤 | 较短 | 3个子浪 |
| C浪 | 与趋势反向 | 常≈A浪或>A浪，整体5-3-5 | 较长 | 5个子浪 |

**波浪计数量化约束**：
1. 2浪不能低于1浪起点（硬性规则）
2. 3浪不能是1、3、5中最短的（硬性规则）
3. 4浪不能与1浪价格区间重叠（硬性规则，期货市场除外）
4. 3浪通常是推动浪中最长的
5. 2浪和4浪交替原则：若2浪简单，4浪复杂；若2浪深，4浪浅

**波浪幅度比例量化**：
- 1浪幅度：基准单位 = X
- 2浪幅度：0.382X - 0.786X
- 3浪幅度：1.0X - 2.618X（通常1.618X）
- 4浪幅度：0.236×3浪 - 0.5×3浪
- 5浪幅度：0.618X - 1.0X

## 适用场景与禁忌
- **适用场景**：日线/周线级别的趋势结构分析和目标位预测
- **禁忌场景**：5分钟等小周期波浪计数噪音过多；波浪计数主观性强，需多方案预案
- **核心约束**：波浪理论是概率工具不是确定性工具，必须设置备用计数方案
