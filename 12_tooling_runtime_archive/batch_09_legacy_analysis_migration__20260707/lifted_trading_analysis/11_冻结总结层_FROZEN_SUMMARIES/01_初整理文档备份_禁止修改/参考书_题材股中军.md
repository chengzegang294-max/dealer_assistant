## 第一部分 体系核心定位与底层逻辑

### 1.1 核心思想一句话提炼
陈鹏·强结构中军体系是一套以「板块结构」为分析单元、以「分歧中的承接行为」为唯一识别标准、以「中军生命周期阶段」为仓位管理依据、以「反复被调用次数」为角色确认硬条件的A股题材交易系统。它完全脱离技术指标，仅依靠板块-个股关系、分歧-承接行为、情绪周期阶段三个基本维度来识别市场中真正承担结构稳定功能的"中军"角色，并在其生命周期的不同阶段匹配相应的交易策略。

| 维度 | 明确界定 |
|------|---------|
| **体系本质** | A股题材板块结构分析工具，核心输出为「当前板块中军是谁 + 中军处于哪个生命周期阶段 + 当前阶段对应的交易策略（仓位/买卖/风控）」 |
| **核心分析对象** | 板块在分歧时反复调用的"承接者"（中军），而非涨幅最大的"表演者" |
| **核心分析工具** | 板块-个股关系、分歧-承接行为、情绪周期阶段（三个基本维度），不使用任何技术指标 |
| **适配行情类型** | A股题材行情（启动/发酵/高潮/退潮四阶段），不适用于纯情绪小票行情和系统性风险阶段 |
| **适配品种** | A股题材板块内的核心标的（容量票为主），不适用于港股/美股/外汇/期货 |
| **核心盈利来源** | ① 确认期分歧回踩买点（胜率最高）；② 主导期滚动波段套利；③ 金矿型中军多轮行情反复参与；④ 轮值中军切换点捕捉 |
| **分析vs交易分离原则** | 盘前锁定板块+候选池（3-8只）→ 盘中只等分歧出现 → 分歧中观察承接 → 确认后按阶段执行对应策略 |

### 1.2 中军三句话硬核定义（全文底座）

| 定义层级 | 原文定义 | 量化解读 | 反例排除 |
|---------|---------|---------|---------|
| **第一句** | 中军一定属于板块，而不是单票 | 脱离板块谈中军=错误；板块不需要它=不是中军 | 孤立强势股、无板块依附的妖股 |
| **第二句** | 中军的本质是承接，而不是拉升 | 看"被砸时扛不扛"，不看"冲的时候多猛" | 情绪拉升者、涨停先锋、涨幅冠军 |
| **第三句** | 中军必须被反复需要，一次不算 | 一次承接=观察；两次承接=候选；三次及以上=确认 | 消息刺激一次性表现、单日护盘行为 |

**关键原文引用**：
> "中军 = 板块在分歧时，反复调用的承接者。不是'涨得最多的'，不是'最有人气的'，不是'最会涨停的'，而是：在结构快要失控时，被市场一次次用来稳住局面的那一只。" —— 第一章1.6节

### 1.3 中军vs龙头vs跟风股：差异化判定规则

| 维度 | 中军 | 龙头 | 跟风股 |
|------|------|------|--------|
| **核心功能** | 结构稳定/承接抛压 | 情绪引领/拉涨高度 | 被动跟随/放大波动 |
| **辨识度来源** | 分歧时抗跌、承接清晰 | 涨幅最大、涨停最多 | 涨得杂乱、波动极大 |
| **持续性** | 板块存活多久它存在多久 | 可能天天换 | 最容易一日游 |
| **交易者适合度** | 结构型交易者 | 情绪型高手 | 散户陷阱区 |
| **容量特征** | 大成交、大市值、装得下钱 | 可大可小 | 通常偏小 |
| **失败模式** | 退位但不崩 | 炸板、A杀 | 直接淘汰 |
| **量化识别** | 分歧时跌幅<板块平均、有连续买盘、结构位不破 | 涨幅排名板块第一、封板最早 | 涨跌无序、成交量忽大忽小 |

### 1.4 核心术语量化定义

| 术语 | 量化定义 | 交易意义 |
|------|---------|---------|
| **中军** | 板块在分歧时，被反复（≥3次）调用的承接者 | 结构交易的核心标的 |
| **承接** | 分歧中有连续买盘、价格不被砸穿关键结构位、下杀可控 | 中军识别的唯一行为标准 |
| **分歧** | 龙头冲高回落/炸板、高位票剧烈换手、板块内涨跌明显分化 | 中军识别的唯一有效场景 |
| **一致** | 板块内多数个股同向上涨、无明显分化 | 中军无法识别的阶段，不参与判断 |
| **试用期中军** | 承接过1-2次、身份未确认 | 轻仓观察，不重仓 |
| **确认期中军** | 被反复调用≥3次、候选池收缩 | 中等仓位，核心参与阶段 |
| **主导期中军** | 一有分歧就找它、市场形成路径依赖 | 滚动波段，不增反减 |
| **退位期中军** | 还能承接但不再是第一选择 | 快进快出，明显降仓 |
| **金矿型中军** | 多轮行情反复被调用、成为默认稳定器 | 可反复参与、长期跟踪 |
| **轮值中军** | 板块容量大、中军角色由多只个股轮流承担 | 不追求唯一，跟踪岗位而非名字 |
| **伪中军** | 看起来像中军但无法持续：高位横盘装稳/跟风承接装中军/消息刺激一次性 | 结构性陷阱，需严格识别过滤 |
| **结构发动机** | 中军的本质比喻：不最显眼但决定板块寿命 | 认知锚点 |

## 第二部分 趋势判定模块（题材周期×中军生命周期）

### 2.1 题材行情四阶段判定

| 阶段 | 判定标准（价量行为） | 中军状态 | 交易策略 |
|------|-------------------|---------|---------|
| **启动期** | 板块从冰点回暖、新主线出现、情绪逐步升温但未失控、中军第一次/第二次承接 | 试用期→确认期过渡 | 可参与，仓位逐步增加，以验证为主 |
| **高潮期** | 涨停泛滥、情绪极度一致、风险被忽视、中军波动变小"假安全" | 主导期 | 降仓滚动、不恋战、不重仓避险 |
| **分歧期** | 板块内明显分化、情绪来回拉扯、市场"找稳定器"、中军反复承接证明价值 | 确认期→主导期 | 核心舞台，只在分歧点参与，只参与被调用的中军 |
| **退潮期** | 板块不再回流、修复失败、情绪快速冷却、中军不再被用 | 退位期→衰亡期 | 退出结构，等下一个周期 |

**关键原文引用**：
> "在情绪启动与分歧期，才谈中军；在情绪高潮与退潮期，谈风险。" —— 第十一章第七节

### 2.2 中军七阶段生命周期判定

| 阶段 | 判定标准 | 量化条件 | 交易动作 |
|------|---------|---------|---------|
| **①孕育期** | 板块反复出现、龙头不稳、分歧能修复、资金体量抬升 | 板块出现≥3次回流，但无明确中军 | 只观察不交易，建立候选池 |
| **②试用期** | 某票在关键分歧中第一次承接，结构被稳住 | 承接1-2次 | "完成了一次有效承接，进入重点观察" |
| **③确认期** | 至少2-3次关键分歧，市场反复选择同一对象，候选池淘汰 | 承接≥3次，候选池从3-8只收缩到1-2只 | "当前阶段，中军成立"，中等仓位 |
| **④主导期** | 一有分歧就找它，资金形成路径依赖 | 承接≥5次，市场默认选择 | 滚动波段，仓位不增反减 |
| **⑤退位期** | 还能承接但不再是第一选择，新承接者出现 | 承接意愿下降，新候选出现 | 快进快出，明显降仓 |
| **⑥进化期** | 经历退位但不崩，多轮行情反复被需要 | 退位后复活≥2次 | 金矿型中军，反复正确参与 |
| **⑦衰亡期** | 板块不再回流，分歧不再修复，中军岗位消失 | 板块≥5日无回流 | 退出整个结构 |

### 2.3 板块"有中军潜力"的四信号判定

| 信号 | 量化标准 | 权重 |
|------|---------|------|
| **反复出现** | 板块隔几天就回到盘面，不是只热一天 | 必备 |
| **开始分化** | 有的继续走，有的明显掉队 | 必备 |
| **成交持续放大** | 板块总成交额逐周递增 | 重要 |
| **龙头开始不稳** | 龙头冲高回落、炸板、换手剧烈 | 必备 |

**判定规则**：4个信号同时出现=板块有中军潜力，进入中军寻找流程。

### 2.4 中军确认五问（从"像"到"是"的量化检查表）

| 问题 | 判定标准 | 通过条件 | 权重 |
|------|---------|---------|------|
| **第一问** | 龙头分歧时，它是不是最能承接的那只？ | 跌下去被连续接、接的过程主动、接完稳住结构位 | 必备 |
| **第二问** | 板块恐慌时，它是不是最稳的那只？ | 有下杀但节奏可控、有放量但价格不塌、有承接不是反抽 | 必备 |
| **第三问** | 修复节点，它是不是最常被拉出来的那只？ | 修复第一波/关键节点/再次尝试都被调用 | 重要 |
| **第四问** | 它是否具备"容量+共识"双重条件？ | 成交足够大+市场愿意多次使用它 | 重要 |
| **第五问** | 在候选池中，是否已没有真正的替代品？ | 其他候选掉队/承接不连续/只在特定场景有效 | 决定性 |

**使用顺序**：第一、二问→初筛；第三问→强化判断；第四问→判断寿命；第五问→最终确认。只要有一问明显不成立=停留在"观察"阶段。

## 第三部分 入场触发模块

### 3.1 中军三种有效买点

#### 买点一：第一次有效承接买点（试用期）

| 要素 | 量化标准 |
|------|---------|
| **适用阶段** | 中军试用期，第一次或第二次被调用 |
| **盘面特征** | 板块第一次明显分歧，龙头走弱或炸板，情绪票下杀，中军候选出现连续承接 |
| **核心判定** | "跌不动了"——不是价格涨没涨，而是抛压被消化 |
| **正确买法** | 不抢最低、不追反弹，在"确认有人接"的位置小仓介入 |
| **仓位** | 轻仓/观察仓（10-20%标准仓位） |
| **目的** | 验证判断，不是为盈利 |
| **常见错误** | 把"第一次承接"当成"确认"；用确认期的仓位做试用期的买点 |

#### 买点二：分歧回踩买点（确认期核心，最标准最舒服）

| 要素 | 量化标准 |
|------|---------|
| **适用阶段** | 中军已被多次验证（≥3次承接），确认期 |
| **盘面特征** | 板块再次出现分歧，市场"下意识找它"，它回踩但结构不破 |
| **核心判定** | "被需要的回踩"——回踩时有承接，关键结构位不破 |
| **正确买法** | 只在分歧时买，只在结构未破时买，中等仓位 |
| **仓位** | 中等仓位（50-70%标准仓位） |
| **目的** | 结构型持有，胜率最高的中军买点 |
| **常见错误** | 等完全走稳再买（错过性价比）；在情绪修复后追高 |

#### 买点三：轮值中军切换点（进阶，难度最高回报最好）

| 要素 | 量化标准 |
|------|---------|
| **适用阶段** | 原中军开始退位，新中军被第一次/第二次调用，板块结构仍然健康 |
| **盘面特征** | 原中军退位信号出现+新承接者在分歧中被调用≥2次 |
| **核心判定** | "岗位正在交接"——买的不是稳定，是角色转移 |
| **正确买法** | 轻仓、快速、只做确认不做信仰 |
| **仓位** | 轻仓（20-30%标准仓位） |
| **目的** | 捕捉新中军确认期的第一波利润 |
| **常见错误** | 仍然死守原中军；或者每天追逐"新的中军" |

### 3.2 盘中2秒识别中军判断流程

**前提条件**（必须满足，否则不启动判断）：
1. 已完成盘前板块锁定
2. 已有候选池（3-8只）
3. 知道今天可能出现分歧

**四步判断卡**：

| 步骤 | 问题 | 判定标准 | 结果 |
|------|------|---------|------|
| **①** | 有分歧吗？ | 龙头冲高回落/高位票集体炸板/板块指数快速回撤，任一条 | 没有→忽略 |
| **②** | 谁在最痛点承接？ | 分歧最痛的位置，把抛压一笔笔吃掉，吃完价格稳住 | 没人→结构危险 |
| **③** | 是不是候选池里的？ | 承接者是否在盘前3-8只候选池中 | 不是→只能观察 |
| **④** | 是不是反复出现？ | 这个名字是否已见过好几次（≥3次分歧出现） | 是→进入中军判断 |

**2秒内否定清单**（命中任一条即刻划掉）：
- 只在修复时出现
- 只拉不接
- 承接一次就消失
- 每次分歧换不同的人

### 3.3 候选池构建规则（入场前置步骤）

| 候选类别 | 数量 | 角色定位 | 中军概率 |
|---------|------|---------|---------|
| **板块龙头** | 1只 | 负责情绪，必须观察 | 低 |
| **龙头备胎（龙二/龙三）** | 1-2只 | 分歧时容易顶上 | 中 |
| **容量票（大市值/大成交）** | 1-2只 | 中军最常出现的区域 | 高 |
| **趋势型核心票** | 1-3只 | 不极端，能反复参与 | 中高 |
| **总计** | 3-8只 | — | 中军99%从池内出 |

**关键约束**：候选池不超过8只，中军99%从候选池中出来，99%不会从池外空降。

## 第四部分 出场止损模块

### 4.1 三种"必须卖"的卖点（铁律）

#### 卖点一：承接失败（第一优先级）

| 要素 | 量化标准 |
|------|---------|
| **触发条件** | 分歧出现，中军没有站出来，或承接明显失败 |
| **具体表现** | 下杀无承接/跌破关键结构位/放量破位/承接断断续续 |
| **执行要求** | 不管盈亏，先走 |
| **常见错误** | "再等等，它是中军"——用信仰对抗结构 |

#### 卖点二：身份撤销（结构变化）

| 要素 | 量化标准 |
|------|---------|
| **触发条件** | 确认它不再是首选；市场明显换人 |
| **具体表现** | 新承接者频繁出现/它从"首选"变"备选"/承接时断时续 |
| **执行要求** | 撤销中军假设，而不是找理由死扛 |
| **核心原则** | 中军不是"还能不能接"，而是"是不是首选" |

#### 卖点三：情绪进入退潮期

| 要素 | 量化标准 |
|------|---------|
| **触发条件** | 板块退潮，情绪不再支持 |
| **具体表现** | 板块不再回流/修复失败/龙头只跌不反/资金系统性撤离 |
| **执行要求** | 降仓或清仓 |
| **核心认知** | 不是中军不行，是情绪已经不允许结构存在 |

### 4.2 中军退位三种结果与对应操作

| 退位结果 | 判定标准 | 操作 |
|---------|---------|------|
| **退位→结构继续** | 板块依然频繁回流，分歧依然能被修复，新的承接者迅速顶上，旧中军退居二线但不崩 | 不再把原中军当唯一核心，可做防守锚，重心转向新承接者 |
| **退位→结构轮换** | 原中军退位，新承接者站出来，角色开始轮流 | 交易核心不是"谁是中军"而是"中军岗位是否仍存在"，围绕承接最稳的参与 |
| **退位→结构瓦解** | 新承接者迟迟不出现/每次分歧无人兜底/修复无力/板块不再回流 | 撤销所有中军假设，立刻退出整个结构 |

**判断口诀**：退位不可怕，没人接班才可怕。

### 4.3 被动离场/清仓条件汇总

| 优先级 | 条件 | 判定标准 | 操作 |
|--------|------|---------|------|
| P0 | 承接失败 | 分歧时中军未站出来或承接明显失败 | 立即清仓 |
| P0 | 身份撤销 | 不再是首选承接者 | 撤销中军假设，清仓 |
| P0 | 情绪退潮 | 板块不再回流，修复失败 | 降仓或清仓 |
| P1 | 连续3次判断失败 | 连续3次中军判断错误 | 暂停中军交易，退回观察模式 |
| P1 | 伪中军识破 | 高位横盘实为出货/跟风承接/消息一次性 | 立即清仓 |
| P2 | 中军进入衰亡期 | 板块≥5日无回流，分歧不再修复 | 退出整个结构 |

### 4.4 极简买卖公式（盘中可用）

> **分歧买承接，修复不追高；承接断即走，身份撤即清。**

## 第五部分 仓位管理模块

### 5.1 中军四阶段×四仓位规则

| 中军阶段 | 结构特征 | 仓位比例 | 仓位逻辑 | 禁忌 |
|---------|---------|---------|---------|------|
| **试用期** | 承接1-2次，候选池仍在，身份未确认 | 10-20%（轻仓/观察仓） | 用最小成本换取最大确定性 | 因为"稳"而加仓；因为"它是中军"而重仓 |
| **确认期** | 多次分歧验证，候选池收缩，市场初步共识 | 50-70%（中等仓位） | 可做结构型持有 | 第一次确认时直接满仓 |
| **主导期** | 一有分歧就找它，路径依赖，"看起来最安全" | 30-50%（不增反减，滚动为主） | 利用稳定性做低风险套利，不赌趋势加速 | 主导期重仓（最接近退位的前一站） |
| **退位/轮值期** | 不再是唯一选择，新承接者出现，结构仍活跃 | 10-20%（快进快出，明显降仓） | 只能"用"不能"信" | 退位期死扛，把理解变信仰 |

### 5.2 核心仓位纪律

| 纪律 | 原文 | 量化执行 |
|------|------|---------|
| **最大仓位禁忌** | "我永远不会在中军身份最确定的时候，用最大仓位" | 主导期仓位≤确认期仓位的70% |
| **阶段匹配原则** | 仓位随"被调用次数"增加，而不是随"涨幅"增加 | 按生命周期阶段定仓位，不按涨跌定仓位 |
| **金矿型仓位** | 不是"一次重仓"，而是"多次正确参与" | 每次参与仓位取决于当前结构阶段 |
| **试用不重仓** | 试用期仓位≤20% | 硬约束 |
| **确认不贪仓** | 确认期仓位50-70%，不满仓 | 硬约束 |
| **主导反减仓** | 主导期仓位30-50%，低于确认期 | 硬约束 |
| **退位快清仓** | 退位期仓位≤20%，快进快出 | 硬约束 |

### 5.3 盈亏比与风控要求

| 交易类型 | 最低盈亏比 | 理想盈亏比 | 止损标准 |
|---------|-----------|-----------|---------|
| **试用期中军** | 1.5:1 | 2:1 | 承接失败即走，不扛 |
| **确认期中军** | 2:1 | 3:1 | 身份撤销即走 |
| **主导期中军** | 1.5:1 | 2:1 | 滚动止损，不恋战 |
| **退位期中军** | 1:1 | 1.5:1 | 快进快出，严格止损 |
| **金矿型中军** | 2:1 | 3:1 | 按当前阶段止损 |

### 5.4 三种"危险仓位"（必须规避）

| 危险类型 | 表现 | 后果 | 预防措施 |
|---------|------|------|---------|
| **确认即满仓** | 试用期直接用确认期仓位 | 一旦误判损失巨大 | 试用期强制≤20% |
| **越涨越加仓** | 把结构交易做成情绪交易 | 主导期高位接盘 | 主导期强制减仓 |
| **退位期死扛** | 把"理解中军"变成"信仰中军" | 结构瓦解后大亏 | 退位期强制≤20% |

## 第六部分 过滤条件模块

### 6.1 伪中军三大骗术识别规则

| 骗术类型 | 典型表现 | 识破方法 | 过滤结果 |
|---------|---------|---------|---------|
| **高位横盘装稳（最常见）** | 位置不低，不再大涨也不怎么跌，分时横着走 | 板块再次分歧时，看它是"被动不跌"还是"主动去接"——只是不跌=高危 | 过滤 |
| **跟风承接装中军（最迷惑小白）** | 龙头分歧时也有承接，修复时也会反弹，"每一步都没缺席" | 核心区分：没有它板块会不会明显更难受？换谁都行=不是中军 | 过滤 |
| **消息刺激装中军（只能用一次）** | 突发利好/政策刺激/产业新闻，关键节点被猛推 | 消息刺激只能解释一次行为；消息消退后结构换人=一次性工具 | 过滤 |

**万能伪中军识别公式**："离开这一次行情，它是否还能被结构需要？"→ 不能=伪中军。

### 6.2 中军体系五大禁区（禁止入场场景）

| 禁区 | 判定标准 | 原因 | 正确做法 |
|------|---------|------|---------|
| **情绪极端冰点期** | 连续普跌、反弹一日游、没有持续主线、板块轮动极快 | 资金在"撤离"不是"构建"，承接只是技术性自救 | 停止中军判断，只观察不参与 |
| **纯情绪小票行情** | 市值极小、一字秒板频繁、换手极低或极高、情绪主导一切 | 装不下资金，不需要稳定，只需要"快" | 切换思维：要么不做，要么承认是情绪博弈 |
| **指数级系统性风险** | 政策突发、指数快速破位、所有板块同步下杀 | 资金不再区分结构，只讲"先活下来" | 立刻撤销所有中军假设，退出或极度降仓 |
| **板块逻辑已结束** | 板块不再回流、分歧不再修复、情绪只跌不反 | 中军岗位已被撤销 | 放弃整个结构，不是换一个"中军" |
| **自身状态不对** | 连续亏损后、情绪急躁、开始"想证明自己" | 容易过度解读，强行确认 | 暂停判断，回到观察和训练模式 |

**盘前自检表**：5个问题中≥2个"不确定"→今天不做中军。
1. 今天有没有清晰主线？
2. 板块是否具备持续性？
3. 市场是否允许结构存在？
4. 是否真的需要稳定器？
5. 我当前情绪是否稳定？

### 6.3 中军失效的提前预警信号

| 预警信号 | 判定标准 | 处理方式 |
|---------|---------|---------|
| **板块不再回流** | 板块≥3日无回流，龙头只跌不反 | 撤销中军判断，减仓或清仓 |
| **分歧不再修复** | 分歧出现后修复失败，情绪快速冷却 | 结构瓦解信号，退出 |
| **不再是第一选择** | 新承接者频繁出现，原中军从首选变备选 | 心理取消"中军身份" |
| **承接断断续续** | 原中军承接不再连续，时有时无 | 降仓，准备退出 |
| **新的承接核心频繁出现** | 每次分歧换不同的人承接 | 结构轮换或瓦解信号 |

**关键规则**：当上述任意2条同时出现时，立刻撤销中军判断。

### 6.4 信号质量评分体系

| 评分项 | +2分（强） | +1分（中） | 0分（弱） | -1分（无效） |
|--------|----------|----------|----------|-------------|
| **承接次数** | ≥5次被调用 | 3-4次 | 1-2次 | 仅1次 |
| **承接质量** | 每次分歧都主动承接、结构位不破 | 多数分歧承接、偶尔破位的边缘 | 承接时断时续 | 只在修复时出现 |
| **容量+共识** | 大成交+市场反复使用 | 中等成交+多次使用 | 小成交或只用1-2次 | 装不下资金 |
| **板块状态** | 启动期或分歧期 | 高潮期 | 退潮初期 | 退潮末期/冰点 |
| **候选池替代性** | 无真正替代品 | 有少量替代但不如它 | 有替代且差距不大 | 换谁都行 |

**信号质量阈值**：
- **极佳信号**：8-10分（确认期中军，中等仓位）
- **良好信号**：5-7分（试用期→确认期过渡，轻仓→中仓）
- **可接受信号**：3-4分（试用期，观察仓）
- **无效信号**：<3分（禁止入场）

### 6.5 中军适用前提四条件（少一个都不行）

1. 有明确且持续的板块主线
2. 板块内存在分歧与修复的循环
3. 资金体量已经大到需要稳定器
4. 市场情绪允许结构存在

**判定规则**：任一条不成立→中军体系失效→停止使用。

## 第七部分 金矿型中军专项规则

### 7.1 三种矿型分级

| 矿型 | 使用次数 | 替代性 | 对板块作用 | 资金态度 | 参与方式 |
|------|---------|--------|-----------|---------|---------|
| **铜矿型** | 1-2次 | 容易 | 阶段性 | 试用 | 单次参与 |
| **银矿型** | 能反复用 | 中等 | 周期性 | 配合 | 条件配合时参与 |
| **金矿型** | 多轮多次 | 极低 | 长期性 | 信任 | 反复正确参与 |

### 7.2 金矿型中军诞生土壤（四条件缺一不可）

| 条件 | 量化标准 |
|------|---------|
| **板块容量足够大** | 小票无法承载，结构必须依赖重心票 |
| **板块逻辑具备跨周期性** | 不是一条消息/一段情绪，可以反复讲反复用 |
| **板块内竞争不极端** | 不天天换核心/不天天换叙事 |
| **资金形成路径依赖** | "一不稳，就找它"的市场习惯 |

### 7.3 金矿型中军四个长期盘面信号

| 信号 | 量化标准 |
|------|---------|
| **分歧越多被调用越多** | 每一轮分歧几乎都有它的身影 |
| **不追求效率只追求稳定** | 很少成为涨幅冠军，但也极少成为拖累 |
| **退位-复活中变强** | 每一次退位都像"养矿"，下一次复活共识更强 |
| **逐渐成为默认中军** | 不需要再证明，市场默认"需要稳定就用它" |

### 7.4 金矿型中军参与原则

| 原则 | 量化执行 |
|------|---------|
| **三个不能做** | 不能追求单次极致收益；不能用情绪票方式做；不能期待天天表现 |
| **三个必须做** | 只在结构分歧时参与；只在被调用时参与；不被短期涨跌干扰判断 |
| **核心纪律** | 矿在，但必须在"被需要"的时候才进场 |
