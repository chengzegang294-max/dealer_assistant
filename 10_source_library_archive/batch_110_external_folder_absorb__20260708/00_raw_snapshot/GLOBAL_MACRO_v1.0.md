## 一、核心策略类型

### 1.1 风险平价（Risk Parity）— 桥水全天候

- **创始人**：钱恩平（Edward Qian），2005年系统阐释；桥水1996年实践
- **核心**：基于资产风险贡献（而非资产种类）配置权重
- **公式化**：低波动资产高配、高波动资产低配，确保每类资产对组合风险贡献均等
- **桥水配置**：30%股票、40%国债、15%黄金、15%其他
- **收益目标**：穿越周期，获得稳健的Beta收益

**桥水中国（2021年起）**：
- 与华润信托合作发行"创意择优"系列
- 投资中国股票、债券、大宗商品及衍生品
- 2022年Q1收益4.81%，百亿私募中排名第三

### 1.2 CTA趋势跟踪（管理期货）

- **定义**：利用期货/期权多空双边交易，跟踪趋势获利
- **特点**：低胜率、高盈亏比；与股债低相关；危机时 often 正收益
- **中国CTA**：2022年Q1大宗商品上涨，CTA策略一枝独秀；洛书投资+7.01%、千象资产+6.88%
- **策略类型**：均线择时、布林带突破、MACD、动量、RSI等

### 1.3 跨市场套利

| 套利类型 | 标的 | 可行性 |
|----------|------|--------|
| A-H股 | 同时上市A股与港股 | ✅ 港股通 |
| 股指期货贴水 | 沪深300期货 vs 现货 | ✅ 需期货权限 |
| 商品期现 | 期货 vs 现货仓单 | ⚠️ 需产业资源 |
| 国债期货 | 期现套利、跨期套利 | ⚠️ 需机构规模 |
