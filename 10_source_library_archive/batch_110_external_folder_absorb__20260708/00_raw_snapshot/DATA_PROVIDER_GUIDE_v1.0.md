## 一、数据分层总览

| 层级 | 数据类型 | 免费方案 | 付费方案 | 适用对象卡 |
|------|----------|----------|----------|-----------|
| L1 | 日K线 + 基础财务 | Tushare Pro / AkShare | Wind / iFinD | 全部 |
| L2 | 分钟K线 + 实时行情 | 有限（积分/频率限制） | JoinQuant / RiceQuant / Wind | VP, YTC |
| L3 | Level-2逐笔 + 委托队列 | ❌ 无免费 | Wind / 交易所直连 | INSTB（needs_extra_data） |
| L4 | 龙虎榜 + 机构持仓 | Tushare Pro（积分） | Wind / 付费API | INSTB（needs_extra_data） |
| L5 | 另类数据（舆情/ESG） | AkShare部分覆盖 | 米筐 / 第三方 | MFLOW（扩展） |

## 二、免费数据源详细对比

### 1. Tushare Pro

| 项目 | 内容 |
|------|------|
| 费用 | 免费（积分制，每日有限额） |
| 覆盖 | 股票、期货、基金、期权、宏观、财报、龙虎榜、北向资金 |
| 频率 | 日K免费，分钟K需积分，Tick/Level-2需高阶权限 |
| 稳定性 | 中（积分不足时返回空DataFrame） |
| 复权 | 支持前复权/后复权 |
| 适用 | 个人研究、低频策略回测 |
| 限制 | 高频调用受限，实时数据有延迟，非商业用途 |

**关键接口**：
- `pro.daily()` — 日K线
- `pro.moneyflow_hsgt()` — 北向资金
- `pro.top_list()` — 龙虎榜
- `pro.fina_indicator()` — 财务指标

### 2. AkShare

| 项目 | 内容 |
|------|------|
| 费用 | 完全免费开源 |
| 覆盖 | 股票、期货、基金、期权、可转债、宏观、舆情、数字货币 |
| 频率 | 依赖第三方网站（东方财富、新浪等），实时性一般 |
| 稳定性 | 低-中（接口可能随网站改版变动） |
| 适用 | 快速原型、多源数据交叉验证 |
| 优势 | 无需注册，即装即用，覆盖面极广 |

**关键接口**：
- `ak.stock_zh_a_hist()` — A股历史K线
- `ak.stock_zh_a_spot_em()` — 实时行情
- `ak.macro_china_gdp_yearly()` — 宏观数据

### 3. Baostock

| 项目 | 内容 |
|------|------|
| 费用 | 完全免费 |
| 覆盖 | A股历史K线、指数成分股、财务报表 |
| 频率 | 日线/周线/月线 |
| 稳定性 | 中（社区活跃度较低） |
| 优势 | 专业的复权数据，长周期历史数据质量高 |
| 劣势 | 接口风格较老，实时数据无覆盖 |

| 项目 | 内容 |
|------|------|
| 费用 | 机构级，年费数万到数十万 |
| 覆盖 | 全市场、全品种、全球数据 |
| 接口 | `wapi` / `PyWAPI` / Excel插件 |
| 优势 | 数据质量最高，覆盖最全，机构标准 |
| 劣势 | 个人用户难以承担 |
| 适用 | 专业资管机构 |

### 2. 同花顺iFinD

| 优势 | 数据质量高，回测环境成熟，迁移成本低 |

### 4. 聚宽 JoinQuant

| 项目 | 内容 |
|------|------|
| 费用 | 免费版（每日100万条查询，1分钟级回测）+ 付费版 |
| 覆盖 | 内置A股数据，支持模拟盘交易 |
| 优势 | 浏览器端编程，社区活跃，策略库丰富 |
| 劣势 | 数据导出受限，实盘需额外付费 |
| 适用 | 策略研究、快速验证 |

## 五、Kimi建议：数据获取策略

### Phase 1（回测阶段）：免费层优先
- **主力**：Tushare Pro（注册获取Token）+ AkShare（备用）
- **存储**：本地Parquet格式（列式存储，压缩率高，读取快）
- **更新**：每日收盘后自动拉取，缓存到本地

### Phase 2（模拟盘阶段）：付费增强
- **补充**：JoinQuant（模拟盘环境）或 RiceQuant（数据质量）
- **目标**：验证策略在更接近实盘的数据环境下的表现

### Phase 3（实盘阶段）：机构级数据
- **升级**：Wind 或 iFinD（确保数据实时性和准确性）
- **注意**：实盘数据的微小错误（复权错误、停牌漏记）可能导致灾难性后果

## 六、数据存储与缓存建议

| 场景 | 推荐格式 | 理由 |
|------|----------|------|
| 原始数据存档 | Parquet | 列式存储，压缩率高，兼容Pandas/Polars |
| 高频计算 | 内存DataFrame | Polars优先，速度比Pandas快10-100倍 |
| 长期历史 | HDF5 | 结构化、可压缩，适合大容量时间序列 |
| 实时行情 | 内存缓存 + 定期落盘 | 低延迟优先 |

---

## 七、数据风险警示

1. **AkShare稳定性风险**：接口依赖第三方网站，可能突然失效。建议：多源交叉验证，Tushare为主、AkShare为辅
2. **Tushare积分耗尽**：高频回测可能触发积分限制。建议：本地缓存，减少重复调用
3. **复权数据一致性**：不同源的复权因子可能不一致。建议：选定一个主数据源，不复用多源复权
4. **停牌处理**：免费源对停牌处理可能不完整。建议：回测引擎必须内置停牌检测逻辑
