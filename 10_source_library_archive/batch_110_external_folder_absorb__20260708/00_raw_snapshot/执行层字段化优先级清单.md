# 执行层字段化优先级清单

> 制作人：Kimi
> 日期：2026-06-19
> 目标：明确 10 个执行层对象的字段化顺序，避免 GLM 散焦

---

## 阅读说明

**为什么需要这份清单？**
- 执行层目前有 13 个对象，只有 3 个可用（XBREAKING、CHZL_BSS、DALT_80）
- 其余 10 个全是"只读概念"或"后续对象入口"
- GLM 资源有限，不能同时推进 10 个，必须排优先级

**排序依据**：
1. **与你现有指标的贴近度**（能否利用已冻结的 KD MTF / Volty / RSJ 字段？）
2. **你的交易风格匹配度**（A股波段为主，外汇趋势为辅）
3. **缠论/TK 互补需求**（已有缠论买卖点，还需要什么类型的执行？）
4. **字段化难度**（越容易提取的先做，快速出成果）

---

## 第一梯队：立即字段化（本轮 GLM 任务）

### 1. CHZL_BSD 细节补全 — 缠论三类买卖点止损规则

| 维度 | 内容 |
|------|------|
| **为什么先做** | CHZL_BSD 已升到 known_input_output，但止损规则还没精确量化。止损是风控核心，没有止损=不能实盘。 |
| **与现有指标关系** | KD MTF P0 的 `kd_week_extreme_zone` 可以作为止损的减仓触发条件 |
| **GLM 需要做什么** | 补全三类买卖点的精确止损公式：1Buy 止损=前一笔极值；2Buy 止损=中枢 ZG/ZD；3Buy 止损=中枢 ZZ 中轴或 ZG/ZD。给出 `atr_multiplier` 建议（如 1.0xATR 或 1.5xATR）。 |
| **预计产出** | `CHZL_BSD_STOPLOSS_RULES.md`：每个 bsd_type 对应的 stop_loss_price 计算公式 |
| **难度** | 低（已有触发条件，只差止损位） |

### 2. TK-R6 — IB 回撤阻挡 → TP3 概率增强

| 维度 | 内容 |
|------|------|
| **为什么先做** | TK-R6 是 TK 系统的"核心优势"——判断 IB 区域是否有效阻挡，决定 TP3 延伸信心。这是 TK 区别于其他价格行为系统的关键特征。 |
| **与现有指标关系** | 直接利用 TK-IB 的输出（ib_high, ib_low），无需额外指标 |
| **GLM 需要做什么** | 给出 5 个状态标签的精确量化定义（touch_only/reject_weak/reject_clear/inside_ib/break_through），用影线/实体比例。给出 threshold 建议。 |
| **预计产出** | `TK_R6_QUANT_SPEC.md`：每个标签的价格行为判据 + 单元测试用例 |
| **难度** | 中（需要人工标注样本验证） |

### 3. TK-R8 — B 区域 Qualify 壳

| 维度 | 内容 |
|------|------|
| **为什么先做** | TK-R8 是 ABC 结构的"过滤器"，防止在无效回撤区入场。没有它，TK-CB 会有很多假信号。 |
| **与现有指标关系** | 与 TK-R1（Fib TP/SL骨架）直接相关，TP3 延伸依赖 ABC 结构成立 |
| **GLM 需要做什么** | 量化 ABC 结构有效性：B 回撤占 AB 的比例阈值（38.2%-61.8%）、C 点创新高/低确认、结构失效条件。 |
| **预计产出** | `TK_R8_QUANT_SPEC.md`：abc_valid + b_zone_qualify 的布尔公式 |
| **难度** | 中（需要波浪比例计算） |

## 第二梯队：本轮完成后跟进（下轮 GLM 任务）

### 4. TK-R7 — AO 背离风险调整标签

| 维度 | 内容 |
|------|------|
| **为什么次做** | R7 是"锦上添花"的风险标签，不是入场必需。先有 R6/R8 的入场过滤，再叠加 R7 的风险修正。 |
| **与现有指标关系** | 与 KD MTF P0 的 `kd_week_extreme_zone` 联合使用（超买+背离=减仓） |
| **GLM 需要做什么** | AO 参数标准化（5/34）、背离判定公式（价格新高+AO未新高）、与 KD MTF 的联合规则。 |
| **预计产出** | `TK_R7_QUANT_SPEC.md`：ao_divergence_flag + risk_adjust_action 的触发条件 |
| **难度** | 低（AO 是标准指标，公式公开） |

### 5. Brooks BPB — Breakout Pullback

| 维度 | 内容 |
|------|------|
| **为什么次做** | Brooks BPB 是 A股波段交易的经典执行方法，与缠论二类买卖点高度重叠，但 Brooks 有更细致的 pullback 深度分类。 |
| **与现有指标关系** | 与 KD MTF `kd_day_signal` 联合使用（回调时 KD 金叉=入场时机） |
| **GLM 需要做什么** | 提取 BPB 的触发条件： breakout 后的 pullback 深度阈值（如 38.2%/50%/61.8% Fib 回撤）、成交量确认。 |
| **预计产出** | `BROOKS_BPB_QUANT_SPEC.md`：pullback_depth + volume_confirm 的字段定义 |
| **难度** | 中（Brooks 原著是文字描述，需要量化转换） |

### 6. YTC TST/BOF/BPB

| 维度 | 内容 |
|------|------|
| **为什么次做** | YTC 框架与你的 KD MTF 三周期体系天然对齐（HTF/TF/LF = 周/日/4H）。TST/BOF/BPB 提供了比 TK 更系统的执行分类。 |
| **与现有指标关系** | YTC S/R框架（已在结构层）是前提，此对象是其执行层延伸 |
| **GLM 需要做什么** | 量化 TST（Test）、BOF（Breakout Failure）、BPB（Breakout Pullback）的判定条件，用价格与 S/R 区的关系。 |
| **预计产出** | `YTC_TST_QUANT_SPEC.md`：三种信号的触发条件 + 失效条件 |
| **难度** | 中（依赖 S/R 区的精确划定） |

| 维度 | 内容 |

### 8. Williams Range Breakout

| 维度 | 内容 |

## 第四梯队：不优先（等市场拓展时再考虑）

### 10. ICT OB/FVG + Seiden SD + BTMM OTE

| 维度 | 内容 |
|------|------|
| **为什么不优先** | 这三个都是"供需区/订单块"类型的执行方法，主观性极强（Order Block 位置因人而异，供需区划定无统一标准）。你的仓库哲学是"只读结构，不预测"，这类方法更适合有经验的交易员主观判断，不适合完全自动化。 |
| **与现有指标关系** | 与 CHZL_ZS（中枢）功能重叠（都是价格重叠区域），但 CHZL_ZS 已有精确公式，这三个没有。 |
| **建议做法** | 先冻结为"只读概念"，等你实际交易中觉得"中枢不够用了，需要更微观的入场区"时再字段化。 |
| **预计产出** | 暂不产出，保持"只读概念"状态 |
| **难度** | 高（主观性强，难以量化） |

## 给 GLM 的指令模板

你可以直接复制以下这段话发给 GLM：

> GLM，请按以下优先级处理执行层字段化：
>
> **第一优先级（本轮必须完成）**：
> 1. CHZL_BSD 止损规则补全（1Buy/2Buy/3Buy 各自的止损位公式）
> 2. TK-R6 IB 回撤阻挡的精确量化（5 个状态标签的价格行为判据）
> 3. TK-R8 B 区域 Qualify 壳（ABC 结构有效性 + B 区域深度阈值）
>
> **第二优先级（本轮完成后跟进）**：
> 4. TK-R7 AO 背离（AO 参数 + 与 KD MTF 联合规则）
> 5. Brooks BPB（pullback 深度 + 成交量确认）
> 6. YTC TST/BOF/BPB（三种信号的判定条件）
>
> **第三优先级（有空再做）**：
> 7. Turtle 唐奇安通道（公开公式，快速字段化）
> 8. Williams Range Breakout（NR4/ID + 突破确认）
> 9. LBR Holy Grail（ADX>30 + EMA20 拉回）
>
> **不优先（保持只读概念）**：
> 10. ICT OB/FVG、Seiden SD、BTMM OTE（主观性太强，等实际交易需要时再字段化）
>
> 每个对象请输出：伪代码 + 字段冻结表 + 一个单元测试用例。
