## 二、高频交易认定标准（明确红线）

**高频交易定义**（满足任一即认定）：
1. 单账户每秒申报/撤单笔数合计 ≥ **300笔**
2. 单账户全日申报/撤单笔数合计 ≥ **20000笔**

**高频交易额外要求**：
- 额外报告服务器位置、系统测试方案
- 差异化收费（流量费、撤单费可能从0.01元/笔升至0.1元/笔）
- 合规成本预计增加15%-20%

**数据**：截至2024年6月末，A股高频交易账户约1600个，占程序化交易额60%。

## 三、四类异常交易行为监控

| 类别 | 监控内容 | 对我们的影响 |
|------|----------|-------------|
| 1. 瞬时申报速率异常 | 短时间内申报量过大 | 中低频策略不受影响 |
| 2. 频繁瞬时撤单 | 订单停留时间需 ≥ **50毫秒** | 确保最小订单停留时间 |
| 3. 频繁拉抬打压 | 多只股票小幅拉抬打压 | 分散交易，避免集中冲击 |
| 4. 短时间大额成交 | 同一机构产品集中同向交易 | 若多账户需合并风控 |

**交易所措施**：
- 触发指标 → 问询和合规教育
- 多次触发 → 限制账户交易、暂停主机托管资源
- 严重违规 → 通报证监会、现场检查、约谈

## 四、程序化交易报告要求

**"先报告，后交易"**：
- 账户基本信息、资金信息、交易信息、软件信息
- 量化机构需报备策略底层逻辑与模型参数
- 未备案算法禁止实盘运行
- 穿透式监管：内外资统一标准

## 五、对我们的系统影响评估

| 维度 | 当前系统状况 | 合规状态 |
|------|-------------|----------|
| 交易频率 | T+1，日频/月频，远<300笔/秒 | ✅ 完全合规 |
| 订单停留 | 日内持有，无频繁撤单 | ✅ 合规 |
| 申报速率 | 非高频，无速率压力 | ✅ 合规 |
| 集中交易 | 单账户单策略，无多产品共振 | ✅ 合规 |
| 报告义务 | 个人投资者，暂无强制报告要求 | ✅ 暂不受影响 |
| 策略备案 | 非机构私募，无需报备算法 | ✅ 暂不受影响 |

> **结论**：我们系统的T+1中低频策略天然合规，不会触发任何高频或异常交易监控。

## 六、Kimi建议：上线前合规检查清单

```
□ 确认交易频率：日均申报笔数 < 20000，峰值 < 300笔/秒
□ 确认订单停留：每笔订单至少停留50ms（避免瞬时撤单）
□ 确认分散交易：单票持仓占ADV < 5%，避免冲击
□ 确认无拉抬打压：不使用"大单扫货"等激进执行方式
□ 若未来转机构运营：建立合规报告流程、策略备案文档
□ 持续关注：监管政策变化（2024-2025已密集出台）
```
