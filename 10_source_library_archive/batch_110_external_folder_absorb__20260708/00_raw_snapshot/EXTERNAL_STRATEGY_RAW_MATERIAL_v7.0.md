## 一、核心发现摘要（Kimi取舍）

### 1. GBDT类模型在A股指数增强中表现最优

- **来源**：国金证券《基于多目标、多模型的机器学习指数增强策略》（2023.12）
- **发现**：XGBoost/LightGBM/CatBoost 在预测IC及超额收益率上领先神经网络
- **数据**：沪深300超额年化15.85%、中证500为20.74%、中证1000为32.82%
- **取舍**：✅ **可纳入参考** — 但需明确这是"选股"场景，不是"择时"场景

### 2. 神经网络风险控制更优，但收益稍逊

- **来源**：同上
- **发现**：LSTM/GRU/TCN/Transformer 最大回撤显著低于GBDT，但收益稍低
- **关键**：两类模型相关性低，等权融合后风险收益平衡最佳
- **取舍**：✅ **可作为风控补充** — 不建议单独作为核心信号源

### 3. 多目标训练优于单一目标

- **发现**：同时优化「超额收益率、信息比率、Calmar比率」三目标，优于单目标
- **取舍**：⚠️ **需额外数据** — 需要较长期历史数据计算Calmar，现有A5层可部分提供

### 4. 随机森林特征重要性：市值因子主导

- **来源**：华泰证券《人工智能选股系列》（2017）
- **发现**：市值因子、反转因子、波动率因子影响最大；2017年小盘股风格失效时回撤巨大
- **警示**：基于树的模型在风格切换时容易集体失效
- **取舍**：✅ **纳入风险认知** — 任何ML模型都必须绑定PeriodQueen环境识别

### 5. 过拟合是ML量化的最大风险

- **来源**：Quant67《机器学习选股：标签构造、防过拟合、SHAP归因》
- **四个信号**：
  1. 训练AUC 0.95 vs 验证AUC 0.55 → 几乎一定过拟合
  2. 5折IC标准差比均值还大 → 时段稳定性差
  3. Top-10特征重要性跨折不重合 → 学到的是噪声偏好
  4. 样本外IC从0.06→0.01→转负 → 典型过拟合衰减曲线
- **取舍**：✅ **强制纳入** — 任何ML对象卡必须附加过拟合检测模块

### 6. 强化学习在A股的应用现状

- **来源**：CSDN多篇、BigQuant
- **发现**：
  - 动作空间：离散（买/卖/持有）或连续（仓位比例）
  - 核心算法：PPO（稳定收敛，15-25%年化，夏普1.2-1.8）> DQN > A3C
  - 奖励函数设计是关键：直接优化夏普比率、累计收益或风险调整收益
  - 风险：黑箱特性、极端行情异常行为、计算成本高需GPU
- **取舍**：⚠️ **谨慎纳入** — 可作为研究对象，但短期内不纳入生产Bundle

## 三、Kimi判断：哪些适合我们的系统

### ✅ 可直接纳入参考
- **XGBoost/LightGBM选股**：已有A5财报层提供基本面因子，可以叠加技术面因子训练模型
- **多模型融合思路**：与现有"投票机制"哲学一致，可扩展为"ML信号+规则信号"双源投票
- **特征重要性监控**：作为对象卡健康度指标，当Top特征突然变化时触发审查

### ⚠️ 需要额外数据/工作
- **强化学习**：需要定义完整的交易环境（状态空间、动作空间、奖励函数），工作量大
- **深度学习模型**：需要GPU训练，与现有"Windows单机部署"约束冲突
- **多目标优化**：需要Calmar比率等长期数据，现有数据可能不足

### ❌ 明确不适合
- **纯LSTM股价预测**：被多篇文献证实过拟合严重，且缺乏可解释性
- **高频RL交易**：与A股T+1约束冲突，且需要Level-2数据
- **无环境识别的ML模型**：2017年小盘股风格失效的教训——任何ML模型必须绑定PeriodQueen
