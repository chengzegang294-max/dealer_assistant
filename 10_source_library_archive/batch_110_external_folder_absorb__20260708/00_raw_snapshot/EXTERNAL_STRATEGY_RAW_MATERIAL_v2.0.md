## 2. 微观结构与集合竞价资料

### 2.1 集合竞价机制详解（A股特色）

**来源**: 多来源综合（Quant67/视界量化/百度文库）
**核心机制**:
- 9:15-9:20：可申报、可撤单 → "虚假申报"高发期
- 9:20-9:25：可申报、不可撤单 → 真实意图反映
- 14:57-15:00：收盘集合竞价（不可撤单）
- 撮合原则：最大成交量原则确定单一开盘价

**Kimi想法**: 我们的数据只有日OHLCV（开盘价=集合竞价结果），没有9:15-9:25期间的逐笔申报数据。因此"集合竞价阶段分析"（如撤单率、订单簿不平衡）在当前数据条件下**不可行**。但以下元素可以采纳：
- **开盘价缺口**：日OHLCV中 `open` vs 前日 `close` 的跳空/低开，可以计算并作为信号
- **集合竞价成交量占比**：光大证券因子（见2.2），可用日数据计算
- **9:20-9:25不可撤单规则**：作为 `MFLOW` 早盘意图判断的"可信度权重"（9:20后的数据比9:15前更可信）

### 2.2 光大证券：集合竞价成交量占比因子

**来源**: BigQuant量化交易，2023-06-01
**核心发现**: 集合竞价阶段成交量占比是"有别于低频因子的有效选股因子"
**公式**: `集合竞价成交量占比 = 集合竞价成交量 / 全天成交量`
**机制**: 集合竞价阶段反映隔夜信息释放后的多空认同度
**Kimi想法**: 这个因子**可以直接用日OHLCV计算**（开盘第一根K线的成交量 ≈ 集合竞价成交量，或者用日内数据）。即使只有日OHLCV，也可以用`开盘30分钟成交量 / 全天成交量`作为近似。这是一个**proxy_quantizable_now**的因子。可以融入 `MFLOW` 对象卡作为 `mflow_open_intensity` 字段。

### 2.3 集合竞价大单识别与试盘现象

**来源**: 百度文库多篇，2025-10-28
**核心发现**:
- 9:20-9:25出现的大单信号可靠性更高（不可撤单）
- 大单识别公式：`集合竞价成交量 = 集合竞价成交金额 / 开盘价`
- 约65%的高开股票当日维持强势，58%低开股票延续弱势
- 五个关键指标：股价变动幅度、委比变化、量比数值、现量大小、涨幅排名

**Kimi想法**: "大单识别"需要Level-2逐笔数据，标记为 `needs_extra_data`。但"高开/低开延续概率"可以用日OHLCV的跳空缺口统计得到。可以建立一个"跳空缺口统计模型"：计算历史数据中向上跳空后当日收红的概率，作为 `VOLFAC` 的辅助判断。这是`proxy_quantizable_now`。

### 2.4 缺口理论与价格发现

**来源**: 百度文库，2025-10-29
**核心机制**: 缺口是集合竞价阶段资金博弈的结果，反映市场共识断裂
- 向上跳空：当日最低价 > 前日最高价
- 向下跳空：当日最高价 < 前日最低价
**Kimi想法**: 缺口理论可以与我们的 `CHZL_TREND`（缠论趋势）结合。缠论中的"缺口"是重要概念（特征序列缺口），但现有对象卡未明确处理。建议：在 `CHZL_TREND` 中新增 `gap_analysis` 字段，记录当日缺口类型（普通/突破/持续/衰竭），作为趋势强度判断的辅助。这是`proxy_quantizable_now`（日OHLCV即可计算）。

### 2.5 高频交易的"开盘动量-收盘反转"策略

**来源**: 海能投顾白皮书，2025-05-13
**核心发现**: 量化机构普遍采用"开盘动量-收盘反转"策略：
- 集合竞价阶段制造虚假流动性幻象
- 尾盘进行大规模反向平仓
- 导致A股高开低走现象影响权重达39.8%
- 异常报撤单次数飙升至平常交易日的3.7倍
- 62%订单存活时间不足0.3秒

**Kimi想法**: 这是**反我们的策略**的信息。如果大量机构在做"开盘动量-收盘反转"，那么：
- **开盘追涨的风险极高**（被机构反向收割）
- **尾盘可能是更好的入场时机**（机构平仓后价格回归）
- 这支持我们的**中低频定位**（不追开盘，等尾盘或次日确认）
- 可以作为 `PERIOD_QUEEN` 的"市场微观结构风险"参数：当检测到"高开低走"模式时，降低 `ATTACK_SUSTAINED` 的置信度

## 3. 尾盘策略资料

### 3.1 尾盘30分钟量化特征

**来源**: 新浪财经/沪深交易所统计，2025-02-16
**核心数据**:
- 收盘前30分钟成交量占全天18.7%
- 价格波动标准差是盘中时段的1.8倍
- 振幅超过1%的交易日占比63.2%
- 最后15分钟价格反转概率41.7%
- 机构大单成交占比提升至28.6%
- 北向资金尾盘净流入占比达当日总量的42%（2022年数据）
- 尾盘30分钟市场噪音较盘中减少37%（VWAP对比）

**Kimi想法**: 这些统计数据非常有价值。可以建立"尾盘特征指标"：
- `尾盘成交量占比 = 14:30-15:00成交量 / 全天成交量`（需要分钟级数据，v1.1）
- `尾盘波动率 = 14:30-15:00价格标准差`（需要分钟级数据，v1.1）
- `尾盘反转信号`：当日14:30-15:00价格方向与9:30-14:30相反，且幅度>1%（需要分钟级数据，v1.1）

但用**日OHLCV的近似**:
- `close_vs_high_low`：收盘价接近最高价还是最低价，反映尾盘方向
- `upper_shadow_ratio`：上影线长度（尾盘回落）
- `lower_shadow_ratio`：下影线长度（尾盘拉升）

这些可以融入 `YTC` 或 `BPB` 作为"日内结构"分析字段。`proxy_quantizable_now`。

### 3.2 尾盘买入法（数据验证）

**来源**: CSDN，2025-05-30
**验证数据**: 1000次交易，收盘前5分钟买入，次日开盘后5分钟卖出
**结果**: 平均收益率2.5%，但个体差异大（有的远高于此，有的亏损严重）
**风险**: 收盘前买入后，次日开盘不利变化无法反应；T+1制度下持仓≤18小时

**Kimi想法**: 平均2.5%但个体差异大 → 说明尾盘策略本身不具备稳定的alpha，而是需要严格的筛选条件。这与我们的"候选池过滤"哲学一致。尾盘策略可以作为 `TrialEntry` 或 `MeanReversion`（v1.1）的一个子场景：仅在满足严格条件（如量比>1.8、MACD金叉、股价在5-20日均线之间）时才允许尾盘入场。但**不作为独立策略**，而是作为现有策略的"时间窗口增强"。

### 3.3 拉尾盘/打尾盘的主力行为分析

**来源**: 东方财富/雪球，2025-05-01/2025-08-08
**拉尾盘目的**:
- 技术面维护（收在关键支撑上方）
- 吸引跟风盘（制造强势假象，次日出货）
- 机构做净值（季末/年末美化报表）
- 消息博弈（提前获知利好抢筹）
- 护盘行为（防止质押爆仓）

**打尾盘目的**:
- 次日拉升前的最后震仓
- 恐慌性抛售

**Kimi想法**: "拉尾盘/打尾盘"是**日OHLCV可检测的**（通过上影线/下影线长度）。可以建立"尾盘异动检测"：
- `tail_abnormality_score = (close - low) / (high - low)`（低位拉尾盘）
- `head_abnormality_score = (high - close) / (high - low)`（高位打尾盘）
- 当 score > 0.7 时，标记为"尾盘异动"

这在 `PERIOD_QUEEN` 的"日线结构分析"中可以作为辅助输入。例如：
- 大量股票同时出现"拉尾盘" → 可能是机构做净值，次日回调概率高
- 大量股票同时出现"打尾盘" → 恐慌性抛售，可能是情绪极端点

### 3.4 沪市基金尾盘新规（2026年6月15日）

**来源**: 虎嗅，2026-07-04
**新规**: 沪市基金尾盘14:57-15:00统一执行收盘集合竞价（仅限价申报、不可撤单）
**影响**: 此前A股尾盘3分钟成交额占全市场约11%，新规后预估回落至5%以内
**影响策略**: 尾盘套利的量化策略收益空间被系统性压缩

**Kimi想法**: 这是**市场结构变化**的重要信息。我们的系统在设计回测时，需要明确**回测时间范围**：
- 2026年6月15日前：尾盘连续竞价，价格可能异动
- 2026年6月15日后：尾盘集合竞价，价格更稳定
- 这会影响`YTC`的S/R框架验证（尾盘价格作为当日收盘价是否可靠）

在回测框架中应增加"市场结构版本"参数，区分不同时间段的交易规则。这是一个重要的**回测精度**问题。

## 4. 行为金融学与情绪指标资料

### 4.1 Fear & Greed Index（恐惧与贪婪指数）

**来源**: CNN Business / 多个中文来源，2026-06-01/2026-07-02
**核心机制**: 7个子指标合成0-100指数：
1. 股票价格动能
2. 股票价格强度（52周新高vs新低比率）
3. 股票价格广度（上涨vs下跌股票比例）
4. 看跌/看涨期权比例（Put/Call Ratio）
5. 垃圾债券需求（风险偏好）
6. 市场波动率（VIX）
7. 避险需求（国债vs股票）

**区间划分**:
- <25：极度恐慌（Extreme Fear）→ 潜在买入机会
- 25-45：恐惧（Fear）
- 45-55：中性（Neutral）
- 55-75：贪婪（Greed）
- >75：极度贪婪（Extreme Greed）→ 回调风险增加

**Kimi想法**: 这是经典的情绪量化框架。我们需要为A股市场构建**A股版恐惧贪婪指数**。但A股没有Put/Call Ratio（期权市场不成熟）、VIX对应不完善。因此需要本土化改造：
- **A股版子指标**:
  1. 涨跌家数比（替代股票广度）
  2. 涨停/跌停家数比（A股特色）
  3. 融资融券余额变化（替代垃圾债券需求）
  4. 波动率指数（iVIX，替代VIX）
  5. 北向资金流向（替代避险需求）
  6. 新开户数/成交量变化（散户情绪）
  7. 市场宽度（新高/新低比率）

- 作为 `PERIOD_QUEEN` 的**情绪输入**，辅助判断 regime_state。
- 当指数>75时，强制降低 `entry_min_votes`（提高门槛）或降低仓位上限。
- 当指数<25时，作为"逆势买入"的辅助信号（但需基本面确认）。

**数据需求**: 需要全市场涨跌家数、融资融券数据、北向资金数据。部分可用（Wind已有），部分需补充。标记为 `needs_extra_data`（v1.1）。

### 4.2 华泰港股情绪指数

**来源**: 华泰证券研报，2025-09-08
**核心机制**: 三大维度十大日度高频指标合成：
1. **资金流向**: 南向资金流入强度、买入成交活跃度、黄金隐含人民币汇率
2. **市场动能**: 交易活跃度、主要指数相对强弱、AH溢价
3. **衍生品隐含预期**: 恒生波指、恒指升贴水、看涨看跌期权持仓比

**区间划分**:
- >70：贪婪区间
- 60-70：乐观
- 40-60：中性
- 30-40：悲观
- <30：恐慌

**历史表现**:
- 2020年以来：恐慌位置买入+贪婪位置卖出 → 累计39.6%绝对收益，49%超额收益
- 多空策略：106%绝对收益，116%超额收益

**Kimi想法**: 华泰的框架非常系统，但针对港股。对于A股，可以构建类似框架：
- **资金流向维度**: 主力资金净流入强度、融资融券余额变化、ETF申购赎回
- **市场动能维度**: 成交额变化率、主要指数RSI、行业宽度
- **隐含预期维度**: 股指期货升贴水、波动率指数（iVIX）

这个可以作为 `MACRO_ENVIRONMENT_SCORER`（v1.0已有五维度宏观评分）的**情绪维度补充**。将宏观评分（利率/汇率/流动性）与市场情绪评分（恐惧/贪婪）结合，作为 `PERIOD_QUEEN` 的"软性建议"输入。

### 4.3 散户行为与主力反向收割

**来源**: 海能投顾/今日头条，2025-05-13/2025-03-23
**核心发现**:
- 78.6%个人投资者在高开时陷入FOMO（错失恐惧症）
- 开盘半小时情绪值>75时，当日收跌概率82.3%
- 散户情绪指标与主力资金净流入呈显著负相关（R²=0.82）
- "钓鱼单"策略：机构在集合竞价制造虚假买盘繁荣→诱使散户追高→连续竞价阶段撤单反手做空

**Kimi想法**: 这些发现**强烈支持我们的"反散户"设计哲学**：
- 当市场情绪极度乐观（散户FOMO）时，系统应该**逆势减仓**（而非追涨）
- 当市场情绪极度悲观（散户恐慌）时，系统应该**逆势建仓**（但需严格风控）
- 这本质是"逆向投资"（Contrarian Investing）的量化表达

可以在 `PERIOD_QUEEN` 中增加 "Contrarian Bias"（逆向偏差）参数：
- 当散户情绪>75（贪婪）时，Contrarian Bias = -1（系统降低买入意愿，提高卖出意愿）
- 当散户情绪<25（恐惧）时，Contrarian Bias = +1（系统提高买入意愿，但需Kelly/VolTarget确认）
- 当情绪中性时，Contrarian Bias = 0

这个参数作为 `PERIOD_QUEEN` 输出的 `pq_contrarian_bias` 字段，直接影响 `entry_min_votes` 和 `max_position_size`。

### 4.4 行为金融学中的心理偏差

**来源**: 微信公众号/凯金斯股票网，2025-08-05
**核心偏差**:
- 确认偏误（Confirmation Bias）：只看支持自己观点的信息
- 羊群效应（Herd Behavior）：跟风交易
- 后悔厌恶（Regret Aversion）：不愿止损
- 控制幻觉（Illusion of Control）：认为能预测短期波动
- 注意力驱动交易（Attention-Driven Trading）：买热搜股/分析师推荐股（通常跑输大盘）

**Kimi想法**: 这些偏差是**设计控制台UI的重要参考**。我们的控制台应该：
- 在交易前显示"行为风险检查清单"：是否确认偏误？是否羊群效应？
- 在皇帝控制台中增加"台谏系统"的"行为审查"功能：六科给事中不仅审查技术信号，还审查用户的心理偏差
- 当用户连续亏损时，系统提示"是否陷入后悔厌恶？建议强制止损"
- 这属于**治理架构的增强**，不是交易策略本身的增强。

## 5. 板块轮动与风格切换资料

### 5.1 量化资金与风格切换

**来源**: 微信公众号，2025-06-05
**核心发现**:
- 量化资金已成为A股市场波动的关键推动力
- 量化策略主要依赖多因子模型（反转因子、动量因子、量价因子）
- **反转因子**: 涨多了可能跌，跌多了可能反弹。但当前有效性减弱（高频套利资金介入）
- **动量因子**: 捕捉非理性情绪（追涨杀跌），在情绪不理性时有效
- 量化资金主导了大小盘风格切换

**Kimi想法**: 反转因子有效性减弱 → 这意味着简单的"均值回归"策略（如v1.1计划中的MeanReversion）在A股可能面临挑战。但动量因子在情绪不理性时有效 → 这支持我们的**趋势跟踪**定位（在ATTACK_SUSTAINED状态，动量因子是核心）。

关键启示：我们的系统需要**动态识别"当前市场是谁主导"**：
- 当量化资金主导（动量有效）时 → 优先趋势跟踪
- 当散户资金主导（反转有效）时 → 优先均值回归
- 这可以通过 `MFLOW` 的"主力资金vs散户资金比例"来判断。

### 5.2 行业轮动策略框架

**来源**: BigQuant/知乎/雪球，2023-2026
**核心逻辑**: 利用不同行业强势时间的错位，切换行业配置以最大化收益
**轮动因子**:
- 20日涨幅/10日涨幅（动量）
- 当前20日涨幅 > 3日前20日涨幅（动量加速）
- RSRS（N日最高价/最低价斜率比）
- BBI动量（多空均线/收盘价）
- ROC6（6日变动速率）
- BIAS10（10日乖离率）

**光大证券ADC模型**: 三位一体自适应行业轮动
- 量价因子 + 财务因子 + 分析师预期因子
- 覆盖产业上中下游，不同美林时钟周期偏向不同标的

**Kimi想法**: 行业轮动是A5财报选股层（`A5_FUNDAMENTAL_INTEGRATION_v1.0.md`）的**上层增强**。目前A5只有个股层面的筛选，没有行业/板块层面的轮动。建议：
- 在 `A5` 选股层增加"行业动量评分"：计算申万/中信行业的20日涨幅排名，只选排名前30%的行业中的个股
- 在 `PERIOD_QUEEN` 中增加"行业轮动状态"判断：当前是"行业集中"（单一行业主导）还是"行业分散"（多行业轮动）
- 当"行业集中"时，允许集中配置热门行业（但单行业上限20%）
- 当"行业分散"时，强制分散配置（至少3个行业）

**数据需求**: 行业指数数据（申万/中信行业指数）。Wind已有。`proxy_quantizable_now`。

### 5.3 风格切换（大小盘/价值成长）

**来源**: 华宝证券基金研报，2023-04-05
**核心发现**:
- A股存在明显的大小盘风格轮动
- 小盘风格基金在特定阶段有超额收益
- 主观多头：偏向成长，大小盘均衡
- 量化多头：偏向小盘成长，行业集中度27%

**Kimi想法**: 风格切换是**宏观环境评分**（`MACRO_ENVIRONMENT_SCORER`）的输入之一。可以将"大小盘风格"、"价值成长风格"作为宏观评分的子维度：
- 当流动性宽松时 → 小盘成长占优
- 当流动性收紧时 → 大盘价值占优
- 当经济扩张时 → 周期/成长占优
- 当经济衰退时 → 防御/价值占优

这与 `MACRO_ENVIRONMENT_SCORER_v1.0.md` 的"五维度评分"可以结合：在"流动性25%"维度中，增加"流动性→风格映射"规则。

## 9. Kimi 的取舍总结（第三批）

### 9.1 确认已有的设计是合理的

- 中低频定位（不追开盘）→ 与"机构开盘反向收割"的实证一致
- 候选池过滤（严格条件）→ 与"尾盘策略个体差异大"的实证一致
- 三层风控（Van Tharp/Kelly/VolTarget）→ 与行为金融学"强制止损避免后悔厌恶"一致
- 治理架构（台谏系统）→ 可以作为"行为审查"的载体

### 9.2 需要补充的增强（第三批）

1. **缺口统计模型**（v1.0）：CHZL_TREND新增gap_analysis，判断缺口类型（普通/突破/持续/衰竭）。
2. **集合竞价成交量占比**（v1.0）：MFLOW新增mflow_open_intensity，作为早盘资金强度指标。
3. **尾盘异动检测**（v1.0）：YTC/BPB新增tail_abnormality_score，检测拉尾盘/打尾盘行为。
4. **A股版恐惧贪婪指数**（v1.1）：基于A股数据（涨跌家数、融资融券、北向资金）构建情绪指数。
5. **逆向偏差参数**（v1.1）：PERIOD_QUEEN新增Contrarian Bias，在市场极端情绪时反向调整策略。
6. **行业动量评分**（v1.1）：A5选股层增加行业筛选，只选行业动量排名前30%的个股。
7. **市场结构版本**（v1.0）：回测框架增加不同时间段的交易规则参数（如尾盘新规）。

### 9.3 保持不做的

- 实时集合竞价分析（需Level-2）
- 高频日内策略（需Tick数据+T+0）
- 跨市场联动（港股通）
- 纯情绪驱动交易（无基本面锚定）
