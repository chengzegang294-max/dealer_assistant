# 御前会议控制台界面设计 v1.0

> **本文档全部内容源于用户（仓库所有者）的想法，由 Kimi 整理为可直接给编程 AI 实现的 UI 设计文档。**
> 版本：v1.0 | 状态：界面设计阶段 | 目标：定义投资管家控制台的所有界面布局与交互流程

---

## 一、设计原则

```text
1. 文化沉浸：所有界面元素使用中国古代制度术语（奏折、批红、留中、六科等）
2. 信息密度高：一个屏幕展示所有关键信息，不需要频繁翻页
3. 操作简洁：常用操作不超过 3 步完成
4. 模式感知：不同制度模式下，界面自动变色、变布局
5. 紧急通道：极端情况下，一键操作永远在最显眼位置
```

```text

常态内阁模式（NORMAL）  →  青绿色  #2E8B57
牛市集权模式（BULL）    →  赤红色  #CD5C5C
熊市监察模式（BEAR）    →  玄黑色  #2F4F4F

危机独裁模式（CRISIS）  →  深红色  #8B0000（带闪烁警告）
```

## 六、通知与警报设计

### 6.1 通知分级

```text
🔴 紧急（立即弹窗 + 声音）
  - 触发条件：组合回撤 > 20%、单笔亏损 > 10%、市场进入 HALT
  - 行为：弹窗覆盖整个屏幕，必须用户确认才能继续

🟡 重要（弹窗提示）
  - 触发条件：组合回撤 > 10%、模式自动切换、六科封驳
  - 行为：右下角弹窗，5 秒后自动消失

🟢 普通（日志记录 + 可选提示）
  - 触发条件：奏折提交、审查通过、交易执行
  - 行为：记录到起居注，主界面状态栏更新

🔵 信息（仅日志）
  - 触发条件：数据同步完成、对象卡计算完成
  - 行为：仅记录日志，不提示
```

## 七、对编程 AI 的实现要求

```text
1. 界面框架：
   - 使用 Python rich 库实现终端界面（https://github.com/Textualize/rich）
   - 或直接使用 print + 字符串拼接（简单方案）
   - 所有界面元素使用 Unicode 框线字符（╔═╗等）

2. 颜色实现：
   - 使用 rich 的 Console(color_system="truecolor")
   - 或 ANSI 转义码（\033[31m 红色等）
   - 每个模式的颜色定义在配置文件中

3. 交互实现：
   - 主循环：while True 读取用户输入
   - 命令解析：使用简单的字符串 split 解析
   - 输入提示：命令行末尾显示 "> _"

4. 状态管理：
   - 控制台状态存储在 EmperorConsole 类中
   - 每次操作后刷新仪表盘
   - 使用 Observer 模式监听系统状态变化

5. 响应速度：
   - 仪表盘刷新 < 1 秒
   - 命令响应 < 0.5 秒
   - 紧急警报立即弹出
```
