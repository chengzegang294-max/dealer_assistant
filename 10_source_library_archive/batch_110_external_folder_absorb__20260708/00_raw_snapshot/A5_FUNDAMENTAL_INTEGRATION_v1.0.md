## 一、A5 组财报书籍概述

### 1.1 两本书的定位

```text
A5 组包含两本财报估值书籍：

1. 《财务报表分析与股票估值》（郭永清著）
   - 核心：基于自由现金流（FCF）的绝对估值模型
   - 方法：DCF（现金流折现）+ 相对估值（PE/PB/PS）
   - 特色：强调"估值是艺术，不是科学"——给出估值区间而非精确值
   - 用户已逐表修复第10章，达到入库标准

2. 《上市公司财报分析》（另一本中文财报书）
   - 核心：基于杜邦分析框架的财务健康度评估
   - 方法：ROE 分解 + 盈利质量分析 + 财务风险识别
   - 特色：强调"排雷"——先排除财务造假/暴雷标的

两本书的互补关系：
  郭永清版 → "定价值"（这个公司值多少钱）
  上市公司财报分析版 → "排雷"（这个公司有没有问题）
```

### 1.2 与现有选股层的对比

```text
现有选股层（MFLOW/VOLFAC/INSTB）：
  - 基于量价数据（资金流向、波动率、机构行为）
  - 高频更新（日频/分钟频）
  - 短期导向（1-4 周）
  - 技术驱动

A5 财报选股层：
  - 基于财务报表（利润表、资产负债表、现金流量表）
  - 低频更新（季频）
  - 中长期导向（6-12 个月）
  - 价值驱动

结论：两者不是替代关系，而是"双轨并行"——
  技术选股（MFLOW/VOLFAC）→ 短期交易机会
  价值选股（A5 财报）→ 中长期持仓标的
```

### 2.2 A5 基本面过滤的具体指标

```text
【第一层：排雷检查（来自《上市公司财报分析》）】

必过项（任一项触发 → 排除）：
  1. 审计意见非标（保留意见、无法表示意见）
  2. 连续两年亏损（ST 风险）
  3. 经营现金流连续为负（盈利质量差）
  4. 应收账款/营收 > 50%（收入确认激进）
  5. 存货周转天数异常增加（产品滞销）
  6. 大股东质押比例 > 80%（资金链风险）
  7. 商誉/净资产 > 30%（减值风险）

评分项（综合评分 < 60 → 排除）：
  ┌─────────────────┬──────────┬─────────────────────────────┐
  │ 指标            │ 权重     │ 评分标准                    │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ ROE（3年均值）   │ 20%     │ >20%:10分, 15-20:8分,      │
  │                 │         │ 10-15:6分, <10:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 营收增长率       │ 15%     │ >30%:10分, 20-30:8分,      │
  │（3年CAGR）      │         │ 10-20:6分, <10:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 净利润现金含量   │ 15%     │ >100%:10分, 80-100:8分,    │
  │                 │         │ 50-80:5分, <50:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 资产负债率       │ 10%     │ <40%:10分, 40-60:7分,      │
  │                 │         │ 60-80:4分, >80:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 毛利率           │ 10%     │ >40%:10分, 30-40:8分,      │
  │                 │         │ 20-30:5分, <20:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 流动比率         │ 10%     │ >2:10分, 1.5-2:8分,        │
  │                 │         │ 1-1.5:5分, <1:0分          │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 股权质押比例     │ 10%     │ <20%:10分, 20-40:7分,      │
  │                 │         │ 40-60:4分, >60:0分         │
  ├─────────────────┼──────────┼─────────────────────────────┤
  │ 商誉占比         │ 10%     │ <10%:10分, 10-20:7分,      │
  │                 │         │ 20-30:4分, >30:0分         │
  └─────────────────┴──────────┴─────────────────────────────┘
```

```text
【第二层：估值评估（来自郭永清《财务报表分析与股票估值》）】

估值方法（双轨验证）：

轨道 A：绝对估值（DCF 模型）
  步骤：
    1. 预测未来 5 年自由现金流（FCF）
    2. 选择折现率（WACC，A 股通常 8-10%）
    3. 计算永续价值（Gordon Growth Model，g=3%）
    4. 企业价值 = PV(FCF) + PV(永续价值)
    5. 每股价值 = 企业价值 / 总股本
  
  判断标准：
    - 当前股价 < DCF 估值下限 → 极度低估（买入）
    - 当前股价在 DCF 估值区间 → 合理（观望）
    - 当前股价 > DCF 估值上限 → 高估（回避）

轨道 B：相对估值（PE/PB Band）
  步骤：
    1. 计算历史 PE Band（5 年分位：10%/25%/50%/75%/90%）
    2. 计算历史 PB Band（同上）
    3. 当前 PE 在历史 25% 分位以下 → 低估
    4. 当前 PB 在历史 25% 分位以下 → 低估
  
  判断标准：
    - PE 和 PB 都在 25% 分位以下 → 极度低估
    - PE 或 PB 在 50% 分位附近 → 合理
    - PE 或 PB 在 75% 分位以上 → 高估

双轨验证规则：
  - DCF 和相对估值都显示低估 → 强烈买入信号
  - DCF 和相对估值分歧 → 深入研究原因
  - 都显示高估 → 排除
```

## 三、A5 与现有选股层的协同

### 3.1 双轨选股流程

```text
流程：A5 基本面选股 → 技术因子过滤 → 对象卡信号确认

详细步骤：

Step 1：A5 基本面选股（每季度执行一次）
  - 输入：全 A 股 5000+ 只
  - 处理：排雷检查 + 财务评分 + 估值评估
  - 输出：基本面候选池（~500 只）
  - 触发条件：财报季（4月、8月、10月）

Step 2：技术因子过滤（每日执行）
  - 输入：基本面候选池（500 只）
  - 处理：MFLOW + VOLFAC + ATRATIO（LIMITED）
  - 输出：技术面候选池（~100 只）
  - 规则：只在基本面候选池内运行技术因子

Step 3：对象卡信号确认（实时）
  - 输入：技术面候选池（100 只）
  - 处理：CHZL_BSD + BPB + TKR7 + YTC
  - 输出：交易候选池（~20 只）

Step 4：风控审查（每笔交易前）
  - 输入：交易候选池（20 只）
  - 处理：Van Tharp + Kelly + PeriodQueen
  - 输出：可交易标的（~5-10 只）

关键设计：
  - A5 是"第一层过滤器"，不是最后一层
  - 技术因子只能在 A5 候选池内运行（基本面黑名单内的标的不允许交易）
  - A5 评分可以上调/下调对象卡的信号强度
```

### 3.2 A5 评分对对象卡信号的影响

```text
A5 财务评分 → 对象卡信号强度调节器：

调节规则：
  A5 综合评分 ≥ 80 → 对象卡信号强度 +1（上限 10）
  A5 综合评分 60-79 → 对象卡信号强度不变
  A5 综合评分 40-59 → 对象卡信号强度 -1（下限 0）
  A5 综合评分 < 40 → 该标的禁止交易（无论技术信号多强）

示例：
  标的 A：CHZL_BSD strength=8, A5 评分=85 → 最终 strength=9
  标的 B：CHZL_BSD strength=8, A5 评分=55 → 最终 strength=7
  标的 C：CHZL_BSD strength=9, A5 评分=35 → 禁止交易

A5 估值状态 → 策略组合选择：
  标的 DCF 折让 > 30%（极度低估）→ 倾向 TrendFollowing 策略（长期持有）
  标的 DCF 折让 10-30%（轻度低估）→ 倾向 BreakoutPullback 策略（波段）
  标的 DCF 折让 < 10%（合理）→ 不进入候选池
```

### 3.3 财报季的特殊处理

```text
财报季（4月、8月、10月）的额外流程：

1. 财报发布前 1 周：
   - 暂停该标的的新开仓（防止业绩暴雷）
   - 已有持仓：设置 tighter stop（-3% 而非 -5%）

2. 财报发布后 3 天内：
   - 重新运行 A5 基本面选股
   - 更新财务评分和估值评估
   - 若评分大幅下降 → 触发"紧急审查"（是否清仓）

3. 财报发布后 1 周：
   - 恢复正常交易
   - 新的 A5 候选池生效

紧急审查触发条件：
  - 财务评分下降 > 20 分
  - 审计意见变为非标
  - 净利润同比下降 > 50%
  - 经营现金流转负
```

    """
    A5 财报估值选股层
    不是对象卡，而是选股层的基础设施
    """
    
    def __init__(self, data_source):
        self.data = data_source
        self.mine_sweep_rules = MineSweepRules()
        self.scoring_model = FinancialScoringModel()
        self.valuation_model = ValuationModel()
    
    def run_quarterly_screening(self, date: str) -> list[str]:
        """
        季度筛选主入口
        
        Returns:
            基本面候选池（股票代码列表）
        """
        # 1. 获取全 A 股财务数据
        all_stocks = self.data.get_all_stocks()
        
        # 2. 排雷检查
        survivors = []
        for symbol in all_stocks:
            financials = self.data.get_financials(symbol, date)
            if self.mine_sweep_rules.check(symbol, financials):
                survivors.append(symbol)
        
        # 3. 财务评分
        scored = []
        for symbol in survivors:
            financials = self.data.get_financials(symbol, date)
            score = self.scoring_model.calculate(financials)
            if score["total_score"] >= 60:
                scored.append((symbol, score))
        
        # 4. 估值评估
        selected = []
        for symbol, score in scored:
            price = self.data.get_price(symbol, date)
            valuation = self.valuation_model.assess(symbol, price, score)

## 六、对编程 AI 的明确指令

```text
1. A5 财报选股层不是对象卡，而是选股基础设施（类似 DataLoader 的扩展）
2. A5 候选池作为技术因子的前置过滤器（技术面只能在基本面候选池内运行）
3. A5 评分可以调节对象卡信号强度（+1/0/-1）
4. 财报季（4月/8月/10月）有特殊处理流程
5. DCF 模型参数允许手动输入（不是全自动）
6. 排雷检查是"一票否决"，评分是"综合筛选"
7. 所有财报数据缓存在本地，季频更新
```
