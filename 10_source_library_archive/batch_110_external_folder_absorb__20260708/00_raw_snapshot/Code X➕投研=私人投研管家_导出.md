### 术语解释
- **宏观环境分析 (Macro environment analysis)**：指从利率、汇率、政策等多方面评估市场整体环境，用以判断当前是处于牛市、熊市还是震荡市的定性评估过程。
- **风险雷达 (Risk Radar)**：一套监测系统，专门用于实时捕捉资产价格异动、波动率变化及估值偏离度，旨在为投资者提供及时的风险提示信号。
- **资产配置 (Asset Allocation)**：指投资者通过将资金分散投资于股票、债券、现金、黄金等不同资产类别，以降低投资组合整体波动，追求收益最大化与风险可控的策略。
- **策略验证 (Strategy Backtesting/Verification)**：指将以往的投资决策或市场判断与实际结果进行复盘对比，分析偏差来源，从而不断优化未来投资逻辑和判断准确性的过程。

## 术语解释
- **宏观环境分析 (Macro environment analysis)**：指从利率、汇率、政策等多方面评估市场整体环境，用以判断当前是处于牛市、熊市还是震荡市的定性评估过程。
- **风险雷达 (Risk Radar)**：一套监测系统，专门用于实时捕捉资产价格异动、波动率变化及估值偏离度，旨在为投资者提供及时的风险提示信号。
- **资产配置 (Asset Allocation)**：指投资者通过将资金分散投资于股票、债券、现金、黄金等不同资产类别，以降低投资组合整体波动，追求收益最大化与风险可控的策略。
- **策略验证 (Strategy Backtesting/Verification)**：指将以往的投资决策或市场判断与实际结果进行复盘对比，分析偏差来源，从而不断优化未来投资逻辑和判断准确性的过程。
