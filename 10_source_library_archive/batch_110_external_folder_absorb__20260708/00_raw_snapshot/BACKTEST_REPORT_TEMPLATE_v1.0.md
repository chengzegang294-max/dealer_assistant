# 回测报告模板规范 v1.0

> **本文档全部内容源于用户（仓库所有者）的想法，由 Kimi 整理为结构化文档供编程 AI 参考。**
> 版本：v1.0 | 状态：模板设计阶段 | 核心目标：定义单因子/组合/系统的三级回测报告标准格式

---

## 一、报告体系总览

```text
三级报告体系：

Level 1: 单因子回测报告（Single Factor Report）
  - 目标：验证单个对象卡的有效性
  - 频率：每个对象卡首次入库时 + 每季度复测
  - 篇幅：5-10 页

Level 2: 组合回测报告（Strategy Bundle Report）
  - 目标：验证策略组合（多个对象卡协同）的有效性
  - 频率：每个策略组合首次定义时 + 每月复盘
  - 篇幅：10-20 页

Level 3: 系统回测报告（System Backtest Report）
  - 目标：验证整个交易系统的端到端表现
  - 频率：每年一次 + 重大参数调整后
  - 篇幅：20-40 页
```

## 六、对编程 AI 的明确指令

```text
1. 报告必须包含：原始数值 + 达标判断（✅/❌）+ 与基准的对比
2. 所有图表必须自动生成（matplotlib/seaborn），不手工绘制
3. 报告输出格式：Markdown + PNG 图表 + CSV 原始数据
4. 三级报告有明确的触发条件和生成频率
5. 日报生成器必须独立实现，不依赖回测引擎
6. 所有报告模板使用 Jinja2 或字符串模板，参数化填充
7. 报告文件命名规范：{type}_{name}_{date}_{version}.md
```
