## 阅读说明

- **object_id**: 对象唯一标识，用于脚本/运行时调用
- **function_bucket**: 功能归属（结构/能量/执行/风控/选股/组合构建）
- **process_layer**: 在流程中的位置（特征→信号→过滤器→仓位→执行约束→组合构建）
- **maturity**: 成熟度（只读概念 / shell_only / 已摘公式 / 可进入候选组合 / 半学术级 / 学术级）
- **mapping**: 与你现有指标（KD MTF / Volty / XBreaking / PV / RSJ）的具体映射关系
- **combines_with**: 建议组合的对象（互补关系）
- **overlaps_with**: 功能重叠的对象（替代关系，不要同时放入同一组合）
- **failure_modes**: 失效场景，用于回测时排除或标记
