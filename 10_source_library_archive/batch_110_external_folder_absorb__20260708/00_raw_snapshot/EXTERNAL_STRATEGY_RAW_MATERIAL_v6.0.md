| **科创板** | ±20% | 无限制 | 按科创板机制 | 上海市场 |

### A3 T+1 与交易单位

- **T+1制度**：当日买入，次一交易日才能卖出
- **主板/创业板**：100股整数倍买入，不足100股一次性卖出
- **科创板**：200股起，超过200股以1股递增
- **北交所**：100股起，每笔申报以1股递增

### A4 退市整理期规则

来源：[新浪财经](https://cj.sina.com.cn/) + [财梯网](https://www.cadforex.com/)

| 市场 | 退市整理期首日 | 退市整理期次日及之后 |
|------|---------------|---------------------|
| **深圳市场** | 无涨跌幅限制，30%/60%两档临时停牌10分钟 | 主板退市10%，创业板退市20% |
| **上海市场** | 不设置涨跌幅限制 | 按原板块机制 |

- 退市整理期：**30个交易日**（停牌天数不计入，不超过5个交易日）
- 届满后5个交易日内退市，转入新三板

## B. 算法交易执行策略

### B1 四大核心算法对比

来源：[链上百科](https://www.5nft.com/) + [微信公众号 - 金融市场中的交易执行算法](https://mp.weixin.qq.com/) + [华盛量化](https://quant-open.hstong.com/)

| 算法 | 核心机制 | 适用场景 | 优势 | 劣势 |
|------|----------|----------|------|------|
| **TWAP** | 时间均匀分割，等比例执行 | 流动性低、需稳定节奏 | 简单、稳定、无需预测 | 不考虑市场成交量变化 |
| **VWAP** | 按历史/实时成交量比例分配 | 追求市场均价、流动性好 | 贴近市场均价、降低冲击 | 需成交量预测 |
| **POV** | 子订单不超过市场成交量的预设比例 | 控制市场冲击 | 自适应市场节奏 | 极端行情下执行慢 |
| **冰山订单** | 只显示部分数量，成交后自动补充 | 隐藏大额意图 | 隐蔽性强、防抢跑 | 流动性差时暴露风险 |

### B2 算法执行流程

来源：[微信公众号 - 金融市场中的交易执行算法](https://mp.weixin.qq.com/)

```
1. 拆单（Slicing）
   └─ 将父订单拆分为N个子订单（通常6-18个）
   
2. 挂单（Placement）
   └─ 根据实时市场情况确定订单类型、价格、数量
   
3. 智能路由（Routing）
   └─ 选择最优交易渠道执行
   
4. 监控与调整
   └─ 跟踪执行进度，动态调整参数
```

### B3 VWAP 公式

```
VWAP = Σ(Pi × Vi) / ΣVi

其中：Pi = 第i次成交价格，Vi = 第i次成交量
```

### B4 冰山订单设计要点

来源：[雪球](https://xueqiu.com/) + [快期](https://www.shinnytech.com/)

- **核心思想**：水面上只露一小部分，主体隐藏在水下
- **自动补单**：当前批次完全成交后，系统自动挂出下一批
- **随机化逻辑**：加入随机延迟触发和虚假订单干扰，降低被识别概率
- **自适应暴露量**：薄市场1%-3%，深度市场8%
- **适用场景**：流动性较高的市场环境

## C. 组合优化与资产配置

### C1 马科维茨均值方差模型

来源：[百度文库](https://wk.baidu.com/) + [CSDN](https://blog.csdn.net/)

**目标函数**：
```
min σ²(rp) = ΣΣ xi·xj·Cov(ri, rj)

约束：
  rp = Σ xi·ri  （组合收益）
  1 = Σ xi      （权重和为1，允许卖空）
  或 1 = Σ xi, xi ≥ 0 （不允许卖空）
```

**关键洞察**：
- 最小方差组合：w* = Σ⁻¹·1 / (1ᵀ·Σ⁻¹·1)
- 等权重组合（朴素组合）通常优于复杂均值方差优化（样本外）
- 逆方差组合：wi = (1/σi²) / Σ(1/σn²)

### C2 Black-Litterman 模型

来源：[民生加银基金合同](https://pdf.dfcfw.com/) + [Upcommons论文](https://upcommons.upc.edu/)

**核心思想**：
- 以**市场均衡权重**为起点（先验）
- 通过投资者的**主观观点**调整预期收益
- 使用**贝叶斯分析**得到后验分布
- 再用**马科维茨框架**优化

**关键特性**：
- 观点不确定性↑ → 后验收益更靠近市场均衡
- 市场均衡不确定性↑ → 后验收益更靠近主观观点
- 带有风险约束（如目标波动率≤5%）

### C3 风险平价/波动率配置

来源：[Upcommons论文](https://upcommons.upc.edu/)

- **放弃预期收益分析**，仅关注波动率
- 构建不受收益约束的最小方差组合
- 研究表明：最小方差组合样本外表现优于有效前沿

### C4 实战策略

来源：[微信公众号 - 马科维茨组合理论](https://mp.weixin.qq.com/)

| 策略 | 说明 |
|------|------|
| 资产配置分散化 | 股票+债券+黄金，降低整体波动 |
| 止损纪律 | 单笔亏损不超过本金2% |
| 仓位控制 | 高风险资产≤5% |
| 再平衡 | 每年调整一次组合，回归目标配置 |
| 低波动因子 | 聚焦低波动率股票，长期跑赢高波动 |

## D. 量化因子库与Barra模型

### D1 Barra CNE5/CNE6 模型架构

来源：[清华大学 - 中国股票风险因子模型白皮书](https://igsm.tsinghua.edu.cn/) + [研报](https://file.iyanbao.com/)

**CNE6模型**：
- 1个 **国家因子**
- 16个 **风格因子**（归为8类）
- 32个 **行业因子**

### D2 十大风格因子

来源：[研报 - 风格动态配置](https://file.iyanbao.com/) + [国盛量化周报](https://pdf.dfcfw.com/)

| 因子 | 代码 | 含义 | 计算方式 |
|------|------|------|----------|
| **市值** | SIZE | 公司规模 | LNCAP（市值自然对数） |
| **非线性市值** | NLSIZE | 中等市值效应 | 市值立方，对市值正交化 |
| **Beta** | BETA | 市场敏感度 | 252日半衰期，504日窗口回归 |
| **动量** | MOM | 趋势延续 | 过去N月累计收益 |
| **残差波动率** | RESVOL | 非系统性风险 | HSIGMA + DASTD + CMRA |
| **估值** | BTOP | 价值/低估值 | 股东权益/市值 |
| **流动性** | LIQUIDITY | 交易活跃度 | 换手率相关 |
| **盈利** | EARNINGS_YIELD | 盈利能力 | 净利润/市值 |
| **成长** | GROWTH | 增长潜力 | 营收/净利润同比增长 |
| **杠杆** | LVRG | 财务杠杆 | 资产负债率相关 |

### D3 数据预处理四步法

来源：[CSDN - 量化多因子数据清洗](https://damodev.csdn.net/) + [百度知道](https://zhidao.baidu.com/)

```
Step 1: 去极值（Outlier Removal）
  ├─ MAD法：中位数绝对偏差
  ├─ 3σ法：超出3倍标准差
  └─ 目的：消除极端值对因子分布的扭曲

Step 2: 标准化（Standardization）
  ├─ Z-Score：(x - μ) / σ
  └─ 目的：统一量纲，使不同因子可比

Step 3: 正交化（Orthogonalization）
  ├─ 方法：特征值分解，对称正交矩阵
  ├─ 公式：S = U·diag(D^(-0.5))·Uᵀ
  └─ 目的：消除因子间相关性，避免重复暴露

Step 4: 中性化（Neutralization）
  ├─ 市值中性化：因子对市值对数回归，取残差
  ├─ 行业中性化：因子对行业哑变量回归，取残差
  └─ 目的：剥离市值/行业影响，得到纯alpha
```

### D4 因子评估指标

来源：[研报 - 因子风格择时策略](https://pdf.dfcfw.com/)

- **Rank-IC**：因子排名与未来收益排名的相关系数
- **因子收益率**：多空组合的收益
- **因子拥挤度**：判断因子是否过热
- **信息比率**：因子超额收益/跟踪误差
