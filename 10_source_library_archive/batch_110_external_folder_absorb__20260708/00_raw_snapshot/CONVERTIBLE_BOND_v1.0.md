## 一、可转债策略（A股特有优势品种）

### 1.1 双低策略（最经典）

```
双低值 = 转债价格 + 转股溢价率 × 100
```

- **低价格**：债性保护，100-115元区间安全边际高
- **低溢价率**：股性强，正股涨则转债跟涨（溢价率<10%算低）
- **筛选**：双低值前30位 → 规模>1.5亿、剩余期限>半年、上市>1个月 → 取前10只等权
- **轮动**：月度调仓
- **历史表现**：2023-2024年基于双低策略的量化组合表现稳健

### 1.2 转股溢价率套利

| 场景 | 操作 | 风险 |
|------|------|------|
| **负溢价（折价）** | 买入转债→T+1转股→T+2卖出正股 | 转股时间差、正股下跌、融券availability |
| **回售套利** | 正股<转股价70%持续30天触发回售，纯债溢价率<0时参与 | 公司不下修、信用风险 |
| **下修博弈** | 正股持续下跌，博弈公司下调转股价 | 下修不及预期、股东大会否决 |

### 1.3 量化进阶因子

- **转债余额（存量规模）**：小规模转债跑赢大盘（流动性溢价+机构忽视）
- **换手率**：低估值+高换手率 = 聪明钱进场信号
- **条款博弈**：强赎倒计时、下修意愿数值化
- **CCB定价**：深度学习模型对传统定价模型的补充

## 二、期权备兑策略（收益增强）

### 2.1 基本原理

持有50ETF/300ETF + 卖出虚值看涨期权，收取权利金增强收益。

| 市场状态 | 效果 |
|----------|------|
| 下跌 | 权利金收入缓冲损失，增强收益 |
| 震荡/温和上涨 | 权利金收入直接增强收益 |
| 快速上涨 | 被行权，收益封顶，跑输现货 |

### 2.2 回测数据（东证衍生品）

| 标的 | 增强效果（不择时） | 增强效果（择时MACD） |
|------|-------------------|---------------------|
| 50ETF | 年化5.5% | 年化8.2% |
| 300ETF | 虚值2%档最优 | 虚值2%档最优 |

**择时优化**：MACD红柱时裸持ETF，绿柱时启用备兑。

### 2.3 对系统的启示

- 可在指数增强组合中配置10%资金用于期权备兑
- 本质是对大幅上涨行情的择时问题
- 需开通期权账户，有50万资金门槛
