## 二、冲击成本模型

### 2.1 线性模型（最基础）

```
MI = η × (V / ADV)
```

- **η**：冲击系数（市场流动性参数）
- **V**：计划交易量（股数或金额）
- **ADV**：平均日成交量（通常取20日均值）

**A股冲击系数η经验值**：

| 股票类型 | 市值规模 | η范围(bps) | 典型值 |
|----------|----------|------------|--------|
| 大盘蓝筹 | >500亿 | 10-20 | 15 |
| 中盘股 | 100-500亿 | 20-40 | 30 |
| 小盘股 | 50-100亿 | 40-100 | 70 |
| 微盘股 | <50亿 | 100-300 | 150 |

**调整因子**：
- 牛市：-10% | 熊市：+20%
- 热门板块：+30% | 冷门板块：-20%
- 开盘/收盘：+40% | 盘中：-10%

### 2.2 平方根模型（Almgren-Chriss，更准确）

```
永久冲击 = α × σ × √(V/VT)
临时冲击 = β × σ × (V/VT) / √(T/τ)
```

**参数**：
- σ：日内波动率（30日已实现波动率）
- VT：市场总成交量
- V：本次交易量
- T：总执行时间（分钟）
- τ：单个时间片长度（分钟）
- α：永久冲击系数（平稳期大盘0.5-0.7，小盘1.0-1.5）
- β：临时冲击系数（正常执行速度，大盘0.8-1.2，小盘1.5-2.0）

**实战案例（小盘股快速执行）**：
- 交易量：3000万（占日均量15%）
- 执行时间：30分钟
- 日波动率：3.5%
- 永久冲击：1.8 × 3.5% × √0.15 = 2.44%
- 临时冲击：2.5 × 3.5% × 0.15 / √(30/1) = 2.39%
- **总冲击：4.83% = 144.9万元**

> **对我们系统的启示**：小盘股分层策略（如果仓位集中）的冲击成本可能吞噬全部alpha。必须限制单票仓位占ADV的比例。

## 三、执行算法

### 3.1 TWAP（时间加权平均价格）

- **原理**：将订单均匀分布在时间窗口内
- **优点**：实现简单，执行可预测，适合流动性稳定股票
- **缺点**：不考虑市场状态，可能错过有利时机
- **A股实现**：剔除集合竞价，考虑午休时间

### 3.2 VWAP（成交量加权平均价格）

- **原理**：根据历史成交量分布分配订单
- **优点**：跟随市场节奏，期望冲击最小
- **实施**：收集近20-60天分钟成交量数据，计算每分钟占比
- **优化**：使用指数加权历史数据，区分不同市场状态

### 3.3 选择建议

| 场景 | 推荐算法 | 理由 |
|------|----------|------|
| 大盘股，低 urgency | VWAP | 冲击最小，跟踪误差低 |
| 小盘股，高 urgency | TWAP+分批 | 避免集中冲击 |
| 高波动日 | VWAP | 波动期IS算法成本可能更高 |
| 占ADV >5% | 强制拆单+日内分散 | 单一信号超过ADV 5%必须拆分 |

## 四、TCA监控仪表盘（建议维度）

Quant67建议的TCA分维度归因：

| 维度 | 监控内容 | 反馈到策略侧 |
|------|----------|-------------|
| 按策略 | 策略A vs B的执行成本差异 | 成本高的策略降低仓位或停用 |
| 按算法 | VWAP/TWAP/IS各算法成本 | 高波动日切回VWAP |
| 按时段 | 开盘前30min/中段/收盘前30min | 避开高成本时段 |
| 按订单大小 | 占ADV 0.1%-0.5%/0.5%-2%/2%-5%/5%+ | 超过5%强制拆分 |
| 按市场状态 | 高波动日(IV>80) vs 低波动日 | 验证冲击系数是否随波动放大 |

## 五、对现有回测框架的补充

### 5.1 回测成本设置建议（必须项）

```python
# 回测引擎成本参数（默认保守设置）
COMMISSION_RATE = 0.00025  # 万2.5
STAMP_DUTY_RATE = 0.0005    # 千0.5（卖出单边）
TRANSFER_FEE_RATE = 0.00001 # 万0.1（双边）
SLIPPAGE_RATE = 0.001       # 0.1%（至少，小盘股需更高）
IMPACT_COST_MODEL = "sqrt"  # 平方根模型

# 小盘股额外冲击成本（根据占ADV比例动态计算）
SMALL_CAP_IMPACT_ADJUSTMENT = True
```

### 5.2 大小盘分层策略的成本修正

| 分层 | 滑点假设 | 冲击成本假设 | 总成本估计 |
|------|----------|--------------|------------|
| 大盘（>500亿） | 0.05% | 0.1% | 0.35%（买入）/ 0.85%（卖出） |
| 中盘（100-500亿） | 0.1% | 0.3% | 0.55% / 1.05% |
| 小盘（50-100亿） | 0.2% | 0.7% | 0.95% / 1.45% |
| 微盘（<50亿） | 0.5% | 1.5% | 2.05% / 2.55% |

> **关键结论**：如果小盘股策略的alpha预期不到2%，回测时又不设足够高的成本，实盘必亏。

## 六、Kimi取舍

### ✅ 必须纳入
- **显性成本模型**：佣金+印花税+过户费，回测默认值必须包含
- **滑点设置**：至少0.1%，小盘股至少0.2-0.5%
- **冲击成本估算**：平方根模型，根据占ADV比例动态计算
- **仓位限制**：单票占ADV不超过5%，否则强制拆分

### ⚠️ 可选增强
- **TWAP/VWAP执行模拟**：回测引擎中模拟订单拆分执行
- **TCA归因报表**：上线后的分维度成本监控
- **最优执行轨迹**：Almgren-Chriss框架，过于复杂

### ❌ 不纳入（当前阶段）
- **实时智能路由**：需要多券商接口
- **暗池/大宗交易**：A股暗池不发达
