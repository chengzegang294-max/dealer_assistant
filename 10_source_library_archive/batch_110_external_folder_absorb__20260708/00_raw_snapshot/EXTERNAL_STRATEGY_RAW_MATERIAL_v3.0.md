## 2. 日历效应资料

### 2.1 A股日历效应全景（聚宽/虎嗅/东吴证券）

**来源**: 多来源综合，2005-2024年Wind数据统计
**核心发现**:

| 效应类型 | 现象 | 核心逻辑 | 备注 |
|----------|------|----------|------|
| **春季躁动** | 1-3月上涨概率高，2月最强（上涨概率76%，平均涨幅4.3%） | 年初流动性宽松+两会政策预期+基金建仓 | 消费/成长板块占优 |
| **四月决断** | 4月分化加剧，业绩确定性强的个股突出 | 年报/一季报密集披露，基本面主导 | 警惕业绩暴雷 |
| **五穷六绝七翻身** | 5-6月调整概率大，7月反弹（7月上涨概率57%） | 年中流动性收紧+业绩真空期 | 近年受外部冲击弱化 |
| **年末效应** | 12月低估值蓝筹稳健，1月消费活跃 | 机构调仓锁定收益+春节消费预期 | 春节后成长股弹性更高 |
| **红周一** | 周一上涨概率54%（沪深300） | 周末政策/消息释放，情绪修复 | 外资流入常见于周一 |
| **黑周四** | 周四下跌概率显著（平均跌幅0.12%，上涨概率43%） | T+1规避周末风险+股指期货交割 | 近年量化普及后弱化 |
| **春节效应** | 节前5天至节后15天上涨概率超60% | 节前避险资金回流，节后流动性宽松 | 创业板节后5日平均涨2.3% |
| **端午劫** | 端午后一周下跌概率72.7%（2013-2023平均跌幅1.15%） | 年中资金面紧张（银行MPA考核） | 近年受美联储影响加深 |
| **3月小盘行情** | 中证2000 3月平均跑赢沪深300（超额1.8%） | 两会政策预期催化题材炒作 | 游资活跃度高 |
| **年末大盘占优** | 12月沪深300跑赢中证1000概率65% | 机构调仓至低波动蓝筹 | 北向资金年末增持消费/金融 |

**Kimi想法**: 日历效应是A股显著的"制度性/季节性"alpha来源，但有几个关键判断：
1. **传统规律正在弱化**：注册制改革、外资占比提升、量化交易普及都在削弱传统日历效应
2. **不应作为独立策略**：日历效应是"概率参考"，不是"确定性信号"。我们的系统应将其作为**PERIOD_QUEEN的辅助输入**，而非独立交易依据
3. **具体融入方式**:
   - 在 `MACRO_ENVIRONMENT_SCORER` 中增加"日历效应日历"：标记当前日期附近的季节性风险/机会
   - 在 `PERIOD_QUEEN` 的状态判断中，当处于传统高风险窗口（如端午后、6月）时，略微提高 `entry_min_votes`（+1）或降低仓位上限（-0.1）
   - 在 `A5` 选股层中，当处于"春季躁动"窗口时，略微提高成长股的评分权重；"年末效应"时提高低估值蓝筹权重
4. **数据需求**: 仅需日期信息。`proxy_quantizable_now`（纯规则，无需额外数据）。

### 2.2 方正证券"周四空仓"策略

**来源**: 方正证券回测，2000-2016年
**核心逻辑**: 逢周四空仓，其余时间持仓
**结果**: 比基准指数好很多
**Kimi想法**: 这是一个简单的日历效应策略，但"空仓"过于粗暴。我们的系统可以借鉴其思想：在"黑周四"窗口（以及传统弱势窗口），不强制空仓，而是**提高投票门槛**（如从3提高到4），让系统自然减少交易。这样既不盲目依赖日历效应，又能在统计弱势窗口保持更谨慎的态度。

### 2.3 光大证券"6-10月空仓"策略

**来源**: 光大证券回测
**核心逻辑**: 6-10月空仓（传统弱势月份）
**结果**: 比基准指数好很多
**Kimi想法**: 与"周四空仓"同理。我们的系统不应直接空仓，而是：
- 在6-10月窗口，降低 `PERIOD_QUEEN` 的 `max_position_size`（如从1.0降到0.7）
- 提高 `entry_min_votes`（如从3提高到4）
- 在 `MACRO_ENVIRONMENT_SCORER` 的"流动性"维度中，6月（半年末）和12月（年末）天然降低流动性评分

## 3. 事件驱动策略资料

### 3.1 事件驱动策略框架（华安基金/孙晨进）

**来源**: 华安基金，2016-06-06
**核心逻辑**: 事件驱动 = 驱动因子（时间/时间+指标）+ 因子与超额收益的关系
**事件类型**:
- 盈利超预期：首个交易日涨幅>5%且<9.9%，未来20日正超额收益
- 限售股解禁：解禁当天及解禁后20日有超额收益
- 高分红送转：预案公布后未来20日正超额收益
- 异常交易公告：发布后前10日到后10日超额收益
- 指数成分调整：调出成分股后20日超额收益

**推荐优先级**（从风险和收益综合考虑）:
1. 调出指数成分策略（股票池确定，时点一致，易构建组合）
2. 高分红送转策略（超额收益稳定）
3. 盈利超预期策略（四季均可操作，年化超额高）
4. 限售股解禁/异常交易公告（收益较低，但时点可提前获知）

**Kimi想法**: 事件驱动策略与我们的"投资管家"定位有一定距离（事件驱动通常需要特定数据触发和快速反应），但以下元素可以融入：
1. **盈利超预期** → 融入 `A5` 的财报评分层：当个股季报超预期时（实际盈利>预期盈利），提高基本面评分
2. **高分红送转** → 融入 `A5` 的"分红/股息"维度：高分红公司评分更高（但需警惕"高送转陷阱"）
3. **限售股解禁** → 融入 `A5` 的排雷机制：即将大规模解禁的公司自动排除（避免抛压风险）
4. **指数成分调整** → 融入 `A5` 的候选池：被调入指数的公司可作为候选池补充

### 3.2 高分红送转策略（详细）

**来源**: 多来源综合（事件驱动选股PDF/红周刊/除权填权策略）
**核心逻辑**:
- 选股：`每股分红送转/分红预案公布日股价 > 5%`
- 高送转股特征：总股本较小、每股公积金较高、每股未分配利润较高、成长性较高
- 时间窗口：预案公告日→股东大会→实施公告→股权登记日→除息日
- 历史规律：10送转5以上个股在反弹期间涨幅更大；1亿以下股本送转股涨幅大；10-20元价格区间受关注程度高

**填权策略**:
- 填权不是必然发生的，需要基本面支撑
- 股息率越低，填权修复越快（大部分一年内修复）
- 抢权仓在股权登记日收盘前了结（锁定收益，规避除权不确定性）
- 填权仓：除权后股价企稳+量能缩至除权日50%以下+不跌破关键支撑 → 二次买点
- 持仓不超过30个交易日，止损-3%或关键支撑位下方
- 红利税：持股<1月20%，1月-1年10%，>1年免

**Kimi想法**: 分红送转策略与我们的系统有以下关联：
1. **排雷机制**：高送转+大股东减持是典型陷阱，A5排雷需包含"高送转且大股东减持"的排除规则
2. **候选池增强**：高分红公司（股息率>3%）可作为价值型候选池加分项
3. **事件日历**：分红日程是确定的时间窗口，可作为 `MACRO_ENVIRONMENT_SCORER` 的"事件日历"输入
4. **填权检测**：日OHLCV可计算"除权后是否填权"（前复权数据），但不需要主动做填权策略（纯投机），只作为基本面分析参考
5. **红利税**：长期持有（>1年）免红利税 → 支持我们的中长线定位

**明确不采纳**：抢权/填权作为独立交易策略（纯投机，与"投资管家"定位不符）。但保留分红信息作为基本面筛选维度。

## 4. 回测稳健性与过拟合检测资料

### 4.1 过拟合检测框架（多来源综合）

**来源**: CSDN/MT5教程/量化回测指南，2025-2026
**核心方法**:

| 方法 | 目的 | 操作步骤 | 通过标准 |
|------|------|----------|----------|
| **样本外测试** | 验证策略在未见过数据上的表现 | 训练集（2020-2023）优化参数 → 测试集（2024）验证 | 样本外表现与样本内差异<20% |
| **Walk-Forward分析** | 滚动窗口验证，贴近实盘逻辑 | 10年数据分50个滚动周期，定期用近期数据优化、下段数据验证 | 各窗口表现一致 |
| **蒙特卡洛模拟** | 随机打乱历史路径，评估策略依赖特定结构的程度 | 随机重采样/加入噪声，1000次回测 | 95%路径盈利 |
| **参数敏感性测试** | 检查策略是否依赖"尖峰"参数 | 参数±10%变化，观察收益变化 | 性能波动<20% |
| **Bootstrap置信区间** | 随机打乱收益序列，评估统计显著性 | 多次重采样计算置信区间 | 置信区间内不包含0 |
| **随机市场数据测试** | 在其他品种/时间段测试 | 同一策略在不同品种/时段运行 | 大面积不亏损 |
| **Purged K-Fold** | 时间序列交叉验证，避免数据泄露 | 删除相邻样本的overlap | 交叉验证结果稳定 |

**稳健性检验流程图**（来自CSDN最佳回答）:
```
原始策略回测 → 经济逻辑检验？ → 否 → 淘汰
                     ↓ 是
              样本内/外划分 → 参数敏感性测试 → 性能波动<20%？
                     ↓ 否 → 淘汰
              加入交易成本重测 → 夏普>1.0？
                     ↓ 否 → 淘汰
              Walk-Forward验证 → 各窗口一致性高？
                     ↓ 否 → 淘汰
              蒙特卡洛情景模拟 → 95%路径盈利？
                     ↓ 否 → 淘汰
              小资金实盘试运行
```

**Kimi想法**: 这是**回测框架的核心质量保障机制**。我们的 `BACKTEST_FRAMEWORK_DESIGN_v1.0.md` 已定义了回测引擎，但缺少详细的**稳健性验证流程**。这是必须补充的：
1. **在回测框架中增加"过拟合检测模块"**（`src/backtest_engine/validation/`）
2. **每个对象卡上线前必须通过**：样本外测试 + Walk-Forward + 参数敏感性测试
3. **策略组合上线前必须通过**：蒙特卡洛模拟 + Bootstrap
4. **定期监控**：策略衰减监测系统（strategy decay monitoring）

**对编程AI的指令**: 在实现回测引擎时，必须包含以下验证模块：
- `OutOfSampleTester`（样本外测试）
- `WalkForwardAnalyzer`（滚动窗口分析）
- `MonteCarloSimulator`（蒙特卡洛模拟）
- `ParameterSensitivityAnalyzer`（参数敏感性分析）
- `StrategyDecayMonitor`（策略衰减监测）

### 4.2 Walk-Forward 分析（详细）

**来源**: MT5教程/量化回测指南
**核心逻辑**: "样本外测试的自动化版本"
**操作**:
- 将10年历史数据划分为50个滚动周期
- 每个周期：用近期数据优化参数 → 用下一段数据验证
- 对比样本内和样本外的表现差异
**Kimi想法**: Walk-Forward 是验证策略**参数稳定性**的黄金标准。我们的对象卡（如CHZL_BSD、BPB）都有可调参数（如ATR倍数、回调深度阈值）。在对象卡上线前，必须做Walk-Forward验证：如果参数在某个窗口表现很好，但在下一个窗口突然失效，说明该参数过拟合。

### 4.3 蒙特卡洛模拟（详细）

**来源**: MT5教程/量化回测指南
**核心逻辑**: 引入随机性，评估策略在"非特定历史路径"下的表现
**方法**:
- 随机打乱历史数据的时间序列
- 加入噪声（随机扰动价格）
- 多次回测（建议1000次）
- 观察最终盈亏分布
**Kimi想法**: 蒙特卡洛可以回答"如果历史重演但顺序不同，策略会怎样？"这是评估策略鲁棒性的重要工具。在我们的系统中，蒙特卡洛可以应用于：
- 单个对象卡：打乱信号顺序，测试信号独立性
- 策略组合：打乱不同对象卡的信号组合，测试组合稳定性
- 市场环境：模拟极端行情（如连续10日跌停），测试风控机制

## 5. 绩效归因资料

### 5.1 Brinson 绩效归因模型

**来源**: 多来源综合（海通证券/AmazingQuant/Brinson教程）
**核心公式**（BHB形式）:
```
超额收益 = 配置收益 + 选股收益 + 交互收益

配置收益 = Σ(w_p^i - w_b^i) × R_b^i
选股收益 = Σw_b^i × (R_p^i - R_b^i)
交互收益 = Σ(w_p^i - w_b^i) × (R_p^i - R_b^i)

其中：
  w_p^i = 组合在i行业的权重
  w_b^i = 基准在i行业的权重
  R_p^i = 组合在i行业的收益
  R_b^i = 基准在i行业的收益
```

**BF形式（Brinson-Fachler）**:
```
超额收益 = 配置效应 + 选择效应 + 交互效应

配置效应 = Σ(w_p^i - w_b^i) × (R_b^i - R_b^total)
选择效应 = Σw_b^i × (R_p^i - R_b^i)
交互效应 = Σ(w_p^i - w_b^i) × (R_p^i - R_b^i)
```

**多期归因**: 单期结果不能简单累加，需考虑再投资影响。Carino算法通过引入因子将乘积关系转变为累加形式。

**Kimi想法**: Brinson模型是**绩效归因的行业标准**，我们的系统必须包含。但需要考虑A股特色：
1. **基准选择**：A股常用基准（沪深300/中证500/中证1000）
2. **行业分类**：申万或中信行业分类
3. **归因维度**：
   - 第一层：Brinson归因（配置+选股+交互）
   - 第二层：多因子归因（风格因子+行业因子+特质收益）
   - 第三层：收益分解（交易收益+选股收益+择时收益+基准收益+交易成本）
4. **与现有文档的关联**:
   - `BACKTEST_REPORT_TEMPLATE_v1.0.md`（三级回测报告）需要包含Brinson归因
   - `A5_FUNDAMENTAL_INTEGRATION`（选股层）需要暴露行业/风格因子，供归因使用
   - `STRATEGY_BUNDLES`（策略组合）需要定义基准，供归因对比

### 5.2 AmazingQuant 的绩效分析框架

**来源**: GitHub (AmazingQuant)，开源
**核心模块**:
1. **净值数据分析**: 年化波动率、日/月收益率分布、最大回撤、夏普/卡玛/特雷诺/索提诺、Beta/跟踪误差/信息比率
2. **交易数据分析**: 滑点损失、总交易次数、胜率、平均持仓周期、换手率、交易费用
3. **持仓数据分析**: 行业市值占比、估值风格分析、综合风格分析
4. **绩效归因**: 多因子归因 + Brinson归因 + 收益分解

**收益分解公式**:
- 市场中性策略: 总收益 = 交易收益 + 选股收益 + 择时收益 + 基差收益 + 交易成本
- 纯股票策略: 总收益 = 交易收益 + 选股收益 + 择时收益 + 基准收益 + 交易成本

**Kimi想法**: AmazingQuant的框架非常系统，与我们已有的 `BACKTEST_REPORT_TEMPLATE_v1.0.md` 高度一致。可以借鉴其"三层归因"设计：
- 第一层（Brinson）：回答"为什么跑赢/跑输基准？"（配置+选股+交互）
- 第二层（多因子）：回答"收益来自哪些因子？"（风格+行业+特质）
- 第三层（收益分解）：回答"收益来自哪些能力？"（交易+选股+择时+成本）

### 5.3 多因子归因模型

**来源**: 海通证券/多因子研报
**核心逻辑**: 
- Fama-French三因子：市场因子、规模因子、价值因子
- Carhart四因子：+动量因子
- Fama-French五因子：+投资因子、盈利因子
- 组合收益 = 因子暴露 × 因子收益 + 特质收益（Alpha）

**Kimi想法**: 多因子归因需要组合持仓数据和因子暴露数据。对于我们的系统：
- 在v1.0阶段，可以先实现**Brinson归因**（数据需求较低，只需行业权重和收益）
- 在v1.1阶段，实现**多因子归因**（需要风格因子数据，如Barra CNE5）
- 特质收益（Alpha）是我们最关心的——它代表了"投资管家"的核心能力（超越因子的选股/择时能力）

## 8. Kimi 的取舍总结（第四批）

### 8.1 确认已有的设计需要补充的

- 回测框架缺少**稳健性验证流程** → 必须增加 validation/ 模块
- 回测报告缺少**绩效归因** → 必须增加Brinson/多因子归因
- 系统缺少**事件日历** → 必须增加日历效应和事件驱动信息

### 8.2 需要补充的增强（第四批）

1. **日历效应日历**（v1.0）：`MACRO_ENVIRONMENT_SCORER` 增加季节维度，标记当前日期附近的传统风险/机会窗口。
2. **事件驱动排雷**（v1.0）：`A5` 排雷增加"限售股解禁预警"和"高送转陷阱"排除规则。
3. **稳健性验证模块**（v1.0）：回测框架增加 `OutOfSampleTester`、`WalkForwardAnalyzer`。
4. **蒙特卡洛模拟**（v1.1）：回测框架增加 `MonteCarloSimulator`。
5. **Brinson归因**（v1.1）：回测报告增加三层归因（Brinson+多因子+收益分解）。
6. **参数敏感性分析**（v1.1）：对象卡参数优化工具，防止"尖峰"参数过拟合。

### 8.3 保持不做的

- 纯日历效应交易（不独立）
- 纯事件驱动高频交易（定位不符）
- 复杂的Barra多因子归因（v1.2后再考虑）
