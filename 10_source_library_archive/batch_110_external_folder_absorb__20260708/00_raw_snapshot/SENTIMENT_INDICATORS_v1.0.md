## 二、核心指标详解

### 2.1 融资融券余额（最重要）

| 指标 | 含义 | 情绪信号 |
|------|------|----------|
| 融资余额上升 | 散户借钱买入 | 看多情绪升温 |
| 融资余额下降 | 散户偿还借款 | 看空/去杠杆 |
| 融券余额上升 | 借股卖出 | 看空情绪升温 |
| 融资使用率 >70% | 杠杆接近上限 | 极度乐观，警惕见顶 |

**数据来源**：Tushare `pro.moneyflow_hsgt()` 或 `pro.margin()`

### 2.2 新增开户数（散户入场信号）

- **逻辑**：牛市尾声伴随大量新开户散户涌入（"邻居阿姨效应"）
- **阈值**：月新增开户数超过过去12个月均值50% → 情绪过热
- **来源**：中国证券登记结算公司月报
- **滞后性**：月频，滞后约1个月，但趋势明确

**历史案例**：
- 2020年：疫情后反弹，新开户超100万户，是均值2-3倍 → 后续高位套牢
- 2024年10月："924"行情，月新开户460万户，同比+50% → 市场阶段性顶部

### 2.3 市场换手率（活跃度指标）

| 换手率 | 市场情绪 | 信号 |
|--------|----------|------|
| <1% | 极度冷清 | 观望/底部区域 |
| 1-3% | 正常 | 中性 |
| 3-5% | 活跃 | 乐观 |
| >5% | 过热 | 警惕回调 |

> **A股整体换手率**：近10年最低0.38%（2016/1/7），最高4.2%（2024/10/8）

### 2.4 北向资金（"聪明钱"）

- **逻辑**：外资通常更理性，持续流入往往预示底部，持续流出预示顶部
- **数据来源**：Tushare `pro.moneyflow_hsgt()`
- **用法**：北向资金连续5日净流入+散户融资余额下降 = 底部信号

### 2.5 小单资金流向（散户方向）

- **逻辑**：小单（<10万元）代表散户交易，小单净流入=散户在买
- **反指标**：小单持续流入+大单流出 = "主力倒货给散户"
- **数据**：需Level-2或付费平台（Wind/同花顺）

## 三、综合情绪指数构建

### 3.1 Baker-Wurgler模型（经典）

选取6个指标，主成分分析构建综合指数：

| 指标 | 权重 | 含义 |
|------|------|------|
| 换手率(TURN) | 52.1% | 交易活跃度 |
| 新增开户数(NA) | 64.0% | 散户入场 |
| 消费者信心(CCI) | 22.9% | 宏观经济预期 |
| 封闭式基金折价率(DCEF) | 35.1% | 机构投资者情绪 |
| IPO数量(NIPO) | 22.7% | 市场供给 |
| IPO首日收益率(RIPO) | 46.3% | 市场热度 |

**公式**：ISI = 0.64×NA + 0.521×TURN + 0.229×CCI + 0.351×DCEF + 0.227×NIPO + 0.463×RIPO

> **注意**：权重来自魏星集（2014）的A股实证，与BW原文不同。

### 3.2 简化版A股情绪指数（建议）

由于CCI/DCEF/NIPO/RIPO数据获取不便，建议构建**简化版**：

```python
# 简化A股情绪指数（A-REI: A-Share Retail Emotion Index）
A_REI = (
    0.40 * normalize(融资余额环比) +
    0.30 * normalize(换手率) +
    0.20 * normalize(北向资金5日累计) +
    0.10 * normalize(新增开户数同比)
)

# 解读
A_REI > 0.8  → 极端乐观（减仓信号）
A_REI < -0.8 → 极端悲观（加仓信号）
-0.2 < A_REI < 0.2 → 中性
```

## 四、情绪指标与PeriodQueen的联动

| 情绪状态 | A-REI范围 | PeriodQueen调整 | 策略影响 |
|----------|-----------|-----------------|----------|
| 极度恐慌 | <-0.8 | 考虑提前转入GESTATION | 提高TrialEntry比例 |
| 悲观 | -0.8 ~ -0.2 | 维持当前状态 | 标准仓位 |
| 中性 | -0.2 ~ 0.2 | 维持当前状态 | 标准仓位 |
| 乐观 | 0.2 ~ 0.8 | 维持当前状态 | 标准仓位，但加强风控 |
| 极度贪婪 | >0.8 | 考虑转入DEFENSE或EXIT | 降低仓位，收紧止损 |

## 五、情绪指标作为反向信号的使用

### 5.1 经典反向逻辑

A股散户情绪的典型模式：

| 市场阶段 | 散户行为 | 情绪指标表现 | 正确做法 |
|----------|----------|--------------|----------|
| 底部 | 恐慌抛售，销户 | 融资余额低，开户数降 | 逆向买入 |
| 上涨初期 | 观望，质疑 | 融资缓慢回升 | 跟随趋势 |
| 上涨中期 | 追涨入场 | 融资余额快速上升 | 持有，警惕 |
| 顶部 | 狂热，杠杆加满 | 融资使用率>70%，开户数激增 | 逐步减仓 |
| 下跌初期 | 死扛，"回调就是机会" | 融资余额仍高 | 坚决止损 |
| 下跌中期 | 割肉，恐慌 | 融资余额骤降 | 等待企稳 |

### 5.2 情绪拐点信号（供PeriodQueen参考）

```
情绪顶信号（满足2项以上）：
□ 融资余额创90日新高
□ 月新增开户数同比>50%
□ 换手率>3%持续5日
□ 北向资金连续5日净流出+散户小单流入

情绪底信号（满足2项以上）：
□ 融资余额创90日新低
□ 新增开户数同比<-20%
□ 换手率<1%持续5日
□ 北向资金连续5日净流入+散户小单流出
```

## 六、Kimi取舍

### ✅ 必须纳入
- **融资余额监控**：Tushare免费数据，日频，最可靠的情绪指标
- **换手率监控**：日频，简单有效
- **北向资金流向**：Tushare免费，"聪明钱"对比
- **A-REI简化指数**：4指标加权，编程AI可直接实现

### ⚠️ 可选增强
- **新增开户数**：月频滞后，但趋势可靠
- **小单资金流向**：需Level-2，效果强但成本高
- **封闭式基金折价率**：日频，但需额外数据维护

### ❌ 不纳入（当前阶段）
- **社交媒体NLP舆情**：需要爬虫+NLP模型，噪声极高，维护成本高
- **IPO相关指标**：月频，且受监管政策影响大（暂停IPO时失效）
- **股吧/论坛情绪**：数据不标准化，难以量化
