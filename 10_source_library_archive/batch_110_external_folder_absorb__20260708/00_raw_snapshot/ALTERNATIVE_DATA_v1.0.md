## 二、A股特定优势

据JPMorgan 2019研报及2021中国量化白皮书：
- A股每月产生：5000份公司披露、10000份卖方报告、10万条股票新闻、**400万篇个人投资者网络信息**
- 中国作为人口大国+互联网大国，天然累积更大数据量
- 散户多、网络活跃 → 舆情/情绪数据丰富
- 2021年11月上海数据交易所成立，九坤投资完成首笔产业链数据交易

## 三、已验证有效的A股另类因子

### 1. 新闻情绪因子（国金证券）
- **数据**：覆盖1000+站点、7000+版面、1700+财经微信公众号
- **方法**：FinGPT情感分析（基于ChatGLM-6B微调）
- **效果**：乐观情感因子IC=3.68%，多空组合年化收益12.71%
- **特点**：与基本面因子相关性低，独立于市值因子

### 2. ESG因子（平安CN-ESG）
- **覆盖**：3900+ A股公司，回溯5年
- **技术**：爬虫+知识图谱+NLP+卫星遥感
- **效果**：沪深300/中证800正面筛选作用显著；财务粉饰因子多空收益11.61%
- **特点**：与传统因子相关性弱，可补充基本面分析

### 3. 夜灯光因子（尔特数科）
- **方法**：卫星夜灯光数据对制造业A股排序
- **效果**：下行周期中仍有稳定超额收益
- **原理**：灯光强度反映工厂开工率/经济活跃度

## 四、挑战与限制

| 挑战 | 说明 |
|------|------|
| **数据质量** | 约40%另类数据存在采样偏差（EagleAlpha, 2022） |
| **信噪比** | 社交媒体数据被机器人污染，情绪指标失真 |
| **合规隐私** | 欧盟GDPR限制，SEC曾对违规使用医疗记录处罚500万美元 |
| **算力成本** | PB级卫星图像需云计算，年成本可达数百万美元 |
| **维护成本** | 爬虫接口频繁变动，需持续维护 |

## 五、Kimi取舍

### ✅ 可低成本纳入
- **新闻舆情因子**：Tushare/akshare有新闻数据，FinBERT开源可用
- **网页抓取**：电商/招聘数据可自建爬虫
- **App数据**：公开下载量数据可作为互联网公司先行指标

### ⚠️ 需付费或额外数据
- **ESG评分**：平安CN-ESG、万得ESG等需授权
- **供应链数据**：数库科技等需购买
- **卫星图像**：专业供应商（RSMetrics、Orbital Insight）价格高昂

### ❌ 不纳入当前系统
- **信用卡/消费数据**：获取门槛极高，且隐私合规风险大
- **高频另类数据**（如秒级GPS）：与A股T+1中低频策略不匹配
