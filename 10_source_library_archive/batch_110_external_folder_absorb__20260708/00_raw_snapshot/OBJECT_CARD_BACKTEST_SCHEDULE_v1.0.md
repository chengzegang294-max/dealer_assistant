# 对象卡回测优先级排期表 v1.0

> 版本：v1.0 | 状态：排期设计阶段 | 覆盖：12 张已冻结对象卡  
> 排期原则：数据可获取性优先 → 对系统贡献度 → 回测复杂度  
> 目标：让回测工作从"无序尝试"变为"分批交付"

## 3. 分批排期详解

### 3.1 第一批：纯 OHLCV 对象卡（Week 1-2）

> **目标**：不依赖任何额外数据，仅用日 K 线完成 4-5 张对象卡的单因子回测。  
> **核心价值**：快速验证对象卡逻辑是否自洽，产出第一批可运行的信号。

#### 3.1.1 VOLFAC_P0_A — 波动率因子（最先启动）

| 项目 | 详情 |
|------|------|
| **为什么最先** | 计算最简单（60 日标准差），且是 VOLTARGET 的核心输入，必须先有结果 |
| **所需数据** | 日收盘价（60 日滚动窗口） |
| **数据获取** | 已有（`trading_analysis/ashare_preprocess.py` 可产出） |
| **回测参数** | 回测区间：2018-2024；股票池：全 A 股；再平衡：月频（波动率按月调整） |
| **验收指标** | 高波动分位（>80%）标的的年化收益应低于低波动分位（<20%）标的 |
| **预计周期** | 1-2 天 |
| **关键风险** | 小盘股天然高波动，需按市值分层验证，否则结论失真 |
| **输出物** | `volfac_vol_regime` 字段的历史序列（2018-2024） |

#### 3.1.2 TKR7_P0_E — AO 背离（与 VOLFAC 并行）

| 项目 | 详情 |
|------|------|
| **为什么并行** | AO 是标准指标（Bill Williams），计算不依赖 VOLFAC，可独立回测 |
| **所需数据** | 日 OHLCV（AO 需要 median price = (high+low)/2） |
| **数据获取** | 已有 |
| **回测参数** | 回测区间：2018-2024；背离确认后持有 5-10 个交易日；止损：bi.low - 0.5ATR |
| **验收指标** | 常规背离胜率 > 40%，隐藏背离胜率 > 45%；confidence < 0.3 的过滤有效性 |
| **预计周期** | 1-2 天 |
| **关键风险** | 震荡市假背离频繁，需在震荡市子区间（2022-2024）单独验证 |
| **输出物** | `ao_divergence_type` 和 `ao_divergence_confidence` 历史序列 |

#### 3.1.3 VP_P0_E — 成交量分布（Week 2 启动）

| 项目 | 详情 |
|------|------|
| **为什么 Week 2** | 需要计算滚动成交量分布（POC/VAH/VAL），比 VOLFAC 复杂 |
| **所需数据** | 日 OHLCV（需 60 日滚动窗口计算成交量分布） |
| **数据获取** | 已有 |
| **回测参数** | 回测区间：2018-2024；信号：VA 突破（价格突破 VAH 做多，突破 VAL 做空）；持有 5-10 日 |
| **验收指标** | 突破胜率 > 42%；volume_integrity_score ≥ 0.6 时胜率应显著高于 < 0.6 |
| **预计周期** | 2-3 天 |
| **关键风险** | 数据不足（<20K 线）时 POC 不可靠，需排除新股/次新股 |
| **输出物** | `poc` / `vah` / `val` / `va_breakout_signal` 历史序列 |

#### 3.1.4 BPB_P0_E — 突破回调（与 VP 并行）

| 项目 | 详情 |
|------|------|
| **为什么并行** | 同样基于 OHLCV，但逻辑是价格行为（趋势线/突破/回调），与 VP 互补 |
| **所需数据** | 日 OHLCV（需要识别趋势线和突破） |
| **数据获取** | 已有 |
| **回测参数** | 回测区间：2018-2024；1st pullback 优先，2nd pullback 限制；回调深度 0.236-0.618 |
| **验收指标** | 1st pullback 胜率 > 45%；2nd pullback 胜率 > 40%；回调 > 0.618 不交易的过滤有效性 |
| **预计周期** | 2-3 天 |
| **关键风险** | 趋势线识别主观，需用参数化方法（如 HH/LL 连线的斜率阈值） |
| **输出物** | `bpb_pullback_count` / `bpb_callback_depth` / `bpb_breakout_quality` 历史序列 |

### 3.2 第二批：额外数据 + 风控层（Week 3-4）

> **目标**：接入 Wind 资金流和 ATR14，完成 MFLOW 和 VOLTARGET 的回测。  
> **核心价值**：选股层和风控层开始参与，系统从"纯信号"升级为"有过滤和风控"。

#### 3.2.1 VOLTARGET_P0_R — 波动率目标（Week 3 启动）

| 项目 | 详情 |
|------|------|
| **为什么 Week 3** | 依赖 VOLFAC 的 `volfac_annualized_vol` 输出，需等第一批完成 |
| **所需数据** | ATR14（日频）+ VOLFAC 输出字段 |
| **数据获取** | ATR14 可从 OHLCV 计算；VOLFAC 输出从第一批获取 |
| **回测参数** | 目标波动率：10%（大盘）/ 20%（小盘）；scalar 调制范围：0.2-2.0；T+1 惩罚系数 |
| **验收指标** | 加入 VolTarget 后组合夏普提升 > 0.1；极端波动期（2020-03）最大回撤降低 > 5% |
| **预计周期** | 2-3 天 |
| **关键风险** | 连续涨跌停 ATR 失真，需用 `limit_atr_corrector` 修正 |
| **输出物** | `vt_scalar` / `vt_size_scalar` 历史序列（用于调制仓位） |

#### 3.2.2 MFLOW_P0_A — 资金流向（Week 3-4）

| 项目 | 详情 |
|------|------|
| **为什么 Week 3-4** | 需要 Wind 资金流向数据，数据获取需时间 |
| **所需数据** | Wind 资金流向因子（50 个因子中核心 2 个：`mfd_sellord` + `mfd_volinflowrate_open_m`） |
| **数据获取** | 需申请 Wind 数据权限或从 `trading_assistant` 数据模块提取 |
| **回测参数** | 回测区间：2018-2024（2018/03 后样本外）；持仓 10 个交易日；T+1 开盘信号 |
| **验收指标** | `mfd_sellord` 多空组合年化收益 > 30%（SBKT_F014 结论：42.12%）；IC>0 占比 > 60% |
| **预计周期** | 3-5 天 |
| **关键风险** | T+1 开盘数据不完整（早盘 9:30 后才更新）；小盘股/ST 股数据缺失 |
| **输出物** | `mflow_sellord_ratio` / `mflow_inflow_ratio` / `mflow_signal_type` 历史序列 |

#### 3.2.3 YTC_P0_E — TST/BOF/BPB（Week 4）

| 项目 | 详情 |
|------|------|
| **为什么 Week 4** | 多周期 S/R 框架需要周线/日线/60min 数据对齐，计算量比单周期大 |
| **所需数据** | 日 OHLCV + 周线 OHLCV + 60min OHLCV（三周期 S/R） |
| **数据获取** | 日/周已有；60min 需额外获取或从分钟级合成 |
| **回测参数** | 回测区间：2018-2024；HTF/TF/LF 三周期 S/R 对齐；TST 信号持有 5-8 日；EXPIRED 15 根 K 线 |
| **验收指标** | S/R 有效时胜率 > 45%；S/R 无效时信号不触发（无胜率）；BOF 胜率 > TST 胜率（因为 BOF 是失败后的反转） |
| **预计周期** | 3-4 天 |
| **关键风险** | S/R 框架主观，需用参数化方法（如 HH/LL 的 3 次确认）；多周期 S/R 冲突时信号降级 |
| **输出物** | `ytc_srf_is_valid` / `ytc_signal_type` / `ytc_confirmation_status` 历史序列 |

### 3.3 第三批：组合回测 + 复杂对象卡（Week 5-6）

> **目标**：将第一批和第二批的产出组合，验证互锁和投票机制。同时处理缠论 BSD 和 Kelly 这类复杂对象。  
> **核心价值**：系统从"单因子独立验证"升级为"组合协同验证"。

#### 3.3.1 CHZL_BSD_P0_E — 缠论三类买卖点（Week 5-6）

| 项目 | 详情 |
|------|------|
| **为什么 Week 5-6** | 最复杂的对象卡，需要笔/中枢/背驰的完整历史数据，且必须与其他对象卡组合验证 |
| **所需数据** | 日 OHLCV（用于分型/笔/中枢计算）+ 已计算的 `CHZL_BI` / `CHZL_ZS` 历史序列 |
| **数据获取** | 笔/中枢数据需从 OHLCV 推导（可用 `trading_analysis` 中的缠论逻辑） |
| **回测参数** | 回测区间：2018-2024；1Buy/2Buy/3Buy 分别回测；止损：bi.low-0.5ATR / prev_low-0.2ATR / zs.zd-0.1ATR |
| **验收指标** | 1Buy 胜率 > 35%（背驰反转难，胜率天然低）；3Buy 胜率 > 45%；2Buy 居中；止损触发率 < 60% |
| **预计周期** | 1-2 周 |
| **关键风险** | 笔/中枢定义主观（新旧笔分歧），需统一用旧笔规则；背驰判断需 MACD 面积计算 |
| **输出物** | `bsd_type` / `bsd_stop_price` / `bsd_is_trailing` / `bsd_id` 历史序列 |

#### 3.3.2 KELLY_P0_R — 凯利公式（Week 5-6，与 CHZL_BSD 并行）

| 项目 | 详情 |
|------|------|
| **为什么并行** | 依赖交易日志，但可以用第一批/第二批的产出模拟交易日志 |
| **所需数据** | 交易日志（从 VP/BPB/YTC 等对象卡的回测结果中提取） |
| **数据获取** | 从第一批/第二批回测中导出：每笔交易的盈亏、胜率、盈亏比 |
| **回测参数** | 历史窗口：最近 30 笔交易；模式：半凯利 / 四分之一凯利 / 自适应；危机模式：连续亏损 3 笔 |
| **验收指标** | 半凯利下最大回撤 < 全凯利的 70%；危机模式触发后仓位降至 < 0.3；样本 < 30 笔时 Kelly 不激活 |
| **预计周期** | 1-2 周 |
| **关键风险** | 胜率估计误差敏感（高估 10% → 仓位翻倍），需用稳健估计（如 Wilson 置信区间） |
| **输出物** | `kelly_f_star` / `kelly_size_scalar` / `kelly_mode` 历史序列 |

#### 3.3.3 组合回测验证（Week 6）

| 项目 | 详情 |
|------|------|
| **目标** | 将 VP + BPB + CHZL_BSD + MFLOW + VOLTARGET + KELLY 组合，验证投票机制 |
| **所需数据** | 第一批 + 第二批的所有输出字段 |
| **回测参数** | entry_min_votes = 3；Van Tharp 2% 上限；VolTarget scalar 调制；Kelly 仓位调制 |
| **验收指标** | 组合夏普 > 任何单因子夏普；组合最大回撤 < 任何单因子最大回撤；投票通过率 30%-70% |
| **预计周期** | 3-5 天 |
| **关键风险** | 互锁冲突导致信号过度过滤（通过率 < 30%），需调整阈值 |
| **输出物** | 组合回测报告：年化收益、夏普、最大回撤、胜率、投票统计、风控触发统计 |

### 3.4 第四批：样本外验证（Week 7-8）

> **目标**：用 2024-2025 年数据（未在训练期内）验证组合表现。  
> **核心价值**：验证系统是否过拟合，决定能否从 v1.3 升级到 v1.4。

| 项目 | 详情 |
|------|------|
| **样本外区间** | 2024-01-01 至 2025-06-30（至少 18 个月） |
| **验证内容** | 组合回测的绩效衰减控制：样本外夏普 ≥ 样本内夏普的 70% |
| **极端行情测试** | 2024-01 至 2024-02（A 股流动性危机）：组合最大回撤应 < 样本内最大回撤的 120% |
| **风格切换测试** | 2024-09 后小盘股行情：组合是否适应风格切换？VOLFAC 的小盘股分层是否有效？ |
| **预计周期** | 1-2 周 |
| **输出物** | 样本外测试报告：绩效对比、衰减分析、极端行情表现、风格切换适应性 |

### 3.5 第五批：有条件激活（Week 9+）

#### 3.5.1 INSTB_P0_A — 机构行为（方法层，不干预执行）

| 项目 | 详情 |
|------|------|
| **为什么最后** | 方法层，不干预实时执行，仅作为背景信息验证 |
| **所需数据** | 季报机构持仓数据（2018-2024） |
| **数据获取** | Wind 或同花顺 F10 |
| **验证方法** | 不生成交易信号，仅验证：机构增持标的后续 30 日收益是否显著高于减持标的 |
| **验收指标** | 机构增持组合年化收益 > 减持组合 10% 以上；筹码集中度 > 1.1 时胜率 > 50% |
| **预计周期** | 3-5 天 |
| **关键风险** | 数据滞后 45-90 天，验证结果只能说明"机构行为有长期相关性"，不能用于实时交易 |

#### 3.5.2 ATRATIO_P0_A — 主动成交占比（有条件激活）

| 项目 | 详情 |
|------|------|
| **激活条件** | 确认有股指期货权限（ASHARE_LONG_SHORT 环境）或切换到外汇/期货市场 |
| **所需数据** | Level-2 逐笔委托/成交数据（成本高，需付费） |
| **数据获取** | 需申请交易所 Level-2 数据或第三方数据商 |
| **回测参数** | 若激活：主动卖出占比 > 60% 时做空；主动买入占比 > 60% 时做多；持有 1-3 日 |
| **验收指标** | 空头胜率 > 45%（仅在允许做空时验证）；纯多头下不验证（已知无效） |
| **预计周期** | 1-2 周（含数据获取时间） |
| **关键风险** | 数据成本极高；纯多头下已知无效，回测价值有限 |
| **决策建议** | 若无法获取 Level-2 数据或确认无做空权限，可将 ATRATIO 永久放入 `future_bucket`，不投入回测资源 |

## 5. 风险与应对

### 5.1 进度风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| Wind 数据获取延迟 | 中 | MFLOW 回测延期 1-2 周 | 用同花顺免费数据替代，或先用 VP/BPB/VOLFAC 推进 |
| 缠论笔/中枢推导错误 | 中高 | CHZL_BSD 回测结果不可靠 | 与 `trading_analysis` 中的缠论逻辑交叉验证；用小样本人工校验 |
| 组合回测时互锁冲突过多 | 中 | 投票通过率 < 30%，系统无法交易 | 逐步放宽过滤器阈值（如从 strict 模式到 moderate 模式） |
| 样本外绩效衰减过大 | 中 | 系统过拟合，需退回重优化 | 增加样本内正则化（如参数随机化、早停机制） |

### 5.2 数据风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 分钟级数据缺失（2018 年前） | 高 | 多周期回测样本不足 | 分钟级回测从 2019 年开始；日线/周线回测保持 2018-2024 |
| 资金流向数据缺失（小盘股/ST） | 高 | MFLOW 覆盖率低 | 缺失数据标记为 'NONE'，不纳入投票；覆盖率 > 80% 即可 |
| 涨跌停数据失真 | 高 | ATR/波动率/VP 计算失真 | 统一使用 `limit_atr_corrector`（剔除涨跌停日） |
