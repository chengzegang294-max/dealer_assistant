# GROUP_08 相关性选股与动态因子项目裁决 v1

## 主负责人裁决

- 当前允许进入正式合同层的相关性选股子集：
  - `S-C04` 相关性选股策略全市场框架
- 当前允许进入正式合同层的动态因子子集：
  - `S-039` Kalman Filter 动态因子选择
  - `S-040` 因子有效性强弱指数
  - `S-041` 净换手率定义作为候选扩展输入

## 为什么先冻结这条组合

- `S-C04` 已经形成：
  - 因子库
  - 显著性规则
  - 滚动窗口
  - 组合输出
- `S-039 / S-040 / S-041` 已经形成：
  - 动态有效性跟踪
  - 有效/失效判断
  - 新因子候选输入
- 两者合并后，刚好形成：
  - 静态选股框架
  - 动态筛选升级层

## 当前不升级为默认逻辑

- 不直接升级为 A股 P0 默认多因子选股引擎
- 不把 Kalman Filter 直接写成当前主线默认因子开关
- 不把净换手率直接纳入当前默认因子池
- 不把尾部相关系数风险管理直接写成当前组合控制器

## 当前可以怎么用

- 作为：
  - 合同层固定资产
  - 研究对象冻结入口
  - 后续验证与 runtime 接线候选
- 不作为：
  - 当日真实交易指令
  - 已验证完毕的生产级选股系统

## 暂不入合同层

- 尾部相关系数在组合风险管理中的应用
- 净换手率的全市场推广
- 仅做横向重复验证的行业复制稿
