# GROUP_08 事件驱动与市场择时项目裁决 v1

## 主负责人裁决

- 当前允许进入正式合同层的事件驱动子集：
  - 业绩预告
  - 指数样本股调整
  - 大股东增持
  - 股权激励
- 当前允许进入正式合同层的市场择时子集：

  - 产业资本净增减持

## 为什么先冻结这两条

- 它们都已经有：
  - 主题入口
  - 对象入口
  - 研究摘要
  - cutpack 量化表
- 也都足够形成：
  - 最小输入
  - 最小输出
  - 参数边界
  - 不接线说明

## 当前不升级为默认逻辑

- 事件驱动线：
  - 不直接升级为 P0 默认事件门控
  - 不把事件组合止损直接写成当前默认组合风控
- 市场择时线：
  - 不直接升级为 P0 默认择时 gate
  - 不把 R² 或产业资本信号直接写成当前首页主信号

## 当前可以怎么用

- 作为：
  - 合同层固定资产
  - 研究对象冻结入口
  - 后续验证与 runtime 接线候选
- 不作为：
  - 当日真实交易指令
  - 已验证完毕的生产级策略
