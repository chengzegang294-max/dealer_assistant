### 思考 
1. **[在数据获取过程中，为什么要强调“增量下载”？](https://bibigpt.co/search?q=%E5%9C%A8%E6%95%B0%E6%8D%AE%E8%8E%B7%E5%8F%96%E8%BF%87%E7%A8%8B%E4%B8%AD%EF%BC%8C%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E5%BC%BA%E8%B0%83%E2%80%9C%E5%A2%9E%E9%87%8F%E4%B8%8B%E8%BD%BD%E2%80%9D%EF%BC%9F)**
  - 因为金融数据体量庞大，重复下载既浪费流量与时间，又容易触发 API 的频率限制。通过增量方式，代码仅获取缺失的最新日期数据并与本地历史库合并，能够极大提高工程效率。
- 2. **[如何判断一个量化因子是否具有实盘价值？](https://bibigpt.co/search?q=%E5%A6%82%E4%BD%95%E5%88%A4%E6%96%AD%E4%B8%80%E4%B8%AA%E9%87%8F%E5%8C%96%E5%9B%A0%E5%AD%90%E6%98%AF%E5%90%A6%E5%85%B7%E6%9C%89%E5%AE%9E%E7%9B%98%E4%BB%B7%E5%80%BC%EF%BC%9F)**
  - 通常参考 IC 和 IR 指标：IC 大于 0.03 表示因子具有一定的预测能力；IR 大于 0.5 通常被认为信号稳定。此外，通过多空分层回测，若高低分组收益具有明显的单调性，则该因子在实盘中更具参考价值。


### 术语解释
- **IC (Information Coefficient)**: 信息系数，衡量当期因子值与下一期个股收益率之间的相关性，反映因子的预测能力。
- **特质波动率 (Idiosyncratic Volatility)**: 指除去市场、市值、估值等共同因子解释部分后的残差波动，通常被视为反映股票个性化信息的指标。
- **分层回测 (Layered Backtesting)**: 将股票根据因子大小分为若干组（如十组），通过对比最高组与最低组的收益差，评估因子区分股票表现的效果。
- **OLS回归 (Ordinary Least Squares)**: 普通最小二乘法，在量化中常用于对个股历史数据进行回归，从而计算出贝塔系数或提取残差项。

## 术语解释
- **IC (Information Coefficient)**: 信息系数，衡量当期因子值与下一期个股收益率之间的相关性，反映因子的预测能力。
- **特质波动率 (Idiosyncratic Volatility)**: 指除去市场、市值、估值等共同因子解释部分后的残差波动，通常被视为反映股票个性化信息的指标。
- **分层回测 (Layered Backtesting)**: 将股票根据因子大小分为若干组（如十组），通过对比最高组与最低组的收益差，评估因子区分股票表现的效果。
- **OLS回归 (Ordinary Least Squares)**: 普通最小二乘法，在量化中常用于对个股历史数据进行回归，从而计算出贝塔系数或提取残差项。
