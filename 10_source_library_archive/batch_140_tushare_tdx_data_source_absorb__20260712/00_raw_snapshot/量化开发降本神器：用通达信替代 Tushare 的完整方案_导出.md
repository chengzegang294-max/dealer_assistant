### 术语解释
- **通达信接口 (Pytdx)**: 一款开源的 Python 库，用于直接连接通达信行情服务器，获取实时及历史的股票、期货等行情数据，是实现低成本量化的核心工具。
- **因子 (Factor)**: 量化投资中的基础元素，指能够解释或预测资产收益的一系列特征指标（如 MACD、KDJ、换手率等），是构建量化策略模型的基石。
- **Mini QMT**: 一种轻量级的量化交易接口，相比于完整版 QMT，它对环境配置要求更低，便于在 Python 中灵活编写策略，但通常需要满足特定券商的开户资产门槛。
- **Tick 数据**: 股票交易中每一笔成交的数据（逐笔成交），包含价格、成交量及时间戳，是进行高频交易策略开发和回测时最细粒度的数据。
