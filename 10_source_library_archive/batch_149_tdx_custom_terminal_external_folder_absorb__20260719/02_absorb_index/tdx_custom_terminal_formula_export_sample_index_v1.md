# TDX Custom Terminal Formula Export Sample Index v1

更新时间：2026-07-20

## 一、这页用途

- 这页只记录已经从终端公式编辑器里实际导出的真实公式样本。
- 这页不把 `funcs/*.sp`、网页页面或 `tn6` 整包导出件误写成公式正文。
- 这页的目标是：
  - 证明当前已经拿到一批 `真实可编辑公式源码`
  - 给后续 `页面层 vs 公式层` 映射提供锚点

## 二、当前样本结论

- 当前已吸收 `17` 组有效样本：
  - `9` 组用户公式样本
  - `8` 组系统公式样本
- 当前样本分两种证据形态：
  - `截图 + 正文 txt`
  - `正文 txt`
- `短中操盘系统` 本轮已补到有效 `txt`，不再是缺口。
- 因此当前口径应更新为：
  - `真公式候选层` 已经拿到一批可直接读的真实公式正文
  - 但仍不是“完整源码库”

## 四、五类代表覆盖判断

- 当前已经较稳命中的类：
  - `板块联动`
    - 以 `HYDB行业对比` 为直接样本
  - `热点涨停/连板`
    - 以 `打板资金`、`沪深涨跌停` 为直接样本
  - `龙虎榜/资金异动`
    - 以 `短线宝`、`上榜资金`、`大宗交易` 为主样本
  - `指数/情绪强弱`
    - 以 `点石成金`、`短线多空对比`、`顶底`、`ZSDB指数对比` 为主样本
  - `个股异动/预警或选股`
    - 以 `启动点`、`差价操作`、`波段操盘`、`短中操盘系统` 为主样本
- 当前主负责人判断：
  - 五类代表样本已经全部命中
  - 后续不再需要为“凑五类”而继续盲补源码
