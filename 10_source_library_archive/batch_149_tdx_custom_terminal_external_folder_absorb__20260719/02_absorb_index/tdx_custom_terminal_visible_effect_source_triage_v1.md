# TDX Custom Terminal Visible Effect Source Triage v1

更新时间：2026-07-20

## 一、这页用途

- 这页只回答一个问题：
  - 当前在这套改版终端里，用户能看见的“效果”更可能来自哪一层。
- 这页不回答：
  - 公式本身是否有效
  - 是否已经拿到全部指标源码

## 二、三分口径

- `页面 / 网页载体`
  - 指由 `html / js / iframe / 外部 API / 本地页面聚合` 驱动的可见效果
- `插件 / 快捷键 / 菜单编排`
  - 指由 `插件配置 / patch / hotkey / menu` 控制的界面动作和交易入口效果
- `真公式候选`
  - 指更接近 `可编辑公式正文` 或 `真实逻辑脚本` 的内容
  - 当前批次里这一类已经拿到一批样本，但仍不得夸写成“已拿到完整源码”

## 四、当前主负责人判断

- 当前可见效果里，最厚的一层仍是：
  - `页面 / 网页载体`
- 第二厚的一层是：
  - `插件 / 快捷键 / 菜单编排`
- 当前最薄、但最值得后续精准补证的一层才是：
  - `真公式候选`
- 当前这层已新增：
  - `17` 组真实公式导出样本
  - 见 `tdx_custom_terminal_formula_export_sample_index_v1.md`
- 因此当前不应先把“导出 3~5 个代表性可编辑指标源码”写成唯一下一手。
- 更合理顺序应是：
  - 先完成这张三分表
  - 再用当前真实样本做首轮映射
  - 最后只对缺类做定向补导
- 本轮补入
  `复盘.html / 直播.html / 涨停龙虎.html / 选股宝直播.html`
  后，
  第三手用于
  `batch150`
  同日外界信息补证的正式页面载体已具备第一执行组合
