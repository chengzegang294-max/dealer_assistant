# 资料库主题对象总表 v1

## 用途

- 这是一张跨主题总检索表。
- 当前作用是把 `主题 -> 对象 -> 批次/正文` 这条阅读链压成一张总表，便于横向比对和快速跳转。

## 默认入口

- `topic_object_matrix_v1.tsv`

## 现在能回答的问题

- 当前有哪些主题已经有对象快入口？
- 某个对象应该先看主题页，还是可以直接一跳进对象页？
- 某条对象的 first-hop 是批次 README、对象卡，还是正文索引？
- 某条对象当前是不是正式来源层默认入口？

## 推荐用法

- 想横向比对：
  - 先看 `topic_object_matrix_v1.tsv`
- 想顺着阅读链往下走：
  - 先点 `topic_entry`
  - 再点 `object_entry`
  - 最后进入批次或正文
- 想快速找常用对象：
  - 直接去 `object_entry/object_entry_index_v1.tsv`

## 当前范围

- 已覆盖：
  - `A股量化研究`
  - `A股数据源决策`
  - `系统吸收与正文回收`
  - `外部吸收与回收提升`
  - `原子方法对象孵化`
  - `财报估值与组合管理`
- 当前仍未覆盖：
  - 更多主题族和未来新增对象
  - 例如更多 `GROUP_08` 子簇等尚未接进当前总表的主题线

## 回链

- 主题入口层：
  - `README.md`
- 对象入口层：
  - `object_entry/README.md`
