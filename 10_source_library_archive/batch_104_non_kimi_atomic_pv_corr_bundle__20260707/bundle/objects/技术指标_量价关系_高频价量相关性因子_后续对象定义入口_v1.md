# 技术指标_量价关系_高频价量相关性因子_后续对象定义入口_v1

## 作用

- 把 `S桶 -> 03_券商研报` 中第二条最适合先做迁移验证的纯时间序列对象，收成明确入口。
- 当前目标不是直接把“价量相关性”变成主线因子库默认字段，而是先固定：
  - 来源锚点
  - 最小输入
  - 最小输出
  - 诊断层角色
  - 与现有 `量价/波动/反转` 解释层的边界

## 当前定位

- 层级：
  - `02_原子化拆解文件` 后续对象层
- 当前角色：
  - `next_object_entry`
  - `DIAG_ONLY_OBJECT_CANDIDATE`
  - `price_volume_diag_label`
- 不是：
  - 当前已接入主线的硬门控
  - 当前已实现的交易因子
  - 当前自动执行入口

## 为什么先从高频价量相关性开

- 在 `yes = 9` 里，它是最容易从 `A股分钟线` 平移到 `FX/商品 1H/4H` 的一类：
  - 只依赖价格与量序列
  - 不依赖 `Level2 / 逐笔 / 订单簿`
  - 便于先做 `diag-only / proof-of-mapping`
- 相比 `成交额 Alpha`：
  - “价量关系”更通用，概念迁移更稳
- 相比 `结构化反转`：
  - 先不引入行业/市值分层这些 A 股专属处理
  - 更适合作为最小时间序列对象

## 来源锚点

- 主来源：
  - `S桶\03_券商研报\01_高频微观\20200223-东吴证券-“技术分析拥抱选股因子”系列研究（一）：高频价量相关性，意想不到的选股因子.pdf`
- 当前吸收结论：
  - `can_map_to_fx = yes`
  - `data_dependency = 分钟线收盘价/成交量/日K`
  - 当前更像 `价量共振/背离诊断标签`

## 最小输入

- 基础行情：
  - `symbol`
  - `timeframe`
  - `bar_time`
  - `open`
  - `high`
  - `low`
  - `close`
- 量能代理：
  - `volume`
  - 若无真实成交量，可先允许：
    - `tick_volume`
- 第一版不强求：
  - `逐笔成交`
  - `盘口快照`
  - `订单簿`

## 最小输出

- `pv_corr_score`
  - 固定窗口内价格收益与量变动的相关性得分
- `pv_sync_state`
  - `confirm / diverge / neutral / unknown`
- `pv_pressure_bias`
  - `up_confirm / down_confirm / mixed / unknown`
- `pv_extreme_flag`
  - `price_up_volume_down / price_down_volume_up / none / unknown`

## 最小对齐逻辑

- 当前先把“价量相关性”承接为：
  - 价量共振/背离的诊断层标签
- 第一版只做：
  - 固定窗口相关性
  - 简单共振/背离分层
  - `proof-of-mapping`
- 第一版不做：
  - 直接进出场规则
  - 与其他因子的综合打分
  - A 股特有分层中性化

## 与现有主线的边界

- 与 `A3`：
  - `A3` 保留量价/换手/筹码的解释层来源
  - 当前这个对象只从中抽一个最小可迁移壳
- 与 `N01/N02`：
  - 不改写它们的状态上下文角色
  - 当前只补一个低依赖的价量诊断标签

## 最小验收定义

- 有一份对象入口文件：
  - 输入/输出/边界明确
- 有一份最小合同草案：
  - 至少冻结 `pv_corr_score / pv_sync_state / pv_pressure_bias`
- 有一份 `proof-of-mapping`：
  - 说明如何从价量序列得到相关性与标签
- 不得提前宣称：
  - 已进入主线默认因子池
  - 已成为入场 gate

## 当前裁决

- `高频价量相关性因子` 当前应固定为：
  - `yes=9` 中第二优先的纯时间序列对象
  - 先落 `diag-only / proof-of-mapping`
  - 先服务于 `价量诊断层`
