# A股 P0 趋势仓位与轮动仓位桥接裁决 v1

## 当前任务

- 把“趋势仓位 / 轮动仓位”从资料想法层收成 `A股 P0` 可以引用但不默认接管执行的桥接口径。

## 主负责人裁决

- 当前 `趋势仓位` 只保留：
  - `regime -> 仓位上限`
  - 作为解释层与后续任务参考
- 当前 `轮动仓位` 只保留：
  - `行业集中 / 分散`
  - `单行业上限 / 最少行业数`
  - 作为 `T04 / T05` 的解释与辅助评估口径
- 当前明确不保留为默认逻辑：
  - 四轴状态直接进仓位引擎
  - VanTharp R 直接进 P0 默认仓位引擎
  - 自动行业轮动与组合优化联动

## 角色边界

- `趋势仓位`
  - 角色：市场状态到总仓位上限的桥接层
  - 更像：解释层 / 风险预算层
  - 不是：选股器 / 行业轮动器 / 默认硬门控
- `轮动仓位`
  - 角色：行业暴露分配与集中度说明层
  - 更像：配置解释层 / 组合暴露约束层
  - 不是：正式行业择时引擎 / 组合优化器

## 适用市场

- 当前只面向：
  - `A股 P0`
- 当前不自动扩展到：
  - 外汇
  - 币圈
  - 期货

## 风险预算口径

- 当前趋势仓位只保留以下桥接建议：
  - `ATTACK_SUSTAINED = 1.0`
  - `ATTACK_CONFIRMED = 0.7`
  - `POWER_TRANSITION = 0.3`
  - `GESTATION = 0.3`
  - `REMAINING_WARMTH / ATTACK_UNSUSTAINED / CUTTING_COMPLETE = 0.0`
- 当前轮动仓位只保留以下桥接建议：
  - `行业集中`：单行业上限 `20%`
  - `行业分散`：至少 `3` 个行业

## 互斥关系

- 若趋势仓位判为 `0.0`：
  - 轮动仓位不再单独放大总仓位
- 若趋势仓位判为 `0.3`：
  - 轮动仓位只能在轻仓范围内决定“集中还是分散”
- 若趋势仓位判为 `0.7 / 1.0`：
  - 轮动仓位才有意义去决定行业暴露的集中度

## 当前可量化字段

- 趋势仓位：
  - `regime_state`
  - `position_cap_total`
  - `single_position_cap`
  - `position_budget_note`
- 轮动仓位：
  - `rotation_state`
  - `industry_concentration_mode`
  - `industry_cap`
  - `min_industry_count`
  - `rotation_note`

## 与验证任务的映射

- `T01`
  - 给趋势仓位提供市场强弱、噪音水平与事件密度背景
- `T03`
  - 决定业绩事件在缺一致预期时，是否还能进入轮动解释链
- `T04`
  - 直接验证轮动仓位相关解释是否值得保留
- `T05`
  - 决定趋势/轮动类比展示在不同样本门槛下是否可用
