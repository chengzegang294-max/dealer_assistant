# 趋势仓位与轮动仓位内化摘要 v1

## 用途

- 把仓库里已经存在但分散在不同材料中的“趋势仓位 / 轮动仓位”思路收成一张可复用摘要卡。
- 当前只提炼可直接桥接到 `A股 P0` 的部分，不把外部资料的完整系统直接照搬到项目默认逻辑。

## 趋势仓位可保留部分

- 最稳定的上游锚点来自：
  - `STRATEGY_BUNDLES_v1.0.md`
- 当前最可用的桥接口径不是复杂仓位引擎，而是：
  - `regime_state -> max_position_size`
- 当前可以直接保留的状态上限示意：
  - `ATTACK_SUSTAINED = 1.0`
  - `ATTACK_CONFIRMED = 0.7`
  - `POWER_TRANSITION = 0.3`
  - `GESTATION = 0.3`
  - `REMAINING_WARMTH / ATTACK_UNSUSTAINED / CUTTING_COMPLETE = 0.0`

## 轮动仓位可保留部分

- 最稳定的上游锚点来自：
  - `EXTERNAL_STRATEGY_RAW_MATERIAL_v2.0.md`
- 当前可保留的不是正式组合优化器，而是：
  - `行业集中 / 行业分散` 的解释层标签
  - 行业暴露上限建议
- 当前最可用的桥接规则是：
  - 当 `行业集中` 时，允许热门行业集中配置，但单行业上限 `20%`
  - 当 `行业分散` 时，强制至少分布到 `3` 个行业

## 与现有对象的关系

- `四轴状态模板`
  - 当前可提供状态模板与字段头，但仍是 `diag-only / proof-ready`
- `VanTharp R`
  - 当前可提供仓位风险框架，但仍不是正式仓位引擎
- `行业轮动与风格轮动对象`
  - 当前可提供轮动研究摘要和候选方法，不直接给出项目默认阈值

## 当前不直接采用部分

- 不直接采用：
  - Kelly 级优化细节
  - 组合级回撤控制完整框架
  - 跨市场统一仓位引擎
  - 自动行业择时和组合优化一体机

## 当前边界

- 当前只服务：
  - 资料整理入库
  - `A股 P0` 的桥接与说明
  - `T01 / T03 / T04 / T05` 的解释型辅助口径
- 当前不服务：
  - P0 默认硬门控
  - 真实交易自动仓位分配器
