## 0. 两种模式（B 全用这套）

### 首跑 / 断档 · FRESH（从底部往上重新扫）

```js
window.__infoLiveIncrementalExportV1Options = {
  forced_room_anchor: "房间正式名",
  reset_checkpoint: true,
  start_position: "bottom",
  scroll_direction: "up",
  max_rounds: 140,
  max_no_new_rounds: 3,
  scroll_sleep_ms: 350
};
```
→ 再贴整份 `live_info_incremental_export_v1.js`

### 续跑 · RESUME（接上次停点往上多滚）

```js
window.__infoLiveIncrementalExportV1Options = {
  forced_room_anchor: "房间正式名",
  reset_checkpoint: false,
  start_position: "keep",
  scroll_direction: "up",
  max_rounds: 140,
  max_no_new_rounds: 3,
  scroll_sleep_ms: 350
};
```
→ 再贴整份 `live_info_incremental_export_v1.js`

启动日志看：

- `resumed_from_checkpoint: true` → 续上了  
- `false` 且 loaded=0 → 当 fresh 再来一轮，或确认同一浏览器未清站点数据  

**B 默认 `max_rounds: 140`**（比 A 短，够用；想多滚改 180）。  
想偷懒只拍一页：可用 current（见文末），缺洞首优先仍建议 **FRESH 增量**。
