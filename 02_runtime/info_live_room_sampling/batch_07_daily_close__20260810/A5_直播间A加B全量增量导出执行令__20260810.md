## 6. 怎么判断“接到上次停的地方”

Console 启动日志会接近：

- `resumed_from_checkpoint: true` → 已从旧停点续  
- `checkpoint_loaded_count: N` → 带入了 N 条旧消息再继续 +新  

若 `false` 且 `checkpoint_loaded_count: 0`：

1. 先别慌，用 **模式 F** 从底部往上补一截  
2. 仍不动：确认是否选对滚动容器（右侧历史区真正在滚）、是否真是 **倒序**  
3. 再给我截 Console 前几行  
4. 清站点数据后所有 checkpoint 都会丢，只能 F 模式重建
