## 一、合同原则

1. 只服务“结构主源最小可用”，不做全字段镜像。
2. 优先保留：身份、高度、题材、时间、金额/涨跌数值。
3. 展示字符串若有对应数值字段，默认降为 `optional`。
4. 长文本（主营、经营范围、长原因）默认不进最小合同。
5. 本轮不扩新接口、不并跑题材中心。

字段级别：

- `required`：最小样本验收必有
- `recommended`：单日样本应尽量有，缺了记缺口
- `optional`：可丢，不挡验收
- `exclude`：明确不进最小合同（原文仍可另存 raw）

## 四、两模块对齐键（最小）

后续单日样本若要对照：

1. 日期键：`ladder.dates[].date` ↔ `sector.data.actualTradeDate`（均 `YYYYMMDD`）
2. 题材/板块弱对齐：`ladder.stocks[].kpl_plate_code` ↔ `sector.rows[].sectorCode`（注意后者常带 `k` 后缀，如 `801660` vs `801660k`）

对齐规则本轮只记缺口，不在合同里强行统一码表。

## 五、验收门槛（合同层）

满足以下即算“最小字段合同可执行”：

1. ladder 日层有 `date/totalStocks/boards`
2. 每个 board 有 `level` + 至少 1 只股票的 required 字段齐全
3. sector 有 `success=true` + `tradeDate/actualTradeDate/rows`
4. 每个 sector row 有 `sectorCode/sectorName/mainNetAmount/strength/pctChg`
5. 未引入第三条新接口

## 六、一句话

- 最小合同只保“能落单日结构样本”的字段：天梯保板高+标的+题材+封板时间+涨跌数值；板块资金保代码+主力净额+强度+涨跌+相对流入。

### 7.2 新指标公式冻结表（8/11 裁决后再改要再走发包流程）

| 指标名 | 冻结公式 | 阈值 / 档位冻结 | 8/10 实测值（验证用）|
|-------|--------|---------------|----------------|
| **分歧指数 Divergence_Index**（Kimi 冻结） | `(open_num 或 0) × level`（level 用 continue_num 或 level 字段；合同里两者二选一，哪个非空用哪个，都非空用 continue_num） | >10 = 🔴；5-10 = 🟡；<5 = 🟢 | 宝鼎科技 3×5=15→🔴；高争民爆 4×3=12→🔴；百花 0×5=0→🟢 |
| **T1 动态阈值档**（Kimi 冻结） | `首板数（level==1 计数）` → 档 A：首板 >80 时 T1 判断阈值 = 20%；档 B：首板 <60 时 T1 判断阈值 = 30%；中间值插值或用 A 档偏保守 | T1 数值 **>对应阈值档** = 有主线；**<阈值档×0.66** = 极散；其余=中性 | 8/10 首板=86 → 档A阈值20% → T1=12.1% <13.2%（0.66×20）→ 极散 ✅ 命中 |
| **T3 有主次阈值**（GLM 修正） | `Top3 主题材数之和 / 总连板数 ×100%` | >55% = 有主次；40-55% = 中间；<40% = 无主线 | 23.2% <40% → 无主线 极散 ✅ |
| **Purity 中高位纯度**（GLM 强制口径 ≥2 板） | `(level>=2)中 primary_theme Top1 数 / (level>=2总数) ×100%` | >50% = 中高位集中；25-50%=中性；<25%=中高位也散 | 医药8只/13只=61.5%>50 → 中高位集中（全池散但中高位有小抱团） |
| **方向对齐度**（DeepSeek 冻结） | `len( {天梯 Top3 primary_theme} ∩ {sector 前5 sectorName 字面/同义词匹配} )` → 0/1/2/3 四档 | 0 = 严重背离（🟡格立刻降级为谨慎）；1 = 弱对齐；2 = 正常；3 = 强同向对齐 | 天梯 Top3=医药+智能电网+电力；sector前5=锂电+有色+黄金+军工+酿酒 → 字面0 → 0/3 严重背离 ✅ |
| **头部比值**（Kimi 补充） | `abs(mainNetAmount 排序第1) / abs(第5)` | >4 = 真抱团尖峰；3-4 = 中；<3 = 头部钝（即使体量也不算集中） | 20.9/8.2=2.6 <3 → 头部钝 ✅ |
| **封板比 3 档** | `abs(order_amount) / abs(trading_amount)`（金额单位都为元，直接相除） | >1=强🟢 / 0.3-1=中🟡 / <0.3=弱🔴 | 百花 4.49e8/5.93e7=7.57→🟢；宝鼎 1.299e8/1.23e9=0.11→🔴 |
| **换率 3 档**（GLM 修正：直接读 `turnover_rate` 百分值字段，不要自算） | 直接读 `stocks[].turnover_rate`（单位已带%） | <10% 低 / 10-25% 中 / >25% 高 | 百花 1.3→低；宝鼎 6.5→中 |
| **高标风险档 R/Y/G 合成规则**（3 条件 OR 关系，任一🔴=R，任一🟡且🔴=R，其余🟢） | 🔴触发任一：封单比<0.3 / 分歧指数>10 / 换率>25 | 🟡触发任一：封单比 0.3-1 / 分歧 5-10 / 换率 10-25 | 百花 封强🟢+DI0🟢+换低🟢 → G🟢；宝鼎 封弱🔴 + DI15🔴 + 换中🟡 → R🔴（任一🔴=R） |
| **假强警示**（原第一版最值钱 + 5家全一致） | `sector 前5合计 <100亿` **且** `今最高板 > 昨最高板`（板数抬升，不是板高数值）= 触发 | 触发 → P1 操作约束里仓位自动降 1 档（积极→中性 / 中性→谨慎 / 谨慎→休息） | 前5=72.5亿<100 且 今5板>昨4板 → ✅ 触发假强警示 |
| **背离持续天数 → 3天降级**（Kimi 冻结） | 连续 N 天满足：「天梯情绪档=高 × sector 资金档=低 × 方向对齐度=0」| N=1 → 🟡谨慎 ； N=2 → 🟡+⚠️警惕第3天；N≥3 → 强制降🔴休息（不管其他指标） | 8/10 N=1 → 🟡首板试错（若 8/11、8/12 再连续两天同状态，8/13 开盘直接休息） |
| **24 房预期差 4 档阈值**（DeepSeek+Kimi+GLM 联合） | A桶9房提及次数 + open_num≥2 反向预警 + float_market_cap（推荐字段）50/20亿切 | 0次且 >50亿+主流 =⭐真预期差；0次且 <20亿冷门=⚠️存疑；1-2次=🟢共鸣；3-4次=⚠️共识；≥5次或3-4次+open_num≥2=🔴陷阱 | 举例：宝鼎 若 A桶提 6次 → 🔴；百花 0次+市值>50亿+医药=⭐ |
| **晋级率 3 档**（GLM 跨日，2→3 最敏感） | `今日 level=3 code ∩ 昨日 level=2 code 的数量 / 昨日 level=2 总数 ×100%`（按 code 严格匹配，排除新直接跳 3 板的题材票） | >50% 顺畅；20-50% 中性；<20% 乱（晋级率<20% + 中位断层同时=次日不做≥3板接力） | 举例：昨2板6 / 今3板2 = 33% 中性（8/10样例；若昨2板仅5只/今3板1只=20% 边缘乱） |

### 7.3 「缺字段时降级」兜底表（最小合同里字段是 recommend 或 optional，拿不到时怎么不崩）
