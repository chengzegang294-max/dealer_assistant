```text
你现在参与的是一个多AI讨论，不是自由闲聊。

TASK:
- 讨论当前这批手头信息源，应该如何分层、排序、付费选择与接入分工，服务于“A5 为金融测试做标准化准备”。
- 本轮目标不是泛泛聊软件，而是要形成：正式源优先级、付费顺序、来源分工、以及当前最小下一步。

BACKGROUND:
- 当前项目主线不是直接做金融回测，也不是继续挖截图页名。
- 当前 A5 已经从“第二轮新日期样本准备”纠偏到“先明确信息源，再决定正式源怎么接进标准化链”。
- 当前已经做完：
  1. 第一日期页面样本已立住
  2. 标准化准备四件套已落盘
  3. 第二日期 workflow 已搭好但降级为备用执行层
- 当前真正卡住的是：
  1. 正式数据源到底优先买哪类
  2. 样本源/增强源/正式源怎么分工
  3. 现有材料如何物尽其用
- 当前已经把手头来源正式吸收为 6 类：
  1. Tushare
  2. 东方财富
  3. 信息直播间/萌侠博客
  4. 同花顺
  5. 微信网页—金十报告&黄金盯盘
  6. 连板天梯网站/quicktiny
- 当前已有判断：
  - 东方财富 = 当前样本源
  - 连板天梯/quicktiny = 高度结构增强源
  - Tushare = 正式结构化数据源候选
  - 同花顺 L2 目前不确定是否值得优先买

DESIRED_EFFECT:
- 这轮讨论希望最后帮助我们达到 4 个效果：
  1. 选出“当前最值得优先付费/接入”的正式源
  2. 明确东方财富、连板天梯、Tushare、同花顺、直播/金十各自的角色
  3. 明确哪些现有来源继续保留，哪些只做旁证或参考层
  4. 给出不超过 3 步的最小下一步，让项目能继续推进而不是停在抽象讨论

KNOWN_CONSTRAINTS:
- 不能把猜测写成事实
- 没有证据支撑的地方必须写 NEED_EVIDENCE
- 当前不要展开：
  - 第二日期 workflow 细节
  - 页面命名细枝末节
  - 任何金融收益结论
- 当前优先稳定“正式数据源选择”与“来源分工”

DISCUSSION_SCOPE:
- 本轮允许讨论：
  1. 正式源应该优先买哪类
  2. 样本源/增强源/正式源/参考层如何分工
  3. 哪些现有来源最值得物尽其用
  4. 多AI讨论本身应该如何分工与回收
- 本轮不要展开：
  1. 具体代码实现
  2. 具体回测策略
  3. 具体单只股票结论

FREE_GUESS_RANGE:
- 允许你合理推测：
  - 如果 Tushare/同花顺L2/连板天梯 具有常见能力，各自更适合承担什么角色
  - 页面源与结构化源的典型分工
  - 在“预算有限、先求标准化准备而不是追求最全”的前提下，怎样排付费顺序更合理
  - 如何最大化利用当前已经有的 6 类来源，而不是从零重来
- 若缺证据必须写 NEED_EVIDENCE：
  - Tushare 当前具体权限层级
  - quicktiny 是否支持历史导出
  - 同花顺 L2 当前是否已实际购买、是否能导出

EXPECTED_OUTPUT:
- 请至少给出 3 个不同方案：
  - 保守方案
  - 平衡方案
  - 激进方案
- 每个方案都要说明：
  - 正式源优先买什么
  - 哪些现有来源继续保留
  - 哪些来源只做旁证
  - 想实现的效果是否能达成
  - 风险与 NEED_EVIDENCE

OUTPUT CONTRACT:
1. 结论摘要
2. 方案对比（至少3个：保守/平衡/激进）
3. 你最推荐的方案
4. 当前最小下一步（最多3条）
5. 你认为当前最值得优先补证的唯一缺口
```
