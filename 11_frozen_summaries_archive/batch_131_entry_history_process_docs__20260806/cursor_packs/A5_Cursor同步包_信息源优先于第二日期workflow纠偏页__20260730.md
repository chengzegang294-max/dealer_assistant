## 一、这页用途

- 本页只做：
  1. 给 `Cursor` 补一条纠偏同步
  2. 明确当前顺序应改为：
     `先信息源明确，再启用第二日期 workflow`
  3. 防止把已搭好的 workflow
     误当成当前默认主线

## 二、当前纠偏结论

- 当前正式纠偏为：
  1. `第二日期接入 workflow`
     不是当前默认下一手
  2. 当前更稳的顺序应是：
     - 先把信息源分层、优先级、角色讲清楚
     - 再决定第二日期样本什么时候进入标准化链
  3. 已完成的 workflow/脚手架
     当前保留为：
     `信息源明确之后的备用执行层`

## 三、为什么要这样纠偏

- 因为当前真正还没冻结清楚的是：
  1. 哪些来源只是当前样本源
  2. 哪些来源是未来金融测试优先源
  3. `东方财富 PC / 付费A股数据 / A股直播空间 / 连板天梯 / batch149-longhuvip`
     分别处于什么层级

- 若这层不先讲清楚，
  继续往下启用第二日期 workflow，
  会让顺序看起来像：
  `执行链先于来源判断`

## 四、当前主线应如何表述

- 当前主线更准确的表述应改为：
  - `先把信息源明确，再决定第二日期怎么进标准化链`

- 当前不是：
  1. 继续补脚手架
  2. 继续深挖截图页名
  3. 直接触发第二日期 workflow

## 五、当前对 Cursor 的执行口径

1. 当前第一优先不是
   `跑第二日期 workflow`
2. 当前第一优先是
   `信息源分层与优先级冻结`
3. 现有第二日期 workflow
   不废弃，
   但降级成：
   `信息源明确之后可直接启用的备用执行链`

## 六、下一步准备做什么

  1. `信息源分层与优先级冻结页`
  2. `当前样本源 / 正式源 / 增强源 / 待接入源`
