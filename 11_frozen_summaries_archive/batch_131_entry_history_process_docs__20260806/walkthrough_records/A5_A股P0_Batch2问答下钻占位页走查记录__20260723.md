# A5 A股 P0 Batch2 问答下钻占位页走查记录

更新时间：2026-07-23

## 一、走查目标

- 验证 `Batch2` 问答下钻已从“入口占位”推进到“真实可进入的占位页”。
- 验证 `首页 -> 标的页 -> 问答页 -> 标的页` 返回链是否保留当前事件上下文。
- 验证推荐问题切换时，占位回答是否按问题类型命中不同字段重点。

## 二、走查环境

- 本地地址：`http://localhost:5173/`
- 走查标的：`300750`
- 走查方式：桌面端真实点击流

## 三、走查路径

- 首页点击 `个股出现启动候选信号`
- 点击 `发出打开标的页动作：300750`
- 标的页切到 `所属行业强弱出现明显偏移`
- 点击 `查看推荐问答`
- 在问答页依次点击：
  - `这次事件为什么触发`
  - `历史类比对应了哪段过去情况`
  - `下一次复查点要看什么`
- 点击 `回到标的页`

## 四、走查结果

- 通过：首页可进入 `/stock/300750`
- 通过：标的页切换相关事件后，URL 会保留 `eventId`
- 通过：问答页正确显示 `标的 / 当前事件 / still_need_evidence`
- 通过：推荐问题切换后，问答标题、问题复述、解释补充、记录提醒都会随问题类型变化
- 通过：点击 `回到标的页` 后，仍停留在原 `eventId` 对应事件，没有丢上下文
- 通过：标的页入口区已去掉禁用输入框，改成“先看推荐问题”的能力说明，和当前可点击入口一致
- 通过：本轮未见页面白屏、路由失效或业务控制台报错

## 五、主负责人结论

- `Batch2` 问答下钻占位页已形成最小真实交互闭环：
  - `标的页当前事件 -> 推荐问题 -> 五段式占位回答 -> 回到原标的事件`
- 当前可以把 `问答下钻` 正式冻结为：
  - `有上下文的占位解释页`
  - 而不是：
  - `自由输入问答`
  - `真实 AI 回答`
