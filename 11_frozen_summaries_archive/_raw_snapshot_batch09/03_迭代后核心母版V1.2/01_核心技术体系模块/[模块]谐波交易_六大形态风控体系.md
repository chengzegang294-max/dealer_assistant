# 核心技术_谐波交易_ABCD形态量化规则

## 核心定义
ABCD形态是谐波交易的基础形态，由A-B-C-D四点构成，B点为A点回撤，D点为C点等幅投射或1.27-1.618扩展，是最常见的谐波交易形态。

## 可量化执行标准

**ABCD形态结构要求（全部满足）**：
1. A→B为初始推动波，幅度≥1xATR
2. B→C为回撤波，C点位于A-B的0.382-0.886回撤区间内
3. C→D为扩展波，D点位于B-C的1.0-1.618扩展位
4. 时间因素：B-C时间与C-D时间比值在0.618-1.618之间
5. A与D不接触（CD≠AB完全等长时允许A=D）

**ABCD入场规则**：

| 入场方式 | 触发条件 | 止损设置 | 目标位 | 仓位 |
|---------|---------|---------|--------|------|
| D点限价 | D点精确到达扩展位(1.0/1.27/1.618) | C点/C点外+0.2xATR | A点/0.618CD | 标准仓 |
| D点确认 | D点出现反转K线(评分≥7分) | C点外+0.2xATR | A点/0.618CD | 标准仓×1.2 |
| 突破入场 | D点反转后突破D点极值 | 极值外+0.2xATR | A点/CD×1.0 | 标准仓 |

**ABCD扩展位优先级**：
- 1.0扩展（等幅AB=CD）：保守D点，胜率最高
- 1.27扩展：标准D点，最常见
- 1.618扩展：激进D点，止损更大

**ABCD失败判定**：
- 价格突破C点 = 形态失败，止损离场
- D点到达后无反转继续运行 = 形态失败
- 连续2次ABCD失败 = 暂停该周期谐波交易

## 适用场景与禁忌
- **适用场景**：所有品种所有周期，5分钟至日线均可
- **禁忌场景**：B-C回撤>AB的100%时形态失效；无反转K线确认的D点禁止入场
- **核心约束**：ABCD是谐波交易基础形态，所有高级形态（加特利/蝙蝠等）均基于ABCD扩展

# 核心技术_谐波交易_三重推动TripleDrive量化规则

## 核心定义
三重推动(Triple Drive/3 Drives)是谐波交易的趋势终结形态，由三个依次同向的推动浪组成，每个推动浪的幅度和时间为斐波那契比例关系，第三推动末端为趋势反转高概率点。

## 可量化执行标准

**三重推动结构要求（全部满足）**：
1. 三个推动浪同向（均为上涨或均为下跌）
2. 每个推动浪之间有回调浪连接
3. 推动浪2幅度 = 推动浪1幅度 × (1.27-1.618)
4. 推动浪3幅度 = 推动浪2幅度 × (1.27-1.618)
5. 时间比例：各推动浪时间也呈斐波那契关系（可选增强条件）

**三重推动入场规则**：

| 要素 | 量化标准 |
|------|---------|
| 第三推动识别 | 价格触及第二推动的1.27-1.618扩展位 |
| 反转确认 | 第三推动末端出现反转K线（评分≥7分） |
| 成交量确认 | 第三推动成交量递减（<第二推动时成交量） |
| 入场点 | 第三推动末端反转K线收盘 |
| 止损 | 第三推动极点外+0.3xATR |
| 目标1 | 第三推动的0.382回撤 |
| 目标2 | 第三推动的0.618回撤 |
| 目标3 | 第二推动起点 |
| 仓位 | 标准仓×1.2（趋势终结高胜率） |
| 最低R:R | 1:2 |

**三重推动与趋势力量关系**：
- 推动浪1幅度大+推动浪2幅度更大+推动浪3最大 = 趋势加速，第三推动末端极高概率反转
- 推动浪3幅度<推动浪2幅度 = 上涨乏力，可能提前反转
- 推动浪3成交量<推动浪2成交量 = 需求/供给枯竭，反转概率提升

**三重推动失败判定**：
- 推动浪3继续延伸超过1.618扩展 = 可能形成五重推动
- 价格突破推动浪2起点 = 形态失效
- 连续2次三重推动失败 = 趋势极强，放弃反转交易

## 适用场景与禁忌
- **适用场景**：趋势末端（日线/4小时）的终极反转识别，结合AL Brooks高潮反转使用
- **禁忌场景**：推动浪幅度<2xATR时形态意义不大；趋势初期（第一推动中）禁止预判三重推动
- **核心约束**：三重推动需等待第三推动完整形成后才可交易，禁止在第二推动中预判第三推动

# 核心技术_谐波交易_入场过滤与止损止盈通用规则

## 核心定义
谐波交易所有形态共用的入场过滤、止损设置、止盈管理、风险控制通用规则，适用于ABCD/加特利/蝙蝠/蝴蝶/螃蟹/三重推动全部形态。

## 可量化执行标准

**入场过滤条件（必须全部满足）**：
1. D点精确触及形态要求的斐波那契位（误差在允许范围内）
2. D点出现反转K线（评分≥7分，蝴蝶/螃蟹≥8分）
3. D点KD指标处于超买(>80)或超卖(<20)区域
4. 形态从X到D的时间≥5根K线（形态需充分发展）
5. D点R:R≥1:2（止损到目标比例）

**止损设置通用规则**：

| 形态类型 | 止损位 | 最大允许止损 |
|---------|--------|-------------|
| ABCD | C点外+0.2xATR | 1xATR |
| 加特利 | X点外+0.2xATR | 1.5xATR |
| 蝙蝠 | X点外+0.2xATR | 1.5xATR |
| 蝴蝶 | D点外+0.3xATR | 2xATR |
| 螃蟹 | D点外+0.4xATR | 2.5xATR |
| 三重推动 | 第三推动极点外+0.3xATR | 2xATR |

**止盈管理通用规则**：
- 目标1（CD的0.382）：到达后平仓50%，止损推至盈亏平衡
- 目标2（CD的0.618）：到达后平仓75%，剩余追踪止损
- 目标3（A点/其他）：到达后100%平仓
- 任何目标到达前出现反向信号K线 = 提前平仓

**风险控制硬性约束**：
- 单笔亏损≤账户资金2%
- 单日最多2笔谐波交易
- 连续2笔止损 = 当日停止谐波交易
- 同一周期同时存在2个以上谐波形态 = 只交易质量最高的1个
- 消息面前后4小时禁止谐波交易

**谐波形态质量评分**：
- 斐波那契位精度（误差越小越好）+40分
- 反转K线质量（评分越高越好）+30分
- KD超买超卖程度（越极端越好）+15分
- 形态时间充分性（>10根K线加分）+15分
- 总分≥70分 = 可交易；<70分 = 观望

## 适用场景与禁忌
- **适用场景**：所有谐波形态交易的统一风控框架
- **禁忌场景**：不满足入场过滤任一条件禁止入场；止损超过最大允许值禁止入场
- **核心约束**：谐波交易是 precision trading，精度要求极高，不达标宁可错过不做错

# 核心技术_谐波交易_加特利Gartley形态量化规则

## 核心定义
加特利形态(Gartley Pattern)是谐波交易最经典形态，由X-A-B-C-D五点构成，B点为XA的0.618回撤，D点为XA的0.786回撤且为BC的1.27-1.618扩展，形状类似"M"或"W"。

## 可量化执行标准

**加特利形态结构要求（全部满足）**：

| 点位 | 计算方式 | 允许误差范围 | 判定标准 |
|------|---------|------------|---------|
| X | 形态起点，显著高点/低点 | - | 波段极点 |
| A | X后的反向极点 | - | XA为初始推动波 |
| B | XA的回撤点 | 0.618±0.03 | B=XA×0.618 |
| C | AB的反弹/回撤点 | 0.382-0.886 | C在AB的0.382-0.886区间内 |
| D | 最终入场点 | XA×0.786±0.03 | D=XA×0.786且D=BC×(1.27-1.618) |

** bullish加特利（W形）入场规则**：
- D点精确触及XA的0.786回撤位
- D点同时触及BC的1.27-1.618扩展位（双条件共振）
- D点出现反转K线（评分≥7分）
- 止损：X点下方+0.2xATR
- 目标1：CD的0.382回撤
- 目标2：CD的0.618回撤
- 目标3：A点
- 仓位：标准仓×1.2（经典形态高胜率）
- 最低R:R：1:2

** bearish加特利（M形）入场规则**：
- D点精确触及XA的0.786回撤位
- D点同时触及BC的1.27-1.618扩展位
- D点出现反转K线（评分≥7分）
- 止损：X点上方+0.2xATR
- 目标1/2/3同上

**加特利形态质量评级**：
- A级：D点精确命中0.786（误差<0.01）+反转K线强信号 = 胜率75%+
- B级：D点误差0.01-0.03 +反转K线中等信号 = 胜率65-75%
- C级：D点误差>0.03 或反转K线弱 = 胜率<65%，谨慎入场

## 适用场景与禁忌
- **适用场景**：日线/4小时/1小时级别的中波段交易，经典形态高胜率
- **禁忌场景**：D点未同时满足XA的0.786和BC的1.27-1.618禁止入场；形态过于扁平（XA<2xATR）意义不大
- **核心约束**：加特利是谐波交易最经典形态，质量要求最高，宁缺毋滥

# 核心技术_谐波交易_蝙蝠Bat形态量化规则

## 核心定义
蝙蝠形态(Bat Pattern)是谐波交易的高胜率形态，由X-A-B-C-D五点构成，B点为XA的0.382-0.500回撤（浅回撤），D点为XA的0.886回撤，因形态形似蝙蝠翅膀而得名。

## 可量化执行标准

**蝙蝠形态结构要求（全部满足）**：

| 点位 | 计算方式 | 允许误差范围 | 判定标准 |
|------|---------|------------|---------|
| X | 形态起点 | - | 波段极点 |
| A | X后的反向极点 | - | XA为初始推动波 |
| B | XA的回撤点 | 0.382-0.500 | B必须在此区间内 |
| C | AB的反弹/回撤点 | 0.382-0.886 | C在AB的0.382-0.886区间内 |
| D | 最终入场点 | XA×0.886±0.03 | D=XA×0.886且D=BC×(1.618-2.618) |

**蝙蝠与加特利的关键区别**：
- 蝙蝠B点回撤浅（0.382-0.500）vs 加特利B点（0.618）
- 蝙蝠D点深（XA的0.886）vs 加特利D点（XA的0.786）
- 蝙蝠BC扩展更大（1.618-2.618）vs 加特利（1.27-1.618）
- 蝙蝠整体更"深"更"尖"

**bullish蝙蝠入场规则**：
- D点精确触及XA的0.886回撤位
- D点同时触及BC的1.618-2.618扩展位
- D点出现反转K线（评分≥7分）
- 止损：X点下方+0.2xATR
- 目标1：CD的0.382回撤
- 目标2：CD的0.618回撤
- 目标3：A点
- 仓位：标准仓×1.5（高胜率形态）
- 最低R:R：1:2

**蝙蝠形态质量评级**：
- A级：B点精确0.500 + D点精确0.886 + 强反转K线 = 胜率80%+
- B级：B点在0.382-0.500区间内 + D点误差<0.03 = 胜率70-80%
- C级：B点靠近区间边缘 + D点误差>0.03 = 谨慎入场

## 适用场景与禁忌
- **适用场景**：日线/4小时级别的反转交易，浅回撤后深度回调的高胜率场景
- **禁忌场景**：B点回撤>0.500时形态可能变异为加特利，需重新分类；D点未满足双条件禁止入场
- **核心约束**：蝙蝠形态是谐波交易中胜率最高的形态之一，A级形态可重仓

# 核心技术_谐波交易_蝴蝶Butterfly形态量化规则

## 核心定义
蝴蝶形态(Butterfly Pattern)是谐波交易的扩展形态，由X-A-B-C-D五点构成，B点为XA的0.786回撤，D点超过X点延伸至XA的1.27-1.618扩展位，整体形态呈蝴蝶展翅状。

## 可量化执行标准

**蝴蝶形态结构要求（全部满足）**：

| 点位 | 计算方式 | 允许误差范围 | 判定标准 |
|------|---------|------------|---------|
| X | 形态起点 | - | 波段极点 |
| A | X后的反向极点 | - | XA为初始推动波 |
| B | XA的回撤点 | 0.786±0.03 | B=XA×0.786 |
| C | AB的反弹/回撤点 | 0.382-0.886 | C在AB的0.382-0.886区间内 |
| D | 最终入场点 | XA×(1.27-1.618) | D超过X点，为XA的1.27-1.618扩展 |

**蝴蝶形态关键特征**：
- D点超过X点（区别于加特利/蝙蝠，D点在XA内部）
- B点回撤较深（0.786）
- CD扩展幅度大（BC的1.618-2.618）
- 整体形态呈"展翅"状，波动幅度大

**bullish蝴蝶（X以下为D点）入场规则**：
- D点触及XA的1.27扩展位（保守）或1.618扩展位（激进）
- D点同时触及BC的1.618-2.618扩展位
- D点出现反转K线（评分≥8分，蝴蝶要求更高）
- 止损：D点下方+0.3xATR（因D点超X，止损较大）
- 目标1：CD的0.382回撤
- 目标2：CD的0.618回撤
- 目标3：A点
- 仓位：标准仓（止损较大，控制仓位）
- 最低R:R：1:2

**bearish蝴蝶（X以上为D点）入场规则**：
- 条件镜像对称
- 止损：D点上方+0.3xATR
- 其余同上

**蝴蝶形态质量评级**：
- A级：D点精确1.27 + B点精确0.786 + 强反转K线 = 胜率70%+
- B级：D点在1.27-1.618区间内 + B点误差<0.03 = 胜率60-70%
- C级：D点靠近1.618（止损过大）或误差>0.03 = 轻仓或放弃

**蝴蝶风险提示**：
- D点超过X点 = 趋势极端延伸，随时可能反转也可能继续
- 蝴蝶形态止损通常较大（因D点远离X点）
- 必须在D点有强反转K线确认，禁止在D点无信号入场

## 适用场景与禁忌
- **适用场景**：趋势极端延伸后的反转交易，大级别D点（1.27优先）
- **禁忌场景**：D点无强反转K线禁止入场；D点>XA的1.618时止损过大，需评估R:R
- **核心约束**：蝴蝶形态风险收益比需严格计算，R:R<1:2时放弃

# 核心技术_谐波交易_螃蟹Crab形态量化规则

## 核心定义
螃蟹形态(Crab Pattern)是谐波交易中D点最深远的形态，由X-A-B-C-D五点构成，B点为XA的0.382-0.618回撤，D点大幅超越X点至XA的1.618扩展位，整体形态似螃蟹钳子大幅张开。

## 可量化执行标准

**螃蟹形态结构要求（全部满足）**：

| 点位 | 计算方式 | 允许误差范围 | 判定标准 |
|------|---------|------------|---------|
| X | 形态起点 | - | 波段极点 |
| A | X后的反向极点 | - | XA为初始推动波 |
| B | XA的回撤点 | 0.382-0.618 | B在此区间内 |
| C | AB的反弹/回撤点 | 0.382-0.886 | C在AB的0.382-0.886区间内 |
| D | 最终入场点 | XA×1.618±0.05 | D=XA×1.618且D=BC×(2.24-3.618) |

**螃蟹形态关键特征**：
- D点最远：XA的1.618扩展（所有谐波形态中D点最远）
- B点灵活：0.382-0.618区间（范围较宽）
- CD扩展极大：BC的2.24-3.618扩展
- 整体形态"张得很开"，波动幅度极大

**bullish螃蟹入场规则**：
- D点触及XA的1.618扩展位
- D点同时触及BC的2.24-3.618扩展位
- D点出现强反转K线（评分≥8分）
- 止损：D点下方+0.4xATR（止损最大）
- 目标1：CD的0.382回撤
- 目标2：CD的0.618回撤
- 目标3：A点
- 仓位：标准仓×0.7（止损大，减仓）
- 最低R:R：1:2.5（因止损大，需更高R:R补偿）

**螃蟹形态适配场景**：
- 极端行情（单边暴涨/暴跌后的最终反转）
- 大周期（日线/周线）的年度级拐点
- 多周期谐波共振的D点叠加

## 适用场景与禁忌
- **适用场景**：极端单边行情后的终极反转，大级别拐点交易
- **禁忌场景**：小周期（<1小时）螃蟹形态失败率高；D点无极强反转K线禁止入场
- **核心约束**：螃蟹形态是所有谐波形态中风险最高的，必须严格止损，R:R不达标绝对放弃
