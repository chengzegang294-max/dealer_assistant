# 核心技术_威科夫_价格周期四阶段量化规则

## 核心定义
威科夫价格周期将市场划分为积累(A)、上涨(M)、派发(D)、下跌(M)四个阶段，通过价格波动结构、成交量特征、K线形态三维度量化判定当前所处阶段。

## 可量化执行标准

**阶段A 积累阶段判定条件（满足4项以上）**：
1. 前期下跌趋势明显，跌幅>10%
2. 价格开始横盘整理，波动幅度收窄（ATR递减20%+）
3. 成交量在下跌末端放量（>均量150%），随后缩量整理
4. 出现弹簧(Spring)现象：价格短暂跌破横盘区间下轨后迅速回到区间内
5. 自动反弹(AR)出现：从区间下轨的自动反弹幅度>区间高度的30%
6. 二次测试(ST)：价格再次测试区间下轨，成交量萎缩

**阶段B 上涨阶段判定条件（满足4项以上）**：
1. 价格突破区间上轨+收盘于上轨外侧
2. 突破时成交量放大（>均量120%）
3. 回踩测试突破点（回测）时不跌破区间上轨
4. 回测成交量萎缩（<突破时成交量的70%）
5. 高点持续抬高，低点持续抬高
6. 均线系统多头排列（5EMA>20EMA>60EMA）

**阶段C 派发阶段判定条件（满足4项以上）**：
1. 前期上涨趋势明显，涨幅>10%
2. 价格开始横盘整理，波动幅度收窄
3. 上涨末端成交量异常放大或萎缩
4. 出现上抛(UT)现象：价格短暂突破横盘区间上轨后迅速回到区间内
5. 自然回落(LPSY)：从区间高点的回落幅度>区间高度的30%
6. 最后支撑点(LPS)：价格测试区间下沿，成交量放大

**阶段D 下跌阶段判定条件（满足4项以上）**：
1. 价格跌破区间下轨+收盘于下轨外侧
2. 跌破时成交量放大
3. 反弹测试跌破点时不突破区间下轨
4. 反弹成交量萎缩
5. 高点持续降低，低点持续降低
6. 均线系统空头排列（5EMA<20EMA<60EMA）

**阶段判定优先级**：
- 成交量特征 > 价格结构 > 时间因素
- 弹簧/上抛是阶段转换的最强信号
- 阶段B和D必须有突破+回测确认

## 适用场景与禁忌
- **适用场景**：股票/指数的中期波段（周线/日线）阶段判定，用于确定大方向
- **禁忌场景**：5分钟等超短周期威科夫阶段判定不可靠；单一信号判定阶段禁止交易
- **核心约束**：威科夫周期以日线/周线为主要判定周期，小周期仅作入场时机选择

# 核心技术_威科夫_供需关系量价分析规则

## 核心定义
供需关系(Supply & Demand)是威科夫体系的核心分析框架，通过价格变动与成交量配合关系，判定买方（需求）与卖方（供给）的力量对比。

## 可量化执行标准

**需求主导信号（多头特征）**：

| 量价组合 | 判定条件 | 需求强度 | 交易含义 |
|---------|---------|---------|---------|
| 价涨量增 | 收盘价上涨>0.5xATR + 成交量>均量120% | 强需求 | 上涨趋势确认，可顺势入场 |
| 价涨量缩 | 收盘价上涨>0.5xATR + 成交量<均量80% | 弱需求 | 上涨乏力，注意反转 |
| 价跌量缩 | 收盘价下跌>0.5xATR + 成交量<均量80% | 供给枯竭 | 下跌末端信号，准备抄底 |
|  Springs量缩 | 价格跌破区间+成交量<均量80% | 供给耗尽 | 弹簧形成，即将反弹 |
| 回踩量缩 | 突破后回踩+成交量<突破时70% | 需求稳定 | 回测成功，可加仓 |

**供给主导信号（空头特征）**：

| 量价组合 | 判定条件 | 供给强度 | 交易含义 |
|---------|---------|---------|---------|
| 价跌量增 | 收盘价下跌>0.5xATR + 成交量>均量120% | 强供给 | 下跌趋势确认，可顺势做空 |
| 价跌量缩 | 收盘价下跌>0.5xATR + 成交量<均量80% | 弱供给 | 下跌乏力 |
| 价涨量缩 | 收盘价上涨>0.5xATR + 成交量<均量80% | 需求不足 | 上涨末端信号 |
| UT量异常 | 价格突破区间+成交量非持续放大 | 假需求 | 上抛形成，即将回落 |
| 反弹量缩 | 跌破后反弹+成交量<跌破时70% | 供给稳定 | 反弹失败，可继续做空 |

**关键量价结构**：
- 努力(成交量)与结果(价格变动)背离：成交量放大但价格变动小 = 潜在反转
- 无需求上涨：连续上涨但成交量递减 = 上涨不可持续
- 无供给下跌：连续下跌但成交量递减 = 下跌即将结束

## 适用场景与禁忌
- **适用场景**：趋势方向确认、阶段转换识别、入场时机选择
- **禁忌场景**：单一量价信号不做独立交易依据，必须结合价格结构；小盘股/庄股量价分析可能失真
- **核心约束**：成交量分析以日线为主，5分钟成交量噪音过多仅作辅助参考

# 核心技术_威科夫_努力与结果法则量化规则

## 核心定义
努力与结果(Effort vs Result)法则是威科夫供需分析的精髓，通过比较成交量（努力）与价格变动幅度（结果）的匹配关系，识别趋势的健康度和潜在反转。

## 可量化执行标准

**努力与结果匹配判定**：

| 类型 | 成交量(努力) | 价格变动(结果) | 市场含义 | 交易动作 |
|------|------------|--------------|---------|---------|
| 健康上涨 | 放大(>120%均量) | 大幅上涨(>1xATR) | 需求强劲，趋势健康 | 持仓或顺势加仓 |
| 健康下跌 | 放大(>120%均量) | 大幅下跌(>1xATR) | 供给强劲，趋势健康 | 持仓或顺势加仓 |
| 上涨背离 | 放大(>120%均量) | 小幅上涨(<0.5xATR) | 需求努力但无结果，上涨乏力 | 警惕反转，减仓 |
| 下跌背离 | 放大(>120%均量) | 小幅下跌(<0.5xATR) | 供给努力但无结果，下跌乏力 | 警惕反转，准备抄底 |
| 无量上涨 | 萎缩(<80%均量) | 上涨(>0.5xATR) | 无需求推动的上涨，不可持续 | 不追涨，准备做空 |
| 无量下跌 | 萎缩(<80%均量) | 下跌(>0.5xATR) | 无供给推动的下跌，即将止跌 | 不追空，准备抄底 |
| 均衡震荡 | 正常(80-120%) | 小幅波动(<0.5xATR) | 供需平衡，等待突破 | 观望 |

**背离量化阈值**：
- 成交量放大比例 / 价格变动幅度 < 1.5 = 正常关系
- 成交量放大比例 / 价格变动幅度 > 2.0 = 疑似背离
- 连续3根K线出现背离 = 确认背离，趋势即将反转

**努力与结果在阶段识别中的应用**：
- 阶段A（积累）：下跌放量→缩量整理 = 供给枯竭
- 阶段B（上涨）：上涨放量→回测缩量 = 需求主导
- 阶段C（派发）：上涨放量→缩量滞涨 = 需求枯竭
- 阶段D（下跌）：下跌放量→反弹缩量 = 供给主导

## 适用场景与禁忌
- **适用场景**：趋势健康度监测、反转预警、持仓管理决策
- **禁忌场景**：单根K线的努力结果不匹配不立即行动，需连续2-3根确认；消息驱动行情量价关系可能失真
- **核心约束**：努力结果法则是辅助判断工具，不直接产生交易信号，需结合价格结构综合决策

# 核心技术_威科夫_复合人操作量化分析

## 核心定义
复合人(Composite Operator)是威科夫理论中对机构主力/大资金操作行为的抽象概念，通过识别复合人的积累-拉升-派发-打压的完整操作周期，跟随主力资金方向进行交易。

## 可量化执行标准

**复合人积累行为识别（满足3项以上）**：
1. 价格下跌末期成交量异常放大（恐慌盘涌出）
2. 价格进入横盘区间，波动收窄（主力吸筹）
3. 区间内多次出现弹簧现象（清洗浮筹）
4. 自动反弹(AR)后二次测试(ST)成交量萎缩
5. 区间内高点和低点逐步抬高（吸筹痕迹）
6. 大单成交占比提升（>日均水平20%）

**复合人拉升行为识别（满足3项以上）**：
1. 价格突破区间上轨+成交量持续放大
2. 突破后回测不跌破区间上轨
3. 均线系统多头排列
4. 上涨过程中回调时间短（<5根K线）、幅度小（<30%涨幅）
5. 量价齐升，无背离现象

**复合人派发行为识别（满足3项以上）**：
1. 价格上涨末期成交量异常放大或萎缩
2. 价格进入横盘区间，波动收窄
3. 区间内多次出现上抛现象（诱多）
4. 自然回落(LPSY)后最后支撑点(LPS)成交量放大
5. 区间内高点和低点逐步降低

**复合人打压行为识别（满足3项以上）**：
1. 价格跌破区间下轨+成交量放大
2. 跌破后反弹不突破区间下轨
3. 均线系统空头排列
4. 下跌过程中反弹时间短（<5根K线）、幅度小

**跟随复合人交易策略**：
- 阶段A（积累）：不操作，观察和等待弹簧信号
- 阶段B（上涨）：回测入场，顺势持仓
- 阶段C（派发）：不操作，观察UT信号准备做空
- 阶段D（下跌）：反弹入场做空，顺势持仓

## 适用场景与禁忌
- **适用场景**：大盘股/指数等主力资金主导的品种，日线/周线级别分析
- **禁忌场景**：小盘股/庄股主力行为过于隐蔽，复合人分析可能失效；散户主导品种量价关系失真
- **核心约束**：复合人分析是方向性判断工具，具体入场仍需等待价格信号确认

# 核心技术_威科夫_弹簧Spring与上抛UT量化判定

## 核心定义
弹簧(Spring)是积累阶段价格短暂跌破区间下轨后迅速回到区间内的假突破形态；上抛(Upthrust, UT)是派发阶段价格短暂突破区间上轨后迅速回到区间内的假突破形态。两者是阶段转换的最强先行信号。

## 可量化执行标准

**弹簧(Spring)量化判定条件（全部满足）**：
1. 前期处于积累阶段横盘区间（≥10根K线）
2. 价格跌破区间下轨（跌破幅度<区间高度的20%）
3. 跌破后迅速回到区间内（5根K线内回到区间内）
4. 回到区间内后收盘于区间下轨之上
5. 跌破时成交量萎缩或正常（非恐慌放量）
6. 回到区间内后出现多头信号K线（评分≥6分）

**弹簧入场规则**：
- 入场点：价格回到区间内+多头信号K线收盘
- 止损：弹簧最低点下方+0.3xATR
- 目标位：区间上轨 + 区间高度等幅投射
- 仓位：标准仓位×1.2（高胜率形态）
- 最低R:R：1:2

**上抛(UT)量化判定条件（全部满足）**：
1. 前期处于派发阶段横盘区间（≥10根K线）
2. 价格突破区间上轨（突破幅度<区间高度的20%）
3. 突破后迅速回到区间内（5根K线内回到区间内）
4. 回到区间内后收盘于区间上轨之下
5. 突破时成交量未持续放大（诱多特征）
6. 回到区间内后出现空头信号K线（评分≥6分）

**上抛入场规则**：
- 入场点：价格回到区间内+空头信号K线收盘
- 止损：上抛最高点上方+0.3xATR
- 目标位：区间下轨 - 区间高度等幅投射
- 仓位：标准仓位×1.2
- 最低R:R：1:2

**弹簧/上抛失败判定**：
- 价格回到区间内后再次跌破/突破区间边界 = 假弹簧/假上抛
- 失败时立即止损，并等待新的确认信号
- 连续2次失败 = 阶段判定可能错误，重新分析

## 适用场景与禁忌
- **适用场景**：日线/周线级别积累/派发阶段的阶段确认交易，最佳胜率形态之一
- **禁忌场景**：无横盘区间基础的弹簧/上抛无效；跌破/突破幅度>区间高度30%为真突破
- **核心约束**：弹簧/上抛必须在收盘确认回到区间内后才可入场，禁止在跌破/突破过程中预判

# 核心技术_威科夫_突破回测确认量化规则

## 核心定义
突破回测(Breakout Test/Back Test)是价格突破区间边界后，回到原边界附近测试支撑/阻力有效性的行为，是威科夫阶段B（上涨）和阶段D（下跌）的关键确认信号。

## 可量化执行标准

**突破确认条件（全部满足）**：
1. 价格突破区间边界（上轨或下轨）
2. 突破时成交量放大（>均量120%）
3. 突破棒收盘于区间边界外侧
4. 次棒确认：次棒收盘仍于区间外侧

**回测成功判定（多头突破后回测，空头反之）**：
1. 价格回踩区间上轨（原阻力位现变支撑位）
2. 回踩幅度≤区间高度的30%
3. 回踩时成交量萎缩（<突破时成交量的70%）
4. 回踩后出现多头信号K线（评分≥5分）
5. 价格不再跌破区间上轨

**回测失败判定（假突破）**：
1. 价格回到区间内并收盘于区间边界内侧
2. 回踩时成交量放大（>突破时成交量）
3. 连续2根棒线收盘于区间内
4. 出现反向信号K线

**突破回测入场规则**：

| 入场类型 | 入场点 | 止损 | 目标 | 仓位 |
|---------|--------|------|------|------|
| 突破入场 | 突破棒收盘于区间外 | 区间边界内侧+0.2xATR | 区间高度×1.618 | 标准仓×0.8 |
| 回测入场 | 回测信号K线收盘 | 回测低点-0.2xATR | 区间高度×1.618 | 标准仓 |
| 二次突破 | 回测后再次突破前高 | 回测低点-0.2xATR | 区间高度×2.0 | 标准仓×1.2 |

**A股特殊适配**：
- T+1制度下，回测入场优于突破入场（避免当日假突破被套）
- 突破后次日高开低走不回测 = 可能为诱多，需谨慎
- 突破后3日内完成回测确认 = 有效突破概率高

## 适用场景与禁忌
- **适用场景**：日线/周线级别的区间突破交易，是威科夫体系最可靠的入场信号
- **禁忌场景**：突破时无成交量放大禁止追单；回测超过区间高度50%视为回测失败
- **核心约束**：突破回测是阶段B和D的必经之路，无回测的突破大概率是假突破
