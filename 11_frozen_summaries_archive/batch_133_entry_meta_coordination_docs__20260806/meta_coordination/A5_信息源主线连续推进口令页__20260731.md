```text

执行要求：
1. 先判断当前主线、当前不是哪条线、当前最值钱的一步。
2. 默认自主拍板，多走几步，不要一步一确认。
3. 先落正式页，再回填主线索引、执行清单和 README。
4. 严禁偏离到页名细节、碎截图补洞、第二日期 workflow 细拆、Pi 支线扩写。
5. 当前固定顺序保持为：
   - 第一手：Tushare 权限与字段覆盖审计
   - 第二手：quicktiny / 连板天梯 历史导出能力核查
   - 第三手：信息直播间 / 金十 锚点与旁证回链规则

   - 信息直播间 = 解释层 / 旁证层 / 可继续试装

   - 当前主线

   - 下一步做什么
   - 是否需要我出手

当前停点：

若无真实硬分歧、权限问题、破坏性操作或新增证据边界，不要停，继续往下推。
```

## 四、什么时候直接用这条口令

- 当前适合直接复制这条口令的场景：
  - 你想让我沿同一条信息源主线继续推
  - 对话被压缩后需要快速恢复节奏
  - 你不想再给碎碎的新指令

## 五、一句话口径
