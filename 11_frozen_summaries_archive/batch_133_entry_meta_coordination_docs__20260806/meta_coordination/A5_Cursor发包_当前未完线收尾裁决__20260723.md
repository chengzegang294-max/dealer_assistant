# A5 Cursor 发包 当前未完线收尾裁决

更新时间：2026-07-23

## 一、用途

- 本页只做：
  - 把当前仓库“未完线收尾顺序”交给 `Cursor` 做一轮实现向审校
- 本页不做：
  - 重开产品方向
  - 让 `Cursor` 直接替代主负责人拍板

## 三、主负责人当前预裁决

- 当前预裁决不是让 `Cursor` 决定方向，而是让它帮忙确认：
  - `5` 条未完线的计数是否稳
  - 收尾顺序是否应保持：
    1. `Batch2 无效/空 eventId 降级`
    2. `git 脏区安排`
    3. `截图区 5 任务`
    4. `活跃文档去漂移`
    5. `FV gate 挂起口径`

## 四、一句话口径

- 这轮 `Cursor` 只审“收尾顺序与是否误开旧线”，不审产品方向，不审新架构。
