# A5 交易逻辑与策略形态 多AI讨论预留页

更新时间：2026-07-16

## 用途

- 把“股票操作怎么赚钱、怎么交易、做什么类型、如何组合使用”正式纳入后续多AI讨论主题。
- 防止这类高价值问题在执行主线里被口头提过后就散掉。

## 当前结论

- 这条线当前不直接抢主线。
- 但它已被正式冻结为：
  - `后续必须进入多AI first-hop 的讨论主题`

## 一、后续应纳入多AI讨论的主题

- 主题 1：
  - 交易赚钱逻辑的主类型
- 主题 2：
  - 趋势延续、突破启动、均值回归、事件驱动各自适合什么市场状态
- 主题 3：
  - 同一指标在不同场景下如何换职责
- 主题 4：
  - 信号如何进入过滤、仓位、退出
- 主题 5：
  - 哪类组合适合做第一轮最小回测
- 主题 6：
  - 当前市场量化资金占比提升后，
    - 股票波动呈现出哪些更稳定的结构特征
    - 这些特征对趋势、突破、反转与仓位控制应怎样改写

## 二、为什么这条线值得多AI

- 因为这里不是简单缺文件。
- 这里是典型的：
  - 缺判断
  - 缺方案比较
  - 缺失败模式对照
- 继续单人往下写，容易变成偏好型拍板。
- 且这轮讨论必须明确允许：
  - 发挥想象空间
  - 提出新的策略形态
  - 推翻当前起点候选

## 三、当前不在这轮展开什么

- 当前不展开：
  - 大规模策略比较
  - 全市场交易风格大全
  - 长周期收益结论争论
- 当前只先把它冻结成：
  - 后续的正式多AI讨论主题

## 四、下一轮适合怎么切

- 等 `target_weight` 真实生成链 smoke-run 再往下推进时：
  - 可直接以 `最小信号组合卡` 为入口
  - 发起一轮多AI讨论
- 当前最顺讨论入口对象：
  - `趋势延续 -> 均线回踩确认`
  - `突破启动 -> 收盘突破 + 量能确认`
- 但当前正式口径也要求：
  - 不拘泥于这两个候选
  - 至少扩展出 `4-6` 类候选或候选簇
  - 允许模型给出“两个都不适合第一轮”的反结论

## 五、后续多AI输出合同补充

- 至少给出：
  - `4-6` 类交易逻辑候选
- 必须覆盖：
  - 趋势延续
  - 突破启动
  - 均值回归或反转
  - 至少一种非 A/B 的新增候选
- 必须允许：
  - 混合型方案
  - 反对型方案
  - 延后型方案
- 必须写清：
  - 各自适合什么状态
  - 为什么能赚钱
  - 最典型的失败模式
  - 该怎么进入过滤、仓位和退出
- 后续还必须补问：
  - 量化资金主导下的波动压缩、尾盘博弈、反身性加速、风格同步化
    分别更适合被当作：
    - 环境过滤器
    - 触发器修正项
    - 仓位缩放约束

## 六、一句话口径

- “怎么赚钱、怎么交易、做什么类型、同一指标怎么在不同场景下用”这条线，已经被正式冻结为后续多AI讨论主线之一，且讨论必须允许扩展、反驳和重组，不拘泥于当前两个起点候选。
