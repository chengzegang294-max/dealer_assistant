# Frozen Summaries Archive

## 用途

- 这里放按批次筛选后迁入的新冻结总结材料。
- 这里不是 `11_冻结总结层_FROZEN_SUMMARIES` 的整包镜像。

## 允许进入

- 当前主线仍需要追溯的冻结总结
- 对活跃对象仍有明确阅读价值的历史总结
- 已确认非乱码、非重复、非损坏残留的材料

## 不允许进入

- 整包冻结总结层复制
- 已有活跃版本完全替代的旧总结
- 乱码残留、损坏备份、恢复中间件
- 没写清保留理由的历史文件
